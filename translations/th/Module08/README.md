# โมดูล 08: ฝึกปฏิบัติด้วย Microsoft Foundry Local - ชุดเครื่องมือสำหรับนักพัฒนาแบบครบวงจร

## ภาพรวม

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) เป็นเจนเนอเรชันถัดไปของการพัฒนา edge AI โดยมอบเครื่องมือที่ทรงพลังให้นักพัฒนาในการสร้าง ปรับใช้ และขยายแอปพลิเคชัน AI ในพื้นที่พร้อมการผสานรวมอย่างราบรื่นกับ Azure AI Foundry โมดูลนี้ครอบคลุม Foundry Local อย่างครบถ้วนตั้งแต่การติดตั้งไปจนถึงการพัฒนาตัวแทนขั้นสูง

**เทคโนโลยีหลัก:**
- Microsoft Foundry Local CLI และ SDK
- การผสานรวม Azure AI Foundry
- การทำนายแบบอุปกรณ์ในพื้นที่
- การแคชและเพิ่มประสิทธิภาพโมเดลในพื้นที่
- สถาปัตยกรรมที่ใช้ตัวแทน

## วัตถุประสงค์การเรียนรู้

หลังจากสำเร็จโมดูลนี้ คุณจะสามารถ:

- **เชี่ยวชาญ Foundry Local**: ติดตั้ง กำหนดค่า และเพิ่มประสิทธิภาพสำหรับการพัฒนาบน Windows 11
- **ปรับใช้โมเดลหลากหลาย**: รันโมเดล phi, qwen, deepseek และ GPT ในพื้นที่ด้วยคำสั่ง CLI
- **สร้างโซลูชันผลิตภัณฑ์**: สร้างแอปพลิเคชัน AI ด้วยการวิศวกรรมพรอมต์ขั้นสูงและการผสานข้อมูล
- **ใช้ระบบนิเวศโอเพ่นซอร์ส**: ผสานรวมโมเดล Hugging Face และผลงานชุมชน
- **พัฒนาตัวแทน AI**: สร้างตัวแทนอัจฉริยะพร้อมความสามารถในการวนซ้ำและการประสานงาน
- **ใช้งานรูปแบบองค์กร**: สร้างโซลูชัน AI ที่เป็นโมดูลและขยายได้สำหรับการใช้งานจริง

## ข้อกำหนดเบื้องต้น

### ความต้องการของระบบ
- **ระบบปฏิบัติการ**: Windows 11 (22H2 หรือใหม่กว่า)
- **หน่วยความจำ**: 16GB RAM (แนะนำ 32GB สำหรับโมเดลขนาดใหญ่)
- **พื้นที่เก็บข้อมูล**: พื้นที่ว่าง 50GB สำหรับการแคชโมเดล
- **ฮาร์ดแวร์**: แนะนำอุปกรณ์ที่เปิดใช้งาน NPU (Copilot+ PC), GPU เป็นทางเลือก
- **เครือข่าย**: อินเทอร์เน็ตความเร็วสูงสำหรับดาวน์โหลดโมเดลเริ่มต้น

### สภาพแวดล้อมการพัฒนา

- Visual Studio Code พร้อมส่วนขยาย AI Toolkit
- Python 3.10+ และ pip
- Git สำหรับควบคุมเวอร์ชัน
- PowerShell หรือ Command Prompt
- Azure CLI (ทางเลือกสำหรับการรวมระบบคลาวด์)

### ความรู้เบื้องต้นที่จำเป็น
- ความเข้าใจพื้นฐานเกี่ยวกับแนวคิด AI/ML
- คุ้นเคยกับบรรทัดคำสั่ง
- พื้นฐานการเขียนโปรแกรม Python
- แนวคิด REST API
- ความรู้พื้นฐานเกี่ยวกับการใช้งาน prompt และการอนุมานด้วยโมเดล

## ผลลัพธ์การเรียนรู้

หลังจากทำโมดูลนี้เสร็จ คุณจะมีความสามารถที่จะ:

### ความเชี่ยวชาญทางเทคนิค
- **ติดตั้งและบริหารจัดการ**: Foundry Local บนสภาพแวดล้อมพัฒนาและผลิต
- **รวมโมเดล**: ทำงานร่วมกับตระกูลโมเดลหลากหลายจาก Microsoft, Hugging Face, และชุมชนได้อย่างราบรื่น
- **สร้างแอปพลิเคชัน**: สร้างแอป AI ที่พร้อมใช้งานในผลิตภัณฑ์ด้วยฟีเจอร์ขั้นสูงและการปรับแต่ง
- **พัฒนาเอเย่นต์**: สร้างเอเย่นต์ AI ขั้นสูงที่มีการตั้งฐานความรู้, การใช้เหตุผล และการรวมเครื่องมือ

### ความเข้าใจเชิงกลยุทธ์
- **การตัดสินใจออกแบบสถาปัตยกรรม**: เลือกระหว่างการติดตั้งในเครื่องกับบนคลาวด์อย่างมีข้อมูล
- **การปรับประสิทธิภาพ**: ปรับแต่งประสิทธิภาพการอนุมานบนฮาร์ดแวร์ต่างๆ
- **การปรับขนาดองค์กร**: ออกแบบแอปที่ปรับขยายได้จากต้นแบบในเครื่องถึงการใช้งานในองค์กร
- **ความเป็นส่วนตัวและความปลอดภัย**: ดำเนินการแก้ปัญหา AI ที่รักษาความเป็นส่วนตัวด้วยการอนุมานในเครื่อง

### ความสามารถด้านนวัตกรรม
- **การสร้างต้นแบบอย่างรวดเร็ว**: สร้างและทดสอบแนวคิดแอป AI อย่างรวดเร็วในทุก 10 ตัวอย่าง
- **การรวมชุมชน**: ใช้โมเดลเปิดและมีส่วนร่วมในระบบนิเวศ
- **รูปแบบขั้นสูง**: นำรูปแบบ AI ขั้นสูงจาก RAG, เอเย่นต์ และการรวมเครื่องมือไปใช้
- **ความเชี่ยวชาญกรอบงาน**: การรวมชั้นสูงกับ LangChain, Semantic Kernel, Chainlit และ Electron
- **การติดตั้งใช้งานจริง**: ติดตั้งโซลูชัน AI ที่ปรับขนาดได้จากต้นแบบในเครื่องถึงระบบองค์กร
- **การพัฒนาพร้อมอนาคต**: สร้างแอปที่เตรียมพร้อมสำหรับเทคโนโลยีและรูปแบบ AI ใหม่ๆ

## การเริ่มต้นใช้งาน

1. **ตั้งค่าสภาพแวดล้อม**: ใช้ Windows 11 พร้อมฮาร์ดแวร์แนะนำ (ดูที่ข้อกำหนดเบื้องต้น)
2. **ติดตั้ง Foundry Local**: ทำตามเซสชันที่ 1 สำหรับการติดตั้งและการกำหนดค่าอย่างครบถ้วน
3. **รันตัวอย่าง 01**: เริ่มที่การรวม REST API เบื้องต้นเพื่อตรวจสอบการตั้งค่า

## คู่มือเริ่มต้นด่วน - ตัวอย่างครบ 10 ตัวอย่าง

### การตั้งค่าสภาพแวดล้อม (จำเป็นสำหรับทุกตัวอย่าง)

```powershell
# 1. ทำสำเนาและไปยัง Module08
cd Module08

# 2. สร้างสภาพแวดล้อม Python เสมือน
py -m venv .venv
.\.venv\Scripts\activate

# 3. ติดตั้ง dependencies พื้นฐาน
pip install -r requirements.txt

# 4. ติดตั้ง Foundry Local (ถ้ายังไม่ติดตั้ง)
winget install Microsoft.FoundryLocal

# 5. ตรวจสอบการติดตั้ง Foundry Local
foundry --version
foundry model list
```

### ตัวอย่างพื้นฐานหลัก (01-06)

**ตัวอย่าง 01: REST แชทเริ่มต้นอย่างรวดเร็ว**
```powershell
# เริ่มต้นบริการ Foundry Local
foundry model run phi-4-mini

# รันเดโมแชท REST
python samples/01/chat_quickstart.py
```

**ตัวอย่าง 02: การรวม OpenAI SDK**
```powershell
# ตรวจสอบให้แน่ใจว่าโมเดลกำลังทำงาน
foundry status

# รันตัวอย่าง SDK
python samples/02/sdk_quickstart.py
```

**ตัวอย่าง 03: การค้นหาและทดสอบโมเดล**
```powershell
# รันทดสอบโมเดลอย่างละเอียด
samples/03/list_and_bench.cmd

# หรือรันส่วนประกอบแต่ละตัว
foundry model list --available
foundry model download qwen2.5-0.5b
foundry model benchmark phi-4-mini
```

**ตัวอย่าง 04: แอประบบ RAG ด้วย Chainlit**
```powershell
# ติดตั้ง dependencies ของ Chainlit
pip install chainlit langchain chromadb

# เริ่มต้นแอปพลิเคชันแชท RAG
chainlit run samples/04/app.py -w
# เปิดเบราว์เซอร์ที่ http://localhost:8000
```

**ตัวอย่าง 05: ระบบจัดการหลายเอเย่นต์**
```powershell
# รันตัวอย่างตัวจัดการเอเย่นต์
python -m samples.05.agents.coordinator

# รันตัวอย่างเอเย่นต์เฉพาะเจาะจง
python samples/05/examples/specialists_demo.py
```

**ตัวอย่าง 06: ตัวส่งเส้นทางโมเดลแบบเครื่องมือ**
```powershell
# กำหนดค่าสภาพแวดล้อม
set BASE_URL=http://localhost:8000
set GENERAL_MODEL=phi-4-mini
set CODE_MODEL=qwen2.5-7b

# เรียกใช้เราเตอร์อัจฉริยะ
python samples/06/router.py "Analyze this Python code for performance issues"
```

### ตัวอย่างผสานขั้นสูง (07-10)

**ตัวอย่าง 07: ลูกค้า API โดยตรง**
```powershell
# ไปยังไดเรกทอรีตัวอย่าง
cd samples/07

# ติดตั้ง dependencies เพิ่มเติม
pip install -r requirements.txt

# รันตัวอย่าง API ขั้นพื้นฐาน

# ลองตอบสนองแบบสตรีม
python examples/streaming.py

# ทดสอบรูปแบบโปรดักชัน
python examples/production.py
```

**ตัวอย่าง 08: แอปแชท Windows 11**
```powershell
# ไปที่ไดเรกทอรีตัวอย่าง
cd samples/08

# ติดตั้ง dependencies ของ Node.js
npm install

# เริ่มต้นแอปพลิเคชัน Electron
npm start

npm run build
```

**ตัวอย่าง 09: ระบบหลายเอเย่นต์ขั้นสูง**
```powershell
# ไปที่ไดเรกทอรีตัวอย่าง
cd samples/09

# ติดตั้ง dependencies ของระบบเอเจนต์
pip install -r requirements.txt

# รันตัวอย่างการประสานงานพื้นฐาน
python examples/basic_coordination.py

# ลองใช้ workflow ที่ซับซ้อน
python examples/complex_workflow.py

# สาธิตเอเจนต์แบบโต้ตอบ
python examples/interactive_demo.py
```

**ตัวอย่าง 10: กรอบเครื่องมือ Foundry**

cd samples/10

# ติดตั้ง dependencies ของเฟรมเวิร์ก
pip install -r requirements.txt

# รันเดโมเครื่องมือพื้นฐาน

python examples/rest_api_server.py
# API พร้อมใช้งานที่ http://localhost:8080

### การแก้ไขปัญหาทั่วไป

**ข้อผิดพลาดในการเชื่อมต่อ Foundry Local**
```powershell
# ตรวจสอบสถานะบริการ
foundry status

# รีสตาร์ทหากจำเป็น
foundry restart

# ตรวจสอบความสามารถในการเข้าถึงจุดสุดท้าย
curl http://localhost:5273/v1/models
```

**ปัญหาการโหลดโมเดล**
```powershell
# ตรวจสอบโมเดลที่มีอยู่
foundry model list --cached

# ดาวน์โหลดโมเดลที่ขาดหาย
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# บังคับรีโหลดหากจำเป็น
foundry model unload --all
foundry model run phi-4-mini
```

**ปัญหาเกี่ยวกับ dependency**
```powershell
# อัปเกรด pip และติดตั้งใหม่อีกครั้ง
python -m pip install --upgrade pip
pip install -r requirements.txt --force-reinstall

# สำหรับตัวอย่าง Node.js
npm cache clean --force
npm install
```
