## การเรียกใช้ฟังก์ชันคืออะไร?

การเรียกใช้ฟังก์ชันเป็นความสามารถอันทรงพลังที่อนุญาตให้โมเดลภาษาเล็ก (SLMs) สามารถโต้ตอบกับเครื่องมือภายนอก, APIs และบริการต่าง ๆ แทนที่จะจำกัดอยู่แค่ข้อมูลที่ฝึกอบรม SLMs สามารถ:

- **เชื่อมต่อกับ API ภายนอก** (บริการสภาพอากาศ, ฐานข้อมูล, เครื่องมือค้นหา)
- **เรียกใช้ฟังก์ชันเฉพาะ** ตามคำขอของผู้ใช้
- **ดึงข้อมูลแบบเรียลไทม์** จากแหล่งข้อมูลต่าง ๆ
- **ทำงานคำนวณ** ผ่านเครื่องมือเฉพาะทาง
- **เชื่อมโยงหลายการดำเนินการ** ด้วยกันเพื่อสร้างขั้นตอนที่ซับซ้อน

ความสามารถนี้เปลี่ยน SLMs จากการเป็นเพียงผู้สร้างข้อความแบบคงที่ไปสู่ตัวแทน AI ที่สามารถทำงานในโลกจริงได้อย่างมีพลวัต

## การทำงานของการเรียกใช้ฟังก์ชัน

กระบวนการเรียกใช้ฟังก์ชันจะดำเนินตามเวิร์กโฟลว์ที่เป็นระบบ:

### 1. การผสานรวมเครื่องมือ
- **เครื่องมือภายนอก**: SLMs สามารถเชื่อมต่อกับ API สภาพอากาศ, ฐานข้อมูล, เว็บเซอร์วิส และระบบภายนอกอื่น ๆ
- **การนิยามฟังก์ชัน**: แต่ละเครื่องมือถูกกำหนดด้วยพารามิเตอร์เฉพาะ, รูปแบบข้อมูลเข้า/ออก และคำอธิบาย
- **ความเข้ากันได้ของ API**: เครื่องมือผสานเข้าผ่านอินเทอร์เฟสมาตรฐาน (REST APIs, SDKs, ฯลฯ)

### 2. การกำหนดฟังก์ชัน
ฟังก์ชันถูกกำหนดด้วยส่วนประกอบสำคัญสามประการ:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. การตรวจจับเจตนา
- **การประมวลผลภาษาธรรมชาติ**: SLM วิเคราะห์แบบข้อความของผู้ใช้เพื่อเข้าใจเจตนา
- **การจับคู่ฟังก์ชัน**: กำหนดว่าฟังก์ชันใดที่จำเป็นต้องใช้เพื่อตอบสนองคำขอ
- **การดึงพารามิเตอร์**: ระบุและดึงพารามิเตอร์ที่จำเป็นจากข้อความของผู้ใช้

### 4. การสร้างผลลัพธ์ JSON
SLM สร้าง JSON ที่มีโครงสร้างประกอบด้วย:
- ชื่อฟังก์ชันที่ต้องการเรียก
- พารามิเตอร์ที่จำเป็นพร้อมค่าที่เหมาะสม
- บริบทการทำงานและข้อมูลเมตา

### 5. การดำเนินการภายนอก
- **การตรวจสอบพารามิเตอร์**: ตรวจสอบว่ามีพารามิเตอร์ทุกตัวที่จำเป็นและมีรูปแบบถูกต้อง
- **การเรียกใช้ฟังก์ชัน**: แอปพลิเคชันดำเนินการฟังก์ชันที่ระบุพร้อมพารามิเตอร์ที่ให้มา
- **การจัดการข้อผิดพลาด**: จัดการกับความล้มเหลว, เวลาหมดอายุ และการตอบสนองที่ไม่ถูกต้อง

### 6. การผสานผลลัพธ์
- **การประมวลผลผลลัพธ์**: ผลของฟังก์ชันถูกส่งคืนไปยัง SLM
- **การผสานบริบท**: SLM นำผลลัพธ์มารวมเข้ากับการตอบกลับ
- **การสื่อสารกับผู้ใช้**: แสดงข้อมูลในรูปแบบที่เป็นธรรมชาติและเหมือนสนทนา

## สถานการณ์การประยุกต์ใช้

### การดึงข้อมูล
แปลงคำถามภาษาธรรมชาติให้เป็นการเรียก API ที่มีโครงสร้าง:
- **"แสดงคำสั่งซื้อล่าสุดของฉัน"** → คิวรี่ฐานข้อมูลพร้อมรหัสผู้ใช้และตัวกรองวันที่
- **"สภาพอากาศที่โตเกียวเป็นอย่างไร?"** → การเรียก API สภาพอากาศพร้อมพารามิเตอร์สถานที่
- **"ค้นหาอีเมลจากจอห์นเมื่อสัปดาห์ที่แล้ว"** → คิวรี่บริการอีเมลพร้อมตัวกรองผู้ส่งและวันที่

### การดำเนินงาน
แปลงคำขอของผู้ใช้เป็นการเรียกฟังก์ชันเฉพาะ:
- **"นัดประชุมพรุ่งนี้เวลา 14:00 น."** → การผสานปฏิทิน API
- **"ส่งข้อความถึงทีม"** → API แพลตฟอร์มสื่อสาร
- **"สำรองไฟล์ของฉัน"** → การดำเนินงานระบบไฟล์

### งานคำนวณ
จัดการงานคณิตศาสตร์หรือการประมวลผลเชิงตรรกะที่ซับซ้อน:
- **"คำนวณดอกเบี้ยทบต้น $10,000 ที่ 5% เป็นเวลา 10 ปี"** → ฟังก์ชันคำนวณทางการเงิน
- **"วิเคราะห์ชุดข้อมูลนี้เพื่อหากระแส"** → เครื่องมือวิเคราะห์สถิติ
- **"ปรับเส้นทางนี้ให้เหมาะสมสำหรับการจัดส่ง"** → อัลกอริทึมปรับเส้นทาง

### เวิร์กโฟลว์การประมวลผลข้อมูล
เชื่อมโยงการเรียกฟังก์ชันหลายตัวสำหรับงานที่ซับซ้อน:
1. **ดึงข้อมูล** จากหลายแหล่ง
2. **แยกวิเคราะห์และตรวจสอบ** ข้อมูล
3. **เปลี่ยนรูปแบบ** ข้อมูลเป็นตามที่ต้องการ
4. **เก็บผลลัพธ์** ในระบบที่เหมาะสม
5. **สร้างรายงาน** หรือภาพนำเสนอ

### การผสาน UI/UX
เปิดใช้งานการอัปเดตอินเทอร์เฟซแบบไดนามิก:
- **"แสดงข้อมูลยอดขายบนแดชบอร์ด"** → การสร้างและแสดงแผนภูมิ
- **"อัปเดตแผนที่ด้วยสถานที่ใหม่"** → การผสานข้อมูลเชิงภูมิศาสตร์
- **"รีเฟรชการแสดงสินค้าคงคลัง"** → การซิงโครไนซ์ข้อมูลแบบเรียลไทม์

## การตั้งค่าการเรียกใช้ฟังก์ชันกับ Phi-4-mini และ Ollama

Phi-4-mini ของ Microsoft รองรับทั้งการเรียกใช้ฟังก์ชันแบบเดี่ยวและแบบขนานผ่าน Ollama วิธีตั้งค่ามีดังนี้:

### ข้อกำหนดเบื้องต้น
- Ollama เวอร์ชัน 0.5.13 หรือสูงกว่า
- โมเดล Phi-4-mini (แนะนำ: `phi4-mini:3.8b-fp16`)

ollama run phi4-mini:3.8b-fp16

# ตรวจสอบว่าโมเดลพร้อมใช้งานแล้ว
ollama list

### ตัวอย่างการเรียกฟังก์ชันแบบเดี่ยว

```python
import json
import requests

# กำหนดเครื่องมือ/ฟังก์ชัน
tools = [
    {
        "name": "get_weather",
        "description": "Get current weather information for a location",
        "parameters": {
            "location": {
                "description": "The city or location name",
                "type": "str",
                "default": "New York"
            },
            "units": {
                "description": "Temperature units (celsius or fahrenheit)",
                "type": "str",
                "default": "celsius"
            }
        }
    }
]

# สร้างข้อความพร้อมระบบพร้อมท์ที่รวมเครื่องมือ
messages = [
    {
        "role": "system",
        "content": "You are a helpful weather assistant",
        "tools": json.dumps(tools)
    },
    {
        "role": "user",
        "content": "What's the weather like in London today?"
    }
]

# ส่งคำขอไปยัง Ollama API
response = requests.post(
    "http://localhost:11434/api/chat",
    json={
        "model": "phi4-mini-fc:3.8b-fp16",
        "messages": messages,
        "stream": False
    }
)

print(response.json())
```

## การทำงานกับการเรียกใช้ฟังก์ชัน Qwen3

Qwen3 มีความสามารถการเรียกใช้ฟังก์ชันขั้นสูงด้วยประสิทธิภาพและความยืดหยุ่นสูง วิธีใช้มีดังนี้:

### การใช้กรอบงาน Qwen-Agent

Qwen-Agent มีกรอบงานระดับสูงที่ช่วยให้ง่ายต่อการใช้งานการเรียกใช้ฟังก์ชัน:

#### การติดตั้ง
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### การตั้งค่าเบื้องต้น

```python
import os
from qwen_agent.agents import Assistant

# กำหนดค่าของ LLM
llm_cfg = {
    'model': 'Qwen3-8B',
    # ตัวเลือกที่ 1: ใช้ Alibaba Model Studio
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # ตัวเลือกที่ 2: ใช้การติดตั้งในเครื่อง
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'EMPTY',
    
    # การกำหนดค่าตัวเลือกสำหรับโหมดคิด
    'generate_cfg': {
        'thought_in_content': True,  # รวมเหตุผลในการตอบกลับ
    }
}

# กำหนดเครื่องมือโดยใช้ MCP (โปรโตคอลบริบทของโมเดล)
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # เครื่องมือรันโค้ดในตัว
]

# สร้างผู้ช่วย
bot = Assistant(llm=llm_cfg, function_list=tools)

# ตัวอย่างการใช้งาน
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# สร้างการตอบกลับพร้อมเรียกใช้ฟังก์ชัน
for response in bot.run(messages=messages):
    print(response)
```

### การกำหนดฟังก์ชันแบบกำหนดเอง

คุณยังสามารถกำหนดฟังก์ชันแบบกำหนดเองสำหรับ Qwen3 ได้:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""

            'condition': 'Partly cloudy',
            'humidity': '65%'
        }

import asyncio
import aiohttp

async def batch_function_calls(function_calls):
    """Execute multiple function calls concurrently"""
    async with aiohttp.ClientSession() as session:
        tasks = []
        for call in function_calls:
            if call["name"] == "fetch_url":
                task = fetch_url_async(session, call["parameters"]["url"])
                tasks.append(task)
        
        results = await asyncio.gather(*tasks)
        return results

async def fetch_url_async(session, url):
    async with session.get(url) as response:
        return await response.text()
```

                         handler: callable, rate_limit: int = 60):
        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # ตรวจสอบว่าฟังก์ชันมีอยู่หรือไม่
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # ตรวจสอบข้อจำกัดของอัตรา
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # ตรวจสอบพารามิเตอร์
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # ดำเนินการฟังก์ชัน
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # บันทึกการดำเนินการที่สำเร็จ
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # บันทึกการดำเนินการที่ล้มเหลว
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # รีเซ็ตตัวนับถ้าผ่านไปหนึ่งนาที
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # ตรวจสอบว่าต่ำกว่าขีดจำกัดหรือไม่
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # ตรวจสอบพารามิเตอร์ที่จำเป็น
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # ตรวจสอบประเภทและข้อจำกัดของพารามิเตอร์
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # การตรวจสอบประเภท
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # การตรวจสอบค่าที่เลือกได้
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
        
        return FunctionResult(success=True)

## สรุป

การเรียกใช้ฟังก์ชันในโมเดลภาษาเล็กเป็นการเปลี่ยนแปลงจากผู้ช่วย AI แบบคงที่ไปสู่ตัวแทนที่มีความสามารถและพลวัตซึ่งสามารถโต้ตอบกับโลกจริง บทเรียนนี้ครอบคลุม:

### ประเด็นสำคัญ

1. **ความเข้าใจพื้นฐาน**: การเรียกใช้ฟังก์ชันเปิดโอกาสให้ SLMs ขยายขอบเขตเกินข้อมูลฝึกอบรมด้วยการเชื่อมต่อกับเครื่องมือและบริการภายนอก

2. **ความยืดหยุ่นในการใช้งาน**: มีหลายวิธีตั้งแต่การใช้งานระดับต่ำด้วยเทมเพลตกำหนดเองถึงกรอบงานระดับสูงเช่น Qwen-Agent และ Foundry Local

3. **ข้อควรพิจารณาในการผลิต**: การใช้งานในองค์กรต้องให้ความสำคัญกับการจัดการข้อผิดพลาด, การจำกัดอัตรา, ความปลอดภัย และการบันทึกการตรวจสอบ

4. **การปรับประสิทธิภาพ**: การออกแบบฟังก์ชันที่เหมาะสม, การดำเนินการที่มีประสิทธิภาพ และการแคชอย่างชาญฉลาดสามารถช่วยปรับปรุงเวลาในการตอบสนองได้อย่างมาก

### ทิศทางในอนาคต

เมื่อเทคโนโลยี SLM พัฒนาอย่างต่อเนื่อง เราคาดว่าจะเห็น:

- **ความแม่นยำในการเรียกใช้ฟังก์ชันที่ดีขึ้น**: การตรวจจับเจตนาและการดึงพารามิเตอร์ที่ดีขึ้น
- **การประมวลผลแบบขนานที่เสถียรขึ้น**: การจัดการหลายฟังก์ชันที่ซับซ้อนมากขึ้น
- **มาตรฐานการผสานรวมที่ดีขึ้น**: โปรโตคอลมาตรฐานสำหรับการผสานเครื่องมือ
- **ฟีเจอร์ความปลอดภัยขั้นสูง**: กลไกการรับรองความปลอดภัยและอนุญาตที่ดียิ่งขึ้น
- **ระบบนิเวศที่ขยายตัว**: ไลบรารีของฟังก์ชันและการผสานที่เติบโตขึ้น

### การเริ่มต้น

เพื่อเริ่มใช้งานการเรียกใช้ฟังก์ชันในโปรเจกต์ของคุณ:

1. **เริ่มต้นง่าย ๆ**: เริ่มจากสถานการณ์เรียกฟังก์ชันแบบเดี่ยวพื้นฐาน
2. **เลือกกรอบงานของคุณ**: เลือกระหว่างการใช้งานตรง (Ollama/Phi-4) หรือผ่านกรอบงานช่วยเหลือ (Qwen-Agent)
3. **ออกแบบฟังก์ชันอย่างรอบคอบ**: มุ่งเน้นที่การกำหนดฟังก์ชันที่ชัดเจนและมีเอกสารครบถ้วน
4. **ใช้งานการจัดการข้อผิดพลาด**: สร้างระบบการจัดการข้อผิดพลาดที่มั่นคงตั้งแต่ต้น
5. **ปรับขนาดอย่างช้า ๆ**: ก้าวจากสถานการณ์ง่ายไปสู่ซับซ้อนเมื่อคุณมีประสบการณ์มากขึ้น

การเรียกใช้ฟังก์ชันเปลี่ยน SLMs จากผู้สร้างข้อความที่น่าประทับใจเป็นตัวแทน AI ที่ใช้งานได้จริงซึ่งสามารถแก้ปัญหาในโลกจริง ด้วยการปฏิบัติตามรูปแบบและแนวทางที่อธิบายในบทเรียนนี้ คุณสามารถสร้างระบบ AI ที่ทรงพลังและเชื่อถือได้ที่ก้าวไกลเกินกว่าอินเทอร์เฟซแชทแบบดั้งเดิม

### ทรัพยากรและเอกสารอ้างอิง
