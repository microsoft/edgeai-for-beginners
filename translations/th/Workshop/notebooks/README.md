# สมุดบันทึกเชิงปฏิบัติการ

> **Jupyter Notebooks แบบโต้ตอบสำหรับการเรียนรู้ Edge AI ด้วยตนเอง**
>
> แบบฝึกหัดที่พัฒนาไปตามลำดับและสามารถเรียนรู้ตามจังหวะของตัวเอง ซึ่งเริ่มตั้งแต่การเติมคำแชทพื้นฐานจนถึงระบบหลายตัวแทนอันซับซ้อนโดยใช้ Microsoft Foundry Local และ Small Language Models

## 📖 แนะนำ

ยินดีต้อนรับสู่ชุดสมุดบันทึกเชิงปฏิบัติการ **EdgeAI สำหรับผู้เริ่มต้น** สมุดบันทึก Jupyter แบบโต้ตอบเหล่านี้มอบประสบการณ์การเรียนรู้แบบปฏิบัติที่คุณจะได้เขียน รัน และทดลองกับโค้ด Edge AI แบบเรียลไทม์

### ทำไมต้องใช้ Jupyter Notebooks?

แตกต่างจากแบบฝึกหัดทั่วไปสมุดบันทึกเหล่านี้มีข้อดีดังนี้:

- **การเรียนรู้แบบโต้ตอบ**: รันเซลล์โค้ดและดูผลลัพธ์ทันที
- **การทดลอง**: ปรับเปลี่ยนพารามิเตอร์และสังเกตการเปลี่ยนแปลงแบบเรียลไทม์
- **เอกสารประกอบ**: คำอธิบายและเซลล์ markdown ช่วยแนะนำแนวคิดต่าง ๆ
- **ความสามารถในการทำซ้ำ**: ตัวอย่างทำงานครบถ้วนที่คุณสามารถอ้างอิงและนำกลับมาใช้ใหม่ได้
- **การแสดงภาพ**: แสดงเมตริกการทำงาน, embedding และผลลัพธ์ในเนื้อหา

### อะไรทำให้สมุดบันทึกเหล่านี้พิเศษ?

สมุดบันทึกแต่ละเล่มได้รับการออกแบบตาม **แนวทางปฏิบัติที่พร้อมสำหรับผลิตจริง**:

✅ **การจัดการข้อผิดพลาดครบถ้วน** - การเสื่อมสภาพอย่างสมเหตุสมผลและข้อความข้อผิดพลาดที่ให้ข้อมูล  
✅ **คำแนะนำชนิดข้อมูล & เอกสารประกอบ** - ฟังก์ชันที่มีลายเซ็นชัดเจนและ docstring  
✅ **การติดตามประสิทธิภาพ** - การติดตามการใช้โทเค็นและการวัดความหน่วง  
✅ **การออกแบบเป็นโมดูล** - รูปแบบที่นำกลับมาใช้ได้ซึ่งคุณปรับใช้ในโปรเจกต์ได้  
✅ **ความซับซ้อนที่เพิ่มขึ้นตามลำดับ** - พัฒนาต่อเนื่องจากเซสชันก่อนหน้าเป็นระบบ

## 🎯 วัตถุประสงค์การเรียนรู้

### ทักษะหลักที่คุณจะพัฒนา

โดยการทำงานผ่านสมุดบันทึกเหล่านี้คุณจะเชี่ยวชาญใน:

1. **การจัดการบริการ AI ท้องถิ่น**
   - กำหนดค่าและจัดการบริการ Microsoft Foundry Local
   - เลือกและโหลดโมเดลที่เหมาะสมกับฮาร์ดแวร์ของคุณ
   - ตรวจสอบการใช้งานทรัพยากรและเพิ่มประสิทธิภาพ
   - จัดการการค้นหาบริการและตรวจสอบสุขภาพ

2. **การพัฒนาแอปพลิเคชัน AI**
   - ใช้งานแชทคอมพลีชันที่รองรับ OpenAI แบบท้องถิ่น
   - สร้างอินเทอร์เฟซสตรีมมิ่งเพื่อประสบการณ์ผู้ใช้ที่ดีขึ้น
   - ออกแบบพรอมต์ที่มีประสิทธิภาพสำหรับ Small Language Models
   - รวมโมเดลท้องถิ่นเข้าสู่แอปพลิเคชัน

3. **การสร้างข้อมูลเสริมด้วยการดึงข้อมูล (Retrieval Augmented Generation, RAG)**
   - สร้างการค้นหาเชิงความหมายด้วย vector embeddings
   - เชื่อมโยงคำตอบ LLM กับเอกสารเฉพาะโดเมน
   - ประเมินคุณภาพ RAG ด้วยเมตริก RAGAS
   - ขยายจากต้นแบบไปสู่การใช้จริง

4. **การเพิ่มประสิทธิภาพ**
   - วิเคราะห์เปรียบเทียบหลายโมเดลอย่างเป็นระบบ
   - วัดค่าวงจรหน่วง, อัตราการรับส่งข้อมูล, และเวลาของโทเค็นแรก
   - เปรียบเทียบ Small Language Models กับ Large Language Models
   - เลือกโมเดลที่เหมาะสมโดยพิจารณาการแลกเปลี่ยนระหว่างประสิทธิภาพและคุณภาพ

5. **การประสานงานหลายตัวแทน (Multi-Agent Orchestration)**
   - ออกแบบตัวแทนเฉพาะงานต่าง ๆ
   - ใช้งานหน่วยความจำและการจัดการบริบทของตัวแทน
   - ประสานงานตัวแทนหลายตัวในเวิร์กโฟลว์ซับซ้อน
   - สร้างรูปแบบผู้ประสานงานสำหรับความร่วมมือของตัวแทน

6. **การกำหนดเส้นทางโมเดลอัจฉริยะ**
   - ใช้งานการตรวจจับเจตนาและการจับคู่รูปแบบ
   - กำหนดเส้นทางคำถามไปยังโมเดลที่เหมาะสมโดยอัตโนมัติ
   - สร้างสายงานหลายขั้นตอน (วางแผน → ดำเนินการ → ปรับปรุง)
   - ออกแบบสถาปัตยกรรม model-as-tools ที่ปรับขนาดได้

### 📗 เซสชัน 02: สายงาน RAG
**ไฟล์**: `session02_rag_pipeline.ipynb`  
**ระยะเวลา**: 30-45 นาที  
**ข้อกำหนดเบื้องต้น**: เซสชัน 01  
**ระดับความยาก**: ⭐⭐ ระดับกลาง

**สิ่งที่คุณจะได้เรียนรู้**:
- พัฒนารูปแบบ Retrieval Augmented Generation (RAG)
- สร้าง vector embeddings ด้วย sentence-transformers
- สร้างการค้นหาเชิงความหมายด้วย cosine similarity

### การตรวจสอบอย่างรวดเร็ว

รันในเซลล์ Python นี้เพื่อตรวจสอบการตั้งค่า:

```python
from foundry_local import FoundryLocalManager
import openai

# เริ่มต้นผู้จัดการ (ค้นหาบริการโดยอัตโนมัติ)
manager = FoundryLocalManager("phi-4-mini")

# กำหนดค่าไคลเอนต์ OpenAI
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# ทดสอบการสนทนาเสร็จสมบูรณ์
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**ผลลัพธ์ที่คาดหวัง**: การตอบกลับทักทายจากโมเดลภายในเครื่อง

1. เส้นทางระดับกลางครบถ้วน
2. **เซสชัน 05** - ผู้ประสานงานหลายตัวแทน
3. **เซสชัน 06** - ตัวกำหนดเส้นทางโมเดล
4. **เซสชัน 06** - ท่อข้อมูลหลายขั้นตอน

**เวลา**: ~6 ชั่วโมง | **เน้น**: รูปแบบในงานผลิตจริง

---

### เส้นทางโปรเจกต์เฉพาะ

1. เส้นทางเริ่มต้นครบถ้วน (เซสชัน 01-03)
2. เลือกหนึ่งเซสชันขั้นสูงตามเป้าหมายของคุณ:
   - **สร้างแอป RAG?** → เซสชัน 02 การประเมิน
   - **ปรับประสิทธิภาพ?** → เซสชัน 04 การเปรียบเทียบ
   - **เวิร์กโฟลว์ซับซ้อน?** → เซสชัน 05 ผู้ประสานงาน
   - **สถาปัตยกรรมปรับขนาดได้?** → เซสชัน 06 ตัวกำหนดเส้นทาง + ท่อข้อมูล

**เวลา**: ~3 ชั่วโมง | **เน้น**: ทักษะเฉพาะโปรเจกต์
