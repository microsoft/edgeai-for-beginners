# ประวัติการเปลี่ยนแปลง

การเปลี่ยนแปลงที่น่าสังเกตทั้งหมดสำหรับ EdgeAI สำหรับผู้เริ่มต้นถูกบันทึกไว้ที่นี่ โปรเจกต์นี้ใช้รายการตามวันที่และรูปแบบ Keep a Changelog (เพิ่ม, เปลี่ยนแปลง, แก้ไข, ลบ, เอกสาร, ย้าย)

## 2025-10-30

### เพิ่ม - การปรับปรุงองค์รวมของ Module06 AI Agents
- **การผนวก Microsoft Agent Framework** (`Module06/01.IntroduceAgent.md`):
  - ส่วนสมบูรณ์เกี่ยวกับ Microsoft Agent Framework สำหรับการพัฒนาเอเจนต์ที่พร้อมผลิต
  - รูปแบบการผนวกโดยละเอียดกับ Foundry Local สำหรับการปรับใช้งานที่ edge
  - ตัวอย่างการประสานงานหลายเอเจนต์ด้วยโมเดล SLM เฉพาะทาง
  - รูปแบบการปรับใช้งานระดับองค์กรพร้อมการจัดการทรัพยากรและการตรวจสอบ
  - คุณสมบัติด้านความปลอดภัยและการปฏิบัติตามข้อกำหนดสำหรับระบบเอเจนต์ที่ edge
  - ตัวอย่างการใช้งานจริง (ค้าปลีก, การดูแลสุขภาพ, บริการลูกค้า)

- **กลยุทธ์การปรับใช้งาน SLM Agent ระดับผลิต**:
  - **Foundry Local**: เอกสาร runtime edge AI ระดับองค์กรสมบูรณ์พร้อมการติดตั้ง, การกำหนดค่า, และรูปแบบการผลิต
  - **Ollama**: การปรับใช้งานเน้นชุมชนพร้อมการตรวจสอบและการจัดการโมเดลอย่างครบถ้วน
  - **VLLM**: เครื่องมืออนุมานประสิทธิภาพสูงพร้อมเทคนิคการปรับแต่งขั้นสูงและคุณสมบัติระดับองค์กร
  - รายการตรวจสอบการปรับใช้งานและตารางเปรียบเทียบสำหรับแพลตฟอร์มทั้งสาม

- **การปรับปรุงเฟรมเวิร์ก SLM ที่เหมาะกับ edge**:
  - **ONNX Runtime**: ส่วนใหม่ครบวงจรสำหรับการปรับใช้งาน SLM Agent แบบข้ามแพลตฟอร์ม
  - รูปแบบการปรับใช้งานสากลใน Windows, Linux, macOS, iOS, และ Android
  - ตัวเลือกการเร่งความเร็วฮาร์ดแวร์ (CPU, GPU, NPU) พร้อมการตรวจจับอัตโนมัติ
  - คุณสมบัติพร้อมใช้งานจริงและการปรับแต่งเฉพาะสำหรับเอเจนต์
  - ตัวอย่างการใช้งานครบถ้วนพร้อมผนวก Microsoft Agent Framework

- **เอกสารอ้างอิงและแหล่งข้อมูลเพิ่มเติม**:
  - ห้องสมุดแหล่งข้อมูลครบถ้วนพร้อมแหล่งข้อมูลที่น่าเชื่อถือกว่า 100 แห่ง
  - งานวิจัยแกนหลักเกี่ยวกับเอเจนต์ AI และโมเดลภาษาเล็ก
  - เอกสารทางการสำหรับเฟรมเวิร์กและเครื่องมือหลักทั้งหมด
  - รายงานอุตสาหกรรม, การวิเคราะห์ตลาด, และเกณฑ์มาตรฐานทางเทคนิค
  - แหล่งการศึกษา, การประชุม, และฟอรัมชุมชน
  - มาตรฐาน, ข้อกำหนด, และเฟรมเวิร์กการปฏิบัติตามข้อกำหนด

### เปลี่ยนแปลง - การปรับปรุงเนื้อหา Module06
- **วัตถุประสงค์การเรียนรู้ที่ปรับปรุง**: เพิ่มทักษะความชำนาญ Microsoft Agent Framework และความสามารถในการปรับใช้งาน edge
- **เน้นการผลิต**: เปลี่ยนจากแนวคิดเป็นแนวทางพร้อมใช้งานด้วยตัวอย่างการผลิต
- **ตัวอย่างโค้ด**: อัปเดตตัวอย่างทั้งหมดเพื่อใช้รูปแบบ SDK สมัยใหม่และแนวทางปฏิบัติที่ดีที่สุด
- **รูปแบบสถาปัตยกรรม**: เพิ่มสถาปัตยกรรมเอเจนต์แบบลำดับชั้นและการประสานงานจาก edge สู่ cloud
- **การเพิ่มประสิทธิภาพการทำงาน**: ปรับปรุงด้วยการจัดการทรัพยากรและคำแนะนำการปรับขนาดอัตโนมัติ

### เอกสาร - การปรับปรุงโครงสร้าง Module06
- **ครอบคลุมเฟรมเวิร์กเอเจนต์อย่างครบถ้วน**: ตั้งแต่แนวคิดพื้นฐานถึงการปรับใช้งานระดับองค์กร
- **กลยุทธ์การปรับใช้งานระดับผลิต**: คู่มือครบถ้วนสำหรับ Foundry Local, Ollama, และ VLLM
- **การปรับแต่งข้ามแพลตฟอร์ม**: เพิ่ม ONNX Runtime สำหรับการปรับใช้งานทั่วไป
- **ห้องสมุดทรัพยากร**: อ้างอิงขนาดใหญ่สำหรับการเรียนรู้และการใช้งานต่อเนื่อง

### เพิ่ม - การอัปเดตเอกสารโปรโตคอลบริบทโมเดล (MCP) Module06
- **การสาธิต MCP ที่ทันสมัย** (`Module06/03.IntroduceMCP.md`):
  - อัปเดตตามข้อกำหนด MCP ล่าสุดจาก modelcontextprotocol.io (เวอร์ชัน 2025-06-18)
  - เพิ่มอนาล็อก USB-C อย่างเป็นทางการสำหรับการเชื่อมต่อแอปพลิเคชัน AI มาตรฐาน
  - อัปเดตส่วนสถาปัตยกรรมด้วยการออกแบบแบบสองชั้นอย่างเป็นทางการ (ชั้นข้อมูล + ชั้นการขนส่ง)
  - เพิ่มเติมเอกสารปฐมภูมิแกนกลางด้วยปฐมภูมิทางเซิร์ฟเวอร์ (เครื่องมือ, ทรัพยากร, คำกระตุ้น) และปฐมภูมิของไคลเอนต์ (การสุ่ม, การชักนำ, การบันทึก)

- **อ้างอิงและทรัพยากร MCP อย่างครบถ้วน**:
  - เพิ่มลิงก์ **MCP สำหรับผู้เริ่มต้น** (https://aka.ms/mcp-for-beginners) 
  - เอกสารและข้อกำหนด MCP ทางการ (modelcontextprotocol.io)
  - ทรัพยากรการพัฒนารวมถึง MCP Inspector และตัวอย่างการใช้งานอ้างอิง

### เพิ่ม - การผนวก Qualcomm QNN ใน Module04
- **ส่วนใหม่ 7: Qualcomm QNN Optimization Suite** (`Module04/05.QualcommQNN.md`):
  - คู่มือแบบละเอียดกว่า 400 บรรทัดเกี่ยวกับกรอบการประมวลผล AI inference แบบรวมของ Qualcomm
  - ครอบคลุมการคำนวณหลากหลายประเภท (Hexagon NPU, Adreno GPU, Kryo CPU)
  - การเพิ่มประสิทธิภาพที่รับรู้ฮาร์ดแวร์สำหรับแพลตฟอร์ม Snapdragon พร้อมการแจกจ่ายงานอย่างชาญฉลาด
  - เทคนิคการควอนไทซ์ขั้นสูง (INT8, INT16, ความแม่นยำผสม) สำหรับการปรับใช้งานบนมือถือ
  - การเพิ่มประสิทธิภาพ inferencing ที่ประหยัดพลังงานสำหรับอุปกรณ์พกพาและแอปพลิเคชันเรียลไทม์
  - คู่มือการติดตั้งครบถ้วนพร้อมการตั้งค่า QNN SDK และสิ่งแวดล้อม
  - ตัวอย่างการใช้งานจริง: การแปลง PyTorch เป็น QNN, การเพิ่มประสิทธิภาพหลายแบ็กเอนด์, การสร้างไบนารีบริบท
  - รูปแบบการใช้งานขั้นสูง: การกำหนดค่าแบ็กเอนด์แบบกำหนดเอง, การควอนไทซ์ไดนามิก, การวิเคราะห์ประสิทธิภาพ
  - ส่วนการแก้ไขปัญหาแบบครบถ้วนและแหล่งข้อมูลชุมชน

- **โครงสร้าง Module04 ที่ได้รับการปรับปรุง**:
  - อัปเดต README.md ให้มี 7 ส่วนแบบก้าวหน้า (จากเดิม 6 ส่วน)
  - เพิ่ม Qualcomm QNN ในตารางเกณฑ์มาตรฐานประสิทธิภาพ (ปรับปรุงความเร็ว 5-15 เท่า, ลดหน่วยความจำ 50-80%)
  - ผลลัพธ์การเรียนรู้ครอบคลุมสำหรับการปรับใช้งาน AI บนมือถือและการเพิ่มประสิทธิภาพพลังงาน

  - เพิ่มการบันทึกรายละเอียดในฟังก์ชัน route()
  - ปรับปรุงผลลัพธ์ทดสอบด้วยผลลัพธ์ที่มีโครงสร้าง
