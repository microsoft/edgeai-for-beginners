# ส่วนที่ 1: พื้นฐานของตระกูลโมเดล Microsoft Phi

ตระกูลโมเดล Microsoft Phi เป็นการเปลี่ยนแปลงแบบแผนในปัญญาประดิษฐ์ แสดงให้เห็นว่าโมเดลที่กะทัดรัดและมีประสิทธิภาพสามารถไปถึงผลลัพธ์ที่น่าทึ่งในขณะที่ใช้ทรัพยากรน้อยกว่ามากเมื่อเทียบกับโมเดลภาษาใหญ่แบบดั้งเดิม เป็นสิ่งสำคัญที่จะเข้าใจว่าเหตุใดตระกูล Phi จึงเปิดใช้งานขีดความสามารถ AI ที่ทรงพลังพร้อมกับความต้องการการคำนวณที่ลดลง ในขณะเดียวกันก็ยังรักษาประสิทธิภาพสูงในงานต่าง ๆ ได้อย่างดีเยี่ยม

## แหล่งข้อมูลสำหรับนักพัฒนา

### หมวดหมู่โมเดล Azure AI Foundry
ตระกูลโมเดล Phi (ยกเว้น Phi-silica) มีให้ผ่าน [Azure AI Foundry Model Catalog](https://ai.azure.com/explore/models?q=phi) ซึ่งทำให้นักพัฒนาสามารถเข้าถึง ปรับแต่ง และนำโมเดลเหล่านี้ไปใช้ในแอปพลิเคชันของตนได้อย่างง่ายดาย หมวดหมู่ดังกล่าวให้วิธีที่ราบรื่นในการทดลองกับตัวแปร Phi ที่แตกต่างกันและผสานรวมเข้าสู่โครงการของคุณ

### Azure AI Foundry
คุณสามารถนำโมเดล Phi ไปใช้และทดลองใช้งานผ่าน [Azure AI Foundry](https://ai.azure.com) ซึ่งให้สภาพแวดล้อมครอบคลุมสำหรับการสร้าง ทดสอบ และปรับใช้โซลูชัน AI โดยไม่ต้องตั้งค่ามาก

### Foundry Local
สำหรับการพัฒนาและปรับใช้แบบโลคอล ให้ตรวจสอบ [Microsoft Foundry Local](https://github.com/microsoft/foundry-local) ซึ่งช่วยให้คุณสามารถรันโมเดล Phi บนเครื่องพัฒนาด้วยการปรับแต่งที่เหมาะสม

## บทนำ

ในบทเรียนนี้ เราจะสำรวจตระกูลโมเดล Phi ของ Microsoft และแนวคิดพื้นฐานต่าง ๆ เราจะครอบคลุมถึงวิวัฒนาการของตระกูล Phi วิธีการฝึกสอนแบบนวัตกรรมที่ทำให้โมเดล Phi มีประสิทธิภาพ ตัวแปรสำคัญในตระกูล และการใช้งานจริงในสถานการณ์ต่าง ๆ

## วัตถุประสงค์การเรียนรู้

เมื่อจบบทเรียนนี้ คุณจะสามารถ:

- เข้าใจปรัชญาการออกแบบและวิวัฒนาการของตระกูลโมเดล Microsoft Phi
- ระบุความนวัตกรรมหลักที่ช่วยให้โมเดล Phi สามารถทำงานได้ดีเยี่ยมด้วยพารามิเตอร์ที่น้อยลง
- รับรู้ข้อดีและข้อจำกัดของตัวแปรโมเดล Phi ที่ต่างกัน
- ใช้ความรู้เกี่ยวกับโมเดล Phi เพื่อเลือกใช้งานตัวแปรที่เหมาะสมในสถานการณ์จริง

## การเข้าใจแบบแผนโมเดล AI แบบดั้งเดิม

โดยทั่วไป การบรรลุประสิทธิภาพสูงในประมวลผลภาษาธรรมชาติต้องการโมเดลภาษาขนาดใหญ่ที่มีพารามิเตอร์นับพันล้านหรือร้อยพันล้านองค์กรมักจะปรับใช้โมเดลเหล่านี้บนคลัสเตอร์ GPU ที่ทรงพลัง โดยเข้าถึงความสามารถผ่าน API หรือโครงสร้างฮาร์ดแวร์เฉพาะ

วิธีนี้ใช้ได้ผลดีสำหรับหลายแอปพลิเคชัน แต่มีข้อจำกัดในสถานการณ์การปรับใช้ในทางปฏิบัติ วิธีดั้งเดิมคือใช้โมเดลที่ต้องการทรัพยากรคำนวณขนาดใหญ่ หน่วยความจำมาก และพลังงานสูง ในขณะที่วิธีนี้ให้การเข้าถึงขีดความสามารถที่ล้ำสมัย มันก็สร้างการพึ่งพาฮาร์ดแวร์ที่มีราคาแพง เพิ่มต้นทุนการดำเนินงานสูง และจำกัดความยืดหยุ่นในการปรับใช้

## ความท้าทายของการปรับใช้ AI อย่างมีประสิทธิภาพ

ความต้องการ AI ที่มีประสิทธิภาพมากขึ้นกลายเป็นสิ่งสำคัญมากขึ้นในสถานการณ์ต่าง ๆ ลองพิจารณาแอปพลิเคชันที่ต้องการการปรับใช้แบบโลคอลเพื่อความเป็นส่วนตัว การใช้งานที่ต้องคำนึงถึงต้นทุนซึ่งค่าใช้จ่าย API คลาวด์อาจสูงเกินไป สถานการณ์การประมวลผลที่ขอบเครือข่ายที่มีทรัพยากรฮาร์ดแวร์จำกัด หรืองานเรียลไทม์ที่เวลาหน่วงต่ำเป็นสิ่งสำคัญ

### ข้อจำกัดหลักในการปรับใช้

การปรับใช้โมเดลขนาดใหญ่แบบดั้งเดิมต้องเผชิญกับข้อจำกัดพื้นฐานหลายประการที่จำกัดการใช้งานในทางปฏิบัติ:

- **ข้อจำกัดด้านต้นทุน**: ต้นทุนการประมวลผลสูงทำให้การปรับใช้อย่างต่อเนื่องมีค่าใช้จ่ายแพงสำหรับหลายองค์กร
- **ข้อจำกัดด้านทรัพยากร**: การเข้าถึงโครงสร้างพื้นฐาน GPU ขั้นสูงมีข้อจำกัดจำกัดตัวเลือกการปรับใช้
- **ข้อกำหนดด้านความเป็นส่วนตัว**: แอปพลิเคชันที่มีข้อมูลอ่อนไหวต้องประมวลผลในเครื่องเพื่อรักษาความเป็นส่วนตัวของข้อมูล
- **ความไวต่อเวลาหน่วง**: แอปพลิเคชันเรียลไทม์ต้องการการตอบสนองทันทีโดยไม่มีความล่าช้าจากการส่งข้อมูลกับคลาวด์

## ปรัชญาโมเดล Microsoft Phi

ตระกูลโมเดล Microsoft Phi เป็นการเปลี่ยนแปลงอย่างลึกซึ้งในปรัชญาการออกแบบโมเดล AI โดยให้ความสำคัญกับประสิทธิภาพและการปรับใช้ในทางปฏิบัติพร้อมกับรักษาคุณลักษณะการทำงานที่แข็งแกร่ง โมเดล Phi บรรลุเป้าหมายนี้ผ่านสถาปัตยกรรมที่นวัตกรรม วิธีการฝึกสอนคุณภาพสูง และเทคนิคการปรับแต่งเฉพาะทาง

ตระกูล Phi รวมหลายแนวทางที่ออกแบบมาเพื่อเพิ่มประสิทธิภาพต่อพารามิเตอร์สูงสุด อนุญาตให้ปรับใช้บนฮาร์ดแวร์มาตรฐานพร้อมทั้งให้ขีดความสามารถ AI อย่างมีนัยสำคัญ เป้าหมายคือรักษาประสิทธิภาพแข่งขันขณะที่ลดความต้องการการคำนวณ การใช้หน่วยความจำ และต้นทุนการดำเนินงานอย่างมาก

### หลักการออกแบบหลักของ Phi

โมเดล Phi สร้างขึ้นบนหลักการพื้นฐานหลายประการที่ทำให้แตกต่างจากโมเดลภาษาใหญ่แบบดั้งเดิม:

- **ความสำคัญของประสิทธิภาพเป็นอันดับแรก**: ปรับแต่งเพื่อประสิทธิภาพสูงสุดต่อพารามิเตอร์ แทนการเพิ่มขนาดอย่างเดียว
- **การฝึกสอนคุณภาพ**: มุ่งเน้นที่ข้อมูลฝึกสอนคุณภาพสูงที่คัดสรรมาอย่างดี มากกว่าการใช้ชุดข้อมูลขนาดมหาศาล
- **ความยืดหยุ่นในการปรับใช้**: ออกแบบให้ทำงานได้ดีในหลายรูปแบบฮาร์ดแวร์
- **ความสามารถเฉพาะทาง**: มักปรับแต่งเพื่อภารกิจหรือโดเมนเฉพาะเพื่อเพิ่มประสิทธิผลสูงสุด

## เทคโนโลยีสำคัญที่สนับสนุนตระกูล Phi

### วิธีการฝึกสอนแบบ "ตำราเรียน"

หนึ่งในแง่มุมที่ปฏิวัติที่สุดของตระกูล Phi คือวิธีการฝึกสอนที่มีคุณภาพเหมือนตำราแท้ แทนที่จะฝึกบนข้อมูลอินเทอร์เน็ตจำนวนมากที่ไม่ได้กรอง โมเดล Phi ใช้เนื้อหาการศึกษาคุณภาพสูงที่คัดสรรมาอย่างรอบคอบ ซึ่งออกแบบมาเพื่อสอนการให้เหตุผล คณิตศาสตร์ การเขียนโค้ด และความรู้ทั่วไปอย่างมีประสิทธิภาพ

วิธีนี้ทำงานโดยการสร้างเนื้อหาการศึกษาสังเคราะห์ที่สะท้อนตำราและวัสดุทางวิชาการคุณภาพสูง ข้อมูลฝึกสอนถูกออกแบบมาให้มีความชัดเจนในการสอนโดยเน้นคำอธิบายชัดเจน การให้เหตุผลทีละขั้นตอน และการนำเสนอความรู้ที่มีโครงสร้าง

### การฝึกให้เหตุผลขั้นสูง

โมเดล Phi รุ่นล่าสุดใช้วิธีการฝึกให้เหตุผลขั้นสูงที่ช่วยให้แก้ปัญหาที่ซับซ้อนหลายขั้นตอนได้ เทคนิคเหล่านี้รวมถึง:

**การฝึกเชนออฟธอท**: โมเดลเรียนรู้ที่จะแยกปัญหาที่ซับซ้อนออกเป็นขั้นตอนย่อยของการให้เหตุผล ทำให้กระบวนการแก้ปัญหาโปร่งใสและน่าเชื่อถือมากขึ้น

**การปรับขนาดในเวลาสรุปผล**: โมเดลสร้างสายเหตุผลโดยละเอียดโดยใช้ทรัพยากรการคำนวณเพิ่มเติมในช่วงการตอบกลับเพื่อความแม่นยำที่ดีขึ้น

**การฝึกที่ขอบขีดความสามารถ**: ข้อมูลฝึกสอนถูกเลือกมาเพื่อท้าทายโมเดลที่ขอบขีดความสามารถปัจจุบัน ส่งเสริมการเรียนรู้รูปแบบการให้เหตุผลที่ซับซ้อน

### นวัตกรรมสถาปัตยกรรม

ตระกูล Phi รวมการปรับแต่งสถาปัตยกรรมหลายด้านที่ออกแบบเพื่อประสิทธิภาพโดยเฉพาะ:

**ประสิทธิภาพพารามิเตอร์**: เลือกสถาปัตยกรรมอย่างรอบคอบเพื่อเพิ่มผลกระทบของแต่ละพารามิเตอร์ของโมเดล

**การบูรณาการมัลติโมดัล**: การรวมประสิทธิภาพของข้อความ ภาพ และเสียงในสถาปัตยกรรมที่กะทัดรัด

**การปรับแต่งฮาร์ดแวร์**: ตัวแปรเฉพาะที่ปรับแต่งเพื่อแพลตฟอร์มฮาร์ดแวร์และสถานการณ์การปรับใช้ต่าง ๆ

## การปรับแต่งฮาร์ดแวร์สำหรับโมเดล Phi

สภาพแวดล้อมการปรับใช้สมัยใหม่ได้รับประโยชน์จากประสิทธิภาพของโมเดล Phi ในหลายการตั้งค่าฮาร์ดแวร์:

### การปรับใช้ที่ปรับแต่งให้เหมาะสมกับ CPU

โมเดล Phi ถูกออกแบบมาให้ทำงานได้ดีบนฮาร์ดแวร์ที่ใช้ CPU เพียงอย่างเดียว ทำให้สามารถปรับใช้บนโครงสร้างพื้นฐานคอมพิวเตอร์มาตรฐานโดยไม่ต้องใช้ตัวเร่ง AI เฉพาะทาง

### การเร่งด้วย GPU

แม้ไม่ต้องการ GPU ที่ทรงพลัง โมเดล Phi สามารถใช้ประโยชน์จากทรัพยากร GPU ที่มีอยู่เพื่อเพิ่มประสิทธิภาพ ให้ความยืดหยุ่นในการปรับใช้

### การบูรณาการอุปกรณ์ Edge

ตัวแปรเฉพาะ เช่น Phi-3-Silica ถูกปรับแต่งสำหรับแพลตฟอร์มการประมวลผลขอบเครือข่าย บรรลุประสิทธิภาพที่น่าประทับใจ เช่น 650 โทเค็นต่อวินาทีโดยใช้พลังงานเพียง 1.5W

## ข้อดีของตระกูลโมเดล Phi

### ประหยัดต้นทุน

โมเดล Phi ลดต้นทุนการดำเนินงานอย่างมากโดยต้องการโครงสร้างพื้นฐานการคำนวณที่น้อยลงมากในขณะที่ยังรักษาประสิทธิภาพแข่งขันได้ ทำให้ AI สามารถเข้าถึงได้สำหรับองค์กรที่มีงบจำกัดหรือแอปพลิเคชันที่มีปริมาณข้อมูลสูงซึ่งต้นทุนต่อการคาดการณ์เป็นเรื่องสำคัญ

### ความยืดหยุ่นในการปรับใช้

ประสิทธิภาพของโมเดล Phi ช่วยเพิ่มความหลากหลายในการปรับใช้บนฮาร์ดแวร์ตั้งแต่โน้ตบุ๊กส่วนตัวจนถึงเซิร์ฟเวอร์องค์กร มอบความยืดหยุ่นให้กับองค์กรในตัวเลือกโครงสร้าง AI ของตน

### ความเป็นส่วนตัวและความปลอดภัย

ประสิทธิภาพของโมเดล Phi ช่วยให้สามารถปรับใช้แบบโลคอลสำหรับแอปพลิเคชันที่ต้องการความเป็นส่วนตัวสูง ทำให้ข้อมูลอ่อนไม่หลุดออกนอกองค์กรพร้อมกับให้ขีดความสามารถ AI ที่ทรงพลัง

### ประสิทธิภาพแบบเรียลไทม์

### ตัวอย่างการให้เหตุผลทางคณิตศาสตร์

Phi-4-mini-reasoning มีความโดดเด่นในการแก้ไขปัญหาคณิตศาสตร์ทีละขั้นตอน เช่น เมื่อถูกถามว่า "วิธีแก้สมการ 3*x^2+4*x+5=1 คืออะไร?" โมเดลจะให้ขั้นตอนการให้เหตุผลอย่างละเอียด:

```
<|system|>Your name is Phi, an AI math expert developed by Microsoft.<|end|>
<|user|>How to solve 3*x^2+4*x+5=1?<|end|>
<|assistant|>
I need to solve the quadratic equation 3x² + 4x + 5 = 1.

First, let me rearrange this to standard form:
3x² + 4x + 5 = 1
3x² + 4x + 5 - 1 = 0  
3x² + 4x + 4 = 0

Now I can use the quadratic formula: x = (-b ± √(b² - 4ac)) / (2a)
Where a = 3, b = 4, c = 4

Let me calculate the discriminant:
b² - 4ac = 4² - 4(3)(4) = 16 - 48 = -32

Since the discriminant is negative (-32), this equation has no real solutions.
The solutions are complex: x = (-4 ± √(-32)) / 6 = (-4 ± 4i√2) / 6 = (-2 ± 2i√2) / 3
```

## วิวัฒนาการของตระกูล Phi

### Phi-1 และ Phi-2: โมเดลพื้นฐาน

โมเดล Phi รุ่นแรกวางรากฐานแนวคิดของข้อมูลฝึกสอนคุณภาพสูงและสถาปัตยกรรมที่มีประสิทธิภาพ:

- **Phi-1 (1.3B พารามิเตอร์)**: แนะนำแนวคิดข้อมูลฝึกสอนคัดสรรสำหรับความเข้าใจภาษาและการสร้างโค้ดพื้นฐาน
- **Phi-2 (2.7B พารามิเตอร์)**: เสริมความสามารถด้านการให้เหตุผลผ่านข้อมูล NLP สังเคราะห์และเนื้อหาเว็บที่ผ่านการกรองอย่างรอบคอบ

### ตระกูล Phi-3: การนำไปใช้หลัก

ซีรีส์ Phi-3 เป็นก้าวสำคัญในความสามารถของ SLM ด้วยตัวแปรเฉพาะทางหลายตัว:

- **Phi-3-mini (3.8B พารามิเตอร์)**: งานภาษาทั่วไปด้วยประสิทธิภาพยอดเยี่ยมที่เหนือกว่าโมเดลที่มีขนาดสองเท่า
- **Phi-3-small (7B พารามิเตอร์)**: ประสิทธิภาพขั้นสูงที่ชนะ GPT-3.5 Turbo ในหลายเกณฑ์วัด
- **Phi-3-medium (14B พารามิเตอร์)**: ประสิทธิภาพระดับองค์กรที่เหนือกว่า Gemini 1.0 Pro
- **Phi-3-vision (4.2B พารามิเตอร์)**: ความสามารถมัลติโมดัลสำหรับการประมวลผลภาพและข้อความ
- **Phi-3-Silica (3.3B พารามิเตอร์)**: ปรับแต่งเฉพาะสำหรับการปรับใช้ใน Windows 11 แบบบิวท์อิน

### ตระกูล Phi-4: การให้เหตุผลขั้นสูง

รุ่นล่าสุดก้าวข้ามขอบเขตความสามารถในการให้เหตุผล:

- **Phi-4 (14B พารามิเตอร์)**: เชี่ยวชาญการให้เหตุผลซับซ้อน โดยเฉพาะด้านคณิตศาสตร์
- **Phi-4-mini (3.8B พารามิเตอร์)**: การให้เหตุผลที่เสริมด้วยการเรียกฟังก์ชันและรองรับบริบทยาว
- **Phi-4-multimodal**: ความสามารถในการประมวลผลเสียง ภาพ และข้อความพร้อมกัน
- **Phi-4-reasoning (14B พารามิเตอร์)**: เชี่ยวชาญงานให้เหตุผลที่ซับซ้อนหลายขั้นตอน
- **Phi-4-reasoning-plus (14B พารามิเตอร์)**: ความแม่นยำที่เพิ่มขึ้นผ่านการเรียนรู้เสริมเพิ่มเติม
- **Phi-4-mini-reasoning (3.8B พารามิเตอร์)**: การให้เหตุผลทางคณิตศาสตร์ที่ปรับแต่งสำหรับสภาพแวดล้อมที่จำกัด

เมื่อเทคโนโลยียังคงพัฒนา เราสามารถคาดหวังว่าโมเดล Phi จะมีความสามารถมากขึ้นในขณะที่รักษาข้อได้เปรียบด้านประสิทธิภาพ ทำให้การปรับใช้ AI ในสถานการณ์ที่เคยถูกจำกัดโดยความต้องการการคำนวณเป็นไปได้มากขึ้น

ตระกูล Phi แสดงให้เห็นว่าอนาคตของการปรับใช้ AI ไม่ได้อยู่ที่การสร้างโมเดลที่ใหญ่ขึ้นเท่านั้น แต่เป็นการสร้างโมเดลที่ชาญฉลาดและมีประสิทธิภาพมากขึ้นที่สามารถทำงานได้ดีในสภาพแวดล้อมฮาร์ดแวร์ที่หลากหลายพร้อมการรักษามาตรฐานประสิทธิภาพสูง


## ตัวอย่างการพัฒนาและการรวมระบบ

### เริ่มต้นอย่างรวดเร็วด้วย Transformers

นี่คือวิธีเริ่มต้นใช้งานโมเดล Phi โดยใช้ไลบรารี Hugging Face Transformers:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# โหลด Phi-4-mini-instruct
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True,
    attn_implementation="flash_attention_2"  # เพื่อประสิทธิภาพที่เหมาะสม
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")

# จัดรูปแบบข้อความแจ้งของคุณโดยใช้เทมเพลตแชท
messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain quantum computing in simple terms."}
]

# ใช้เทมเพลตแชท
input_text = tokenizer.apply_chat_template(messages, tokenize=False)
inputs = tokenizer(input_text, return_tensors="pt")

# สร้างคำตอบ
with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=200, temperature=0.7)
    
response = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(response)
```

ตัวอย่างต่อไปนี้แสดงวิธีการปรับแต่ง Phi-4-mini-instruct สำหรับงานเฉพาะ:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig
from trl import SFTTrainer
from datasets import load_dataset

# การกำหนดค่าสำหรับการปรับแต่ง LoRA
peft_config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
    target_modules="all-linear"
)

# การกำหนดค่าการฝึกที่ปรับให้เหมาะสมสำหรับประสิทธิภาพ
training_config = TrainingArguments(
    output_dir="./phi-4-mini-finetuned",
    learning_rate=5.0e-06,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=1,
    num_train_epochs=1,
    bf16=True,
    gradient_checkpointing=True,
    warmup_ratio=0.2,
    save_steps=100
)

# โหลดโมเดลและตัวตัดคำ
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")
tokenizer.pad_token = tokenizer.unk_token
tokenizer.padding_side = 'right'

# โหลดและประมวลผลชุดข้อมูล
train_dataset = load_dataset("HuggingFaceH4/ultrachat_200k", split="train_sft")

# เริ่มต้นตัวฝึก
trainer = SFTTrainer(
    model=model,
    args=training_config,
    peft_config=peft_config,
    train_dataset=train_dataset,
    max_seq_length=2048,
    tokenizer=tokenizer,
    packing=True
)

# เริ่มการปรับแต่ง
trainer.train()
```

import onnxruntime as ort
import numpy as np

session = ort.InferenceSession("phi-4-mini-quantized.onnx")

input_ids = tokenizer.encode("Hello, how are you?", return_tensors="np")

## การวัดผลประสิทธิภาพและความสำเร็จ

ตระกูลโมเดล Phi ได้สร้างผลงานที่น่าประทับใจในหลายการวัดผล โดยมักมีประสิทธิภาพเหนือกว่าโมเดลที่ใหญ่กว่ามาก:

### ไฮไลต์ประสิทธิภาพหลัก

**ความยอดเยี่ยมด้านการให้เหตุผลทางคณิตศาสตร์:**
- Phi-4 ได้ความแม่นยำ 82.5% ใน AIME 2025 (การคัดเลือก Math Olympiad)
- Phi-4-reasoning (14B) มีประสิทธิภาพดีกว่า DeepSeek-R1-Distill-70B (ใหญ่กว่า 5 เท่า) ในการวัดผลเหตุผล
- Phi-4-mini-reasoning (3.8B) สามารถเทียบเท่ากับโมเดลที่ใหญ่กว่าถึงสองเท่าในงานให้เหตุผลทางคณิตศาสตร์

**ความสำเร็จด้านประสิทธิภาพ:**
- Phi-3-Silica ทำงานได้ 650 โทเค็นต่อวินาที โดยใช้พลังงานเพียง 1.5W
- Phi-4-mini (3.8B) ให้ประสิทธิภาพใกล้เคียงกับโมเดลที่ใหญ่กว่ามาก

**ผลการวัดประสิทธิภาพ:**
- **MMLU (Massive Multitask Language Understanding)**: ประสิทธิภาพแข่งขันได้ใน 57 วิชาวิชาการ
- **HumanEval**: ความสามารถในการสร้างโค้ดที่แข็งแกร่ง โดยเฉพาะในภาษา Python
- **MGSM**: การแก้ปัญหาคณิตศาสตร์แบบหลายภาษาในระดับชั้นประถม
- **DROP**: งานความเข้าใจและให้เหตุผลที่ซับซ้อน
- **SimpleQA**: ความแม่นยำในการตอบคำถามข้อเท็จจริง

## คู่มือการเลือกโมเดล

### สำหรับแอปพลิเคชันพื้นฐาน
- **Phi-3-mini**: สร้างข้อความง่าย ๆ, ถามตอบพื้นฐาน, ตอบสนองอย่างรวดเร็ว
- **Phi-4-mini**: การให้เหตุผลที่ปรับปรุง พร้อมความสามารถเรียกใช้ฟังก์ชัน

### สำหรับงานคณิตศาสตร์และการให้เหตุผล
- **Phi-4**: การแก้ปัญหาคณิตศาสตร์ซับซ้อนและให้เหตุผล
- **Phi-4-reasoning**: ให้เหตุผลหลายขั้นตอนพร้อมคำอธิบายละเอียด

- **Phi-4-mini-reasoning**: การให้เหตุผลทางคณิตศาสตร์ที่มีประสิทธิภาพสำหรับสภาพแวดล้อมที่มีทรัพยากรจำกัด

### สำหรับแอปพลิเคชันมัลติโหมด
- **Phi-3-vision**: การประมวลผลภาพและข้อความร่วมกัน
- **Phi-4-multimodal**: ความสามารถครอบคลุมเสียง, การมองเห็น และข้อความ

1. เข้าใจปรัชญาการออกแบบและวิวัฒนาการของตระกูลโมเดล Microsoft Phi ตั้งแต่ Phi-1 ถึง Phi-4
2. ระบุความคิดริเริ่มสำคัญ รวมถึงการฝึกอบรมที่มีคุณภาพ "เหมือนหนังสือเรียน" และการปรับแต่งสถาปัตยกรรม
3. ตระหนักถึงข้อดีและข้อจำกัดของโมเดล Phi แบบต่าง ๆ ในสถานการณ์การปรับใช้ที่แตกต่างกัน
4. ใช้ความรู้ในการเลือกโมเดล Phi ที่เหมาะสมสำหรับกรณีการใช้งานและข้อจำกัดของฮาร์ดแวร์
5. นำเทคนิคการปรับแต่งไปใช้ในการปรับใช้โมเดล Phi บนอุปกรณ์ที่มีข้อจำกัดด้านทรัพยากร
6. อธิบายข้อได้เปรียบเชิงสถาปัตยกรรมของตระกูลโมเดล Phi เมื่อเทียบกับโมเดลภาษาใหญ่แบบดั้งเดิม
7. เลือกแบบโมเดล Phi ที่เหมาะสมตามความต้องการใช้งานเฉพาะและข้อจำกัดของฮาร์ดแวร์
8. นำโมเดล Phi ไปใช้ในทั้งสถานการณ์คลาวด์และเอดจ์โดยมีการกำหนดค่าที่เหมาะสม
9. ใช้เทคนิคการทำควอนตาไลเซชันและการปรับแต่งเพื่อเพิ่มประสิทธิภาพของโมเดล Phi บนอุปกรณ์เป้าหมาย
10. ประเมินการแลกเปลี่ยนระหว่างขนาดโมเดล ประสิทธิภาพ และความสามารถในตระกูล Phi
