## ফাংশন কলিং কি?

ফাংশন কলিং একটি শক্তিশালী সক্ষমতা যা স্মল ল্যাঙ্গুয়েজ মডেলস (SLMs)-কে বাহ্যিক টুলস, এপিআই এবং সার্ভিসের সাথে যোগাযোগ করার সুযোগ দেয়। শুধুমাত্র তাদের প্রশিক্ষণ ডেটার মধ্যে সীমাবদ্ধ থাকার পরিবর্তে, এখন SLMs করতে পারে:

- **বাহ্যিক এপিআইগুলোর সাথে সংযুক্ত হওয়া** (আবহাওয়া সার্ভিস, ডেটাবেস, সার্চ ইঞ্জিন)
- **ব্যবহারকারীর অনুরোধ অনুসারে নির্দিষ্ট ফাংশনগুলো কার্যকর করা**
- **বিভিন্ন উৎস থেকে রিয়েল-টাইম তথ্য প্রাপ্তি**
- **বিশেষায়িত টুলসের মাধ্যমে গণনামূলক কাজ সম্পাদন করা**
- **জটিল ওয়ার্কফ্লোগুলোর জন্য একাধিক অপারেশন চেইন করা**

এই সক্ষমতা SLMs-কে স্থির টেক্সট জেনারেটর থেকে বাস্তব কাজ সম্পাদনকারী গতিশীল AI এজেন্টে রূপান্তর করে।

## ফাংশন কলিং কিভাবে কাজ করে

ফাংশন কলিং প্রক্রিয়া একটি পদ্ধতিবদ্ধ ওয়ার্কফ্লো অনুসরণ করে:

### 1. টুল ইন্টিগ্রেশন
- **বাহ্যিক টুলস**: SLMs আবহাওয়া এপিআই, ডেটাবেস, ওয়েব সার্ভিস এবং অন্যান্য বাহ্যিক সিস্টেমের সাথে সংযোগ স্থাপন করতে পারে
- **ফাংশন ডেফিনেশনস**: প্রতিটি টুল নির্দিষ্ট প্যারামিটার, ইনপুট/আউটপুট ফরম্যাট এবং বিবরণের সাথে সংজ্ঞায়িত করা হয়
- **এপিআই সামঞ্জস্যতা**: টুলগুলো স্ট্যান্ডার্ডাইজড ইন্টারফেস (REST API, SDK ইত্যাদি) মাধ্যমে সংযুক্ত হয়

### 2. ফাংশন সংজ্ঞা
ফাংশনগুলো তিনটি মূল উপাদানের সঙ্গে সংজ্ঞায়িত হয়:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. উদ্দেশ্য শনাক্তকরণ
- **প্রাকৃতিক ভাষা প্রক্রিয়াকরণ**: SLM ব্যবহারকারীর ইনপুট বিশ্লেষণ করে উদ্দেশ্য বুঝে
- **ফাংশন মিলানো**: নির্ধারণ করে কোন ফাংশন(গুলি) অনুরোধ পূরণ করতে হবে
- **প্যারামিটার আহরণ**: ব্যবহারকারীর বার্তা থেকে প্রয়োজনীয় প্যারামিটার সনাক্ত ও আহরণ করে

### 4. JSON আউটপুট তৈরি
SLM একটি কাঠামোবদ্ধ JSON তৈরি করে যার মধ্যে থাকে:
- কল করার জন্য ফাংশন নাম
- প্রয়োজনীয় প্যারামিটার এবং যথাযথ মানসমূহ
- এক্সিকিউশন প্রসঙ্গ এবং মেটাডাটা

### 5. বাহ্যিক এক্সিকিউশন
- **প্যারামিটার যাচাইকরণ**: নিশ্চিত করে সব প্রয়োজনীয় প্যারামিটার উপস্থিত এবং সঠিক ফরম্যাটে আছে
- **ফাংশন কার্যকরকরণ**: অ্যাপ্লিকেশন প্রদত্ত প্যারামিটার নিয়ে নির্দিষ্ট ফাংশন চালায়
- **ত্রুটি পরিচালনা**: ব্যর্থতা, টাইমআউট, এবং অবৈধ প্রতিক্রিয়া ব্যবস্থাপনা

### 6. প্রতিক্রিয়া সংযোজন
- **ফলাফল প্রক্রিয়াকরণ**: ফাংশনের আউটপুট SLM-কে ফেরত দেওয়া হয়
- **প্রসঙ্গ সংজ্ঞা**: SLM ফলাফলগুলো তার প্রতিক্রিয়ায় সংযোজন করে
- **ব্যবহারকারী যোগাযোগ**: তথ্য প্রাকৃতিক ও কথোপকথনমুখী ফরম্যাটে উপস্থাপন করে

## প্রয়োগের পরিস্থিতি

### ডেটা আহরণ
প্রাকৃতিক ভাষার প্রশ্নগুলোকে কাঠামোবদ্ধ এপিআই কল হিসেবে রূপান্তর করুন:
- **"আমার সাম্প্রতিক অর্ডার দেখাও"** → ব্যবহারকারী আইডি এবং তারিখ ফিল্টারের সাথে ডেটাবেস কুয়েরি
- **"টোকিওতে আবহাওয়া কেমন?"** → অবস্থানের প্যারামিটারসহ আবহাওয়া এপিআই কল
- **"গত সপ্তাহের জন-এর ইমেইলগুলো খুঁজে বের করো"** → প্রেরক এবং তারিখ ফিল্টারের সাথে ইমেইল সার্ভিস কুয়েরি

### অপারেশন কার্যকরকরণ
ব্যবহারকারীর অনুরোধগুলোকে নির্দিষ্ট ফাংশন কল হিসেবে রূপান্তর করুন:
- **"আগামীকাল বিকেল ২টায় একটি মিটিং নির্ধারণ করো"** → ক্যালেন্ডার এপিআই ইন্টিগ্রেশন
- **"টিমকে একটি বার্তা পাঠাও"** → যোগাযোগ প্ল্যাটফর্ম এপিআই
- **"আমার ফাইলগুলোর ব্যাকআপ তৈরি করো"** → ফাইল সিস্টেম অপারেশন

### গণনামূলক কাজ
জটিল গাণিতিক বা যৌক্তিক অপারেশন পরিচালনা করুন:
- **"$10,000 এর উপর ৫% হারে ১০ বছর জন্য সংযুক্ত সুদের হিসাব করো"** → আর্থিক গণনা ফাংশন
- **"এই ডেটাসেট ট্রেন্ড বিশ্লেষণ করো"** → পরিসংখ্যান বিশ্লেষণ টুলস
- **"ডেলিভারির জন্য এই রুট অপ্টিমাইজ করো"** → রুট অপ্টিমাইজেশন অ্যালগরিদম

### ডেটা প্রসেসিং ওয়ার্কফ্লোসমূহ
জটিল অপারেশনের জন্য একাধিক ফাংশন কল চেইন করুন:
1. **বিভিন্ন উৎস থেকে ডেটা আহরণ**
2. **তথ্য পার্স এবং যাচাইপ্রাপ্ত করা**
3. **প্রয়োজনীয় ফরম্যাটে ডেটা রূপান্তর**
4. **সঠিক সিস্টেমে ফলাফল সংরক্ষণ**
5. **রিপোর্ট বা ভিজুয়ালাইজেশন তৈরি**

### UI/UX ইন্টিগ্রেশন
গতিশীল ইন্টারফেস আপডেট সক্ষম করুন:
- **"ড্যাশবোর্ডে বিক্রয় ডেটা দেখাও"** → চার্ট তৈরি এবং প্রদর্শন
- **"নতুন অবস্থান সহ মানচিত্র আপডেট করো"** → ভূ-স্থানিক ডেটা ইন্টিগ্রেশন
- **"ইনভেন্টরি ডিসপ্লে রিফ্রেশ করো"** → রিয়েল-টাইম ডেটা সিঙ্ক্রোনাইজেশন

## Phi-4-mini এবং Ollama দিয়ে ফাংশন কলিং সেট আপ

Microsoft's Phi-4-mini Ollama-এর মাধ্যমে একক এবং সমান্তরাল ফাংশন কলিং উভয় সমর্থন করে। সেট আপ করার পদ্ধতি এখানে:

### প্রয়োজনীয়তা
- Ollama ভার্সন 0.5.13 বা তার উপরে
- Phi-4-mini মডেল (সুপারিশকৃত: `phi4-mini:3.8b-fp16`)

### ইনস্টলেশন ধাপসমূহ

#### ১. Phi-4-mini ইনস্টল এবং চালানো
```bash
# মডেল ডাউনলোড করুন (যদি ইতিমধ্যে উপস্থিত না থাকে)
ollama run phi4-mini:3.8b-fp16

# যাচাই করুন মডেলটি উপলব্ধ আছে কি না
ollama list
```

### একক ফাংশন কলিং উদাহরণ

```python
import json
import requests

# সরঞ্জাম/ফাংশন নির্ধারণ করুন
tools = [
    {
        "name": "get_weather",
        "description": "Get current weather information for a location",
        "parameters": {
            "location": {
                "description": "The city or location name",
                "type": "str",
                "default": "New York"
            },
            "units": {
                "description": "Temperature units (celsius or fahrenheit)",
                "type": "str",
                "default": "celsius"
            }
        }
    }
]

# টুলগুলি সহ সিস্টেম প্রম্পট দিয়ে বার্তা তৈরি করুন
messages = [
    {
        "role": "system",
        "content": "You are a helpful weather assistant",
        "tools": json.dumps(tools)
    },
    {
        "role": "user",
        "content": "What's the weather like in London today?"
    }
]

# অললামা API-তে অনুরোধ করুন
response = requests.post(
    "http://localhost:11434/api/chat",
    json={
        "model": "phi4-mini-fc:3.8b-fp16",
        "messages": messages,
        "stream": False
    }
)

print(response.json())
```

### সমান্তরাল ফাংশন কলিং উদাহরণ

import json
import requests

# সমান্তরাল কার্যকরীর জন্য একাধিক টুল সংজ্ঞায়িত করুন
AGENT_TOOLS = {
    "booking_flight": {
        "name": "booking_flight",
        "description": "Book a flight ticket",
        "parameters": {
            "departure": {
                "description": "Departure airport code",
                "type": "str"
            },
            "destination": {
                "description": "Destination airport code", 
                "type": "str"
            },
            "outbound_date": {
                "description": "Departure date (YYYY-MM-DD)",
                "type": "str"
            },
            "return_date": {
                "description": "Return date (YYYY-MM-DD)",
                "type": "str"
            }
        }
    },
    "booking_hotel": {
        "name": "booking_hotel",
        "description": "Book a hotel room",
        "parameters": {
            "city": {
                "description": "City name for hotel booking",
                "type": "str"
            },
            "check_in_date": {
                "description": "Check-in date (YYYY-MM-DD)",
                "type": "str"
            },
            "check_out_date": {
                "description": "Check-out date (YYYY-MM-DD)",
                "type": "str"
            }
        }
    }
}

SYSTEM_PROMPT = """
You are my travel agent with some tools available.
"""

messages = [
    {
        "role": "system",
        "content": SYSTEM_PROMPT,
        "tools": json.dumps(AGENT_TOOLS)
    },
    {
        "role": "user", 
        "content": "I need to travel from London to New York from March 21 2025 to March 27 2025. Please book both flight and hotel."

### কাস্টম ফাংশন বাস্তবায়ন

আপনি Qwen3-এর জন্য কাস্টম ফাংশনও সংজ্ঞায়িত করতে পারেন:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # আবহাওয়া API কল সিমুলেট করুন
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# কাস্টম টুল ব্যবহার করুন
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

import asyncio
import aiohttp

async def batch_function_calls(function_calls):
    """Execute multiple function calls concurrently"""
    async with aiohttp.ClientSession() as session:
        tasks = []
        for call in function_calls:
            if call["name"] == "fetch_url":
                task = fetch_url_async(session, call["parameters"]["url"])
                tasks.append(task)
        
        results = await asyncio.gather(*tasks)
        return results

async def fetch_url_async(session, url):
    async with session.get(url) as response:
        return await response.text()

                "region": {"type": "string", "required": False},
                "product_category": {"type": "string", "required": False}

            },

            rate_limit=200
        )
    
    def register_function(self, name: str, description: str, parameters: Dict, 
                         handler: callable, rate_limit: int = 60):
        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # ফাংশনের অস্তিত্ব যাচাই করুন
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # রেট লিমিট চেক করুন
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # প্যারামিটার যাচাই করুন
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # ফাংশন কার্যকর করুন
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # সফল কার্যকরির লগ করুন
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # ব্যর্থ কার্যকরির লগ করুন
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # যদি একটি মিনিট পেরিয়ে যায় তবে কাউন্টার রিসেট করুন
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # সীমার নিচে আছে কিনা চেক করুন
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # প্রয়োজনীয় প্যারামিটার চেক করুন
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # প্যারামিটার টাইপ ও সীমাবদ্ধতা যাচাই করুন
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # টাইপ যাচাই
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # এনাম যাচাই
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
        
        return FunctionResult(success=True)

            'total_opportunities': 45,
            'conversion_rate': 0.67,
            'top_products': [
                {'product_id': 'PROD-001', 'sales': 45000},
                {'product_id': 'PROD-002', 'sales': 32000}
            ],
            'generated_at': datetime.now().isoformat()
        }
    
    async def _send_notification(self, recipients: List[str], message: str, 
                               priority: str = 'medium', channel: str = 'email') -> Dict:
        """Send notification through specified channel"""
        # বিজ্ঞপ্তি সেবা কল সিমুলেট করুন
        await asyncio.sleep(0.1)
        
        notification_id = f"NOTIF-{datetime.now().strftime('%Y%m%d%H%M%S')}"
        
        return {
            'notification_id': notification_id,
            'recipients': recipients,
            'channel': channel,
            'priority': priority,
            'status': 'sent',
            'sent_at': datetime.now().isoformat()
        }
    
    def get_function_definitions(self) -> List[Dict]:
        """Get OpenAI-compatible function definitions for all registered functions"""
        definitions = []
        
        for func_name, func_info in self.functions.items():
            definition = {
                'name': func_name,
                'description': func_info['description'],
                'parameters': {
                    'type': 'object',
                    'properties': {},
                    'required': []
                }
            }
            
            for param_name, param_info in func_info['parameters'].items():
                definition['parameters']['properties'][param_name] = {
                    'type': param_info['type'],
                    'description': param_info.get('description', '')
                }
                
                if 'enum' in param_info:
                    definition['parameters']['properties'][param_name]['enum'] = param_info['enum']
                
                if 'default' in param_info:
                    definition['parameters']['properties'][param_name]['default'] = param_info['default']
                
                if param_info.get('required', False):
                    definition['parameters']['required'].append(param_name)
            
            definitions.append(definition)
        
        return definitions

## উপসংহার

স্মল ল্যাঙ্গুয়েজ মডেলস-এ ফাংশন কলিং একটি পরম্পরাগত AI সহকারীদের থেকে গতিশীল, সক্ষম এজেন্টে রূপান্তরিত হওয়ার একটি উদ্ভাবনী পরিবর্তন। এই টিউটোরিয়ালে covered করা হয়েছে:

### মূল বিষয়সমূহ

১. **ভিত্তি বোঝাপড়া**: ফাংশন কলিং SLMs-কে বহিরাগত টুল এবং সার্ভিসের সাথে সংযুক্ত করে তাদের প্রশিক্ষণ ডেটার বাইরে প্রসারিত করার সুযোগ দেয়।

২. **বাস্তবায়নের নমনীয়তা**: কম-স্তরের কাস্টম টেমপ্লেট থেকে উচ্চ-স্তরের ফ্রেমওয়ার্ক যেমন Qwen-Agent এবং Foundry Local পর্যন্ত বিভিন্ন পন্থা রয়েছে।

৩. **প্রোডাকশন বিবেচনা**: এন্টারপ্রাইজ ডেপলয়মেন্টের জন্য ত্রুটি পরিচালনা, রেট লিমিটিং, নিরাপত্তা ও অডিট লগিং গুরুত্বপূর্ণ।

৪. **কর্মক্ষমতা অপ্টিমাইজেশন**: যথাযথ ফাংশন ডিজাইন, দক্ষ এক্সিকিউশন এবং স্মার্ট ক্যাশিং উল্লেখযোগ্যভাবে প্রতিক্রিয়া সময় উন্নত করতে পারে।

### ভবিষ্যতের দিশা

SLM প্রযুক্তি উন্নয়ন অব্যাহত থাকলে, আমরা প্রত্যাশা করতে পারি:

- **উন্নত ফাংশন কলিং সঠিকতা**: উন্নত উদ্দেশ্য শনাক্তকরণ এবং প্যারামিটার আহরণ
- **উন্নত সমান্তরাল প্রক্রিয়াকরণ**: অধিক জটিল বহু-ফাংশন সমন্বয়
- **শ্রেষ্ঠতর ইন্টিগ্রেশন স্ট্যান্ডার্ড**: টুল ইন্টিগ্রেশনের জন্য স্ট্যান্ডার্ডাইজড প্রোটোকল
- **উন্নত নিরাপত্তা বৈশিষ্ট্য**: উন্নত প্রমাণীকরণ এবং অনুমোদন ব্যবস্থা
- **বিস্তৃত ইকোসিস্টেম**: প্রস্তুত নির্মিত ফাংশন ও ইন্টিগ্রেশনের বাড়তি লাইব্রেরি

### শুরু করার নির্দেশনা

আপনার প্রকল্পে ফাংশন কলিং বাস্তবায়ন শুরু করতে:

১. **সহজ শুরু করুন**: প্রাথমিক একক ফাংশন পরিস্থিতি থেকে শুরু করুন
২. **আপনার ফ্রেমওয়ার্ক নির্বাচন করুন**: সরাসরি বাস্তবায়ন (Ollama/Phi-4) অথবা ফ্রেমওয়ার্ক-সহায়তায় (Qwen-Agent) মধ্যে নির্বাচন করুন
৩. **ফাংশন সাবধানে ডিজাইন করুন**: স্পষ্ট এবং ভালো কাগজপত্রযুক্ত ফাংশন সংজ্ঞায় জোর দিন
৪. **ত্রুটি পরিচালনা নিশ্চিত করুন**: শুরু থেকেই দৃঢ় ত্রুটি পরিচালনা তৈরি করুন
৫. **ক্রমাগত বৃদ্ধি করুন**: অভিজ্ঞতা অর্জনের সাথে সহজ থেকে জটিল পরিস্থিতি পর্যন্ত যান

ফাংশন কলিং SLMs-কে অসাধারণ টেক্সট জেনারেটর থেকে বাস্তব বিশ্বের সমস্যা সমাধানে সক্ষম বাস্তব AI এজেন্টে রূপান্তর করে। এই টিউটোরিয়ালে প্রদত্ত প্যাটার্ন ও অনুশীলন অনুসরণ করে, আপনি শক্তিশালী, নির্ভরযোগ্য AI সিস্টেম তৈরি করতে পারবেন যা প্রচলিত চ্যাট ইন্টারফেসের অনেক বাইরে প্রসারিত।
