# সেকশন ০৩ - মডেল কনটেক্সট প্রোটোকল (MCP) ইন্টিগ্রেশন

## MCP (মডেল কনটেক্সট প্রোটোকল) পরিচিতি

মডেল কনটেক্সট প্রোটোকল (MCP) একটি ওপেন-সোর্স স্ট্যান্ডার্ড যা AI অ্যাপ্লিকেশনগুলোকে বাইরের সিস্টেমের সাথে সংযুক্ত করার জন্য। MCP ব্যবহার করে, Claude বা ChatGPT এর মতো AI অ্যাপ্লিকেশনগুলি ডেটা সোর্স (যেমন, স্থানীয় ফাইল, ডাটাবেস), টুলস (যেমন, সার্চ ইঞ্জিন, ক্যালকুলেটর), এবং ওয়ার্কফ্লো (যেমন, বিশেষায়িত প্রম্পট) এর সাথে সংযোগ স্থাপন করতে পারে—যাতে তারা গুরুত্বপূর্ণ তথ্য অ্যাক্সেস করে এবং কাজ সম্পাদন করতে পারে।

MCP কে ভাবুন AI অ্যাপ্লিকেশনগুলোর জন্য একটি **USB-C পোর্ট** হিসেবে। যেমন USB-C ইলেকট্রনিক ডিভাইসগুলো সংযোগের জন্য একটি স্ট্যান্ডার্ডাইজড পদ্ধতি প্রদান করে, MCP সেই একইভাবে AI অ্যাপ্লিকেশনগুলিকে বাইরের সিস্টেমের সাথে সংযোগ করার একটি স্ট্যান্ডার্ডাইজড উপায় প্রদান করে।

### MCP কি কি সক্ষম করে?

MCP AI অ্যাপ্লিকেশনগুলোর জন্য শক্তিশালী ক্ষমতা উন্মুক্ত করে:

- **ব্যক্তিগতকৃত AI অ্যাসিস্ট্যান্টস**: এজেন্টগুলো আপনার Google ক্যালেন্ডার এবং নোশনে অ্যাক্সেস পেতে পারে, একটি আরও ব্যক্তিগতকৃত AI অ্যাসিস্ট্যান্ট হিসেবে কাজ করে
- **উন্নত কোড জেনারেশন**: Claude Code একটি Figma ডিজাইন ব্যবহার করে সম্পূর্ণ ওয়েব অ্যাপ তৈরি করতে পারে
- **এন্টারপ্রাইজ ডেটা ইন্টিগ্রেশন**: এন্টারপ্রাইজ চ্যাটবটগুলি প্রতিষ্ঠান জুড়ে একাধিক ডাটাবেসের সাথে সংযোগ স্থাপন করতে পারে, ব্যবহারকারীদের চ্যাট ব্যবহার করে ডেটা বিশ্লেষণ করার ক্ষমতা প্রদান করে
- **সৃজনশীল ওয়ার্কফ্লো**: AI মডেলগুলি Blender এ 3D ডিজাইন তৈরি করতে পারে এবং 3D প্রিন্টার ব্যবহার করে মুদ্রণ করতে পারে
- **রিয়েল-টাইম তথ্য অ্যাক্সেস**: আপ-টু-ডেট তথ্যের জন্য বাইরের ডেটা সোর্সের সাথে সংযোগ
- **জটিল মাল্টি-স্টেপ অপারেশনস**: একাধিক টুল এবং সিস্টেম সংমিশ্রণে জটিল ওয়ার্কফ্লো সম্পাদন

### MCP কেন গুরুত্বপূর্ণ?

MCP পুরো ইকোসিস্টেম জুড়ে সুবিধা প্রদান করে:

**ডেভেলপারদের জন্য**: MCP AI অ্যাপ্লিকেশন বা এজেন্ট তৈরি বা ইন্টিগ্রেশনের সময় উন্নয়ন সময় এবং জটিলতা কমায়।

**AI অ্যাপ্লিকেশনগুলোর জন্য**: MCP ডেটা সোর্স, টুলস এবং অ্যাপসের একটি ইকোসিস্টেমে প্রবেশাধিকার দেয় যা ক্ষমতা বৃদ্ধি করে এবং শেষ ব্যবহারকারী অভিজ্ঞতা উন্নত করে।

**শেষ ব্যবহারকারীদের জন্য**: MCP এমন AI অ্যাপ্লিকেশন বা এজেন্ট তৈরি করে যা আপনার ডেটা অ্যাক্সেস করতে পারে এবং প্রয়োজনে আপনার পক্ষ থেকে পদক্ষেপ নিতে পারে।

## MCP তে ছোট ভাষার মডেল (SLMs)

ছোট ভাষার মডেলগুলো AI ডিপ্লয়মেন্টের জন্য একটি কার্যকরী পন্থা উপস্থাপন করে, যা বেশ কিছু সুবিধা প্রদান করে:

### SLMs এর সুবিধাসমূহ
- **সংসাধন দক্ষতা**: কম কম্পিউটেশনাল প্রয়োজন
- **দ্রুত সাড়া সময়**: রিয়েল-টাইম অ্যাপ্লিকেশনগুলোর জন্য কম বিলম্ব  
- **লীলা খরচ**: ন্যূনতম অবকাঠামো প্রয়োজন
- **গোপনীয়তা**: স্থানীয়ভাবে চালানো যায়, ডেটা প্রেরণ ছাড়াই
- **কাস্টমাইজেশন**: নির্দিষ্ট ডোমেইনের জন্য সহজে ফাইন-টিউন করা যায়

### MCP এর সাথে SLMs কেন ভালো কাজ করে

MCP এর সাথে SLMs এর যুগলবন্দি একটি শক্তিশালী সংমিশ্রণ তৈরি করে যেখানে মডেলের যুক্তিবাদ ক্ষমতা বাহ্যিক টুলস দ্বারা বাড়ানো হয়, যা তাদের ছোট প্যারামিটার সংখ্যাকে উন্নত কার্যকারিতার মাধ্যমে পরিপূরক করে।

## Python MCP SDK সারসংক্ষেপ

Python MCP SDK MCP সক্ষম অ্যাপ্লিকেশন তৈরি করার ভিত্তি প্রদান করে। SDK তে অন্তর্ভুক্ত:

- **ক্লায়েন্ট লাইব্রেরি**: MCP সার্ভারে সংযোগ করার জন্য
- **সার্ভার ফ্রেমওয়ার্ক**: কাস্টম MCP সার্ভার তৈরির জন্য
- **প্রোটোকল হ্যান্ডলার**: যোগাযোগ পরিচালনার জন্য
- **টুল ইন্টিগ্রেশন**: বাইরের ফাংশনগুলি কার্যকর করার জন্য

## ব্যবহারিক বাস্তবায়ন: Phi-4 MCP ক্লায়েন্ট

আসুন Microsoft এর Phi-4 মিনি মডেল ব্যবহার করে MCP ক্ষমতাসহ একটি বাস্তব বাস্তবায়ন দেখি।

### MCP আর্কিটেকচার সারসংক্ষেপ

MCP একটি **ক্লায়েন্ট-সার্ভার আর্কিটেকচার** অনুসরণ করে যেখানে MCP হোস্ট (একটি AI অ্যাপ্লিকেশন যেমন Claude Code বা Claude Desktop) এক বা একাধিক MCP সার্ভারের সাথে সংযোগ স্থাপন করে। MCP হোস্ট প্রতিটি MCP সার্ভারের জন্য একটি MCP ক্লায়েন্ট তৈরি করে এটি সম্পন্ন করে।

#### প্রধান অংশগ্রহণকারীগণ

- **MCP হোস্ট**: AI অ্যাপ্লিকেশন যা এক বা একাধিক MCP ক্লায়েন্ট নিয়ন্ত্রণ এবং পরিচালনা করে
- **MCP ক্লায়েন্ট**: একটি কম্পোনেন্ট যা MCP সার্ভারের সাথে সংযোগ বজায় রাখে এবং MCP হোস্টের ব্যবহারের জন্য MCP সার্ভার থেকে কনটেক্সট গ্রহণ করে
- **MCP সার্ভার**: একটি প্রোগ্রাম যা MCP ক্লায়েন্টদের জন্য কনটেক্সট প্রদান করে

#### দুই-স্তর আর্কিটেকচার

MCP দুটি আলাদা স্তর নিয়ে গঠিত:

**ডেটা স্তর**: ক্লায়েন্ট-সার্ভার যোগাযোগের জন্য JSON-RPC ভিত্তিক প্রোটোকল সংজ্ঞায়িত করে, যার মধ্যে রয়েছে:
- লাইফসাইকেল ম্যানেজমেন্ট (সংযোগ প্রারম্ভ, ক্ষমতা আলোচনার)
- মূল প্রিমিটিভস (টুলস, রিসোর্স, প্রম্পট)
- ক্লায়েন্ট ফিচারস (স্যাম্পলিং, এলিসিটেশন, লগিং)
- ইউটিলিটি ফিচারস (নোটিফিকেশন, প্রগ্রেস ট্র্যাকিং)

**ট্রান্সপোর্ট স্তর**: যোগাযোগের প্রক্রিয়া এবং চ্যানেলসমূহ সংজ্ঞায়িত করে:
- **STDIO ট্রান্সপোর্ট**: স্থানীয় প্রসেসের জন্য স্ট্যান্ডার্ড ইনপুট/আউটপুট স্ট্রীম ব্যবহার করে (অপটিমাল পারফরম্যান্স, কোনো নেটওয়ার্ক ওভারহেড নেই)
- **স্ট্রিমেবল HTTP ট্রান্সপোর্ট**: রিমোট সার্ভারের জন্য HTTP POST এবং ঐচ্ছিক সার্ভার-সেন্ট ইভেন্টস ব্যবহার করে (মানক HTTP অথেন্টিকেশন সমর্থন করে)

### MCP কোর প্রিমিটিভস

MCP প্রিমিটিভস সংজ্ঞায়িত করে যে ধরনের কনটেক্সচুয়াল তথ্য AI অ্যাপ্লিকেশনে শেয়ার করা যায় এবং কি ধরনের অ্যাকশন সম্পাদন করা যেতে পারে।

#### সার্ভার প্রিমিটিভস

MCP তিনটি মূল প্রিমিটিভ সংজ্ঞায়িত করে যা সার্ভারগুলো প্রকাশ করতে পারে:

**টুলস**: নির্বাহযোগ্য ফাংশন যা AI অ্যাপ্লিকেশনগুলো অ্যাকশন সম্পাদন করার জন্য কল করতে পারে
- উদাহরণ: ফাইল অপারেশন, API কল, ডাটাবেস অনুসন্ধান
- পদ্ধতি: `tools/list`, `tools/call`
- ডায়নামিক আবিষ্কার এবং কার্যকরী সমর্থন করে

**রিসোর্সস**: ডেটা সোর্স যা AI অ্যাপ্লিকেশনকে কনটেক্সচুয়াল তথ্য প্রদান করে
- উদাহরণ: ফাইল কনটেন্ট, ডাটাবেস রেকর্ড, API রেসপন্স
- পদ্ধতি: `resources/list`, `resources/read`
- কাঠামোবদ্ধ ডেটায় অ্যাক্সেস সক্ষম করে

**প্রম্পটস**: পুনর্ব্যবহারযোগ্য টেমপ্লেট যা ভাষার মডেলের সাথে ইন্টারঅ্যাকশন কাঠামো তৈরি করতে সহায়তা করে
- উদাহরণ: সিস্টেম প্রম্পট, কয়েকটি শট উদাহরণ
- পদ্ধতি: `prompts/list`, `prompts/get`
- AI ইন্টারঅ্যাকশন প্যাটার্নগুলোকে স্ট্যান্ডার্ডাইজ করে

#### ক্লায়েন্ট প্রিমিটিভস

MCP এমন প্রিমিটিভস সংজ্ঞায়িত করে যা ক্লায়েন্টরা প্রকাশ করতে পারে সমৃদ্ধ ইন্টারঅ্যাকশনের জন্য:

**স্যাম্পলিং**: সার্ভারগুলিকে ক্লায়েন্টের AI অ্যাপ্লিকেশন থেকে ভাষার মডেল কমপ্লিশন অনুরোধ করার অনুমতি দেয়
- পদ্ধতি: `sampling/complete`
- মডেল-নিরপেক্ষ সার্ভার উন্নয়ন সক্ষম করে
- হোস্টের ভাষার মডেলে প্রবেশাধিকার প্রদান করে

**এলিসিটেশন**: সার্ভারগুলোকে ব্যবহারকারীদের কাছ থেকে অতিরিক্ত তথ্য অনুরোধ করার অনুমতি দেয়
- পদ্ধতি: `elicitation/request`
- ব্যবহারকারী ইন্টারঅ্যাকশন এবং নিশ্চিতকরণ সক্ষম করে
- ডায়নামিক তথ্য সংগ্রহ সমর্থন করে

**লগিং**: সার্ভারগুলোকে ক্লায়েন্টদের কাছে লগ মেসেজ পাঠানোর অনুমতি দেয়
- ডিবাগিং এবং মনিটরিংয়ের জন্য ব্যবহৃত
- সার্ভার অপারেশনে দৃশ্যমানতা প্রদান করে

### MCP প্রোটোকল লাইফসাইকেল

#### প্রারম্ভিকরণ এবং ক্ষমতা আলোচনার

MCP একটি স্টেটফুল প্রোটোকল যা লাইফসাইকেল ব্যবস্থাপনা প্রয়োজন। প্রারম্ভিকরণ প্রক্রিয়া বেশ কিছু গুরুত্বপূর্ণ উদ্দেশ্য পালন করে:

1. **প্রোটোকল ভার্সন আলোচনার**: নিশ্চিত করে যে ক্লায়েন্ট এবং সার্ভার উভয়ই সামঞ্জস্যপূর্ণ প্রোটোকল ভার্সন ব্যবহার করছে (যেমন, "2025-06-18")
2. **ক্ষমতা আবিষ্কার**: প্রতিটি পক্ষ সমর্থিত ফিচার এবং প্রিমিটিভগুলি ঘোষণায় করে
3. **পরিচয় বিনিময়**: সনাক্তকরণ এবং ভার্সন তথ্য প্রদান করে

```python

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {
      "elicitation": {},  # ক্লায়েন্ট ব্যবহারকারীর ইন্টারঅ্যাকশন সমর্থন করে
      "sampling": {}      # ক্লায়েন্ট এলএলএম সম্পূরক প্রদান করতে পারে
    },
    "clientInfo": {
      "name": "edge-ai-client",
      "version": "1.0.0"
    }
  }
}
```

## MCP ইকোসিস্টেম এবং উন্নয়ন

### MCP প্রকল্পের পরিধি

মডেল কনটেক্সট প্রোটোকল ইকোসিস্টেমে কয়েকটি মূল উপাদান অন্তর্ভুক্ত:

- **[MCP স্পেসিফিকেশন](https://modelcontextprotocol.io/specification/latest)**: ক্লায়েন্ট এবং সার্ভার বাস্তবায়নের জন্য অফিসিয়াল স্পেসিফিকেশন
- **[MCP SDKs](https://modelcontextprotocol.io/docs/sdk)**: বিভিন্ন প্রোগ্রামিং ভাষার জন্য SDK যা MCP বাস্তবায়ন করে
- **MCP উন্নয়ন টুলস**: MCP সার্ভার এবং ক্লায়েন্ট ডেভেলপমেন্ট টুলস, যার মধ্যে রয়েছে [MCP ইন্সপেক্টর](https://github.com/modelcontextprotocol/inspector)
- **[MCP রেফারেন্স সার্ভার বাস্তবায়ন](https://github.com/modelcontextprotocol/servers)**: MCP সার্ভারের রেফারেন্স বাস্তবায়ন

### MCP উন্নয়ন শুরু করা

MCP দিয়ে নির্মাণ শুরু করার জন্য:

**সার্ভার তৈরি করুন**: [MCP সার্ভার তৈরি করুন](https://modelcontextprotocol.io/docs/develop/build-server) আপনার ডেটা এবং টুলস প্রকাশ করতে

**ক্লায়েন্ট তৈরি করুন**: [অ্যাপ্লিকেশন ডেভেলপ করুন](https://modelcontextprotocol.io/docs/develop/build-client) যা MCP সার্ভারের সাথে সংযুক্ত হয়

**কনসেপ্ট শেখা**: [MCP এর মূল কনসেপ্ট ও আর্কিটেকচার বোঝা](https://modelcontextprotocol.io/docs/learn/architecture)

## উপসংহার

MCP এর সাথে সংহত SLMs AI অ্যাপ্লিকেশন উন্নয়নে একটি পরিবর্তনশীল ধারা উপস্থাপন করে। ছোট মডেলের দক্ষতাকে বাহ্যিক টুলসের শক্তির সাথে সংযুক্ত করে, ডেভেলপাররা বুদ্ধিমান সিস্টেম তৈরি করতে পারে যা সংস্থান-বঞ্চিত এবং অত্যন্ত সক্ষম।

মডেল কনটেক্সট প্রোটোকল AI অ্যাপ্লিকেশনকে বাইরের সিস্টেমের সাথে সংযুক্ত করার জন্য একটি স্ট্যান্ডার্ডাইজড উপায় প্রদান করে, যেমন USB-C ইলেকট্রনিক ডিভাইসের জন্য একটি সার্বজনীন সংযোগ স্ট্যান্ডার্ড প্রদান করে। এই স্ট্যান্ডার্ডাইজেশন নিম্নলিখিতগুলো সক্ষম করে:

- **সহজ ইন্টিগ্রেশন**: AI মডেলগুলোকে বিভিন্ন ডেটা সোর্স এবং টুলসের সাথে সংযোগ করুন
- **ইকোসিস্টেম বৃদ্ধিঃ** এক দফা তৈরি করুন, একাধিক AI অ্যাপ্লিকেশন জুড়ে ব্যবহার করুন
- **ক্ষমতা বৃদ্ধি**: বাহ্যিক কার্যকারিতার মাধ্যমে SLMs এর ক্ষমতা বর্ধিত করুন
- **রিয়েল-টাইম আপডেটস**: ডায়নামিক, সাড়া দেয়া AI অ্যাপ্লিকেশন সমর্থন করুন

মূল গ্রহণযোগ্যতা:
- MCP একটি ওপেন স্ট্যান্ডার্ড যা AI অ্যাপ্লিকেশন এবং বাইরের সিস্টেমের মধ্যে সেতুবন্ধন করে
- প্রোটোকল টুলস, রিসোর্সস, এবং প্রম্পটকে কোর প্রিমিটিভ হিসেবে সমর্থন করে
- রিয়েল-টাইম নোটিফিকেশন ডায়নামিক, সাড়া দেয়া অ্যাপ্লিকেশন সক্ষম করে
- সঠিক লাইফসাইকেল ম্যানেজমেন্ট এবং ত্রুটি পরিচালনা প্রোডাকশন ব্যবহারের জন্য অপরিহার্য
- ইকোসিস্টেম ব্যাপক SDK এবং উন্নয়ন সরঞ্জাম প্রদান করে
