## প্রজেক্ট ওভারভিউ

EdgeAI ফর বিগিনার্স হলো একটি বিস্তৃত শিক্ষামূলক রিপোজিটরি যা ছোট ভাষার মডেল (SLMs) সহ এজ AI উন্নয়ন শেখায়। কোর্সটি এজএআইয়ের মূলাবলী, মডেল ডিপ্লয়মেন্ট, অপটিমাইজেশন পদ্ধতি এবং Microsoft Foundry Local এবং বিভিন্ন AI ফ্রেমওয়ার্ক ব্যবহার করে প্রোডাকশন-রেডি ইমপ্লিমেন্টেশনগুলি কভার করে।

**কী প্রযুক্তি:**
- পাইথন ৩.৮+ (AI/ML স্যাম্পলগুলির প্রধান ভাষা)
- .NET C# (AI/ML স্যাম্পল)
- JavaScript/Node.js ইলেকট্রন সহ (ডেস্কটপ অ্যাপ্লিকেশনের জন্য)
- Microsoft Foundry Local SDK
- Microsoft Windows ML
- VSCode AI Toolkit
- OpenAI SDK
- AI ফ্রেমওয়ার্ক: LangChain, Semantic Kernel, Chainlit
- মডেল অপটিমাইজেশন: Llama.cpp, Microsoft Olive, OpenVINO, Apple MLX

**রিপোজিটরি ধরন:** ৮টি মডিউল এবং ১০টি বিস্তৃত স্যাম্পল অ্যাপ্লিকেশন সহ শিক্ষামূলক কন্টেন্ট রিপোজিটরি

**আর্কিটেকচার:** মাল্টি-মডিউল শেখার পথ যা প্র্যাকটিক্যাল স্যাম্পল দিয়ে এজ AI ডিপ্লয়মেন্ট প্যাটার্ন দেখায়

## প্রয়োজনীয়তা

### প্রয়োজনীয় টুলস

- **Python 3.8+** - AI/ML স্যাম্পল এবং নোটবুকের জন্য
- **Node.js 16+** - ইলেকট্রন স্যাম্পল অ্যাপ্লিকেশনের জন্য
- **Git** - ভার্সন কন্ট্রোলের জন্য
- **Microsoft Foundry Local** - AI মডেল লোকালি চালানোর জন্য

### সুপারিশকৃত টুলস

- **Visual Studio Code** - Python, Jupyter, এবং Pylance এক্সটেনশনের সাথে
- **Windows Terminal** - ভালো কমান্ড-লাইন অভিজ্ঞতার জন্য (Windows ব্যবহারকারীর জন্য)
- **Docker** - কন্টেইনারাইজড ডেভেলপমেন্টের জন্য (ঐচ্ছিক)

### সিস্টেম প্রয়োজন

- **RAM**: নূন্যতম ৮GB, বহু-মডেল ব্যবহারের জন্য ১৬GB+ সুপারিশকৃত
- **স্টোরেজ**: মডেল ও ডিপেন্ডেন্সি জন্য ১০GB+ ফ্রি স্পেস
- **অপरेटিং সিস্টেম**: Windows 10/11, macOS 11+, অথবা Linux (Ubuntu 20.04+)
- **হার্ডওয়্যার**: AVX2 সাপোর্ট সহ CPU; GPU (CUDA, Qualcomm NPU) ঐচ্ছিক কিন্তু সুপারিশকৃত

### জ্ঞানের প্রাথমিক ধারণা

- পাইথন প্রোগ্রামিংয়ের প্রাথমিক ধারণা
- কমান্ড-লাইন ইন্টারফেসে পরিচিতি
- AI/ML ধারণাগুলির জ্ঞান (স্যাম্পল ডেভেলপমেন্টের জন্য)
- Git ওয়ার্কফ্লো এবং পুল রিকোয়েস্ট প্রসেস সম্পর্কে জানা

```bash

cd edgeai-for-beginners

# কোন বিল্ড ধাপ প্রয়োজন নেই - এটি প্রধানত একটি শিক্ষামূলক কন্টেন্ট রেপোজিটোরি
```

### পাইথন স্যাম্পল সেটআপ (Module08 এবং Workshop স্যাম্পল)

```bash
# ভার্চুয়াল পরিবেশ তৈরি এবং সক্রিয় করুন
python -m venv .venv
# উইন্ডোজ-এ
.venv\Scripts\activate

source .venv/bin/activate

# Foundry Local SDK এবং নির্ভরশীলতা ইনস্টল করুন
pip install foundry-local-sdk openai

# Module08 নমুনাগুলির জন্য অতিরিক্ত নির্ভরশীলতা ইনস্টল করুন
cd Module08
pip install -r requirements.txt

# ওয়ার্কশপ নির্ভরশীলতা ইনস্টল করুন
cd ../Workshop

```

### Foundry Local সেটআপ

Foundry Local স্যাম্পল চালানোর জন্য প্রয়োজন। অফিসিয়াল রিপোজিটরি থেকে ডাউনলোড করে ইন্সটল করুন:

**ইন্সটলেশন:**
- **Windows**: `winget install Microsoft.FoundryLocal`
- **macOS**: `brew tap microsoft/foundrylocal && brew install foundrylocal`
- **ম্যানুয়াল**: [রিলিজ পেজ](https://github.com/microsoft/Foundry-Local/releases) থেকে ডাউনলোড করুন

**দ্রুত শুরু:**
```bash
# আপনার প্রথম মডেল চালান (প্রয়োজনে স্বয়ংক্রিয়ভাবে ডাউনলোড হবে)
foundry model run phi-4-mini

# উপলভ্য মডেলগুলি তালিকা করুন
foundry model ls

# সার্ভিসের অবস্থা চেক করুন
foundry service status
```

**দ্রষ্টব্য**: Foundry Local স্বয়ংক্রিয়ভাবে আপনার হার্ডওয়্যারের জন্য সেরা মডেল ভেরিয়েন্ট নির্বাচন করে (CUDA GPU, Qualcomm NPU, অথবা CPU)।

### বিষয়বস্তু উন্নয়ন

১. প্রাসঙ্গিক মডিউল ডিরেক্টরিগুলিতে `.md` ফাইল সম্পাদনা করুন
২. বিদ্যমান ফরম্যাটিং প্যাটার্ন অনুসরণ করুন
৩. কোড উদাহরণগুলি সঠিক ও পরীক্ষিত কিনা নিশ্চিত করুন
৪. প্রয়োজন হলে সংশ্লিষ্ট অনূদিত বিষয়বস্তু আপডেট করুন (অথবা অটোমেশনে 맡ান)

```bash
# মৌলিক চ্যাট ফাংশনালিটি পরীক্ষা করুন

ইলেকট্রন স্যাম্পলের টেস্ট অবকাঠামো রয়েছে:

npm run test:e2e   # শেষ থেকে শেষ পর্যন্ত টেস্ট চালান
npm run lint       # কোড স্টাইল পরীক্ষা করুন
```

## টেস্টিং নির্দেশাবলী

### বিষয়বস্তু যাচাই

রিপোজিটরি অটোমেটেড ট্রান্সলেশন ওয়ার্কফ্লো ব্যবহার করে। অনুবাদের জন্য ম্যানুয়াল পরীক্ষা প্রয়োজন নেই।

**বিষয়বস্তু পরিবর্তনের জন্য ম্যানুয়াল যাচাই:**
১. `.md` ফাইলগুলির প্রিভিউ দেখে Markdown রেন্ডারিং পরীক্ষা করুন
২. সব লিঙ্ক বৈধ টার্গেট নির্দেশ করে কিনা নিশ্চিত করুন
৩. ডকুমেন্টেশনে থাকা কোড স্নিপেটগুলো পরীক্ষা করুন
৪. ছবি ঠিকমতো লোড হচ্ছে কিনা নিশ্চিত করুন

### স্যাম্পল অ্যাপ্লিকেশন টেস্টিং

### অবদানWorkflow

১. **রিপোজিটরি ফর্ক করুন** এবং `main` থেকে নতুন ব্রাঞ্চ তৈরি করুন
২. **আপনার পরিবর্তন করুন** কোড স্টাইল গাইডলাইনস অনুযায়ী
৩. **পরিপূর্ণভাবে পরীক্ষা করুন** উপরে দেয়া টেস্টিং নির্দেশাবলী অনুযায়ী
৪. **পরিষ্কার মেসেজ সহ কমিট করুন** conventional commits ফরম্যাট অনুসরণ করে
৫. **আপনার ফর্কে পুশ করুন** এবং একটি পুল রিকোয়েস্ট তৈরি করুন
৬. **রিভিউ সময় মেইনটেইনারদের মতামতের উত্তর দিন**

### ব্রাঞ্চ নামকরণ নিয়ম

- `feature/<module>-<description>` - নতুন ফিচার অথবা বিষয়বস্তুর জন্য
- `fix/<module>-<description>` - বাগ ফিক্সের জন্য
- `docs/<description>` - ডকুমেন্টেশন উন্নতির জন্য
- `refactor/<description>` - কোড রিফ্যাক্টরিংয়ের জন্য

## ফাউন্ড্রি লোকাল ইন্টিগ্রেশন

অধিকাংশ Module08 স্যাম্পলের জন্য Microsoft Foundry Local চালানো প্রয়োজন।

### ইন্সটলেশন এবং সেটআপ

**Foundry Local ইন্সটল করুন:**
```bash
# উইন্ডোজ
winget install Microsoft.FoundryLocal

# ম্যাকওএস
brew tap microsoft/foundrylocal

```

**পাইথন SDK ইন্সটল করুন:**
```bash

```

### Foundry Local শুরু করা
```bash
# সার্ভিস শুরু করুন এবং একটি মডেল চালান (প্রয়োজন হলে স্বয়ংক্রিয়ভাবে ডাউনলোড হবে)
foundry model run phi-3.5-mini

# অথবা স্বয়ংক্রিয় হার্ডওয়্যার অপ্টিমাইজেশনের জন্য মডেল এলিয়াস ব্যবহার করুন
foundry model run phi-4-mini
foundry model run qwen2.5-0.5b
foundry model run qwen2.5-coder-0.5b

# সার্ভিসের অবস্থা পরীক্ষা করুন
foundry service status

# উপলব্ধ মডেলগুলি তালিকা করুন
foundry model ls
```

### SDK ব্যবহার (পাইথন)
```python
from foundry_local import FoundryLocalManager
import openai

# স্বয়ংক্রিয় হার্ডওয়্যার অপ্টিমাইজেশনের জন্য মডেল উপনাম ব্যবহার করুন
alias = "phi-4-mini"

# ম্যানেজার তৈরি করুন (সেবা স্বয়ংক্রিয়ভাবে শুরু করে এবং মডেল লোড করে)
manager = FoundryLocalManager(alias)

# স্থানীয় ফাউন্ড্রি সেবার জন্য OpenAI ক্লায়েন্ট কনফিগার করুন
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# মডেল ব্যবহার করুন
response = client.chat.completions.create(
    model=manager.get_model_info(alias).id,
    messages=[{"role": "user", "content": "Hello!"}]
)
```

### Foundry Local যাচাই করা
```bash
# সার্ভিস স্টেটাস এবং এন্ডপয়েন্ট
foundry service status

# লোড করা মডেলগুলোর তালিকা (REST API)
curl http://localhost:<port>/v1/models

# নোট: 'foundry service status' চালানোর সময় পোর্ট প্রদর্শিত হয়
```

### স্যাম্পলগুলির জন্য পরিবেশ পরিবর্তনশীল

অধিকাংশ স্যাম্পল এই পরিবেশ পরিবর্তনশীল ব্যবহার করে:
```bash
# ফাউন্ড্রি লোকাল কনফিগারেশন
# নোট: SDK (FoundryLocalManager) স্বয়ংক্রিয়ভাবে এন্ডপয়েন্ট সনাক্ত করে
set MODEL=phi-4-mini  # বা phi-3.5-mini, qwen2.5-0.5b, qwen2.5-coder-0.5b
set API_KEY=            # লোকাল ব্যবহারের জন্য প্রয়োজন নেই

# ম্যানুয়াল এন্ডপয়েন্ট (যদি SDK ব্যবহার না করেন)
# 'foundry service status' দ্বারা পোর্ট দেখানো হয়
set BASE_URL=http://localhost:<port>

# Azure OpenAI ফলব্যাকের জন্য (ঐচ্ছিক)
set AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com
set AZURE_OPENAI_API_KEY=your-api-key
set AZURE_OPENAI_API_VERSION=2024-08-01-preview
```

**দ্রষ্টব্য**: যখন `FoundryLocalManager` ব্যবহার করা হয়, SDK স্বয়ংক্রিয়ভাবে সার্ভিস ডিসকভারি এবং মডেল লোডিং পরিচালনা করে। মডেল উপনামগুলি (যেমন `phi-3.5-mini`) নিশ্চিত করে আপনার হার্ডওয়ারের জন্য সেরা ভ্যারিয়েন্ট নির্বাচন হয়।

#### মডেল ডাউনলোড ব্যর্থতা
**সমস্যা:** Foundry Local মডেল ডাউনলোড করতে ব্যর্থ হচ্ছে

**সমাধান:**
```bash
# ইন্টারনেট সংযোগ পরীক্ষা করুন
# মডেল ক্যাশ মুছে পুনরায় চেষ্টা করুন
foundry model remove <model-alias>
foundry model run <model-alias>

# উপলব্ধ ডিস্ক স্থান পরীক্ষা করুন (মডেলগুলি ২-১৬জিবি হতে পারে)
# নিশ্চিত করুন ফায়ারওয়াল সেটিংস ডাউনলোডের অনুমতি দেয়
```

## প্রজেক্ট-নির্দিষ্ট নোটস

### Module08 স্যাম্পল অ্যাপ্লিকেশনসমূহ

রিপোজিটরিটি ১০টি বিস্তৃত স্যাম্পল অ্যাপ্লিকেশন অন্তর্ভুক্ত করে:

১. **০১-REST চ্যাট কুইকস্টার্ট** - বেসিক OpenAI SDK ইন্টিগ্রেশন
২. **০২-OpenAI SDK ইন্টিগ্রেশন** - উন্নত SDK ফিচার
৩. **০৩-মডেল ডিসকভারি ও বেঞ্চমার্কিং** - মডেল তুলনা টুল
৪. **০৪-Chainlit RAG অ্যাপ্লিকেশন** - রিটারিভাল-অগমেন্টেড জেনারেশন
৫. **০৫-মাল্টি-এজেন্ট অর্কেস্ট্রেশন** - বেসিক এজেন্ট সমন্বয়
৬. **০৬-মডেলস-অ্যাজ-টুলস রাউটার** - বুদ্ধিমান মডেল রাউটিং
৭. **০৭-ডাইরেক্ট API ক্লায়েন্ট** - লো-লেভেল API ইন্টিগ্রেশন
৮. **০৮-Windows 11 চ্যাট অ্যাপ** - স্থানীয় ইলেকট্রন ডেস্কটপ অ্যাপ্লিকেশন
৯. **০৯-উন্নত মাল্টি-এজেন্ট সিস্টেম** - জটিল এজেন্ট অর্কেস্ট্রেশন
১০. **১০-Foundry টুলস ফ্রেমওয়ার্ক** - LangChain/Semantic Kernel ইন্টিগ্রেশন

### ওয়ার্কশপ স্যাম্পল অ্যাপ্লিকেশনগুলি


ওয়ার্কশপে ৬টি প্রগতিশীল সেশন রয়েছে যা বাস্তব প্রয়োগের সঙ্গে:

১। **সেশন ০১** - Foundry Local ইন্টিগ্রেশনের সাথে চ্যাট বুটস্ট্রাপ
২। **সেশন ০২** - RAG পাইপলাইন এবং RAGAS এর মাধ্যমে মূল্যায়ন
৩। **সেশন ০৩** - ওপেন-সোর্স মডেলগুলোর বেঞ্চমার্কিং
৪। **সেশন ০৪** - মডেল তুলনা এবং নির্বাচন
৫। **সেশন ০৫** - মাল্টি-এজেন্ট অর্কেস্ট্রেশন সিস্টেম
৬। **সেশন ০৬** - মডেল রাউটিং এবং পাইপলাইন ব্যবস্থাপনা

প্রতিটি নমুনা Foundry Local এর সঙ্গে এজ AI উন্নয়নের বিভিন্ন দিক প্রদর্শন করে।

### কর্মক্ষমতা বিবেচনা

- SLM গুলো এজ ডিপ্লয়মেন্টের জন্য অপ্টিমাইজড (২-১৬GB RAM)
- লোকাল ইনফারেন্সে ৫০-৫০০মিলিসেকেন্ড রেসপন্স সময় পাওয়া যায়
- কোয়ান্টাইজেশন প্রযুক্তি ৭৫% আকার হ্রাস এবং ৮৫% কর্মক্ষমতা ধরে রাখে
- স্থানীয় মডেল দিয়ে রিয়েল-টাইম কথোপকথনের সক্ষমতা

### সুরক্ষা এবং গোপনীয়তা

- সমস্ত প্রক্রিয়াকরণ স্থানীয়ভাবে হয় - কোন ডেটা ক্লাউডে পাঠানো হয় না
- গোপনীয়তাসংবেদনশীল অ্যাপ্লিকেশন (হেলথকেয়ার, ফাইনান্স) এর জন্য উপযুক্ত
- ডেটা সার্বভৌমত্বের মানদণ্ড পূরণ করে
- Foundry Local সম্পূর্ণ স্থানীয় হার্ডওয়্যারে চলে
