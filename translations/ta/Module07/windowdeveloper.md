# விண்டோஸ் எட்ஜ் ஏஐ அபிவிருத்தி வழிகாட்டி

## அறிமுகம்

மைக்ரோசாப்டின் விண்டோஸ் ஏஐ ஃபவுன்ட்ரி தளம் பயன்படுத்தி சாதனத்தில் உள்ள ஏஐ சக்தியைப் பயனாக்கும் புத்திசாலியான செயலிகளை உருவாக்கும் உங்கள் விரிவான வழிகாட்டியாக விண்டோஸ் எட்ஜ் ஏஐ அபிவிருத்திக்கு வரவேற்கிறோம். இந்த வழிகாட்டி, விண்டோஸ் ஹார்ட்வேர் விரைவாக்கத்தின் முழு பரத்தை பயன்படுத்தி அவர்களது செயலிகளில் முன்னணி எட்ஜ் ஏஐ திறன்களை ஒருங்கிணைக்க விரும்பும் விண்டோஸ் அபிவிருத்தி நிபுணர்களுக்காக சிறப்பாக வடிவமைக்கப்பட்டுள்ளது.

### விண்டோஸ் ஏஐ நன்மைகள்

விண்டோஸ் ஏஐ ஃபவுன்ட்ரி என்பது மாதிரி தேர்வு மற்றும் நுட்ப நூலாக்கத்திலிருந்து தொடங்கி CPU, GPU, NPU மற்றும் ஹைபிரிட் கிளவுட் கட்டமைப்புகளில் உள்ளடக்கிய AI அபிவிருத்தி முழு வாழ்க்கைச் சுழற்சியையும் ஆதரிக்கும் ஒருங்கிணைந்த, நம்பகமான மற்றும் பாதுகாப்பான தளத்தை குறிக்கிறது. இந்த தளம் வழங்குவது:

- **ஹார்ட்வேர் அப்ஸ்ட்ராக்ஷன்**: AMD, Intel, NVIDIA மற்றும் Qualcomm சிலிகானில் இடைவிடாத விநியோகம்
- **சாதனத்தில் உள்ள நுண்ணறிவு**: முழுமையாக உள்ளூர் ஹார்ட்வேர் இயங்கும் தனியுரிமை பாதுகாப்பான ஏஐ
- **மேம்படுத்தப்பட்ட செயல்திறன்**: விண்டோஸ் ஹார்ட்வேர் அமைப்புகளுக்கு முன்னதாக நுட்ப நூலாக்கம் செய்யப்பட்ட மாதிரிகள்
- **எண்டர்ப்ரைஸ் தயாரா**: உற்பத்தியில் பயன்படுத்தக்கூடிய பாதுகாப்பு மற்றும் இணக்கமான அம்சங்கள்

### விண்டோஸ் எம்.எல்
விண்டோஸ் மெஷின் லெர்னிங் (எம்.எல்) C#, C++, மற்றும் பைத்தான் அபிவிருத்தி நிபுணர்களுக்கு ONNX ஏஐ மாதிரிகளை ONNX Runtime மூலம் உள்ளூர் விண்டோஸ் பிசி களில் இயக்க அனுமதிக்கிறது, பல்வேறு ஹார்ட்வேர்களுக்கான (CPUகள், GPUகள், NPUகள்) தானாக செயல்படுபவர் மேலாண்மை உடன். [ONNX Runtime](https://onnxruntime.ai/docs/)்கு PyTorch, Tensorflow/Keras, TFLite, scikit-learn மற்றும் பிற கட்டமைப்புகளிலிருந்தும் மாதிரிகள் பயன்படுத்தப்படலாம்.


![WindowsML A diagram illustrating an ONNX model going through Windows ML to then reach NPUs, GPUs, and CPUs.l](https://learn.microsoft.com/en-us/windows/ai/images/winml-diagram.png)

விண்டோஸ் எம்.எல் ONNX Runtime இற்கான பொதுவான விண்டோஸ் பரப்பளவில் ஒரு பிரதியை வழங்கும், மேலும் இயக்க செயலாளர்களை (EPகளை) இயக்க தகவமைப்புடன் வழக்கமாக பதிவிறக்கம் செய்யும் திறனையும் வழங்குகிறது.

### ஏன் Edge AIக்காக விண்டோஸ்?

**யுனிவர்சல் ஹார்ட்வேர் ஆதரவு**
விண்டோஸ் எம்.எல் முழு விண்டோஸ் சூழலில் தானாக ஹார்ட்வேர் நுட்ப நூலாக்கத்தை வழங்குகிறது, உங்கள் ஏஐ செயலிகள் அடிப்படையில் உள்ள சிலிகான் கட்டமைப்புக்கு பின்பற்றாமல் சிறந்த செயல்திறன் செய்ய உறுதி செய்கிறது.

**ஒன்றிணைந்த ஏஐ ரன்டைம்**
அடங்கிய விண்டோஸ் எம்.எல் ஊசல் இயந்திரம் சிக்கலான அமைவு தேவைகளை அகற்றுகிறது, அபிவிருத்தி நிபுணர்கள் அமைப்பு கவலைகள் பதிலாக செயலியின் லாஜிக் மீது கவனம் செலுத்த அனுமதிக்கிறது.

**கோபைலட்+ பிசி சிறப்பு நுட்ப நூலாக்கம்**
தொடர்புடைய நியூரல் செயலாக்க அலகுகளுடன் (NPUs) அடுத்த தலைமுறை விண்டோஸ் சாதனங்களுக்கு நியமிக்கப்பட்ட இயக்க APIகள் மின் ஒவ்வொரு வாட்டுக்குமான சிறந்த செயல்திறனை வழங்கும் முறையில் வடிவமைக்கப்பட்டவை.

**அபிவிருத்தி சூழல்**
விசுவல் ஸ்டுடியோ ஒருங்கிணைப்பு, விரிவான ஆவணங்கள் மற்றும் துரிதமாக அபிவிருத்திக்க உதவும் மாதிரி செயலிகள் உள்ளிட்ட பணியாளர்கள்.

## கற்றல் குறிக்கோள்கள்

இந்த விண்டோஸ் எட்ஜ் ஏஐ அபிவிருத்தி வழிகாட்டியை முடிப்பதன் மூலம், நீங்கள் விண்டோஸ் தளத்தில் உற்பத்தி தயார மேலும் ஏஐ செயலிகளை கட்டுவதற்கான தேவையான திறன்களை வல்லுநராக்குவீர்கள்.

### மைய தொழில்நுட்ப திறன்கள்

**விண்டோஸ் ஏஐ ஃபவுன்ட்ரி தேர்ச்சி**
- விண்டோஸ் ஏஐ ஃபவுன்ட்ரி தள கட்டுமானம் மற்றும் கூறுகளை புரிந்துகொள்ளுங்கள்
- விண்டோஸ் சூழலில் முழுமையான ஏஐ அபிவிருத்தி வாழ்க்கை சுழற்சியினை வழிநடத்துங்கள்
- சாதனத்தில் ஓடும் ஏஐ செயலிகளுக்கு பாதுகாப்பு சிறந்த நடைமுறைகளைப் பின்பற்றுங்கள்
- வெவ்வேறு விண்டோஸ் ஹார்ட்வேர் அமைப்புகளுக்குத் செயலிகளை நுட்ப நூலாக்குங்கள்

**API ஒருங்கிணைப்பு நுணுக்கம்**
- உரை, காட்சி மற்றும் பன்மொழி செயலிகளுக்கான விண்டோஸ் ஏஐ APIகளை தேர்ச்சி பெறுங்கள்
- உரை உருவாக்கம் மற்றும் காரணமறுக்கும் Phi Silica மொழி மாதிரி ஒருங்கிணைப்பு செயல்படுத்துங்கள்
- கட்டமைக்கப்பட்ட படத்தைத் திருத்தும் APIகளை பயன்படுத்தி கணினி காட்சி திறன்களை desplegue செய்து கொள்ளுங்கள்
- முன்புதயார் செய்யப்பட்ட மாதிரிகளை LoRA (குறைந்த தர நிரலாக்கம்) முறைகளால் தனித்துவப்படுத்துங்கள்

**ஃபவுன்ட்ரி லோக்கல் அமலாக்கம்**
- ஃபவுன்ட்ரி லோக்கல் CLIஐ பயன்படுத்தி திறந்த மூல மொழி மாதிரிகளை தேடுங்கள், மதிப்பீடு செய்யுங்கள் மற்றும் நிறுவுங்கள்
- உள்ளூர் நிறுவலுக்கு மாதிரி நுட்ப நூலாக்கம் மற்றும் அளவீட்டலைப் புரிந்துகொள்ளுங்கள்
- இணைய இணைப்பைத் தேவைப்படாமல் இயங்கும் ஆஃப்லைன் ஏஐ திறன்களை அமல்படுத்துங்கள்
- உற்பத்தி சூழல்களில் மாதிரி வாழ்க்கைக்காலங்களையும் புதுப்பிப்புகளையும் மேலாண்மை செய்யுங்கள்

**விண்டோஸ் எம்.எல் நிறுவல்**
- தனிப்பயன் ONNX மாதிரிகளை விண்டோஸ் செயலிகளில் விண்டோஸ் எம்.எல் மூலம் கொண்டு வாருங்கள்
- CPU, GPU மற்றும் NPU கட்டமைப்புகளில் தானாக ஹார்ட்வேர் விரைவாக்கத்தை பயன்படுத்துங்கள்
- சிறந்த வளப் பயன்பாட்டுடன் நேரடி ஊசல் (inference) செயல்படுத்துங்கள்
- பல்வேறு விண்டோஸ் சாதன வகைகளுக்கான விரிவாக்கக்கூடிய ஏஐ செயலிகளை வடிவமைக்கவும்

### செயலி மேம்பாட்டுத் திறன்கள்

**குறுக்குவழி விண்டோஸ் மேம்பாடு**
- .NET MAUI பயன்படுத்தி யுனிவர்சல் விண்டோஸ் நிறுவலுக்கான ஏஐ இயக்கப்பட்ட செயலிகளை உருவாக்குங்கள்
- Win32, UWP மற்றும் முன்னேற்ற வலை செயலிகளில் ஏஐ திறன்களை ஒருங்கிணைக்கவும்
- ஏஐ செயலாக்க நிலைகளுக்கு எளிதில் மாறக்கூடிய பதிலளிக்கும் UI வடிவமைப்புகளை அமல்படுத்துங்கள்
- சரியான பயனர் அனுபவ முறைமைகளுடன் ஒத்திசைக்காத ஏஐ செயல்பாடுகளை கையாளுங்கள்

**செயல்திறன் மேம்பாடு**
- வெவ்வேறு ஹார்ட்வேர் அமைப்புகளில் ஏஐ ஊசல் செயல்திறனை பகுப்பாய்வு செய்து மேம்படுத்துங்கள்
- பெரிய மொழி மாதிரிகளுக்கான திறமையான நினைவக மேலாண்மையை செயல்படுத்துங்கள்
- கிடைக்கும் ஹார்ட்வேர் திறன்களின் அடிப்படையில் மெருகூட்டப்பட்ட செயலிகளை வடிவமைக்கவும்
- அடிக்கடி பயன்படும் ஏஐ செயல்களுக்கு கேஷிங் திட்டங்களை பயன்படுத்துங்கள்

**உற்பத்தி தயாராகுதல்**
- விரிவான பிழை கையாளல் மற்றும் மாற்று முறைகளை செயல்படுத்துங்கள்
- ஏஐ செயலி செயல்திறனை கண்காணிக்கும் மற்றும் டெலிமெட்ரி வடிவமைக்கவும்
- உள்ளூர் ஏஐ மாதிரி சேமிப்பிற்கும் இயக்கத்திற்கும் பாதுகாப்பு சிறந்த நடைமுறைகளைப் பின்பற்றுங்கள்
- நிறுவன மற்றும் நுகர்வோர் செயலிகளுக்கான நிறுவன திட்டங்களை திட்டமிடுங்கள்

### வியாபார மற்றும் மூலக கலந்துணர்வு

**ஏஐ செயலி கட்டமைப்பு**
- உள்ளூர் மற்றும் கிளவுட் ஏஐ செயலாக்கத்திற்குள் இடையே சிறந்த முறையில் இயங்கும் கலவை கட்டமைப்புகளை வடிவமைக்கவும்
- மாதிரி அளவு, நிபுணத்துவம் மற்றும் ஊசல் வேகத்துக்குள் வர்த்தக பரிமாற்றங்களை மதிப்பீடு செய்யவும்
- தனியுரிமையை பேணி நுண்ணறிவைப் பயன்படுத்தும் தரவு ஓட்டக் கட்டமைப்புகளை திட்டமிடுங்கள்
- பயனர்கள் கோரிக்கைகளுடன் பரிமாணமடைகக்கூடிய செலவு குறைந்த ஏஐ தீர்வுகளை செயல்படுத்துங்கள்

**சந்தை நிலைப்பாடு**

### 1. விண்டோஸ் ஏஐ APIகள்

விண்டோஸ் ஏஐ APIகள் சாதனத்தில் உள்ள மாதிரிகள் மூலம் இயக்கப்படும், கோபைலட்+ பிசி சாதனங்களில் குறைந்த அமைவு மற்றும் சிறந்த செயல்திறனுக்கான நுட்ப நூலாக்கத்துடன் தயாராக பயன்படுத்தக்கூடிய ஏஐ திறன்களை வழங்குகின்றன.

#### முக்கிய API வகைகள்

**Phi Silica மொழி மாதிரி**
- நுணுக்கமான ஆனால் சக்திவாய்ந்த மொழி மாதிரி சொற்தொகுப்பு மற்றும் காரணமறுக்கும்
- குறைந்த மின் சாப்பாட்டுடன் நேரடி ஊசலுக்கு நுட்ப நூலாக்கம் செய்யப்பட்டுள்ளது
- LoRA முறைகளைப் பயன்படுத்தி தனிப்பயனாக்கலை ஆதரிக்கிறது
- விண்டோஸ் செமாண்டிக் தேடல் மற்றும் அறிவியல் மீட்பு ஒருங்கிணைப்பு

**கணினி காட்சி APIகள்**
- **உரை அங்கீகாரம் (OCR)**: உயர் துல்லியத்துடன் படங்களில் இருந்து உரையை கூறிடுதல்
- **பட உயர்தர மேலுமை**: உள்ளூர் ஏஐ மாதிரிகளைப் பயன்படுத்தி படங்களை உயர்த்துதல்
- **பட பகுப்பாய்வு**: படங்களில் குறிப்பிட்ட பொருட்கள் மற்றும் பகுதியை கண்டறிந்து தனித்துவப்படுத்தல்
- **பட விளக்கம்**: காட்சி உள்ளடக்கத்திற்கு விரிவான உரை விளக்கங்கள் உருவாக்கல்
- **பொருள் அகற்றல்**: AI சக்தியூட்டிய பதிப்பதூக்குதலில் படத்தில் வேண்டாத பொருட்களை நீக்குதல்

**பன்மொழி திறன்கள்**
- **காட்சி-மொழி ஒருங்கிணைப்பு**: உரையும் படங்களின் புரிதலையும் ஒன்றிணைத்தல்
- **செமாண்டிக் தேடல்**: ஒரு இயற்கை மொழி வினவல் மூலம் பன்மூலக்கேடு உள்ளடக்கத்தில் தேடல்
- **அறிவியல் மீட்பு**: உள்ளூர் தரவுடன் நுண்ணறிவான தேடல் அனுபவங்களை கட்டமைத்தல்

### 2. ஃபவுன்ட்ரி லோக்கல்

ஃபவுன்ட்ரி லோக்கல், விண்டோஸ் சிலிகானில் தயாராக பயன்படுத்தக்கூடிய திறந்த மூல மொழி மாதிரிகளுக்கு விரைவில் அணுகலை அபிவிருத்தி நிபுணர்களுக்கு வழங்குகிறது, மாதிரிகளை உலாவுதல், பரிசோதித்தல், தொடர்பு கொள்ளுதல் மற்றும் உள்ளூர் செயலிகளில் நிறுவல் செய்யும் திறன் உடன்.

#### Foundry Local மாதிரிகளுக்கான முன் தேவைகள்

**சிஸ்டம் தேவைகள்:**

- JavaScript/Electron மாதிரிகளுக்கு Node.js v16+

```powershell
foundry --version
foundry model list
```

#### முக்கிய அம்சங்கள்

- தானாகவே மேம்படுத்தல் மற்றும் அளவுகோல் பணிகள்

**உள்ளூர் நிறுவல்**
- மேகம் சார்ந்த சார்புகள் இல்லாமல் முழுமையான ஆஃப்லைன் செயல்பாடு
- தனிப்பயன் மாதிரி வடிவங்கள் மற்றும் அமைப்புகளுக்கு ஆதரவு
- தானாகவே இயங்கும் ஹார்ட்வேர் மேம்பாடுடன் திறம்பட மாதிரி சேவை

### 3. Windows ML

Windows ML என்பது Windows-இல் முக்கிய AI மேடை மற்றும் ஒருங்கிணைந்த முன்மொழிவுக் கால செயல்பாடு ஆகும், இது டெவலப்பர்களுக்கு Windows ஹார்ட்வேர் சூழலில் தனிப்பயன் மாதிரிகளை திறம்பட நிறுவ உதவுகிறது.

#### வடிவமைப்பு நன்மைகள்

**பொருத்தக்கூடிய ஹார்ட்வேர் ஆதரவு**
- AMD, Intel, NVIDIA மற்றும் Qualcomm சிலிக்கான் களுக்கான தானாகவே மேம்படுத்தல்
- CPU, GPU, மற்றும் NPU ஏற்றுமதிக்கான ஆதரவு மற்றும் தெளிவான மாற்றம்
- தனிப்பட்ட மேடை விசேஷ மேம்பாடுகளை அகற்றும் ஹார்ட்வேர் ஒழுங்கமைப்பு

**மாதிரி நுண்ணறிவு**
- பிரபல அமைப்புகளிலிருந்து தானாக மாற்றம் செய்யக்கூடிய ONNX மாதிரி வடிவத்திற்கு ஆதரவு
- தயாரிப்பு தரும் செயல்திறன் உடனான தனிப்பயன் மாதிரி நிறுவல்
- முன்னாள் Windows பயன்பாட்டு வடிவமைப்புகளுடன் இணையமைவு

**தொழில்துறை ஒருங்கிணைப்பு**
- Windows பாதுகாப்பு மற்றும் அமக்குறிப்பு கட்டமைப்புகளுக்குத் தகுதிசெய்யப்பட்டது
- தொழில்துறை நிறுவல் மற்றும் மேலாண்மை கருவிகளுக்கு ஆதரவு
- Windows சாதன மேலாண்மை மற்றும் கண்காணிப்பு அமைப்புகளுடன் இணையல்

### கட்டம் 1: சூழல் அமைப்பு மற்றும் கருவிகள் வரையறுத்தல்

### கட்டம் 3: பயன்பாட்டு மேம்பாடு

- AI செயல்பாட்டிற்கான தானியங்கி சோதனைகளை நடைமுறைப்படுத்தவும்
- AI மேம்படுத்தப்பட்ட அம்சங்களுடன் பயனர் அனுபவ சோதனைகளை நடத்தவும்

### கட்டம் 4: மேம்படுத்தல் மற்றும் நிறுவல்

- வெவ்வேறு செயல்திறன் சூழல்களுக்கு பயனர் அனுபவத்தை மிகைப்படுத்தவும்

**தயாரிப்பு நிறுவல்**

- தொழில்துறை மற்றும் பயனர் நிறுவல்களுக்கு வெளியீட்டு திட்டங்களை ஆய்வுசெய்யவும்

## நடைமுறை அமலாக்க உதாரணங்கள்

- பெரிய ஆவண தொகுதிகளுக்கான அசிஞ்சி செயலாக்கத்தை நடைமுறைப்படுத்தவும்

## செயல்திறன் மேம்பாடு உத்திகள்

- நினைவக மேம்பாட்டுக்கு மாதிரி அளவுகோல் திருத்தம் செயல்படுத்தவும்

- பாதுகாப்பான மாதிரி புதுப்பிப்பு முறைகளை நடைமுறைப்படுத்தவும்
- கையெழுத்தான மாதிரிகள் பயன்படுத்தி மோசடி தடையை உறுதிப்படுத்தவும்
- மாதிரி கோப்புகள் மற்றும் அமைப்புகளுக்கு அணுகல் கட்டுப்பாடுகளை வழிமுறைப்படுத்தவும்

### ஒத்துழைப்பு கவனங்கள்

**ஒழுங்கமைப்புச் சார்பு**
- GDPR, HIPAA, மற்றும் பிற ஒழுங்கமைப்பு தேவைகளுடன் இணக்கமான பயன்பாடுகளை வடிவமைக்கவும்
- AI முடிவெடுக்கும் செயல்முறைகளுக்கான பதிவேடு கண்காணிப்பை நடைமுறைப்படுத்தவும்
- AI உருவாக்கிய முடிவுகளுக்கான வெளிப்படைத்தன்மை அம்சங்களை வழங்கவும்
- AI தரவு செயலாக்கத்தில் பயனர் கட்டுப்பாட்டை செயல்படுத்தவும்

**தொழில்துறை பாதுகாப்பு**
- Windows தொழில்துறை பாதுகாப்பு கொள்கைகளுடன் ஒருங்கிணைக்கவும்
- தொழில்துறை மேலாண்மை கருவிகளை வழக்கமாக நிறுவலுக்கு ஆதரவு
- AI அம்சங்களுக்கு பங்கு அடிப்படையிலான அணுகல் கட்டுப்பாடுகளை நடைமுறைப்படுத்தவும்
- AI செயல்திறனுக்கான நிர்வாக கட்டுப்பாடுகளை வழங்கவும்

## சிக்கல்களை தீர்க்க மற்றும் பிழை திருத்தம்

### பொதுவான மேம்பாட்டு சவால்கள்

**கட்டமைப்பு பிரச்சினைகள்**
- Windows AI API மாதிரிகளுக்கு ARM64 மேடையை உறுதிசெய்யவும்
- Windows App SDK பதிப்பு பொருத்தத்தைக் கண்டு பிடிக்கவும் (1.8.1+ தேவையானது)
- தொகுப்பின் அடையாளம் சரியாக அமைக்கப்பட்டதா என்பதை சரிபார்க்கவும் (Windows AI APIs க்கு தேவை)
- இலக்கு கட்டமைப்பு பதிப்பு ஆதரவை உறுதிசெய்ய கட்டுமான கருவிகளை சரிபார்க்கவும்

**மாதிரி ஏற்றல் பிரச்சினைகள்**
- Windows ML உடன் ONNX மாதிரி பொருத்தத்தை மதிப்பாய்வு செய்யவும்
- மாதிரி கோப்பின் முழுமை மற்றும் வடிவமைப்பு தேவைகளை சரிபார்க்கவும்
- குறிப்பிட்ட மாதிரிகளுக்கு தேவையான ஹார்ட்வேர் திறன்களை உறுதிசெய்யவும்
- மாதிரி ஏற்றுவதற்கான நினைவக ஒதுக்கீடு பிரச்சினைகளை பிழைத்திருத்தவும்
- ஹார்ட்வேர் வேகமூட்டல் செயல்பாடுகளுக்கான செயல்பாட்டு வழங்குநர் பதிவு செயல் உறுதிசெய்யவும்

**நிறுவல் முறை கவனங்கள்**
- **சுய-வாய்ந்த முறை**: பெரிய நிறுவல் அளவு உடன் முழுமையாக ஆதரிக்கப்பட்டது
- **வடிவமைப்பு சார்ந்த முறை**: நொறுக்கிய பரப்பளவு ஆனால் பகிரப்பட்ட இயக்கக்காலம் தேவை
- **பேக்கேஜ் செய்யாத பயன்பாடுகள்**: Windows AI APIs க்கு தெரியாமல் நிறுத்தப்பட்டது
- self-contained ARM64 நிறுவலுக்காக `dotnet run -p:Platform=ARM64 -p:SelfContained=true` பயன்படுத்தவும்

**செயல்திறன் பிரச்சனைகள்**
- வெவ்வேறு ஹார்ட்வேர் கட்டமைப்புகளில் பயன்பாட்டு செயல்திறனை கண்காணிக்கவும்
- AI செயலாக்க குழாய்களில் அதிருப்திகள் கண்டறியவும்
- தரவு முன்கைப்படுத்தல் மற்றும் பின்னர் செயல் நடைமுறைகளை மேம்படுத்தவும்
- செயல்திறன் கண்காணிப்பு மற்றும் அறிவிப்புகளை நடைமுறைப்படுத்தவும்

**இணையமைப்பு கடினங்கள்**
- சரியான பிழை கையாளலுடன் API இணையமைப்பு பிரச்சனைகளை பிழைத்திருத்தவும்
- உள்ளீட்டு தரவு வடிவமைப்புகள் மற்றும் முன்கைப்படுத்தல் தேவைகளை சரிபார்க்கவும்
- எல்லைக் காட்சி மற்றும் பிழை நிலைமைகளை முழுமையாக சோதிக்கவும்
- தயாரிப்பு பிரச்சனைகளுக்கான விரிவான பதிவேட்டைப் பயன்படுத்தவும்

### பிழை திருத்தும் கருவிகள் மற்றும் தொழில்நுட்பங்கள்

**Visual Studio இணையமைவு**
- மாதிரி செயல்பாட்டு பகுப்பாய்வுக்காக AI கருவி திருத்தியை பயன்படுத்தவும்
- AI செயல்பாடுகளுக்கு செயல்திறன் கண்காணிப்பை நடைமுறைப்படுத்தவும்
- சரியான தவறுகாணல் கையாளலுடன் அசிங்க் AI செயல்பாடுகளை பிழைத்திருத்தவும்
- மேம்பாட்டிற்கான நினைவக கண்காணிப்பு கருவிகளைப் பயன்படுத்தவும்

**Windows AI Foundry கருவிகள்**
- மாதிரி சோதனை மற்றும் சரிபார்க்க Foundry Local CLI ஐ பயன்படுத்தவும்
- இணையமைவு சரிபார்ப்புக்கு Windows AI API சோதனைக் கருவிகள்
- AI செயல்பாடு கண்காணிப்புக்கான தனிப்பயன் பதிவேட்டைப் பயன்படுத்தவும்
- AI செயல்பாடு நம்பகத்தன்மைக்கான தானியங்கி சோதனைகளை உருவாக்கவும்

## உங்கள் பயன்பாடுகளுக்கு எதிர்கால பாதுகாப்பு

### புதிய தொழில்நுட்பங்கள்

**அடுத்த தலைமுறை ஹார்ட்வேர்**
- எதிர்கால NPU திறன்கள் பயன்பாடுகளை வடிவமைக்கவும்
- அதிகமான மாதிரி அளவுகளுக்கு மற்றும் சிக்கலுக்கு திட்டமிடவும்
- மேம்படும் ஹார்ட்வேர் க்கான தானாகவே ஏற்படும் வடிவமைப்புகளை செயல்படுத்தவும்
- எதிர்கால ஒத்திசைவு க்கான உயிர்மரபணு தயாரான கணக்கீடுகளை கருதவும்

**மேம்பட்ட AI திறன்கள்**
- பல தரவு வகைகளிலும் பன்முறையாக்க AI இணையமைவுக்கு தயாராக இருங்கள்
- பல சாதனங்களுக்கிடையேயான நேரடி கூட்டுப் பணிக்காவும் திட்டமிடவும்
- கூட்டுக் கற்றல் திறன்களுக்கு வடிவமைக்கவும்
- முனைய-மேகம் புகைக்குழாய்திரைக் நுண்ணறிவு கட்டமைப்புகளைக் கருதவும்

### தொடர்ச்சியான கற்றல் மற்றும் தகுதிவீதம்

**மாதிரி புதுப்பிப்புகள்**
- பிரச்சனையற்ற மாதிரி புதுப்பிப்பு முறைகளை நடைமுறைப்படுத்தவும்
- மேம்பட்ட மாதிரி திறன்கள் அடங்கிய பயன்பாடுகளை வடிவமைக்கவும்
- முந்தைய மாதிரிகளுடன் பின்னோக்கி பொருந்துதலுக்கான திட்டமிடவும்
- மாதிரி செயல்திறன் மதிப்பீட்டிற்கான A/B சோதனையை அமைக்கவும்

**அம்ச வளர்ச்சி**
- புதிய AI திறன்களை ஏற்றுக்கொள்ளும் பிளக்குல் வடிவமைப்புகளை உருவாக்கவும்
- புதிய Windows AI API இணைப்புக்கான திட்டமிடல்
- படிப்படியான திறன் வெளியீட்டுக்கான அம்ச கொடிகளை செயல்படுத்தவும்
- மேம்பட்ட AI அம்சங்களுக்கு இணங்க பயனர் இடைமுகங்களை வடிவமைக்கவும்

##结论

Windows Edge AI மேம்பாடு சக்திவாய்ந்த AI திறன்களும் வலுவான, பாதுகாப்பான, அளவிடக்கூடிய Windows மேடையும் இணைவதைக் குறிக்கிறது. Windows AI Foundry சூழலை ஆற்றல் பெறுவதன் மூலம், டெவலப்பர்கள் சிறந்த தனிப்பட்ட அனுபவங்களை வழங்கும் நுண்ணறிவு பயன்பாடுகளை உருவாக்கக்கூடியனர், அதேசமயம் மிக உயர்ந்த தனியுரிமை, பாதுகாப்பு மற்றும் செயல்திறன் தர நெறிமுறைகளை பராமரிக்கின்றனர்.

Windows AI API கள், Foundry Local, மற்றும் Windows ML இன் கூட்டு அடுத்த தலைமுறை நுண்ணறிவு Windows பயன்பாடுகளுக்கு ஒப்பிட முடியாத அடிப்படையை வழங்குகிறது. AI வளர்ந்துவருவதை தொடர்ந்தும், Windows மேடை உங்கள் பயன்பாடுகள் வளர்ந்து வரும் தொழில்நுட்பங்களுடன் விரிவடையும்படி உறுதி செய்கிறது, மேலும் பல்வேறு Windows ஹார்ட்வேர் சூழல்களில் பொருந்துதலும் செயல்திறனும் பராமரிக்கப்படுகின்றன.

நீங்கள் நுகர்வோர் பயன்பாடுகளையா, தொழில்துறை தீர்வுகளையா, அல்லது சிறப்பு துறை கருவிகளையா உருவாக்குகிறீர்கள் என்பதைப்பொறுத்தது இல்லாமல், Windows Edge AI மேம்பாடு உங்களுடன் கூடிய நுண்ணறிவு, எதிர்வினையுள்ள, மற்றும் ஆழமாக ஒருங்கிணைந்த அனுபவங்களை உருவாக்கும் ஆற்றலை வழங்குகிறது, இது நவீன Windows சாதனங்களின் முழு திறனையும் பயன்படுத்துகிறது.
