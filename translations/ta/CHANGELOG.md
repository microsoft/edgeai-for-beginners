# மாற்றக் குறிப்பு

EdgeAI for Beginners இல் அனைத்து முக்கியமான மாற்றங்களும் இங்கே பதிவுசெய்யப்பட்டுள்ளன. இந்த திட்டம் தேதி அடிப்படையிலான நுழைவுகளை மற்றும் Keep a Changelog பாணியை (சேர்க்கப்பட்டது, மாற்றப்பட்டது, சரிசெய்யப்பட்டது, அகற்றப்பட்டது, ஆவணங்கள், நகர்த்தப்பட்டது) பயன்படுத்துகிறது.

## 2025-10-30

### சேர்க்கப்பட்டது - Module06 AI முகவரிகள் விரிவான மேம்பாடு
- **Microsoft Agent Framework ஒருங்கிணைப்பு** (`Module06/01.IntroduceAgent.md`):
  - தயாரிப்பு தயாரான முகவர் மேம்பாட்டுக்கான Microsoft Agent Framework பற்றிய முழுமையான பகுதி
  - எட்ஜ் பயன்பாட்டிற்கான Foundry Local உடன் விரிவான ஒருங்கிணைப்பு மாதிரிகள்
  - சிறப்பு SLM மாதிரிகளுடன் பல-முகவர் ஒருங்கிணைவு உதாரணங்கள்
  - வள மேலாண்மை மற்றும் கண்காணிப்புடன் நிறுவன பயன்பாட்டு மாதிரிகள்
  - எட்ஜ் முகவர் அமைப்புகளுக்கான பாதுகாப்பு மற்றும் இணக்கமான அம்சங்கள்
  - உண்மையான உலகான செயல்படுத்தல் உதாரணங்கள் (சில்லறை வாணிகம், சுகாதாரம், வாடிக்கையாளர் சேவை)

- **உற்பத்தி SLM முகவர் பயன்பாட்டு நுட்பங்கள்**:
  - **Foundry Local**: நிறுவனம் தரம் வாய்ந்த எட்ஜ் AI ரன்டைம் ஆவணங்கள் நிறுவல், கட்டமைப்பு மற்றும் தயாரிப்பு மாதிரிகள் உடன்
  - **Ollama**: விரிவான கண்காணிப்பு மற்றும் மாதிரி மேலாண்மையுடன் சமூக மையப்படுத்தப்பட்ட பயன்பாடு
  - **VLLM**: மேம்பட்ட மேம்பாட்டு முறைகள் மற்றும் நிறுவன அம்சங்களுடன் உயர் செயல்திறன் கணிப்பு இயந்திரம்
  - மூன்று தளங்களுக்கான தயாரிப்பு பயன்பாட்டு சரிபார்ப்பு பட்டியல் மற்றும் ஒப்பீட்டு அட்டவணைகள்

- **எட்ஜ்-ஒப்பந்த SLM வடிவமைப்புகள் மேம்பாடு**:
  - **ONNX Runtime**: பன்முக SLM முகவர் பயன்பாட்டுக்கான புதிய முழுமையான பகுதி
  - Windows, Linux, macOS, iOS மற்றும் Android மேல் பல தள பயன்பாட்டு மாதிரிகள்
  - தானாக கண்டறியும் CPU, GPU, NPU போன்ற ஹார்டுவேர் வேகப்படுத்தும் விருப்பங்கள்
  - தயாரிப்பு தயாரான அம்சங்கள் மற்றும் முகவர்-குறிப்பிட்ட ஆப்டிமைசேஷன்கள்
  - Microsoft Agent Framework ஒருங்கிணைப்புடன் முழுமையான செயல்படுத்தல் உதாரணங்கள்

- **குறிக்கோள்கள் மற்றும் மேலதிக வாசிப்பு**:
  - 100+ அதிகாரப்பூர்வ மூலங்களுடன் விரிவான ஆதார நூலகம்
  - AI முகவரிகள் மற்றும் சிறு மொழி மாதிரிகள் பற்றிய முக்கிய ஆராய்ச்சி கட்டுரைகள்
  - அனைத்து முக்கிய வடிவமைப்புகள் மற்றும் கருவிகளுக்கான அதிகாரப்பூர்வ ஆவணங்கள்
  - தொழிற்துறை அறிக்கைகள், சந்தை பகுப்பாய்வு மற்றும் தொழில்நுட்ப குறியீடுகள்
  - கல்வி வளங்கள், மாநாடுகள் மற்றும் சமூகவியல் உள்நிலைங்கள்
  - தரநிலைகள், குறிப்புகள் மற்றும் இணக்கமான வடிவமைப்புகள்

### மாற்றப்பட்டது - Module06 உள்ளடக்க நவீகரிப்பு
- **மேம்படுத்தப்பட்ட கற்றல் நோக்கங்கள்**: Microsoft Agent Framework திறன்கள் மற்றும் எட்ஜ் பயன்பாடு திறன்களை சேர்த்தோம்
- **உற்பத்தி கவனம்**: ஒரு கருதுகோளிலிருந்து செயல்படுத்த தயாரான வழிகாட்டுதலுக்கு மாற்றம், தயாரிப்பு உதாரணங்களுடன்
- **குறியீட்டு உதாரணங்கள்**: அனைத்து உதாரணங்களும் நவீன SDK மாதிரிகளுக்கு புதுப்பிக்கப்பட்டன மற்றும் சிறந்த நடைமுறைகள்
- **விடிவிடுக்கலமைப்புக் கொள்கைகள்**: அடுக்கு முகவர் விடிவிடுக்கல்கள் மற்றும் எட்ஜ்-க்கு மேக இணக்கத்தைச் சேர்த்தோம்
- **செயல்திறன் மேம்பாடு**: வள மேலாண்மை மற்றும் தானாக அளவீடு பரிந்துரைகளுடன் மேம்பட்டது

### சேர்க்கப்பட்டது - Module06 மாதிரி தொடர்பு நெறிமுறை (MCP) ஆவண புதுப்பிப்பு
- **MCP அறிமுக நவீகரிப்பு** (`Module06/03.IntroduceMCP.md`):
  - modelcontextprotocol.io இல் இருந்து 2025-06-18 பதிப்பின் சமீபத்திய MCP குறிப்புகளுடன் புதுப்பிக்கப்பட்டது
  - ஸ்டான்டர்டைசான AI பயன்பாட்டு இணைப்புகளுக்கு அதிகாரப்பூர்வ USB-C உருமாற்றம் சேர்க்கப்பட்டது
  - அதிகாரப்பூர்வ இரண்டு அடுக்கு வடிவமைப்பு பகுப்புடன் புதுப்பிக்கப்பட்டது (தரவு அடுக்கு + போக்குவரத்து அடுக்கு)
  - மூலத் தன்மையுடனும் (கருவிகள், வளங்கள், தூண்டுதல்கள்) மற்றும் கிளையண்ட் தன்மையுடனும் (தோற்றமிட்டு வழங்கல், கேள்வி, பதிவு) கூடிய விரிவான ஆவணங்கள்

- **விரிவான MCP குறிக்கோள்கள் மற்றும் வளங்கள்**:
  - **MCP for Beginners** இணைப்புடன் சேர்க்கப்பட்டது (https://aka.ms/mcp-for-beginners)
  - அதிகாரப்பூர்வ MCP ஆவணங்கள் மற்றும் குறிப்புகள் (modelcontextprotocol.io)
  - MCP ஆய்வாளரும் குறிப்பு செயல்பாட்டிலும் உள்ள வளங்கள்
  - தொழில்நுட்ப தரநிலைகள் (JSON-RPC 2.0, JSON Schema, OpenAPI, Server-Sent Events)

  - உள்ளூர் மாதிரிகள் (`samples/05/multi_agent_orchestration.ipynb`) க்கான சரியான குறுக்குப்பயன்பாட்டுடன் ஒருங்கிணைந்தது
  - பழைய `functions` பார்க்கப்படும் நவீன `tools` சுட்டியுடன் செயல்பாடு அழைப்புகள் புதுப்பிக்கப்பட்டன
  - கண்காணிப்பு மற்றும் புள்ளி கணக்கீடு உடன் தயாரிப்பு தயாரான வடிவமைப்புகள் சேர்க்கப்பட்டன

  - உள்ளூர் செயல்பாட்டுடன் ஒத்திசைந்தது (`samples/06/router.py` மற்றும் `samples/06/model_router.ipynb`)
