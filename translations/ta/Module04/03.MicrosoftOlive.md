## அறிமுகம்

Microsoft Olive என்பது பல்துறையினருக்குமான, எளிதாக பயன்படுத்தக்கூடிய ஹார்டுவேர்-அறிந்த மாடல் சிறப்புத்திறன் மேம்பாட்டுத் தொகுப்பு ஆகும், இது வெவ்வேறு ஹார்டுவேர் தளங்களுக்கான இயந்திர கற்றல் மாடல்களை விரைவாக சாதாரணமாக்குகிறது. நீங்கள் CPU, GPU அல்லது சிறப்பு AI துரிதப்படுத்திகளையும் இலக்காகக் கொண்டாலும்கூட, Olive சிறந்த செயல்திறனை அடையும் வகையில், மாடல் துல்லியத்தையும் பாதுகாத்து உங்களுக்கு உதவுகிறது.

## Microsoft Olive என்றால் என்ன?

Olive என்பது எளிதாகப் பயன்படுத்தக்கூடிய ஹார்டுவேர்-அறிந்த மாடல் சிறப்புத்திறன் மேம்பாட்டு கருவி, இது மாடல் சுருக்கம், சிறப்புத்திறன் மேம்பாடு மற்றும் தொகுப்பு ஆகிய துறைகளில் தொழில்துறை முன்னணி தொழில்நுட்பங்களை இணைத்து செயல்படுகிறது. இது ONNX Runtime உடன் ஒன்றிணைந்து முழுமையான தீர்வு வழங்குகிறது.

### முக்கிய அம்சங்கள்

- **ஹார்டுவேர்-அறிந்த சிறப்புத்திறன் மேம்பாடு**: உங்கள் இலக்கு ஹார்டுவேர் க்கான சிறந்த சிறப்புத்திறன் முறைகளை தானாக தேர்ந்தெடுக்கும்
- **40+ சேர்ந்த உள்ளக சிறப்புத்திறன் கூறுகள்**: மாடல் சுருக்கம், அளவீடு, வரைபட சிறப்புத்திறன் மற்றும் பலவற்றை உள்ளடக்கும்
- **எளிய CLI இடைமுகம்**: பொதுவான சிறப்புத்திறன் நடவடிக்கைகளுக்கான எளிய கட்டளைகள்
- **பன்முக உட்கட்டமைப்பு ஆதரவு**: PyTorch, Hugging Face மாடல்கள் மற்றும் ONNX உடன் இயங்கும்
- **பிரபலமான மாடல் ஆதரவு**: Olive தானாகவே Llama, Phi, Qwen, Gemma போன்ற பிரபலமான மாடல் கட்டமைப்புகளை உடனடியாக மேம்படுத்த முடியும்

### நன்மைகள்

- **முறைமை நேரக் குறைப்பு**: பல்வேறு சிறப்புத்திறன் முறைகளை தனிப்பயனாக்காமல் முயற்சிக்க தேவையில்லை
- **செயல்திறன் வளர்ச்சிகள்**: சில சந்தர்ப்பங்களில் 6 மடங்கு வரை வேக முன்னேற்றம்
- **பன்முக தளங்களில் பரவல்**: மேம்படுத்தப்பட்ட மாடல்கள் வெவ்வேறு ஹார்டுவேர்கள் மற்றும் செயல்தளங்களில் வேலை செய்கின்றன
- **துல்லியத்தைக் காப்பது**: சிறப்புத்திறன் செயல்முறைகள் செயல்திறனை மேம்படுத்தும் போதே மாடல் தரத்தைக் காக்கின்றன

## பதிவிறக்கம் செய்வது எப்படி

### முனைவேண்டியவை

- Python 3.8 அல்லது அதற்கு மேலான பதிப்பு
- pip தொகுப்பு மேலாளர்
- மெய்நிகர் சூழல் (பரிந்துரைக்கப்படுகிறது)

### அடிப்படை பதிவிறக்கம்

ஒரு மெய்நிகர் சூழலை உருவாக்கி இயக்கவும்:

```bash
# மெய்நிகர் சுற்றுப்புறம் உருவாக்கு
python -m venv olive-env

# மெய்நிகர் சுற்றுப்புறத்தை செயல்படுத்து
# விண்டோஸில்:
olive-env\Scripts\activate
# மேக்ஓஎஸ்/லினக்சில்:
source olive-env/bin/activate
```

தானாக சிறப்புத்திறன் அம்சங்களுடன் Olive ஐ நிறுவவும்:

```bash
pip install olive-ai[auto-opt]
pip install transformers onnxruntime-genai
```

### விருப்ப சார்ந்த சார்புகள்

Olive கூடுதல் அம்சங்களுக்கு பல விருப்ப சார்ந்த சார்புக்களை வழங்குகிறது:

# அனைத்து அம்சங்களுக்கும்

## விரைவு துவக்கக் கையேடு

### உங்கள் முதலாவது சிறப்புத்திறன்

Olive இன் தானாக சிறப்புத்திறன் அம்சத்தை பயன்படுத்தி ஒரு சிறுத்தர மொழி மாடலை மேம்படுத்துவோம்:

```bash
olive auto-opt \
  --model_name_or_path HuggingFaceTB/SmolLM2-135M-Instruct \
  --output_path models/smolm2-optimized \
  --device cpu \
  --provider CPUExecutionProvider \
  --use_ort_genai \
  --precision int4 \
  --log_level 1
```

### இந்த கட்டளை என்ன செய்கிறது

சிறப்புத்திறன் செயல்முறை: உள்ளூர் கேச்சிலிருந்து மாடலைப் பெற்று, ONNX வரைபடத்தைப் பிடித்து ONNX தரவு கோப்பில் எடைகளைச் சேமிப்பதும், ONNX வரைபடத்தை மேம்படுத்துவதும், RTN முறையைப் பயன்படுத்தி மாடலை int4 ஆக அளவீடு செய்வதும் ஆகும்.

### கட்டளை அளவுருக்கள் விளக்கம்

- `--model_name_or_path`: Hugging Face மாடல் அடையாளம் அல்லது உள்ளூர் பாதை
- `--output_path`: மேம்படுத்தப்பட்ட மாடல் சேமிக்கப்படும் அடைவகம்
- `--device`: இலக்கு சாதனம் (cpu, gpu)
- `--provider`: அமல்படுத்தும் வழங்குநர் (CPUExecutionProvider, CUDAExecutionProvider, DmlExecutionProvider)
- `--use_ort_genai`: ONNX Runtime Generate AI ஐ பரிமாற்றத்திற்கு பயன்படுத்தவும்
- `--precision`: அளவீடு துல்லியம் (int4, int8, fp16)
- `--log_level`: பதிவு அளவுரு (0=குறைந்த, 1=விரிவான)

## உதாரணம்: Qwen3 ஐ ONNX INT4 ஆக மாற்றுதல்

கொடுக்கப்பட்டுள்ள Hugging Face உதாரணம் [lokinfey/Qwen3-8B-ONNX-INT4-CPU](https://huggingface.co/lokinfey/Qwen3-8B-ONNX-INT4-CPU) அடிப்படையில், Qwen3 மாடலை எப்படி மேம்படுத்துவது:

### படி 1: மாடலை பதிவிறக்குதல் (விருப்பமானது)

பதிவிறக்கும் நேரத்தை குறைக்க முக்கிய கோப்புகளை மட்டும் கேச்சிங் செய்யவும்:

```bash
huggingface-cli download Qwen/Qwen2.5-0.5B-Instruct *.json *.safetensors *.txt
```

### படி 2: Qwen3 மாடலை மேம்படுத்துதல்

```bash
olive auto-opt \
  --model_name_or_path Qwen/Qwen2.5-0.5B-Instruct \
  --output_path models/qwen3-onnx-int4 \
  --device cpu \
  --provider CPUExecutionProvider \
  --use_ort_genai \
  --precision int4 \
  --log_level 1
```

### படி 3: மேம்படுத்தப்பட்ட மாடலை சோதனை செய்தல்

உங்கள் மேம்படுத்தப்பட்ட மாடலை சோதனை செய்ய எளிய Python ஸ்கிரிப்ட் உருவாக்கவும்:

```python
import onnxruntime_genai as og

# மேம்படுத்தப்பட்ட மாதிரியை ஏற்றவும்
model = og.Model('models/qwen3-onnx-int4')
tokenizer = og.Tokenizer(model)

# ஒரு உரையாடல் வடிவமைப்பை உருவாக்கவும்
chat_template = '<|im_start|>user\n{input}<|im_end|>\n<|im_start|>assistant\n'

# உரையை உருவாக்கவும்
prompt = "What is machine learning?"
input_tokens = tokenizer.encode(chat_template.format(input=prompt))

params = og.GeneratorParams(model)
params.set_search_options(max_length=200)
params.input_ids = input_tokens

generator = og.Generator(model, params)

print("Generated response:")
while not generator.is_done():
    generator.compute_logits()
    generator.generate_next_token()
    
    new_token = generator.get_next_tokens()[0]
    print(tokenizer.decode([new_token]), end='', flush=True)

print()
```

## சிறந்த நடைமுறைகள்

### 1. மாடல் தேர்வு
- சோதனைக்காக சிறிய மாடல்களுடன் துவங்கவும் (எ.கா., 0.5B-7B அளவுருக்கள்)
- உங்கள் இலக்கு மாடல் கட்டமைப்பு Olive மூலம் ஆதரிக்கப்படுகிறது என்பதை உறுதிப்படுத்தவும்

### 2. ஹார்டுவேர் கருத்துக்களை
- உங்கள் சிறப்புத்திறன் இலக்கை உங்கள் பரவல் ஹார்டுவேர் பயன்பாட்டுடன் பொருத்தவும்
- CUDA பொருத்தமான ஹார்டுவேர்கள் இருந்தால் GPU சிறப்புத்திறன் பயன்படுத்தவும்
- விண்டோஸ் இயந்திரங்களுக்கு இணைந்த காட்சி இருப்பின் DirectML கருத்தில் கொள்ளவும்

### 3. துல்லியம் தேர்வு
- **INT4**: அதிகபட்ச சுருக்கம், சிறிய துல்லியத் தப்புகள்
- **INT8**: அளவு மற்றும் துல்லியத்திற்கான நல்ல சமன்வு
- **FP16**: குறைந்த துல்லியத் தவறுகள், மிதமான அளவு குறைப்பு

### 4. சோதனை மற்றும் உறுதிப்படுத்தல்
- எப்போதும் சுயமறுஉபயோகங்களை வைத்து மேம்படுத்தப்பட்ட மாடல்களை சோதிக்கவும்
- செயல்திறன் அளவுருக்களை (தாமதம், ஊக்கத்திறன், துல்லியம்) ஒப்பிடவும்
- மதிப்பீட்டுக்கான பிரதிநிதி உள்ளீட்டு தரவுகளைப் பயன்படுத்தவும்

### 5. முறை முறைசார்ந்த மேம்பாடு
- விரைவான முடிவுகளுக்கு தானாக சிறப்புத்திறன் அவசியம்
- நுட்பமான கட்டுப்பாட்டுக்கு கட்டமைப்பு கோப்புகளை பயன்படுத்தவும்
- வித்தியாசமான சிறப்புத்திறன் கடப்பாடு முயற்சிக்கவும்

- **தாமதக் குறைப்பு**: சாதாரணத்தினை விட 2-6 மடங்கு வேகம்
- **நினைவகக் குறைப்பு**: அளவீட்டால் 50-75% நினைவக பயன்பாடு குறைப்பு
- **துல்லியத்தைக் காப்பாற்றல்**: 95-99% துல்லியம் பாதுகாக்கப்பட்டது

### AI கருவிப் தொகுப்புடன் ஒருங்கிணைத்தல்

செய்முறைகள் வசதியாக ஒருங்கிணைக்கின்றன:
- **VS Code AI கருவி தொகுப்பு**: மாடல் சிறப்புத்திறன் நேரடி ஒருங்கிணைப்பு
- **Azure Machine Learning**: மேகத்திலான சிறப்புத்திறன் செயல்முறை
- **ONNX Runtime**: சிறப்பான நுட்ப ஊக்கப்படுத்தல்
