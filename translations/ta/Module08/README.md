# Module 08: Microsoft Foundry Local உடன் கைமுறையடிப்படையாக்கம் - முழுமையான டெவலப்பர் கருவிகள் தொகுப்பு

## கண்ணோட்டம்

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) அடுத்த தலைமுறை எட்ஜ் AI அபிவிருத்தியை பிரதிநிதித்துவப்படுத்துகிறது, மேம்படுத்திய கருவிகளை வழங்கி, AI பயன்பாடுகளை உள்ளூரில் கட்டமைக்க, அமல்படுத்த மற்றும் அளவிட உதவுகிறது, அதே நேரத்தில் Azure AI Foundry உடன் இணக்கம் தொடர்கிறது. இந்த தொகுப்பு நிறுவல் முதல் மேம்படுத்தப்பட்ட ஏஜென்ட் அபிவிருத்தியை முழுமையாக கையாள்கிறது.

**முக்கிய தொழில்நுட்பங்கள்:**
- Microsoft Foundry Local CLI மற்றும் SDK
- Azure AI Foundry இணைப்பு
- சாதனத்தில் நெறிப் முனைகண்டுபிடிப்பு
- உள்ளூரான மாதிரி கാഷிங் மற்றும் முக்கியத்துவப் பெருக்குதல்
- ஏஜென்ட் அடிப்படையிலான கட்டமைப்புகள்

## கற்றல் குறிக்கோள்கள்

இந்த தொகுப்பை முடித்தவுடன், நீங்கள்:

- **Foundry Local ஆல் புரிதல்**: Windows 11 அபிவிருத்திக்கான நிறுவல், அமைத்தல் மற்றும் மேம்படுத்தல்
- **பல்வேறு மாதிரிகள் இயக்கம்**: phi, qwen, deepseek மற்றும் GPT மாதிரிகளை உள்ளூரில் CLI கட்டளைகள் கொண்டு இயக்குதல்
- **உற்பத்தி தீர்வுகள் கட்டமைத்தல்**: மேம்பட்ட ப்ராம்ட் இன்ஜினியரிங் மற்றும் தரவு ஒருங்கிணைப்புடனான AI பயன்பாடுகள் உருவாக்குதல்
- **திறந்த மூலச் சூழனை பயன்படுத்துதல்**: Hugging Face மாதிரிகள் மற்றும் சமுதாய பங்களிப்புகளை சேர்த்தல்
- **AI ஏஜென்ட்கள் உருவாக்குதல்**: தரைத்தட்டுப்பாடுகள் மற்றும் ஒருங்கிணைப்பு திறன்களுடன் புத்தியுள்ள ஏஜென்ட்கள் கட்டமைத்தல்
- **எண்டர்பிரைஸ் மாதிரிகள் நடைமுறைப்படுத்தல்**: உற்பத்தி விரிவீடுகளுக்கு தகுந்த தனிப்பயன் மற்றும் அளவிடக்கூடிய AI தீர்வுகள் உருவாக்கல்

## முன்னோக்கிய தேவைகள்

### முறைமைத் தேவைகள்
- **இருக்கும் செயலியமைப்பு**: Windows 11 (22H2 அல்லது அதற்கு மேல்)
- **நினைவகம்**: 16GB RAM (பெரிய மாதிரிகளுக்கு 32GB பரிந்துரை)
- **சேமிப்பு**: மாதிரி காஷிங்கிற்காக 50GB இலவச இடம்
- **ஹார்ட்வேர்**: NPU-செம்மை கொண்ட சாதனம் பரிந்துரை (Copilot+ PC), GPU விருப்பம்
- **நெட்வொர்க்**: ஆரம்ப மாதிரி பதிவிறக்கம் க்கான வேகமான இணையம்

### அபிவிருத்தி சூழல்
- Visual Studio Code மற்றும் AI Toolkit விரிவாக்கம்
- Python 3.10+ மற்றும் பிப்
- பதிப்புக் கட்டுப்பாட்டிற்கு Git
- PowerShell அல்லது கட்டளை முறைமை
- Azure CLI (மேக இணைக்கப்பட்டலில் விருப்பம்)

### அறிவியல் தேவைகள்
- AI/ML கருத்துக்களின் அடிப்படை புரிதல்
- கட்டளை வரி பழக்கம்
- Python நிரலாக்க அடிப்படைகள்
- REST API கருத்துக்கள்
- ப்ராம்ப்டிங் மற்றும் மாதிரி நெறியியல் அடிப்படை

## கற்றல் முடிவுகள்

இந்த தொகுப்பை முடித்த பிறகு, நீங்கள்:

### தொழில்நுட்ப தேர்ச்சி
- **Foundry Local ஐ நிறுவி, நிர்வகிக்க**: அபிவிருத்தி மற்றும் உற்பத்தி சூழல்களில்
- **மாதிரிகள் இணைப்பு**: Microsoft, Hugging Face மற்றும் சமுதாய மூலங்களைச் சேர்ந்த பல்வேறு மாதிரி குடும்பங்களுடன் தட்டுவிழா இல்லாமல் பணிபுரிதல்
- **பயன்பாடுகள் உருவாக்கு**: மேம்பட்ட அம்சங்களுடனும் மேம்பாடுகளுடனும் உற்பத்தி-தயாரிய AI பயன்பாடுகளை உருவாக்கல்
- **ஏஜென்ட்களை உருவாக்கு**: தரைத்தட்டு, கருத்தாக்கம் மற்றும் கருவி இணைப்பு கொண்ட அந்தரங்க AI ஏஜென்ட்கள் செயல்படுத்தல்

### நீதி புரிதல்
- **கட்டமைப்பு முடிவுகள்**: உள்ளூர் மற்றும் மேக விரிவாக்கத்திற்குமான அறிவார்ந்த தேர்வுகள் செய்தல்
- **செயல்திறன் மேம்பாடு**: பொருத்த மாறுபாடுகளுக்கு ஏற்ப பார்க்கும் திறனை மேம்படுத்தல்
- **நிறுவனர் அளவீடு**: உள்ளூரான பரிசோதனைகளில் இருந்து நிறுவன விரிவாக்கங்களுக்கு பயன்பாட்டை வடிவமைத்தல்
- **தனியுரிமை மற்றும் பாதுகாப்பு**: உள்ளூரில் பார்வை நிரூபிப்புடன் தனியுரிமை பாதுகாக்கப்பட்டது AI தீர்வுகளை நடைமுறைப்படுத்தல்

### புதுமை திறன்கள்
- **வேகமான கட்டமைப்பு**: அனைத்து 10 மாதிரி முறைகளிலும் விரைவாக AI பயன்பாட்டுக் கான்செப்டுகளை கட்டமைந்து சோதித்தல்
- **சமுதாய இணைப்பு**: திறந்த மூல மாதிரிகளை பயன்படுத்தி சூழலை வளப்படுத்தல்
- **மேம்பட்ட மாதிரிகள்**: RAG, ஏஜென்ட்கள் மற்றும் கருவி இணைப்புகள் போன்ற முன்னில்லா AI மாதிரிகளை நடைமுறையாக்குதல்
- **கட்டமைப்பு தேர்ச்சி**: LangChain, Semantic Kernel, Chainlit மற்றும் Electron உடன் நிபுணத்துவ இணைப்பு
- **உற்பத்தி விரிவாக்கம்**: உள்ளூர் மாதிரிகள் முதல் நிறுவன அமைப்புகள் வரை விரிவாக்கக்கூடிய AI தீர்வுகளை வெளியிடுதல்
- **எதிர்காலத்திற்கு தயார் அபிவிருத்தி**: எதிர்பார்க்கப்படும் AI தொழில்நுட்பங்கள் மற்றும் மாதிரிகளுக்கு தயாராக பயன்பாடுகளை உருவாக்கல்

## விரைவான தொடக்கு வழிகாட்டி - அனைத்து 10 மாதிரிகளும்

### சூழல் அமைப்பு (எல்லா மாதிரிகளுக்குமான தேவை)

```powershell
# 1. Module08 ஐ கிளோன் செய்து செல்லவும்
cd Module08

# 2. Python க்கான வர்ச்சுவல் சுற்றுப்புறம் உருவாக்கவும்
py -m venv .venv
.\.venv\Scripts\activate

# 3. அடிப்படை சார்புகளைக் நிறுவவும்
pip install -r requirements.txt

# 4. Foundry Local ஐ (ஏற்கனவே நிறுவப்படவில்லை என்றால்) நிறுவவும்
winget install Microsoft.FoundryLocal

# 5. Foundry Local நிறுவலை சரிபார்க்கவும்
foundry --version
foundry model list
```

### அடிப்படை மூல மாதிரிகள் (01-06)

**மாதிரி 01: REST சாட் விரைவு தொடக்கம்**
```powershell
# ஃபௌண்ட்ரி லோகல் சேவையை தொடங்கு
foundry model run phi-4-mini

# ரெஸ்ட் சந்தைப்படை நிகழ்வை இயக்கு
python samples/01/chat_quickstart.py
```

**மாதிரி 02: OpenAI SDK இணைப்பு**
```powershell
# மாதிரி இயங்குவதை உறுதி செய்க
foundry status

# SDK டெமோவை இயக்குக
python samples/02/sdk_quickstart.py
```

**மாதிரி 03: மாதிரி கண்டுபிடித்தலும் ஒப்பிடலும்**
```powershell
# விரிவான மாதிரி சோதனையை இயக்கவும்
samples/03/list_and_bench.cmd

# அல்லது தனி கூறுகளை இயக்கவும்
foundry model list --available
foundry model download qwen2.5-0.5b
foundry model benchmark phi-4-mini
```

**மாதிரி 04: Chainlit RAG பயன்பாடு**
```powershell
# Chainlit சார்ந்த பொருட்களை நிறுவவும்

# RAG உரையாடல் செயலியை தொடக்கம் செய்க
chainlit run samples/04/app.py -w
# http://localhost:8000 இல் உலாவியைத் திறக்கிறது
```

**மாதிரி 05: பல ஏஜென்ட் ஒருங்கிணைப்பு**
```powershell

# குறிப்பிட்ட முகவர் உதாரணங்களை இயக்கவும்
```

**மாதிரி ஏற்றல் சிக்கல்கள்**
```powershell
# கிடைக்கும் மாதிரிகள் சரிபார்க்கவும்
foundry model list --cached

# கிடைக்காத மாதிரிகள் பதிவிறக்கம் செய்யவும்
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# தேவையானால் மீண்டும் ஏற்றம் செய்யவும்
foundry model unload --all
foundry model run phi-4-mini
```

```powershell
# pip ஐ மேம்படுத்தி மீண்டும் நிறுவவும்
python -m pip install --upgrade pip
pip install -r requirements.txt --force-reinstall

# Node.js மாதிரிகளுக்காக
npm cache clean --force
npm install
```
