# அமர்வு 3: திறந்த மூல மாடல் கண்டறிதலும் மேலாண்மையும்

## கண்ணோட்டம்

இந்த அமர்வு Foundry Local உடன் நடைமுறை மாடல் கண்டறிதல் மற்றும் மேலாண்மையை மையமாகக் கொண்டது. கிடைக்கும் மொடல்கள் பட்டியலிட, வெவ்வேறு விருப்பங்களை சோதிக்க, மற்றும் அடிப்படை செயல்திறன் பண்புகளை புரிந்துகொள்ள கற்றுக்கொள்வீர்கள். முறையை பயிற்சியுடன் கூடிய ஆய்வுக்கு அதிக முக்கியத்துவம் கொடுக்கும், இது உங்களுக்கான பயன்பாடுகளுக்கான சரியான மொடல்களை தேர்வு செய்ய foundry CLI உதவும்.

## கற்பது குறிக்கோள்கள்

- மாடல் கண்டறிதல் மற்றும் மேலாண்மைக்கு foundry CLI கட்டளைகளை ஆற்றலில் கற்று கொள்வது
- மாடல் சேமிப்பகம் மற்றும் உள்ளூர் சேமிப்பு மாதிரிகளை புரிந்து கொள்வது
- வேகமாக வெவ்வேறு மொடல்களை சோதித்து ஒப்பிட கற்றுக்கொள்வது
- மாடல் தேர்வு மற்றும் மதிப்பீட்டுக்கான நடைமுறை வேலைநிரலை உருவாக்குதல்
- Foundry Local மூலம் கிடைக்கும் வளர்ந்து வரும் மாடல் சூழ்நிலையை ஆராய்வது

## முன் தேவைகள்

- அமர்வு 1: Foundry Local உடன் தொடக்கம் முடித்திருக்க வேண்டும்
- Foundry Local CLI நிறுவப்பட்டு அணுகக்கூடியது
- மாடல் பதிவிறக்கங்களுக்கு போதுமான சேமிப்பு இடம் (1GB முதல் 20GB+ வரை மாடல்கள் இருப்பது சாத்தியம்)
- மாடல் வகைகள் மற்றும் பயன்பாடுகள் அடிப்படையில் புரிதல்-Foundry Local உடன் மூலத்தள மாடல்கள்

இந்த அமர்வு திறந்த மூல மாடல்களை Foundry L## பாகம் 6: நடைமுறை பயிற்சி

### பயிற்சி: மாடல் கண்டறிதல் மற்றும் ஒப்பிடல்

Sample 03 அடிப்படையில் உங்களுடைய தானியங்கி மதிப்பீடு ஸ்கிரிப்டை உருவாக்குங்கள்:

```cmd
REM create_model_test.cmd

echo.
echo Model test complete!
```

4. **கண்டறிதல்களை பதிவு செய்யுங்கள்**: எளிய ஒப்புமை பட்டியலை உருவாக்குங்கள்

## பாகம் 7: பிரச்சனைகள் தீர்வு மற்றும் சிறந்த நடைமுறைகள்

### பொதுவான பிரச்சனைகள் மற்றும் தீர்வுகள்

**மாடல் துவங்குவதில்லை:**
```cmd
REM Check service status
foundry service status

REM Restart service if needed
foundry service stop
foundry service start

REM Try with verbose output
foundry model run phi-4-mini --verbose
```

**போதுமான நினைவகமில்லை:**
- சிறிய மாடல்களுடன் துவங்குங்கள் (`phi-4-mini`)

- எல்லைகளை அடிக்கடி தாக்கும் போது RAM உயர்த்துங்கள்

**மந்தமான செயல்திறன்:**
- மாடல் முழுமையாக ஏற்றப்பட்டிருக்கிறதா என்பதை உறுதிப்படுத்துங்கள் (விரிவான வெளிப்பாட்டைப் பார்க்கவும்)
- தேவையற்ற பின்னணி செயலிகளைக் மூடுங்கள்
- வேகமான சேமிப்பை (SSD) பரிசீலிக்கவும்

### சிறந்த நடைமுறைகள்

1. **சிறியதாக துவங்குங்கள்**: அமைப்பை சரிபார்க்க `phi-4-mini` உடன் தொடங்குங்கள்
2. **ஒரே நேரத்தில் ஒரு மாடல்**: புதியதை துவங்குவதற்கு முன் முந்தைய மாடல்களை நிறுத்துங்கள்
3. **வளங்களை கண்காணிக்கவும்**: நினைவக பயன்பாட்டைப் பார்த்து வைக்கவும்
4. **மாவு சோதனை செய்யவும்**: சமமான ஒப்பீடுகளுக்காக அதே கோரிக்கைகளை பயன்படுத்துங்கள்
5. **결과들을 பதிவு செய்யவும்**: உங்கள் பயன்பாடுகளுக்கான மாடல் செயல்திறனில் குறிப்பு வைக்கவும்

## பாகம் 1: Foundry CLI மூலம் மாடல் கண்டறிதல்

### அடிப்படை மாடல் மேலாண்மை கட்டளைகள்

foundry CLI மாடல் கண்டறிதலும் மேலாண்மையும் குறித்த நேரடியான கட்டளைகளை வழங்குகிறது:

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### உங்கள் முதல் மொடல்களை இயக்குதல்

செயல்திறன் பண்புகளை புரிந்து கொள்ள பிரபலமான, நன்கு சோதிக்கப்பட்ட மொடல்களுடன் தொடங்குங்கள்:

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**குறிப்பு:** `--verbose` கொடியுடன் தொடக்க தகவல்கள் விரிவாகக் கொடுக்கப்படும், அதாவது:
- மாடல் பதிவிறக்க முன்னேற்றம் (முதல் முறையில்)
- நினைவக ஒதுக்கீட்டு விவரங்கள்
- சேவை இணைப்புச் செய்திகள்
- செயல்திறன் துவக்க அளவைகள்

### மாடல் வகைகளைக் கோரிக்கை செய்வது

**சிறிய மொழி மொடல்கள் (SLMs):**
- `phi-4-mini`: விரைவு, திறமையானது, பொது உரையாடலுக்கு சிறந்தது
- `phi-4`: அதிக திறன் கொண்ட பதிப்பு, சிறந்த ஆராய்ச்சி திறன்

**நடுத்தர மொடல்கள்:**
- `qwen2.5-7b`: சிறந்த ஆராய்ச்சி திறன் மற்றும் நீண்ட உள்ளடக்கம்
- `deepseek-r1-7b`: குறியீடு உருவாக்கத்திற்கு சிறந்தது

**மிகப்பெரிய மொடல்கள்:**
- `llama-3.2`: மேட்டாவின் சமீபத்திய திறந்த மூல மாடல்
- `qwen2.5-14b`: நிறுவன மட்டமான ஆராய்ச்சி திறன்

## பாகம் 2: விரைவான மாடல் சோதனை மற்றும் ஒப்பிடல்

## பாகம் 5: எளிய மாடல் செயல்திறன் மதிப்பீடு

### அடிப்படை செயல்திறன் சோதனை

மாடல் செயல்திறனை ஒப்பிட இண்டை நேரடியான முறையை கீழே காண்கிறீர்கள்:

```python
# simple_bench.py - மாதிரி 03 கள் அடிப்படையில்
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# தற்போது இயங்கும் மாமல் சோதனை செய்யவும்
if __name__ == "__main__":
    # வெவ்வேறு மாடல்களுடன் சோதனை செய்யவும் (ஒவ்வொரு மாடலும் முதலில் ஆரம்பிக்கவும்)
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```
