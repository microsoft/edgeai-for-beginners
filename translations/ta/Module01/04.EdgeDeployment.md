## அறிமுகம்

இந்த பகுதியில், எஜ் சாதனங்களில் AI மாடல்களை பயன்படுத்துவதற்கான நடைமுறை அம்சங்களை ஆராய்வோம். வெற்றிகரமான எஜ் பயன்பாட்டிற்கான முக்கிய கருத்துக்கள், வன்பொருள் தளம் தேர்வு மற்றும் தனித்துவமான எஜ் கணினி சூழல்களுக்கு உரிய மேம்படுத்தல் தொழில்நுட்பங்களை காண்போம்.

## கற்றல் நோக்கங்கள்

இந்தப் பகுதியின் முடிவில், நீங்கள்:

- வெற்றிகரமான எஜ் AI பயன்பாட்டிற்கான முக்கிய கருத்துக்களை புரிந்துகொள்ள முடியும்
- வேறுபட்ட எஜ் AI பணிகளுக்கான பொருத்தமான வன்பொருள் தளங்களை அடையாளம் காண முடியும்
- வேறுபட்ட எஜ் AI வன்பொருள் தீர்வுகளுக்கிடையேயான வர்த்தக-நிலைகளை உணர முடியும்
- பல்வேறு எஜ் AI வன்பொருள் தளங்களுக்கு தனித்துவமான மேம்படுத்தல் உத்திகளைக் கையாள முடியும்

## எஜ் AI பயன்பாட்டு கருத்துக்கள்

எஜ் சாதனங்களில் AIயை பயன்படுத்துவது மேக பயன்பாட்டுடன் ஒப்பிடுகையில் தனித்துவமான சவால்களையும் தேவைகளையும் கொண்டுள்ளது. வெற்றிகரமான எஜ் AI அமல்படுத்தல் பல காரணிகளை கவனமாக பரிசீலிக்க வேண்டும்:

### வன்பொருள் வளக் குறைப்புகள்

எஜ் சாதனங்களுக்கு, மேக கட்டமைப்புடன் ஒப்பிடுகையில், நிரலாக்க வளங்கள் குறைவாக உள்ளன:

- **நினைவகக் குறைப்புகள்**: பல எஜ் சாதனங்களுக்கு தக்க RAM (சில MB முதல் சில GB வரை) மட்டுமே உள்ளது
- **நிலைத்த சேமிப்பு கொள்கைகள்**: குறைந்த நிலைத்த சேமிப்பு காரணமாக மாடல் அளவு மற்றும் தரவு மேலாண்மை பாதிக்கப்படுகிறது
- **செயலாக்க சக்தி**: CPU/GPU/NPU திறன்கள் கட்டுப்படுத்தப்படுவதால் முடிவெடுக்கும் வேகம் குறைகிறது
- **திறன் பயன்பாடு**: பல எஜ் சாதனங்கள் பேட்டரி திறனில் இயங்குகின்றன அல்லது வெப்பக் கட்டுப்பாடுகள் உள்ளன

### இணைப்பு கருத்துக்கள்

எஜ் AI மாறும் இணைப்புகளுடன் செயல்படவேண்டும்:

- ** இடைநீக்கம் இணைப்பு**: நெட்வொர்க் துண்டிப்பு பொழுதும் செயல்பாடுகள் தொடர வேண்டும்
- **பாண்ட்விட் குறைகள்**: தரவு மையங்களுடன் ஒப்பிடுகையில் குறைந்த தரவு பரிமாற்ற திறன்
- **தாமதத் தேவைகள்**: பல பயன்பாடுகள் நேரடி அல்லது அருகிலுள்ள நேர விரைவில் செயலாக்கம் தேவை
- **தரவு ஒத்திசைவு**: உள்ளூர் செயலாக்கத்தை தவிற மேக ஒத்திசைவை பராமரித்தல்

### பாதுகாப்பு மற்றும் தனியுரிமை தேவைகள்

எஜ் AI, பாதுகாப்பு சவால்களை அறிமுகப்படுத்துகிறது:

- **படிமுறைக் பாதுகாப்பு**: சாதனங்கள் நடைமுறைமாக அணுகக்கூடிய இடங்களில் அமைக்கப்படலாம்
- **தரவு பாதுகாப்பு**: ஆபத்து வாய்ப்புள்ள சாதனங்களில் செவிவரவான தரவு செயலாக்கம்
- **அங்கீகாரம்**: எஜ் சாதன செயல்பாட்டுக்கு பாதுகாப்பான அணுகல் கட்டுப்பாடு
- **புதுப்பிப்பு மேலாண்மை**: மாடல் மற்றும் மென்பொருள் புதுப்பிப்புகளுக்கான பாதுகாப்பான முறைகள்

### பயன்பாடு மற்றும் மேலாண்மை

நடைமுறை பயன்பாட்டுக் கருத்துக்கள்:

- **கூட்டப்பட்டது மேலாண்மை**: பல எஜ் பயன்பாடுகள் பகிரப்பட்ட பிற சாதனங்களை உள்ளடக்குகின்றன
- **பதிப்பு கட்டுப்பாடு**: பகிரப்பட்ட சாதனங்களில் மாடல் பதிப்புகளை பராமரித்தல்
- **மிகவும் கண்காணித்தல்**: செயல்திறன் கண்காணிப்பு மற்றும் பிழை கண்டறிதல் எஜ் பகுதியில்
- **வாழ்க்கைச்சுழற்சி மேலாண்மை**: முதல் பயன்பாட்டிலிருந்து புதுப்பிப்புகள் மற்றும் ஓய்வுக்கு வரை

#### மேம்பாட்டு அணுகுமுறை

Intel OpenVINO கருவிப்பெட்டியை மாடல்களை மேம்படுத்த மற்றும் பயன்படுத்த வழங்குகிறது:

```python
# உதாரணம்: எட்ஜ் டிப்ளாய்மெண்டுக்காக OpenVINO பயன்படுத்துதல்
from openvino.inference_engine import IECore

# இன்பெரன்ஸ் என்ஜினைப் தொடக்கம் செய்யவும்
ie = IECore()

# IR கோப்புகளில் இருந்து நெட்வொர்க்கை படியுங்கள்
net = ie.read_network(model="optimized_model.xml", weights="optimized_model.bin")

# உள்ளீட்டு மற்றும் வெளியீட்டு புளாப்களை தயார் செய்யவும்
input_blob = next(iter(net.input_info))
output_blob = next(iter(net.outputs))

# நெட்வொர்க்கை சாதனத்தில் (CPU, GPU, MYRIAD, மற்றும் பிற) ஏற்றவும்
exec_net = ie.load_network(network=net, device_name="CPU")

# உள்ளீட்டை தயார் செய்யவும்
input_data = preprocess_image("sample.jpg")

# இன்பெரன்ஸை இயக்கவும்
result = exec_net.infer(inputs={input_blob: input_data})

# வெளியீட்டை செயலாக்கவும்
output = result[output_blob]
```

```python
# கட்டுமானர் மற்றும் நெட்வொர்க்கை உருவாக்கவும்
logger = trt.Logger(trt.Logger.INFO)
builder = trt.Builder(logger)
network = builder.create_network(1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH))

# ONNX மாடலை பகுப்பாய்வு செய்யவும்
parser = trt.OnnxParser(network, logger)
with open("model.onnx", "rb") as f:
    parser.parse(f.read())

# திறம்பட தீர்மானம்செய்யும் அமைப்பை உருவாக்கவும்
config = builder.create_builder_config()
config.max_workspace_size = 1 << 30  # 1ஜிபி
config.set_flag(trt.BuilderFlag.FP16)

# இயந்திரத்தை உருவாக்கி தொடர் வடிவாக்கவும்
engine = builder.build_engine(network, config)
with open("model.trt", "wb") as f:
    f.write(engine.serialize())

# ரன் டைம் உருவாக்கி செயல்படுத்தவும்
runtime = trt.Runtime(logger)
engine = runtime.deserialize_cuda_engine(open("model.trt", "rb").read())
context = engine.create_execution_context()

# தீர்மானத்தைக் இயக்கவும்
input_data = preprocess_image("sample.jpg")
output = run_inference(context, input_data, engine)
```

- **பேட்டரி தாக்கம்**: AI பணிகள் இயங்கும் பொழுது இயங்கும் காலம் குறைவு
- **வெப்ப தொடர்ந்து திறன்**: நீடித்த செயல்பாட்டின்போது வெப்பம் உயரும் அளவு

- **F1 மதிப்பிடல்**: துல்லியம் மற்றும் மறுபரிசீலனையின் சமநிலை
- **குறுந்தொகை தாக்கம்**: முழுமையான துல்லியத்திலும் குறுந்தொகை மாடலைப் பொருத்தும்போது உள்ள வேறுபாடு

## பயன்பாட்டுப் பற்றிய முறைமைகள் மற்றும் சிறந்த நடைமுறைகள்

### நிறுவனம் பயன்பாட்டு காட்சியங்கள்

- **கன்டெய்னரைசேஷன்**: தொடர்ச்சியான பயன்பாட்டிற்கு Docker போன்ற முறைகளை பயன்படுத்துதல்
- **கூட்டம் மேலாண்மை**: சாதன மேலாண்மை க்கு Azure IoT Edge போன்ற தீர்வுகளைப் பயன்படுத்துதல்
- **கண்காணித்தல்**: தொலைதரவு தரவு சேகரிப்பு மற்றும் செயல்திறன் கண்காணிப்பு
- **புதுப்பிப்பு மேலாண்மை**: மாடல் மற்றும் மென்பொருள் மேம்படுத்த சக்தியான OTA புதுப்பிப்பு முறைகள்

### கலப்பு மேகம்-எஜ் மாதிரிகள்


- **மேகம் பயிற்சி, என்‌ஜ் கருத்துஅறிவு**: மேகத்தில் பயிற்சி, என்‌ஜுக்கு பிரியோகிக்கவும்
- **என்‌ஜ் முன்னெச்சரிக்கை, மேகம் பகுப்பாய்வு**: என்‌ஜில் அடிப்படைக் கையாளுதல், மேகத்தில் מורிகுசார்ந்த பகுப்பாய்வு
- **ஃபெடரேட்டட் கற்றல்**: தரவை மையப்படுத்தாமலே பகிரப்பட்ட மாடல் மேம்பாடு
- **தொடர் கற்றல்**: என்‌ஜ் தரவுகளிலிருந்து தொடர்ச்சியான மாடல் மேம்பாடு

### ஒருங்கிணைப்பு முறைகள்

- **சென்சார் ஒருங்கிணைப்பு**: கேமராக்கள், மைக்ரோபோன்கள் மற்றும் பிற சென்சார்கள் நேரடியாக இணைப்பு
- **அசச்சுவேட்டர் கட்டுப்பாடு**: மோட்டார்கள், அலைவரிகள் மற்றும் பிற வெளியீடுகளின் நேரடி கட்டுப்பாடு
- **சிஸ்டம் ஒருங்கிணைப்பு**: உள்ளமைந்த நிறுவன சிஸ்டங்களுடன் தொடர்பு
- **ஐஓடி ஒருங்கிணைப்பு**: விரிவான ஐஓடி சூழல்களுடன் இணைப்பு

## தொழில்-சூழல் பிரத்தியேக பருவச்செயல்கள்

### சுகாதாரம்

- **நோயாளி தனியுரிமை**: மருத்துவத் தரவிற்கான ஹிபாஅ கையேடு ஒட்டுமொத்த இணக்கம்
- **மருத்துவ சாதனங்கள் ஒழுங்குமுறை**: FDA மற்றும் பிற ஒழுங்கு நிபந்தனைகள்
- **நம்பகத்தன்மை தேவைகள்**: முக்கிய பயன்பாடுகளுக்கான தவறில்லாதத் தாங்குமுறை
- **ஒருங்கிணைப்பு தரநிலைகள்**: FHIR, HL7 மற்றும் பிற சுகாதார இடைநிலை தரநிலைகள்

### உற்பத்தி

- **தொழிற்துறை சூழல்**: கடுமையான சூழலுக்கான பலப்படுத்தல்
- **நேரடி தேவைகள்**: கட்டுப்பாட்டு அமைப்புகளுக்கான தீர்மானிக்கப்பட்ட செயல்திறன்
- **பாதுகாப்பு அமைப்புகள்**: தொழிற்துறை பாதுகாப்பு நடைமுறைகளுடன் ஒருங்கிணைப்பு
- **பழைய அமைப்பு ஒருங்கிணைப்பு**: உள்ளமைந்த OT அடித்தளத்துடன் இணைப்பு

### வாகனத் துறை

- **செயல்பாட்டுப் பாதுகாப்பு**: ISO 26262 இணக்கம்
- **சூழல் பலப்படுத்தல்**: வெப்பநிலை வேறுபாடுகளில் செயல்பாடு
- **மின்சாரம் நிர்வாகம்**: பேட்டரி திறம்பட செயல்பாடு
- **வாழ்க்கைசுற்று நிர்வாகம்**: வாகன வாழ்க்கைப்பாட்டிற்கு நீண்டகால ஆதரவு

### புத்திசாலி நகரங்கள்

- **வெளிப்புற பிரியோகம்**: வானிலை எதிர்ப்பும் உடல் பாதுகாப்பும்
- **அளவுகள் நிர்வாகம்**: ஆயிரக்கணக்கான முதல் கோடி பரவலான சாதனங்கள்
- **இணைய மாறுபாடு**: கருத்து தளர்ச்சி கொண்ட இணைப்புடன் செயல்பாடு
- **தனியுரிமை பரிந்துரைகள்**: பொதுவான இடத் தரவுகளின் பொறுப்பான கையாள்தல்

## என்‌ஜ் ஏஐ ஹார்ட்வேர் பான்மைகள் எதிர்காலம்

### எழுச்சி காண்கிற ஹார்ட்வேர் முன்னேற்றங்கள்

- **ஏஐ-சாதக சிலிகான்**: கூடுதலாக நிபுணத்துவம் பெற்ற NPUs மற்றும் ஏஐ விரைவூட்டி
- **நியூரோமார்பிக் கணினி**: மேம்பட்ட திறமைக்கான மூளையை மாதிரிப்படுத்திய கட்டமைப்புகள்
- **இன்-மெமரி கணினி**: ஏஐ செயல்பாடுகளுக்கான தரவு இயக்கம் குறைப்பு
- **பன்மை-டை பேக்கேஜிங்**: நிபுணத்துவம் பெற்ற ஏஐ செயலி கூட்டமைப்பு ஒருங்கிணைப்பு

### மென்பொருள் மற்றும் ஹார்ட்வேர் இணைந்த வளர்ச்சி

- **ஹார்ட்வேர்-அறிந்து நெர்வல் கட்டமைப்பு தேடல்**: குறிப்பிட்ட ஹார்ட்வேர் பொருத்தப்பட்ட மாடல்கள்
- **கம்பைலர் முன்னேற்றங்கள்**: மாடல்களின் ஹார்ட்வேர் அறிவுறுத்தல்களுக்கு மேம்பட்ட மொழிபெயர்ப்பு
- **நிபுணத்துவமான கிராப் மேம்பாடுகள்**: ஹார்ட்வேர்-சாதக நெட்வொர்க் மாற்றங்கள்
- **இயங்குதிறன் ஏற்றுமதி**: செயல்பாட்டு நேர விருத்தி கிடைக்கும் வளங்களின் அடிப்படையில்

### தரநிலை முயற்சிகள்

- **ONNX மற்றும் ONNX காப்பகம்**: பன்மைத் தள மாடல் இடைமுகம்
- **MLIR**: பல நிலை இடைநிலை நிரூபணம் மெஷின் கற்க
- **OpenXLA**: வேகமான அளவியல் கணித தொகுப்பு
- **TMUL**: டென்சர் செயலி ஊடுருவல் தனிப்பட்ட படிகள்

## என்‌ஜ் ஏஐ பிரியோகக் குறித்த தொடக்கம்

### வளர்ச்சி சூழல் அமைப்பு

1. **இயங்குதளம் தேர்ந்தெடு**: உங்கள் பயன்பாட்டிற்கு ஏற்ற தளம் தேர்வு செய்க
2. **SDKகள் மற்றும் கருவிகள் நிறுவுக**: உற்பத்தியாளரின் வளர்ச்சி தொகுப்பைப் பதிக்கவும்
3. **மேம்படுத்தல் கருவிகள் அமைக்கவும்**: அளவைக்குறைக்கும் மற்றும் தொகுப்புசெய்யும் மென்பொருள் நிறுவுக
4. **CI/CD குழாயை அமைக்கவும்**: தானியங்கி சோதனை மற்றும் பிரியோகம் செயல்முறை அமைக்கவும்

### பிரியோகம் சரிபார்ப்பு பட்டியல்

- **மாடல் மேம்பாடு**: அளவைக்குறைப்பு, பிருனிங் மற்றும் கட்டமைப்பு மேம்பாடு
- **செயல்திறன் சோதனை**: நோக்கிய சூழலில் இலக்கு இயங்குதளத்தில் மதிப்பீடு செய்க
- **மின்சாரம் பகுப்பாய்வு**: ஆற்றல் நுகர்வு மாதிரிகளை அளவிடுக
- **பாதுகாப்பு ஆய்வு**: தரவு பாதுகாப்பு மற்றும் அணுகல் கட்டுப்பாடுகளை சோதிக்கவும்
- **புதுப்பிப்பு கருவி**: பாதுகாப்பான புதுப்பிப்பு திறன்களை செயல்படுத்தவும்
- **கண்காணிப்பு அமைப்பு**: தொலைபார்பு சேகரிப்பு மற்றும் எச்சரிக்கை அமைக்கவும்
