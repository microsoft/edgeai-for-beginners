# பகுதி 2: உள்ளூர் சுற்றுச்சூழல் பரவல் - தனியுரிமை முதன்மையான தீர்வுகள்

சிறப்பு மொழி மாதிரிகள் (SLMs) உள்ளூர் பரவல் தனியுரிமை பாதுகாக்கும், செலவு குறைத்த எஐ தீர்வுகளுக்கான ஒரு புரட்சியாகும். இந்த விரிவான வழிகாட்டி, Ollama மற்றும் Microsoft Foundry Local என்ற இரண்டு சக்திவாய்ந்த கட்டமைப்புக்களை ஆராய்கிறது, அவை டெவலப்பர்களுக்கு SLMகளின் முழு திறனையும் பயன்படுத்தி, அவர்களின் பரவல் சூழல் முழுமையாக கட்டுப்பாட்டில் வைக்கும் வசதியை வழங்குகிறது.

## அறிமுகம்

இக்கற்கையில், உள்ளூர் சூழல்களில் சிறப்பு மொழி மாதிரிகளுக்கான மேம்பட்ட பரவல் திட்டங்களை ஆராய்வோம். உள்ளூர் எஐ பரவல் அடிப்படைக் கருத்துக்களை எடுத்துக்காட்டி, முன்னணி இரண்டு தளங்களை (Ollama மற்றும் Microsoft Foundry Local) பரிசீலித்து, தயாரிப்பு-தயாராகத் தயாரித்த தீர்வுகளுக்கான நடைமுறை அமலாக்க வழிகாட்டுதலை வழங்குவோம்.

## கற்றல் நோக்கங்கள்

இக்கற்கையின் முடிவில், நீங்கள் முடியும்:

- உள்ளூர் SLM பரவல் கட்டமைப்புகளின் வடிவமைப்பு மற்றும் பயன்களைப் புரிந்துகொள்ள
- Ollama மற்றும் Microsoft Foundry Local பயன்படுத்தி தயாரிப்பு-தயாராக பரவலை அமல்படுத்த
- குறிப்பிட்ட தேவைகள் மற்றும் கட்டுப்பாடுகளைக் கொண்டு பொருத்தமான தளத்தை தேர்வு மற்றும் ஒப்பிட்டு
- உள்ளூர் பரவலை செயல்திறன், பாதுகாப்பு மற்றும் அளவீட்டுத்திறனுக்குத் தக்கப்படுத்த

## உள்ளூர் SLM பரவல் கட்டமைப்புகளை புரிந்துகொள்ளல்

உள்ளூர் SLM பரவல் என்பது மேக சார்ந்த எஐ சேவைகளிலிருந்து, நிறுவனஉள்ளேயான, தனியுரிமை பாதுகாக்கும் தீர்வுகளுக்கான ஒரு அடிப்படைக் மாற்றத்தைச் சொல்கிறது. இதன் மூலம் நிறுவனங்கள் தங்களுடைய எஐ அடித்தளத்தை முழுமையாக கட்டுப்படுத்தி, தரவுச் சொந்தக்காரத்தன்மை மற்றும் செயல்பாட்டு சுயாதீனத்தை உறுதிசெய்ய முடியும்.

### பரவல் கட்டமைப்பு வகைப்படுத்தல்கள்

வெவ்வேறு பரவல் அணுகுமுறைகளை புரிந்துகொள்வது குறிப்பிட்ட பயன்பாடுகளுக்கான சரியான திட்டத்தைத் தேர்வு செய்ய உதவுகிறது:

- **முடிவு-கவனிக்கப்பட்டது**: அனாயாசமான அமைப்பு, சோதனை மற்றும் மாதிரிபணிக்க இதற்கானது
- **நிறுவன தரம்**: தயாரிப்பு-தயாரான தீர்வுகள் மற்றும் நிறுவன ஒருங்கிணைப்பு திறன்கள்
- **குரூஸ்-தள அமைப்பு**: வெவ்வேறு இயக்க முறைமைகளிலும் கடினத்தில் ஒரேபோல் பணியாற்றுதல்

### உள்ளூர் SLM பரவலின் முக்கிய நன்மைகள்

உள்ளூர் SLM பரவும் பல அடிப்படையான நன்மைகள் ஓரு நிறுவன மற்றும் தனியுரிமை-முகம்மையான பயன்பாடுகளுக்கு சிறந்தது ஆகிறது:

**தனியுரிமை மற்றும் பாதுகாப்பு**: உள்ளூர் செயலாக்கம் நிறுவனத்தின் இன்ஃபிராஸ்ட்ரக்சர் உரிமையில் நுண்ணறிந்த தரவின் ஓய்வின்றி வெளியே செல்லாமல் இருப்பதை உறுதி செய்கிறது, GDPR, HIPAA மற்றும் பிற விதிகளுடன் ஏற்படுவதை உறுதி செய்கிறது. வகைப்படுத்தப்பட்ட சூழல்களுக்கு ஏர்-கேப்ப்டு பரவல்கள் இயலும், முழுமையான ஆய்வு தடங்களும் பாதுகாப்பை பராமரிக்கின்றன.

**செலவு திறன்**: ஒவ்வொரு டோக்கனுக்கான விலைமைக்கு இடைநீக்கம் செயல்பாட்டு செலவுகளை கணிசமாகக் குறைக்கிறது. குறைந்த பாண்ட் வீதம் தேவை மற்றும் மேக சார்பற்ற தன்மையால் நிறுவன பட்ஜெட் திட்டங்களுக்கு கணிப்பிடக்கூடிய செலவு அமைப்புகள் கிடைக்கின்றன.

**செயல்திறன் மற்றும் நம்பகத்தன்மை**: வேகமான ஊகிப்போகும் நேரங்கள் பிரிண்டு தாமதமின்றி நேரடி பயன்பாடுகளுக்கு உதவுகின்றன. இணையதள இணைப்பினால் பாதிக்கப்படாமல் தொடர்ந்து இயங்கும் இயல்பு கொண்டுள்ளது, உள்ளூர் வள உத்தமாதிகරණம் மூலம் ஒரடிச் செயல்திறன் வழங்கப்படுகிறது.

### டெவலப்பர் ஒருங்கிணைப்பு உதாரணங்கள்

**Python API ஒருங்கிணைப்பு**:

```python
import requests
import json

# API முடிவுக்குள் அமைப்பு
OLLAMA_ENDPOINT = "http://localhost:11434/api/generate"

# மாடல் அளவுருக்கள்
params = {
    "model": "phi4:mini",
    "prompt": "Write a function to calculate the Fibonacci sequence in Python",
    "system": "You are a helpful Python programming assistant. Provide clean, efficient code with comments.",
    "stream": False,
    "options": {
        "temperature": 0.2,
        "top_p": 0.95,
        "num_predict": 1024
    }
}

# API கோரிக்கை செய்
response = requests.post(OLLAMA_ENDPOINT, json=params)
result = response.json()

# பதிலை செயல்படுத்து மற்றும் காட்டு
print(result["response"])

# ஒளிபரப்பு எடுத்துக்காட்டு (உடனடி பதில்களுக்கு)
def stream_response():
    params["stream"] = True
    response = requests.post(OLLAMA_ENDPOINT, json=params, stream=True)
    
    for line in response.iter_lines():
        if line:
            chunk = json.loads(line)
            if "response" in chunk:
                print(chunk["response"], end="", flush=True)
            if chunk.get("done", False):
                print()
                break

# stream_response()  # ஒளிபரப்பு எடுத்துக்காட்டை இயக்க மறுகோப்பை நீக்கு
```

        top_p: 0.9,
        num_predict: 1024
      }
    });
    
    return response.data.response;
  } catch (error) {

  }
}

## Microsoft Foundry Local: நிறுவன இறுக்கு AI தளம்

### நிறுவன தர கட்டமைப்பு

Microsoft Foundry Local என்பது Microsoft சூழலுடன் ஆழமாக ஒருங்கிணைக்கும் நிறுவன இறுக்க AI தயாரிப்பு பரவலுக்கான முழுமையான தீர்வாகும்.

**ONNX அடிப்படையிலான அமைப்பு**: தொழில் முறை ONNX Runtime இல் கட்டமைக்கப்பட்ட Foundry Local பல்வேறு ஹார்ட்வேர் கட்டமைப்புகளில் சிறந்த செயல்திறன் வழங்குகிறது. விண்டோஸ் ML ஒருங்கிணைப்பு மூலம் இயல்பான விண்டோஸ் மேம்படுத்தலை வழங்குகிறது மற்றும் குரூஸ்-தள பொருந்துதலும் கண்காணிக்கிறது.

**ஹார்ட்வேர் விரைவு சிறந்த நிலை**: CPUs, GPUs மற்றும் NPUs இல் நுண்ணறிந்த வலுவான கண்டறிதல் மற்றும் மேம்படுத்தலை Foundry Local வழங்குகிறது. ஹார்ட்வேர் வணிகர்களிடம் (AMD, Intel, NVIDIA, Qualcomm) ஆழ்ந்த ஒத்துழைப்பு நிறுவன உபகரணங்களில் சிறந்த செயல்திறனை உறுதிசெய்கிறது.

### மேம்பட்ட டெவலப்பர் அனுபவம்

**பல இடைமுக அணுகல்**: Foundry Local மாதிரி மேலாண்மை மற்றும் பரவல் ஊக்கத்திற்கான சக்திவாய்ந்த CLI, பன்மொழி SDKகள் (Python, NodeJS) இயல்பான ஒருங்கிணைப்பு, மற்றும் OpenAI பொருந்தும் RESTful APIகளை வழங்குகிறது.

### நிறுவன பாதுகாப்பு செயல்பாடு

**Ollama பாதுகாப்பு சிறந்த நடைமுறைகள்**:
- பிணைய தனிமைபாடு தீக்காப்பு விதிகள் மற்றும் VPN அணுகலுடன்
- எதிர்மறை பிரதிநிதி ஒருங்கிணைப்பினை கொண்டு அங்கீகாரம்
- மாதிரி கூர்மைகூறும் சரிபார்ப்பு மற்றும் பாதுகாப்பான பகிர்வு
- API அணுகல் மற்றும் மாதிரி செயல்பாடுகளுக்கான ஆய்வு பதிவு

**Foundry Local நிறுவன பாதுகாப்பு**:
- செயற்கூறு அடிப்படையிலான அணுகல் கட்டுப்பாடு மற்றும் Active Directory ஒருங்கிணைவு
- முழுமையான ஆய்வு தடங்கள் மற்றும் கட்டுரைப்படுத்தல் அறிக்கை
- குறியாக்கப்பட்ட மாதிரி சேமிப்பு மற்றும் பாதுகாப்பான பரவல்
- Microsoft பாதுகாப்பு அடித்தளம் ஒருங்கிணைவு

### விதிமுறைகள் மற்றும் ஒழுங்குமுறை தேவைகள்

- கட்டுரைப்படுத்தல் அறிக்கைக்கான ஆய்வு பதிவு
- நுண்ணறிந்த தரவு கையாள்வதற்கான அணுகல் கட்டுப்பாடுகள்
- தரவு பாதுகாப்புக்கான ஓய்விலும் பயணத்திலும் குறியாக்கம்

## எதிர்கால ரुझான்கள் மற்றும் கருத்துக்கள்

### வளர்ந்து வரும் தொழில்நுட்பங்கள்

உள்ளூர் SLM பரவல் சூழல் மற்றும் பல முக்கிய ரुझான்களை தொடர்ந்து மேம்படுகிறது:

**மேம்பட்ட மாதிரி கட்டமைப்புகள்**: மேம்பட்ட செயல்திறன் மற்றும் திறன் விகிதங்கள் கொண்ட அடுத்த தலைமுறை SLMகள் உருவாகின்றன, இதில் மிஷ்சர்-ஆஃப்-எக்ஸ்பெர்ட்ஸ் மாதிரிகள் மற்றும் சிறப்பு கட்டமைப்புகள் உள்ளன.

**ஹார்ட்வேர் ஒருங்கிணைவு**: NPUகள், தனிப்பயன் சிலிகான் மற்றும் இறுக்கு கணினி விரைவு கருவிகளுடன் ஆழ்ந்த ஒருங்கிணைவு செயல்பாடுகளை மேம்படுத்தும்.

**சுற்றுச்சூழல் பரிணாமம்**: பரவல் தளங்களில் நிலையான முயற்சிகள் மற்றும் வித்தியாச கட்டமைப்புக்களின் மேம்பட்ட ஒருங்கிணைவு பல தள பரவலை எளிமையாக்கும்.

### தொழில்நுட்ப ஒத்துழைவு முனைப்புகள்

**நிறுவன ஒத்துழைவு**: தனியுரிமை தேவைகள், செலவு திறன், மற்றும் விதிமுறை பின்பற்றுதல் காரணமாக நிறுவன ஒத்துழைவு அதிகரித்துள்ளது. அரசு மற்றும் பாதுகாப்பு துறைகள் குறிப்பாக ஏர்-கேப்ப்டு பரவலை முன்வைக்கின்றன.

**சர்வதேச கருத்துக்கள்**: கடுமையான தரவு பாதுகாப்பு விதிகள் உள்ள பகுதிகளுக்கு உள்ளூர் பரவல் ஏற்றுக்கொள்ளப்படுகிறதே அதிகரிக்கிறது.

## சவால்கள் மற்றும் கருத்துக்கள்

### தொழில்நுட்ப சவால்கள்

**அடித்தள தேவைகள்**: உள்ளூர் பரவல் கவனமாக திறன் திட்டமிடல் மற்றும் ஹார்ட்வேர் தேர்வை கேட்கிறது. வளர்ந்து வரும் பணிச்சுமைகளுக்கு அளவீடு மற்றும் செலவு கட்டுப்பாடுகளை சமன்வயப்படுத்தத் தேவை.

**🔧 பராமரிப்பு மற்றும் புதுப்பிப்புகள்**: மாதிரி புதுப்பிப்புகள், பாதுகாப்பு திருத்தங்கள், மற்றும் செயல்திறன் மேம்பாடுகள் தனிமூல வளங்கள் மற்றும் கிறுக்கல் திறன் தேவைக்கிறது. தயாரிப்பு சூழலுக்கு தானியங்கி பரவல் குழாய்கள் அவசியம்.

### பாதுகாப்பு கருத்துக்கள்

**மாதிரி பாதுகாப்பு**: அனுமதி இல்லாத அணுகல் அல்லது மாதிரி திருட்டை தடுக்கும் முழுமையான பாதுகாப்பு நடவடிக்கைகள் குறியாக்கம், அணுகல் கட்டுப்பாடுகள் மற்றும் ஆய்வு பதிவுகளை உள்ளடக்கியவை அவசியம்.

**தரவு பாதுகாப்பு**: ஊகிப்பு குழாயில் முழு பாதுகாப்பான தரவு கையாளல் பண்புகளை உறுதி செய்தல், செயல்திறனையும் பயன்படுத்தும்அளவையும் பராமரித்தல்.

## முடிவுரை

Ollama மற்றும் Microsoft Foundry Local இடையே தேர்வு நிறுவனர் தேவைகள், தொழில்நுட்ப கட்டுப்பாடுகள் மற்றும் நேர்த்தி நோக்கங்களைக் கொண்டுள்ளது. இரண்டு தளங்களும் உள்ளூர் SLM பரவலுக்கு விரிவான நன்மைகளை வழங்குகின்றன, Ollama குரூஸ்-தள பொருந்துதலிலும் எளிதான பயன்பாடிலும் சிறந்து விளங்குகிறது; Foundry Local நிறுவன தர மேம்பாடுகளும் Microsoft சூழல் ஒருங்கிணைவுப் பணிகளும் உண்டு.

எஐ பரவலின் எதிர்காலம் உள்ளூர் செயலாக்க நன்மைகளை மேக அளவிட திறனுடன் இணைக்கும் கலவையான முறைகளில் உள்ளது. உள்ளூர் SLM பரவலைத் திறம்பட கையாளும் நிறுவனங்கள் தங்களுடைய தரவு மற்றும் அடித்தளத்தில் முழு கட்டுப்பாடு கொண்டு AI தொழில்நுட்பங்களை பயன்படுத்த சிறந்த நிலைப்பாட்டில் நிற்கும்.

உள்ளூர் SLM பரவலில் வெற்றி பெற தொழில்நுட்ப தேவைகள், பாதுகாப்பு விளைவுகள் மற்றும் செயல்பாட்டு நடைமுறைகள் குறித்து கவனமாக பரிசீலனை தேவை. சிறந்த நடைமுறைகளை பின்பற்றி மற்றும் இந்தத் தளங்களின் வலிமைகளை பயன்படுத்தி, நிறுவனங்கள் தாங்கள் எதிர்கொள்ளும் தேவைகள் மற்றும் கட்டுப்பாடுகளுக்கு பொருந்தக்கூடிய உறுதியான, அளவீட்டுத் திறனுள்ள மற்றும் பாதுகாப்பான எஐ தீர்வுகளை உருவாக்கலாம்.
