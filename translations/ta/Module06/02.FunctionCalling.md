## செயல்பாட்டைப் பயன்படிக்கல் என்றால் என்ன?

செயல்பாட்டைப் பயன்படிக்கல் என்பது சிறிய மொழி மாதிரிகள் (SLMs) வெளிப்புற கருவிகள், APIகள் மற்றும் சேவைகளுடன் தொடர்பு கொள்ளும் சக்திவாய்ந்த திறனாகும். அடுத்து தங்களது பயிற்சி தரவுகளை மட்டுப்படுத்தாமல், SLMகள் இப்போது முடியும்:

- **வெளிப்புற APIகளுடன் இணைபடு** (வானிலை சேவைகள், தரவுத்தளங்கள், தேடல் இயந்திரங்கள்)
- **பயனரின் கோரிக்கைகள் அடிப்படையில் குறிப்பிட்ட செயல்பாடுகளை இயக்கு**
- **பல்வேறு மூலங்களிலிருந்து நேரடி தகவல்களை மீட்டெடு**
- **திறமையான கருவிகள் மூலம் கணித நடவடிக்கைகளை செய்**
- **பன்முக நிகழ்வுகளை சங்கிலிசெய்** கூடிய குழப்பமான பணிகளுக்காக

இந்த திறன் SLMகளை நிலையான உரை உருவாக்குநர்களாக இருந்து மாற்றி, சாத்தியமான செயல் படைக்கும் செயற்கை நுண்ணறிவு முகவரிகளாக மாற்றுகிறது.

## செயல்பாட்டுப் பயன்படிக்கல் எவ்வாறு இயங்குகிறது

செயல்பாட்டைப் பயன்படிக்கல் செயல்முறை ஒரு முறைமான பணிவழிப்படியாகும்:

### 1. கருவி ஒருங்கிணைப்பு
- **வெளிப்புற கருவிகள்**: SLMகள் வானிலை APIகள், தரவுத்தளங்கள், இணைய சேவைகள் மற்றும் பிற வெளிப்புற அமைப்புகளுடன் இணைக்க முடியும்
- **செயல்பாட்டு வரையறைகள்**: ஒவ்வொரு கருவியும் குறிப்பிட்ட அளவுருக்கள், உள்ளீடு/வெளியீடு வடிவங்கள், விளக்கங்களுடன் வரையறுக்கப்படுகிறது
- **API இணையமை**: கருவிகள் ஒழுங்குபடுத்தப்பட்ட இடைமுகங்கள் (REST APIகள், SDKகள் மற்றும் பிற) மூலம் ஒருங்கிணைக்கப்படுகின்றன

### 2. செயல்பாட்டின் வரையறை
செயல்பாடுகள் மூன்று முக்கிய கூறுகளுடன் வரையறுக்கப்படுகின்றன:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. நோக்க விருப்பம் கண்டறிதல்
- **இசைபொடிக்கும் மொழி செயலாக்கம்**: பயனர் உள்ளீட்டை ஆராய்ந்து நோக்கத்தை புரிந்து கொள்கிறது
- **செயல்பாடு பொருத்தல்**: கோரிக்கைக்கென்று எந்த செயல்பாடு(கள்) தேவை என்பதை நிர்ணயம் செய்கிறது
- **அளவுரு சேகரிப்பு**: பயனரின் செய்தியில் இருந்து தேவையான அளவுருக்களை கண்டறிந்து எடுக்கிறது

### 4. JSON வெளியீடு உருவாக்கம்
SLM கட்டமைக்கப்பட்ட JSON உருவாக்குகிறது, அதில்:
- அழைக்க வேண்டிய செயல்பாட்டின் பெயர்
- தேவையான அளவுருக்கள் சரியான மதிப்புகளுடன்
- செயலாக்க சூழல் மற்றும் தரவுக்குறிப்புகள்

### 5. வெளிப்புற செயலாக்கம்
- **அளவுரு சரிபார்ப்பு**: தேவையான அனைத்து அளவுருக்களும் உள்ளனவா மற்றும் சரியாக வடிவமைக்கப்பட்டுள்ளனவா என உறுதிசெய்கிறது
- **செயல்பாடு நடைமுறைப்படுத்தல்**: கொடுக்கப்பட்ட அளவுருக்களுடன் குறிப்பிட்ட செயல்பாட்டை செயல்படுத்துகிறது
- **பிழை கையாளல்**: தோல்விகள், நேரம் முடிவுகள், மற்றும் தவறான பதில்களை நிர்வகிக்கிறது

### 6. பதில் ஒருங்கிணைப்பு
- **결과 செயலாக்கம்**: செயல்பாட்டு வெளியீடு SLMக்கு திரும்ப வழங்கப்படுகிறது
- **சூழல் ஒருங்கிணைப்பு**: SLM அதன் பதிலில் பெறப்பட்ட முடிவுகளை ஒன்று செய்கிறது
- **பயனர் தொடர்பு**: தகவலை இயல்பான, உரையாடல் வடிவில் வழங்குகிறது

## விண்ணப்ப ச் சாவல்கள்

### தரவு மீட்டெடுப்பு
இயல்பான மொழி கேள்விகளை கட்டமைக்கப்பட்ட API அழைப்புகளாக மாற்றுதல்:
- **"என் சமீபத்திய ஆர்டர்கள் காட்டவும்"** → பயனர் ஐடி மற்றும் தேதிக்கான வடிகட்டிகளுடன் தரவுத்தளக் கேள்வி
- **"டோக்கியோவில் வானிலை என்ன?"** → வானிலை API அழைப்புடன் இடம் அளவுரு
- **"கடந்த வாரம் ஜோனிடமிருந்து மின்னஞ்சல்கள் கண்டுபிடி"** → அனுப்புநர் மற்றும் தேதி வடிகட்டிகளுடன் மின்னஞ்சல் சேவைக் கேள்வி

### செயல்பாட்டு நடைமுறை
பயனர் கோரிக்கைகளை குறிப்பிட்ட செயல்பாட்டு அழைப்புகளாக மாற்றுதல்:
- **"நாளை மாலை 2 மணிக்கு கூட்டத்தை திட்டமிடுக"** → காலண்டர் API ஒருங்கிணைப்பு
- **"அணி உறுப்பினருக்கு செய்தி அனுப்பு"** → தொடர்பு தளம் API
- **"என் கோப்புகளின் காப்புப்பிரதி உருவாக்கு"** → கோப்பு அமைப்பு செயல்பாடு

### கணித பணிகள்
சிக்கலான கணித அல்லது தர்க்க நடவடிக்கைகளை நிர்வகிக்க:
- **"$10,000 மீது 5% கண்சேர்க்கை வட்டி 10 வருடத்திற்கு கணக்கிடு"** → நிதி கணக்கீட்டு செயல்பாடு
- **"இந்த தரவு தொகுப்பை போக்குகளைப் பற்றி பகுப்பாய்வு செய்"** → புள்ளியியல் ஆய்வு கருவிகள்
- **"விதைகள் விரிவாக்கம் செய்து உத்தரவாதமாய் மாற்று"** → மார்க்கெட் மேம்படுத்தல் ஆல்கோரிதம்கள்

### தரவு செயலாக்க பணிவழிகள்
குழப்பமான நடவடிக்கைகள் க்கான பல செயல்பாட்டைப் பயன்படிக்கல் சங்கிலி:
1. **பல்வேறு மூலங்களிலிருந்து தரவுகளை மீட்டு**
2. **தகவலை பாகுபடுத்தி சரிபார்க்கவும்**
3. **தரவை தேவையான வடிவிற்கு மாற்று**
4. **முடிவுகளை தொடர்புடைய அமைப்புகளில் சேமி**
5. **அறிக்கைகள் அல்லது காட்சிப்படுத்தல்களை உருவாக்கு**

### UI/UX ஒருங்கிணைப்பு
இயக்கமுள்ள பயன்பாட்டு இடைமுக மேம்பாடுகளை செயல் படுத்து:
- **"டேஷ்போர்டில் விற்பனை தரவை காட்டவும்"** → படிவாக்கம் மற்றும் காட்சி
- **"புதிய இடங்கள் கொண்ட வரைபடத்தை புதுப்பி"** → நிலத்தரவு தரவு ஒருங்கிணைப்பு
- **"சரக்குத் தொகுப்பை புதுப்பி"** → நேரடி தரவு ஒத்திசைவு

## Phi-4-mini மற்றும் Ollama உடன் செயல்பாட்டைப் பயன்படிக்கல் அமைத்தல்

### முந்தைய தேவைகள்
- Ollama பதிப்பு 0.5.13 அல்லது அதற்கு மேல்
- Phi-4-mini மாதிரி (பிரிந்த பரிந்துரை: `phi4-mini:3.8b-fp16`)

### நிறுவுதல் படிகள்

```bash
ollama run phi4-mini:3.8b-fp16
```


### தனிப்பட்ட செயல்பாட்டுப் பயன்படிக்கல்

Qwen3 க்கான தனிப்பட்ட செயல்பாடுகளை நீங்கள் வரையறுக்கலாம்:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # வானிலை API அழைப்பை சிமுலேட் செய்யவும்
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# விருப்பமான கருவியை பயன்படுத்தவும்
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

### பொதுவான சிக்கல்கள் மற்றும் தீர்வுகள்

#### சிக்கல் 1: செயல்பாடு அழைக்கப்படவில்லை
**அறிகுறிகள்**: மாதிரி உரையாடல் பதிலிடுகிறது, செயல்பாடு அழைக்காமல்

**தீர்வுகள்**:
1. **செயல்பாட்டு விளக்கத்தை சரிபார்**: அது பயனர் நோக்கத்துடன் தெளிவாக பொருந்துகிறது என்பதை உறுதி செய்
2. **அளவுரு வரையறைகளை சரி பார்த்து**: தேவையான அனைத்து அளவுருக்களும் சரியாக வரையறுக்கப்பட்டுள்ளனவா என பார்க்க
3. **கணினி வாய்ப்புரை பரிசீலனை**: எப்போது செயல்பாடுகளைப் பயன்படுத்த வேண்டும் என்று தெளிவான வழிமுறைகளைச் சேர்க்கவும்
4. **தெளிவான கோரிக்கையுடன் சோதிக்கவும்**: உதாரணம் "லண்டனுக்கான வானிலை செயல்பாட்டைப் பயன்படுத்தவும்"

#### சிக்கல் 2: தவறான அளவுருக்கள்
**அறிகுறிகள்**: செயல்பாடு தவறான அல்லது பூரணமான அல்லாத அளவுருக்களுடன் அழைக்கப்பட்டது

**தீர்வுகள்**:

```python
import asyncio
import aiohttp

async def batch_function_calls(function_calls):
    """Execute multiple function calls concurrently"""
    async with aiohttp.ClientSession() as session:
        tasks = []
        for call in function_calls:
            if call["name"] == "fetch_url":
                task = fetch_url_async(session, call["parameters"]["url"])
                tasks.append(task)
        
        results = await asyncio.gather(*tasks)
        return results

async def fetch_url_async(session, url):
    async with session.get(url) as response:
        return await response.text()
```

```python
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # வெற்றிகரமான செயல்பாட்டை பதிவு செய்க
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # தோல்வியடைந்த செயல்பாட்டை பதிவு செய்க
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # ஒரு நிமிடம் கடந்தால் கவுண்டரை மீட்டமைக்கவும்
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # வரம்புக்குள்ளேயா என்பதை சோதிக்கவும்
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # தேவைப்படும் அளவுருக்களை சரிபார்க்கவும்
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # அளவுரு வகைகள் மற்றும் கட்டுப்பாடுகளைச் சரிபார்க்கவும்
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # வகை சரிபார்ப்பு
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # எணும் சரிபார்ப்பு
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
        
        return FunctionResult(success=True)
    
    def _log_function_call(self, function_name: str, parameters: Dict, result: FunctionResult):
        """Log function call for audit purposes"""
        log_entry = {
            'timestamp': result.timestamp.isoformat(),
            'function_name': function_name,

            'success': result.success,

    def get_function_definitions(self) -> List[Dict]:
        """Get OpenAI-compatible function definitions for all registered functions"""
        definitions = []

            definition = {
                'name': func_name,
                'description': func_info['description'],
                'parameters': {
                    'type': 'object',
                    'properties': {},
                    'required': []
                }
            }
            
            for param_name, param_info in func_info['parameters'].items():
                definition['parameters']['properties'][param_name] = {
                    'type': param_info['type'],
                    'description': param_info.get('description', '')
                }

                if 'default' in param_info:

                if param_info.get('required', False):
                    definition['parameters']['required'].append(param_name)
            
            definitions.append(definition)
        
        return definitions
```

சிறிய மொழி மாதிரிகளில் செயல்பாட்டைப் பயன்படிக்கல் நிலையான AI உதவியாளர்களிலிருந்து இயல் கொண்ட, உண்மையான உலக பணிகளைச் செய்யக்கூடிய முகவரிகளாக மாற்றுவதாகும். இந்த பாடத்தில்:

### முக்கியமான எடுத்துக்காட்டுகள்

1. **அடித்தளம் புரிதல்**: செயல்பாட்டுப் பயன்படிக்கல் SLMகளை வெளியுற கருவிகள் மற்றும் சேவைகளுடன் இணைந்து பயிற்சி தரவுகளுக்கு அப்பால் செல்ல வைக்கிறது.

2. **நடைமுறை சுதந்திரம்**: தனிப்பயன் வார்ப்புருக்கள் வரை முதல் Qwen-Agent மற்றும் Foundry Local போன்ற உயர்நிலை கட்டமைப்புகள் வரை பல முறைமைகள் உள்ளன.

3. **உற்பத்தி கருத்துக்கள்**: நிறுவன செயல்பாடுகளுக்கு பிழை கையாளல், விகிதக் கட்டுப்பாடு, பாதுகாப்பு மற்றும் மேற்கோள் பதிவை கவனிக்க வேண்டும்.

4. **செயல்திறன் மேம்பாடு**: சரியான செயல்பாடு வடிவமைப்பு, திறமையான இயக்கம் மற்றும் புத்திசாலித்தனமான சேமிப்பு பதிலின் நேரத்தை சிறப்பாக மேம்படுத்த முடியும்.

### எதிர்கால திசைகள்

SLM தொழில்நுட்பம் வளர்ச்சியடையும் போது எதிர்பார்க்கலாம்:

- **செயல்பாட்டுப் பயன்பாட்டுக் கண்ணோட்டம் மேம்பாடு**: சிறந்த நோக்கு கண்டறிதல் மற்றும் அளவுரு சேகரிப்பு
- **மேம்பட்ட இணை செயலாக்கம்**: கலைத்தன்மையுள்ள பன்முக செயல்பாடுகளுக்கு மேம்பட்ட ஒழுங்குபடுத்தல்
- **நன்றாக ஒருங்கிணைப்பு தரநிலைகள்**: கருவி ஒருங்கிணைக்க நிலையான நெறிமுறைகள்
- **மேம்பட்ட பாதுகாப்பு அம்சங்கள்**: மேம்பட்ட அங்கீகாரம் மற்றும் அங்கீகாரம் முறைகள்
- **பரப்பிய சூழல்**: முன்னுரிமை செயல்பாடுகள் மற்றும் ஒருங்கிணைப்புகளின் நூலகம்

### துவக்கம் செய்ய

உங்கள் திட்டங்களில் செயல்பாட்டுப் பயன்படிக்கலை தொடங்க:

1. **எளிமையாக தொடங்கு**: அடிப்படை ஒற்றை செயல்பாடு நிகழ்வுகளுடன் தொடங்கு
2. **உங்கள் கட்டமைப்பைத் தேர்ந்தெடு**: நேரடி நடைமுறை (Ollama/Phi-4) அல்லது கட்டமைப்பு உதவியுடன் (Qwen-Agent) தேர்வு செய்க
3. **கவனமாக செயல்பாடுகளை வடிவமைக்கு**: தெளிவான, அற்புதமான செயல்பாடு வரையறைகளுக்கு உாஜலம் கொடு
4. **பிழை கையாளலை நடைமுறைப்படுத்து**: துவக்கத்தில் வலுவான பிழை கையாளலை உருவாக்கிக் கொள்
5. **நெடியாய் வளர்ச்சியடையவும்**: அனுபவம் பெறும்போது எளிமையிலிருந்து சிக்கலான நிகழ்வுகளுக்கு நகர்க

செயல்பாட்டைப் பயன்படிக்கல் SLMக்களை கவர்ச்சியான உரை உருவாக்குநர்களிலிருந்து நிஜ உலக பிரச்சனைகள் தீர்க்கக்கூடிய நடைமுறை AI முகவரிகளாக மாற்றுகிறது. இந்த பாடத்தில் வழங்கப்பட்ட மாதிரிகள் மற்றும் நடைமுறைகளை பின்பற்றி நீங்கள் பெரிய, நம்பகமான AI அமைப்புகளை உருவாக்க முடியும்.
