# பிரிவு 03 - மாதிரி_CONTEXT_நெறிமுறை (MCP) ஒருங்கிணைப்பு

## MCP (மாதிரியான CONTEXT நெறிமுறை) அறிமுகம்

மாதிரி_CONTEXT_நெறிமுறை (MCP) என்பது வெளிப்படையான வழிகாட்டி சுட்டி ஆகும், அது குறியாக்க ஏஐ பயன்பாடுகளை வெளிப் பக்க அமைப்புகளுடன் இணைக்க உதவுகிறது. MCP யைப் பயன்படுத்தி, Claude அல்லது ChatGPT போன்ற AI பயன்பாடுகள் தரவு மூலங்களுடன் (இடைநிலை கோப்புகள், தரவுத்தளங்கள்), கருவிகள் (தேடல் இயந்திரங்கள், கணக்க calculators), மற்றும் பணிச்செறிவுகளுடன் (சிறப்பு ஊக்கங்கள்) இணைந்து முக்கியத் தகவல்களை அணுகி பணிகளை செய்ய முடியும்.

MCP ஐ AI பயன்பாடுகளுக்கான **USB-C போர்ட்டாக** கருதலாம். USB-C மின் சாதனங்களை இணைக்கும் நிலையான வழியை வழங்குவதில் போலவே, MCP AI பயன்பாடுகளை வெளிப்பக்க அமைப்புகளுடன் இணைக்க நிலையான வழியை உருவாக்குகிறது.

### MCP மூலம் என்ன செய்ய முடியும்?

MCP AI பயன்பாடுகளுக்கு சக்திவாய்ந்த திறன்களை திறக்கிறது:

- **தனிப்பயன் AI உதவியாளர்**: Google காலண்டர் மற்றும் Notion ஐ அணுகி தனிப்பட்ட AI உதவியாளராக செயல்திறன் பெற முடியும்
- **மேம்பட்ட குறியீடு உருவாக்கம்**: Claude Code Figma வடிவமைப்பை பயன்படுத்தி முழு வலை பயன்பாட்டை உருவாக்க முடியும்
- **நிறுவன தரவு ஒருங்கிணைப்பு**: நிறுவனத்தின் பல தரவுத்தளங்களை இணைத்து, ஆதாரமான தரவு பகுப்பாய்வை உரையாடல் மூலம் செய்யும் நிறுவனர் அட்டை (chatbot)
- **புனைவு பணிச்செறிவுகள்**: Blender மூலம் 3D வடிவமைப்புகளை உருவாக்கி 3D பிரிண்டர் மூலம் பிரிண்ட் செய்ய முடியும்
- **உண்மையான நேர தகவல் அணுகல்**: புதுப்பிக்கப்பட்ட தகவல்களுக்கான வெளிப்படுத்தல் தரவு மூலங்களை இணைத்தல்
- **சிக்கலான பல படி செயல்பாடுகள்**: பல கருவிகள் மற்றும் அமைப்புகளை இணையச் செய்து வெகுஜன பணிச்செறிவுகளை செய்தல்

### MCP ஏன் முக்கியம்?

MCP பக்கேந்திர சூழலில் பல நன்மைகள் வழங்குகிறது:

**மேம்படுத்துநர்களுக்கு**: AI பயன்பாடு அல்லது முகவருடன் கட்டும்போது MCP மேம்பாட்டை எளிதாக்கி நேரத்தையும் சிக்கலையும் குறைக்கிறது.

**AI பயன்பாடுகளுக்கு**: MCP தரவு மூலங்கள், கருவிகள் மற்றும் செயலிகள் என்ற சூழலில் அணுகல் வழங்கி திறன்களை மேம்படுத்துகிறது.

**பயன்படுத்துநர்களுக்கு**: MCP மூலம் அதிக திறமையான AI பயன்பாடுகள் அல்லது முகவர்கள் உங்கள் தரவை அணுகி தேவையான வேளைகளில் உங்கள் சார்பாக நடவடிக்கை எடுக்க முடியும்.

## MCP இல் சிறிய மொழி மாதிரிகள் (SLMs)

சிறிய மொழி மாதிரிகள் AI பயன்பாட்டிற்கு திறமையான அணுகுமுறையை வழங்குகின்றன, பல நன்மைகளுடன்:

### SLM க்கு நன்மைகள்
- **வள திறன் செயல்திறன்**: குறைந்த கணினி தேவைகள்
- **வேகமான பதில் நேரம்**: நேரடி பயன்பாடுகளுக்கு குறைந்த தாமதம்  
- **செலவு குறைத்தல்**: குறைந்த அமைப்பு தேவைகள்
- **தனியுரிமை**: தரவு பரிமாற்றமின்றி உள்ளூர் இயங்கல்
- **தனிப்பயன்**: குறிப்பிட்ட துறைகளுக்கு எளிதில் போடல்

### SLM க்கள் MCP உடன் சிறப்பாக வேலை செய்வதற்கான காரணம்

SLM மற்றும் MCP இணைந்து மாதிரியின் காரண விளக்க திறன்களை வெளிப்பாட்டு கருவிகளால் விரிவுபடுத்தி, குறைந்த அளவிலான அளவுரு எண்ணிக்கையை பூர்த்தி செய்கின்றனர்.

## Python MCP SDK கண்ணோட்டம்

Python MCP SDK MCP செயலிகளை கட்டுவதற்கான அடிப்படையை வழங்குகிறது. SDK இல் அடங்கும்:

- **கிளையண்ட் பைபிளியோக்கள்**: MCP சர்வர்களை இணைத்தல்
- **சர்வர் கட்டமைப்பு**: தனிப்பயன் MCP சர்வர்களை உருவாக்குதல்
- **நெறிமுறை மேலாளர்கள்**: தொடர்பு மேலாண்மை
- **கருவி ஒருங்கிணைப்பு**: வெளிப்புற செயல்பாடுகளை இயக்குதல்

## நடைமுறை அமலாக்கம்: Phi-4 MCP கிளையண்ட்

Microsoft இன் Phi-4 சிறிய மாதிரியை MCP திறன்களோடு இணைத்து ஒரு நடைமுறை உதாரணத்தை பார்க்கலாம்.

### MCP கட்டமைப்பு கண்ணோட்டம்

MCP ஒரு **கிளையண்ட்-சர்வர் கட்டமைப்பை** பின்பற்றுகிறது; MCP ஹோஸ்ட் (Claude Code அல்லது Claude Desktop போன்ற AI பயன்பாடு) பல MCP சர்வர்களுடன் இணைகிறது. ஒவ்வொரு MCP சர்வருக்கும் ஒரு கிளையண்ட் உருவாக்குவது மூலம் இது செயற்படுகிறது.

#### முக்கிய பங்காளிகள்

- **MCP ஹோஸ்ட்**: ஒரு அல்லது பல MCP கிளையண்ட்களை ஒருங்கிணைத்து நிர்வகிக்கும் AI பயன்பாடு
- **MCP கிளையண்ட்**: MCP சர்வருடன் இணைப்பை பராமரித்து ஹோஸ்ட் பயன்பாட்டுக்கான CONTEXT ஐ பெறும் கூறு
- **MCP சர்வர்**: MCP கிளையண்ட்களுக்கு CONTEXT வழங்கும் நிரல்

#### இரண்டு அடுக்கு கட்டமைப்பு

MCP இரண்டு தன்மையான அடுக்குகளை கொண்டுள்ளது:

**தரவு அடுக்கு**: கிளையண்ட்-சர்வர் தொடர்புக்கான JSON-RPC அடிப்படையிலான நெறிமுறையை வரையறுக்கிறது, இதில்:
- வாழ்நாள் மேலாண்மை (இணைப்பு துவக்கம், திறன் பேச்சுவார்த்தை)
- முக்கிய அடிப்படைகள் (கருவிகள், வளங்கள், ஊக்கங்கள்)
- கிளையண்ட் அம்சங்கள் (தயாரிப்பு, வெளியேற்றம், பதிவேற்றம்)
- பயனுள்ள அம்சங்கள் (அறிவிப்பு, முன்னேற்ற கண்காணிப்பு)

**கூடுதல் அடுக்கு**: தொடர்பு முறை மற்றும் சேனல்கள் நிர்ணயம்:
- **STDIO பரிமாற்றம்**: உள்ளூர் செயலிகளுக்கு உள்ளீடு/வெளியீடு ஓட்டங்கள் (மிகச்சிறந்த செயல்திறன், கட்டமைப்பு இல்லாமல்)
- **ஓட்டக்குழாய் HTTP பரிமாற்றம்**: HTTP POST மற்றும் விருப்ப Server-Sent Events ஐ பயன்படுத்தி தூர சர்வர்களுடன் (பொதுவான HTTP அங்கீகாரம் ஆதரவு)

```
│  └─────────────────────────────────┘ │
└─────────────────┬───────────────────┘
                  │
┌─────────────────┴───────────────────┐
│         MCP Server 1                │
│    (Local/Remote Context Provider)  │
└─────────────────────────────────────┘
```

### MCP முதன்மை அடிப்படைகள்

MCP AI பயன்பாடுகளுடன் பகிரக்கூடிய CONTEXT தகவல்களின் வகைகள் மற்றும் செய்யக்கூடிய நடவடிக்கைகள் வரையறுக்கப்பட்ட அடிப்படைகளை வகைப்படுத்துகிறது.

#### சர்வர் அடிப்படைகள்

MCP சர்வர்கள் வெளிப்படுத்தக்கூடிய மூன்று முதன்மை அடிப்படைகள் உள்ளன:

**கருவிகள்**: AI பயன்பாடுகள் செயல்படுத்தக்கூடிய செயற்பாடுகள்
- உதாரணம்: கோப்பு செயல்பாடுகள், API அழைப்புகள், தரவுத்தளம் கேள்விகள்
- முறைகள்: `tools/list`, `tools/call`
- இயங்குவதையும் கண்டறிதலையும் ஆதரிக்கிறது

**வளங்கள்**: AI பயன்பாட்டிற்கு CONTEXT தரும் தரவுத்தளங்கள்
- உதாரணம்: கோப்பு உள்ளடக்கம், தரவுத்தளம் பதிவுகள், API பதில்கள்
- முறைகள்: `resources/list`, `resources/read`
- கட்டமைக்கப்பட்ட தரவுகளுக்கு அணுகலை வழங்குகிறது

**ஊக்கங்கள்**: மொழி மாதிரிகளுடன் தொடர்புகளை முன்னேற்ற reusable வார்ப்புருக்கள்
- உதாரணம்: அமைப்பு ஊக்கங்கள், சில எடுத்துக்காட்டுகள்
- முறைகள்: `prompts/list`, `prompts/get`
- AI தொடர்பு முறைமைகளை நிலைநிறுத்துகிறது

#### கிளையண்ட் அடிப்படைகள்

MCP கிளையண்ட்களும் மோசையூட்டும் தொடர்பை முன்னெடுக்கக்கூடிய அடிப்படைகளை வழங்குகிறது:

**தயாரிப்பு**: சர்வர்கள் கிளையண்டின் AI பயன்பாட்டிலிருந்து மொழி மாதிரி முடிவுகளை கோர முடியும்
- முறை: `sampling/complete`
- மாதிரி சாராத சர்வர் மேம்பாட்டை ஆதரிக்கிறது
- ஹோஸ்ட் மொழி மாதிரிக்கு அணுகலை வழங்குகிறது

**தகவல் சேகரிப்பு**: சர்வர்கள் பயனர்களிடமிருந்து கூடுதல் தகவல் கேட்க முடியும்
- முறை: `elicitation/request`
- பயனர் தொடர்பு மற்றும் உறுதிப்படுத்தலை ஆதரிக்கிறது
- நகர்நிலை தகவல் சேகரிப்பை ஆதரிக்கிறது

**பதிவேற்றம்**: சர்வர்கள் கிளையண்ட்களுக்கு பதிவு செய்திகளை அனுப்பும் திறன்
- பிழைத்திருத்தம் மற்றும் கண்காணிக்க பயன்படும்
- சர்வர் செயல்பாடுகளுக்கான தெளிவை வழங்குகிறது

### MCP நெறிமுறை வாழ்நாள்

#### துவக்கம் மற்றும் திறன் பேச்சுவார்த்தை

MCP ஒரு நிலையான நிலையில் செயல்படும் நெறிமுறை, அதற்கான வாழ்நாய் மேலாண்மை அவசியம். துவக்க செயல்முறை முக்கிய நோக்கங்கள் நிறைவேற்றுகிறது:

1. **நெறிமுறை பதிப்பு பேச்சுவார்த்தை**: கிளையண்டும் சர்வரும் பொருந்தக்கூடிய பதிப்புகளைப் பயன்படுத்தி உறுதிப்படுத்தல் (எ.கா., "2025-06-18")
2. **திறன் கண்டறிதல்**: ஒவ்வொரு பக்கம் ஆதரிக்கும் அம்சங்கள் மற்றும் அடிப்படைகள் வெளிப்படுத்துதல்
3. **அடையாள பரிமாற்றம்**: அங்கீகார மற்றும் பதிப்பு தகவல் வழங்கல்

```python
# உதாரண துவக்க கோரிக்கை
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {
      "elicitation": {},  # கிளையன்ட் பயனர் தொடர்பை ஆதரிக்கிறது
      "sampling": {}      # கிளையன்ட் LLM முடிவுகளை வழங்க முடியும்
    },
    "clientInfo": {
      "name": "edge-ai-client",
      "version": "1.0.0"
    }
  }
}
```

#### கருவி கண்டறிதலும் செயல்படுத்தலும்

துவக்கத்துக்குப்பின் கிளையண்ட்கள் கருவிகளை கண்டறிந்து இயக்க முடியும்:

```python
# கிடைக்கக்கூடிய கருவிகளை கண்டறி
tools_response = await session.list_tools()

# ஒரு கருவியை இயக்குக
result = await session.call_tool(
    "weather_current",
    {
        "location": "San Francisco",
        "units": "imperial"
    }
)
```

#### நேரடி அறிவிப்புகள்

MCP நகர்நிலை புதுப்பிப்புகளுக்கான நேரடி அறிவிப்புகளை ஆதரிக்கிறது:

```python
# கருவிகள் மாற்றும் பொழுது சர்வர் அறிவிப்பை அனுப்புகிறது
{
  "jsonrpc": "2.0",
  "method": "notifications/tools/list_changed"
}

# வாடிக்கையாளர் கருவி பட்டியலை புதுப்பிப்பதன் மூலம் பதிலளிக்கிறது

```

```python
import asyncio
from ghmodel_mcp_demo import OllamaClient, Phi4MiniMCPClient

async def automated_interaction():
    # MCP சேவையக அளவுருக்களை அமைக்கவும்

        command="npx",

    )

    async with Phi4MiniMCPClient(server_params) as mcp_client:

        llm_client = OllamaClient()

            "Help me automate a web task",
            tools
        )
        return response

# தானியக்கத்தை செயல்படுத்தவும்
result = asyncio.run(automated_interaction())
print(result)
```

## மேம்பட்ட அம்சங்கள்

### பலபின்னணி ஆதரவு

மற்ற வகையான Ollama மற்றும் vLLM பின்புறங்களை ஆதரிக்கிறது, உங்கள் தேவைக்கு ஏற்ப தேர்வு செய்யலாம்:

- **Ollama**: உள்ளூர் மேம்பாடுகள் மற்றும் சோதனைக்குப் சிறப்பானது
- **vLLM**: தயாரிப்பு மற்றும் அதிகப்பெருக்க சூழலுக்கு மிகச்சிறந்தது

### இணைப்பு நெறிமுறைகள் தகுதிகள்

இரண்டு இணைப்பு அம்சங்கள் ஆதரிக்கப்படுகின்றன:

**STDIO முறை**: நேரடி செயலி தொடர்பு
- குறைந்த தாமதம்
- உள்ளூர் கருவிகளுக்குப் பொருத்தமானது
- எளிய அமைப்பு

**SSE முறை**: HTTP அடிப்படையிலான ஓட்டக் காட்சி
- வலையமைப்பு இணைத்தல்
- பகிரப்பட்ட அமைப்புகளுக்கு மேம்பட்டது
- நேரடி புதுப்பிப்புகள்

### கருவி ஒருங்கிணைப்பு திறன்கள்

பல கருவிகளுடன் ஒருங்கிணைக்கும் திறன் உள்ளது:
- வலை தானியங்கி (Playwright)
- கோப்பு செயல்பாடுகள்
- API பரிமாற்றங்கள்
- அமைப்பு கட்டளைகள்
- தனிப்பயன் செயல்பாடுகள்

## பிழை கையாள்தல் மற்றும் சிறந்த நடைமுறைகள்

### முழுமையான பிழை மேலாண்மை

செயல்பாட்டில் பல பிழை கையாள்வுகள் உள்ளன:

**இணைப்பு பிழைகள்:**
- MCP சர்வர் தோல்விகள்
- வலை ஒத்திகை காலாவதிகள்
- இணைப்பு பிரச்சனைகள்

**கருவி இயக்க பிழைகள்:**
- கருவிகள் இல்லாதவை
- அளவுரு சரிபார்ப்பு
- செயல்பாடு தோல்விகள்

**மறுஉத்தரவு செயல்பாட்டு பிழைகள்:**
- JSON பகுப்பாய்வு பிரச்சனைகள்
- வடிவமைப்பு முரண்பாடுகள்
- LLM பதில் தவறுகள்

### சிறந்த நடைமுறைகள்

1. **வள மேலாண்மை**: async பார்வையாளர் மேலாளர்களை பயன்படுத்தவும்
2. **பிழை கையாள்தல்**: முழுமையான முயற்சி-பிடி தொகுதிகளை அமல்படுத்தவும்
3. **பதிவேற்றம்**: சரியான பதிவேற்ற நிலைகளை இயக்கு
4. **பாதுகாப்பு**: உள்ளீடுகளை சரிபார்த்து வெளியீடுகளை சுத்திகரிக்கவும்
5. **செயல்திறன்**: இணைப்பு கூட்டமைப்பு மற்றும் சேமிப்பகம் பயன்படுத்தவும்

Model Context Protocol சூழலில் பல முக்கிய கூறுகள் உள்ளன:

- **[MCP விவரக்குறிப்பு](https://modelcontextprotocol.io/specification/latest)**: கிளையண்டுகள் மற்றும் சர்வர்களுக்கான நடைமுறை தேவைகளை விளக்கும் அதிகாரப்பூர்வ விவரம்
- **[MCP SDK கள்](https://modelcontextprotocol.io/docs/sdk)**: MCP ஐ நடைமுறைப்படுத்தும் பல நிரலாக்க மொழிகளுக்கான SDK கள்
- MCP சர்வர் மற்றும் கிளையண்டுகள் மேம்படுத்த கருவிகள், அதில் [MCP விசாரணை கருவி](https://github.com/modelcontextprotocol/inspector) உட்பு
- **[MCP குறிப்பு சர்வர் நடைமுறைகள்](https://github.com/modelcontextprotocol/servers)**: MCP சர்வர் குறிப்பு நடைமுறைகள்

### MCP மேம்பாட்டை ஆரம்பித்தல்

**கிளையண்டுகள் உருவாக்க**: [MCP சர்வர்களுடன் இணையும் பயன்பாடுகள் உருவாக்கவும்](https://modelcontextprotocol.io/docs/develop/build-client)

**கருத்துக்களை கற்றுக்கொள்ளவும்**: [MCP அடிப்படைகள் மற்றும் கட்டமைப்பை புரிந்து கொள்ளவும்](https://modelcontextprotocol.io/docs/learn/architecture)

## முடிவு

SLMகள் MCP உடன் இணைந்து AI பயன்பாடு மேம்பாட்டில் ஒரு பரிமாற்றத்தை வெளிப்படுத்துகின்றன. சிறிய மாதிரிகளின் திறனோடு வெளிப்புற கருவிகளின் வலிமையை இணைத்து, மேம்படுத்துநர்கள் வள திறன்சேர்ச்சியுடனும் மிகச்சிறந்த திறனுடன் கூடிய புத்திசாலித்தன்மை அமைப்புகளைத் தயாரிக்க முடியும்.

Model Context Protocol AI பயன்பாடுகளை வெளிப்புற அமைப்புகளுடன் இணைக்க நிலையான வழியை வழங்குகிறது, USB-C மின் சாதனங்களுக்கு பொதுவான இணைப்பு முறையாக இருப்பது போல. இந்த நிலையான வழி:

- **திறந்த ஒருங்கிணைப்பு**: ஆற்றல் ஐ மாதிரிகளை பல தரவுமூலங்கள் மற்றும் கருவிகளுடன் இணைக்கிறது
- **சூழல் வளர்ச்சி**: ஒருமுறை கட்டமைப்பு, பல AI பயன்பாட்டில் பயன்படுத்தும்
- **திறன் மேம்பாடு**: SLM களை வெளிப்புற செயல்பாடுகளால் கூர்மையாக்குதல்
- **நேரடி புதுப்பிப்புகள்**: நகர்நிலை மற்றும் பதிலளிக்கும் AI பயன்பாடுகள் ஆதரவு

முக்கிய எடுத்துக்காட்டுகள்:
- MCP AI பயன்பாடுகளும் வெளிப்புற அமைப்புகளுக்கும் இடையே ஒரு திறந்த நிலையான அமைப்பு ஆகும்
- இந்த நெறிமுறை கருவிகள், வளங்கள் மற்றும் ஊக்கங்களை மூல அடிப்படையாக கொண்டுள்ளது
- நேரடி அறிவிப்புகள் நகர்நிலை மற்றும் பதிலளிக்கும் பயன்பாடுகளை உருவாக்க உதவுகின்றன
- சரியான வாழ்நாள் மேலாண்மை மற்றும் பிழை சிறப்பித்தல் தயாரிப்பு பயன்பாட்டிற்கு அவசியம்
- சூழலில் முழுமையான SDK கள் மற்றும் மேம்பாட்டு கருவிகளை வழங்குகிறது
