# பிரிவு 1: Microsoft Phi மாதிரி குடும்பத்தின் அடிப்படைகள்

Microsoft Phi மாதிரி குடும்பம் செயற்கை நுண்ணறிவில் ஒரு புதிய போக்கு மாற்றத்தை பிரதிநிதித்துவம் செய்கிறது, இது சுருக்கமான, திறமையான மாதிரிகள் உள்ளடக்கமான செயல்திறனை பெற்றுக் கொள்ள முடியுமென காட்டுகிறது, மேலும் பாரம்பரிய பெரிய மொழி மாதிரிகளுக்கு விட மிகக் குறைந்த வளங்களை பயன்படுத்துகிறது. Phi குடும்பம் பலவித பணிகளை மிகச் சிறந்த செயல்திறனுடன் குறைவான கணினிசார் தேவைகள் கொண்டு சக்திவாய்ந்த AI திறன்களை எப்படி வழங்குகிறது என்பதை புரிந்து கொள்வது முக்கியம்.

## அறிமுகம்

இந்த பாடத்தில், Microsoft Phi மாதிரி குடும்பம் மற்றும் அதன் அடிப்படைக் கருத்துக்களை ஆராய்வோம். Phi குடும்பத்தின் வளர்ச்சி, திறமையான பயிற்சி முறைமைகள், குடும்பத்தின் முக்கிய மாறுபாடுகள் மற்றும் பல்வேறு சூழல்களில் அதன் பிரயோகங்கள் ஆகியவற்றைப் பேசுவோம்.

## கற்றல் நோக்கங்கள்

இந்த பாடம் முடிந்தவுடன், நீங்கள்:

- Microsoft Phi மாதிரி குடும்பத்தின் வடிவமைப்பு தத்துவம் மற்றும் வளர்ச்சியை புரிந்துகொள்கிறீர்கள்.
- குறைவான அளவுசார் அளவுகளுடன் சிறந்த செயல்திறனை Phi மாதிரிகள் பெறுவதற்கு முக்கிய கண்டுபிடிப்புகளை அடையாளப்படுத்துகிறீர்கள்.
- வெவ்வேறு Phi மாதிரி வகைகளின் நன்மைகள் மற்றும் வரம்புகளை அறியிறீர்கள்.
- Phi மாதிரிகளின் அறிவைப் பயன்படுத்தி, உண்மையான சூழலுக்கு ஏற்ற வகைகளை தேர்ந்தெடுக்கின்றீர்கள்.

## பாரம்பரிய AI மாதிரி போக்கை புரிதல்

வழக்கமாக, இயற்கை மொழி செயலாக்கத்தில் மிகச்சிறந்த செயல்திறனை அடைய பெரும் அளவிலான மொழி மாதிரிகள், பில்லியன் கணக்கான அளவு அளவுகோள்களுடன் தேவைப்பட்டதாகும். நிறுவனங்கள் சாதாரணமாக இந்த மாதிரிகளை சக்திவாய்ந்த GPU கிளஸ்டர்களில் இயக்கி, API இடைமுகங்கள் அல்லது தனிவகுப்பு हार்ட்வேர் மூலம் அறிமுகப்படுத்துகின்றன.

இது பல பயன்பாடுகளுக்கு நன்றாக செயல்படுகின்றது, ஆனால் நடைமுறை பயன்படுத்தும் சூழல் சவால்களின் வரம்புகள் உள்ளது. பாரம்பரிய முறையில் மிகப்பெரிய கணினிசார் வளங்கள், பெரும் நினைவகங்கள் மற்றும் அதிகமான சக்தி உபயோகங்கள் தேவையாகின்றன. இது முன்னணி திறன்களை வழங்குவது போல் இருந்தாலும், செலவான ஹார்ட்வேர் மீது சார்புகளை உருவாக்குகிறது, அதிக செயல்பாட்டு செலவுகளை ஏற்படுத்துகிறது, மற்றும் வெளியீட்டு சுதந்திரத்தை குறைக்கிறது.

## திறமையான AI வெளியீட்டு சவால்கள்

பலவித சூழல்களில் திறமையான AI தேவைகள் அதிகரித்து வருகின்றன. தனிப்பட்ட பாதுகாப்பு காரணங்களுக்காக உள்ளூர் வெளியீடு தேவையான செயல்பாடுகள், மேக API செலவுகள் மிகவும் அதிகமாகும் செலவு எடுக்கும் செயல்பாடுகள், குறைந்த வளங்கள் கொண்ட எட்ஜ் கணினி சூழல்கள், அல்லது தாமதமின்றி பதிலும் தேவைப்படும் நேரடி செயல்பாடுகள் ஆகியவற்றை எடுத்துக்கொள்ளலாம்.

### முக்கிய வெளியீட்டு வரம்புகள்

பாரம்பரிய மிகப்பெரிய மாதிரி வெளியீட்டுகள் சில நிறுவனங்களில் நடைமுறைப் பயன்பாடுகளுக்கு வரம்புகளை உருவாக்குகின்றன:

- **செலவு வரம்புகள்**: அதிக கணினிசார் செலவுகள் தொடர்ச்சியான வெளியீட்டை விலை அதிகமாக்குகின்றன.
- **வள வரம்புகள்**: உயர் தர GPU வளங்களுக்கு குறைவான அணுகல் வெளியீட்டு தேர்வுகளை ஒட்டுத்துணையாக வகுக்கிறது.
- **தனிப்பட்ட தேவைகள்**: தரவுச் பாதுகாப்பை உறுதிசெய்ய உள்ளூர் செயலாக்கம் தேவைப்படும் பயனர் பணிகள்.
- **தாமத உணர்வு**: நேரடி செயல்பாடுகள் மேக சுற்றுப்பயண வினாடிகளுடன் உடனடி பதில்கள் வேண்டும்.

## Microsoft Phi மாதிரி தத்துவம்

Microsoft Phi மாதிரி குடும்பம் AI மாதிரி வடிவமைப்பில் அடிப்படையில் மாற்றத்தை குறிக்கிறது, திறமையை மற்றும் நடைமுறை வெளியீட்டை முன்னுரிமை வைத்து, வலுவான செயல்திறன் பண்புகளை பராமரிக்கிறது. Phi மாதிரிகள் புதுமையான கட்டமைப்புகள், உயர்தர பயிற்சி முறைமைகள் மற்றும் சிறப்பு சீர்திருத்தக் தொழில்நுட்பங்களின் மூலம் இதைப் பெறுகின்றன.

Phi குடும்பம் ஒரு அளவுக்கு திறன் அதிகரிக்க பல அணுகுமுறைகளை கொண்டுள்ளது, இது பராமாணு அடிப்படையில் செயல்திறனை அதிகரிக்க பிரயோஜனப்படுத்துகிறது, சாதாரண ஹார்ட்வேர் இயந்திரங்களில் வெளியிடத்தக்கவாறு உள்ள சிறப்பு AI திறன்களை வழங்குகிறது. குறைந்த கணினிசாரா தேவைகள், நினைவகப் பயன்பாடு மற்றும் செயல்பாட்டு செலவுகளை மிகக் குறைக்க வேண்டும் என்பதே நோக்கம்.

### முக்கிய Phi வடிவமைப்பு தத்துவங்கள்

Phi மாதிரிகள் பாரம்பரிய பெரிய மொழி மாதிரிகளைவிட மிக்க சில அடிப்படைக் கொள்கைகளை அடிப்படையாகக் கொண்டு உருவாக்கப்படுகின்றன:

- **திறமை முதன்மை**: முழுமையான அளவு இல்லாமல் ஒரே அளவுக்கு அதிகபட்ச செயல்திறன் அடைய குறையாக உள்ள பராமетровுக்கு கவனம் செலுத்தல்.
- **உயர் தர பயிற்சி**: மிகப்பெரிய தரவுத்தொகுப்புகளை விட உயர்தர மற்றும் நன்கு தேர்ந்தெடுக்கப்பட்ட பயிற்சி தரவுகளுக்குப் முக்கியத்துவம்.
- **வெளியீட்டு விறுவிறுப்பான தன்மை**: பலவித ஹார்ட்வேர் கட்டமைப்புகளில் சிறப்பாக இயங்க வடிவமைப்பு.
- **சிறப்பு திறன்கள்**: உறுதியான விளைவுகளைப் பெற குறிப்பிட்ட பணிகள் அல்லது துறைகளுக்கு சிறப்பாக சீர்திருத்தம்.

## Phi குடும்பத்தைத் தூண்டுவிக்கும் முக்கிய தொழில்நுட்பங்கள்

### "படிப்புத்தகச்" பயிற்சி முறை

Phi குடும்பத்தின் மிகப் புதுமையான அம்சங்களில் ஒன்று "படிப்புத்தக தரம்" பயிற்சி முறைமையாகும். பெரும் அளவிலான சுத்தமற்ற இணையத் தரவுத் தொகுப்பை பயிற்சிக்குப் பயன்படுத்துவதற்கு பதிலாக, Phi மாதிரிகள் காரணாய்வு, கணிதம், குறியீட்டு மற்றும் பொது அறிவைப் பயிற்று செய்ய முக்கியமான மற்றும் உயர்தர கல்வி உள்ளடக்கங்களை பயன்படுத்துகின்றன.

இந்த முறை, உயர்தர பாட நூல்கள் மற்றும் கல்வி பொருளின் வடிவத்துடன் அசல் உருவான கல்வி உள்ளடக்கங்களை உருவாக்கி பயிற்சி தரவாக பயன்படுதுகின்றது. பயிற்சி தரவு தெளிவான விளக்கங்கள், படிப்படியாகிய காரணாய்வு, மற்றும் கட்டமைக்கப்பட்ட அறிவு வழங்கலைக் குறிக்கின்றது.

### முன்னேற்றமான காரணாய்வு பயிற்சி

சமீபத்திய Phi மாதிரிகள் சிக்கலான பல படிகள் கொண்ட பிரச்சினை தீர்க்கத் திறன்கள் கொண்ட காரணாய்வு பயிற்சி முறைகள் உள்ளடக்குகின்றன. இதில்:

First, let me rearrange this to standard form:
3x² + 4x + 5 = 1
3x² + 4x + 5 - 1 = 0  
3x² + 4x + 4 = 0

Now I can use the quadratic formula: x = (-b ± √(b² - 4ac)) / (2a)

b² - 4ac = 4² - 4(3)(4) = 16 - 48 = -32

Phi-3 தொடர் SLM திறன்களில் பெரும் முன்னேற்றத்தை கண்டது, பல சிறப்பு வகைகளுடன்:

## மேம்பாடு மற்றும் ஒருங்கிணைப்பு உதாரணங்கள்

### Transformers உடன் விரைவான துவக்கம்

Hugging Face Transformers நூலகத்தைப் பயன்படுத்தி Phi மாதிரிகளுடன் தொடங்குவது இங்கே உள்ளது:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# Phi-4-mini-instruct ஐ ஏற்று
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True,
    attn_implementation="flash_attention_2"  # சிறந்த செயல்திறனுக்காக
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")

# அஞ்சல் மாதிரியைப் பயன்படுத்தி உங்கள் கேள்வியை வடிவமைக்கவும்
messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain quantum computing in simple terms."}
]

# அஞ்சல் மாதிரியைப் பயன்படுத்தவும்
input_text = tokenizer.apply_chat_template(messages, tokenize=False)
inputs = tokenizer(input_text, return_tensors="pt")

# பதிலை உருவாக்கவும்
with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=200, temperature=0.7)
    
response = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(response)
```

### நுட்பமாக ஐந்து-தட்டுபடுத்தல் உதாரணம்

குறிப்பிட்ட பணிகளுக்காக Phi-4-mini-instruct ஐ நுட்பமாக ஐந்து-தட்டுபடுத்துவது எப்படி என்பது அடுத்த உதாரணத்தில் காட்டப்பட்டுள்ளது:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig
from trl import SFTTrainer
from datasets import load_dataset

# LoRA நுட்பமயமாக்கலுக்கான அமைப்புகள்
peft_config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
    target_modules="all-linear"
)

# திறமைக்கு உகந்த பயிற்சி அமைப்புகள்
training_config = TrainingArguments(
    output_dir="./phi-4-mini-finetuned",
    learning_rate=5.0e-06,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=1,
    num_train_epochs=1,
    bf16=True,
    gradient_checkpointing=True,
    warmup_ratio=0.2,
    save_steps=100
)

# மாதிரியையும் டோக்கனையஸர் ஐயும் ஏற்று
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")
tokenizer.pad_token = tokenizer.unk_token
tokenizer.padding_side = 'right'

# தரவுத்தொகுப்பை ஏற்று செயலாக்கு
train_dataset = load_dataset("HuggingFaceH4/ultrachat_200k", split="train_sft")

# பயிற்சியாளரை துவக்கம் செய்
trainer = SFTTrainer(
    model=model,
    args=training_config,
    peft_config=peft_config,
    train_dataset=train_dataset,
    max_seq_length=2048,
    tokenizer=tokenizer,
    packing=True
)

# நுட்பமயமாக்கலைத் துவக்கு
trainer.train()
```

### ONNX உடன் மொபைல் பயன்பாடு

import onnxruntime as ort

session = ort.InferenceSession("phi-4-mini-quantized.onnx")

input_ids = tokenizer.encode("Hello, how are you?", return_tensors="np")

response = tokenizer.decode(predicted_ids[0], skip_special_tokens=True)

## செயல்திறன் அளவைகள் மற்றும் சாதனைகள்

### முக்கிய செயல்திறன் சிறப்பம்சங்கள்

**கணித காரணத்திறன் சிறந்தது:**

## மாதிரி தேர்வு வழிகாட்டி

### அடிப்படை பயன்பாடுகளுக்காக
