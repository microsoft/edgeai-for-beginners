# தொடக்கம் மாணவர்களுக்கு எட்ஜ்ஏஐ - பணிமனை

> **உற்பத்தி-தகுதியான எட்ஜ் AI செயலிகளைக் கட்டமைக்க செய்முறை கற்றல் பாதை**
>
> Microsoft Foundry Local மூலம் உள்ளூரில் AI ஏற்றுதல், முதலாவது சந்தை முடிப்பிலிருந்து பன்முக முகவர் ஒருங்கிணைப்பு வரை 6 முன்னேற்றமான அமர்வுகளில்.

---

## 🎯 அறிமுகம்

**தொடக்கம் மாணவர்களுக்கு எட்ஜ்ஏஐ பணிமனை**க்கு வரவேற்கிறோம் - முழுமையாக உள்ளூரில் இயங்கும் புத்திசாலி செயலிகள் உருவாக்க உங்கள் செய்முறை கையேடு. இந்த பணிமனை Microsoft Foundry Local மற்றும் சிறிய மொழி மாடல்கள் (SLMs) பயன்படுத்தி கருத்துப்பூர்வமான எட்ஜ் AI கொள்கைகளானதை உலகிற்கு பொருந்தக்கூடிய திறன்களில் மாற்றும்ச் செயற்கை பயிற்சி வழியாக.

### இந்த பணிமனை ஏன்?

**எட்ஜ் AI புரட்சிஇப்போது உள்ளது**

உலகம் முழுவதும் அமைப்புகள் மேக சார்ந்த AI-யிலிருந்து எட்ஜ் கம்ப்யூட்டிங்கிற்குக் கடந்து முக்கிய மூன்று காரணங்கள் உள்ளன:

1. **தனியுரிமை & ஒழுங்குபடுத்தல்** - வசதி பகிர்வு இல்லாமல் உள்ளூரில் நுண்ணறிவு தரவை செயலாக்குதல் (HIPAA, GDPR, நிதி ஒழுங்குகள்)
2. **செயல்திறன்** - நெட்வொர்க் தாமதத்தை நீக்குதல் (50-500ms உள்ளூர்நிலை vs 500-2000ms மேக சுற்றுப்பயணம்)
3. **கட்டுப்பாடு செலவு** - ஒவ்வொரு டோக்கனுக்கும் API செலவுகளை நீக்கி மேக செலவினை இல்லாமல் பருமன் செயல்

**ஆனால் எட்ஜ் AI வேறுபாடாக உள்ளது**

உள்ளூரில் AI இயக்கு புதிய திறன்களை தேவைப்படுத்துகிறது:
- வள தேவைகளுக்கு மாடல் தேர்வு மற்றும் மேம்படுத்தல்
- உள்ளூர்சேவை மேலாண்மை மற்றும் ஹார்ட்வேர் விருத்தி
- சிறிய மாடல்களுக்கு ப்ராம்ட் பொறியியல்
- எட்ஜ் கருவிகளுக்கான உற்பத்தி ஏற்றல் வடிவங்கள்

**இந்த பணிமனை அந்த திறன்களை வழங்குகிறது**

6 கவனிக்கப்பட்ட அமர்வுகளில் (~3 மணி நேரம் மொத்தம்), நீங்கள் "ஹலோ உலகம்" என்ற தொடக்கம் முதல் உள்ளூரில் இயங்கும் உற்பத்தி-தயாரான பன்முக முகவர் அமைப்புகள் வரை முன்னேறுவீர்கள்.

## 📚 கற்றல் நோக்கங்கள்

இந்த பணிமனை முடித்தபின்பு, நீங்கள் செய்யக்கூடியவைகள்:

### அடிப்படை திறன்கள்
1. **உள்ளூர் AI சேவைகளை ஏற்று நிர்வகிக்க**
   - Microsoft Foundry Local ஐ நிறுவி கதைமைக்கு கொண்டு வருதல்
   - எட்ஜ் ஏற்றலுக்கு பொருத்தமான மாடல்களை தேர்ந்தெடுக்க
   - மாடல் வாழ்கை ஆராய்ச்சி (பதிவிறக்க, ஏற்ற, கேச்)
   - வள பயன்பாடுகளை கண்காணித்து செயல்திறனை மேம்படுத்த

2. **AI இயக்கப்படுத்தப்பட்ட செயலிகளை உருவாக்க**
   - உள்ளூரில் OpenAI-க்கு பொருந்தும் அரட்டையால் நிறைவேற்றுக
   - சிறிய மொழி மாடல்களுக்கு நல்ல ப்ராம்ட்களை வடிவமைக்க
   - சிறந்த பயனர் அனுபவத்திற்கு ஸ்ட்ரீமிங் பதில்களை கையாள
   - உள்ளூர் மாடல்களை இருந்த செயலிகளுடன் இணைக்க

3. **RAG (தரவு இணைப்பு உருவாக்கம்) அமைப்புகளை உருவாக்க**
   - செம்மைத் தேடலை எம்பெடிங்ஸுடன் கட்டமைக்க
   - LLM பதில்களை துறை சார்ந்த அறிவில் அடித்துணைக்க
   - RAG தரத்தை தொழில்துறை நெறிமுறை அளவுகோல்கள் கொண்டு மதிப்பிட
   - மாதிரியில் இருந்து உற்பத்தி நிலைக்கு பரிமாற்றம்

4. **மாடல் செயல்திறனை மேம்படுத்த**
   - உங்கள் பயன்பாட்டிற்கான பல மாடல்களை ஒப்பிடும் தரவரையறைகளை செய்ய
   - தாமதம், ஓடுகை, முதல் டோக்கன் நேரம் கணக்கிடு
   - வேகம்/தர வரிசையில் சிறந்த மாடலை தேர்ந்தெடு
   - உண்மையான சூழ்நிலைகளில் SLM மற்றும் LLM என்று வேறுபாடுகளை ஒப்பிடு

5. **பன்முக முகவர் அமைப்புகளை ஒருங்கிணைத்தல்**
   - வேறுபட்ட பணி முகவர்களுக்கு சிறப்பு வடிவமைபு செய்ய
   - முகவர் நினைவு மற்றும் சூழல் மேலாண்மை ஐ நடைமுறைப்படுத்து
   - சிக்கலான பணிசூழல்களில் முகவர்களை ஒருங்கிணைத்தல்
   - பல மாடல்களுக்கு ஞான பூர்வமாக கோரிக்கைகளை வழிமாற்று

6. **உற்பத்தி-தகுதியான தீர்வுகளை ஏற்று செயல் படுத்து**
   - பிழை கையாளுதல் மற்றும் மீண்டும் முயற்சி நியமங்களை நிர்வகிக்க
   - டோக்கன் பயன்பாடு மற்றும் அமைப்பு வளங்கள் கண்காணிக்க
   - மாடல்-சூழல் மாதிரிகள் மூலம் பருமன் அமைப்புகளை கட்டமைக்க
   - எட்ஜ் முதல் கலவை (எட்ஜ் + மேகம்) வரை இடமாற்று பாதைகள் திட்டமிடு

### தொழில்-தகுதியான திறன்கள்

**இந்த பணிமனை முடித்தபின்பு, நீங்கள் தயார்:**

✅ **தனியுரிமை முதன்மை செயலிகள் உருவாக்க**
- உள்ளூர் அடிப்படையில் பிஎச்ச்ஐ/பிஐஐ கையாளும் மருத்துவ பயன்பாடுகள்
- ஒழுங்கினைப் பின்பற்றும் நிதி சேவைகள்
- தரவு கண்காப்பு தேவையுள்ள அரசு அமைப்புகள்

✅ **எட்ஜ் சூழல்களுக்கு மேம்படுத்தல்**
- வளக்குறைவான ஐஓடி கருவிகள்
- தொலைதூரமில்லாத முதன்மை கைபேசி பயன்பாடுகள்
- குறைந்த தாமத நேரம் உடைய நேரடி அமைப்புகள்

✅ **புத்திசாலி معماريக்களை வடிவமைக்க**
- சிக்கலான பணிநடத்தலுக்கு பன்முக முகவர் அமைப்புகள்
- கலவையான எட்ஜ்-மேகம் ஏற்றல்கள்
- செலவு குறைந்த AI ஒளிப்படம்

✅ **எட்ஜ் AI முயற்சிகளுக்கு அடுத்தடுத்து வழிநடத்த**
- திட்டங்களுக்கு எட்ஜ் AI சாத்தியத்தை மதிப்பிடு
- பொருத்தமான மாடல்கள் மற்றும் கட்டமைப்புகளை தேர்ந்தெடு
- பருமன் உள்ளூர் AI தீர்வுகளை வடிவமைக்க

### 3 படிகளில் அமைத்தல்

#### 1. Foundry Local ஐ நிறுவவும்

**விண்டோஸ்:**
```powershell
winget install Microsoft.FoundryLocal
```

**மேகோஎஸ்:**
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

**நிறுவலின் சரிபார்ப்பு:**
```bash
foundry --version
foundry service status
```

**Azure AI Foundry Local ஒரு நிலையாக போர்ட் கொண்டு இயங்குவதை உறுதி செய்யவும்**

```bash
# FoundryLocal ஐ 58123 போர்ட்டை (இயல்புநிலை) பயன்படுத்த அமைக்கவும்
foundry service set --port 58123 --show

# அல்லது வேறு போர்ட்டை பயன்படுத்தவும்
foundry service set --port 58000 --show
```

**இயங்குது என்பதை சரிபார்க்கவும்:**
```bash
# சேவை நிலையைச் சரிபார்
foundry service status

# முனை சோதனைசெய்
curl http://127.0.0.1:58123/v1/models
```
**கிடைக்கும் மாடல்களை கண்டுபிடி**
உங்கள் Foundry Local மேற்பரப்பில் எந்த மாடல்கள் கிடைக்கிறது என்று அறிய, நீங்கள் மாடல்கள் எண்ட்பாயிண்ட் கோரிக்கை செய்யலாம்:

```bash
# கமாண்ட்/பாஷ்/பவர்ஷெல்
foundry model list
```

வலை எண்ட்பாயிண்ட் மூலம் 

```bash
# Windows PowerShell
powershell -Command "Invoke-RestMethod -Uri 'http://127.0.0.1:58123/v1/models' -Method Get"

# அல்லது curl பயன்படுத்துவது (இருப்பின்)
curl http://127.0.0.1:58123/v1/models
```

| `RAG_QUESTION` | RAG குழாய்க்கான சோதனை கேள்வியை மாற்று | `Why use RAG with local inference?` |
| `AGENT_QUESTION` | ஏஜெண்ட் குழாய்க்கான கேள்வியை மாற்று | `Explain why edge AI matters for compliance.` |
| `AGENT_MODEL_PRIMARY` | ஆராய்ச்சி ஏஜெண்டுக்கான மாதிரி தனிநாமம் | `phi-4-mini` |
| `AGENT_MODEL_EDITOR` | ஆசிரியர் ஏஜெண்டுக்கான மாதிரி தனிநாமம் (வேறுபடலாம்) | `gpt-oss-20b` |
| `SHOW_USAGE` | `1` என்றால், முடிவுக்கு டோக்கன் பயன்பாடு அச்சிடும் | `1` |
| `RETRY_ON_FAIL` |  கடினமான உரையாடல் பிழைகளில் ஒருமுறை மீண்டும் முயற்சி செய்யும் | `1` |
| `RETRY_BACKOFF` | மீண்டும் முயற்சிக்க சில வினாடிகள் காத்திருக்க | `1.0` |

ஒரு மாறி அமைக்கப்படவில்லை என்றால், ஸ்கிரிப்ட்கள் பொருத்தமான இயல்புகளுக்கு திரும்பும். ஒரு மாதிரி காட்சிகளுக்கு பொதுவாக `FOUNDRY_LOCAL_ALIAS` மட்டுமே தேவைப்படும்.

### உதவி தொகுப்பு

அனைத்து மாதிரிகளும் இப்போது `samples/workshop_utils.py` என்ற உதவி தொகுப்பைப் பகிர்கின்றன:

* பேர் காவல் செய்யப்பட்ட `FoundryLocalManager` + OpenAI கிளையண்ட் உருவாக்கம்
* விருப்பமான மீண்டும் முயற்சி + பயன்பாடு அச்சிடுவதுடன் `chat_once()` உதவி
* எளிய டோக்கன் பயன்பாடு அறிக்கை (செயலில் வைக்க `SHOW_USAGE=1`)

இது நகல் எழுத்துக்களை குறைத்து, உள்ளூர் மாதிரி ஒருங்கிணைப்பிற்கான சிறந்த நடைமுறைகளை முன்னிலையில் காட்டு.

## CLI கட்டளை சரியான கையேடு

பணிமனை தற்போதைய பதிவு செய்யப்பட்ட / நிலையான Foundry Local CLI கட்டளைகளையே பயன்படுத்தும்.

### குறிப்பிடப்பட்ட நிலையான கட்டளைகள்

| வகை | கட்டளை | நோக்கம் |
|----------|---------|---------|
| மையம் | `foundry --version` | நிறுவப்பட்ட பதிப்பு காண்பி |
| சேவை | `foundry service start` | உள்ளூர் சேவையைத் தொடங்கு (தானாக இல்லை என்றால்) |
| சேவை | `foundry service status` | சேவை நிலையை காண்பி |
| மாதிரிகள் | `foundry model list` | பட்டியல் / கிடைக்கக்கூடிய மாதிரிகள் |
| மாதிரிகள் | `foundry model download <alias>` | மாதிரி எடை பதிவிறக்கம் செய் |
| மாதிரிகள் | `foundry model run <alias>` | உள்ளூர் மாதிரியை இயக்கு; ஒருநிலைச் செயலுக்கு `--prompt` உடன் சேர்த்து |
| மாதிரிகள் | `foundry model unload <alias>` / `foundry model stop <alias>` | நினைவகத்தில் இருந்து மாதிரியை அகற்று (ஆதரிக்கப்படுகிற போது) |
| கேசே | `foundry cache list` | கேசே செய்யப்பட்ட (பதிவிறக்கம் செய்யப்பட்ட) மாதிரிகள் பட்டியல் |

### ஒருநிலை ப்ராம்ட் வடிமுறை

பழையதாகப் பயன்பாட்டிலிருந்து தவறான `model chat` துணைக்கட்டளையின் பதிலாக, பயன்படுத்துக:

```powershell
foundry model run <alias> --prompt "Your question here"
```

இது ஒரு ப்ராம்ட்/பதில் ஒருமுறை செயல் செய்து பின்னர் வெளியேறும்.

### அகற்றப்பட்ட / தவிர்க்கப்பட்ட வடிமுறைகள்

| தவறான / பதிவு செய்யப்படாத | மாற்று / வழிகாட்டு |
|---------------------------|------------------------|
| `foundry model chat <model> "..."` | `foundry model run <model> --prompt "..."` |
| `foundry model list --running` | சாதாரண `foundry model list` + சமீபத்திய செயல்பாடு / பதிவு பார்க்கவும் |
| `foundry model list --cached` | `foundry cache list` |
| `foundry model stats <model>` | அளவீடு பைத்தான் ஸ்கிரிப்ட் + OS கருவிகள் (Task Manager / `nvidia-smi`) பயன்படுத்தவும் |
| `foundry model benchmark ...` | `samples/session03/benchmark_oss_models.py` |

### அளவீடு மற்றும் தொலைதிருத்தம்

- தாமதம், p95, டோக்கன்கள்/விநாடி: `samples/session03/benchmark_oss_models.py`
- முதல் டோக்கன் தாமதம் (ஸ்ட்ரீமிங்): `BENCH_STREAM=1` ஸெட்டிங்
- வள பயன்பாடு: OS கண்காணிப்பாளர்கள் (Task Manager, Activity Monitor, `nvidia-smi`).

புதிய CLI தொலைதிருத்த கட்டளைகள் மேம்படும்போது, அவற்றை அமர்வு மார்க்டவுன்களுக்குள் மாற்றங்கள் மிகக் குறைவாக கொண்டு சேர்க்கலாம்.

### தானியங்கி குருட்டு பராமரிப்பு

பழைய CLI வடிமுறைகள் மறுபடியும் எழுவதை தடுக்க ஒரு தானியங்கி லின்டர் பயன்படுத்தப்படுகிறது:

ஸ்கிரிப்ட்: `Workshop/scripts/lint_markdown_cli.py`

பழைய வடிமுறைகள் குறியீடு கட்டங்களுக்குள் தடுக்கப்படுகின்றன.

பரிந்துரைக்கப்பட்ட மாற்றங்கள்:
| பழையது | மாற்று |
