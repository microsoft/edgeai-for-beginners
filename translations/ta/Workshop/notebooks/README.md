# வேலைக்கூடக் கையெழுத்து புத்தகங்கள்

> **கைகளில் நடைமுறை எட்ஜ் ஏஐ கற்றலுக்கான இன்டரக்டிவ் ஜூபிடர் நோட்புக்குகள்**
>
> மைக்ரோசாஃப்ட் ஃபவுண்ட்ரி லோகல் மற்றும் சிறிய மொழி மாதிரிகளை பயன்படுத்தி அடிப்படையான உரையாடல் நிறைவேற்றல்களிலிருந்து முன்னேறிய ஆயிரம் முகப்பு பல்வேறு முகவரி அமைப்புகளுக்கு முன்னேறும், தானாக முன்னேறும் கற்கை வழிகாட்டிகள்.

---

## 📖 அறிமுகம்

**புதியவர்களுக்கு எட்ஜ் ஏஐ வேலைக்கூடக் கையெழுத்துப் புத்தகங்கள்** தொகுப்புக்குள் உங்கள் வரவேற்பு. இந்த இன்டரக்டிவ் ஜூபிடர் நோட்புக்குகள் நேரடி அனுபவ கற்றலை வழங்குகின்றன, இதில் நீங்கள் எட்ஜ் ஏஐ குறியீட்டின் எழுதுதல், இயக்குதல் மற்றும் முயற்சி செய்வது நிகழ்கிறது.

### ஜூபிடர் நோட்புக்குகளை ஏன் தேர்வு செய்தீர்கள்?

பாரம்பரிய கற்கை பயிற்சிகளுக்கு மாறாக, இந்த நோட்புக்குகள்:

- **இன்டரக்டிவ் கற்றல்**: குறியீட்டு செல்களை இயக்கி உடனடி முடிவுகளைப் பார்க்கலாம்
- **முயற்சி செய்வது**: அளவுருக்களை மாற்றி நேரடியாக மாற்றங்களை கவனிக்கலாம்
- **ஆவணங்கள்**: கருத்துக்களை வழிநடத்த inline விளக்கங்கள் மற்றும் மார்க்க்டவுன் செல்கள்
- **மறு உருவாக்கக்கூடியது**: நீங்கள் மேற்கோள் இடி பயன்படுத்தக்கூடிய முழுமையான வேலை செய்கின்ற உதாரணங்கள்
- **காட்சிப்படுத்தல்**: செயல்திறன் அளவைகள், இடம்அமைப்புகள் மற்றும் முடிவுகளை inline காணலாம்

### இந்த நோட்புக்குகளை சிறப்பாக செய்யும் அம்சங்கள்?

ஒவ்வொரு நோட்புக்கும் **உற்பத்தி தயாரான சிறந்த நடைமுறைகள்** பின்பற்ற வடிவமைக்கப்பட்டுள்ளது:

✅ **அனைத்தும் விரிவான பிழை கையாளுதல்** - மென்மையான இழப்பு மற்றும் தகவலளிக்கும் பிழை செய்திகள்  
✅ **தர வகை குறிப்புகள் மற்றும் ஆவணங்கள்** - தெளிவான செயலியல் கையொப்பங்கள் மற்றும் டாக்ஸ்டிரிங்குகள்  
✅ **செயல்திறன் கண்காணித்தல்** - டோக்கன் பயன்பாடு கண்காணிப்பு மற்றும் தாமத அளவைகள்  
✅ **மாடியுலர் வடிவமைப்பு** - உங்கள் திட்டங்களுக்கு தகுந்து மாற்றக்கூடிய பழக்கவழக்கங்கள்  
✅ **முன்னேறும் சிக்கல்** - முந்தைய அமர்வுகளின் அடிப்படையில் கட்டமைக்கப்பட்டுள்ளது

## 🎯 கற்றல் இலக்குகள்

### நீங்கள் மேம்படுத்தக்கூடிய கைவினைப் புலிமைகள்

இந்த நோட்புக்குகளில் பணியாற்றி, நீங்கள் தேர்ச்சியடைவீர்கள்:

1. **உள்ளூரான ஏஐ சேவை மேலாண்மை**
   - மைக்ரோசாஃப்ட் ஃபவுண்ட்ரி லோகல் சேவைகள் அமைத்து நிர்வகிக்கவும்
   - உங்கள் ஹார்ட்வேருக்கான பொருத்தமான மாதிரிகளை தேர்வு செய்து ஏற்றவும்
   - வள பயன்பாட்டை கண்காணித்து செயல்திறனை சிறப்பாக்கவும்
   - சேவை கண்டறிதல் மற்றும் ஆரோக்கிய சோதனை நடத்தவும்

2. **ஏஐ பயன்பாட்டு மேம்பாடு**
   - உள்ளூரில் ஓபன் ஏஐ படியான உரையாடல் நிறைவேற்றல்களை நடைமுறைப்படுத்தவும்
   - சிறந்த பயனர் அனுபவத்திற்கு ஸ்ட்ரீமிங் இடைமுகங்களை உருவாக்கவும்
   - சிறிய மொழி மாதிரிகளுக்கான பயனுள்ள ப்ராம்ப்டுகளை வடிவமைக்கவும்
   - உள்ளூர் மாதிரிகளை பயன்பாடுகளில் ஒருங்கிணைக்கவும்

3. **திரட்டலுக்கூடிய உருவாக்கல் (RAG)**
   - வெக்டர் இடம்அமைப்புகளுடன் செம்மையான தேடலை உருவாக்கவும்
   - LLM பதில்களை குறிப்பிட்ட துறை ஆவணங்களில் நிலைநிறுத்தவும்
   - RAGAS அளவுகோலில் RAG தரத்தை மதிப்பீடு செய்யவும்
   - மாதிரியை முதல் உருவாக்கத்திலிருந்து உற்பத்தி நிலைக்கு கொண்டு செல்லவும்

4. **செயல்திறன் சிறப்பு படுத்தல்**
   - பல மாதிரிகளை முறையாக ஒப்பிடவும்
   - தாமதம், throughput, முதல்குறிப்புப் பொருள் நேரம் அளவிடவும்
   - சிறிய மொழி மாதிரிகள் மற்றும் பெரிய மொழி மாதிரிகள் ஒப்பிடவும்
   - செயல்திறன்/தரம் வர்த்தகங்களின் அடிப்படையில் சிறந்த மாதிரிகளை தேர்வுசெய்யவும்

5. **பல முகவர்களின் ஒருங்கிணைப்பு**
   - வேறுபட்ட பணிகளுக்கான சிறப்பான முகவர்களை வடிவமைக்கவும்
   - முகவர் நினைவகமும் சூழல் மேலாண்மையும் நடைமுறைப்படுத்தவும்
   - சிக்கலான பணிச்செயல்களில் பல முகவர்களை ஒருங்கிணைக்கவும்
   - முகவர் ஒத்துழைப்பு க்கான ஒருங்கிணைப்பு முறைபாடுகளை உருவாக்கவும்

6. **திறன் வாய்ந்த மாதிரி வழித்தடம்**
   - நோக்கத்தைக் கண்டறிதலும் முறைப்பட்டியலுடன் பொருத்தலும் நடைமுறைப்படுத்தவும்
   - கேள்விகள் பொருத்தமான மாதிரிகளுக்கு தானாக அனுப்பவும்
   - பலடி படிகளைக் கொண்ட குழுக்களை உருவாக்கவும் (திட்டமிடு → செயல்படுத்து → சிறப்பாக்கு)
   - விருப்பமான மாதிரி-ஆசாரமான கருவி அமைப்புகளை வடிவமைக்கவும்

### விரைவு பரிசோதனை

அமைப்பை உறுதிப்படுத்த ஒரு Python செலியில் இதை இயக்கு:

```python
from foundry_local import FoundryLocalManager
import openai

# மேலாளரை துவக்கம் செய்க (சேவையை தானாக கண்டுபிடிக்கும்)
manager = FoundryLocalManager("phi-4-mini")

# OpenAI கிளையண்டை கட்டமைக்கவும்
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# பேச்சு முடிவை சோதிக்கவும்
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**எதிர்பார்த்த வெளியீடு**: உள்ளூர் மாதிரியிடமிருந்து ஒரு வணக்க பதில்.
