# راهنمای توسعه هوش مصنوعی لبه ویندوز

## مقدمه

به توسعه هوش مصنوعی لبه ویندوز خوش آمدید - راهنمای جامع شما برای ساخت برنامه‌های هوشمند که از قدرت هوش مصنوعی در دستگاه با استفاده از پلتفرم Windows AI Foundry مایکروسافت بهره می‌برند. این راهنما به‌طور خاص برای توسعه‌دهندگان ویندوز طراحی شده است که می‌خواهند قابلیت‌های پیشرفته هوش مصنوعی لبه را به برنامه‌های خود اضافه کنند و در عین حال از طیف کامل تسریع سخت‌افزاری ویندوز بهره‌مند شوند.

### مزیت Windows AI

Windows AI Foundry یک پلتفرم یکپارچه، مطمئن و امن است که از چرخه کامل توسعه هوش مصنوعی پشتیبانی می‌کند - از انتخاب و تنظیم مدل گرفته تا بهینه‌سازی و استقرار در معماری‌های پردازنده مرکزی (CPU)، پردازنده گرافیکی (GPU)، واحدهای پردازش عصبی (NPU) و ابر هیبریدی. این پلتفرم توسعه هوش مصنوعی را با ارائه موارد زیر دموکراتیزه می‌کند:

- **انتزاع سخت‌افزار**: استقرار بی‌درنگ بر روی سیلیکون‌های AMD، Intel، NVIDIA و Qualcomm
- **هوشمندی در دستگاه**: هوش مصنوعی با حفظ حریم خصوصی که به‌طور کامل روی سخت‌افزار محلی اجرا می‌شود
- **عملکرد بهینه**: مدل‌هایی که به‌طور پیش‌فرض برای پیکربندی‌های سخت‌افزاری ویندوز بهینه شده‌اند
- **آماده برای سازمان‌ها**: ویژگی‌های امنیتی و تطابق در سطح تولید

### Windows ML 
Windows Machine Learning (ML) این امکان را برای توسعه‌دهندگان C#، C++ و Python فراهم می‌کند تا مدل‌های هوش مصنوعی ONNX را به‌صورت محلی روی رایانه‌های ویندوز با استفاده از ONNX Runtime اجرا کنند، با مدیریت خودکار تامین‌کنندگان اجرا برای سخت‌افزارهای مختلف (CPU‌ها، GPU‌ها، NPU‌ها). [ONNX Runtime](https://onnxruntime.ai/docs/) را می‌توان با مدل‌های PyTorch، Tensorflow/Keras، TFLite، scikit-learn و دیگر فریم‌ورک‌ها استفاده کرد.


![WindowsML نموداری که یک مدل ONNX را نشان می‌دهد که از طریق Windows ML عبور می‌کند و سپس به NPUها، GPUها و CPUها می‌رسد.](https://learn.microsoft.com/en-us/windows/ai/images/winml-diagram.png)

Windows ML نسخه‌ای مشترک از ONNX Runtime را در سرتاسر ویندوز فراهم می‌کند، به همراه قابلیت دانلود پویا تامین‌کنندگان اجرا (EP‌ها).

### چرا ویندوز برای هوش مصنوعی لبه؟

**پشتیبانی سخت‌افزاری جهانی**
Windows ML به‌طور خودکار بهینه‌سازی سخت‌افزاری را در کل اکوسیستم ویندوز انجام می‌دهد و تضمین می‌کند که برنامه‌های هوش مصنوعی شما بهترین عملکرد را صرف‌نظر از معماری سیلیکونی زیرین داشته باشند.

**زمان اجرای هوش مصنوعی یکپارچه**
موتور استنتاج داخلی Windows ML نیازهای پیچیده راه‌اندازی را حذف می‌کند و به توسعه‌دهندگان اجازه می‌دهد تا روی منطق برنامه تمرکز کنند نه نگرانی‌های زیرساختی.

**بهینه‌سازی Copilot+ رایانه شخصی**
APIهای ویژه طراحی شده مخصوص دستگاه‌های نسل بعد ویندوز با واحدهای پردازش عصبی (NPU) اختصاصی که عملکرد استثنایی بر وات ارائه می‌دهند.

**اکوسیستم توسعه‌دهندگان**
ابزارهای غنی شامل ادغام Visual Studio، مستندات جامع و برنامه‌های نمونه که دوره‌های توسعه را تسریع می‌کنند.

## اهداف یادگیری

با تکمیل این راهنمای توسعه هوش مصنوعی لبه ویندوز، مهارت‌های ضروری برای ساخت برنامه‌های هوش مصنوعی آماده تولید در پلتفرم ویندوز را فرا خواهید گرفت.

### مهارت‌های فنی اصلی

**تسلط بر Windows AI Foundry**
- درک معماری و اجزای پلتفرم Windows AI Foundry
- هدایت چرخه کامل توسعه هوش مصنوعی در اکوسیستم ویندوز
- اجرای بهترین روش‌های امنیتی برای برنامه‌های هوش مصنوعی در دستگاه
- بهینه‌سازی برنامه‌ها برای پیکربندی‌های مختلف سخت‌افزاری ویندوز

**تخصص در یکپارچه‌سازی API**
- تسلط بر APIهای Windows AI برای برنامه‌های متنی، بینایی و چندرسانه‌ای
- پیاده‌سازی یکپارچه‌سازی مدل زبان Phi Silica برای تولید متن و استدلال
- به‌کارگیری قابلیت‌های بینایی کامپیوتری با استفاده از APIهای پردازش تصویر داخلی
- سفارشی‌سازی مدل‌های پیش‌آموزش دیده با تکنیک‌های LoRA (سازگاری با رتبه پایین)

**اجرای Foundry Local**
- مرور، ارزیابی و استقرار مدل‌های زبان متن‌باز با استفاده از Foundry Local CLI
- درک بهینه‌سازی مدل و کمیت‌بندی برای استقرار محلی
- پیاده‌سازی قابلیت‌های هوش مصنوعی آفلاین که بدون اتصال اینترنت عمل می‌کنند
- مدیریت چرخه عمر مدل‌ها و به‌روزرسانی‌ها در محیط‌های تولید

**استقرار Windows ML**
- انتقال مدل‌های سفارشی ONNX به برنامه‌های ویندوز با استفاده از Windows ML
- بهره‌گیری از تسریع سخت‌افزاری خودکار در معماری‌های CPU، GPU و NPU
- اجرای استنتاج بلادرنگ با استفاده بهینه از منابع
- طراحی برنامه‌های هوش مصنوعی مقیاس‌پذیر برای دسته‌های مختلف دستگاه‌های ویندوز

### مهارت‌های توسعه برنامه

**توسعه ویندوز چندسکویی**
- ساخت برنامه‌های مجهز به هوش مصنوعی با استفاده از .NET MAUI برای استقرار جهانی ویندوز
- ادغام قابلیت‌های هوش مصنوعی در برنامه‌های Win32، UWP و برنامه‌های وب پیش‌رونده
- پیاده‌سازی طراحی‌های رابط کاربری پاسخگو که به وضعیت پردازش هوش مصنوعی سازگار می‌شوند
- مدیریت عملیات هوش مصنوعی ناهمزمان با الگوهای تجربه کاربری مناسب

**بهینه‌سازی عملکرد**
- پروفایل و بهینه‌سازی عملکرد استنتاج هوش مصنوعی در پیکربندی‌های مختلف سخت‌افزاری
- پیاده‌سازی مدیریت حافظه کارآمد برای مدل‌های زبان بزرگ
- طراحی برنامه‌هایی که بر اساس توانایی‌های سخت‌افزاری موجود به‌صورت تدریجی تنزل می‌کنند
- پیاده‌سازی استراتژی‌های کش برای عملیات متداول هوش مصنوعی

**آمادگی برای تولید**
- اجرای مدیریت جامع خطاها و مکانیزم‌های پشتیبان
- طراحی تله‌متری و نظارت برای عملکرد برنامه هوش مصنوعی
- بهره‌گیری از بهترین شیوه‌های امنیتی برای ذخیره و اجرای مدل‌های هوش مصنوعی محلی
- برنامه‌ریزی استراتژی‌های استقرار برای برنامه‌های سازمانی و مصرف‌کننده

### درک تجاری و استراتژیک

**معماری برنامه هوش مصنوعی**
- طراحی معماری‌های هیبریدی که بین پردازش محلی و ابری هوش مصنوعی بهینه می‌شوند
- ارزیابی معادلات بین اندازه مدل، دقت و سرعت استنتاج
- برنامه‌ریزی معماری جریان داده که حریم خصوصی را حفظ کرده و در عین حال هوشمندی را فعال می‌کند
- پیاده‌سازی راه‌حل‌های هوش مصنوعی مقرون‌به‌صرفه که با نیازهای کاربران مقیاس‌پذیر هستند

**موقعیت‌یابی در بازار**
- درک مزیت‌های رقابتی برنامه‌های هوش مصنوعی بومی ویندوز
- شناسایی موارد استفاده که هوش مصنوعی در دستگاه تجربه‌های کاربری برتر ارائه می‌دهد
- توسعه استراتژی‌های ورود به بازار برای برنامه‌های ویندوز مجهز به هوش مصنوعی
- موقعیت‌یابی برنامه‌ها برای بهره‌برداری از مزایای اکوسیستم ویندوز

### جریان کاری رایج نمونه‌ها

بیشتر نمونه‌های Windows ML الگوی استاندارد زیر را دنبال می‌کنند:

1. **راه‌اندازی محیط** - ایجاد محیط اجرای ONNX
2. **ثبت تامین‌کنندگان اجرا** - کشف و ثبت شتاب‌دهنده‌های سخت‌افزاری موجود (CPU، GPU، NPU)
3. **بارگذاری مدل** - بارگذاری مدل ONNX، در صورت نیاز کامپایل برای سخت‌افزار هدف
4. **پیش‌پردازش ورودی** - تبدیل تصاویر/داده‌ها به فرمت ورودی مدل
5. **اجرای استنتاج** - اجرای مدل و دریافت پیش‌بینی‌ها
6. **پردازش نتایج** - اعمال نرم‌افزار (softmax) و نمایش بهترین پیش‌بینی‌ها

### پشتیبانی سخت‌افزاری

همه نمونه‌ها به‌طور خودکار سخت‌افزار موجود را شناسایی و استفاده می‌کنند:
- **CPU** - پشتیبانی جهانی در تمام دستگاه‌های ویندوز
- **GPU** - شناسایی و بهینه‌سازی خودکار برای سخت‌افزار گرافیکی موجود
- **NPU** - استفاده از واحدهای پردازش عصبی در دستگاه‌های پشتیبانی شده (رایانه‌های شخصی Copilot+)

## اجزای پلتفرم Windows AI Foundry

### 1. APIهای Windows AI

APIهای Windows AI قابلیت‌های هوش مصنوعی آماده استفاده را ارائه می‌دهند که توسط مدل‌های درون دستگاه پشتیبانی شده‌اند، برای بهینه‌سازی کارایی و عملکرد در دستگاه‌های رایانه شخصی Copilot+ با حداقل نیاز به راه‌اندازی بهینه شده‌اند.

#### دسته‌بندی‌های اصلی API

**مدل زبان Phi Silica**
- مدل زبان کوچک اما قدرتمند برای تولید متن و استدلال
- بهینه‌سازی شده برای استنتاج بلادرنگ با مصرف کم انرژی
- پشتیبانی از تنظیم دقیق سفارشی با استفاده از تکنیک‌های LoRA
- یکپارچه‌سازی با جستجوی معنایی ویندوز و بازیابی دانش

**APIهای بینایی کامپیوتری**
- **تشخیص متن (OCR)**: استخراج متن از تصاویر با دقت بالا
- **رزولوشن تصویر عالی**: ارتقاء تصاویر با استفاده از مدل‌های هوش مصنوعی محلی
- **بخش‌بندی تصویر**: شناسایی و جداسازی اشیاء خاص در تصاویر
- **توصیف تصویر**: تولید توضیحات متنی دقیق برای محتوای بصری
- **حذف شیء**: حذف اشیاء ناخواسته از تصاویر با نقاشی هوش مصنوعی

**قابلیت‌های چندرسانه‌ای**
- **ادغام دید و زبان**: ترکیب فهم متن و تصویر
- **جستجوی معنایی**: فعال‌سازی پرس‌وجوهای زبان طبیعی در میان محتوای چندرسانه‌ای
- **بازیابی دانش**: ساخت تجربه‌های جستجوی هوشمند با داده‌های محلی

### 2. Foundry Local

Foundry Local به توسعه‌دهندگان دسترسی سریع به مدل‌های زبان متن‌باز آماده برای استفاده روی سیلیکون ویندوز را عرضه می‌کند و امکان مرور، آزمایش، تعامل و استقرار مدل‌ها در برنامه‌های محلی فراهم می‌سازد.

#### نمونه‌های برنامه Foundry Local

مخزن [Foundry Local](https://github.com/microsoft/Foundry-Local/tree/main/samples) نمونه‌های جامعی را در زبان‌ها و فریم‌ورک‌های مختلف ارائه می‌دهد که الگوهای مختلف ادغام و موارد استفاده را نشان می‌دهند.

#### دسته‌بندی نمونه‌ها بر اساس مورد استفاده

**RAG (تولید تقویت‌شده با بازیابی)**
- **dotNET/rag**: پیاده‌سازی کامل RAG با استفاده از Semantic Kernel، پایگاه داده برداری Qdrant و جاسازی‌های JINA
- **معماری**: دریافت اسناد → شکستن متن → جاسازی‌های برداری → جستجوی شباهت → پاسخ‌های توجه‌دار به متن زمینه
- **فناوری‌ها**: Microsoft.SemanticKernel، Qdrant.Client، جاسازی‌های BERT ONNX، گفتگو با تکمیل استریمینگ

**برنامه‌های دسکتاپ**
- **electron/foundry-chat**: برنامه چت آماده تولید با تغییر مدل محلی/ابری
- **ویژگی‌ها**: انتخابگر مدل، پاسخ‌های استریم شده، مدیریت خطا، استقرار چندسکویی
- **معماری**: فرایند اصلی Electron، ارتباط IPC، اسکریپت‌های preload ایمن

**نمونه‌های ادغام SDK**
- **JavaScript (Node.js)**: تعامل پایه با مدل و پاسخ‌های استریم شده
- **Python**: استفاده از API سازگار با OpenAI با استریمینگ ناهمزمان
- **Rust**: ادغام در سطح پایین با reqwest و tokio برای عملیات ناهمزمان

#### تنظیمات اختصاصی نمونه‌ها

# تنظیم متغیرهای محیطی برای بازگشت به ابر

$env:YOUR_ENDPOINT="your-cloud-endpoint"

npm install

### ۳. Windows ML

Windows ML به عنوان پلتفرم اصلی هوش مصنوعی و زمان‌اجرای استنتاج ادغام‌شده روی ویندوز عمل می‌کند و به توسعه‌دهندگان امکان می‌دهد مدل‌های سفارشی را به‌صورت مؤثر در سراسر اکوسیستم سخت‌افزاری گسترده ویندوز مستقر کنند.

#### مزایای معماری

**پشتیبانی سخت‌افزاری جهانی**
- بهینه‌سازی خودکار برای سیلیکون‌های AMD، Intel، NVIDIA و Qualcomm

- انتزاع سخت‌افزار که کار بهینه‌سازی ویژه پلتفرم را حذف می‌کند

**انعطاف‌پذیری مدل**
- پشتیبانی از فرمت مدل ONNX با تبدیل خودکار از چارچوب‌های محبوب
- استقرار مدل سفارشی با عملکرد درجه تولید
- ادغام با معماری‌های موجود برنامه‌های ویندوز

**ادغام سازمانی**
- سازگار با چارچوب‌های امنیتی و تطابق ویندوز
- پشتیبانی از ابزارهای استقرار و مدیریت سازمانی
- ادغام با سیستم‌های مدیریت و نظارت دستگاه ویندوز

- اعتبارسنجی اینکه ابزارهای ساخت نسخه چارچوب موردنظر را پشتیبانی کنند

**مسائل بارگذاری مدل**
- اعتبارسنجی سازگاری مدل ONNX با Windows ML
- بررسی صحت فایل مدل و نیازمندی‌های فرمت
- اطمینان از سازگاری سخت‌افزاری مورد نیاز برای مدل‌های خاص
- عیب‌یابی مشکلات تخصیص حافظه هنگام بارگذاری مدل
- اطمینان از ثبت ارائه‌دهنده اجرا برای تسریع سخت‌افزار

**ملاحظات حالت استقرار**
- **حالت خودمحتوا**: کاملاً پشتیبانی شده با اندازه استقرار بزرگ‌تر
- **حالت متکی به چارچوب**: ردپای کوچکتر ولی نیازمند زمان اجرای مشترک
- **برنامه‌های بسته‌بندی نشده**: دیگر برای API های Windows AI پشتیبانی نمی‌شود
- استفاده از `dotnet run -p:Platform=ARM64 -p:SelfContained=true` برای استقرار خودمحتوای ARM64

**مسائل عملکرد**
- پروفایل‌گیری عملکرد برنامه در پیکربندی‌های سخت‌افزاری مختلف
- شناسایی گلوگاه‌ها در خطوط پردازش AI
- بهینه‌سازی عملیات پیش‌پردازش و پس‌پردازش داده‌ها
- پیاده‌سازی نظارت عملکرد و هشداردهی

**مشکلات ادغام**
- عیب‌یابی مشکلات ادغام API با مدیریت مناسب خطا
- اعتبارسنجی قالب‌های داده ورودی و نیازهای پیش‌پردازش
- آزمایش دقیق شرایط مرزی و خطاها
- پیاده‌سازی ثبت وقایع جامع برای عیب‌یابی مشکلات تولید

### ابزارها و تکنیک‌های دیباگ

**ادغام Visual Studio**
- استفاده از دیباگر AI Toolkit برای تحلیل اجرای مدل
- پیاده‌سازی پروفایلینگ عملکرد برای عملیات AI
- دیباگ عملیات ناهمزمان AI با مدیریت استثنا مناسب
- استفاده از ابزارهای پروفایل حافظه برای بهینه‌سازی

**ابزارهای Windows AI Foundry**
- بهره‌برداری از Foundry Local CLI برای تست و اعتبارسنجی مدل
- استفاده از ابزارهای تست API های Windows AI برای تأیید ادغام
- پیاده‌سازی ثبت وقایع سفارشی برای نظارت بر عملیات AI
- ایجاد تست‌های خودکار برای اطمینان از قابلیت اطمینان AI

## آینده‌نگری در برنامه‌های شما

### فناوری‌های نوظهور

**سخت‌افزار نسل بعدی**
- طراحی برنامه‌ها برای بهره‌گیری از قابلیت‌های NPU آینده
- برنامه‌ریزی برای افزایش اندازه و پیچیدگی مدل‌ها
- پیاده‌سازی معماری‌های تطبیقی برای سخت‌افزار در حال تحول
- ملاحظه الگوریتم‌های آماده کوانتومی برای سازگاری آینده

**قابلیت‌های پیشرفته AI**
- آماده‌سازی برای ادغام AI چند حالته در داده‌های بیشتر
- برنامه‌ریزی برای همکاری AI در زمان واقعی بین چند دستگاه
- طراحی برای قابلیت‌های یادگیری همگانی
- ملاحظه معماری‌های هوش هیبریدی لبه-ابر

### یادگیری و سازگاری مداوم

**به‌روزرسانی مدل‌ها**
- پیاده‌سازی مکانیزم‌های به‌روزرسانی بی‌وقفه مدل
- طراحی برنامه‌ها برای سازگار شدن با قابلیت‌های بهبود یافته مدل
- برنامه‌ریزی برای سازگاری برگشتی با مدل‌های موجود
- پیاده‌سازی تست A/B برای ارزیابی عملکرد مدل

**تکامل ویژگی‌ها**
- طراحی معماری‌های مدولار که قابلیت‌های جدید AI را بپذیرند
- برنامه‌ریزی برای ادغام API های نوظهور ویندوز AI
- پیاده‌سازی پرچم‌های ویژگی برای انتشار تدریجی قابلیت‌ها
- طراحی رابط‌های کاربری که به ویژگی‌های پیشرفته AI تطبیق یابند

## نتیجه‌گیری

توسعه Windows Edge AI نمایانگر همگرایی قابلیت‌های قدرتمند AI با پلتفرم ویندوز قوی، ایمن و مقیاس‌پذیر است. با تسلط بر اکوسیستم Windows AI Foundry، توسعه‌دهندگان می‌توانند برنامه‌های هوشمندی ایجاد کنند که تجربه‌های استثنایی کاربری فراهم می‌آورند و در عین حال بالاترین استانداردهای حریم خصوصی، امنیت و عملکرد را حفظ می‌کنند.

ترکیب API های Windows AI، Foundry Local، و Windows ML پایه‌ای بی‌نظیر برای ساخت نسل بعدی برنامه‌های هوشمند ویندوز فراهم می‌کند. با ادامه پیشرفت AI، پلتفرم ویندوز تضمین می‌کند که برنامه‌های شما با فناوری‌های نوظهور مقیاس می‌یابند و در عین حال سازگاری و عملکرد در سراسر اکوسیستم متنوع سخت‌افزار ویندوز حفظ شود.

چه در حال ساخت برنامه‌های مصرفی، راه‌حل‌های سازمانی یا ابزارهای تخصصی صنعتی باشید، توسعه Windows Edge AI شما را قادر می‌سازد تجربه‌های هوشمند، پاسخگو و عمیقاً یکپارچه‌شده‌ای ایجاد کنید که از تمامی پتانسیل دستگاه‌های مدرن ویندوز بهره‌مند شوند.
