# بخش ۲: استقرار محیط محلی - راهکارهای حفظ حریم خصوصی

استقرار محلی مدل‌های زبان کوچک (SLM) نمایانگر یک تغییر پارادایم به سمت راهکارهای هوش مصنوعی حفظ‌کننده حریم خصوصی و مقرون‌به‌صرفه است. این راهنمای جامع دو چارچوب قدرتمند — Ollama و Microsoft Foundry Local — را بررسی می‌کند که به توسعه‌دهندگان امکان بهره‌برداری کامل از قابلیت‌های SLM را در حالی که کنترل کامل بر محیط استقرار خود دارند، می‌دهد.

## مقدمه

در این درس، استراتژی‌های پیشرفته استقرار مدل‌های زبان کوچک در محیط‌های محلی را بررسی خواهیم کرد. مفاهیم پایه استقرار هوش مصنوعی محلی را پوشش داده، دو پلتفرم پیشرو (Ollama و Microsoft Foundry Local) را بررسی کرده و راهنمایی‌های عملی برای پیاده‌سازی آماده تولید ارائه می‌دهیم.

## اهداف یادگیری

تا پایان این درس، قادر خواهید بود:

- معماری و مزایای چارچوب‌های استقرار محلی مدل‌های زبان کوچک را درک کنید.
- استقرارهای آماده تولید را با استفاده از Ollama و Microsoft Foundry Local پیاده‌سازی کنید.
- پلتفرم مناسب را بر اساس نیازها و محدودیت‌های خاص مقایسه و انتخاب کنید.
- استقرارهای محلی را برای عملکرد، امنیت و مقیاس‌پذیری بهینه کنید.

## درک معماری‌های استقرار محلی SLM

استقرار محلی SLM نمایانگر تغییر بنیادین از خدمات هوش مصنوعی وابسته به ابر به راهکارهای در محل، حفظ‌کننده حریم خصوصی است. این رویکرد به سازمان‌ها امکان می‌دهد کنترل کامل بر زیرساخت هوش مصنوعی خود را حفظ کرده و همزمان حاکمیت داده‌ها و استقلال عملیاتی را تضمین کنند.

### طبقه‌بندی چارچوب‌های استقرار

درک رویکردهای مختلف استقرار به انتخاب استراتژی مناسب برای موارد استفاده خاص کمک می‌کند:

- **متمرکز بر توسعه**: راه‌اندازی ساده برای آزمایش و نمونه‌سازی
- **سطح سازمانی**: راهکارهای آماده تولید با قابلیت ادغام سازمانی  
- **چند پلتفرمی**: سازگاری جهانی در سیستم‌عامل‌ها و سخت‌افزارهای مختلف

### مزایای کلیدی استقرار محلی SLM

استقرار محلی SLM چند مزیت بنیادین ارائه می‌دهد که آن را برای کاربردهای سازمانی و حساس به حریم خصوصی ایده‌آل می‌سازد:

**حریم خصوصی و امنیت**: پردازش محلی تضمین می‌کند داده‌های حساس هرگز از زیرساخت سازمان خارج نمی‌شوند و انطباق با GDPR، HIPAA و سایر مقررات را فراهم می‌کند. استقرارهای ایزوله برای محیط‌های طبقه‌بندی شده ممکن است، در حالی که سوابق کامل حسابرسی نظارت امنیتی را حفظ می‌کنند.

**صرفه‌جویی در هزینه**: حذف مدل‌های قیمت‌گذاری بر اساس هر توکن به طور چشمگیری هزینه‌های عملیاتی را کاهش می‌دهد. نیازهای پهنای باند کمتر و وابستگی کمتر به ابر ساختار هزینه قابل پیش‌بینی برای بودجه‌بندی سازمانی ارائه می‌کند.

**عملکرد و قابلیت اطمینان**: زمان‌های تفسیر سریع‌تر بدون تأخیر شبکه برنامه‌های زمان واقعی را ممکن می‌سازد. عملکرد آفلاین تضمین می‌کند که عملیات بدون وابستگی به اتصال اینترنت ادامه یابد، در حالی که بهینه‌سازی منابع محلی عملکردی پایدار فراهم می‌کند.

## Ollama: پلتفرم استقرار محلی جهانی

### معماری اصلی و فلسفه

Ollama به عنوان یک پلتفرم جهانی و کاربرپسند برای توسعه‌دهندگان طراحی شده است که استقرار LLM محلی را در تنظیمات سخت‌افزاری و سیستم‌عامل‌های متنوع دمکراتیک می‌کند.

**پایه فنی**: ساخته شده بر اساس چارچوب قدرتمند llama.cpp، Ollama از فرمت مدل بهینه GGUF برای عملکرد بهینه استفاده می‌کند. سازگاری چند پلتفرمی رفتار یکسان را در محیط‌های Windows، macOS و Linux تضمین می‌کند، در حالی که مدیریت هوشمند منابع بهینه‌سازی استفاده از CPU، GPU و حافظه را فراهم می‌آورد.

**فلسفه طراحی**: Ollama سادگی را بدون قربانی کردن عملکرد در اولویت قرار می‌دهد و استقرار بدون نیاز به پیکربندی را برای بهره‌وری فوری ارائه می‌کند. این پلتفرم سازگاری مدل گسترده را حفظ می‌کند و APIهای یکسان را در معماری‌های مختلف مدل ارائه می‌دهد.

### ویژگی‌ها و قابلیت‌های پیشرفته

**برتری مدیریت مدل**: Ollama چرخه عمر مدیریت مدل را با کشیدن خودکار، ذخیره‌سازی موقت و نسخه‌بندی ارائه می‌دهد. پلتفرم از اکوسیستم مدل گسترده‌ای شامل Llama 3.2، Google Gemma 2، Microsoft Phi-4، Qwen 2.5، DeepSeek، Mistral و مدل‌های جاسازی تخصصی پشتیبانی می‌کند.

**سفارشی‌سازی از طریق فایل‌های مدل**: کاربران پیشرفته می‌توانند پیکربندی‌های مدل سفارشی با پارامترهای خاص، فرمان‌های سیستم و تغییرات رفتار ایجاد کنند. این امکان بهینه‌سازی‌های حوزه‌ای و نیازهای کاربردی تخصصی را فراهم می‌سازد.

**بهینه‌سازی عملکرد**: Ollama به طور خودکار شتاب سخت‌افزاری در دسترس از جمله NVIDIA CUDA، Apple Metal و OpenCL را شناسایی و استفاده می‌کند. مدیریت هوشمند حافظه استفاده بهینه از منابع را در تنظیمات سخت‌افزاری مختلف تضمین می‌کند.

### استراتژی‌های پیاده‌سازی تولید

**نصب و راه‌اندازی**: Ollama نصب ساده را در تمام پلتفرم‌ها از طریق نصاب‌های بومی، مدیریت بسته‌ها (WinGet، Homebrew، APT) و کانتینرهای Docker برای استقرار کانتینری فراهم می‌آورد.

```bash

# ویندوز (WinGet)
winget install Ollama.Ollama

# مک‌اواس (Homebrew)
brew install ollama

# لینوکس (curl)
curl -fsSL https://ollama.com/install.sh | sh

# استقرار داکر
docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama
```

**دستورات و عملیات اساسی**:


### نمونه‌های ادغام توسعه‌دهنده

**ادغام API پایتون**:

```python
import requests
import json

# پیکربندی نقطه پایانی API
OLLAMA_ENDPOINT = "http://localhost:11434/api/generate"

# پارامترهای مدل
params = {
    "model": "phi4:mini",
    "prompt": "Write a function to calculate the Fibonacci sequence in Python",
    "system": "You are a helpful Python programming assistant. Provide clean, efficient code with comments.",
    "stream": False,
    "options": {
        "temperature": 0.2,
        "top_p": 0.95,
        "num_predict": 1024
    }
}

# ارسال درخواست API
response = requests.post(OLLAMA_ENDPOINT, json=params)
result = response.json()

# پردازش و نمایش پاسخ
print(result["response"])

# نمونه‌ی پخش زنده (برای پاسخ‌های زمان واقعی)
def stream_response():
    params["stream"] = True
    response = requests.post(OLLAMA_ENDPOINT, json=params, stream=True)
    
    for line in response.iter_lines():
        if line:
            chunk = json.loads(line)
            if "response" in chunk:
                print(chunk["response"], end="", flush=True)
            if chunk.get("done", False):
                print()
                break

# stream_response()  # برای اجرای نمونه پخش زنده این خط را از حالت کامنت خارج کنید
```

**ادغام جاوااسکریپت/تایپ‌اسکریپت (Node.js)**:

```javascript
const axios = require('axios');

// پیکربندی API
const OLLAMA_API = 'http://localhost:11434/api';

// تابعی برای تولید متن با Ollama
async function generateText(model, prompt, systemPrompt = '') {
  try {
    const response = await axios.post(`${OLLAMA_API}/generate`, {
      model: model,
      prompt: prompt,
      system: systemPrompt,
      stream: false,
      options: {
        temperature: 0.7,
        top_k: 40,
        top_p: 0.9,
        num_predict: 1024
      }
    });
    
    return response.data.response;
  } catch (error) {
    console.error('Error generating text:', error.message);
    throw error;
  }
}

// نمونه استفاده در یک API اکسپرس
const express = require('express');
const app = express();
app.use(express.json());

app.post('/api/chat', async (req, res) => {
  const { message } = req.body;
  
  try {
    const response = await generateText(
      'phi4:mini',
      message,
      'You are a helpful AI assistant.'
    );
    
    res.json({ response });
  } catch (error) {
    res.status(500).json({ error: 'Failed to generate response' });
  }
});

app.listen(3000, () => {
  console.log('API server running on port 3000');
});
```

## Microsoft Foundry Local: پلتفرم هوش مصنوعی لبه سازمانی

### معماری سطح سازمانی

Microsoft Foundry Local یک راهکار جامع سازمانی است که به طور خاص برای استقرارهای تولیدی هوش مصنوعی لبه با ادغام عمیق در اکوسیستم مایکروسافت طراحی شده است.

**پایه مبتنی بر ONNX**: ساخته شده بر مبنای استاندارد صنعتی ONNX Runtime، Foundry Local عملکرد بهینه‌ای را در ساختارهای سخت‌افزاری متنوع ارائه می‌دهد. پلتفرم از ادغام Windows ML برای بهینه‌سازی بومی ویندوز بهره می‌برد و در عین حال سازگاری چندپلتفرمی را حفظ می‌کند.

**عالی بودن شتاب سخت‌افزاری**: Foundry Local شناسایی هوشمند سخت‌افزار و بهینه‌سازی در CPUها، GPUها و NPUها را ارائه می‌دهد. همکاری عمیق با فروشندگان سخت‌افزار (AMD، Intel، NVIDIA، Qualcomm) عملکرد بهینه را روی تنظیمات سخت‌افزاری سازمانی تضمین می‌کند.

### تجربه پیشرفته توسعه‌دهنده

**دسترسی چندرابطه‌ای**: Foundry Local رابط‌های توسعه گسترده‌ای از جمله خط فرمان قدرتمند برای مدیریت و استقرار مدل، SDKهای چندزبانه (Python, NodeJS) برای ادغام بومی، و APIهای RESTful با سازگاری OpenAI برای مهاجرت یکپارچه ارائه می‌کند.

**ادغام با Visual Studio**: این پلتفرم به طور بی‌وقفه با ابزار AI Toolkit برای VS Code ادغام شده و ابزارهای تبدیل، کوانتیزاسیون و بهینه‌سازی مدل را در محیط توسعه ارائه می‌دهد. این ادغام گردش‌های کاری توسعه را تسریع و پیچیدگی استقرار را کاهش می‌دهد.

**خط تولید بهینه‌سازی مدل**: ادغام Microsoft Olive گردش‌های کاری پیشرفته بهینه‌سازی مدل شامل کوانتیزاسیون دینامیک، بهینه‌سازی گراف و تنظیم تخصصی برای سخت‌افزار را ممکن می‌کند. قابلیت تبدیل ابری از طریق Azure ML به بهینه‌سازی مقیاس‌پذیر برای مدل‌های بزرگ کمک می‌کند.

### ادغام اکوسیستم سازمانی

**امنیت و انطباق**: Foundry Local ویژگی‌های امنیتی سازمانی شامل کنترل دسترسی مبتنی بر نقش، ثبت گزارش‌های حسابرسی، گزارش‌دهی انطباق و ذخیره امن مدل را ارائه می‌دهد. ادغام با زیرساخت امنیتی مایکروسافت رعایت سیاست‌های امنیتی سازمانی را تضمین می‌کند.

**خدمات هوش مصنوعی تعبیه‌شده**: این پلتفرم قابلیت‌های آماده استفاده‌ای نظیر Phi Silica برای پردازش محلی زبان، AI Imaging برای بهبود و تحلیل تصویر، و APIهای تخصصی برای وظایف متداول هوش مصنوعی سازمانی ارائه می‌دهد.

## تحلیل مقایسه‌ای: Ollama در مقابل Foundry Local

### مقایسه معماری فنی

| **جنبه** | **Ollama** | **Foundry Local** |
|------------|------------|-------------------|
| **فرمت مدل** | GGUF (از طریق llama.cpp) | ONNX (از طریق ONNX Runtime) |
| **تمرکز پلتفرم** | جهانی چندپلتفرمی | بهینه‌سازی ویندوز/ سازمانی |
| **ادغام سخت‌افزار** | پشتیبانی GPU/CPU عمومی | ادغام عمیق Windows ML و NPU |
| **بهینه‌سازی** | کوانتیزاسیون llama.cpp | Microsoft Olive + ONNX Runtime |
| **ویژگی‌های سازمانی** | محوریت جامعه | سطح سازمانی با توافق‌نامه‌های SLA |

### ویژگی‌های عملکرد

**نقاط قوت عملکرد Ollama**:
- عملکرد استثنایی CPU از طریق بهینه‌سازی llama.cpp
- رفتار سازگار در پلتفرم‌ها و سخت‌افزارهای مختلف
- استفاده بهینه از حافظه با بارگذاری هوشمند مدل
- زمان‌های راه‌اندازی سرد سریع برای توسعه و تست

**مزایای عملکرد Foundry Local**:
- استفاده بهتر از NPU در سخت‌افزارهای مدرن ویندوز
- شتاب GPU بهینه شده از طریق همکاری با فروشندگان
- نظارت و بهینه‌سازی عملکرد سطح سازمانی
- قابلیت استقرار مقیاس‌پذیر برای محیط‌های تولید

### تحلیل تجربه توسعه

**تجربه توسعه‌دهنده Ollama**:
- حداقل نیازهای راه‌اندازی با بهره‌وری فوری
- رابط خط فرمان شهودی برای تمام عملیات
- پشتیبانی گسترده جامعه و مستندسازی
- سفارشی‌سازی انعطاف‌پذیر از طریق فایل‌های مدل

**تجربه توسعه‌دهنده Foundry Local**:
- ادغام کامل IDE با اکوسیستم Visual Studio
- گردش‌های کاری توسعه سازمانی با ویژگی‌های همکاری تیمی
- کانال‌های پشتیبانی حرفه‌ای با پشتیبانی مایکروسافت
- ابزارهای پیشرفته دیباگ و بهینه‌سازی

### بهینه‌سازی مورد استفاده

**وقتی Ollama را انتخاب کنید**:
- توسعه برنامه‌های چندپلتفرمی که به رفتار سازگار نیاز دارند
- اولویت دادن به شفافیت منبع‌باز و مشارکت جامعه
- کار با منابع یا محدودیت‌های بودجه‌ای محدود
- ساخت برنامه‌های پژوهشی یا آزمایشی
- نیاز به سازگاری مدل گسترده در معماری‌های مختلف

**وقتی Foundry Local را انتخاب کنید**:
- استقرار برنامه‌های سازمانی با الزامات عملکرد سختگیرانه
- بهره‌گیری از بهینه‌سازی سخت‌افزار اختصاصی ویندوز (NPU، Windows ML)
- نیاز به پشتیبانی سازمانی، SLA و ویژگی‌های انطباق
- ساخت برنامه‌های تولیدی با ادغام در اکوسیستم مایکروسافت
- نیاز به ابزارهای بهینه‌سازی پیشرفته و گردش‌های کاری توسعه حرفه‌ای

## استراتژی‌های پیشرفته استقرار

### الگوهای استقرار کانتینری

**کانتینریزه کردن Ollama**:

```dockerfile
FROM ollama/ollama:latest

# Pre-load models for faster startup
RUN ollama pull qwen2.5:3b
RUN ollama pull phi4:mini

# Custom configuration
COPY modelfile ./
RUN ollama create enterprise-model -f modelfile

# Expose API port
EXPOSE 11434

# Health check
HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
  CMD curl -f http://localhost:11434/api/health || exit 1
```

**استقرار سازمانی Foundry Local**:

```yaml
apiVersion: apps/v1
kind: Deployment

      app: foundry-local

    spec:

      - name: foundry-local
```

## روندها و ملاحظات آینده

### فناوری‌های نوظهور

چشم‌انداز استقرار محلی SLM با چند روند کلیدی در حال تحول است:

**معماری‌های مدل پیشرفته**: نسل بعدی SLMها با بهره‌وری و نسبت قابلیت بهبود یافته پدیدار می‌شوند، از جمله مدل‌های ترکیبی کارشناس برای مقیاس‌بندی پویا و معماری‌های تخصصی برای استقرار لبه.

**ادغام سخت‌افزار**: ادغام عمیق‌تر با سخت‌افزار تخصصی هوش مصنوعی شامل NPUها، سیلیکون سفارشی و شتاب‌دهنده‌های محاسبات لبه عملکردهای بهبود یافته را فراهم می‌کند.

**تحولات اکوسیستم**: تلاش‌های استانداردسازی در پلتفرم‌های استقرار و بهبود تعامل‌پذیری بین چارچوب‌های مختلف استقرار چندپلتفرمی را ساده‌تر خواهد کرد.

### الگوهای پذیرش صنعتی

**پذیرش سازمانی**: پذیرش سازمانی با نیازهای حفظ حریم خصوصی، بهینه‌سازی هزینه و الزامات انطباق افزایش یافته است. بخش‌های دولت و دفاع به ویژه بر استقرارهای ایزوله تمرکز دارند.

**ملاحظات جهانی**: الزامات حاکمیت داده‌های بین‌المللی پذیرش استقرار محلی به ویژه در مناطق با مقررات سختگیرانه محافظت داده را هدایت می‌کنند.

## چالش‌ها و ملاحظات

### چالش‌های فنی

**نیازمندی‌های زیرساختی**: استقرار محلی به برنامه‌ریزی دقیق ظرفیت و انتخاب سخت‌افزار نیاز دارد. سازمان‌ها باید بین نیازهای عملکردی و محدودیت‌های هزینه تعادل برقرار کنند و در عین حال مقیاس‌پذیری برای بارهای کاری در حال رشد تضمین شود.

**🔧 نگهداری و به‌روزرسانی‌ها**: به‌روزرسانی‌های منظم مدل، وصله‌های امنیتی و بهینه‌سازی عملکرد نیازمند منابع و تخصص اختصاصی است. خطوط تولید استقرار خودکار برای محیط‌های تولید ضروری می‌شوند.

### ملاحظات امنیتی

**امنیت مدل**: حفاظت از مدل‌های اختصاصی در برابر دسترسی یا استخراج غیرمجاز نیازمند اقدامات امنیتی جامع از جمله رمزگذاری، کنترل دسترسی و ثبت گزارش‌های حسابرسی است.

**حفاظت داده‌ها**: تضمین مدیریت امن داده‌ها در طول خط لوله استنباط در حالی که استانداردهای عملکرد و قابلیت استفاده حفظ می‌شوند.

## نتیجه‌گیری

انتخاب بین Ollama و Microsoft Foundry Local بستگی به نیازهای خاص سازمانی، محدودیت‌های فنی و اهداف راهبردی دارد. هر دو پلتفرم مزایای جذابی برای استقرار محلی SLM ارائه می‌دهند، به طوری که Ollama در سازگاری چندپلتفرمی و سهولت استفاده برتری دارد، در حالی که Foundry Local بهینه‌سازی سطح سازمانی و ادغام در اکوسیستم مایکروسافت را فراهم می‌کند.

آینده استقرار هوش مصنوعی در رویکردهای ترکیبی است که مزایای پردازش محلی را با قابلیت‌های ابری ترکیب می‌کنند. سازمان‌هایی که استقرار محلی SLM را به خوبی مدیریت کنند، در استفاده از فناوری‌های هوش مصنوعی در حالی که کنترل بر داده‌ها و زیرساخت خود را حفظ می‌کنند، موقعیت برتری خواهند داشت.

موفقیت در استقرار محلی SLM نیازمند توجه دقیق به نیازهای فنی، ملاحظات امنیتی و روندهای عملیاتی است. با پیروی از بهترین شیوه‌ها و بهره‌گیری از نقاط قوت این پلتفرم‌ها، سازمان‌ها می‌توانند راهکارهای هوش مصنوعی قدرتمند، مقیاس‌پذیر و امن بسازند که نیازها و محدودیت‌های خاص آن‌ها را برآورده می‌کنند.
