## فراخوانی تابع چیست؟

فراخوانی تابع قابلیتی قدرتمند است که به مدل‌های زبانی کوچک (SLMs) اجازه می‌دهد با ابزارها، APIها و سرویس‌های خارجی تعامل داشته باشند. به جای اینکه محدود به داده‌های آموزشی خود باشند، SLMها اکنون می‌توانند:

- **اتصال به APIهای خارجی** (سرویس‌های آب و هوا، پایگاه‌های داده، موتورهای جستجو)
- **اجرای توابع مشخص** بر اساس درخواست‌های کاربر
- **دریافت اطلاعات بلادرنگ** از منابع مختلف
- **انجام وظایف محاسباتی** از طریق ابزارهای تخصصی
- **زنجیره‌ای کردن عملیات متعدد** برای جریان‌های کاری پیچیده

این قابلیت، SLMها را از تولیدکنندگان متنی ایستا به عامل‌های هوش مصنوعی پویا تبدیل می‌کند که می‌توانند وظایف دنیای واقعی را انجام دهند.

## چگونه فراخوانی تابع کار می‌کند

فرایند فراخوانی تابع یک جریان کاری سیستماتیک را دنبال می‌کند:

### ۱. ادغام ابزار
- **ابزارهای خارجی**: SLMها می‌توانند به APIهای آب و هوا، پایگاه‌های داده، سرویس‌های وب و سایر سیستم‌های خارجی متصل شوند
- **تعریف توابع**: هر ابزار با پارامترها، فرمت‌های ورودی/خروجی و توضیحات مشخص تعریف می‌شود
- **سازگاری API**: ابزارها از طریق رابط‌های استاندارد (APIهای REST، SDKها و غیره) ادغام می‌شوند

### ۲. تعریف تابع
توابع با سه مولفه کلیدی تعریف می‌شوند:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### ۳. تشخیص قصد
- **پردازش زبان طبیعی**: SLM ورودی کاربر را برای درک قصد تحلیل می‌کند
- **مطابقت تابع**: تعیین می‌کند کدام تابع(ها) برای پاسخ به درخواست لازم است
- **استخراج پارامتر**: پارامترهای لازم را از پیام کاربر شناسایی و استخراج می‌کند

### ۴. تولید خروجی JSON
SLM ساختار JSON تولید می‌کند که شامل:
- نام تابعی که باید فراخوانی شود
- پارامترهای مورد نیاز با مقادیر مناسب
- بستر اجرا و متادیتا

### ۵. اجرای خارجی
- **اعتبارسنجی پارامترها**: اطمینان از اینکه همه پارامترهای لازم وجود دارند و به درستی قالب‌بندی شده‌اند
- **اجرای تابع**: برنامه تابع مشخص‌شده را با پارامترهای ارائه‌شده اجرا می‌کند
- **مدیریت خطا**: رسیدگی به شکست‌ها، اتمام زمان و پاسخ‌های نامعتبر

### ۶. ادغام پاسخ
- **پردازش نتیجه**: خروجی تابع به SLM بازگردانده می‌شود
- **ادغام با بستر**: SLM نتایج را در پاسخ خود وارد می‌کند
- **ارتباط با کاربر**: اطلاعات را به شکل طبیعی و مکالمه‌ای ارائه می‌دهد

## سناریوهای کاربردی

### بازیابی داده
تبدیل پرسش‌های زبان طبیعی به فراخوانی‌های API ساختاریافته:
- **"نمایش سفارشات اخیر من"** → پرس‌وجوی پایگاه داده با آی‌دی کاربر و فیلترهای تاریخ
- **"هوای توکیو چطور است؟"** → فراخوانی API آب و هوا با پارامتر مکان
- **"ایمیل‌های جان هفته گذشته را پیدا کن"** → پرس‌وجوی سرویس ایمیل با فرستنده و فیلترهای تاریخ

### اجرای عملیات
تبدیل درخواست‌های کاربر به فراخوانی‌های تابع مشخص:
- **"جلسه‌ای برای فردا ساعت ۲ بعدازظهر برنامه‌ریزی کن"** → ادغام API تقویم
- **"پیامی به تیم ارسال کن"** → API پلتفرم ارتباطی
- **"نسخه پشتیبان از فایل‌هایم بساز"** → عملیات سیستم فایل

### وظایف محاسباتی
رسیدگی به عملیات ریاضی یا منطقی پیچیده:
- **"محاسبه بهره مرکب روی ۱۰,۰۰۰ دلار با نرخ ۵٪ برای ۱۰ سال"** → تابع محاسبات مالی
- **"این داده‌ها را برای روندها تحلیل کن"** → ابزارهای تحلیل آماری
- **"این مسیر را برای تحویل بهینه کن"** → الگوریتم‌های بهینه‌سازی مسیر

### جریان‌های کاری پردازش داده
زنجیره‌ای کردن چندین فراخوانی تابع برای عملیات پیچیده:
۱. **بازیابی داده** از منابع متعدد
۲. **تجزیه و اعتبارسنجی** اطلاعات
۳. **تبدیل** داده‌ها به فرمت مورد نظر
۴. **ذخیره نتایج** در سیستم‌های مناسب
۵. **ایجاد گزارش‌ها** یا مصورسازی‌ها

### ادغام UI/UX
فعال کردن به‌روزرسانی‌های پویا در رابط کاربری:
- **"نمایش داده‌های فروش در داشبورد"** → تولید و نمایش نمودار
- **"نقشه را با موقعیت‌های جدید به‌روزرسانی کن"** → ادغام داده‌های جغرافیایی
- **"نمایش موجودی را تازه کن"** → همگام‌سازی داده‌های بلادرنگ

## کار با فراخوانی تابع Qwen3

Qwen3 قابلیت‌های فراخوانی تابع پیشرفته‌ای با عملکرد عالی و انعطاف‌پذیری ارائه می‌دهد. در اینجا نحوه پیاده‌سازی آن آمده است:

### استفاده از چارچوب Qwen-Agent

Qwen-Agent یک چارچوب سطح بالا فراهم می‌کند که پیاده‌سازی فراخوانی تابع را ساده می‌کند:

#### نصب
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### تنظیمات پایه

```python
import os
from qwen_agent.agents import Assistant

# پیکربندی مدل زبانی بزرگ
llm_cfg = {
    'model': 'Qwen3-8B',
    # گزینه ۱: استفاده از استودیو مدل علی‌بابا
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # گزینه ۲: استفاده از استقرار محلی
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'EMPTY',
    
    # پیکربندی اختیاری برای حالت تفکر
    'generate_cfg': {
        'thought_in_content': True,  # شامل کردن استدلال در پاسخ
    }
}

# تعریف ابزارها با استفاده از MCP (پروتکل زمینه مدل)
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # ابزار اجرای کد داخلی
]

# ایجاد دستیار
bot = Assistant(llm=llm_cfg, function_list=tools)

# نمونه استفاده
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# تولید پاسخ با فراخوانی تابع
for response in bot.run(messages=messages):
    print(response)
```

### پیاده‌سازی توابع سفارشی

همچنین می‌توانید توابع سفارشی برای Qwen3 تعریف کنید:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # شبیه‌سازی تماس با API هواشناسی
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# استفاده از ابزار سفارشی
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

## ادغام محلی Foundry

Foundry Local مایکروسافت API سازگار با OpenAI را برای اجرای مدل‌ها به صورت محلی با حفظ حریم خصوصی و عملکرد بالا فراهم می‌کند.

### راه‌اندازی و نصب

#### ویندوز
نصب‌کننده را از [صفحه انتشار Foundry Local](https://github.com/microsoft/Foundry-Local/releases) دانلود کرده و دستورالعمل‌های نصب را دنبال کنید.

#### مک‌اواس
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

#### استفاده پایه

```python
import openai
from foundry_local import FoundryLocalManager

# مقداردهی اولیه با نام مستعار مدل
alias = "phi-3.5-mini"  # یا هر مدل پشتیبانی شده
manager = FoundryLocalManager(alias)

# ایجاد کلاینت OpenAI که به نقطه پایانی محلی اشاره می‌کند
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# تعریف توابع برای مدل
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# انجام درخواست فراخوانی تابع
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

### نمونه ادغام سازمانی

```python
import asyncio
import json
from typing import Dict, List, Any
from dataclasses import dataclass
from datetime import datetime

@dataclass
class FunctionResult:
    """Standard result format for all function calls"""
    success: bool
    data: Any = None
    error: str = None
    execution_time: float = 0.0
    timestamp: datetime = None

class EnterpriseAIAgent:
    """Production-ready AI agent with comprehensive function calling capabilities"""
    
    def __init__(self, config: Dict):
        self.config = config
        self.functions = {}
        self.audit_log = []
        self.rate_limiters = {}
        
        # راه‌اندازی توابع اصلی کسب‌وکار
        self._register_core_functions()
    
    def _register_core_functions(self):
        """Register all available business functions"""
        
        # توابع CRM
        self.register_function(
            name="get_customer_info",
            description="Retrieve customer information from CRM",
            parameters={
                "customer_id": {"type": "string", "required": True},
                "include_history": {"type": "boolean", "default": False}
            },
            handler=self._get_customer_info,
            rate_limit=100  # تماس‌ها در هر دقیقه
        )
        
        # توابع فروش
        self.register_function(
            name="create_sales_opportunity",
            description="Create a new sales opportunity",
            parameters={
                "customer_id": {"type": "string", "required": True},
                "product_id": {"type": "string", "required": True},
                "estimated_value": {"type": "number", "required": True},
                "expected_close_date": {"type": "string", "required": True}
            },
            handler=self._create_sales_opportunity,
            rate_limit=50
        )
        
        # توابع تحلیل
        self.register_function(
            name="generate_sales_report",
            description="Generate sales performance report",
            parameters={
                "period": {"type": "string", "enum": ["daily", "weekly", "monthly", "quarterly"]},
                "region": {"type": "string", "required": False},
                "product_category": {"type": "string", "required": False}
            },
            handler=self._generate_sales_report,
            rate_limit=10
        )
        
        # توابع اعلان
        self.register_function(
            name="send_notification",
            description="Send notification to team members",
            parameters={
                "recipients": {"type": "array", "items": {"type": "string"}},
                "message": {"type": "string", "required": True},
                "priority": {"type": "string", "enum": ["low", "medium", "high"], "default": "medium"},
                "channel": {"type": "string", "enum": ["email", "slack", "teams"], "default": "email"}
            },
            handler=self._send_notification,
            rate_limit=200
        )
    
    def register_function(self, name: str, description: str, parameters: Dict, 
                         handler: callable, rate_limit: int = 60):
        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # اعتبارسنجی وجود تابع
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # بررسی محدودیت نرخ
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # اعتبارسنجی پارامترها
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # اجرای تابع
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # ثبت اجرای موفق
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # ثبت اجرای ناموفق
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # بازنشانی شمارنده در صورت گذشتن یک دقیقه
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # بررسی اینکه در محدودیت هستیم
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # بررسی پارامترهای مورد نیاز
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # اعتبارسنجی نوع و محدودیت‌های پارامتر
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # اعتبارسنجی نوع
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # اعتبارسنجی شمارشی
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
```

## جمع‌بندی

فراخوانی تابع در مدل‌های زبانی کوچک نشان‌دهنده یک تغییر پارادایم از دستیارهای هوش مصنوعی ایستا به عامل‌های پویا و توانمند است که می‌توانند با دنیای واقعی تعامل کنند. این آموزش موضوعات زیر را پوشش داده است:

### نکات کلیدی

۱. **درک پایه**: فراخوانی تابع به SLMها امکان می‌دهد فراتر از داده‌های آموزشی خود رفته و به ابزارها و سرویس‌های خارجی متصل شوند.

۲. **انعطاف‌پذیری پیاده‌سازی**: رویکردهای متعددی وجود دارد، از پیاده‌سازی‌های سطح پایین با قالب‌های سفارشی تا چارچوب‌های سطح بالا مانند Qwen-Agent و Foundry Local.

۳. **ملاحظات تولید**: استقرار در سازمان‌ها نیازمند توجه به مدیریت خطا، محدودیت نرخ، امنیت و ثبت گزارش‌های حسابرسی است.

۴. **بهینه‌سازی عملکرد**: طراحی صحیح توابع، اجرای بهینه و ذخیره‌سازی هوشمند می‌تواند به طور قابل توجهی زمان پاسخ را بهبود بخشد.

### جهت‌های آینده

با پیشرفت فناوری SLM انتظار می‌رود:

- **بهبود دقت فراخوانی تابع**: تشخیص بهتر قصد و استخراج پارامترها
- **پردازش موازی پیشرفته‌تر**: هماهنگی پیچیده‌تر برای چندین تابع
- **استانداردهای ادغام بهتر**: پروتکل‌های استاندارد برای ادغام ابزارها
- **ویژگی‌های امنیتی پیشرفته**: مکانیزم‌های پیشرفته احراز هویت و مجوزدهی
- **گسترش اکوسیستم**: افزایش کتابخانه توابع و ادغام‌های از پیش ساخته شده

### شروع به کار

برای شروع پیاده‌سازی فراخوانی تابع در پروژه‌هایتان:

۱. **شروع ساده**: با سناریوهای تابع تک‌تایی پایه شروع کنید
۲. **انتخاب چارچوب**: بین پیاده‌سازی مستقیم (Ollama/Phi-4) یا چارچوب کمکی (Qwen-Agent) انتخاب کنید
۳. **طراحی دقیق توابع**: روی تعریف‌های واضح و مستند شده تمرکز کنید
۴. **پیاده‌سازی مدیریت خطا**: از ابتدا مدیریت خطاهای مستحکم بسازید
۵. **گسترش تدریجی**: با کسب تجربه، از سناریوهای ساده به پیچیده‌تر حرکت کنید

فراخوانی تابع، SLMها را از تولیدکنندگان متنی برجسته به عامل‌های هوش مصنوعی عملی تبدیل می‌کند که قادر به حل مشکلات دنیای واقعی هستند. با دنبال کردن الگوها و روش‌های این آموزش، می‌توانید سیستم‌های هوش مصنوعی قدرتمند و قابل اعتمادی بسازید که فراتر از رابط‌های متداول گفتگو عمل می‌کنند.
