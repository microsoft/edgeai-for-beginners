# Bölüm 2: Yerel Ortamda Dağıtım - Gizlilik Öncelikli Çözümler

Küçük Dil Modellerinin (SLM'ler) yerel dağıtımı, gizliliği koruyan, maliyet-etkin AI çözümlerine yönelik bir paradigma değişimini temsil eder. Bu kapsamlı rehber, geliştiricilerin SLM'lerin tam potansiyelini kullanırken dağıtım ortamları üzerinde tam kontrol sahibi olmalarını sağlayan iki güçlü çerçeveyi—Ollama ve Microsoft Foundry Local—inceler.

## Giriş

Bu derste, yerel ortamlarda Küçük Dil Modelleri için ileri seviye dağıtım stratejilerini keşfedeceğiz. Yerel AI dağıtımının temel kavramlarını ele alacak, iki önde gelen platformu (Ollama ve Microsoft Foundry Local) inceleyecek ve üretim hazır çözümler için pratik uygulama rehberi sunacağız.

## Öğrenim Hedefleri

Dersin sonunda şunları yapabileceksiniz:

- Yerel SLM dağıtım çerçevelerinin mimarisini ve faydalarını anlamak.
- Ollama ve Microsoft Foundry Local kullanarak üretim hazır dağıtımları uygulamak.
- Belirli gereksinimlere ve kısıtlamalara göre uygun platformu karşılaştırmak ve seçmek.
- Performans, güvenlik ve ölçeklenebilirlik için yerel dağıtımları optimize etmek.

## Yerel SLM Dağıtım Mimarilerinin Anlaşılması

Yerel SLM dağıtımı, bulut bağımlı AI servislerinden, kuruluş içinde gizliliği koruyan çözümlere temel bir geçiştir. Bu yaklaşım, kuruluşların AI altyapıları üzerinde tam kontrol sağlamaları ve veri egemenliği ile operasyonel bağımsızlık temin etmeleri için olanak tanır.

### Dağıtım Çerçevesi Sınıflandırmaları

Farklı dağıtım yaklaşımlarını anlamak, belirli kullanım durumlarına uygun stratejiyi seçmeye yardımcı olur:

- **Geliştirme Odaklı**: Deney ve prototipleme için sadeleştirilmiş kurulum
- **Kurumsal Düzey**: Kurumsal entegrasyon yeteneklerine sahip üretim hazır çözümler  
- **Çapraz Platform**: Farklı işletim sistemleri ve donanımlar arasında evrensel uyumluluk

### Yerel SLM Dağıtımının Temel Avantajları

Yerel SLM dağıtımı, kurumsal ve gizlilik odaklı uygulamalar için ideal kılan birçok temel avantaj sunar:

**Gizlilik ve Güvenlik**: Yerel işleme, hassas verilerin kuruluş altyapısından asla çıkmamasını sağlar; GDPR, HIPAA ve diğer düzenleyici gereksinimlerle uyumu mümkün kılar. Sınıflandırılmış ortamlar için hava boşluklu dağıtımlar mümkündür ve tam denetim kayıtları güvenlik gözetimini sağlar.

**Maliyet Etkinliği**: Token başına ücretlendirme modellerinin ortadan kalkması operasyonel maliyetleri önemli ölçüde düşürür. Daha düşük bant genişliği gereksinimleri ve azalan bulut bağımlılığı, kurumsal bütçeleme için öngörülebilir maliyet yapıları sunar.

**Performans ve Güvenilirlik**: Ağ gecikmesi olmadan daha hızlı çıkarım süreleri gerçek zamanlı uygulamalara imkan tanır. Çevrimdışı işlevsellik, internet bağlantısına bakılmaksızın sürekli operasyon sağlar; yerel kaynak optimizasyonu tutarlı performans sunar.

## Ollama: Evrensel Yerel Dağıtım Platformu

### Temel Mimari ve Felsefe

Ollama, farklı donanım konfigürasyonları ve işletim sistemlerinde yerel büyük dil modeli dağıtımını demokratikleştiren, geliştirici dostu evrensel bir platform olarak tasarlanmıştır.

**Teknik Temel**: Güçlü llama.cpp çerçevesi üzerine inşa edilen Ollama, optimum performans için verimli GGUF model formatını kullanır. Çapraz platform uyumluluğu, Windows, macOS ve Linux ortamlarında tutarlı davranış sağlar; akıllı kaynak yönetimi CPU, GPU ve bellek kullanımını optimize eder.

**Tasarım Felsefesi**: Ollama, fonksiyonellikten ödün vermeden sadeliği ön planda tutar ve sıfır yapılandırma ile hızlı verimlilik sağlar. Platform geniş model uyumluluğunu korurken farklı model mimarileri arasında tutarlı API’lar sunar.

### İleri Özellikler ve Yetkinlikler

**Model Yönetiminde Mükemmellik**: Ollama, otomatik çekme, önbellekleme ve sürümleme ile kapsamlı model yaşam döngüsü yönetimi sağlar. Llama 3.2, Google Gemma 2, Microsoft Phi-4, Qwen 2.5, DeepSeek, Mistral ve özel gömme modeller dahil geniş bir model ekosistemini destekler.

**Modelfiles ile Özelleştirme**: İleri düzey kullanıcılar, özel parametreler, sistem istemleri ve davranış değişiklikleri içeren özel model konfigürasyonları oluşturabilir. Bu, alan odaklı optimizasyonlar ve özel uygulama gereksinimlerini mümkün kılar.

**Performans Optimizasyonu**: Ollama, NVIDIA CUDA, Apple Metal ve OpenCL dahil mevcut donanım hızlandırmayı otomatik olarak algılar ve kullanır. Akıllı bellek yönetimi, farklı donanım yapılandırmalarında kaynak kullanımını en üst düzeye çıkarır.

### Geliştirici Entegrasyon Örnekleri

**Python API Entegrasyonu**:

```python
import requests
import json

# API uç noktası yapılandırması
OLLAMA_ENDPOINT = "http://localhost:11434/api/generate"

# Model parametreleri
params = {
    "model": "phi4:mini",
    "prompt": "Write a function to calculate the Fibonacci sequence in Python",
    "system": "You are a helpful Python programming assistant. Provide clean, efficient code with comments.",
    "stream": False,
    "options": {
        "temperature": 0.2,
        "top_p": 0.95,
        "num_predict": 1024
    }
}

# API isteği yap
response = requests.post(OLLAMA_ENDPOINT, json=params)
result = response.json()

# Yanıtı işle ve göster
print(result["response"])

# Akış örneği (gerçek zamanlı yanıtlar için)
def stream_response():
    params["stream"] = True
    response = requests.post(OLLAMA_ENDPOINT, json=params, stream=True)
    
    for line in response.iter_lines():
        if line:
            chunk = json.loads(line)
            if "response" in chunk:
                print(chunk["response"], end="", flush=True)
            if chunk.get("done", False):
                print()
                break

# stream_response()  # Akış örneğini çalıştırmak için yorum satırını kaldırın
```

**JavaScript/TypeScript Entegrasyonu (Node.js)**:

```javascript
const axios = require('axios');

// API yapılandırması
const OLLAMA_API = 'http://localhost:11434/api';

// Ollama ile metin oluşturma fonksiyonu
async function generateText(model, prompt, systemPrompt = '') {
  try {
    const response = await axios.post(`${OLLAMA_API}/generate`, {
      model: model,
      prompt: prompt,
      system: systemPrompt,
      stream: false,
      options: {
        temperature: 0.7,
        top_k: 40,
        top_p: 0.9,
        num_predict: 1024
      }
    });
    
    return response.data.response;
  } catch (error) {
    console.error('Error generating text:', error.message);
    throw error;
  }
}

// Express API'de örnek kullanım
const express = require('express');
const app = express();
app.use(express.json());

app.post('/api/chat', async (req, res) => {
  const { message } = req.body;
  
  try {
    const response = await generateText(
      'phi4:mini',
      message,
      'You are a helpful AI assistant.'
    );
    
    res.json({ response });
  } catch (error) {
    res.status(500).json({ error: 'Failed to generate response' });
  }
});

app.listen(3000, () => {
  console.log('API server running on port 3000');
});
```

## Microsoft Foundry Local: Kurumsal Edge AI Platformu

### Kurumsal Düzey Mimari

Microsoft Foundry Local, Microsoft ekosistemine derin entegrasyon ile üretim düzeyinde edge AI dağıtımları için özel olarak tasarlanmış kapsamlı bir kurumsal çözümdür.

**ONNX Tabanlı Temel**: Endüstri standardı ONNX Runtime üzerine inşa edilen Foundry Local, çeşitli donanım mimarilerinde optimize performans sunar. Windows ML entegrasyonunu kullanarak yerel Windows optimizasyonu sağlar ve çapraz platform uyumluluğunu korur.

**Donanım Hızlandırma Mükemmelliği**: Foundry Local, CPU, GPU ve NPU’larda akıllı donanım algılama ve optimizasyon özelliklerine sahiptir. Donanım üreticileri (AMD, Intel, NVIDIA, Qualcomm) ile derin işbirliği optimal performansı garanti eder.

### İleri Geliştirici Deneyimi

**Çoklu Arayüz Erişimi**: Foundry Local, model yönetimi ve dağıtım için güçlü CLI, yerel entegrasyon için çoklu programlama dili SDK’ları (Python, NodeJS) ve sorunsuz geçiş için OpenAI uyumlu RESTful API’lar sağlar.

**Visual Studio Entegrasyonu**: Platform, AI Toolkit for VS Code ile sorunsuz entegre olup, geliştirme ortamında model dönüştürme, kantifikasyon ve optimizasyon araçları sunar. Bu entegrasyon, geliştirme iş akışlarını hızlandırır ve dağıtım karmaşıklığını azaltır.

**Model Optimizasyon Boru Hattı**: Microsoft Olive entegrasyonu, dinamik kantifikasyon, grafik optimizasyonu ve donanım-spesifik ayarlamalar dahil gelişmiş model optimizasyonu sağlar. Azure ML aracılığıyla bulut tabanlı dönüştürme yetenekleri büyük modeller için ölçeklenebilir optimizasyon sunar.

## Karşılaştırmalı Analiz: Ollama vs Foundry Local

### Teknik Mimari Karşılaştırması

| **Özellik** | **Ollama** | **Foundry Local** |
|------------|------------|-------------------|
| **Model Formatı** | GGUF (llama.cpp üzerinden) | ONNX (ONNX Runtime üzerinden) |
| **Platform Odaklılığı** | Evrensel çapraz platform | Windows/Kurumsal optimizasyon |
| **Donanım Entegrasyonu** | Genel GPU/CPU desteği | Derin Windows ML, NPU desteği |
| **Optimizasyon** | llama.cpp kantifikasyonu | Microsoft Olive + ONNX Runtime |
| **Kurumsal Özellikler** | Topluluk odaklı | SLAlı kurumsal düzey |

### Performans Özellikleri

**Ollama Performans Güçlü Yönleri**:
- llama.cpp optimizasyonuyla üstün CPU performansı
- Farklı platformlar ve donanımlar arasında tutarlı davranış
- Akıllı model yükleme ile verimli bellek kullanımı
- Geliştirme ve test senaryolarında hızlı soğuk başlangıç süreleri

**Foundry Local Performans Avantajları**:
- Modern Windows donanımlarında üstün NPU kullanımı
- Üretici iş ortaklıklarıyla optimize edilmiş GPU hızlandırma
- Kurumsal düzey performans izleme ve optimizasyon
- Üretim ortamları için ölçeklenebilir dağıtım yetenekleri

### Geliştirme Deneyimi Analizi

**Ollama Geliştirici Deneyimi**:
- Anında verimlilikle minimal kurulum gereksinimleri
- Tüm işlemler için sezgisel komut satırı arayüzü
- Kapsamlı topluluk desteği ve dokümantasyon
- Modelfiles ile esnek özelleştirme

**Foundry Local Geliştirici Deneyimi**:
- Visual Studio ekosistemiyle kapsamlı IDE entegrasyonu
- Takım işbirliği özellikleri ile kurumsal geliştirme iş akışları
- Microsoft destekli profesyonel destek kanalları
- Gelişmiş hata ayıklama ve optimizasyon araçları

### Kullanım Durumu Optimizasyonu

**Ollama'yı Seçin Eğer**:
- Tutarlı davranış gerektiren çapraz platform uygulamaları geliştiriyorsanız
- Açık kaynak şeffaflığı ve topluluk katkılarını önceliklendiriyorsanız
- Kısıtlı kaynaklar veya bütçe kısıtlamalarıyla çalışıyorsanız
- Deneysel veya araştırma odaklı uygulamalar inşa ediyorsanız
- Farklı mimariler arasında geniş model uyumluluğu gerekiyorsa

**Foundry Local'ı Seçin Eğer**:
- Katı performans gereksinimleri olan kurumsal uygulamalar dağıtıyorsanız
- Windows özel donanım optimizasyonlarından (NPU, Windows ML) faydalanıyorsanız
- Kurumsal destek, SLA’lar ve uyumluluk özellikleri istiyorsanız
- Microsoft ekosistemi entegrasyonlu üretim uygulamaları geliştiriyorsanız
- Gelişmiş optimizasyon araçları ve profesyonel geliştirme iş akışlarına ihtiyaç duyuyorsanız

      run: |
        foundry-local models pull microsoft/phi-4-mini
        foundry-local deploy --config production.json
