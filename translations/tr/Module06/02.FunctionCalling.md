## Fonksiyon Çağrısı Nedir?

Fonksiyon çağrısı, Küçük Dil Modellerinin (SLM'ler) dış araçlar, API'ler ve servislerle etkileşime girmesine olanak tanıyan güçlü bir yetenektir. Eğitim verileri ile sınırlı kalmak yerine, SLM'ler artık:

- **Dış API’lere bağlanabilir** (hava durumu servisleri, veri tabanları, arama motorları)
- **Kullanıcı isteklerine göre belirli fonksiyonları çalıştırabilir**
- **Gerçek zamanlı bilgileri** çeşitli kaynaklardan alabilir
- **Özel araçlar aracılığıyla hesaplama görevleri** yapabilir
- **Karmaşık iş akışları için birden fazla işlemi ardışık olarak zincirleyebilir**

Bu yetenek, SLM'leri statik metin oluşturuculardan gerçek dünya görevlerini yerine getirebilen dinamik yapay zeka ajanlarına dönüştürür.

## Fonksiyon Çağrısı Nasıl Çalışır

Fonksiyon çağrısı süreci sistematik bir iş akışını takip eder:

### 1. Araç Entegrasyonu
- **Dış Araçlar**: SLM'ler hava durumu API'leri, veri tabanları, web servisleri ve diğer dış sistemlere bağlanabilir
- **Fonksiyon Tanımları**: Her araç, belirli parametreler, giriş/çıkış formatları ve açıklamalarla tanımlanır
- **API Uyumluluğu**: Araçlar standart arayüzler (REST API'ler, SDK'lar vb.) üzerinden entegre edilir

### 2. Fonksiyon Tanımı
Fonksiyonlar üç ana bileşenle tanımlanır:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Niyet Algılama
- **Doğal Dil İşleme**: SLM, kullanıcı girdiğini analiz ederek niyeti anlar
- **Fonksiyon Eşleştirme**: İstek için hangi fonksiyon(lar)ın gerekli olduğuna karar verir
- **Parametre Çıkarımı**: Kullanıcının mesajından gerekli parametreleri belirler ve çıkarır

### 4. JSON Çıktısı Oluşturma
SLM, aşağıları içeren yapılandırılmış JSON oluşturur:
- Çağrılacak fonksiyon adı
- Uygun değerlerle gerekli parametreler
- Çalıştırma bağlamı ve meta veriler

### 5. Dışa Yürütme
- **Parametre Doğrulama**: Tüm gerekli parametrelerin mevcut ve doğru formatta olduğundan emin olunur
- **Fonksiyon Yürütme**: Uygulama, belirtilen fonksiyonu verilen parametrelerle çalıştırır
- **Hata Yönetimi**: Hatalar, zaman aşımı ve geçersiz yanıtlar yönetilir

### 6. Yanıt Entegrasyonu
- **Sonuç İşleme**: Fonksiyon çıktısı SLM’ye döndürülür
- **Bağlam Entegrasyonu**: SLM, sonuçları yanıtına entegre eder
- **Kullanıcı İletişimi**: Bilgiler doğal, konuşma tarzında sunulur

## Uygulama Senaryoları

### Veri Alma
Doğal dil sorgularını yapılandırılmış API çağrılarına dönüştürme:
- **"Son siparişlerimi göster"** → Kullanıcı kimliği ve tarih filtreli veri tabanı sorgusu
- **"Tokyo'da hava nasıl?"** → Lokasyon parametreli hava durumu API çağrısı
- **"Geçen haftadan John'dan gelen e-postaları bul"** → Gönderen ve tarih filtreli e-posta hizmeti sorgusu

### İşlem Yürütme
Kullanıcı isteklerini belirli fonksiyon çağrılarına dönüştürme:
- **"Yarın saat 14:00 için toplantı ayarla"** → Takvim API entegrasyonu
- **"Takıma mesaj gönder"** → İletişim platformu API'si
- **"Dosyalarımın yedeğini al"** → Dosya sistemi işlemi

### Hesaplama Görevleri
Karmaşık matematiksel veya mantıksal işlemleri yönetme:
- **"10.000$'ın %5 faizle 10 yıl bileşik faizini hesapla"** → Finansal hesaplama fonksiyonu
- **"Bu veri setinde trend analizi yap"** → İstatistiksel analiz araçları
- **"Teslimat için bu rotayı optimize et"** → Rota optimizasyon algoritmaları

### Veri İşleme İş Akışları
Karmaşık işlemler için birden çok fonksiyon çağrısını zincirleme:
1. **Birden fazla kaynaktan veri al**
2. **Bilgiyi ayrıştır ve doğrula**
3. **Veriyi istenilen formata dönüştür**
4. **Sonuçları uygun sistemlerde sakla**
5. **Raporlar veya görselleştirmeler oluştur**

### UI/UX Entegrasyonu
Dinamik arayüz güncellemelerini etkinleştirme:
- **"Panelde satış verilerini göster"** → Grafik oluşturma ve gösterim
- **"Haritayı yeni konumlarla güncelle"** → Coğrafi veri entegrasyonu
- **"Envanter görüntüsünü yenile"** → Gerçek zamanlı veri senkronizasyonu

#### Temel Kurulum

```python
import os
from qwen_agent.agents import Assistant

# LLM'yi yapılandır
llm_cfg = {
    'model': 'Qwen3-8B',
    # Seçenek 1: Alibaba Model Studio kullan
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # Seçenek 2: Yerel dağıtımı kullan
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'EMPTY',
    
    # Düşünme modu için isteğe bağlı yapılandırma
    'generate_cfg': {
        'thought_in_content': True,  # Yanıtta muhakemeyi dahil et
    }
}

# MCP (Model Context Protocol) kullanarak araçları tanımla
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # Dahili kod yürütme aracı
]

# Asistanı oluştur
bot = Assistant(llm=llm_cfg, function_list=tools)

# Örnek kullanım
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# Fonksiyon çağrısı ile yanıt oluştur
for response in bot.run(messages=messages):
    print(response)
```

### Özel Fonksiyon Uygulaması

Qwen3 için ayrıca özel fonksiyonlar tanımlayabilirsiniz:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Hava durumu API çağrısını simüle edin
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Özel aracı kullanın
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

## Foundry Local Entegrasyonu

Microsoft'un Foundry Local ürünü, modelleri yerel olarak çalıştırmak için OpenAI uyumlu bir API sunar; gizlilik ve performans artırılmıştır.

### Kurulum ve Yükleme

#### Windows
Kurulum dosyasını [Foundry Local sürümleri sayfasından](https://github.com/microsoft/Foundry-Local/releases) indirip kurulum yönergelerini izleyin.

#### macOS
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

#### Temel Kullanım

```python
import openai
from foundry_local import FoundryLocalManager

# Model takma adı ile başlat
alias = "phi-3.5-mini"  # Veya desteklenen herhangi bir model
manager = FoundryLocalManager(alias)

# Yerel uç noktaya işaret eden OpenAI istemcisi oluştur
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Model için fonksiyonları tanımla
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Fonksiyon çağırma isteği yap
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

### Yaygın Sorunlar ve Çözümleri

#### Sorun 1: Fonksiyon Çağrılmıyor
**Belirtiler**: Model, fonksiyon çağırmak yerine metinle yanıt verir

**Çözümler**:
1. **Fonksiyon açıklamasını kontrol et**: Kullanıcı niyetiyle açıkça eşleştiğinden emin ol
2. **Parametre tanımlarını doğrula**: Tüm gerekli parametrelerin doğru tanımlandığından emin ol
3. **Sistem yönlendirmesini gözden geçir**: Fonksiyonların ne zaman kullanılacağı hakkında net talimatlar ekle
4. **Açık isteklerle test et**: Örneğin "Londra için hava durumu fonksiyonunu kullan lütfen" dene

#### Sorun 2: Yanlış Parametreler
**Belirtiler**: Fonksiyon yanlış veya eksik parametrelerle çağrılıyor

**Çözümler**:
1. **Parametre örnekleri ekle**: Tanımlarda örnek değerler göster
2. **Enum kısıtlamaları kullan**: Parametre değerlerini mümkün olduğunca belirli seçeneklerle sınırlandır
3. **Yedek değerler uygula**: İsteğe bağlı parametreler için mantıklı varsayılanlar sağla

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }

class EnterpriseAIAgent:
    """Production-ready AI agent with comprehensive function calling capabilities"""

    def register_function(self, name: str, description: str, parameters: Dict, 
                         handler: callable, rate_limit: int = 60):
        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Fonksiyonun varlığını doğrula
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Oran limitlerini kontrol et
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Parametreleri doğrula
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Fonksiyonu çalıştır
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Başarılı çalıştırmayı kaydet
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Başarısız çalıştırmayı kaydet
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Bir dakika geçtiyse sayacı sıfırla
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Limitin altında olup olmadığını kontrol et
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Gerekli parametreleri kontrol et
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Parametre tiplerini ve kısıtlamalarını doğrula
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Tip doğrulaması
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # Enum doğrulaması
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )

            print(f"Task {i+1} completed successfully")
        else:
            print(f"Task {i+1} failed: {result.error}")
    
    # Denetim kaydını göster
    print(f"\n=== Audit Log ({len(agent.audit_log)} entries) ===")
    for entry in agent.audit_log[-3:]:  # Son 3 girdiyi göster
        print(f"{entry['timestamp']}: {entry['function_name']} - {'SUCCESS' if entry['success'] else 'FAILED'}")

# Kurumsal demoyu çalıştır
# asyncio.run(enterprise_demo())
```
