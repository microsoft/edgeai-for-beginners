## Επισκόπηση Έργου

Το EdgeAI για Αρχάριους είναι ένα ολοκληρωμένο εκπαιδευτικό αποθετήριο που διδάσκει την ανάπτυξη Edge AI με Μικρά Γλωσσικά Μοντέλα (SLMs). Το μάθημα καλύπτει βασικές αρχές EdgeAI, ανάπτυξη μοντέλων, τεχνικές βελτιστοποίησης και υλοποιήσεις έτοιμες για παραγωγή χρησιμοποιώντας το Microsoft Foundry Local και διάφορα πλαίσια AI.

**Κύριες Τεχνολογίες:**
- Python 3.8+ (κύρια γλώσσα για AI/ML δείγματα)
- .NET C# (δείγματα AI/ML)
- JavaScript/Node.js με Electron (για επιτραπέζιες εφαρμογές)
- Microsoft Foundry Local SDK
- Microsoft Windows ML 
- VSCode AI Toolkit
- OpenAI SDK
- Πλαίσια AI: LangChain, Semantic Kernel, Chainlit
- Βελτιστοποίηση Μοντέλου: Llama.cpp, Microsoft Olive, OpenVINO, Apple MLX

**Τύπος Αποθετηρίου:** Αποθετήριο εκπαιδευτικού περιεχομένου με 8 ενότητες και 10 ολοκληρωμένες εφαρμογές δειγμάτων

**Αρχιτεκτονική:** Μονοπάτι μάθησης πολλαπλών ενοτήτων με πρακτικά δείγματα που παρουσιάζουν πρότυπα ανάπτυξης edge AI

## Προαπαιτούμενα

### Απαιτούμενα Εργαλεία

- **Python 3.8+** - Για δείγματα και σημειωματάρια AI/ML
- **Node.js 16+** - Για την εφαρμογή δειγμάτων Electron
- **Git** - Για έλεγχο εκδόσεων
- **Microsoft Foundry Local** - Για τοπική εκτέλεση μοντέλων AI

### Συνιστώμενα Εργαλεία

- **Visual Studio Code** - Με επεκτάσεις Python, Jupyter και Pylance
- **Windows Terminal** - Για καλύτερη εμπειρία γραμμής εντολών (χρήστες Windows)

- **RAM**: τουλάχιστον 8GB, συνιστώνται 16GB+ για σενάρια πολλαπλών μοντέλων

- **ΛΣ**: Windows 10/11, macOS 11+ ή Linux (Ubuntu 20.04+)
- **Υλικό**: CPU με υποστήριξη AVX2; GPU (CUDA, Qualcomm NPU) προαιρετικά αλλά συνιστώνται

- Βασική κατανόηση προγραμματισμού Python

## Οδηγίες Pull Request

### Ροή Συνεισφοράς

1. **Κάντε fork το αποθετήριο** και δημιουργήστε ένα νέο branch από το `main`
2. **Κάντε τις αλλαγές σας** ακολουθώντας τις οδηγίες στυλ κώδικα

- `feature/<module>-<description>` - Για νέες λειτουργίες ή περιεχόμενο

- `docs/<description>` - Για βελτιώσεις τεκμηρίωσης
- `refactor/<description>` - Για αναδιάρθρωση κώδικα

### Μορφή Μηνύματος Commit

```
<type>(<scope>): <description>

[optional body]

[optional footer]
```

## Ενσωμάτωση Foundry Local

Τα περισσότερα δείγματα της Ενότητας 08 απαιτούν το Microsoft Foundry Local να εκτελείται.

### Εγκατάσταση & Ρύθμιση

**Εγκατάσταση Foundry Local:**
```bash
# Windows
winget install Microsoft.FoundryLocal

# macOS
brew tap microsoft/foundrylocal
brew install foundrylocal
```

**Εγκατάσταση Python SDK:**
```bash
pip install foundry-local-sdk openai
```

### Εκκίνηση Foundry Local
```bash
# Εκκίνηση υπηρεσίας και εκτέλεση μοντέλου (κατεβάζει αυτόματα αν χρειαστεί)
foundry model run phi-3.5-mini

# Ή χρησιμοποιήστε ψευδώνυμα μοντέλων για αυτόματη βελτιστοποίηση υλικού
foundry model run phi-4-mini
foundry model run qwen2.5-0.5b
foundry model run qwen2.5-coder-0.5b

# Έλεγχος κατάστασης υπηρεσίας
foundry service status

# Λίστα διαθέσιμων μοντέλων
foundry model ls
```

### Χρήση SDK (Python)
```python
from foundry_local import FoundryLocalManager
import openai

# Χρησιμοποιήστε το ψευδώνυμο μοντέλου για αυτόματη βελτιστοποίηση υλικού
alias = "phi-4-mini"

# Δημιουργήστε διαχειριστή (εκκινεί αυτόματα την υπηρεσία και φορτώνει το μοντέλο)
manager = FoundryLocalManager(alias)

# Διαμορφώστε τον πελάτη OpenAI για την τοπική υπηρεσία Foundry
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Χρησιμοποιήστε το μοντέλο
response = client.chat.completions.create(
    model=manager.get_model_info(alias).id,
    messages=[{"role": "user", "content": "Hello!"}]
)
```

### Επαλήθευση Foundry Local
```bash
# Κατάσταση υπηρεσίας και τελικό σημείο
foundry service status

# Καταχώριση φορτωμένων μοντέλων (REST API)
curl http://localhost:<port>/v1/models

# Σημείωση: Η θύρα εμφανίζεται κατά την εκτέλεση 'foundry service status'
```

### Μεταβλητές Περιβάλλοντος για τα Δείγματα

Τα περισσότερα δείγματα χρησιμοποιούν αυτές τις μεταβλητές περιβάλλοντος:
```bash
# Τοπική διαμόρφωση Foundry
# Σημείωση: Το SDK (FoundryLocalManager) ανιχνεύει αυτόματα το σημείο τερματισμού
set MODEL=phi-4-mini  # ή phi-3.5-mini, qwen2.5-0.5b, qwen2.5-coder-0.5b
set API_KEY=            # Δεν απαιτείται για τοπική χρήση

# Χειροκίνητο σημείο τερματισμού (αν δεν χρησιμοποιείται το SDK)
# Η θύρα εμφανίζεται μέσω της 'foundry service status'
set BASE_URL=http://localhost:<port>

# Για εναλλακτικό Azure OpenAI (προαιρετικό)
set AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com
set AZURE_OPENAI_API_KEY=your-api-key
set AZURE_OPENAI_API_VERSION=2024-08-01-preview
```

**Σημείωση**: Όταν χρησιμοποιείτε το `FoundryLocalManager`, το SDK διαχειρίζεται αυτόματα την ανίχνευση υπηρεσίας και τη φόρτωση μοντέλων. Τα ψευδώνυμα μοντέλων (π.χ. `phi-3.5-mini`) εξασφαλίζουν ότι επιλέγεται η καλύτερη παραλλαγή για το υλικό σας.

## Συνηθισμένα Προβλήματα και Αντιμετώπιση

> **Συμβουλή**: Ελέγξτε τα [Προβλήματα GitHub](https://github.com/microsoft/edgeai-for-beginners/issues) για γνωστά ζητήματα και λύσεις.

### Κρίσιμα Προβλήματα (Μπλοκαριστικά)

#### Το Foundry Local δεν Εκτελείται
**Πρόβλημα:** Τα δείγματα αποτυγχάνουν με σφάλματα σύνδεσης

**Λύση:**
```bash
# Ελέγξτε αν η υπηρεσία λειτουργεί
foundry service status

# Ξεκινήστε την υπηρεσία με ένα μοντέλο
foundry model run phi-4-mini

# Ή ξεκινήστε ρητά την υπηρεσία
foundry service start

# Λίστα με φορτωμένα μοντέλα
foundry model ls

# Επαληθεύστε μέσω REST API (θύρα εμφανίζεται στο 'foundry service status')
curl http://localhost:<port>/v1/models
```

### Συνηθισμένα Προβλήματα (Μέτρια)

#### Προβλήματα Python Virtual Environment
**Πρόβλημα:** Σφάλματα εισαγωγής module

**Λύση:**
```bash
# Βεβαιωθείτε ότι έχει ενεργοποιηθεί το εικονικό περιβάλλον
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

# Επανεγκαταστήστε τις εξαρτήσεις
pip install -r requirements.txt
```

#### Προβλήματα Κατασκευής Electron
**Πρόβλημα:** Αποτυχίες `npm install` ή build

**Λύση:**
```bash
cd Module08/samples/08
# Καθαρή εγκατάσταση
npm run clean
rm -rf node_modules package-lock.json
npm install
```

### Προβλήματα Ροής Εργασίας (Μικρά)

#### Σύγκρουση Ροής Εργασίας Μετάφρασης
**Πρόβλημα:** Το PR μετάφρασης συγκρούεται με τις αλλαγές σας

**Λύση:**
- Επεξεργαστείτε μόνο αρχεία πηγαίου αγγλικού κώδικα
- Αφήστε τη ροή εργασίας αυτοματοποιημένης μετάφρασης να διαχειριστεί τις μεταφράσεις
- Εάν παρουσιαστούν συγκρούσεις, συγχωνεύστε το `main` στο branch σας μετά τη συγχώνευση των μεταφράσεων

#### Αποτυχίες Λήψης Μοντέλου
**Πρόβλημα:** Το Foundry Local αποτυγχάνει να κατεβάσει μοντέλα

**Λύση:**
```bash
# Ελέγξτε τη σύνδεση στο διαδίκτυο
# Καθαρίστε την κρυφή μνήμη του μοντέλου και δοκιμάστε ξανά
foundry model remove <model-alias>
foundry model run <model-alias>

# Ελέγξτε τον διαθέσιμο χώρο στο δίσκο (τα μοντέλα μπορεί να είναι 2-16GB)
# Επαληθεύστε ότι οι ρυθμίσεις του τείχους προστασίας επιτρέπουν τα ληφθέντα αρχεία
```

### Εφαρμογές Δειγμάτων Εργαστηρίου


Το Εργαστήριο περιλαμβάνει 6 προοδευτικές συνεδρίες με πρακτικές υλοποιήσεις:

1. **Συνεδρία 01** - Εκκίνηση συνομιλίας με ενσωμάτωση Foundry Local
2. **Συνεδρία 02** - Σωλήνας RAG και αξιολόγηση με RAGAS
3. **Συνεδρία 03** - Σύγκριση μοντέλων ανοιχτού κώδικα
4. **Συνεδρία 04** - Σύγκριση και επιλογή μοντέλου
5. **Συνεδρία 05** - Συστήματα ορχήστρωσης πολλαπλών πρακτόρων
6. **Συνεδρία 06** - Δρομολόγηση μοντέλου και διαχείριση σωλήνα

Κάθε παράδειγμα δείχνει διαφορετικές πτυχές της ανάπτυξης Edge AI με το Foundry Local.

### Επιπτώσεις στην Απόδοση

- Τα SLM είναι βελτιστοποιημένα για ανάπτυξη στο edge (2-16GB RAM)
- Η τοπική επαγωγή παρέχει χρόνους απόκρισης 50-500ms
- Τεχνικές ποσοτικοποίησης επιτυγχάνουν 75% μείωση μεγέθους με διατήρηση 85% της απόδοσης
- Δυνατότητες επικοινωνίας σε πραγματικό χρόνο με τοπικά μοντέλα

### Ασφάλεια και Απόρρητο

- Όλη η επεξεργασία γίνεται τοπικά - δεν αποστέλλονται δεδομένα στο cloud
- Κατάλληλο για εφαρμογές ευαίσθητες στο απόρρητο (υγεία, χρηματοοικονομικά)
- Συμμορφώνεται με απαιτήσεις κυριαρχίας δεδομένων
- To Foundry Local τρέχει αποκλειστικά σε τοπικό υλικό
