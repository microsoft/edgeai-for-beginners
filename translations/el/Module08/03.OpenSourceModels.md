## Μέρος 1: Ανακάλυψη Μοντέλου με Foundry CLI

### Βασικές Εντολές Διαχείρισης Μοντέλου

Το foundry CLI παρέχει απλές εντολές για ανακάλυψη και διαχείριση μοντέλων:

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### Τρέχοντας Τα Πρώτα Σας Μοντέλα

Ξεκινήστε με δημοφιλή, καλά δοκιμασμένα μοντέλα για να κατανοήσετε τα χαρακτηριστικά απόδοσης:

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**Σημείωση:** Η σημαία `--verbose` παρέχει λεπτομερείς πληροφορίες εκκίνησης, περιλαμβάνοντας:
- Πρόοδο λήψης μοντέλου (στο πρώτο τρέξιμο)
- Λεπτομέρειες κατανομής μνήμης
- Πληροφορίες σύνδεσης υπηρεσίας
- Μετρικές αρχικοποίησης απόδοσης

### Κατανόηση Κατηγοριών Μοντέλων

**Μικρά Γλωσσικά Μοντέλα (SLMs):**
- `phi-4-mini`: Γρήγορο, αποδοτικό, ιδανικό για γενική συνομιλία
- `phi-4`: Πιο ικανή έκδοση με καλύτερη λογική

**Μεσαία Μοντέλα:**
- `qwen2.5-7b`: Εξαιρετική λογική και μεγαλύτερο πλαίσιο
- `deepseek-r1-7b`: Βελτιστοποιημένο για δημιουργία κώδικα

**Μεγαλύτερα Μοντέλα:**
- `llama-3.2`: Το πιο πρόσφατο μοντέλο ανοιχτού κώδικα της Meta
- `qwen2.5-14b`: Επιχειρησιακής κλάσης λογική

## Μέρος 3: Cache Μοντέλου και Διαχείριση Αποθήκευσης

### Κατανόηση της Cache Μοντέλου

Το Foundry Local διαχειρίζεται αυτόματα τη λήψη και την cache των μοντέλων:

```cmd
REM Check cache directory and contents
foundry cache ls

REM View cache location
foundry cache cd

REM Clean up unused models (if needed)
foundry cache clean
```

### Θεωρήσεις Αποθήκευσης Μοντέλου

**Τυπικά Μεγέθη Μοντέλων:**
- `phi-4-mini`: ~2.5 GB
- `qwen2.5-7b`: ~4.1 GB  
- `deepseek-r1-7b`: ~4.3 GB
- `llama-3.2`: ~4.9 GB
- `qwen2.5-14b`: ~8.2 GB

**Καλύτερες Πρακτικές Αποθήκευσης:**
- Κρατήστε 2-3 μοντέλα στην cache για γρήγορη εναλλαγή
- Αφαιρέστε μη χρησιμοποιούμενα μοντέλα για να ελευθερώσετε χώρο: `foundry cache clean`
- Παρακολουθείτε τη χρήση δίσκου, ειδικά σε μικρότερα SSD
- Σκεφτείτε τα μεγέθη μοντέλων έναντι των δυνατοτήτων

## Μέρος 5: Απλή Αξιολόγηση Απόδοσης Μοντέλων

### Βασική Δοκιμή Απόδοσης

Εδώ είναι μια απλή προσέγγιση για τη σύγκριση της απόδοσης μοντέλων:

```python
# simple_bench.py - Βασισμένο στα πρότυπα Δείγμα 03
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# Δοκιμάστε το τρέχον μοντέλο που εκτελείται
if __name__ == "__main__":
    # Δοκιμάστε με διαφορετικά μοντέλα (ξεκινήστε πρώτα κάθε μοντέλο)
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```

### Χειροκίνητη Αξιολόγηση Ποιότητας

Για κάθε μοντέλο, δοκιμάστε με συνεπή prompts και αξιολογήστε χειροκίνητα:

**Δοκιμαστικά Prompts:**
1. "Εξηγήστε τους κβαντικούς υπολογιστές με απλά λόγια."
2. "Γράψτε μια συνάρτηση Python για ταξινόμηση μιας λίστας."
3. "Ποια είναι τα πλεονεκτήματα και τα μειονεκτήματα της απομακρυσμένης εργασίας;"
4. "Περίληψη των ωφελειών της edge AI."

**Κριτήρια Αξιολόγησης:**
- **Ακρίβεια**: Είναι οι πληροφορίες σωστές;
- **Καθαρότητα**: Είναι η εξήγηση εύκολη στην κατανόηση;
- **Πληρότητα**: Απαντά στο πλήρες ερώτημα;
- **Ταχύτητα**: Πόσο γρήγορα ανταποκρίνεται;
