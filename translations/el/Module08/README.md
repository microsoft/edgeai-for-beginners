# Ενότητα 08: Πρακτική με το Microsoft Foundry Local - Πλήρης Εργαλειοθήκη Προγραμματιστή

## Επισκόπηση

Το [Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) αντιπροσωπεύει την επόμενη γενιά ανάπτυξης edge AI, παρέχοντας στους προγραμματιστές ισχυρά εργαλεία για να δημιουργούν, αναπτύσσουν και κλιμακώνουν εφαρμογές AI τοπικά, διατηρώντας παράλληλα αδιάλειπτη ενσωμάτωση με το Azure AI Foundry. Αυτή η ενότητα προσφέρει ολοκληρωμένη κάλυψη του Foundry Local από την εγκατάσταση έως την προηγμένη ανάπτυξη πρακτόρων.

**Βασικές Τεχνολογίες:**
- CLI και SDK του Microsoft Foundry Local
- Ενσωμάτωση με Azure AI Foundry
- Εξαγωγή συμπερασμάτων μοντέλων στη συσκευή
- Τοπική προσωρινή αποθήκευση και βελτιστοποίηση μοντέλων
- Αρχιτεκτονικές με βάση πράκτορες

## Στόχοι Μάθησης

Με την ολοκλήρωση αυτής της ενότητας, θα:

- **Κατακτήσετε το Foundry Local**: Εγκατάσταση, ρύθμιση και βελτιστοποίηση για ανάπτυξη στα Windows 11
- **Αναπτύξετε Ποικίλα Μοντέλα**: Εκτέλεση μοντέλων phi, qwen, deepseek και GPT τοπικά με εντολές CLI
- **Δημιουργήσετε Παραγωγικές Λύσεις**: Κατασκευή εφαρμογών AI με προηγμένη μηχανική ερωτημάτων και ενσωμάτωση δεδομένων
- **Αξιοποιήσετε το Οικοσύστημα Ανοιχτού Κώδικα**: Ενσωμάτωση μοντέλων Hugging Face και κοινοτικών συνεισφορών
- **Αναπτύξετε Πράκτορες AI**: Δημιουργία έξυπνων πρακτόρων με δυνατότητες καθοδήγησης και ορχήστρωσης
- **Υλοποιήσετε Εταιρικά Μοτίβα**: Δημιουργία αρθρωτών, κλιμακούμενων λύσεων AI για παραγωγική ανάπτυξη

## Προαπαιτούμενα

### Απαιτήσεις Συστήματος
- **Λειτουργικό Σύστημα**: Windows 11 (22H2 ή νεότερο)
- **Μνήμη**: 16GB RAM (συνιστώνται 32GB για μεγαλύτερα μοντέλα)
- **Χώρος Αποθήκευσης**: 50GB ελεύθερου χώρου για προσωρινή αποθήκευση μοντέλων
- **Υλικό**: Συνιστάται συσκευή με NPU (PC Copilot+), GPU προαιρετικό
- **Δίκτυο**: Υψηλής ταχύτητας σύνδεση στο διαδίκτυο για αρχικές λήψεις μοντέλων

### Περιβάλλον Ανάπτυξης

- Visual Studio Code με την επέκταση AI Toolkit
- Python 3.10+ και pip
- Git για έλεγχο εκδόσεων
- PowerShell ή Command Prompt
- Azure CLI (προαιρετικό για ενσωμάτωση στο cloud)

### Προαπαιτούμενες Γνώσεις
- Βασική κατανόηση εννοιών AI/ML
- Εξοικείωση με τη γραμμή εντολών
- Βασικές γνώσεις προγραμματισμού Python
- Έννοιες REST API
- Βασικές γνώσεις για prompting και εξαγωγή συμπερασμάτων μοντέλων

## Σύνοψη


Αυτό το module αντιπροσωπεύει την αιχμή της ανάπτυξης edge AI, συνδυάζοντας τα εργαλεία επιχειρηματικού επιπέδου της Microsoft με την ευελιξία και την καινοτομία του οικοσυστήματος ανοιχτού κώδικα. Κατακτώντας το Foundry Local μέσα από όλα τα 10 ολοκληρωμένα δείγματα, θα βρεθείτε στην πρώτη γραμμή της ανάπτυξης εφαρμογών AI.

**Ολοκληρωμένη Διαδρομή Μάθησης:**
- **Θεμέλιο** (Δείγματα 01-03): Ενσωμάτωση API και διαχείριση μοντέλου
- **Εφαρμογές** (Δείγματα 04-06): RAG, πράκτορες και έξυπνη δρομολόγηση
- **Προχωρημένο** (Δείγματα 07-10): Πλαίσια παραγωγής και ενσωμάτωση σε επιχειρήσεις

Για ενσωμάτωση Azure OpenAI (Συνεδρία 2), δείτε τα ξεχωριστά αρχεία README των δειγμάτων για τις απαιτούμενες μεταβλητές περιβάλλοντος και τις ρυθμίσεις έκδοσης API.
