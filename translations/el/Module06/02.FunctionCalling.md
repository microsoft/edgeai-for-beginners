## Τι είναι η Κλήση Συνάρτησης;

Η κλήση συνάρτησης είναι μια ισχυρή δυνατότητα που επιτρέπει στα Μικρά Μοντέλα Γλώσσας (SLMs) να αλληλεπιδρούν με εξωτερικά εργαλεία, APIs και υπηρεσίες. Αντί να περιορίζονται στα δεδομένα εκπαίδευσής τους, τα SLMs μπορούν τώρα:

- **Σύνδεση με εξωτερικά APIs** (υπηρεσίες καιρού, βάσεις δεδομένων, μηχανές αναζήτησης)
- **Εκτέλεση συγκεκριμένων συναρτήσεων** βάσει αιτημάτων χρηστών
- **Ανάκτηση πληροφοριών σε πραγματικό χρόνο** από διάφορες πηγές
- **Εκτέλεση υπολογιστικών εργασιών** μέσω εξειδικευμένων εργαλείων
- **Αλυσίδωση πολλών ενεργειών** για σύνθετες ροές εργασίας

Αυτή η δυνατότητα μετατρέπει τα SLMs από στατικούς δημιουργούς κειμένου σε δυναμικούς πράκτορες AI που μπορούν να εκτελούν εργασίες στον πραγματικό κόσμο.

## Πώς Λειτουργεί η Κλήση Συνάρτησης

Η διαδικασία κλήσης συνάρτησης ακολουθεί μια συστηματική ροή εργασίας:

### 1. Ενσωμάτωση Εργαλείων
- **Εξωτερικά Εργαλεία**: Τα SLMs μπορούν να συνδεθούν με APIs καιρού, βάσεις δεδομένων, web services και άλλα εξωτερικά συστήματα
- **Ορισμοί Συναρτήσεων**: Κάθε εργαλείο ορίζεται με συγκεκριμένες παραμέτρους, μορφές εισόδου/εξόδου και περιγραφές
- **Συμβατότητα API**: Τα εργαλεία ενσωματώνονται μέσω τυποποιημένων διεπαφών (REST APIs, SDKs κ.ά.)

### 2. Ορισμός Συνάρτησης
Οι συναρτήσεις ορίζονται με τρία βασικά στοιχεία:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Ανίχνευση Πρόθεσης
- **Επεξεργασία Φυσικής Γλώσσας**: Το SLM αναλύει την είσοδο του χρήστη για να κατανοήσει την πρόθεση
- **Ταύτιση Συνάρτησης**: Καθορίζει ποια συνάρτηση/ες απαιτούνται για την ικανοποίηση του αιτήματος
- **Εξαγωγή Παραμέτρων**: Εντοπίζει και εξάγει τις απαιτούμενες παραμέτρους από το μήνυμα του χρήστη

### 4. Δημιουργία Έξοδου JSON
Το SLM παράγει δομημένο JSON που περιέχει:
- Όνομα της συνάρτησης προς κλήση
- Απαιτούμενες παραμέτρους με τις κατάλληλες τιμές
- Πλαίσιο εκτέλεσης και μεταδεδομένα

### 5. Εξωτερική Εκτέλεση
- **Επικύρωση Παραμέτρων**: Διασφαλίζει ότι όλες οι απαιτούμενες παράμετροι υπάρχουν και είναι σωστά μορφοποιημένες
- **Εκτέλεση Συνάρτησης**: Η εφαρμογή εκτελεί την καθορισμένη συνάρτηση με τις παρεχόμενες παραμέτρους
- **Διαχείριση Σφαλμάτων**: Αντιμετωπίζει αποτυχίες, χρονικά όρια και λανθασμένες απαντήσεις

### 6. Ενσωμάτωση Απάντησης
- **Επεξεργασία Αποτελεσμάτων**: Η έξοδος της συνάρτησης επιστρέφεται στο SLM
- **Ενσωμάτωση Πλαισίου**: Το SLM ενσωματώνει τα αποτελέσματα στην απάντησή του
- **Επικοινωνία με Χρήστη**: Παρουσιάζει τις πληροφορίες σε φυσική, συνομιλιακή μορφή

## Σενάρια Εφαρμογής

### Ανάκτηση Δεδομένων
Μετατρέψτε ερωτήματα φυσικής γλώσσας σε δομημένες κλήσεις API:
- **"Δείξε μου τις πρόσφατες παραγγελίες"** → Ερώτημα βάσης δεδομένων με ID χρήστη και φίλτρα ημερομηνιών
- **"Ποιος είναι ο καιρός στο Τόκιο;"** → Κλήση API καιρού με παράμετρο τοποθεσίας
- **"Βρες τα email από τον John την περασμένη εβδομάδα"** → Ερώτημα υπηρεσίας email με φίλτρα αποστολέα και ημερομηνίας

### Εκτέλεση Ενεργειών
Μετατρέψτε αιτήματα χρηστών σε συγκεκριμένες κλήσεις συναρτήσεων:
- **"Προγραμμάτισε μια συνάντηση για αύριο στις 2 μμ"** → Ενσωμάτωση API ημερολογίου
- **"Στείλε μήνυμα στην ομάδα"** → API πλατφόρμας επικοινωνίας
- **"Δημιούργησε αντίγραφο ασφαλείας των αρχείων μου"** → Ενέργεια αρχείου συστήματος

### Υπολογιστικές Εργασίες
Αντιμετωπίστε σύνθετες μαθηματικές ή λογικές εργασίες:
- **"Υπολόγισε το σύνθετο επιτόκιο για $10,000 με 5% για 10 χρόνια"** → Συνάρτηση οικονομικού υπολογισμού
- **"Ανάλυσε αυτό το σύνολο δεδομένων για τάσεις"** → Εργαλεία στατιστικής ανάλυσης
- **"Βελτιστοποίησε αυτή τη διαδρομή για παράδοση"** → Αλγόριθμοι βελτιστοποίησης διαδρομής

### Ροές Επεξεργασίας Δεδομένων
Αλυσιδωτές κλήσεις πολλών συναρτήσεων για σύνθετες εργασίες:
1. **Ανάκτηση δεδομένων** από πολλές πηγές
2. **Ανάλυση και επικύρωση** των πληροφοριών
3. **Μετασχηματισμός** των δεδομένων στην απαιτούμενη μορφή
4. **Αποθήκευση αποτελεσμάτων** σε κατάλληλα συστήματα
5. **Δημιουργία αναφορών** ή απεικονίσεων

### Ενσωμάτωση UI/UX
Δυναμικές ενημερώσεις διεπαφής:
- **"Δείξε δεδομένα πωλήσεων στον πίνακα ελέγχου"** → Δημιουργία και εμφάνιση γραφήματος
- **"Ενημέρωσε τον χάρτη με νέες τοποθεσίες"** → Ενσωμάτωση γεωχωρικών δεδομένων
- **"Ανανέωσε την εμφάνιση αποθέματος"** → Συγχρονισμός δεδομένων σε πραγματικό χρόνο

```python

    'model': 'Qwen3-8B',
    # Επιλογή 1: Χρησιμοποιήστε το Alibaba Model Studio
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # Επιλογή 2: Χρησιμοποιήστε τοπική ανάπτυξη
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'ΚΕΝΟ',
    
    # Προαιρετική διαμόρφωση για λειτουργία σκέψης

                'command': 'uvx',
```

### Υλοποίηση Προσαρμοσμένων Συναρτήσεων

Μπορείτε επίσης να ορίσετε προσαρμοσμένες συναρτήσεις για το Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Προσομοίωση κλήσης API καιρού
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Χρησιμοποιήστε το προσαρμοσμένο εργαλείο
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

## Τοπική Ενσωμάτωση Foundry

Το Foundry Local της Microsoft παρέχει ένα API συμβατό με OpenAI για εκτέλεση μοντέλων τοπικά με αυξημένη ιδιωτικότητα και απόδοση.

### Ρύθμιση και Εγκατάσταση

#### Windows
Κατεβάστε τον εγκαταστάτη από τη [σελίδα εκδόσεων Foundry Local](https://github.com/microsoft/Foundry-Local/releases) και ακολουθήστε τις οδηγίες εγκατάστασης.

#### macOS
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

#### Βασική Χρήση

```python
import openai
from foundry_local import FoundryLocalManager

# Αρχικοποίηση με ψευδώνυμο μοντέλου
alias = "phi-3.5-mini"  # Ή οποιοδήποτε υποστηριζόμενο μοντέλο
manager = FoundryLocalManager(alias)

# Δημιουργία πελάτη OpenAI που δείχνει στην τοπική διεύθυνση
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Ορισμός συναρτήσεων για το μοντέλο
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Κάντε αίτημα κλήσης συνάρτησης
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

```python
import asyncio
import json
from typing import Dict, List, Any
from dataclasses import dataclass
from datetime import datetime

@dataclass
class FunctionResult:
    """Standard result format for all function calls"""
    success: bool
    data: Any = None
    error: str = None
    execution_time: float = 0.0
    timestamp: datetime = None

class EnterpriseAIAgent:
    """Production-ready AI agent with comprehensive function calling capabilities"""
    
    def __init__(self, config: Dict):
        self.config = config
        self.functions = {}
        self.audit_log = []
        self.rate_limiters = {}
        
        # Αρχικοποιήστε βασικές επιχειρηματικές λειτουργίες
        self._register_core_functions()
    
    def _register_core_functions(self):
        """Register all available business functions"""
        
        # Λειτουργίες CRM
        self.register_function(
            name="get_customer_info",
            description="Retrieve customer information from CRM",
            parameters={
                "customer_id": {"type": "string", "required": True},

        )
        
        # Λειτουργίες πωλήσεων
        self.register_function(

            parameters={

                "expected_close_date": {"type": "string", "required": True}
            },
            handler=self._create_sales_opportunity,
            rate_limit=50
        )
        
        # Λειτουργίες αναλύσεων
        self.register_function(
            name="generate_sales_report",
            description="Generate sales performance report",
            parameters={
                "period": {"type": "string", "enum": ["daily", "weekly", "monthly", "quarterly"]},
                "region": {"type": "string", "required": False},
                "product_category": {"type": "string", "required": False}
            },
            handler=self._generate_sales_report,
            rate_limit=10
        )
        
        # Λειτουργίες ειδοποιήσεων
        self.register_function(
            name="send_notification",
            description="Send notification to team members",
            parameters={
                "recipients": {"type": "array", "items": {"type": "string"}},
                "message": {"type": "string", "required": True},
                "priority": {"type": "string", "enum": ["low", "medium", "high"], "default": "medium"},
                "channel": {"type": "string", "enum": ["email", "slack", "teams"], "default": "email"}
            },
            handler=self._send_notification,
            rate_limit=200
        )
    
    def register_function(self, name: str, description: str, parameters: Dict, 
                         handler: callable, rate_limit: int = 60):
        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Επαληθεύστε ότι η λειτουργία υπάρχει
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Ελέγξτε τα όρια ρυθμού
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Επαληθεύστε τις παραμέτρους
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Εκτελέστε τη λειτουργία
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Καταγράψτε την επιτυχή εκτέλεση
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Καταγράψτε την αποτυχημένη εκτέλεση
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Επαναφέρετε τον μετρητή αν έχει περάσει ένα λεπτό
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Ελέγξτε αν είναι εντός ορίου
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Ελέγξτε τις απαιτούμενες παραμέτρους
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Επαληθεύστε τους τύπους και τους περιορισμούς παραμέτρων
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Επαλήθευση τύπου
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # Επαλήθευση enum
                if 'enum' in param_info and value not in param_info['enum']:

                        success=False,

                definition['parameters']['properties'][param_name] = {

                    'description': param_info.get('description', '')
                }
```

## Συμπέρασμα

Η κλήση συνάρτησης στα Μικρά Μοντέλα Γλώσσας αντιπροσωπεύει μια αλλαγή παραδείγματος από στατικούς βοηθούς AI σε δυναμικούς, ικανούς πράκτορες που μπορούν να αλληλεπιδρούν με τον πραγματικό κόσμο. Αυτό το σεμινάριο κάλυψε:

### Κύρια Σημεία

1. **Βασική Κατανόηση**: Η κλήση συνάρτησης επιτρέπει στα SLM να επεκτείνονται πέρα από τα δεδομένα εκπαίδευσής τους συνδεόμενα με εξωτερικά εργαλεία και υπηρεσίες.

2. **Ευελιξία Υλοποίησης**: Υπάρχουν πολλαπλές προσεγγίσεις, από χαμηλού επιπέδου υλοποιήσεις με προσαρμοσμένα πρότυπα έως πλαίσια υψηλού επιπέδου όπως το Qwen-Agent και το Foundry Local.

3. **Παραμέτρους Παραγωγής**: Οι επιχειρησιακές αναπτύξεις απαιτούν προσοχή στη διαχείριση σφαλμάτων, τον περιορισμό ρυθμού, την ασφάλεια και την καταγραφή ελέγχου.

4. **Βελτιστοποίηση Απόδοσης**: Ο κατάλληλος σχεδιασμός συνάρτησης, η αποδοτική εκτέλεση και η έξυπνη αποθήκευση μπορούν να βελτιώσουν σημαντικά τους χρόνους απόκρισης.

### Μελλοντικές Κατευθύνσεις

Καθώς η τεχνολογία SLM εξελίσσεται, αναμένουμε:

- **Βελτίωση Ακρίβειας Κλήσης Συνάρτησης**: Καλύτερη ανίχνευση πρόθεσης και εξαγωγή παραμέτρων
- **Ενισχυμένη Παράλληλη Επεξεργασία**: Πιο εξελιγμένη ορχήστρωση πολλαπλών συναρτήσεων
- **Καλύτερα Πρότυπα Ενσωμάτωσης**: Τυποποιημένα πρωτόκολλα για ενσωμάτωση εργαλείων
- **Προηγμένα Χαρακτηριστικά Ασφάλειας**: Ενισχυμένοι μηχανισμοί πιστοποίησης και εξουσιοδότησης
- **Διευρυμένο Οικοσύστημα**: Ανάπτυξη βιβλιοθήκης προκατασκευασμένων συναρτήσεων και ενσωματώσεων

### Ξεκινώντας

Για να ξεκινήσετε την υλοποίηση κλήσης συνάρτησης στα έργα σας:

1. **Ξεκινήστε Απλά**: Ξεκινήστε με βασικά σενάρια μεμονωμένης συνάρτησης
2. **Επιλέξτε το Πλαίσιο σας**: Επιλέξτε μεταξύ άμεσης υλοποίησης (Ollama/Phi-4) ή πλαίσιο υποβοήθησης (Qwen-Agent)
3. **Σχεδιάστε Προσεκτικά τις Συναρτήσεις**: Επικεντρωθείτε σε καθαρές, καλά τεκμηριωμένες ορισμούς συναρτήσεων
4. **Υλοποιήστε Διαχείριση Σφαλμάτων**: Δημιουργήστε ανθεκτική διαχείριση σφαλμάτων από την αρχή
5. **Κλιμακώστε Σταδιακά**: Μεταβείτε από απλά σε σύνθετα σενάρια καθώς αποκτάτε εμπειρία

Η κλήση συνάρτησης μετατρέπει τα SLM από εντυπωσιακούς δημιουργούς κειμένου σε πρακτικούς πράκτορες AI ικανούς να λύνουν προβλήματα του πραγματικού κόσμου.
