# Ενότητα 03 - Ολοκλήρωση Πρωτοκόλλου Πλαισίου Μοντέλου (MCP)

## Εισαγωγή στο MCP (Model Context Protocol)

Το Πρωτόκολλο Πλαισίου Μοντέλου (MCP) είναι ένα ανοιχτού κώδικα πρότυπο για τη σύνδεση εφαρμογών ΤΝ με εξωτερικά συστήματα. Χρησιμοποιώντας το MCP, εφαρμογές ΤΝ όπως ο Claude ή το ChatGPT μπορούν να συνδεθούν σε πηγές δεδομένων (π.χ., τοπικά αρχεία, βάσεις δεδομένων), εργαλεία (π.χ., μηχανές αναζήτησης, υπολογιστές) και ροές εργασίας (π.χ., εξειδικευμένες εντολές)—ενεργοποιώντας την πρόσβαση σε βασικές πληροφορίες και την εκτέλεση εργασιών.

Σκεφτείτε το MCP σαν μια **θύρα USB-C για εφαρμογές ΤΝ**. Όπως η USB-C παρέχει έναν τυποποιημένο τρόπο σύνδεσης ηλεκτρονικών συσκευών, έτσι το MCP παρέχει έναν τυποποιημένο τρόπο για τη σύνδεση εφαρμογών ΤΝ με εξωτερικά συστήματα.

### Τι Μπορεί να Επιτρέψει το MCP;

Το MCP ξεκλειδώνει ισχυρές δυνατότητες για εφαρμογές ΤΝ:

- **Εξατομικευμένοι Βοηθοί ΤΝ**: Οι πράκτορες μπορούν να έχουν πρόσβαση στο Ημερολόγιό σας Google και στο Notion, λειτουργώντας σαν πιο εξατομικευμένος βοηθός ΤΝ
- **Προηγμένη Δημιουργία Κώδικα**: Το Claude Code μπορεί να δημιουργήσει μια ολόκληρη εφαρμογή ιστού χρησιμοποιώντας ένα σχέδιο Figma
- **Ενσωμάτωση Επιχειρησιακών Δεδομένων**: Επιχειρησιακά chatbot μπορούν να συνδεθούν σε πολλαπλές βάσεις δεδομένων σε έναν οργανισμό, δρώντας ώστε οι χρήστες να αναλύουν δεδομένα μέσω συνομιλίας
- **Δημιουργικές Ροές Εργασίας**: Μοντέλα ΤΝ μπορούν να δημιουργήσουν 3D σχέδια στο Blender και να τα εκτυπώσουν χρησιμοποιώντας έναν 3D εκτυπωτή
- **Πρόσβαση σε Πληροφορίες σε Πραγματικό Χρόνο**: Σύνδεση με εξωτερικές πηγές δεδομένων για ενημερωμένες πληροφορίες
- **Σύνθετες Πολυβηματικές Λειτουργίες**: Εκτέλεση προηγμένων ροών εργασίας που συνδυάζουν πολλαπλά εργαλεία και συστήματα

### Γιατί Είναι Σημαντικό το MCP;

Το MCP προσφέρει οφέλη σε ολόκληρο το οικοσύστημα:

**Για Προγραμματιστές**: Το MCP μειώνει τον χρόνο ανάπτυξης και την πολυπλοκότητα κατά την κατασκευή ή ενσωμάτωση σε εφαρμογή ή πράκτορα ΤΝ.

**Για Εφαρμογές ΤΝ**: Το MCP παρέχει πρόσβαση σε οικοσύστημα πηγών δεδομένων, εργαλείων και εφαρμογών που ενισχύουν τις δυνατότητες και βελτιώνουν την εμπειρία του τελικού χρήστη.

**Για Τελικούς Χρήστες**: Το MCP οδηγεί σε πιο ικανές εφαρμογές ή πράκτορες ΤΝ που μπορούν να έχουν πρόσβαση στα δεδομένα σας και να αναλάβουν δράσεις με εκ μέρους σας όταν είναι αναγκαίο.

## Μικρά Γλωσσικά Μοντέλα (SLMs) στο MCP

Τα Μικρά Γλωσσικά Μοντέλα αντιπροσωπεύουν μια αποτελεσματική προσέγγιση στην ανάπτυξη ΤΝ, προσφέροντας αρκετά πλεονεκτήματα:

### Πλεονεκτήματα των SLMs
- **Αποδοτικότητα Πόρων**: Χαμηλότερες απαιτήσεις υπολογιστών
- **Ταχύτεροι Χρόνοι Απόκρισης**: Μειωμένη καθυστέρηση για εφαρμογές σε πραγματικό χρόνο  
- **Οικονομία**: Ελάχιστες ανάγκες υποδομής
- **Απόρρητο**: Μπορεί να τρέξει τοπικά χωρίς μετάδοση δεδομένων
- **Εξατομίκευση**: Εύκολη βελτιστοποίηση για συγκεκριμένους τομείς

### Γιατί τα SLMs Λειτουργούν Καλά με το MCP

Τα SLMs σε συνδυασμό με το MCP δημιουργούν έναν ισχυρό συνδυασμό όπου οι ικανότητες σκέψης του μοντέλου ενισχύονται με εξωτερικά εργαλεία, αντισταθμίζοντας τον μικρότερο αριθμό παραμέτρων τους μέσω βελτιωμένης λειτουργικότητας.

## Επισκόπηση Python MCP SDK

Το Python MCP SDK παρέχει τη βάση για την κατασκευή εφαρμογών που υποστηρίζουν MCP. Το SDK περιλαμβάνει:

- **Βιβλιοθήκες Client**: Για σύνδεση με διακομιστές MCP
- **Πλαίσιο Server**: Για δημιουργία προσαρμοσμένων διακομιστών MCP
- **Διαχειριστές Πρωτοκόλλου**: Για διαχείριση της επικοινωνίας
- **Ενσωμάτωση Εργαλείων**: Για την εκτέλεση εξωτερικών λειτουργιών

### Επισκόπηση Αρχιτεκτονικής MCP

Το MCP ακολουθεί μια **αρχιτεκτονική πελάτη-διακομιστή** όπου ένας διακομιστής MCP (μια εφαρμογή ΤΝ όπως Claude Code ή Claude Desktop) δημιουργεί συνδέσεις με έναν ή περισσότερους διακομιστές MCP. Ο διακομιστής επιτυγχάνει αυτό δημιουργώντας έναν πελάτη MCP για κάθε διακομιστή MCP.

#### Κύριοι Συμμετέχοντες

- **Διακομιστής MCP**: Η εφαρμογή ΤΝ που συντονίζει και διαχειρίζεται έναν ή πολλαπλούς πελάτες MCP
- **Πελάτης MCP**: Μια συνιστώσα που διατηρεί σύνδεση με διακομιστή MCP και λαμβάνει πλαίσιο από αυτόν για χρήση από τον διακομιστή MCP
- **Διακομιστής MCP**: Ένα πρόγραμμα που παρέχει πλαίσιο στους πελάτες MCP

#### Διπλό-Επίπεδη Αρχιτεκτονική

Το MCP αποτελείται από δύο διακριτά επίπεδα:

**Επίπεδο Δεδομένων**: Ορίζει το πρωτόκολλο βασισμένο σε JSON-RPC για την επικοινωνία πελάτη-διακομιστή, συμπεριλαμβανομένων:
- Διαχείριση κύκλου ζωής (εκκίνηση σύνδεσης, διαπραγμάτευση δυνατοτήτων)
- Βασικές πρωτόγονες λειτουργίες (εργαλεία, πόροι, εντολές)
- Χαρακτηριστικά πελάτη (δειγματοληψία, εκτίμηση, καταγραφή)
- Χαρακτηριστικά βοηθητικά (ειδοποιήσεις, παρακολούθηση προόδου)

**Επίπεδο Μεταφοράς**: Ορίζει τους μηχανισμούς και τα κανάλια επικοινωνίας:
- **Μεταφορά STDIO**: Χρησιμοποιεί ροές εισόδου/εξόδου για τοπικές διεργασίες (βελτιστοποιημένη απόδοση, χωρίς επίβάρυνση δικτύου)
- **Μεταφορά Streamable HTTP**: Χρησιμοποιεί HTTP POST με προαιρετικά Server-Sent Events για απομακρυσμένους διακομιστές (υποστηρίζει τυπική HTTP αυθεντικοποίηση)

### Βασικές Πρωτόγονες Λειτουργίες MCP

Το MCP ορίζει πρωτόγονες λειτουργίες που καθορίζουν τους τύπους των πληροφοριών πλαισίου που μπορούν να μοιραστούν με εφαρμογές ΤΝ και το εύρος των ενεργειών που μπορούν να εκτελεστούν.

#### Πρωτόγονα Διακομιστή

Το MCP ορίζει τρία βασικά πρωτόγονα που μπορούν να εκθέσουν οι διακομιστές:

**Εργαλεία**: Εκτελέσιμες λειτουργίες που οι εφαρμογές ΤΝ μπορούν να καλούν για να εκτελέσουν ενέργειες
- Παραδείγματα: λειτουργίες αρχείων, κλήσεις API, ερωτήματα βάσης δεδομένων
- Μέθοδοι: `tools/list`, `tools/call`
- Υποστηρίζουν δυναμική ανίχνευση και εκτέλεση

**Πόροι**: Πηγές δεδομένων που παρέχουν πληροφορίες πλαισίου στις εφαρμογές ΤΝ
- Παραδείγματα: περιεχόμενο αρχείων, εγγραφές βάσεων δεδομένων, απαντήσεις API
- Μέθοδοι: `resources/list`, `resources/read`
- Επιτρέπουν πρόσβαση σε δομημένα δεδομένα

**Εντολές**: Επαναχρησιμοποιούμενα πρότυπα που βοηθούν στη δομή των αλληλεπιδράσεων με μοντέλα γλώσσας
- Παραδείγματα: εντολές συστήματος, παραδείγματα few-shot
- Μέθοδοι: `prompts/list`, `prompts/get`
- Τυποποιούν πρότυπα αλληλεπίδρασης με ΤΝ

#### Πρωτόγονα Πελάτη

Το MCP ορίζει επίσης πρωτόγονες λειτουργίες που μπορούν να εκθέσουν οι πελάτες για να επιτρέψουν πλουσιότερες αλληλεπιδράσεις:

**Δειγματοληψία**: Επιτρέπει στους διακομιστές να ζητούν ολοκληρώσεις από το μοντέλο γλώσσας της εφαρμογής ΤΝ του πελάτη
- Μέθοδος: `sampling/complete`
- Επιτρέπει ανάπτυξη διακομιστή ανεξάρτητου μοντέλου
- Παρέχει πρόσβαση στο μοντέλο γλώσσας του οικοδεσπότη

**Αίτηση Πληροφοριών**: Επιτρέπει στους διακομιστές να ζητούν πρόσθετες πληροφορίες από χρήστες
- Μέθοδος: `elicitation/request`
- Επιτρέπει αλληλεπίδραση και επιβεβαίωση από χρήστες
- Υποστηρίζει δυναμική συλλογή πληροφοριών

**Καταγραφή**: Παρέχει τη δυνατότητα στους διακομιστές να στέλνουν μηνύματα καταγραφής στους πελάτες
- Χρησιμοποιείται για έλεγχο και παρακολούθηση
- Παρέχει ορατότητα στις λειτουργίες του διακομιστή

### Κύκλος Ζωής Πρωτοκόλλου MCP

#### Εκκίνηση και Διαπραγμάτευση Δυνατοτήτων

Το MCP είναι ένα κατάσταση-διατηρούμενο πρωτόκολλο που απαιτεί διαχείριση κύκλου ζωής. Η διαδικασία εκκίνησης εξυπηρετεί πολλαπλούς κρίσιμους σκοπούς:

1. **Διαπραγμάτευση Έκδοσης Πρωτοκόλλου**: Διασφαλίζει ότι πελάτης και διακομιστής χρησιμοποιούν συμβατές εκδόσεις πρωτοκόλλου (π.χ., "2025-06-18")
2. **Ανακάλυψη Δυνατοτήτων**: Κάθε μέρος δηλώνει τις υποστηριζόμενες λειτουργίες και πρωτόγονα
3. **Ανταλλαγή Ταυτότητας**: Παρέχει πληροφορίες αναγνώρισης και έκδοσης

```python
# Παράδειγμα αιτήματος αρχικοποίησης
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {
      "elicitation": {},  # Ο πελάτης υποστηρίζει αλληλεπίδραση χρήστη
      "sampling": {}      # Ο πελάτης μπορεί να παρέχει συμπληρώσεις LLM
    },
    "clientInfo": {
      "name": "edge-ai-client",
      "version": "1.0.0"
    }
  }
}
```

#### Ανακάλυψη και Εκτέλεση Εργαλείων

Μετά την εκκίνηση, οι πελάτες μπορούν να εντοπίσουν και να εκτελέσουν εργαλεία:

```python
# Ανακαλύψτε διαθέσιμα εργαλεία
tools_response = await session.list_tools()

# Εκτελέστε ένα εργαλείο
result = await session.call_tool(
    "weather_current",
    {
        "location": "San Francisco",
        "units": "imperial"
    }
)
```

#### Ειδοποιήσεις σε Πραγματικό Χρόνο

Το MCP υποστηρίζει ειδοποιήσεις σε πραγματικό χρόνο για δυναμικές ενημερώσεις:

```python
# Ο διακομιστής στέλνει ειδοποίηση όταν αλλάζουν τα εργαλεία
{
  "jsonrpc": "2.0",
  "method": "notifications/tools/list_changed"
}

# Ο πελάτης ανταποκρίνεται ανανεώνοντας τη λίστα εργαλείων
await session.list_tools()  # Λήψη ενημερωμένων εργαλείων
```

## Προηγμένα Χαρακτηριστικά

### Υποστήριξη Πολλαπλών Backend

Η υλοποίηση υποστηρίζει τόσο Ollama όσο και vLLM backend, δίνοντάς σας τη δυνατότητα επιλογής ανάλογα με τις ανάγκες σας:

- **Ollama**: Καλύτερο για τοπική ανάπτυξη και δοκιμές
- **vLLM**: Βελτιστοποιημένο για παραγωγή και σενάρια υψηλής απόδοσης

### Ευέλικτα Πρωτόκολλα Σύνδεσης

Υποστηρίζονται δύο τρόποι σύνδεσης:

**Λειτουργία STDIO**: Άμεση επικοινωνία διεργασιών
- Χαμηλότερη καθυστέρηση
- Κατάλληλο για τοπικά εργαλεία
- Απλή ρύθμιση

**Λειτουργία SSE**: Ροή βασισμένη σε HTTP
- Ικανό δίκτυο
- Καλύτερο για κατανεμημένα συστήματα
- Ενημερώσεις σε πραγματικό χρόνο

### Δυνατότητες Ενσωμάτωσης Εργαλείων

Το σύστημα μπορεί να ενσωματωθεί με ποικίλα εργαλεία:
- Αυτοματοποίηση ιστού (Playwright)
- Λειτουργίες αρχείων
- Αλληλεπιδράσεις API
- Εντολές συστήματος
- Προσαρμοσμένες λειτουργίες

## Οικοσύστημα MCP και Ανάπτυξη

### Εύρος Έργου MCP

Το οικοσύστημα του Πρωτοκόλλου Πλαισίου Μοντέλου περιλαμβάνει αρκετά βασικά συστατικά:

- **[Προδιαγραφή MCP](https://modelcontextprotocol.io/specification/latest)**: Επίσημη προδιαγραφή που καθορίζει απαιτήσεις υλοποίησης για πελάτες και διακομιστές
- **[SDKs MCP](https://modelcontextprotocol.io/docs/sdk)**: SDKs για διάφορες γλώσσες προγραμματισμού που υλοποιούν το MCP
- **Εργαλεία Ανάπτυξης MCP**: Εργαλεία για ανάπτυξη διακομιστών και πελατών MCP, συμπεριλαμβανομένου του [MCP Inspector](https://github.com/modelcontextprotocol/inspector)
- **[Υλοποιήσεις Αναφοράς Διακομιστών MCP](https://github.com/modelcontextprotocol/servers)**: Υλοποιήσεις αναφοράς διακομιστών MCP

### Ξεκινώντας με την Ανάπτυξη MCP

Για να αρχίσετε να αναπτύσσετε με MCP:

**Δημιουργία Διακομιστών**: [Δημιουργήστε διακομιστές MCP](https://modelcontextprotocol.io/docs/develop/build-server) για να εκθέσετε τα δεδομένα και τα εργαλεία σας

**Δημιουργία Πελατών**: [Αναπτύξτε εφαρμογές](https://modelcontextprotocol.io/docs/develop/build-client) που συνδέονται με διακομιστές MCP

**Μάθετε Έννοιες**: [Κατανοήστε τις βασικές έννοιες](https://modelcontextprotocol.io/docs/learn/architecture) και την αρχιτεκτονική του MCP

## Συμπέρασμα

Τα SLMs ενσωματωμένα με το MCP αντιπροσωπεύουν μια αλλαγή παραδείγματος στην ανάπτυξη εφαρμογών ΤΝ. Συνδυάζοντας την αποδοτικότητα μικρών μοντέλων με τη δύναμη εξωτερικών εργαλείων, οι προγραμματιστές μπορούν να δημιουργήσουν ευφυή συστήματα που είναι ταυτόχρονα αποδοτικά πόρων και εξαιρετικά ικανά.

Το Πρωτόκολλο Πλαισίου Μοντέλου παρέχει έναν τυποποιημένο τρόπο σύνδεσης εφαρμογών ΤΝ με εξωτερικά συστήματα, όπως η USB-C παρέχει ένα παγκόσμιο πρότυπο σύνδεσης για ηλεκτρονικές συσκευές. Αυτή η τυποποίηση επιτρέπει:

- **Αδιάλειπτη Ενσωμάτωση**: Σύνδεση μοντέλων ΤΝ με ποικίλες πηγές δεδομένων και εργαλεία
- **Ανάπτυξη Οικοσυστήματος**: Δημιουργία μιας φοράς, χρήση σε πολλές εφαρμογές ΤΝ
- **Ενισχυμένες Δυνατότητες**: Ενίσχυση των SLMs με εξωτερική λειτουργικότητα
- **Ενημερώσεις σε Πραγματικό Χρόνο**: Υποστήριξη δυναμικών, ανταποκρινόμενων εφαρμογών ΤΝ

Βασικά σημεία:
- Το MCP είναι ένα ανοιχτό πρότυπο που γεφυρώνει εφαρμογές ΤΝ και εξωτερικά συστήματα
- Το πρωτόκολλο υποστηρίζει εργαλεία, πόρους και εντολές ως βασικά πρωτόγονα
- Οι ειδοποιήσεις σε πραγματικό χρόνο επιτρέπουν δυναμικές, ανταποκρινόμενες εφαρμογές
- Η σωστή διαχείριση κύκλου ζωής και η διαχείριση σφαλμάτων είναι απαραίτητες για χρήση στην παραγωγή
- Το οικοσύστημα παρέχει ολοκληρωμένα SDKs και εργαλεία ανάπτυξης
