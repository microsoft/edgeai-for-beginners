## Εισαγωγή

Το Microsoft Olive είναι ένα ισχυρό, εύχρηστο εργαλείο βελτιστοποίησης μοντέλων με επίγνωση υλικού που απλοποιεί τη διαδικασία βελτιστοποίησης μοντέλων μηχανικής μάθησης για ανάπτυξη σε διαφορετικές πλατφόρμες υλικού. Είτε στοχεύετε CPU, GPU ή εξειδικευμένους επιταχυντές AI, το Olive σας βοηθά να πετύχετε βέλτιστη απόδοση διατηρώντας την ακρίβεια του μοντέλου.

## Τι είναι το Microsoft Olive;

Το Olive είναι ένα εύχρηστο εργαλείο βελτιστοποίησης μοντέλων με επίγνωση υλικού που συνδυάζει τεχνικές αιχμής στην συμπίεση, βελτιστοποίηση και μεταγλώττιση μοντέλων. Λειτουργεί με το ONNX Runtime ως πλήρης λύση βελτιστοποίησης inferencing. 

### Κύρια Χαρακτηριστικά

- **Βελτιστοποίηση με Επίγνωση Υλικού**: Επιλογή αυτόματων βέλτιστων τεχνικών για τον στοχευόμενο εξοπλισμό σας
- **Πάνω από 40 Ενσωματωμένα Συστατικά Βελτιστοποίησης**: Καλύπτει συμπίεση μοντέλων, κβαντοποίηση, βελτιστοποίηση γραφήματος και άλλα
- **Εύκολο CLI**: Απλές εντολές για κοινές εργασίες βελτιστοποίησης
- **Υποστήριξη Πολυπλαισίου**: Λειτουργεί με PyTorch, Hugging Face μοντέλα και ONNX
- **Υποστήριξη Δημοφιλών Μοντέλων**: Το Olive μπορεί να βελτιστοποιήσει αυτόματα δημοφιλείς αρχιτεκτονικές μοντέλων όπως Llama, Phi, Qwen, Gemma κλπ

### Οφέλη

- **Μειωμένος Χρόνος Ανάπτυξης**: Χωρίς ανάγκη χειροκίνητης δοκιμής διαφόρων τεχνικών βελτιστοποίησης
- **Κέρδη Απόδοσης**: Σημαντικές βελτιώσεις ταχύτητας (έως και 6 φορές σε κάποιες περιπτώσεις)
- **Ανάπτυξη Πλατφορμών**: Βελτιστοποιημένα μοντέλα λειτουργούν σε διαφορετικό υλικό και λειτουργικά συστήματα
- **Διατήρηση Ακρίβειας**: Οι βελτιστοποιήσεις διατηρούν την ποιότητα ενώ βελτιώνουν την απόδοση

## Οδηγός Γρήγορης Εκκίνησης

### Η πρώτη σας βελτιστοποίηση

Ας βελτιστοποιήσουμε ένα μικρό γλωσσικό μοντέλο χρησιμοποιώντας τη λειτουργία αυτόματης βελτιστοποίησης του Olive:

```bash
olive auto-opt \
  --model_name_or_path HuggingFaceTB/SmolLM2-135M-Instruct \
  --output_path models/smolm2-optimized \
  --device cpu \
  --provider CPUExecutionProvider \
  --use_ort_genai \
  --precision int4 \
  --log_level 1
```

### Τι κάνει αυτή η εντολή

Η διαδικασία βελτιστοποίησης περιλαμβάνει: απόκτηση μοντέλου από τον τοπικό cache, σύλληψη του ONNX Graph και αποθήκευση των βαρών σε αρχείο δεδομένων ONNX, βελτιστοποίηση του ONNX Graph, και κβαντοποίηση του μοντέλου σε int4 με τη μέθοδο RTN.

### Επεξήγηση παραμέτρων εντολής

- `--model_name_or_path`: Αναγνωριστικό μοντέλου Hugging Face ή τοπική διαδρομή
- `--output_path`: Φάκελος όπου θα αποθηκευτεί το βελτιστοποιημένο μοντέλο
- `--device`: Στοχευμένη συσκευή (cpu, gpu)
- `--provider`: Πάροχος εκτέλεσης (CPUExecutionProvider, CUDAExecutionProvider, DmlExecutionProvider)
- `--use_ort_genai`: Χρήση ONNX Runtime Generate AI για inferencing
- `--precision`: Ακρίβεια κβαντοποίησης (int4, int8, fp16)
- `--log_level`: Βαθμός καταγραφής (0=ελάχιστο, 1=λεπτομερές)

## Παράδειγμα: Μετατροπή Qwen3 σε ONNX INT4

Βασισμένο στο παράδειγμα Hugging Face στο [lokinfey/Qwen3-8B-ONNX-INT4-CPU](https://huggingface.co/lokinfey/Qwen3-8B-ONNX-INT4-CPU), εδώ είναι πώς να βελτιστοποιήσετε ένα μοντέλο Qwen3:

### Βήμα 1: Λήψη μοντέλου (Προαιρετικό)

Για να ελαχιστοποιήσετε τον χρόνο λήψης, κάντε cache μόνο τα απαραίτητα αρχεία:

```bash
huggingface-cli download Qwen/Qwen2.5-0.5B-Instruct *.json *.safetensors *.txt
```

### Βήμα 2: Βελτιστοποίηση μοντέλου Qwen3

```bash
olive auto-opt \
  --model_name_or_path Qwen/Qwen2.5-0.5B-Instruct \
  --output_path models/qwen3-onnx-int4 \
  --device cpu \
  --provider CPUExecutionProvider \
  --use_ort_genai \
  --precision int4 \
  --log_level 1
```

### Βήμα 3: Δοκιμάστε το βελτιστοποιημένο μοντέλο

Δημιουργήστε ένα απλό σενάριο Python για να δοκιμάσετε το βελτιστοποιημένο μοντέλο σας:

```python
import onnxruntime_genai as og

# Φορτώστε το βελτιστοποιημένο μοντέλο
model = og.Model('models/qwen3-onnx-int4')
tokenizer = og.Tokenizer(model)

# Δημιουργήστε ένα πρότυπο συνομιλίας
chat_template = '<|im_start|>user\n{input}<|im_end|>\n<|im_start|>assistant\n'

# Δημιουργήστε κείμενο
prompt = "What is machine learning?"
input_tokens = tokenizer.encode(chat_template.format(input=prompt))

params = og.GeneratorParams(model)
params.set_search_options(max_length=200)
params.input_ids = input_tokens

generator = og.Generator(model, params)

print("Generated response:")
while not generator.is_done():
    generator.compute_logits()
    generator.generate_next_token()
    
    new_token = generator.get_next_tokens()[0]
    print(tokenizer.decode([new_token]), end='', flush=True)

print()
```

### Δομή Έξοδου

Μετά τη βελτιστοποίηση, ο φάκελος εξόδου σας θα περιλαμβάνει:

```
models/qwen3-onnx-int4/
├── model.onnx              # Optimized ONNX model
├── model.onnx.data         # Model weights
├── genai_config.json       # Generation configuration
├── tokenizer.json          # Tokenizer files
├── tokenizer_config.json
└── special_tokens_map.json
```

## Καλές Πρακτικές

### 1. Επιλογή Μοντέλου
- Ξεκινήστε με μικρότερα μοντέλα για δοκιμές (π.χ. 0.5B-7B παράμετροι)
- Βεβαιωθείτε ότι η αρχιτεκτονική του στόχου υποστηρίζεται από το Olive

### 2. Λαμβάνοντας Υπόψη το Υλικό
- Ταιριάξτε το στόχο βελτιστοποίησης με το υλικό ανάπτυξης
- Χρησιμοποιήστε βελτιστοποίηση GPU αν έχετε υλικό συμβατό με CUDA
- Εξετάστε το DirectML για μηχανές Windows με ενσωματωμένα γραφικά

### 3. Επιλογή Ακρίβειας
- **INT4**: Μέγιστη συμπίεση, μικρή απώλεια ακρίβειας
- **INT8**: Καλή ισορροπία μεγέθους και ακρίβειας
- **FP16**: Ελάχιστη απώλεια ακρίβειας, μέτρια μείωση μεγέθους

### 4. Δοκιμές και Επικύρωση
- Πάντα δοκιμάζετε βελτιστοποιημένα μοντέλα με τα συγκεκριμένα σας σενάρια χρήσης
- Συγκρίνετε μετρικές απόδοσης (καθυστέρηση, ροή, ακρίβεια)
- Χρησιμοποιήστε αντιπροσωπευτικά δεδομένα εισόδου για αξιολόγηση

### 5. Επαναληπτική Βελτιστοποίηση
- Ξεκινήστε με αυτόματη βελτιστοποίηση για γρήγορα αποτελέσματα
- Χρησιμοποιήστε αρχεία ρυθμίσεων για λεπτομερή έλεγχο
- Πειραματιστείτε με διαφορετικές διελεύσεις βελτιστοποίησης

## Αποθετήριο Συνταγών Olive

### Εισαγωγή στις Συνταγές Olive

Το αποθετήριο [microsoft/olive-recipes](https://github.com/microsoft/olive-recipes) συμπληρώνει το βασικό σύνολο εργαλείων Olive παρέχοντας μια ολοκληρωμένη συλλογή έτοιμων προς χρήση συνταγών βελτιστοποίησης για δημοφιλή μοντέλα AI. Αυτό το αποθετήριο λειτουργεί ως πρακτικό αναφορά τόσο για τη βελτιστοποίηση δημόσια διαθέσιμων μοντέλων όσο και για τη δημιουργία ροών εργασίας βελτιστοποίησης για ιδιόκτητα μοντέλα.

### Κύρια Χαρακτηριστικά

- **Περισσότερες από 100 Προεγκατεστημένες Συνταγές**: Έτοιμες διαμορφώσεις βελτιστοποίησης για δημοφιλή μοντέλα
- **Υποστήριξη Πολλαπλών Αρχιτεκτονικών**: Καλύπτει μοντέλα transformer, όρασης και πολυτροπικές αρχιτεκτονικές
- **Εξειδικευμένες Βελτιστοποιήσεις Υλικού**: Συνταγές με εξατομίκευση για CPU, GPU και ειδικούς επιταχυντές
- **Δημοφιλείς Οικογένειες Μοντέλων**: Περιλαμβάνει Phi, Llama, Qwen, Gemma, Mistral, και άλλες

### Υποστηριζόμενες Οικογένειες Μοντέλων

Το αποθετήριο περιλαμβάνει συνταγές βελτιστοποίησης για:

#### Γλωσσικά Μοντέλα
- **Microsoft Phi**: Phi-3-mini, Phi-3.5-mini, Phi-4-mini, Phi-4-reasoning
- **Meta Llama**: Llama-2-7b, Llama-3.1-8B, Llama-3.2-1B/3B
- **Alibaba Qwen**: Qwen1.5-7B, Qwen2-7B, Qwen2.5 σειρά (0.5B έως 14B)
- **Google Gemma**: Διάφορες διαμορφώσεις μοντέλων Gemma
- **Mistral AI**: Σειρά Mistral-7B
- **DeepSeek**: Μοντέλα σειράς R1-Distill

#### Μοντέλα Όρασης και Πολυτροπικά
- **Stable Diffusion**: v1.4, XL-base-1.0
- **CLIP Μοντέλα**: Διάφορες διαμορφώσεις CLIP-ViT
- **ResNet**: Βελτιστοποιήσεις ResNet-50
- **Vision Transformers**: ViT-base-patch16-224

#### Εξειδικευμένα Μοντέλα
- **Whisper**: OpenAI Whisper-large-v3
- **BERT**: Βασικά και πολυγλωσσικά παραλλαγές
- **Sentence Transformers**: all-MiniLM-L6-v2
