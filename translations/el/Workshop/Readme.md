# EdgeAI για Αρχάριους - Εργαστήριο

> **Πρακτική Διαδρομή Μάθησης για Δημιουργία Εφαρμογών Edge AI Έτοιμων για Παραγωγή**
>
> Επιδεξιότητα στην τοπική ανάπτυξη AI με το Microsoft Foundry Local, από την πρώτη ολοκλήρωση συνομιλίας έως την ορχήστρωση πολυπρακτόρων σε 6 προοδευτικές συνεδρίες.

---

## 🎯 Εισαγωγή

Καλωσορίσατε στο **EdgeAI για Αρχάριους Εργαστήριο** - ο πρακτικός, εμπειρικός οδηγός σας για την κατασκευή έξυπνων εφαρμογών που εκτελούνται αποκλειστικά σε τοπικό υλικό. Αυτό το εργαστήριο μετατρέπει τις θεωρητικές έννοιες του Edge AI σε δεξιότητες πραγματικού κόσμου μέσω προοδευτικά απαιτητικών ασκήσεων χρησιμοποιώντας το Microsoft Foundry Local και Μικρά Γλωσσικά Μοντέλα (SLMs).

### Γιατί αυτό το εργαστήριο;

**Η Επανάσταση του Edge AI είναι Εδώ**

Οργανισμοί παγκοσμίως μετακινούνται από το AI μέσω cloud στο edge computing για τρεις κρίσιμους λόγους:

1. **Απόρρητο & Συμμόρφωση** - Επεξεργασία ευαίσθητων δεδομένων τοπικά χωρίς μετάδοση σε cloud (HIPAA, GDPR, χρηματοοικονομικοί κανονισμοί)
2. **Απόδοση** - Εξάλειψη καθυστέρησης δικτύου (50-500ms τοπικά έναντι 500-2000ms σε cloud με επιστροφή)
3. **Έλεγχος Κόστους** - Αφαίρεση κόστους API ανά token και κλιμάκωση χωρίς έξοδα cloud

**Αλλά το Edge AI είναι Διαφορετικό**

Η εκτέλεση AI επί τόπου απαιτεί νέες δεξιότητες:
- Επιλογή και βελτιστοποίηση μοντέλων για περιορισμούς πόρων
- Διαχείριση τοπικών υπηρεσιών και επιτάχυνση υλικού
- Μηχανική προτροπής για μικρότερα μοντέλα
- Πρότυπα παραγωγικής ανάπτυξης για συσκευές edge

**Αυτό το εργαστήριο παρέχει αυτές τις δεξιότητες**

Σε 6 συγκεντρωμένες συνεδρίες (~3 ώρες συνολικά), θα προχωρήσετε από το "Hello World" στην ανάπτυξη παραγωγικών συστημάτων με πολλούς πράκτορες - όλα να εκτελούνται τοπικά στη συσκευή σας.

## 📚 Εκπαιδευτικοί Στόχοι

Με την ολοκλήρωση αυτού του εργαστηρίου, θα μπορείτε να:

### Βασικές Δεξιότητες
1. **Αναπτύξτε και Διαχειριστείτε Τοπικές Υπηρεσίες AI**
   - Εγκατάσταση και ρύθμιση Microsoft Foundry Local
   - Επιλογή κατάλληλων μοντέλων για edge ανάπτυξη
   - Διαχείριση κύκλου ζωής μοντέλων (λήψη, φόρτωση, προσωρινή αποθήκευση)
   - Παρακολούθηση χρήσης πόρων και βελτιστοποίηση απόδοσης

2. **Κατασκευάστε Εφαρμογές με Τεχνητή Νοημοσύνη**
   - Υλοποίηση OpenAI-συμβατών συνομιλιών τοπικά
   - Σχεδιασμός αποτελεσματικών προτροπών για Μικρά Γλωσσικά Μοντέλα
   - Διαχείριση ροών απαντήσεων για καλύτερη εμπειρία χρήστη
   - Ενσωμάτωση τοπικών μοντέλων σε υπάρχουσες εφαρμογές

3. **Δημιουργήστε Συστήματα RAG (Αναζήτηση Ενισχυμένη με Ανάκτηση)**
   - Δημιουργία σημασιολογικής αναζήτησης με ενσωματώσεις (embeddings)
   - Βάση απαντήσεων LLM σε ειδική γνώση τομέα
   - Αξιολόγηση ποιότητας RAG με βιομηχανικά πρότυπα
   - Κλιμάκωση από πρωτότυπο σε παραγωγή

4. **Βελτιστοποίηση Απόδοσης Μοντέλων**
   - Σύγκριση πολλών μοντέλων για την περίπτωσή σας
   - Μέτρηση καθυστέρησης, ρυθμού και χρόνου πρώτου token
   - Επιλογή βέλτιστων μοντέλων με βάση ανταλλαγές ταχύτητας/ποιότητας
   - Σύγκριση SLM έναντι LLM σε πραγματικά σενάρια

5. **Ορχήστρωση Συστημάτων με Πολλαπλούς Πράκτορες**
   - Σχεδιασμός εξειδικευμένων πρακτόρων για διαφορετικές εργασίες
   - Υλοποίηση μνήμης πρακτόρων και διαχείριση συμφραζομένων
   - Συντονισμός πρακτόρων σε σύνθετες ροές εργασίας
   - Έξυπνη δρομολόγηση αιτημάτων ανάμεσα σε πολλαπλά μοντέλα

6. **Ανάπτυξη ΛύσεωνΈτοιμων για Παραγωγή**
   - Υλοποίηση χειρισμού σφαλμάτων και λογικής επανάληψης
   - Παρακολούθηση χρήσης token και πόρων συστήματος
   - Κατασκευή κλιμακούμενων αρχιτεκτονικών με πρότυπα μοντέλων ως εργαλεία
   - Σχεδιασμός διαδρομών μετανάστευσης από edge σε υβριδικό (edge + cloud)

## 🚀 Γρήγορη Εκκίνηση

### Προαπαιτούμενα

**Απαιτήσεις Συστήματος:**
- **ΛΣ**: Windows 10/11, macOS 11+, ή Linux (Ubuntu 20.04+)
- **RAM**: Ελάχιστο 8GB, 16GB+ συνιστάται
- **Χώρος Αποθήκευσης**: 10GB+ ελεύθερου χώρου για μοντέλα
- **CPU**: Μοντέρνος επεξεργαστής με υποστήριξη AVX2
- **GPU** (προαιρετικό): CUDA-συμβατό ή Qualcomm NPU για επιτάχυνση

**Απαιτήσεις Λογισμικού:**
- **Python 3.8+** ([Download](https://www.python.org/downloads/))
- **Microsoft Foundry Local** ([Installation Guide](#install-foundry-local))
- **Git** ([Download](https://git-scm.com/downloads))
- **Visual Studio Code** (συνιστάται) ([Download](https://code.visualstudio.com/))

### Ρύθμιση σε 3 Βήματα

#### 1. Εγκαταστήστε το Foundry Local

**Windows:**
```powershell
winget install Microsoft.FoundryLocal
```

**macOS:**
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

**Επαληθεύστε την Εγκατάσταση:**
```bash
foundry --version
foundry service status
```

**Βεβαιωθείτε ότι το Azure AI Foundry Local τρέχει με σταθερή θύρα**

```bash
# Ορίστε το FoundryLocal να χρησιμοποιεί την θύρα 58123 (προεπιλογή)
foundry service set --port 58123 --show

# Ή χρησιμοποιήστε μια διαφορετική θύρα
foundry service set --port 58000 --show
```

**Επαληθεύστε ότι λειτουργεί:**
```bash
# Έλεγχος κατάστασης υπηρεσίας
foundry service status

# Δοκιμάστε το σημείο τερματισμού
curl http://127.0.0.1:58123/v1/models
```
**Εύρεση Διαθέσιμων Μοντέλων**
Για να δείτε ποια μοντέλα είναι διαθέσιμα στην περίπτωσή σας Foundry Local, μπορείτε να κάνετε ερώτημα στο endpoint μοντέλων:

```bash
# cmd/bash/powershell
foundry model list
```

Χρησιμοποιώντας Web Endpoint 

```bash
# Windows PowerShell
powershell -Command "Invoke-RestMethod -Uri 'http://127.0.0.1:58123/v1/models' -Method Get"

# Ή χρησιμοποιώντας curl (αν είναι διαθέσιμο)
curl http://127.0.0.1:58123/v1/models
```

#### 2. Αντιγράψτε το Αποθετήριο & Εγκαταστήστε Εξαρτήσεις

```bash
# Κλωνοποίησε το αποθετήριο
git clone https://github.com/microsoft/edgeai-for-beginners.git
cd edgeai-for-beginners/Workshop

# Δημιουργία εικονικού περιβάλλοντος
python -m venv .venv

# Ενεργοποίηση εικονικού περιβάλλοντος
# Windows:
.\.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# Εγκατάσταση εξαρτήσεων
pip install -r requirements.txt
```

#### 3. Τρέξτε το Πρώτο Σας Δείγμα

```bash
# Εκκινήστε το Foundry Local και φορτώστε ένα μοντέλο
foundry model run phi-4-mini

# Εκτελέστε το παράδειγμα εκκίνησης συνομιλίας
cd samples
python -m session01.chat_bootstrap "What is edge AI?"
```

**✅ Επιτυχία!** Πρέπει να δείτε μια ροή απάντησης σχετικά με το edge AI.

## Παράρτημα Ακρίβειας Εντολών CLI

Το εργαστήριο χρησιμοποιεί σκόπιμα μόνο τεκμηριωμένες / σταθερές εντολές Foundry Local CLI.

### Αναφερόμενες Σταθερές Εντολές

| Κατηγορία | Εντολή | Σκοπός |
|----------|---------|---------|
| Κύριες | `foundry --version` | Εμφάνιση εγκατεστημένης έκδοσης |
| Υπηρεσία | `foundry service start` | Εκκίνηση τοπικής υπηρεσίας (αν δεν ξεκινά αυτόματα) |
| Υπηρεσία | `foundry service status` | Εμφάνιση κατάστασης υπηρεσίας |
| Μοντέλα | `foundry model list` | Λίστα καταλόγου / διαθέσιμων μοντέλων |
| Μοντέλα | `foundry model download <alias>` | Λήψη βαρών μοντέλου στην κρυφή μνήμη |
| Μοντέλα | `foundry model run <alias>` | Εκκίνηση (φόρτωση) μοντέλου τοπικά· συνδυάζεται με `--prompt` για one‑shot |
| Μοντέλα | `foundry model unload <alias>` / `foundry model stop <alias>` | Αποφόρτωση μοντέλου από μνήμη (αν υποστηρίζεται) |
| Cache | `foundry cache list` | Λίστα αποθηκευμένων (κατεβασμένων) μοντέλων |

### Πρότυπο One‑Shot Prompt

Αντί της απαρχαιωμένης υποεντολής `model chat`, χρησιμοποιήστε:

```powershell
foundry model run <alias> --prompt "Your question here"
```

Εκτελεί έναν κύκλο προτροπής/απόκρισης και εξέρχεται.

### Αφαιρεμένα / Αποφευγόμενα Πρότυπα

| Απαρχαιωμένο / Μη τεκμηριωμένο | Αντικατάσταση / Οδηγία |
|---------------------------|------------------------|
| `foundry model chat <model> "..."` | `foundry model run <model> --prompt "..."` |
| `foundry model list --running` | Χρησιμοποιήστε απλό `foundry model list` + πρόσφατη δραστηριότητα / αρχεία καταγραφής |
| `foundry model list --cached` | `foundry cache list` |
| `foundry model stats <model>` | Χρησιμοποιήστε το python script αξιολόγησης + εργαλεία OS (Task Manager / `nvidia-smi`) |
| `foundry model benchmark ...` | `samples/session03/benchmark_oss_models.py` |

### Αξιολόγηση & Τηλεμετρία

- Καθυστέρηση, p95, tokens/sec: `samples/session03/benchmark_oss_models.py`
- Καθυστέρηση πρώτου τοκενίου (streaming): ορίστε `BENCH_STREAM=1`
- Χρήση πόρων: Παρακολούθηση OS (Task Manager, Activity Monitor, `nvidia-smi`).

Καθώς νέες εντολές τηλεμετρίας CLI σταθεροποιούνται ροή, μπορούν να ενσωματωθούν με ελάχιστες αλλαγές στα markdowns συνεδρίας.

### Αυτόματος Έλεγχος Lint

Ένας αυτόματος ελεγκτής αποτρέπει την επανεισαγωγή απαρχαιωμένων προτύπων CLI μέσα σε fenced code blocks των αρχείων markdown:

Σενάριο: `Workshop/scripts/lint_markdown_cli.py`

Απαρχαιωμένα πρότυπα αποκλείονται μέσα σε fenced code blocks.

Προτεινόμενες αντικαταστάσεις:
| Απαρχαιωμένο | Αντικατάσταση |
|------------|-------------|
| `foundry model chat <a> "..."` | `foundry model run <a> --prompt "..."` |
| `model list --running` | `model list` |
| `model list --cached` | `cache list` |
| `model stats` | Script αξιολόγησης + εργαλεία συστήματος |
| `model benchmark` | `samples/session03/benchmark_oss_models.py` |
| `model list --available` | `model list` |

Τρέξτε τοπικά:
```powershell
python Workshop\scripts\lint_markdown_cli.py --verbose
```

GitHub Action: `.github/workflows/markdown-cli-lint.yml` τρέχει σε κάθε push και PR.

Προαιρετικό hook πριν commit:
```bash
echo "python Workshop/scripts/lint_markdown_cli.py" > .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

## Πίνακας Γρήγορης Μεταφοράς CLI → SDK

| Εργασία | CLI Μία-Γραμμή | SDK (Python) Αντίστοιχο | Σημειώσεις |
|------|---------------|-------------------------|-------|
| Εκτέλεση μοντέλου μία φορά (προτροπή) | `foundry model run phi-4-mini --prompt "Hello"` | `manager=FoundryLocalManager("phi-4-mini"); client=OpenAI(base_url=manager.endpoint, api_key=manager.api_key or "not-needed"); client.chat.completions.create(model=manager.get_model_info("phi-4-mini").id, messages=[{"role":"user","content":"Hello"}])` | Το SDK εκκινεί αυτόματα υπηρεσία και caching |
| Λήψη (cache) μοντέλου | `foundry model download qwen2.5-0.5b` | `FoundryLocalManager("qwen2.5-0.5b")  # ενεργοποιεί λήψη/φόρτωση` | Ο διαχειριστής επιλέγει την καλύτερη παραλλαγή αν το ψευδώνυμο αντιστοιχεί σε πολλές εκδόσεις |
| Λίστα καταλόγου | `foundry model list` | `# χρήση manager για κάθε ψευδώνυμο ή διατήρηση γνωστής λίστας` | CLI συγκεντρώνει· SDK τρέχοντως ανά-ψευδώνυμο |
| Λίστα αποθηκευμένων μοντέλων | `foundry cache list` | `manager.list_cached_models()` | Μετά την αρχικοποίηση του manager (οποιοδήποτε ψευδώνυμο) |
| Λήψη URL endpoint | (ρητό) | `manager.endpoint` | Χρησιμοποιείται για δημιουργία συμβατού πελάτη OpenAI |
| Προθέρμανση μοντέλου | `foundry model run <alias>` και πρώτη προτροπή | `chat_once(alias, messages=[...])` (βοηθητικό) | Βοηθητικά χειρίζονται αρχική ψυχρή καθυστέρηση ζέσταμα |
| Μέτρηση καθυστέρησης | `python -m session03.benchmark_oss_models` | `import benchmark_oss_models` (ή νέο εξαγωγέα script) | Προτιμήστε script για συνεπή μετρικά |
| Σταμάτημα / αποφόρτωση μοντέλου | `foundry model unload <alias>` | (Δεν εκτίθεται – επανεκκινήστε υπηρεσία / διεργασία) | Συνήθως δεν απαιτείται για ροή εργαστηρίου |
| Λήψη χρήσης τοκενίων | (δείτε έξοδο) | `resp.usage.total_tokens` | Παρέχεται αν το backend επιστρέφει αντικείμενο χρήσης |
