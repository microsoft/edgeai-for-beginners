## 📖 Εισαγωγή

Καλώς ορίσατε στη συλλογή **EdgeAI για Αρχάριους Τετράδια Εργαστηρίου**. Αυτά τα διαδραστικά τετράδια Jupyter προσφέρουν μια πρακτική μαθησιακή εμπειρία όπου θα γράφετε, θα εκτελείτε και θα πειραματίζεστε με κώδικα Edge AI σε πραγματικό χρόνο.

### Γιατί Τετράδια Jupyter;

Σε αντίθεση με τα παραδοσιακά μαθήματα, αυτά τα τετράδια προσφέρουν:

- **Διαδραστική Μάθηση**: Εκτελέστε κελιά κώδικα και δείτε άμεσα αποτελέσματα
- **Πειραματισμός**: Τροποποιήστε παραμέτρους και παρακολουθήστε αλλαγές σε πραγματικό χρόνο
- **Τεκμηρίωση**: Επεξηγήσεις και κελιά markdown καθοδηγούν στις έννοιες
- **Αναπαραγωγιμότητα**: Πλήρη παραδείγματα για αναφορά και επαναχρησιμοποίηση
- **Οπτικοποίηση**: Προβολή μετρικών απόδοσης, embeddings και αποτελεσμάτων εντός του τετραδίου

### Τι Κάνει Αυτά τα Τετράδια Ειδικά;

Κάθε τετράδιο έχει σχεδιαστεί ακολουθώντας **καλές πρακτικές έτοιμες για παραγωγή**:

✅ **Ολοκληρωμένος Χειρισμός Σφαλμάτων** - Ομαλή υποβάθμιση και ενημερωτικά μηνύματα σφαλμάτων  
✅ **Υποδείξεις Τύπων & Τεκμηρίωση** - Καθαρά ορισμένα signatures συναρτήσεων και docstrings  
✅ **Παρακολούθηση Απόδοσης** - Παρακολούθηση χρήσης tokens και μετρήσεις καθυστέρησης  
✅ **Μοντέρνος Σχεδιασμός** - Επαναχρησιμοποιήσιμα μοτίβα που μπορείτε να προσαρμόσετε στα έργα σας  
✅ **Προοδευτική Πολυπλοκότητα** - Χτίζει συστηματικά πάνω στις προηγούμενες συνεδρίες

## 🎯 Μαθησιακοί Στόχοι

### Βασικές Δεξιότητες που θα Αναπτύξετε

Μέσα από αυτές τις συνεδρίες, θα μάθετε:

1. **Διαχείριση Τοπικής Υπηρεσίας AI**
   - Ρύθμιση και διαχείριση υπηρεσιών Microsoft Foundry Local
   - Επιλογή και φόρτωση κατάλληλων μοντέλων για το υλικό σας
   - Παρακολούθηση χρήσης πόρων και βελτιστοποίηση απόδοσης
   - Διαχείριση ανακάλυψης υπηρεσίας και έλεγχου υγείας

2. **Ανάπτυξη Εφαρμογών AI**
   - Υλοποίηση συμβατών με OpenAI chat completions τοπικά
   - Δημιουργία streaming διεπαφών για καλύτερη εμπειρία χρήστη
   - Σχεδίαση αποτελεσματικών prompts για Μικρά Γλωσσικά Μοντέλα
   - Ενσωμάτωση τοπικών μοντέλων σε εφαρμογές

3. **Αναδρομική Γενιά με Εμπλουτισμό (RAG)**
   - Δημιουργία σημασιολογικής αναζήτησης με vector embeddings
   - Εδαφοποίηση απαντήσεων LLM σε έγγραφα συγκεκριμένου τομέα
   - Αξιολόγηση ποιότητας RAG με μετρικές RAGAS
   - Κλιμάκωση από πρωτότυπο έως παραγωγή

4. **Βελτιστοποίηση Απόδοσης**
   - Συστηματική αξιολόγηση πολλαπλών μοντέλων
   - Μέτρηση καθυστέρησης, throughput και χρόνου πρώτου token
   - Σύγκριση Μικρών και Μεγάλων Γλωσσικών Μοντέλων
   - Επιλογή βέλτιστων μοντέλων βάσει ισορροπίας απόδοσης/ποιότητας

5. **Ορχήστρωση Πολλαπλών Πρακτόρων**
   - Σχεδίαση ειδικών πρακτόρων για διάφορα καθήκοντα
   - Υλοποίηση μνήμης πρακτόρων και διαχείρισης πλαισίου
   - Συντονισμός πολλαπλών πρακτόρων σε πολύπλοκα ροή εργασίας
   - Δημιουργία μοτίβων συντονιστή για συνεργασία πρακτόρων

6. **Έξυπνη Δρομολόγηση Μοντέλων**
   - Υλοποίηση ανίχνευσης πρόθεσης και αντιστοίχισης προτύπων
   - Αυτόματη δρομολόγηση ερωτημάτων σε κατάλληλα μοντέλα
   - Δημιουργία πολυβηματικών pipelines (σχεδιασμός → εκτέλεση → βελτίωση)
   - Σχεδίαση κλιμακούμενων αρχιτεκτονικών μοντέλου-ως-εργαλείου

### Γρήγορη Επαλήθευση

Εκτελέστε αυτό σε κελί Python για να επαληθεύσετε τη ρύθμιση:

```python
from foundry_local import FoundryLocalManager
import openai

# Αρχικοποίηση διαχειριστή (αυτόματη ανίχνευση υπηρεσίας)
manager = FoundryLocalManager("phi-4-mini")

# Διαμόρφωση πελάτη OpenAI
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Δοκιμή ολοκλήρωσης συνομιλίας
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**Αναμενόμενο Αποτέλεσμα**: Μια απάντηση χαιρετισμού από το τοπικό μοντέλο.
