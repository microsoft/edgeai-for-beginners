## Część 7: Rozwiązywanie problemów i dobre praktyki

### Typowe problemy i rozwiązania

**Model się nie uruchamia:**
```cmd
REM Check service status
foundry service status

REM Restart service if needed
foundry service stop
foundry service start

REM Try with verbose output
foundry model run phi-4-mini --verbose
```

**Niewystarczająca pamięć:**
- Zacznij od mniejszych modeli (`phi-4-mini`)
- Zamknij inne aplikacje
- Zwiększ pamięć RAM, jeśli często osiągasz limity

**Wolna wydajność:**
- Upewnij się, że model jest w pełni załadowany (sprawdź szczegółowe informacje)
- Zamknij niepotrzebne aplikacje działające w tle
- Rozważ szybszy dysk (SSD)

### Dobre praktyki

1. **Zacznij od małych modeli**: Rozpocznij z `phi-4-mini` by zweryfikować konfigurację
2. **Jeden model na raz**: Zatrzymuj poprzednie modele przed uruchomieniem nowych
3. **Monitoruj zasoby**: Obserwuj zużycie pamięci
4. **Testuj konsekwentnie**: Używaj tych samych promptów dla uczciwych porównań

## Część 1: Odkrywanie modeli z Foundry CLI

### Podstawowe polecenia zarządzania modelami

CLI foundry oferuje proste polecenia do odkrywania i zarządzania modelami:

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### Uruchamianie pierwszych modeli

Zacznij od popularnych, dobrze przetestowanych modeli, aby poznać charakterystyki wydajności:

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**Uwaga:** Flaga `--verbose` dostarcza szczegółowe informacje startowe, w tym:
- Postęp pobierania modelu (przy pierwszym uruchomieniu)
- Szczegóły przydziału pamięci
- Informacje o powiązaniu usługi
- Metryki inicjalizacji wydajności

### Zrozumienie kategorii modeli

**Małe modele językowe (SLM):**
- `phi-4-mini`: szybki, wydajny, świetny do ogólnej rozmowy
- `phi-4`: bardziej zaawansowana wersja z lepszym rozumowaniem

**Modele średnie:**
- `qwen2.5-7b`: doskonałe rozumowanie i dłuższy kontekst
- `deepseek-r1-7b`: zoptymalizowany do generowania kodu

**Większe modele:**
- `llama-3.2`: najnowszy model open-source Meta
- `qwen2.5-14b`: rozumowanie na poziomie przedsiębiorstwa

```cmd
REM Test via curl (Windows Command Prompt)
curl -X POST http://localhost:8000/v1/chat/completions ^
  -H "Content-Type: application/json" ^
  -d "{\"model\":\"phi-4-mini\",\"messages\":[{\"role\":\"user\",\"content\":\"Explain edge AI in one sentence.\"}],\"max_tokens\":50}"
```

### Alternatywa testowania PowerShell

```powershell
# Podejście PowerShell do testowania
$body = @{
    model = "phi-4-mini"
    messages = @(
        @{

    )
    max_tokens = 50

Invoke-RestMethod -Uri "http://localhost:8000/v1/chat/completions" -Method Post -Body $body -ContentType "application/json"
```

## Część 3: Zarządzanie pamięcią podręczną i przechowywaniem modeli

### Zrozumienie pamięci podręcznej modeli

Foundry Local automatycznie zarządza pobieraniem i buforowaniem modeli:

```cmd
REM Check cache directory and contents
foundry cache ls

REM View cache location
foundry cache cd

REM Clean up unused models (if needed)
foundry cache clean
```

### Uwagi dotyczące przechowywania modeli

**Typowe rozmiary modeli:**
- `phi-4-mini`: ~2,5 GB
- `qwen2.5-7b`: ~4,1 GB  
- `deepseek-r1-7b`: ~4,3 GB
- `llama-3.2`: ~4,9 GB
- `qwen2.5-14b`: ~8,2 GB

**Dobre praktyki przechowywania:**
- Przechowuj 2-3 modele w pamięci podręcznej dla szybkiego przełączania
- Usuwaj nieużywane modele, aby zwolnić miejsce: `foundry cache clean`
- Monitoruj zużycie dysku, szczególnie na mniejszych SSD
- Uwzględniaj kompromisy między rozmiarem modelu a jego możliwościami

### Monitorowanie wydajności modeli

Gdy modele działają, monitoruj zasoby systemowe:

**Menadżer zadań Windows:**
- Obserwuj użycie pamięci (modele pozostają załadowane w RAM)
- Monitoruj wykorzystanie CPU podczas wnioskowania
- Sprawdzaj operacje dyskowe przy początkowym ładowaniu modelu

**Monitorowanie z linii poleceń:**
```cmd
REM Check memory usage (PowerShell)
Get-Process | Where-Object {$_.ProcessName -like "*foundry*"} | Select-Object ProcessName, WorkingSet64

REM Monitor running models
foundry service ps
```

## Część 4: Praktyczne wskazówki wyboru modeli

### Wybór modeli według zastosowania

**Do rozmów ogólnych i Q&A:**
- Zacznij od: `phi-4-mini` (szybki, wydajny)
- Ulepsz do: `phi-4` (lepsze rozumowanie)
- Zaawansowany: `qwen2.5-7b` (dłuższy kontekst)

**Do generowania kodu:**
- Zalecany: `deepseek-r1-7b`
- Alternatywa: `qwen2.5-7b` (również dobry do kodu)

**Do złożonego rozumowania:**
- Najlepszy: `qwen2.5-7b` lub `qwen2.5-14b`
- Opcja budżetowa: `phi-4`

### Przewodnik po wymaganiach sprzętowych

**Minimalne wymagania systemowe:**
```
phi-4-mini:     8GB RAM,  entry-level CPU
phi-4:         12GB RAM,  mid-range CPU
qwen2.5-7b:    16GB RAM,  mid-range CPU
deepseek-r1:   16GB RAM,  mid-range CPU
qwen2.5-14b:   24GB RAM,  high-end CPU
```

**Zalecane dla najlepszej wydajności:**
- 32 GB+ RAM dla komfortowego przełączania wielu modeli
- Dysk SSD dla szybszego ładowania modeli
- Nowoczesny CPU z dobrą wydajnością jednowątkową
- Wsparcie NPU (komputery z Windows 11 Copilot+) dla akceleracji

### Przepływ pracy przełączania modeli

```cmd
REM Start different model

REM Verify model is running
```

## Część 5: Prosty benchmarking modeli

### Podstawowy test wydajności

Oto proste podejście do porównania wydajności modeli:

```python
# simple_bench.py - Oparte na wzorcach z Przykładu 03
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# Testuj aktualnie uruchomiony model
if __name__ == "__main__":
    # Testuj z różnymi modelami (najpierw uruchom każdy model)
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```

### Ręczna ocena jakości

Dla każdego modelu testuj przy użyciu tych samych promptów i oceniaj ręcznie:

**Testowe prompt-y:**
1. "Wyjaśnij obliczenia kwantowe prostym językiem."
2. "Napisz funkcję w Pythonie do sortowania listy."
3. "Jakie są zalety i wady pracy zdalnej?"
4. "Podsumuj korzyści AI na krawędzi sieci."

**Kryteria oceny:**
- **Dokładność**: Czy informacje są poprawne?
- **Jasność**: Czy wyjaśnienie jest łatwe do zrozumienia?
- **Kompletność**: Czy odpowiada na całe pytanie?
- **Szybkość**: Jak szybko odpowiada?

### Monitorowanie zużycia zasobów

```cmd

REM In another terminal, monitor resources

foundry service ps
```
