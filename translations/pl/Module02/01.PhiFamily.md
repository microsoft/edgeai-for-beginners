## Kluczowe technologie umożliwiające rodzinę Phi

### Podejście "podręcznikowe" do treningu

Jednym z najbardziej rewolucyjnych aspektów rodziny Phi jest metodologia treningu o "jakości podręcznikowej". Zamiast trenować na ogromnych, nieselekcjonowanych danych z internetu, modele Phi korzystają ze starannie dobranych, wysokiej jakości materiałów edukacyjnych zaprojektowanych do skutecznego nauczania rozumowania, matematyki, programowania i wiedzy ogólnej.

To podejście polega na tworzeniu syntetycznych materiałów edukacyjnych, które odzwierciedlają wysokiej jakości podręczniki i materiały akademickie. Dane szkoleniowe są specjalnie zaprojektowane, aby były pedagogicznie poprawne, koncentrując się na jasnych wyjaśnieniach, krok po kroku rozumowaniu i uporządkowanej prezentacji wiedzy.

### Zaawansowane szkolenie w rozumowaniu

Najnowsze modele Phi wykorzystują zaawansowane metody treningu rozumowania, które umożliwiają rozwiązywanie złożonych, wieloetapowych problemów. Techniki te obejmują:

**Chain-of-Thought Training**: Modele uczą się rozbijać skomplikowane problemy na pośrednie etapy rozumowania, co sprawia, że proces rozwiązywania problemów jest bardziej przejrzysty i wiarygodny.

**Inference-Time Scaling**: Modele generują szczegółowe łańcuchy rozumowania, wykorzystując dodatkowe zasoby obliczeniowe podczas generowania odpowiedzi dla poprawy dokładności.

**Edge-of-Capability Training**: Dane szkoleniowe są specjalnie wybierane, aby wyzwalać model na granicy jego aktualnych możliwości, promując naukę złożonych wzorców rozumowania.

### Innowacje architektoniczne

Rodzina Phi zawiera kilka optymalizacji architektonicznych zaprojektowanych specjalnie pod kątem efektywności:

**Efektywność parametrów**: Dokładne wybory architektoniczne maksymalizujące wpływ każdego parametru w modelu.

**Integracja multimodalna**: Efektywna integracja możliwości przetwarzania tekstu, wizji i mowy w kompaktowych architekturach.

**Optymalizacja sprzętowa**: Specjalistyczne warianty zoptymalizowane pod kątem konkretnych platform sprzętowych i scenariuszy wdrożeniowych.

### Przykład rozumowania matematycznego

Phi-4-mini-reasoning doskonale radzi sobie z rozwiązywaniem krok po kroku problemów matematycznych. Na przykład, na pytanie "Jak rozwiązać 3*x^2+4*x+5=1?", model podaje szczegółowe kroki rozumowania:

```
<|system|>Your name is Phi, an AI math expert developed by Microsoft.<|end|>
<|user|>How to solve 3*x^2+4*x+5=1?<|end|>
<|assistant|>
I need to solve the quadratic equation 3x² + 4x + 5 = 1.

First, let me rearrange this to standard form:
3x² + 4x + 5 = 1
3x² + 4x + 5 - 1 = 0  
3x² + 4x + 4 = 0

Now I can use the quadratic formula: x = (-b ± √(b² - 4ac)) / (2a)
Where a = 3, b = 4, c = 4

Let me calculate the discriminant:
b² - 4ac = 4² - 4(3)(4) = 16 - 48 = -32

Since the discriminant is negative (-32), this equation has no real solutions.
The solutions are complex: x = (-4 ± √(-32)) / 6 = (-4 ± 4i√2) / 6 = (-2 ± 2i√2) / 3
```

## Ewolucja rodziny Phi

### Phi-1 i Phi-2: modele podstawowe

Wczesne modele Phi ustanowiły fundamenty oparte na wysokiej jakości danych szkoleniowych i efektywnych architekturach:

- **Phi-1 (1,3 mld parametrów)**: Wprowadził koncepcję kuratorowanych danych szkoleniowych dla podstawowego rozumienia języka i generowania kodu.
- **Phi-2 (2,7 mld parametrów)**: Ulepszone zdolności rozumowania poprzez syntetyczne dane NLP i starannie filtrowane treści internetowe.

### Rodzina Phi-3: adopcja główna

Seria Phi-3 oznaczała przełom w możliwościach SLM z wieloma specjalistycznymi wariantami:

- **Phi-3-mini (3,8 mld parametrów)**: Ogólne zadania językowe z wyjątkową efektywnością, przewyższając modele dwukrotnie większe.
- **Phi-3-small (7 mld parametrów)**: Zaawansowana wydajność przewyższająca GPT-3.5 Turbo w różnych benchmarkach.
- **Phi-3-medium (14 mld parametrów)**: Wydajność klasy korporacyjnej przewyższająca Gemini 1.0 Pro.
- **Phi-3-vision (4,2 mld parametrów)**: Zdolności multimodalne do przetwarzania obrazów i tekstu.
- **Phi-3-Silica (3,3 mld parametrów)**: Specjalistyczna optymalizacja dla wbudowanych wdrożeń Windows 11.

### Rodzina Phi-4: zaawansowane rozumowanie

Najnowsza generacja przesuwa granice możliwości rozumowania:

- **Phi-4 (14 mld parametrów)**: Specjalizacja w złożonym rozumowaniu, szczególnie w matematyce.
- **Phi-4-mini (3,8 mld parametrów)**: Ulepszone rozumowanie z wywoływaniem funkcji i wsparciem długiego kontekstu.
- **Phi-4-multimodal**: Jednoczesne przetwarzanie mowy, wizji i tekstu.
- **Phi-4-reasoning (14 mld parametrów)**: Specjalizacja w złożonych, wieloetapowych zadaniach rozumowania.
- **Phi-4-reasoning-plus (14 mld parametrów)**: Zwiększona dokładność dzięki dodatkowym metodom uczenia ze wzmocnieniem.
- **Phi-4-mini-reasoning (3,8 mld parametrów)**: Rozumowanie matematyczne zoptymalizowane dla środowisk o ograniczonych zasobach.

## Przykłady rozwoju i integracji

### Szybki start z Transformers

Oto jak zacząć pracę z modelami Phi za pomocą biblioteki Hugging Face Transformers:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# Załaduj Phi-4-mini-instruct
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True,
    attn_implementation="flash_attention_2"  # Dla zoptymalizowanej wydajności
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")

# Sformatuj swój prompt używając szablonu czatu
messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain quantum computing in simple terms."}
]

# Zastosuj szablon czatu
input_text = tokenizer.apply_chat_template(messages, tokenize=False)
inputs = tokenizer(input_text, return_tensors="pt")

# Wygeneruj odpowiedź
with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=200, temperature=0.7)
    
response = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(response)
```

### Przykład dostrajania

Poniższy przykład pokazuje, jak dostroić model Phi-4-mini-instruct do konkretnych zadań:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig
from trl import SFTTrainer
from datasets import load_dataset

# Konfiguracja do fine-tuningu LoRA
peft_config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
    target_modules="all-linear"
)

# Konfiguracja treningu zoptymalizowana pod kątem wydajności
training_config = TrainingArguments(
    output_dir="./phi-4-mini-finetuned",
    learning_rate=5.0e-06,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=1,
    num_train_epochs=1,
    bf16=True,
    gradient_checkpointing=True,
    warmup_ratio=0.2,
    save_steps=100
)

# Załaduj model i tokenizer
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")
tokenizer.pad_token = tokenizer.unk_token
tokenizer.padding_side = 'right'

# Załaduj i przetwórz zbiór danych
train_dataset = load_dataset("HuggingFaceH4/ultrachat_200k", split="train_sft")

# Zainicjuj trenera
trainer = SFTTrainer(
    model=model,
    args=training_config,
    peft_config=peft_config,
    train_dataset=train_dataset,
    max_seq_length=2048,
    tokenizer=tokenizer,
    packing=True
)

# Rozpocznij fine-tuning
trainer.train()
```
