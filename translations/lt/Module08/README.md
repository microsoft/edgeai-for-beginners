# Modulis 08: Darbas su Microsoft Foundry Local – Pilna kūrėjo įrankių rinkinys

## Apžvalga

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) yra naujos kartos edge AI kūrimas, suteikiantis kūrėjams galingus įrankius kurti, diegti ir mastelizuoti AI programas vietoje, kartu užtikrinant sklandžią integraciją su Azure AI Foundry. Šis modulis suteikia išsamų Foundry Local aptarimą nuo įdiegimo iki pažangios agentų kūrimo.

**Pagrindinės technologijos:**
- Microsoft Foundry Local CLI ir SDK
- Azure AI Foundry integracija
- Modelio spėjimas įrenginyje
- Vietinis modelio talpinimas ir optimizavimas
- Agentų pagrindu sukurtos architektūros

## Mokymosi tikslai

Baigę šį modulį, jūs:

- **Įvaldykite Foundry Local**: Įdiekite, konfigūruokite ir optimizuokite Windows 11 kūrimui
- **Diegkite įvairius modelius**: Vietoje vykdykite phi, qwen, deepseek ir GPT modelius su CLI komandomis
- **Kurti gamybinius sprendimus**: Kurkite AI programas su pažangia užklausų inžinerija ir duomenų integracija
- **Išnaudokite atvirojo kodo ekosistemą**: Integruokite Hugging Face modelius ir bendruomenės indėlius
- **Kurti AI agentus**: Kurkite intelektualius agentus su pagrindimu ir koordinavimo galimybėmis
- **Įgyvendinkite verslo modelius**: Kurkite modulinės, mastelio keitimo AI sprendimus gamybai

## Išankstiniai reikalavimai

### Sistemos reikalavimai
- **Operacinė sistema**: Windows 11 (22H2 arba naujesnė)
- **Atmintis**: 16GB RAM (didesniems modeliams rekomenduojama 32GB)
- **Saugykla**: 50GB laisvos vietos modelių talpinimui
- **Aparatūra**: Rekomenduojama NPU palaikoma įranga (Copilot+ PC), GPU neprivaloma
- **Tinklas**: Aukštos spartos internetas pradiniams modelių atsisiuntimams

### Kūrimo aplinka

- Visual Studio Code su AI Toolkit plėtiniu
- Python 3.10+ ir pip
- Git versijų kontrolei
- PowerShell arba Komandų eilutė
- Azure CLI (nebūtina, debesų integracijai)

### Žinių pagrindai
- Pagrindinės AI/ML koncepcijų žinios
- Komandų eilutės pažintis
- Python programavimo pagrindai
- REST API koncepcijos
- Pagrindinės žinios apie užklausų kūrimą ir modelių interpretavimą

## Mokymosi rezultatai

Baigę šį modulį, būsite pasirengę:

### Techninė meistrystė
- **Diegti ir valdyti**: Foundry Local įdiegimus kūrimo ir gamybos aplinkose
- **Integruoti modelius**: Sklandžiai dirbti su įvairiomis modelių šeimomis iš Microsoft, Hugging Face ir bendruomenės šaltinių
- **Kūrti programas**: Kurti gamybinio lygio AI programas su pažangiomis funkcijomis ir optimizacijomis
- **Vystyti agentus**: Įdiegti sudėtingus AI agentus su kontekstualizavimu, samprotavimu ir įrankių integracija

### Strateginis suvokimas
- **Architektūros sprendimai**: Priimti informuotus sprendimus apie vietinį arba debesų diegimą
- **Veikimo optimizavimas**: Optimizuoti interpretavimo efektyvumą įvairiose aparatūros konfigūracijose
- **Įmonių skalavimas**: Projektuoti programas, kurios skalės nuo vietinių prototipų iki įmonių diegimų
- **Privatumas ir saugumas**: Įgyvendinti privatumo užtikrinančius AI sprendimus su vietine interpretacija

### Inovacijų galimybės
- **Greita prototipavimas**: Greitai kurti ir testuoti AI programų koncepcijas visiems 10 pavyzdžių modelių
- **Bendruomenės integracija**: Naudotis atvirojo kodo modeliais ir prisidėti prie ekosistemos
- **Pažangios schemos**: Įdiegti pažangias AI schemas, įskaitant RAG, agentus ir įrankių integraciją
- **Sistemos meistrystė**: Ekspertų lygio integracija su LangChain, Semantic Kernel, Chainlit ir Electron
- **Gamybinis diegimas**: Diegti keičiamus AI sprendimus nuo vietinių prototipų iki įmonių sistemų
- **Ateities technologijoms pasiruošusi plėtra**: Kurti programas, pasiruošusias naujoms AI technologijoms ir schemoms

```powershell

cd Module08

# 2. Sukurkite Python virtualią aplinką

.\.venv\Scripts\activate

# 3. Įdiekite pagrindines priklausomybes
pip install -r requirements.txt

# 4. Įdiekite Foundry Local (jei dar neįdiegta)

# 5. Patikrinkite Foundry Local diegimą
```

### Dažniausiai pasitaikančių problemų šalinimas

**Foundry Local ryšio klaidos**
```powershell
# Patikrinkite paslaugos būseną
foundry status

# Paleiskite iš naujo, jei reikia
foundry restart

# Patikrinkite galinio taško pasiekiamumą
curl http://localhost:5273/v1/models
```

**Modelių įkėlimo problemos**
```powershell
# Patikrinti galimus modelius
foundry model list --cached

# Atsisiųsti trūkstamus modelius
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# Jei reikia, priverstinai perkelti įkėlimą
foundry model unload --all
foundry model run phi-4-mini
```

**Priklausomybių problemos**
```powershell
# Atnaujinkite pip ir iš naujo įdiekite
python -m pip install --upgrade pip
pip install -r requirements.txt --force-reinstall

# Node.js pavyzdžiams
npm cache clean --force
npm install
```
