## Microsoft Phi modelių filosofija

Microsoft Phi modelių šeima žymi pagrindinį požiūrio į DI modelių dizainą poslinkį, prioritetą teikiant efektyvumui ir praktiniam diegimui išlaikant stiprias našumo charakteristikas. Phi modeliai tai pasiekia naudodami novatoriškas architektūras, aukštos kokybės mokymo metodikas ir specializuotas optimizavimo technikas.

Phi šeima apima įvairius požiūrius, skirtus maksimaliai našumo išraiškai per kiekvieną parametrą, leidžiant diegti standartinėje aparatūroje ir suteikiant reikšmingas DI galimybes. Tikslas – išlaikyti konkurencingą našumą, tuo pačiu dramatiškai sumažinant skaičiavimo reikalavimus, atminties naudojimą ir eksploatacijos kaštus.

### Pagrindiniai Phi dizaino principai

Phi modeliai yra sukurti remiantis keliais pagrindiniais principais, kurie juos skiria nuo tradicinių didelių kalbos modelių:

- **Efektyvumas pirmiausia**: Optimizuoti maksimaliam našumui per parametrą, o ne absoliučiai skalai.
- **Kokybiškas mokymas**: Dėmesys aukštos kokybės, atrinktiems mokymo duomenims, o ne masyviems duomenų rinkiniams.
- **Lankstumas diegimui**: Sukurti veikti efektyviai įvairiose aparatūros konfigūracijose.
- **Specializuotos galimybės**: Dažnai optimizuoti konkrečioms užduotims ar sritims maksimaliam efektyvumui.

## Pagrindinės technologijos, leisiančios Phi šeimai veikti

### „Vadovėlinis“ mokymo metodas

Vienas iš labiausiai revoliucinių Phi šeimos aspektų yra "vadovėlinės kokybės" mokymo metodika. Vietoj to, kad būtų mokoma naudojant milžiniškus nesufiltruotus interneto duomenis, Phi modeliai naudoja atidžiai atrinktą, aukštos kokybės edukacinį turinį, skirtą efektyviai mokyti samprotavimą, matematiką, programavimą ir bendrą žinių bazę.

Šis metodas veikia kuriant sintetinį edukacinį turinį, kuris atitinka aukštos kokybės vadovėlius ir akademines medžiagas. Mokymo duomenys yra pedagogiškai pagrįsti, orientuoti į aiškius paaiškinimus, žingsnis po žingsnio samprotavimą ir struktūruotą žinių pateikimą.

### Pažangus samprotavimo mokymas

Naujieji Phi modeliai įtraukia pažangias samprotavimo mokymo metodikas, leidžiančias spręsti sudėtingas daugiasluoksnes problemas. Šios technikos apima:

**Grandininio samprotavimo mokymas**: Modeliai mokomi išskaidyti sudėtingas problemas į tarpinį samprotavimo etapus, kad jų sprendimo procesas būtų aiškesnis ir patikimesnis.

**Išvados metu vykdoma skalė**: Modeliai generuoja išsamius samprotavimo grandinius, naudojant papildomus skaičiavimo išteklius atsakymo kūrimo metu, siekiant didesnio tikslumo.

**Galimybių ribos mokymas**: Mokymo duomenys specialiai parinkti taip, kad modelis būtų iššūkis ties savo galimybių riba, skatinant sudėtingų samprotavimo modelių įsisavinimą.

### Architektūriniai patobulinimai

Phi šeima apima keletą architektūrinių optimizacijų, sukurtų būtent efektyvumui:

**Parametrų efektyvumas**: Atsargūs architektūriniai sprendimai, maksimizuojantys kiekvieno modelio parametro poveikį.

**Daugi-modalinis integravimas**: Efektyvus teksto, vaizdų ir balso apdorojimo galimybių integravimas į kompaktiškas architektūras.

**Aparatūros optimizavimas**: Specializuoti variantai, optimizuoti konkrečioms aparatūros platformoms ir diegimo scenarijams.

## Praktiniai pavyzdžiai ir naudojimo atvejai

Prieš gilindamiesi į techninę raidą, pažiūrėkime keletą konkrečių pavyzdžių, ką Phi modeliai gali atlikti:

### Matematinio samprotavimo pavyzdys

Phi-4-mini-reasoning puikiai sprendžia matematikos problemas žingsnis po žingsnio. Pavyzdžiui, paklaustas „Kaip išspręsti 3*x^2+4*x+5=1?“, modelis pateikia detalias samprotavimo eilutes:

```
<|system|>Your name is Phi, an AI math expert developed by Microsoft.<|end|>
<|user|>How to solve 3*x^2+4*x+5=1?<|end|>
<|assistant|>
I need to solve the quadratic equation 3x² + 4x + 5 = 1.

First, let me rearrange this to standard form:
3x² + 4x + 5 = 1
3x² + 4x + 5 - 1 = 0  
3x² + 4x + 4 = 0

Now I can use the quadratic formula: x = (-b ± √(b² - 4ac)) / (2a)
Where a = 3, b = 4, c = 4

Let me calculate the discriminant:
b² - 4ac = 4² - 4(3)(4) = 16 - 48 = -32

Since the discriminant is negative (-32), this equation has no real solutions.
The solutions are complex: x = (-4 ± √(-32)) / 6 = (-4 ± 4i√2) / 6 = (-2 ± 2i√2) / 3
```

## Kūrimo ir integracijos pavyzdžiai

### Greitas startas su Transformers

Štai kaip pradėti naudoti Phi modelius su Hugging Face Transformers biblioteka:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# Įkelti Phi-4-mini-instruct
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True,
    attn_implementation="flash_attention_2"  # Optimizuotam veikimui
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")

# Suformatuokite savo užklausą naudodami pokalbių šabloną
messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain quantum computing in simple terms."}
]

# Taikyti pokalbių šabloną
input_text = tokenizer.apply_chat_template(messages, tokenize=False)
inputs = tokenizer(input_text, return_tensors="pt")

# Sugeneruoti atsakymą
with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=200, temperature=0.7)
    
response = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(response)
```

```python
    target_modules="all-linear"
)

# Mokymo konfigūracija optimizuota efektyvumui
training_config = TrainingArguments(
    output_dir="./phi-4-mini-finetuned",
    learning_rate=5.0e-06,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=1,
    num_train_epochs=1,
    bf16=True,
    gradient_checkpointing=True,
    warmup_ratio=0.2,
    save_steps=100
)

# Įkelti modelį ir žodyną
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")
tokenizer.pad_token = tokenizer.unk_token
tokenizer.padding_side = 'right'

# Įkelti ir apdoroti duomenų rinkinį
train_dataset = load_dataset("HuggingFaceH4/ultrachat_200k", split="train_sft")

# Inicializuoti trenerį
trainer = SFTTrainer(
    model=model,
    args=training_config,
    peft_config=peft_config,
    train_dataset=train_dataset,
    max_seq_length=2048,
    tokenizer=tokenizer,
    packing=True
)

# Pradėti smulkų derinimą
trainer.train()
```
