## Kas yra funkcijų kvietimas?

Funkcijų kvietimas yra galinga galimybė, leidžianti mažiesiems kalbos modeliams (SLM) bendrauti su išorinėmis priemonėmis, API ir paslaugomis. Vietoj to, kad jie būtų ribojami tik mokymo duomenų, SLM dabar gali:

- **Jungtis prie išorinių API** (oro sąlygų paslaugos, duomenų bazės, paieškos varikliai)
- **Vykdyti konkrečias funkcijas** pagal vartotojo užklausas
- **Gauti realaus laiko informaciją** iš įvairių šaltinių
- **Atlikti skaičiavimo užduotis** per specializuotas priemones
- **Grandinėti kelis veiksmus** sudėtingiems darbo procesams

Ši galimybė transformuoja SLM iš statinių tekstų generatorių į dinamiškus DI agentus, galinčius atlikti realaus pasaulio užduotis.

## Kaip veikia funkcijų kvietimas

Funkcijų kvietimo procesas vyksta sisteminiu darbo eiga:

### 1. Priemonių integracija
- **Išorinės priemonės**: SLM gali jungtis prie oro sąlygų API, duomenų bazių, žiniatinklio paslaugų ir kitų išorinių sistemų
- **Funkcijų apibrėžimai**: Kiekviena priemonė apibrėžiama su specifiniais parametrais, įvesties/išvesties formatais ir aprašymais
- **API suderinamumas**: Priemonės integruojamos per standartizuotas sąsajas (REST API, SDK ir kt.)

### 2. Funkcijos apibrėžimas
Funkcijos apibrėžiamos trimis pagrindiniais komponentais:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Ketinimo aptikimas
- **Natūralios kalbos apdorojimas**: SLM analizuoja vartotojo įvestį, kad suprastų ketinimą
- **Funkcijų suderinimas**: Nustato, kurios funkcijos reikalingos užklausos įvykdymui
- **Parametrų išgavimas**: Identifikuoja ir ištraukia reikiamus parametrus iš vartotojo žinutės

### 4. JSON išvesties generavimas
SLM generuoja struktūrizuotą JSON, kuriame yra:
- Kvietimo funkcijos pavadinimas
- Reikalingi parametrai su tinkamomis reikšmėmis
- Vykdymo kontekstas ir metaduomenys

### 5. Išorinis vykdymas
- **Parametrų patikrinimas**: Užtikrina, kad visi reikalingi parametrai yra pateikti ir tinkamai suformatuoti
- **Funkcijos vykdymas**: Programa vykdo nurodytą funkciją su pateiktais parametrais
- **Klaidų valdymas**: Tvarko gedimus, laiko apribojimus ir neteisingus atsakymus

### 6. Atsakymo integracija
- **Rezultatų apdorojimas**: Funkcijos išvestis grąžinama SLM
- **Konteksto integravimas**: SLM įtraukia rezultatus į savo atsakymą
- **Vartotojo bendravimas**: Informacija pateikiama natūralia, pokalbių forma

## Taikymo scenarijai

### Duomenų gavimas
Paverskite natūralios kalbos užklausas į struktūrizuotus API kvietimus:
- **"Rodyk mano naujausius užsakymus"** → Duomenų bazės užklausa su vartotojo ID ir datos filtrais

- **"Rask el. laiškus iš Johno praeitą savaitę"** → El. pašto paslaugos užklausa su siuntėjo ir datos filtrais

### Veiksmų vykdymas

- **"Suplanuok susitikimą rytoj 14 val."** → Kalendoriaus API integracija

- **"Sukurk atsarginę mano failų kopiją"** → Failų sistemos operacija

Apdorokite sudėtingus matematinius ar loginio pobūdžio veiksmus:

### Duomenų apdorojimo darbo eigos

### Pasirinktinių funkcijų įgyvendinimas

Taip pat galite apibrėžti pasirinktinės funkcijas Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Apsimesti orų API kvietimą
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Naudokite pasirinktą įrankį
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

```python
import openai
from foundry_local import FoundryLocalManager

# Inicializuoti su modelio aliasu
alias = "phi-3.5-mini"  # Ar bet kuris palaikomas modelis
manager = FoundryLocalManager(alias)

# Sukurti OpenAI klientą, nukreiptą į vietinį galinį tašką
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Apibrėžti funkcijas modeliui
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Padaryti funkcijos kvietimo užklausą
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

### Dažnos problemos ir sprendimai

#### Problema 1: Funkcija nekviečiama
**Simptomai**: Modelis atsako tekstu, vietoj funkcijos kvietimo

**Sprendimai**:
1. **Patikrinkite funkcijos aprašymą**: Įsitikinkite, kad aiškiai atitinka vartotojo ketinimą
2. **Patikrinkite parametrų apibrėžimus**: Užtikrinkite, kad visi būtini parametrai yra tinkamai apibrėžti
3. **Peržiūrėkite sistemos užklausą**: Įtraukite aiškias instrukcijas, kada naudoti funkcijas
4. **Išbandykite su aiškiomis užklausomis**: Pvz., "Prašau naudoti orų funkciją gauti duomenis Londone"

#### Problema 2: Neteisingi parametrai
**Simptomai**: Funkcija kviečiama su netaisyklingais arba trūkstamais parametrais

**Sprendimai**:
1. **Pridėkite parametrų pavyzdžius**: Įtraukite pavyzdines reikšmes parametrų aprašymuose
2. **Naudokite enum apribojimus**: Ribokite parametro reikšmes specifinėmis galimybėmis, kur tai įmanoma
3. **Įgyvendinkite rezervo reikšmes**: Nustatykite protarpines reikšmes pasirenkamiems parametrams

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }
}
```

#### Problema 3: Paralinio funkcijų kvietimo nesėkmių
**Simptomai**: Kai turėtų veikti kelios funkcijos, veikia tik viena

```python
    def register_function(self, name: str, description: str, parameters: Dict,

        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Patvirtinti, kad funkcija egzistuoja
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Patikrinti kvotų apribojimus
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Patvirtinti parametrus
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Vykdyti funkciją
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Užfiksuoti sėkmingą vykdymą
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Užfiksuoti nepavykusį vykdymą
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Atstatyti skaitiklį, jei praėjo minutė
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Patikrinti, ar neviršyta riba
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Patikrinti reikalingus parametrus
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Patvirtinti parametrų tipus ir apribojimus
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Tipo patvirtinimas
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # Enum patvirtinimas
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )

    for entry in agent.audit_log[-3:]:  # Rodyti paskutinius 3 įrašus
        print(f"{entry['timestamp']}: {entry['function_name']} - {'SUCCESS' if entry['success'] else 'FAILED'}")

# Paleisti įmonių demonstraciją
# asyncio.run(enterprise_demo())
```

## Išvada

Funkcijų kvietimas mažosiose kalbų modeliuose žymi paradigmų pokytį nuo statinių DI asistentų į dinamiškus, pajėgius agentus, galinčius bendrauti su realiu pasauliu. Ši pamoka apėmė:

### Pagrindinės įžvalgos

1. **Pagrindų supratimas**: Funkcijų kvietimas leidžia SLM išplaukti už jų mokymo duomenų ribų, jungiantis prie išorinių įrankių ir paslaugų.

2. **Įgyvendinimo lankstumas**: Yra keli būdai – nuo žemų lygių įgyvendinimų su pasirinktiniais šablonais iki aukšto lygio sistemų, kaip Qwen-Agent ir Foundry Local.

3. **Produkcijos aspektai**: Verslo diegimai reikalauja dėmesio klaidų valdymui, kvotų ribojimui, saugumui ir audito registravimui.

4. **Našumo optimizavimas**: Tinkamas funkcijų dizainas, efektyvus vykdymas ir išmanus talpinimas gali smarkiai pagerinti atsako laikus.

### Ateities kryptys

Tol, kol SLM technologija toliau vystysis, galime tikėtis:

- **Pagerintas funkcijų kvietimo tikslumas**: Geresnis ketinimų atpažinimas ir parametrų išgavimas
- **Išplėstas paralelinis apdorojimas**: Sudėtingesnė kelių funkcijų koordinacija
- **Geresni integracijos standartai**: Standartizuoti protokolai priemonių integracijai
- **Pažangios saugumo funkcijos**: Pagerintos autentifikacijos ir autorizacijos priemonės
- **Išplėstas ekosistema**: Auganti paruoštų funkcijų ir integracijų biblioteka

### Kaip pradėti

Norėdami pradėti įgyvendinti funkcijų kvietimą savo projektuose:

1. **Pradėkite paprastai**: Pradėkite nuo pagrindinių vienos funkcijos scenarijų
2. **Pasirinkite sistemą**: Nuspręskite tarp tiesioginio įgyvendinimo (Ollama/Phi-4) arba sistemos palaikymo (Qwen-Agent)
3. **Atidžiai projektuokite funkcijas**: Koncentruokitės į aiškius, gerai dokumentuotus funkcijų apibrėžimus
4. **Įgyvendinkite klaidų valdymą**: Nuo pradžių kurkite atsparų klaidų valdymą
5. **Didinkite mastą palaipsniui**: Pereikite nuo paprastų prie sudėtingų scenarijų, įgiję patirties

Funkcijų kvietimas transformuoja SLM iš įspūdingų teksto generatorių į praktiškus DI agentus, galinčius spręsti realaus pasaulio problemas. Sekdami šiame vadove aprašytus modelius ir praktiką, galėsite kurti galingas, patikimas DI sistemas, kurios žymiai pranoksta tradicines pokalbių sąsajas.
