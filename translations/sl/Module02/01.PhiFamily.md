## Ključne tehnologije, ki omogočajo družino Phi

### Metoda usposabljanja "iz učbenika"

Ena najbolj revolucionarnih lastnosti družine Phi je metodologija usposabljanja z "kakovostjo učbenika". Namesto usposabljanja na ogromnih količinah nefiltriranih podatkov z interneta, modeli Phi uporabljajo skrbno izbrane, visokokakovostne izobraževalne vsebine, zasnovane za učinkovito učenje razmišljanja, matematike, kodiranja in splošnega znanja.

Ta pristop deluje s ustvarjanjem sintetične izobraževalne vsebine, ki posnema visokokakovostne učbenike in akademski material. Podatki za usposabljanje so posebej zasnovani, da so pedagoško ustrezni, osredotočeni na jasne razlage, postopno razmišljanje in strukturirano predstavitev znanja.

### Napredno usposabljanje za razmišljanje

Nedavni modeli Phi vključujejo sofisticirane metodologije usposabljanja za razmišljanje, ki omogočajo kompleksno reševanje problemov več korakov. Te tehnike vključujejo:

**Usposabljanje verige misli**: Modeli se naučijo razbiti kompleksne probleme na vmesne korake razmišljanja, kar naredi njihov proces reševanja problemov bolj pregleden in zanesljiv.

**Prilagajanje med inferenco**: Modeli ustvarjajo podrobne verige razmišljanja, ki izkoriščajo dodatne računalniške vire med generiranjem odziva za izboljšano natančnost.

**Usposabljanje na meji zmogljivosti**: Podatki za usposabljanje so posebej izbrani, da model izzovejo na meji njegovih trenutnih zmožnosti, kar spodbuja učenje kompleksnih vzorcev razmišljanja.

### Arhitekturne inovacije

Družina Phi vključuje več arhitekturnih optimizacij, zasnovanih posebej za učinkovitost:

**Učinkovitost parametrov**: Skrbne arhitekturne izbire, ki maksimirajo vpliv vsakega parametra v modelu.

**Večmodalna integracija**: Učinkovita integracija besedilnih, vizualnih in govorno obdelovalnih zmogljivosti v kompaktnem arhitekturnem okviru.

**Optimizacija strojne opreme**: Specializirane različice optimizirane za specifične strojne platforme in scenarije nameščanja.

### Primer matematičnega razmišljanja

Phi-4-mini-reasoning odlično obvladuje postopno reševanje matematičnih problemov. Na primer, ko ga vprašamo "Kako rešiti 3*x^2+4*x+5=1?", model poda podrobne korake razmišljanja:

```
<|system|>Your name is Phi, an AI math expert developed by Microsoft.<|end|>
<|user|>How to solve 3*x^2+4*x+5=1?<|end|>
<|assistant|>
I need to solve the quadratic equation 3x² + 4x + 5 = 1.

First, let me rearrange this to standard form:
3x² + 4x + 5 = 1
3x² + 4x + 5 - 1 = 0  
3x² + 4x + 4 = 0

Now I can use the quadratic formula: x = (-b ± √(b² - 4ac)) / (2a)
Where a = 3, b = 4, c = 4

Let me calculate the discriminant:
b² - 4ac = 4² - 4(3)(4) = 16 - 48 = -32

Since the discriminant is negative (-32), this equation has no real solutions.
The solutions are complex: x = (-4 ± √(-32)) / 6 = (-4 ± 4i√2) / 6 = (-2 ± 2i√2) / 3
```

## Razvoj družine Phi

Zgodnji modeli Phi so postavili temeljna načela kakovostnih podatkov za usposabljanje in učinkovitih arhitektur:

Serija Phi-3 je predstavljala preboj v zmogljivostih SLM z več specializiranimi različicami:

## Primeri razvoja in integracije

### Hitri začetek s Transformers

Tako začnete z modeli Phi z uporabo knjižnice Hugging Face Transformers:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# Naloži Phi-4-mini-instruct
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True,
    attn_implementation="flash_attention_2"  # Za optimizirano zmogljivost
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")

# Oblikujte vaš poziv s pomočjo predloge za klepet
messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain quantum computing in simple terms."}
]

# Uporabi predlogo za klepet
input_text = tokenizer.apply_chat_template(messages, tokenize=False)
inputs = tokenizer(input_text, return_tensors="pt")

# Ustvari odgovor
with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=200, temperature=0.7)
    
response = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(response)
```

### Primer fino nastavitve

Naslednji primer prikazuje, kako fino nastaviti Phi-4-mini-instruct za specifične naloge:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig
from trl import SFTTrainer
from datasets import load_dataset

# Konfiguracija za LoRA fino nastavljanje
peft_config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
    target_modules="all-linear"
)

# Konfiguracija učenja optimizirana za učinkovitost
training_config = TrainingArguments(
    output_dir="./phi-4-mini-finetuned",
    learning_rate=5.0e-06,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=1,
    num_train_epochs=1,
    bf16=True,
    gradient_checkpointing=True,
    warmup_ratio=0.2,
    save_steps=100
)

# Naloži model in tokenizator
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")
tokenizer.pad_token = tokenizer.unk_token
tokenizer.padding_side = 'right'

# Naloži in obdela nabor podatkov
train_dataset = load_dataset("HuggingFaceH4/ultrachat_200k", split="train_sft")

# Inicializiraj trenerja

    model=model,

    peft_config=peft_config,
    train_dataset=train_dataset,
```
