## Kaj je klic funkcije?

Klic funkcije je zmogljivost, ki omogoča majhnim jezikovnim modelom (SLMs), da komunicirajo z zunanjimi orodji, API-ji in storitvami. Namesto da bi bili omejeni na svoje podatke za učenje, lahko SLM-ji zdaj:

- **Povežejo se z zunanjimi API-ji** (vremenske storitve, baze podatkov, iskalniki)
- **Izvedejo specifične funkcije** na podlagi uporabniških zahtev
- **Pridobijo informacije v realnem času** iz različnih virov
- **Izvajajo računske naloge** preko specializiranih orodij
- **Povežejo več operacij** za kompleksne delovne tokove

Ta zmogljivost spremeni SLM-je iz statičnih generatorjev besedila v dinamične AI agente, ki lahko izvajajo naloge v resničnem svetu.

## Kako deluje klic funkcije

Postopek klica funkcije sledi sistematičnemu delovnemu procesu:

### 1. Integracija orodij
- **Zunanja orodja**: SLM-ji se povezujejo z vremenskimi API-ji, bazami podatkov, spletnimi storitvami in drugimi zunanjimi sistemi
- **Definicije funkcij**: Vsako orodje je opredeljeno s specifičnimi parametri, formati vhodov/izhodov in opisi
- **Združljivost API**: Orodja so integrirana preko standardiziranih vmesnikov (REST API, SDK ipd.)

### 2. Definicija funkcije
Funkcije so definirane s tremi ključnimi komponentami:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Zaznavanje namena
- **Obdelava naravnega jezika**: SLM analizira uporabnikov vnos za razumevanje namena
- **Skladnost funkcij**: Določi, katera funkcija(e) je potrebno izvesti za izpolnitev zahteve
- **Izvleček parametrov**: Identificira in izvleče potrebne parametre iz sporočila uporabnika

### 4. Generiranje JSON izhoda
SLM generira strukturiran JSON, ki vsebuje:
- Ime funkcije, ki jo je treba poklicati
- Potrebne parametre z ustreznimi vrednostmi
- Kontekst izvedbe in metapodatke

### 5. Zunanja izvedba
- **Preverjanje parametrov**: Zagotavlja, da so vsi zahtevani parametri prisotni in pravilno oblikovani
- **Izvedba funkcije**: Aplikacija izvede določeno funkcijo s podanimi parametri
- **Obravnava napak**: Upravljanje z napakami, prekinitvami in neveljavnimi odgovori

### 6. Integracija odziva
- **Obdelava rezultatov**: Izhod funkcije se vrne SLM-ju
- **Integracija konteksta**: SLM vključi rezultate v svoj odgovor
- **Komunikacija z uporabnikom**: Predstavi informacije v naravnem, pogovornem formatu

## Scenariji uporabe

### Pridobivanje podatkov
Pretvori naravne jezikovne poizvedbe v strukturirane API klice:
- **"Pokaži moje nedavne naročnike"** → Poizvedba baze podatkov z ID uporabnika in datumski filtri
- **"Kakšno je vreme v Tokiu?"** → Klic vremenskega API z lokacijskim parametrom
- **"Najdi e-pošto od Johna prejšnji teden"** → Poizvedba e-poštne storitve s pošiljateljem in datumski filtri

### Izvedba operacij
Pretvori uporabniške zahteve v specifične klice funkcij:
- **"Rezerviraj sestanek za jutri ob 14:00"** → Integracija koledarskega API-ja
- **"Pošlji sporočilo ekipi"** → API platforme za komunikacijo
- **"Ustvari varnostno kopijo mojih datotek"** → Operacija datotečnega sistema

### Računske naloge
Obravnava zahtevne matematične ali logične operacije:
- **"Izračunaj obrestno mero na $10.000 po 5% za 10 let"** → Funkcija finančnega izračuna
- **"Analiziraj ta nabor podatkov za trende"** → Orodja za statistično analizo
- **"Optimiziraj to pot za dostavo"** → Algoritmi optimizacije poti

### Delovni tokovi obdelave podatkov
Poveži več funkcijskih klicev za kompleksne operacije:
1. **Pridobi podatke** iz več virov
2. **Razčleni in preveri** informacije
3. **Pretvori** podatke v zahtevan format
4. **Shrani rezultate** v ustrezne sisteme
5. **Ustvari poročila** ali vizualizacije

### Integracija UI/UX
Omogoči dinamične posodobitve vmesnika:
- **"Pokaži podatke o prodaji na nadzorni plošči"** → Generiranje in prikaz grafikonov
- **"Posodobi zemljevid z novimi lokacijami"** → Integracija geosprostorskih podatkov
- **"Osveži prikaz inventarja"** → Sinhronizacija podatkov v realnem času

### Implementacija po meri

Prav tako lahko definirate lastne funkcije za Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Simuliraj klic vremenskega API-ja
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Uporabi prilagojeno orodje
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

import openai

# Inicializirajte z aliasom modela

    {
        "name": "calculate_tax",

            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number",

                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Naredite zahtevek za klic funkcije
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"

print(response.choices[0].message.content)

### Pogoste težave in rešitve

#### Težava 1: Funkcija ni poklicana
**Simptomi**: Model odgovarja z besedilom namesto da bi poklical funkcijo

**Rešitve**:
1. **Preverite opis funkcije**: Poskrbite, da jasno ustreza uporabnikovemu namenu
2. **Preverite definicije parametrov**: Zagotovite, da so vsi zahtevani parametri pravilno definirani
3. **Preverite sistemski poziv**: Vključite jasna navodila o uporabi funkcij
4. **Preizkusite z neposrednimi zahtevami**: Na primer "Prosim uporabi vremensko funkcijo za pridobitev podatkov za London"

#### Težava 2: Napačni parametri
**Simptomi**: Funkcija je poklicana z napačnimi ali manjkajočimi parametri

**Rešitve**:
1. **Dodajte primere parametrov**: Vključite vzorčne vrednosti v opise parametrov
2. **Uporabite omejitve enum**: Omejite vrednosti parametrov na določene možnosti, kjer je mogoče
3. **Implementirajte privzete vrednosti**: Zagotovite smiselne privzete vrednosti za opcijske parametre

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }
}
```

#### Težava 3: Napake pri vzporednem klicu funkcij
**Simptomi**: Izvede se le ena funkcija, čeprav bi moralo teči več

**Rešitve**:
1. **Preverite podporo modela**: Prepričajte se, da vaš model podpira vzporedni klic funkcij
2. **Posodobite sistemski poziv**: Vključite "nekatera orodja" ali "več orodij" v sistemsko sporočilo
3. **Uporabite primerne različice modelov**: Priporočeno Phi-4-mini:3.8b-fp16 za Ollamo

#### Težava 4: Težave s predlogami pri Ollama
**Simptomi**: Klic funkcije ne deluje z privzeto nastavitvijo Ollama

**Rešitve**:
1. **Uporabite lastno ModelFile**: Uporabite popravljeno predlogo iz tega vodiča
2. **Posodobite Ollame**: Poskrbite, da imate različico 0.5.13 ali višjo
3. **Preverite kvantizacijo modela**: Višje stopnje kvantizacije (Q8_0, fp16) delujejo bolje kot močno kvantizirane različice

### Optimizacija zmogljivosti

#### 1. Učinkovit dizajn funkcij

        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Preverite, ali funkcija obstaja
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Preverite omejitve hitrosti klicev
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Preverite parametre
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Izvedite funkcijo
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Zabeležite uspešno izvedbo
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )

            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Ponastavite števec, če je minila minuta
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Preverite, ali ste pod omejitvijo
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Preverite zahtevane parametre
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Preverite tipe in omejitve parametrov
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Preverjanje tipa
                expected_type = param_info.get('type')

                        error=f"Parameter '{param_name}' must be a string"
                    )

                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):

                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )

                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"

## Zaključek

Klic funkcije v majhnih jezikovnih modelih predstavlja paradigmo premika iz statičnih AI pomočnikov v dinamične, zmožne agente, ki lahko komunicirajo z resničnim svetom. Ta vodič je zajel:

### Ključni poudarki

1. **Temeljno razumevanje**: Klic funkcij omogoča SLM, da se razširijo preko svojih podatkov za učenje s povezovanjem na zunanja orodja in storitve.

2. **Fleksibilnost implementacije**: Obstaja več pristopov, od nizkonivojskih implementacij z lastnimi predlogami do visokorazrednih ogrodij, kot sta Qwen-Agent in Foundry Local.

3. **Premisleki za produkcijo**: Podjetniške uvedbe zahtevajo pozornost pri obravnavi napak, omejitvah hitrosti, varnosti in beleženju revizij.

4. **Optimizacija zmogljivosti**: Pravilna zasnova funkcij, učinkovita izvedba in pametno predpomnjenje lahko močno izboljšajo čas odziva.

### Prihodnje smernice

Z nadaljnjim razvojem tehnologije SLM lahko pričakujemo:

- **Izboljšano natančnost klica funkcij**: Boljše zaznavanje namena in izvleček parametrov
- **Izboljšano vzporedno procesiranje**: Bolj sofisticirana orkestracija več funkcij
- **Boljše standarde za integracijo**: Standardizirane protokole za integracijo orodij
- **Napredne varnostne funkcije**: Izboljšani mehanizmi preverjanja pristnosti in pooblastil
- **Razširjen ekosistem**: Rastoča knjižnica vnaprej izdelanih funkcij in integracij

### Začetek

Za začetek implementacije klica funkcij v vaših projektih:

1. **Začnite enostavno**: Začnite z osnovnimi scenariji z eno funkcijo
2. **Izberite ogrodje**: Odločite se med neposredno implementacijo (Ollama/Phi-4) ali s pomočjo ogrodja (Qwen-Agent)
3. **Natančno oblikujte funkcije**: Osredotočite se na jasne, dobro dokumentirane definicije funkcij
4. **Implementirajte obravnavo napak**: Zgradite robustno obravnavo napak od začetka
5. **Postopno skaliranje**: Premikajte se od enostavnega do zahtevnejšega scenarija, ko pridobivate izkušnje

Klic funkcije spremeni SLM-je iz impresivnih generatorjev besedila v praktične AI agente, sposobne reševati probleme v resničnem svetu. Z upoštevanjem vzorcev in praks iz tega vodiča lahko zgradite zmogljive, zanesljive AI sisteme, ki segajo daleč preko tradicionalnih klepetalnih vmesnikov.
