## ما هو استدعاء الوظائف؟

استدعاء الوظائف هو قدرة قوية تتيح لنماذج اللغات الصغيرة (SLMs) التفاعل مع أدوات خارجية وواجهات برمجة التطبيقات والخدمات. بدلاً من أن تكون مقيدة ببيانات تدريبها فقط، يمكن الآن للنماذج الصغيرة:

- **التواصل مع واجهات برمجة التطبيقات الخارجية** (خدمات الطقس، قواعد البيانات، محركات البحث)
- **تنفيذ وظائف محددة** بناءً على طلبات المستخدم
- **استخراج معلومات في الوقت الحقيقي** من مصادر متعددة
- **أداء مهام حسابية** عبر أدوات متخصصة
- **ربط عمليات متعددة** معًا لسير عمل معقد

هذه القدرة تحول النماذج الصغيرة من مولدات نصوص ثابتة إلى وكلاء ذكاء اصطناعي ديناميكيين قادرين على أداء مهام العالم الحقيقي.

## كيف يعمل استدعاء الوظائف

يتبع استدعاء الوظائف سير عمل منهجي:

### 1. تكامل الأدوات
- **الأدوات الخارجية**: يمكن للنماذج الصغيرة الاتصال بواجهات الطقس وقواعد البيانات والخدمات الشبكية وأنظمة أخرى خارجية
- **تعريفات الوظائف**: يتم تعريف كل أداة بمعلمات معينة، وصيغ دخول/خروج، ووصف
- **التوافق مع API**: يتم دمج الأدوات عبر واجهات موحدة (REST APIs، SDKs، إلخ)

### 2. تعريف الوظيفة
تُعرف الوظائف بثلاثة مكونات رئيسية:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. الكشف عن النية
- **معالجة اللغة الطبيعية**: يحلل النموذج مدخلات المستخدم لفهم النية
- **مطابقة الوظيفة**: يحدد الوظيفة/الوظائف المطلوبة لتنفيذ الطلب
- **استخراج المعلمات**: يحدد ويستخلص المعلمات المطلوبة من رسالة المستخدم

### 4. توليد مخرجات JSON
يولد النموذج الصغير JSON منظماً يحتوي على:
- اسم الوظيفة المراد استدعاؤها
- المعلمات المطلوبة بالقيم المناسبة
- سياق التنفيذ والبيانات الوصفية

### 5. التنفيذ الخارجي
- **التحقق من المعلمات**: يتأكد من وجود كل المعلمات المطلوبة وصياغتها بشكل صحيح
- **تنفيذ الوظيفة**: يتم تنفيذ الوظيفة المحددة بالمعلمات المقدمة
- **معالجة الأخطاء**: يدير حالات الفشل، انتهاء المهلة، والاستجابات غير الصالحة

### 6. دمج الاستجابة
- **معالجة النتائج**: تُعاد مخرجات الوظيفة إلى النموذج الصغير
- **دمج السياق**: يدمج النموذج النتائج في استجابته
- **التواصل مع المستخدم**: يعرض المعلومات بطريقة طبيعية وحوارية

## سيناريوهات التطبيقات

### استرجاع البيانات
تحويل استفسارات اللغة الطبيعية إلى مكالمات API منظمة:
- **"أظهر طلبياتي الأخيرة"** → استعلام قاعدة بيانات مع معرّف المستخدم ومرشحات التاريخ
- **"كيف الطقس في طوكيو؟"** → مكالمة API الطقس مع معلمة الموقع
- **"ابحث عن رسائل من جون الأسبوع الماضي"** → استعلام خدمة البريد الإلكتروني مع مرشحات المرسل والتاريخ

### تنفيذ العمليات
تحويل طلبات المستخدم إلى استدعاءات دوال محددة:
- **"حدد موعد اجتماع غداً الساعة 2 بعد الظهر"** → دمج مع واجهة برمجة تقويم
- **"أرسل رسالة إلى الفريق"** → واجهة برمجة منصة التواصل
- **"أنشئ نسخة احتياطية من ملفاتي"** → عملية نظام ملفات

### المهام الحسابية
معالجة العمليات الرياضية أو المنطقية المعقدة:
- **"احسب الفائدة المركبة على 10,000 دولار بمعدل 5% لمدة 10 سنوات"** → وظيفة حساب مالي
- **"حلل هذه مجموعة البيانات للاتجاهات"** → أدوات التحليل الإحصائي
- **"حسن هذه المسار للتوصيل"** → خوارزميات تحسين المسار

### سير عمل معالجة البيانات
ربط مكالمات وظائف متعددة لعمليات معقدة:
1. **استرجاع البيانات** من مصادر متعددة
2. **تحليل والتحقق من صحة** المعلومات
3. **تحويل** البيانات إلى الصيغة المطلوبة
4. **تخزين النتائج** في الأنظمة المناسبة
5. **توليد تقارير** أو تصورات

### تكامل واجهة المستخدم وتجربة المستخدم
تمكين تحديثات ديناميكية للواجهة:
- **"اعرض بيانات المبيعات على لوحة المعلومات"** → توليد وعرض المخططات
- **"حدّث الخريطة بالمواقع الجديدة"** → دمج البيانات الجغرافية المكانية
- **"جدّد عرض المخزون"** → مزامنة بيانات في الوقت الحقيقي

- إصدار Ollama 0.5.13 أو أعلى
- نموذج Phi-4-mini (مُوصى به: `phi4-mini:3.8b-fp16`)

### مثال استدعاء وظيفة مفردة

```python
import json
import requests

# تعريف الأداة/الدالة
tools = [
    {
        "name": "get_weather",
        "description": "Get current weather information for a location",
        "parameters": {
            "location": {

            },

                "description": "Temperature units (celsius or fahrenheit)",

                "default": "celsius"

    }

    {
        "role": "system",
        "content": "You are a helpful weather assistant",

    },
    {
        "role": "user",
        "content": "What's the weather like in London today?"

]

    "http://localhost:11434/api/chat",
    json={

        "messages": messages,
        "stream": False
    }
)

print(response.json())
```

## العمل مع استدعاء وظائف Qwen3

تقدم Qwen3 قدرات استدعاء وظيفة متقدمة مع أداء ومرونة ممتازة. إليك كيفية تطبيقها:

### استخدام إطار عمل Qwen-Agent

يوفر Qwen-Agent إطار عمل عالي المستوى يبسط تنفيذ استدعاء الوظائف:

#### التثبيت
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### الإعداد الأساسي

```python
import os
from qwen_agent.agents import Assistant

# تكوين نموذج اللغة الكبير
llm_cfg = {
    'model': 'Qwen3-8B',
    # الخيار 1: استخدام استوديو نموذج علي بابا
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # الخيار 2: استخدام النشر المحلي
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'فارغ',
    
    # تكوين اختياري لوضع التفكير
    'generate_cfg': {
        'thought_in_content': True,  # تضمين الاستدلال في الاستجابة
    }
}

# تعريف الأدوات باستخدام بروتوكول سياق النموذج (MCP)
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # أداة تنفيذ الشفرة المدمجة
]

# إنشاء المساعد
bot = Assistant(llm=llm_cfg, function_list=tools)

# مثال على الاستخدام
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# توليد الاستجابة مع استدعاء الدالة
for response in bot.run(messages=messages):
    print(response)
```

### تنفيذ وظيفة مخصصة

يمكنك أيضًا تعريف وظائف مخصصة لـ Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # محاكاة استدعاء واجهة برمجة تطبيقات الطقس
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# استخدم الأداة المخصصة
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

## التكامل المحلي مع Foundry

تقدم Foundry Local من مايكروسوفت واجهة برمجة تطبيقات متوافقة مع OpenAI لتشغيل النماذج محليًا مع تعزيز الخصوصية والأداء.

### الإعداد والتثبيت

#### ويندوز
حمّل المثبّت من [صفحة إصدارات Foundry Local](https://github.com/microsoft/Foundry-Local/releases) واتبع تعليمات التثبيت.

#### ماك أو إس
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

#### الاستخدام الأساسي

```python
import openai
from foundry_local import FoundryLocalManager

# التهيئة مع الاسم المستعار للنموذج
alias = "phi-3.5-mini"  # أو أي نموذج مدعوم
manager = FoundryLocalManager(alias)

# إنشاء عميل OpenAI يشير إلى نقطة النهاية المحلية
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# تعريف الدوال للنموذج
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# إجراء طلب استدعاء الدالة
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

### ميزات متقدمة في Foundry Local

#### إدارة النماذج
```bash
# سرد النماذج المتاحة
foundry model list

# تحميل نموذج معين
foundry model download phi-3.5-mini

# تشغيل النموذج بشكل تفاعلي
foundry model run phi-3.5-mini

# إزالة النموذج من الذاكرة المؤقتة
foundry model remove phi-3.5-mini

# حذف جميع النماذج الموجودة في الذاكرة المؤقتة
foundry model remove "*"
```

#### تحسين الأداء
يختار Foundry Local تلقائيًا أفضل نسخة من النموذج تناسب عتاد جهازك:
- **CUDA GPU**: تنزيل نماذج محسنة لوحدات معالجة الرسوميات
- **معالج Qualcomm NPU**: استخدام نسخ معززة بوحدة المعالجة العصبية
- **وحدة المعالجة المركزية فقط**: اختيار نماذج محسنة للمعالج المركزي

        self.functions[name] = {

            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,

        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # التحقق من وجود الدالة
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # فحص حدود المعدل
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # التحقق من المعطيات
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # تنفيذ الدالة
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # تسجيل التنفيذ الناجح
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # تسجيل التنفيذ الفاشل
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # إعادة تعيين العداد إذا مرّت دقيقة
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # التحقق من كون العدد تحت الحد
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # التحقق من المعطيات المطلوبة
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # التحقق من أنواع المعطيات والقيود
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # التحقق من النوع

                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )

                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )

    def get_function_definitions(self) -> List[Dict]:
        """Get OpenAI-compatible function definitions for all registered functions"""
        definitions = []
        
        for func_name, func_info in self.functions.items():
            definition = {
                'name': func_name,
                'description': func_info['description'],
                'parameters': {
                    'type': 'object',
                    'properties': {},
                    'required': []
                }
            }
            
            for param_name, param_info in func_info['parameters'].items():
                definition['parameters']['properties'][param_name] = {
                    'type': param_info['type'],
                    'description': param_info.get('description', '')
                }
                
                if 'enum' in param_info:
                    definition['parameters']['properties'][param_name]['enum'] = param_info['enum']
                
                if 'default' in param_info:
                    definition['parameters']['properties'][param_name]['default'] = param_info['default']
                
                if param_info.get('required', False):
                    definition['parameters']['required'].append(param_name)
            
            definitions.append(definition)
        
        return definitions

## الخلاصة

يمثل استدعاء الوظائف في نماذج اللغات الصغيرة تحولًا من مساعدين ذكيين ثابتين إلى وكلاء ديناميكيين قادرين على التفاعل مع العالم الحقيقي. لقد غطى هذا الدرس:

### النقاط الرئيسية

1. **فهم الأساسيات**: يتيح استدعاء الوظائف للنماذج الصغيرة تجاوز بيانات التدريب عبر الاتصال بالأدوات والخدمات الخارجية.

2. **مرونة التنفيذ**: توجد طرق متعددة من التطبيقات منخفضة المستوى بالقوالب المخصصة إلى الأُطر عالية المستوى مثل Qwen-Agent و Foundry Local.

3. **اعتبارات الإنتاج**: تتطلب النشر المؤسسي الانتباه لمعالجة الأخطاء، تحديد معدلات الطلب، الأمان، وتسجيل التدقيق.

4. **تحسين الأداء**: التصميم السليم للوظائف، التنفيذ الفعال، والتخزين المؤقت الذكي يمكن أن يحسن أوقات الاستجابة بشكل كبير.

### الاتجاهات المستقبلية

مع تطور تقنية النماذج الصغيرة، نتوقع:

- **تحسين دقة استدعاء الوظائف**: أفضل في الكشف عن النية واستخراج المعلمات
- **تعزيز المعالجة المتوازية**: تنظيم أكثر تعقيدًا للوظائف المتعددة
- **معايير تكامل أفضل**: بروتوكولات موحدة لدمج الأدوات
- **ميزات أمان متقدمة**: تحسين آليات المصادقة والتفويض
- **توسيع النظام البيئي**: مكتبة متزايدة من الوظائف والدمجات المسبقة الصنع

### البدء

لبدء تنفيذ استدعاء الوظائف في مشاريعك:

1. **ابدأ ببساطة**: ابدأ بسيناريوهات استدعاء وظيفة واحدة أساسية
2. **اختر إطار العمل**: حدد بين التنفيذ المباشر (Ollama/Phi-4) أو المساعدة بإطار عمل (Qwen-Agent)
3. **صمّم الوظائف بحرص**: ركز على تعريفات واضحة وموثقة جيدًا للوظائف
4. **طبّق معالجة الأخطاء**: ابني معالجة أخطاء قوية منذ البداية
5. **وسّع تدريجيًا**: انتقل من السيناريوهات البسيطة إلى المعقدة مع اكتساب الخبرة

يحول استدعاء الوظائف النماذج الصغيرة من مولدات نصوص مبهرة إلى وكلاء ذكاء اصطناعي عمليين قادرين على حل مشاكل العالم الحقيقي. باتباع الأنماط والممارسات الموضحة في هذا الدرس، يمكنك بناء أنظمة ذكاء اصطناعي قوية وموثوقة تتجاوز واجهات الدردشة التقليدية بكثير.
