# मॉड्यूल 08: माइक्रोसॉफ्ट फाउंड्री लोकल के साथ हाथों से काम - पूर्ण डेवलपर टूलकिट

## अवलोकन

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) एज AI विकास की अगली पीढ़ी का प्रतिनिधित्व करता है, जो डेवलपर्स को शक्तिशाली टूल प्रदान करता है ताकि वे स्थानीय स्तर पर AI एप्लिकेशन बना सकें, प्रकाशित कर सकें और स्केल कर सकें, और Azure AI Foundry के साथ सहज एकीकरण बनाए रख सकें। यह मॉड्यूल स्थापना से लेकर उन्नत एजेंट विकास तक Foundry Local का व्यापक कवरेज प्रदान करता है।

**मुख्य तकनीकें:**
- माइक्रोसॉफ्ट फाउंड्री लोकल CLI और SDK
- Azure AI Foundry एकीकरण
- डिवाइस पर मॉडल निष्कर्षण
- स्थानीय मॉडल कैशिंग और अनुकूलन
- एजेंट-आधारित संरचनाएं

## सीखने के उद्देश्य

इस मॉड्यूल को पूरा करके, आप:

- **Foundry Local में महारत हासिल करें**: Windows 11 विकास के लिए स्थापना, कॉन्फ़िगर और अनुकूलन करें
- **विभिन्न मॉडल तैनात करें**: CLI कमांड के साथ स्थानीय रूप से phi, qwen, deepseek, और GPT मॉडल चलाएं
- **उत्पादन समाधान बनाएं**: उन्नत प्रॉम्प्ट इंजीनियरिंग और डेटा एकीकरण के साथ AI एप्लिकेशन बनाएं
- **ओपन-सोर्स इकोसिस्टम का लाभ उठाएं**: Hugging Face मॉडल और सामुदायिक योगदानों को एकीकृत करें
- **AI एजेंट विकसित करें**: ग्राउंडिंग और ऑर्केस्ट्रेशन क्षमताओं वाले बुद्धिमान एजेंट बनाएं
- **एंटरप्राइज़ पैटर्न लागू करें**: उत्पादन तैनाती के लिए मॉड्यूलर, स्केलेबल AI समाधान बनाएं

## पूर्व आवश्यकताएँ

### सिस्टम आवश्यकताएँ
- **ऑपरेटिंग सिस्टम**: Windows 11 (22H2 या बाद का संस्करण)
- **मेमोरी**: 16GB RAM (बड़े मॉडल के लिए 32GB अनुशंसित)
- **स्टोरेज**: मॉडल कैशिंग के लिए 50GB खाली स्थान
- **हार्डवेयर**: NPU-सक्षम डिवाइस अनुशंसित (Copilot+ PC), GPU वैकल्पिक
- **नेटवर्क**: प्रारंभिक मॉडल डाउनलोड के लिए उच्च गति इंटरनेट

### विकास वातावरण

- Visual Studio Code विथ एआई टूलकिट एक्सटेंशन
- पायथन 3.10+ और पिप
- वर्शन कंट्रोल के लिए Git
- PowerShell या कमांड प्रॉम्प्ट
- Azure CLI (क्लाउड इंटीग्रेशन के लिए वैकल्पिक)

### ज्ञान पूर्वापेक्षाएँ
- एआई/एमएल के मूल अवधारणाओं की समझ

## सीखने के परिणाम

इस मॉड्यूल को पूरा करने के बाद, आप सक्षम होंगे:

### तकनीकी महारत
- **डिप्लॉय और प्रबंधित करें**: विकास और उत्पादन वातावरणों में Foundry Local इंस्टालेशन
- **मॉडल इंटीग्रेट करें**: Microsoft, Hugging Face और समुदाय स्रोतों से विभिन्न मॉडल परिवारों के साथ निर्बाध काम करें
- **ऐप्लिकेशन बनाएं**: उन्नत फीचर्स और ऑप्टिमाइजेशन के साथ प्रोडक्शन-तैयार AI ऐप्लिकेशन बनाएँ
- **एजेंट्स विकसित करें**: ग्राउंडिंग, तर्क और टूल इंटीग्रेशन के साथ परिष्कृत AI एजेंट्स लागू करें

### रणनीतिक समझ
- **आर्किटेक्चर निर्णय**: स्थानीय बनाम क्लाउड डिप्लॉयमेंट के बीच सूचित निर्णय लें
- **प्रदर्शन अनुकूलन**: विभिन्न हार्डवेयर कॉन्फ़िगरेशन में इन्फरेंस प्रदर्शन को अनुकूलित करें
- **उद्यम स्केलिंग**: स्थानीय प्रोटोटाइप से उद्यम डिप्लॉयमेंट तक ऐप्लिकेशन का डिज़ाइन करें
- **गोपनीयता और सुरक्षा**: स्थानीय इन्फरेंस के साथ गोपनीयता-संरक्षित AI समाधान लागू करें

### नवाचार क्षमताएँ
- **तेज़ प्रोटोटाइपिंग**: सभी 10 नमूना पैटर्न पर त्वरित AI ऐप्लिकेशन विचार बनाएं और परीक्षण करें
- **समुदाय इंटीग्रेशन**: ओपन-सोर्स मॉडल का उपयोग करें और इकोसिस्टम में योगदान दें
- **उन्नत पैटर्न**: RAG, एजेंट्स, और टूल इंटीग्रेशन सहित उन्नत AI पैटर्न लागू करें
- **फ्रेमवर्क महारत**: LangChain, Semantic Kernel, Chainlit, और Electron के साथ विशेषज्ञ स्तर का इंटीग्रेशन
- **प्रोडक्शन डिप्लॉयमेंट**: स्थानीय प्रोटोटाइप से उद्यम सिस्टम तक स्केलेबल AI समाधान डिप्लॉय करें
- **भविष्य-तैयार विकास**: उभरती AI तकनीकों और पैटर्न के लिए तैयार ऐप्लिकेशन बनाएं

### आम समस्याओं का समाधान

**Foundry Local कनेक्शन त्रुटियाँ**
```powershell
# सेवा स्थिति जांचें
foundry status

# आवश्यक होने पर पुनः आरंभ करें
foundry restart

# एंडपॉइंट की पहुंच सत्यापित करें
curl http://localhost:5273/v1/models
```

**मॉडल लोडिंग समस्याएँ**
```powershell
# उपलब्ध मॉडल जांचें
foundry model list --cached

# गायब मॉडल डाउनलोड करें
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# आवश्यक होने पर पुनः लोड करें
foundry model unload --all
foundry model run phi-4-mini
```

**निर्भरता समस्याएँ**
```powershell
# पाइप को अपग्रेड करें और पुनः स्थापित करें
python -m pip install --upgrade pip
pip install -r requirements.txt --force-reinstall

# Node.js नमूनों के लिए
npm cache clean --force
npm install
```

## सारांश


यह मॉड्यूल एज AI विकास की अत्याधुनिक तकनीक का प्रतिनिधित्व करता है, जो Microsoft के एंटरप्राइज़-ग्रेड टूल्स को ओपन-सोर्स इकोसिस्टम की लचीलापन और नवाचार के साथ संयोजित करता है। Foundry Local को सभी 10 व्यापक सैंपल के माध्यम से मास्टर करके, आप AI एप्लिकेशन विकास के अग्रिम पंक्ति में होंगे।

**पूर्ण सीखने का मार्ग:**
- **बुनियाद** (सैंपल 01-03): API एकीकरण और मॉडल प्रबंधन
- **एप्लिकेशन** (सैंपल 04-06): RAG, एजेंट, और बुद्धिमान रूटिंग
- **उन्नत** (सैंपल 07-10): उत्पादन ढांचे और एंटरप्राइज़ एकीकरण

Azure OpenAI एकीकरण (सत्र 2) के लिए, आवश्यक पर्यावरण चर और API संस्करण सेटिंग्स के लिए व्यक्तिगत सैंपल README फ़ाइलें देखें।
