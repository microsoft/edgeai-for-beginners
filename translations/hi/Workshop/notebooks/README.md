# कार्यशाला नोटबुक्स

> **इंटरैक्टिव जुपिटर नोटबुक्स हैंड्स-ऑन एज AI सीखने के लिए**
>
> प्रगतिशील, स्व-गति से चलने वाले ट्यूटोरियल जो बुनियादी चैट पूर्णताओं से लेकर उन्नत मल्टी-एजेंट सिस्टम तक माइक्रोसॉफ्ट फाउंड्री लोकल और स्मॉल लैंग्वेज मॉडल्स का उपयोग करते हुए निर्माण करते हैं।

---

## 📖 परिचय

**एजएआई फॉर बिगिनर्स वर्कशॉप नोटबुक्स** संग्रह में आपका स्वागत है। ये इंटरैक्टिव जुपिटर नोटबुक्स एक हैंड्स-ऑन सीखने का अनुभव प्रदान करती हैं जहाँ आप एज एआई कोड को वास्तविक समय में लिखेंगे, निष्पादित करेंगे और प्रयोग करेंगे।

### जुपिटर नोटबुक्स क्यों?

पारंपरिक ट्यूटोरियल्स से अलग, ये नोटबुक्स प्रदान करती हैं:

- **इंटरैक्टिव लर्निंग**: कोड सेलों को चलाएं और तुरंत परिणाम देखें
- **प्रयोग**: पैरामीटर संशोधित करें और वास्तविक समय में बदलाव देखें
- **डॉक्यूमेंटेशन**: इनलाइन व्याख्याएँ और मार्कडाउन सेल्स आपको सिद्धांतों के माध्यम से मार्गदर्शन करते हैं
- **पुनरुत्पादनीयता**: पूर्ण कार्यशील उदाहरण जिन्हें आप संदर्भित और पुनः उपयोग कर सकते हैं
- **दृश्यता**: प्रदर्शन मेट्रिक्स, एम्बेडिंग्स, और परिणाम इनलाइन देखें

### ये नोटबुक्स खास क्या बनाती हैं?

प्रत्येक नोटबुक **प्रोडक्शन-रेडी सर्वश्रेष्ठ प्रथाओं** का पालन करते हुए डिज़ाइन की गई है:

✅ **व्यापक त्रुटि प्रबंधन** - सौम्य गिरावट और सूचनात्मक त्रुटि संदेश  
✅ **टाइप हिंट्स और डॉक्यूमेंटेशन** - स्पष्ट फ़ंक्शन सिग्नेचर और डॉकस्ट्रिंग  
✅ **प्रदर्शन निगरानी** - टोकन उपयोग और विलंबता मापन  
✅ **मॉड्यूलर डिज़ाइन** - पुनः उपयोग योग्य पैटर्न जिन्हें आप अपने प्रोजेक्ट्स में अनुकूलित कर सकते हैं  
✅ **प्रगतिशील जटिलता** - पिछले सत्रों पर व्यवस्थित आधार पर निर्माण करता है

## 🎯 सीखने के उद्देश्य

### मुख्य कौशल जिन्हें आप विकासित करेंगे

इन नोटबुक्स के माध्यम से कार्य करने पर, आप मास्टर करेंगे:

1. **लोकल एआई सेवा प्रबंधन**
   - माइक्रोसॉफ्ट फाउंड्री लोकल सेवाओं को कॉन्फ़िगर और प्रबंधित करें
   - अपने हार्डवेयर के लिए उपयुक्त मॉडल चुनें और लोड करें
   - संसाधन उपयोग की निगरानी करें और प्रदर्शन अनुकूलित करें
   - सेवा खोज और स्वास्थ्य जांच को संभालें

2. **एआई एप्लिकेशन विकास**
   - ओपनएआई-संगत चैट पूर्णताओं को लोकली लागू करें
   - बेहतर उपयोगकर्ता अनुभव के लिए स्ट्रीमिंग इंटरफेस बनाएं
   - स्मॉल लैंग्वेज मॉडल्स के लिए प्रभावी प्रॉम्प्ट डिज़ाइन करें
   - एप्लिकेशन्स में लोकल मॉडल्स एकीकृत करें

3. **रिट्रीवल ऑगमेंटेड जनरेशन (RAG)**
   - वक्टर एम्बेडिंग्स के साथ सेमांटिक सर्च बनाएं
   - डोमेन-विशिष्ट दस्तावेजों में LLM प्रतिक्रियाओं को ग्राउंड करें
   - RAGAS मेट्रिक्स के साथ RAG गुणवत्ता का मूल्यांकन करें
   - प्रोटोटाइप से प्रोडक्शन तक पैमाना बढ़ाएं

4. **प्रदर्शन अनुकूलन**
   - कई मॉडलों का व्यवस्थित रूप से बेंचमार्क करें
   - विलंबता, थ्रूपुट, और पहली टोकन समय मापें
   - स्मॉल लैंग्वेज मॉडल्स बनाम लार्ज लैंग्वेज मॉडल्स की तुलना करें
   - प्रदर्शन/गुणवत्ता व्यापार-ऑफ के आधार पर इष्टतम मॉडल चुनें

5. **मल्टी-एजेंट ऑर्केस्ट्रेशन**
   - विभिन्न कार्यों के लिए विशेषज्ञ एजेंट डिज़ाइन करें
   - एजेंट मेमोरी और संदर्भ प्रबंधन लागू करें
   - जटिल वर्कफ़्लोज़ में कई एजेंटों का समन्वय करें
   - एजेंट सहयोग के लिए समन्वयक पैटर्न बनाएं

6. **स्मार्ट मॉडल राउटिंग**
   - इरादा पहचान और पैटर्न मिलान लागू करें
   - स्वचालित रूप से उपयुक्त मॉडलों तक क्वेरी रूट करें
   - बहु-चरण पाइपलाइन्स बनाएं (योजना → निष्पादन → परिष्करण)
   - स्केलेबल मॉडल-एज़-टूल्स आर्किटेक्चर डिज़ाइन करें

### 📗 सत्र 02: RAG पाइपलाइन

**आप क्या सीखेंगे**:
- रिट्रीवल ऑगमेंटेड जनरेशन (RAG) पैटर्न लागू करें
- वाक्य-रूपांतरणकर्ता के साथ वक्टर एम्बेडिंग्स बनाएं
- कोसाइन समानता के साथ सेमांटिक सर्च बनाएं

### त्वरित सत्यापन

सेटअप सत्यापित करने के लिए इसे एक पायथन सेल में चलाएँ:

```python
from foundry_local import FoundryLocalManager
import openai

# प्रबंधक आरंभ करें (सेवा को स्वतः खोजता है)
manager = FoundryLocalManager("phi-4-mini")

# OpenAI क्लाइंट कॉन्फ़िगर करें
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# चैट पूर्णता का परीक्षण करें
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**अपेक्षित आउटपुट**: स्थानीय मॉडल से एक अभिवादन प्रतिक्रिया।
