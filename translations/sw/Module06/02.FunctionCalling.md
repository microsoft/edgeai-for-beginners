## Nini maana ya Kupiga Simu za Kazi?

Kupiga simu za kazi ni uwezo wenye nguvu unaoruhusu Modeli Ndogo za Lugha (SLMs) kuingiliana na zana za nje, APIs, na huduma. Badala ya kuwa na kikomo kwa data zao za mafunzo, SLMs sasa zinaweza:

- **Kuunganisha na APIs za nje** (huduma za hali ya hewa, hifadhidata, injini za utafutaji)
- **Kutekeleza kazi maalum** kulingana na maombi ya mtumiaji
- **Kupata habari za wakati halisi** kutoka vyanzo mbalimbali
- **Kufanya kazi za kihisabati** kupitia zana maalum
- **Kuingiza operesheni nyingi mfululizo** kwa kazi ngumu

Uwezo huu hubadilisha SLMs kutoka kizalishaji cha maandishi kimya kuwa mawakala wa AI wenye nguvu wanaoweza kutekeleza kazi halisi.

## Jinsi Kupiga Simu za Kazi Kazi

Mchakato wa kupiga simu za kazi unafuata mtiririko wa kazi ulio pangiliwa:

### 1. Muunganiko wa Zana
- **Zana za Nje**: SLMs zinaweza kuunganisha na APIs za hali ya hewa, hifadhidata, huduma za mtandao, na mifumo mingine ya nje
- **Maelezo ya Kazi**: Kila zana huwekwa na vigezo maalum, muundo wa ingizo/ matokeo, na maelezo
- **Ulinganifu wa API**: Zana huunganishwa kupitia kiolesura cha kawaida (REST APIs, SDKs, n.k.)

### 2. Ufafanuzi wa Kazi
Kazi hufafanuliwa na vipengele vitatu muhimu:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Kugundua Nia
- **Usindikaji wa Lugha Asilia**: SLM huchambua ingizo la mtumiaji kuelewa nia
- **Kufuata Kazi**: Huhakikisha ni kazi gani zinazohitajika kutimizwa kwa ombi
- **Kutoa Vigezo**: Hutambua na kutoa vigezo vinavyohitajika kutoka ujumbe wa mtumiaji

### 4. Uzalishaji wa Matokeo ya JSON
SLM hutengeneza JSON iliyopangwa ikiwa na:
- Jina la kazi ya kupiga simu
- Vigezo vinavyohitajika na thamani sahihi
- Muktadha wa utekelezaji na metadata

### 5. Utekelezaji wa Nje
- **Uhakiki wa Vigezo**: Kuhakikisha vigezo vyote vinavyohitajika vipo na vimepangwa vizuri
- **Utekelezaji wa Kazi**: Programu hutekeleza kazi iliyoainishwa kwa vigezo vilivyotolewa
- **Kushughulikia Makosa**: Kusimamia kushindwa, muda wa kukamilika, na majibu yasiyo sahihi

### 6. Muungano wa Majibu
- **Usindikaji wa Matokeo**: Matokeo ya kazi hurudishwa kwa SLM
- **Muunganiko wa Muktadha**: SLM hujumuisha matokeo katika jibu lake
- **Mawasiliano na Mtumiaji**: Huonyesha taarifa kwa mtindo wa mazungumzo ya asili

## Matumizi ya Maombi

### Kupata Data
Badilisha maswali ya lugha ya asili kuwa simu za API zilizo pangiliwa:
- **"Onyesha maagizo yangu ya hivi karibuni"** → Utafutaji wa hifadhidata kwa ID ya mtumiaji na vichujio vya tarehe
- **"Hali ya hewa Tokyo iko aje?"** → Simu ya API ya hali ya hewa kwa parameter ya eneo
- **"Tafuta barua pepe kutoka kwa John wiki iliyopita"** → Utafutaji wa huduma ya barua pepe kwa mtumaji na vichujio vya tarehe

### Kutekeleza Operesheni
Badilisha maombi ya mtumiaji kuwa simu za kazi maalum:
- **"Panga mkutano kesho saa 8 mchana"** → Muunganiko wa API ya kalenda
- **"Tuma ujumbe kwa timu"** → API ya jukwaa la mawasiliano
- **"Tengeneza nakala rudufu ya faili zangu"** → Operesheni ya mfumo wa faili

### Kazi za Kihisabati
Tumia operesheni tata za kihisabati au za mantiki:
- **"Hesabu riba ya mchanganyiko ya $10,000 kwa 5% kwa miaka 10"** → Kazi ya hesabu za kifedha
- **"Chambua dataset hii kwa mwenendo"** → Zana za uchambuzi wa takwimu
- **"Boresha njia hii kwa ajili ya usambazaji"** → Algoriti ya kuboresha njia

### Mtiririko wa Usindikaji wa Data
Kuengeza simu nyingi za kazi kwa operesheni ngumu:
1. **Pata data** kutoka vyanzo vingi
2. **Chambua na hakiki** taarifa
3. **Badilisha** data kuwa muundo unaotakiwa
4. **Hifadhi matokeo** katika mifumo inayofaa
5. **Tengeneza ripoti** au maonyesho ya kuona

### Muunganiko wa Kiolesura cha Mtumiaji/UI/UX
Ruhusu masasisho ya kiolesura yenye mabadiliko:
- **"Onyesha data za mauzo kwenye dashibodi"** → Uzalishaji na maonyesho ya chati
- **"Sasisha ramani na maeneo mapya"** → Muunganiko wa data ya kijiografia
- **"Sasisha onyesho la hesabu"** → Usawazishaji wa data kwa wakati halisi

### Utekelezaji wa Kazi Maalum

Pia unaweza kufafanua kazi maalum kwa Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Tengeneza simulizi ya simu ya API ya hali ya hewa
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Tumia chombo maalum
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

import openai

    api_key=manager.api_key

functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Fanya ombi la kuita kazi
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"

print(response.choices[0].message.content)

### Matatizo ya Kawaida na Suluhisho

#### Tatizo 1: Kazi Haipigwi Simu
**Dalili**: Mfano hutafakari majibu kwa maandishi badala ya kupiga simu ya kazi

**Suluhisho**:
1. **Angalia maelezo ya kazi**: Hakikisha inalingana wazi na nia ya mtumiaji
2. **Thibitisha ufafanuzi wa vigezo**: Hakikisha vigezo vyote vinavyohitajika vimefafanuliwa vizuri
3. **Kagua maelekezo ya mfumo**: Jumuisha maelekezo wazi kuhusu wakati wa kutumia kazi
4. **Jaribu kwa maombi ya wazi**: Jaribu "Tafadhali tumia kazi ya hali ya hewa kupata data za London"

#### Tatizo 2: Vigezo Visivyo Sahihi
**Dalili**: Kazi inaitwa na vigezo vibaya au vinavyokosekana

**Suluhisho**:
1. **Ongeza mifano ya vigezo**: Jumuisha thamani za mfano katika maelezo ya vigezo
2. **Tumia vikwazo vya enum**: Punguza thamani za vigezo kwa chaguzi maalum inapowezekana
3. **Tekeleza thamani mbadala**: Toa chaguo la msingi kwa vigezo hiari

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }
}
```

#### Tatizo 3: Kushindwa kwa Kupiga Simu za Kazi Sambamba
**Dalili**: Kazi moja tu inatekelezwa wakati zingine nyingi zinapaswa kuendeshwa

**Suluhisho**:
1. **Angalia msaada wa mfano**: Hakikisha mfano wako unaunga mkono kupiga simu za kazi sambamba
2. **Sasisha maelekezo ya mfumo**: Jumuisha "zana kadhaa" au "zana nyingi" katika ujumbe wa mfumo
3. **Tumia matoleo yanayofaa ya mfano**: Phi-4-mini:3.8b-fp16 inapendekezwa kwa Ollama

#### Tatizo 4: Matatizo ya Templeti na Ollama
**Dalili**: Kupiga simu ya kazi haifanyi kazi na mpangilio wa chaguo-msingi wa Ollama

            'rate_limit': rate_limit,
            'call_count': 0,

        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Thibitisha kazi ipo
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Angalia mipaka ya kiwango
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Thibitisha vigezo
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Tekeleza kazi
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Andika utekelezaji uliofanikiwa
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Andika utekelezaji uliofeli
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Weka upya kioni ikiwa dakika moja imethibitishwa
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Angalia kama uko chini ya kikomo
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Angalia vigezo vinavyohitajika
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Thibitisha aina za vigezo na vizingiti
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Uthibitisho wa aina
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # Uthibitisho wa orodha ya chaguo
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
        
        return FunctionResult(success=True)

### Muhimu wa Mafunzo

1. **Uelewa wa Msingi**: Kupiga simu za kazi huruhusu SLMs kupanua zaidi data zao za mafunzo kwa kuungana na zana na huduma za nje.

2. **Kubadilika kwa Utekelezaji**: Kuna njia nyingi, kutoka utekelezaji wa ngazi ya chini na templeti maalum hadi mifumo ya ngazi ya juu kama Qwen-Agent na Foundry Local.

3. **Mambo ya Kuzingatia kwa Uzalishaji**: Uanzishaji wa biashara unahitaji kuzingatia utatuzi wa makosa, udhibiti wa viwango, usalama, na ufuatiliaji wa rekodi.

4. **Uboreshaji wa Utendaji**: Ubunifu mzuri wa kazi, utekelezaji bora, na uhifadhi mahiri wa matokeo yanaweza kuboresha sana wakati wa majibu.

### Mwelekeo wa Baadaye

Kadiri teknolojia ya SLM inavyoendelea, tunaweza kutarajia:

- **Kuboresha Usahihi wa Kupiga Simu za Kazi**: Kugundua nia na kutoa vigezo vilivyo bora zaidi
- **Kuongeza Ufanisi wa Usindikaji Sambamba**: Muunganiko wa kazi nyingi kwa usahihi zaidi
- **Viwango Bora vya Muunganiko**: Itifaki za kawaida kwa muunganiko wa zana
- **Sifa Zaidi za Usalama**: Mbinu za kuimarisha uthibitishaji na idhini
- **Ukuaji wa Mfumo wa Zana**: Maktaba inayokua ya kazi zilizojengwa kabla na miguso

### Kuanzia

Kuanzisha utekelezaji wa kupiga simu za kazi katika miradi yako:

1. **Anza kwa urahisi**: Anza na matukio rahisi ya kazi moja moja
2. **Chagua Mfumo Wako**: Chagua kati ya utekelezaji wa moja kwa moja (Ollama/Phi-4) au kupitia mfumo (Qwen-Agent)
3. **Buni Kazi kwa Uangalifu**: Lenga kwa ufafanuzi mzuri, ulioandikwa vizuri wa kazi
4. **Tekeleza Utatuzi wa Makosa**: Jenga utatuzi wa makosa thabiti tangu mwanzo
5. **Panda Kiwango Polepole**: Hamia kutoka matukio rahisi hadi magumu kadri unavyozidi kupata uzoefu

Kupiga simu za kazi hubadilisha SLMs kutoka wazalishaji wa maandishi wakubwa kuwa mawakala wenye uwezo wa kutatua matatizo halisi ya dunia. Kwa kufuata mifumo na kanuni zilizowekwa katika mafunzo haya, unaweza kujenga mifumo ya AI yenye nguvu, ya kuaminika inayozidi zaidi kiolesura cha mazungumzo cha kawaida.
