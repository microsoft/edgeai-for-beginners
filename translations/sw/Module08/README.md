# Moduli 08: Kutumia Microsoft Foundry Local - Seti Kamili ya Zana za Mwana Developer

## Muhtasari

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) inawakilisha kizazi kijacho cha maendeleo ya AI ya edge, ikiwapatia waendelezaji zana zenye nguvu za kujenga, kupeleka, na kupanua programu za AI kwa njia ya mahali huku wakidumisha muunganisho mzuri na Azure AI Foundry. Moduli hii inatoa mafanikio kamili ya Foundry Local kutoka usakinishaji hadi maendeleo ya mawakala wa hali ya juu.

**Teknolojia Muhimu:**
- Microsoft Foundry Local CLI na SDK
- Muunganisho wa Azure AI Foundry
- Ufafanuzi wa mfano kwenye kifaa
- Kuhifadhi na kuboresha mfano kwa eneo
- Miundo inayozingatia mawakala

## Malengo ya Kujifunza

Kwa kukamilisha moduli hii, utaweza:

- **Tawala Foundry Local**: Sakinisha, sanidi, na boresha kwa maendeleo ya Windows 11
- **Weka Mifano Mbalimbali**: Endesha mifano ya phi, qwen, deepseek, na GPT kwa ndani kwa amri za CLI
- **Jenga Suluhisho za Uzalishaji**: Tengeneza programu za AI kwa uhandisi wa hali ya juu wa prompt na muunganisho wa data
- **Tumia Mfumo wa Chanzo Wazi**: Unganisha mifano ya Hugging Face na michango ya jamii
- **Tengeneza Mawakala wa AI**: Jenga mawakala wenye akili kwa uwezo wa msingi na uratibu
- **Tekeleza Mifumo ya Kampuni**: Tengeneza suluhisho za AI zinazoweza kupanuliwa kwa uzalishaji

## Mahitaji ya Awali

### Mahitaji ya Mfumo
- **Mfumo wa Uendeshaji**: Windows 11 (22H2 au zaidi)
- **Kumbukumbu**: 16GB RAM (32GB inapendekezwa kwa mifano mikubwa)
- **Hifadhi**: Nafasi ya bure ya 50GB kwa kuhifadhi mfano
- **Vifaa**: Kifaa chenye NPU kinaahidiwa (Copilot+ PC), GPU si lazima
- **Mtandao**: Intaneti ya kasi kwa upakuaji wa mfano wa awali

### Mazingira ya Maendeleo

- Visual Studio Code na kifurushi cha AI Toolkit
- Python 3.10+ na pip
- Git kwa udhibiti wa toleo
- PowerShell au Command Prompt
- Azure CLI (hiari kwa mchakato wa wingu)

### Maarifa Yanayohitajika
- Uelewa wa msingi wa dhana za AI/ML
- Uzoefu wa mstari wa amri
- Misingi ya programu ya Python
- Dhana za REST API
- Maarifa ya msingi ya kuamsha na kutumia modeli

## Mwongozo wa Kuanzia Haraka - Sampuli Zote 10

### Usanidi wa Mazingira (Inahitajika kwa Sampuli Zote)

```powershell
# 1. Nakili na uelekeze kwenda Module08
cd Module08

# 2. Unda mazingira ya virtual ya Python
py -m venv .venv
.\.venv\Scripts\activate

# 3. Sakinisha utegemezi wa msingi
pip install -r requirements.txt

# 4. Sakinisha Foundry Local (kama bado haijasakinishwa)
winget install Microsoft.FoundryLocal

# 5. Thibitisha usakinishaji wa Foundry Local
foundry --version
foundry model list
```

### Sampuli za Msingi wa Msingi (01-06)

**Sampuli 01: Mwanzilishi wa mazungumzo ya REST**
```powershell
# Anza huduma ya Foundry Local
foundry model run phi-4-mini

# Endesha maonyesho ya mazungumzo ya REST
python samples/01/chat_quickstart.py
```

**Sampuli 02: Muunganisho wa SDK ya OpenAI**
```powershell
# Hakikisha mfano unaendesha
foundry status

# Endesha onyesho la SDK
python samples/02/sdk_quickstart.py
```

**Sampuli 03: Ugunduzi wa Modeli & Kupima**
```powershell
# Endesha upimaji kamili wa mifano
samples/03/list_and_bench.cmd

# Au endesha vipengele binafsi
foundry model list --available
foundry model download qwen2.5-0.5b
foundry model benchmark phi-4-mini
```

**Sampuli 04: Programu ya Chainlit RAG**
```powershell
# Sakinisha utegemezi wa Chainlit
pip install chainlit langchain chromadb

# Anzisha programu ya mazungumzo ya RAG
chainlit run samples/04/app.py -w
# Fungua kivinjari kwenye http://localhost:8000
```

**Sampuli 05: Uendeshaji wa Mawakala Wengi**
```powershell
# Endesha onyesho la muongozaji wa wakala
python -m samples.05.agents.coordinator

# Endesha mifano maalum ya wakala
python samples/05/examples/specialists_demo.py
```

**Sampuli 06: Kichocheo cha Modeli kama Zana**
```powershell
# Sanidi mazingira
set BASE_URL=http://localhost:8000
set GENERAL_MODEL=phi-4-mini
set CODE_MODEL=qwen2.5-7b

# Endesha njia ya akili
python samples/06/router.py "Analyze this Python code for performance issues"
```

### Utatuzi wa Masuala ya Kawaida

**Makosa ya Muunganisho wa Foundry Local**
```powershell
# Kagua hali ya huduma
foundry status

# Anzisha upya ikiwa inahitajika
foundry restart

# Thibitisha upatikanaji wa mwisho wa huduma
curl http://localhost:5273/v1/models
```

**Masuala ya Kupakia Modeli**
```powershell
# Angalia mifano iliyopo
foundry model list --cached

# Pakua mifano iliyokosekana
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# Lazimisha upya upakiaji ikiwa inahitajika
foundry model unload --all
foundry model run phi-4-mini
```

**Masuala ya Mtegemezi**
```powershell
# Sasisha pip na usakinishe tena
python -m pip install --upgrade pip
pip install -r requirements.txt --force-reinstall

# Kwa sampuli za Node.js
npm cache clean --force
npm install
```
