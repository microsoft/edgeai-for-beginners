## Sehemu ya 1: Ugunduzi wa Mfano kwa Foundry CLI

### Amri za Msingi za Usimamizi wa Mfano

CLI ya foundry hutoa amri rahisi kwa ajili ya ugunduzi na usimamizi wa mifano:

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### Kuendesha Mifano Yako ya Kwanza

Anza na mifano maarufu na iliyojaribiwa vizuri kuelewa sifa za utendaji:

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**Kumbuka:** Bendera `--verbose` hutoa taarifa za kina za mwanzo, ikiwa ni pamoja na:
- Maendeleo ya kupakua mfano (kwa wakati wa kwanza kuendesha)
- Maelezo ya mgawanyo wa kumbukumbu
- Taarifa ya kufunga huduma
- Vipimo vya kuanzisha utendaji

### Kuuelewa Aina za Mifano

**Mifano Midogo ya Lugha (SLMs):**
- `phi-4-mini`: Haraka, yenye ufanisi, nzuri kwa mazungumzo ya jumla
- `phi-4`: Toleo lenye uwezo zaidi na mantiki bora

**Mifano ya Kati:**
- `qwen2.5-7b`: Mantiki bora na muktadha mrefu
- `deepseek-r1-7b`: Imepangwa kwa ajili ya uundaji wa msimbo

**Mifano Mikubwa:**
- `llama-3.2`: Mfano mpya wa chanzo huru wa Meta
- `qwen2.5-14b`: Mantiki ya kiwango cha biashara

## Sehemu ya 3: Usimamizi wa Cache na Uhifadhi wa Mfano

### Kuuelewa Cache ya Mfano

Foundry Local huendesha upakuaji wa mifano na uhifadhi wa cache kiotomatiki:

```cmd
REM Check cache directory and contents
foundry cache ls

REM View cache location
foundry cache cd

REM Clean up unused models (if needed)
foundry cache clean
```

### Mambo ya Kuzingatia Kuhifadhi Mfano

**Ukubwa wa Kawaida wa Mfano:**
- `phi-4-mini`: ~2.5 GB
- `qwen2.5-7b`: ~4.1 GB  
- `deepseek-r1-7b`: ~4.3 GB
- `llama-3.2`: ~4.9 GB
- `qwen2.5-14b`: ~8.2 GB

**Mbinu Bora za Uhifadhi:**
- Hifadhi mifano 2-3 kwa kubadili haraka
- Ondoa mifano isiyotumika ili kufungua nafasi: `foundry cache clean`
- Angalia matumizi ya diski, hasa katika SSD ndogo ndogo
- Fikiria ukubwa wa mfano dhidi ya sifa zake

### Ufuatiliaji wa Utendaji wa Mfano

Wakati mifano inaendeshwa, fuatilia rasilimali za mfumo:

**Msimamizi wa Kazi wa Windows:**
- Tazama matumizi ya kumbukumbu (mifano hubaki imechukuliwa ndani ya RAM)
- Angalia matumizi ya CPU wakati wa tahmini
- Kagua I/O ya diski wakati wa kuanza kwa mfano

**Ufuatiliaji wa Amri ya Mstari:**
```cmd
REM Check memory usage (PowerShell)
Get-Process | Where-Object {$_.ProcessName -like "*foundry*"} | Select-Object ProcessName, WorkingSet64

REM Monitor running models
foundry service ps
```

## Sehemu ya 5: Kupima Utendaji wa Mfano Rahisi

### Majaribio ya Utendaji wa Msingi

Hapa ni njia rahisi ya kulinganisha utendaji wa mfano:

```python
# simple_bench.py - Inategemea mifumo ya Mfano 03
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# Jaribu mfano unaoendesha sasa
if __name__ == "__main__":
    # Jaribu na mifano tofauti (anzisha kila mfano kwanza)
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```
