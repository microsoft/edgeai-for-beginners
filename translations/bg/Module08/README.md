# Модул 08: Работа с Microsoft Foundry Local - Пълен комплект инструменти за разработчици

## Общ преглед

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) представлява следващото поколение в разработката на edge AI, като предоставя на разработчиците мощни инструменти за създаване, внедряване и мащабиране на AI приложения локално, запазвайки безпроблемна интеграция с Azure AI Foundry. Този модул осигурява цялостно покритие на Foundry Local - от инсталацията до усъвършенствана разработка на агенти.

**Основни технологии:**
- Microsoft Foundry Local CLI и SDK
- Интеграция с Azure AI Foundry
- Извеждане на модели на устройството
- Локално кеширане и оптимизация на модели
- Архитектури, базирани на агенти

## Цели на обучението

Като завършите този модул, ще:

- **Овладеете Foundry Local**: Инсталиране, конфигуриране и оптимизация за разработка на Windows 11
- **Внедрите разнообразни модели**: Стартиране на phi, qwen, deepseek и GPT модели локално с CLI команди
- **Създадете производствени решения**: Създаване на AI приложения с усъвършенствано проектиране на подкани и интеграция на данни
- **Използвате екосистема с отворен код**: Интеграция на модели Hugging Face и общностни допринасяния
- **Развивате AI агенти**: Създаване на интелигентни агенти с възможности за заземяване и оркестриране
- **Прилагате корпоративни модели**: Създаване на модулни, мащабируеми AI решения за продукционно внедряване

## Предварителни изисквания

### Системни изисквания
- **Операционна система**: Windows 11 (22H2 или по-нова)
- **Памет**: 16GB RAM (32GB препоръчително за по-големи модели)
- **Съхранение**: 50GB свободно място за кеширане на модели
- **Хардуер**: Препоръчва се устройство с NPU (Copilot+ PC), GPU е по избор
- **Мрежа**: Високоскоростен интернет за първоначално изтегляне на модели

### Среда за разработка

- Visual Studio Code с разширението AI Toolkit
- Python 3.10+ и pip
- Git за контрол на версиите
- PowerShell или Command Prompt
- Azure CLI (по избор за интеграция с облак)

### Отстраняване на чести проблеми

**Грешки при свързване с Foundry Local**
```powershell
# Проверете статуса на услугата
foundry status

# Рестартирайте при необходимост
foundry restart

# Проверете достъпността на крайния пункт
curl http://localhost:5273/v1/models
```

**Проблеми с зареждане на модели**
```powershell
# Провери наличните модели
foundry model list --cached

# Изтегли липсващите модели
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# Задължително презареждане при необходимост
foundry model unload --all
foundry model run phi-4-mini
```

**Проблеми със зависимости**
```powershell
# Актуализирайте pip и преинсталирайте
python -m pip install --upgrade pip
pip install -r requirements.txt --force-reinstall

# За примери с Node.js
npm cache clean --force
npm install
```
