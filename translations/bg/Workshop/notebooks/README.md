## 📖 Въведение

Добре дошли в колекцията **Работилнични бележници EdgeAI за начинаещи**. Тези интерактивни Jupyter бележници предоставят практически опит, където ще пишете, изпълнявате и експериментирате с код за Edge AI в реално време.

### Защо Jupyter бележници?

За разлика от традиционните уроци, тези бележници предлагат:

- **Интерактивно учене**: Изпълнявайте клетките с код и виждайте незабавни резултати
- **Експериментиране**: Променяйте параметри и наблюдавайте промените в реално време
- **Документация**: Обяснения на място и markdown клетки ви водят през концепциите
- **Възпроизводимост**: Пълни работещи примери, които можете да използвате и реферирате
- **Визуализация**: Преглед на метрики за производителност, embeddings и резултати в самия бележник

### Какво прави тези бележници специални?

Всеки бележник е проектиран според **най-добрите практики за продуктивна готовност**:

✅ **Изчерпателно обработване на грешки** - Мек спад и информативни съобщения за грешки  
✅ **Подсказки за типове и документация** - Ясни подписи на функции и docstrings  
✅ **Мониторинг на производителността** - Следене на използването на токени и измерване на забавяне  
✅ **Модулен дизайн** - Преправяеми шаблони, които можете да адаптирате за вашите проекти  
✅ **Прогресивна сложност** - Систематично надграждане върху предишните сесии

## 🚀 Започване

### Изисквания

**Системни изисквания**:
- **ОС**: Windows 10/11, macOS 11+ или Linux (Ubuntu 20.04+)
- **RAM**: минимум 8GB, препоръчва се 16GB+
- **Дисково пространство**: 10GB+ свободно място за модели
- **Хардуер**: CPU с AVX2; GPU (CUDA, Qualcomm NPU) по избор

**Софтуерни изисквания**:
- **Python 3.8+** с pip
- **Jupyter Notebook** или **VS Code** с разширение Jupyter
- **Microsoft Foundry Local** инсталиран и конфигуриран
- **Git** (за клониране на хранилището)

### Стъпки за инсталация

#### 1. Инсталиране на Foundry Local

**Windows**:
```cmd
winget install Microsoft.FoundryLocal
```

**macOS**:
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

**Проверка на инсталацията**:
```bash
foundry --version
```

#### 2. Настройка на Python среда

```bash
# Навигирайте до директория Workshop
cd Workshop

# Създайте виртуална среда
python -m venv .venv

# Активирайте виртуалната среда
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

# Инсталирайте зависимости
pip install -r requirements.txt
```

#### 3. Стартиране на Foundry Local

```bash
# Зареждане на модел (автоматично изтегляне при необходимост)
foundry model run phi-4-mini

# Проверете дали услугата работи
foundry service status
```

#### 4. Стартиране на Jupyter

```bash
# Стартиране на Jupyter Notebook
jupyter notebook notebooks/

# Или използвайте VS Code с разширението Jupyter
code notebooks/
```

```python
from foundry_local import FoundryLocalManager
import openai

# Инициализиране на мениджър (автоматично открива услугата)
manager = FoundryLocalManager("phi-4-mini")

# Конфигуриране на OpenAI клиент
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Тест на завършване на чат
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**Очакван резултат**: Отговор за поздрав от локалния модел.
