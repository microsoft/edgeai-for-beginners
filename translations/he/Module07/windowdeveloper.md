# מדריך פיתוח AI ב-Windows Edge

## הקדמה

ברוכים הבאים לפיתוח AI ב-Windows Edge – המדריך המקיף שלכם לבניית יישומים חכמים המנצלים את כוח ה-AI במכשיר באמצעות פלטפורמת Windows AI Foundry של מיקרוסופט. מדריך זה תוכנן במיוחד למפתחים של Windows הרוצים לשלב יכולות Edge AI חדשניות ביישומים שלהם תוך ניצול ספקטרום המלא של האצת חומרה ב-Windows.

### היתרון של Windows AI

Windows AI Foundry מייצגת פלטפורמה מאוחדת, אמינה ובטוחה התומכת במחזור החיים המלא של פיתוח AI – מבחירת מודל וכיוונון ועד לאופטימיזציה והטמעה על פני ארכיטקטורות CPU, GPU, NPU וענן היברידי. פלטפורמה זו דמוקרטית את פיתוח ה-AI על ידי מתן:

- **הפשטת חומרה**: הטמעה חלקה על גבי סיליקון של AMD, אינטל, NVIDIA ו-Qualcomm
- **אינטליגנציה במכשיר**: AI המגן על הפרטיות ורץ במלואו על החומרה המקומית
- **ביצועים מותאמים**: מודלים מותאמים מראש לתצורות חומרה של Windows
- **מוכנות ארגונית**: מאפייני אבטחה ועמידה בדרישות ברמת הייצור

### Windows ML 
Windows Machine Learning (ML) מאפשר למפתחים ב-C#, C++ ו-Python להפעיל מודלי AI של ONNX מקומית במחשבי Windows דרך ONNX Runtime, עם ניהול ספקי ביצוע אוטומטי עבור חומרה שונה (CPU, GPU, NPU). ניתן להשתמש ב-[ONNX Runtime](https://onnxruntime.ai/docs/) עם מודלים מ-PyTorch, Tensorflow/Keras, TFLite, scikit-learn ועוד.


![WindowsML A diagram illustrating an ONNX model going through Windows ML to then reach NPUs, GPUs, and CPUs.l](https://learn.microsoft.com/en-us/windows/ai/images/winml-diagram.png)

Windows ML מספק העתק משותף ברחבי Windows של ONNX Runtime, בנוסף ליכולת להורדת ספקי ביצוע (EPs) דינמית.

### מדוע Windows עבור Edge AI?

**תמיכה אוניברסלית בחומרה**
Windows ML מספק אופטימיזציה אוטומטית לחומרה בכל אקוסיסטם Windows, ומבטיח שהיישומים שלכם AI יפעלו בצורה מיטבית ללא תלות בארכיטקטורת הסיליקון התחתונה.

**סביבת הריצה AI משולבת**
מנוע החיזוי של Windows ML המובנה מבטל את הצורך בתצורות מורכבות, מה שנותן למפתחים להתמקד בלוגיקת היישום במקום בתשתיות.

**אופטימיזציית Copilot+ למחשב**
APIs ייעודיים שנוצרו במיוחד למכשירי Windows מהדור הבא עם יחידות עיבוד עצביות (NPUs) שמספקות ביצועים יוצאי דופן לאנרגיה.

**אקוסיסטם מפתחים**
כלים עשירים הכוללים אינטגרציה עם Visual Studio, תיעוד מקיף ודוגמאות יישומים שמאיצים את מחזורי הפיתוח.

## מטרות הלמידה

בסיום מדריך הפיתוח ל-Windows Edge AI הזה, תשלוט במיומנויות החיוניות לבניית יישומי AI מוכנים לייצור בפלטפורמת Windows.

### מיומנויות טכניות מרכזיות

- הבן את הארכיטקטורה והרכיבים של פלטפורמת Windows AI Foundry

- ליישם שיטות עבודה מומלצות לאבטחה ביישומי AI במכשיר
- לאפשר אופטימיזציה של יישומים לתצורות חומרה שונות של Windows

**מומחיות באינטגרציית API**
- לשלוט ב-APIs של Windows AI עבור טקסט, ראייה ויישומים מולטימודאליים
- לממש אינטגרציה של מודל השפה Phi Silica ליצירת טקסט והיגיון
- להפעיל יכולות ראיית מחשב באמצעות APIs מובנים לעיבוד תמונה
- להתאים מודלים מאומנים מראש באמצעות טכניקות LoRA (Low-Rank Adaptation)

**יישום Foundry Local**
- לגלוש, להעריך ולהטמיע מודלי שפה בקוד פתוח באמצעות Foundry Local CLI
- להבין אופטימיזציה וכימות של מודלים לפריסה מקומית
- לממש יכולות AI אופליין הפועלות ללא חיבור לאינטרנט
- לנהל מחזורי חיים ועדכונים של מודלים בסביבות ייצור

**פריסת Windows ML**
- להביא מודלים מותאמים אישית של ONNX ליישומי Windows באמצעות Windows ML
- לנצל האצת חומרה אוטומטית על פני ארכיטקטורות CPU, GPU ו-NPU
- לממש חיזוי בזמן אמת עם ניצול אופטימלי של משאבים
- לתכנן יישומי AI סקלביליים למגוון קטגוריות מכשירי Windows

- לנהל פעולות AI אסינכרוניות עם תבניות חווית משתמש מתאימות

**אופטימיזציית ביצועים**
- לבצע פרופיל ואופטימיזציה של ביצועי חיזוי AI בתצורות חומרה שונות

- לעצב יישומים המתדרדרים בצורה מחושבת בהתבסס על יכולות חומרה זמינות
- להחיל אסטרטגיות קאשינג לפעולות AI הנפוצות

**מוכנות לייצור**
- לממש טיפול שגיאות נרחב ומנגנוני גיבוי
- לעצב טלמטריה ומעקב אחרי ביצועי היישום AI
- להחיל שיטות עבודה מומלצות לאבטחת אחסון והרצת מודלים מקומיים

**ארכיטקטורת יישומי AI**

- להעריך פשרות בין גודל, דיוק ומהירות החיזוי של המודל
- לתכנן ארכיטקטורות זרימת נתונים השומרות על פרטיות תוך היכולת לאפשר אינטיליגנציה
- לממש פתרונות AI חסכוניים בסקלאביליות בהתאם לביקושים המשתנים

**מיקום בשוק**
- להבין יתרונות תחרותיים של יישומי AI טבעיים ל-Windows
- לזהות תרחישים שבהם AI במכשיר מספק חווית משתמש עליונה
- לפתח אסטרטגיות Go-to-market ליישומי Windows משופרי AI

### תהליך עבודה נפוץ בדוגמאות

רוב הדוגמאות של Windows ML עוקבות אחרי התבנית הסטנדרטית הבאה:

1. **אתחול סביבה** - יצירת סביבה ל-ONNX Runtime
2. **רישום ספקי ביצוע** - גילוי ורישום מאיצי חומרה זמינים (CPU, GPU, NPU)
3. **טעינת מודל** - טעינת מודל ONNX, אפשרות הידור לחומרת יעד
4. **קדם עיבוד קלט** - המרת תמונות/נתונים לפורמט קלט של המודל
5. **הרצת חיזוי** - הפעלת המודל וקבלת תחזיות
6. **עיבוד תוצאות** - הפעלת softmax והצגת התחזיות המובילות

## רכיבי פלטפורמת Windows AI Foundry

### 1. APIs של Windows AI

APIs של Windows AI מספקים יכולות AI מוכנות לשימוש, המופעלות על ידי מודלים במכשיר, מותאמים ליעילות וביצועים במכשירי Copilot+ PC עם דרישות התקנה מינימליות.

#### קטגוריות API מרכזיות

**מודל שפה Phi Silica**
- מודל שפה קטן אך עוצמתי ליצירת טקסט והיגיון
- מותאם לחיזוי בזמן אמת עם צריכת חשמל מינימלית
- תמיכה בכיוונון מותאם אישית באמצעות טכניקות LoRA
- אינטגרציה עם חיפוש סמנטי ושליפת ידע של Windows

**APIs לראיית מחשב**
- **זיהוי טקסט (OCR)**: חילוץ טקסט מתמונות בדייקנות גבוהה
- **שיפור רזולוציה של תמונות**: הגדלת תמונות באמצעות מודלי AI מקומיים
- **סגמנטציה של תמונות**: זיהוי ובידוד אובייקטים ספציפיים בתמונות
- **תיאור תמונה**: יצירת תיאורים טקסטואליים מפורטים לתוכן חזותי
- **מחיקת אובייקט**: הסרת אובייקטים לא רצויים מתמונות באמצעות צביעה עם AI

**יכולות מולטימודאליות**
- **אינטגרציית ראיה-שפה**: שילוב הבנת טקסט ותמונה
- **חיפוש סמנטי**: הפעלת שאילתות בשפה טבעית על תוכן מולטימדיה
- **שליפת ידע**: בניית חוויות חיפוש חכמות עם נתונים מקומיים

### 2. Foundry Local

Foundry Local מספק למפתחים גישה מהירה למודלי שפה בקוד פתוח מוכנים לשימוש על סיליקון Windows, עם היכולת לגלוש, לבדוק, לאינטראקציה ולפרוס מודלים ביישומים מקומיים.

#### קטגוריות דוגמאות לפי מקרה שימוש

**RAG (Generation משופר על ידי אחזור)**
- **dotNET/rag**: מימוש מלא של RAG באמצעות Semantic Kernel, בסיס נתונים וקטורין Qdrant, ואימבדינגס של JINA
- **ארכיטקטורה**: הכנסת מסמכים → חלוקת טקסט לחלקים → אימבדינגס וקטוריים → חיפוש דמיון → תגובות מותאמות להקשר
- **טכנולוגיות**: Microsoft.SemanticKernel, Qdrant.Client, BERT ONNX אימבדינגס, השלמת שיחה בזרם

**יישומי שולחן עבודה**
- **electron/foundry-chat**: אפליקציית צ'אט מוכנה לייצור עם החלפה בין מודל מקומי/ענן
- **תכונות**: בורר מודלים, תגובות בזרם, טיפול בשגיאות, פריסה חוצת פלטפורמות
- **ארכיטקטורה**: תהליך ראשי של Electron, תקשורת IPC, סקריפטי preload מאובטחים

**דוגמאות אינטגרציה עם SDK**
- **JavaScript (Node.js)**: אינטראקציה בסיסית עם מודל ותגובות בזרם
- **Python**: שימוש ב-API תואם OpenAI עם סטרימינג אסינכרוני
- **Rust**: אינטגרציה ברמה נמוכה עם reqwest ו-tokio לפעולות אסינכרוניות

#### דרישות מוקדמות לדוגמאות של Foundry Local

**דרישות מערכת:**
- Windows 11 עם Foundry Local מותקן
- Node.js v16+ לדוגמאות JavaScript/Electron
- .NET 8.0+ לדוגמאות C#
- Python 3.10+ לדוגמאות פייתון
- Rust 1.70+ לדוגמאות רסט

**התקנה:**
```powershell
# התקן את Foundry במחשב המקומי
winget install Microsoft.FoundryLocal

# אמת את ההתקנה
foundry --version
foundry model list
```

#### הגדרות ספציפיות לדוגמאות

**דוגמת dotNET RAG:**
```powershell
# התקן חבילות דרושות דרך NuGet
# Microsoft.SemanticKernel.Connectors.Onnx
# Microsoft.SemanticKernel.Connectors.Qdrant
# Qdrant.Client

# הפעל מסד נתוני וקטורים של Qdrant
docker run -p 6333:6333 qdrant/qdrant

# הפעל פנקס Jupyter
jupyter notebook rag_foundrylocal_demo.ipynb
```

**דוגמת צ'אט Electron:**
```powershell
# הגדר משתני סביבה לגיבוי בענן
$env:YOUR_API_KEY="your-cloud-api-key"
$env:YOUR_ENDPOINT="your-cloud-endpoint"
$env:YOUR_MODEL_NAME="your-cloud-model"

# התקן תלותיות והרץ
npm install
npm start
```

**דוגמאות JavaScript/Python/Rust:**
```powershell
# הורד דגם (דוגמה עם phi-3.5-mini)
foundry model run phi-3.5-mini

# הפעל דוגמה מתאימה
node src/app.js          # JavaScript
python src/app.py        # Python
cargo run               # Rust
```

### 3. Windows ML

Windows ML משמש כפלטפורמת בינה מלאכותית מרכזית ורuntime אינפרנס משולב ב-Windows, ומאפשר למפתחים לפרוס מודלים מותאמים ביעילות ברחבי אקוסיסטם החומרה הרחב של Windows.

#### יתרונות ארכיטקטורה

**תמיכה אוניברסלית בחומרה**
- אופטימיזציה אוטומטית לסיליקון של AMD, Intel, NVIDIA ו-Qualcomm
- תמיכה בהרצת CPU, GPU ו-NPU עם החלפה שקופה
- אבסטרקציה של חומרה שמבטלת את הצורך בעבודת אופטימיזציה לפי פלטפורמה

**גמישות מודל**
- תמיכה בפורמט מודל ONNX עם המרה אוטומטית ממסגרות פופולריות
- פריסת מודלים מותאמים עם ביצועים ברמת ייצור
- אינטגרציה עם ארכיטקטורות אפליקציות קיימות ב-Windows

**אינטגרציה ארגונית**
- תאימות למסגרות אבטחה ותקינה של Windows
- תמיכה בכלי ניהול ופריסה ארגוניים
- אינטגרציה עם מערכות ניהול ומעקב של מכשירי Windows

- השתמש בדיבאגר AI Toolkit לניתוח הרצת מודל
- יישם פרופילינג ביצועים לפעולות AI
- מצא באגים בפעולות AI אסינכרוניות עם טיפול תקין בחריגות
- השתמש בכלי פרופילינג זיכרון לאופטימיזציה

**כלי Windows AI Foundry**
- נצל את Foundry Local CLI לבדיקת מודלים ואימות
- השתמש בכלי בדיקת APIs של Windows AI לאימות אינטגרציה
- יישם רישום מותאם למעקב על פעולות AI
- צור בדיקות אוטומטיות לאמינות פונקציונליות AI

- עצב ממשקי משתמש שמתאימים לתכונות AI משופרות

## סיכום

הפיתוח של Windows Edge AI מייצג את המפגש בין יכולות AI עוצמתיות עם פלטפורמת Windows יציבה, מאובטחת וסקיילבילית. באמצעות שליטה באקוסיסטם Windows AI Foundry, מפתחים יכולים ליצור אפליקציות חכמות שמציעות חוויות משתמש יוצאות דופן תוך שמירה על הסטנדרטים הגבוהים ביותר של פרטיות, אבטחה וביצועים.

השילוב בין Windows AI APIs, Foundry Local ו-Windows ML מספק בסיס שאין שני לו לבניית הדור הבא של אפליקציות Windows חכמות. ככל ש-AI ממשיך להתפתח, הפלטפורמה של Windows מוודאת שהאפליקציות שלך יתרחבו עם הטכנולוגיות המתפתחות תוך שמירה על תאימות וביצועים לאורך האקוסיסטם המגוון של חומרת Windows.

בין אם אתה בונה אפליקציות לצרכן, פתרונות ארגוניים, או כלים תעשייתיים מומחים, פיתוח Windows Edge AI מאפשר לך ליצור חוויות חכמות, תגובתיות ומשולבות לעומק הניצלות את מלוא הפוטנציאל של מכשירי Windows מודרניים.
