
- 如果经常达到限制，升级内存

**性能缓慢：**
- 确保模型已完全加载（检查详细输出）
- 关闭不必要的后台程序
- 考虑使用更快的存储（SSD）

## 第1部分：使用 Foundry CLI 进行模型发现

### 基本模型管理命令

foundry CLI 提供了简单明了的模型发现和管理命令：

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### 运行您的第一个模型

从流行且经过充分测试的模型开始，了解性能特性：

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**注意：** `--verbose` 标志可查看详细的启动信息，包括：
- 模型下载进度（首次运行时）
- 内存分配详情
- 服务绑定信息
- 性能初始化指标

### 理解模型分类

**小型语言模型（SLMs）：**
- `phi-4-mini`：快速高效，适合普通聊天
- `phi-4`：能力更强，推理更佳

**中型模型：**
- `qwen2.5-7b`：推理出色，支持更长上下文
- `deepseek-r1-7b`：针对代码生成优化

**大型模型：**
- `llama-3.2`：Meta 最新开源模型

**最低系统需求：**
```
phi-4-mini:     8GB RAM,  entry-level CPU
phi-4:         12GB RAM,  mid-range CPU
qwen2.5-7b:    16GB RAM,  mid-range CPU
deepseek-r1:   16GB RAM,  mid-range CPU
```

- 32GB以上内存，方便多模型切换

## 第5部分：简单模型基准测试

### 基础性能测试

这是比较模型性能的简单方法：

```python
# simple_bench.py - 基于样例03模式
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# 测试当前运行的模型
if __name__ == "__main__":
    # 使用不同的模型进行测试（先启动每个模型）
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```

### 手动质量评估

对每个模型使用一致的提示进行测试并手动评估：

**测试提示：**
1. “用简单术语解释量子计算。”
2. “写一个Python函数对列表进行排序。”
3. “远程工作的优缺点有哪些？”
4. “总结边缘AI的优势。”

**评估标准：**
- <strong>准确性</strong>：信息是否正确？
- <strong>清晰度</strong>：解释是否易于理解？
- <strong>完整性</strong>：是否涵盖了完整问题？
- <strong>速度</strong>：响应速度如何？
