# ಅಧಿವೇಶನ 3: ಓಪನ್-ಸೋರ್ಸ್ ಮಾದರಿ ಪತ್ತೆಮಾಡಿಕೆ ಮತ್ತು ನಿರ್ವಹಣೆ

## ಅವಲೋಕನ

ಈ ಅಧಿವೇಶನವು Foundry Local ನೊಂದಿಗೆ ಪ್ರಾಯೋಗಿಕ ಮಾದರಿ ಪತ್ತೆಮಾಡಿಕೆ ಮತ್ತು ನಿರ್ವಹಣೆಯಲ್ಲಿ ಗಮನ ಕೇಂದ್ರಿತ ಮಾಡುತ್ತದೆ. ನೀವು ಲಭ್ಯವಿರುವ ಮಾದರಿಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುವುದನ್ನು, ವಿವಿಧ ಆಯ್ಕೆಗಳು ಪರೀಕ್ಷಿಸುವುದನ್ನು, ಮತ್ತು ಮೂಲ ಕಾರ್ಯಕ್ಷಮತಾ ಲಕ್ಷಣಗಳ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದನ್ನು ಕಲಿಯುತ್ತೀರಿ. ಈ ವಿಧಾನವು Foundry CLI ನೊಂದಿಗೆ ಕೈಗೊಳ್ಳುವ ಅನ್ವೇಷಣೆ ಮೇಲೆ ಒತ್ತು ನೀಡುತ್ತದೆ, ಇದು ನಿಮ್ಮ ಬಳಕೆ ಪ್ರಕರಣಗಳಿಗೆ ಸೂಕ್ತ ಮಾದರಿಗಳನ್ನು ಆಯ್ಕೆಮಾಡಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

## ಕಲಿಕೆ ಉದ್ದೇಶಗಳು

- ಮಾದರಿ ಪತ್ತೆಮಾಡಿಕೆ ಮತ್ತು ನಿರ್ವಹಣೆಗೆ Foundry CLI ಆಜ್ಞೆಗಳನ್ನು ನಿಪುಣತೆ ಹೊಂದುವುದು
- ಮಾದರಿ ಕ್ಯಾಶ್ ಮತ್ತು ಸ್ಥಳೀಯ ಸಂಗ್ರಹಣಾ ಮಾದರಿಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದು
- ಬೇಗನೆ ವಿವಿಧ ಮಾದರಿಗಳನ್ನು ಪರೀಕ್ಷಿಸಿ ಹೋಲಿಸಲು ಕಲಿಯುವುದು
- ಮಾದರಿ ಆಯ್ಕೆ ಮತ್ತು ಬೆಂಚ್ ಮಾರ್ಕಿಂಗ್ ಗೆ ಪ್ರಾಯೋಗಿಕ ಕಾರ್ಯಪ್ರವಾಹಗಳನ್ನು ಸ್ಥಾಪಿಸುವುದು
- Foundry Local ಮೂಲಕ ಲಭ್ಯವಿರುವ ಮಾದರಿಗಳ ಬೆಳೆಯುತ್ತಿರುವ ಪರಿಸರವನ್ನು ಅನ್ವೇಷಿಸುವುದು

## ಪೂರ್ವಶರತ್ತುಗಳು

- ಅಧಿವೇಶನ 1: Foundry Local ನೊಂದಿಗೆ ಆರಂಭಿಸಲಾಗಿದೆ ಸಂಪೂರ್ಣಗೊಳಿಸಲಾಗಿದೆ
- Foundry Local CLI ಸ್ಥಾಪಿತ ಮತ್ತು ಲಭ್ಯವಿದೆ
- ಮಾದರಿ ಡೌನ್ಲೋಡ್ ಗಾಗಿ ಸಾಕ್ಷಮ ಸಂಗ್ರಹಣಾ ಸ್ಥಳ (ಮಾದರಿಗಳು 1GB ರಿಂದ 20GB+ ವರೆಗಿನ ಗಾತ್ರವಿರಬಹುದು)
- ಮಾದರಿ ಪ್ರಕಾರಗಳು ಮತ್ತು ಬಳಕೆ ಪ್ರಕರಣಗಳ ಮೂಲ ತಿಳಿವು-Foundry Local ಜೊತೆ ಸೋರ್ಸ್ ಮಾದರಿಗಳು

## ಅವಲೋಕನ

ಈ ಅಧಿವೇಶನವು ಓಪನ್ ಸೋರ್ಸ್ ಮಾದರಿಗಳನ್ನು Foundry L ಗೆ ತರುವ ವಿಧಾನವನ್ನು ಅನ್ವೇಷಿಸುತ್ತದೆ## ಭಾಗ 6: ಕೈಗೊಳ್ಳುವ ಅಭ್ಯಾಸ

### ಅಭ್ಯಾಸ: ಮಾದರಿ ಪತ್ತೆಮಾಡಿಕೆ ಮತ್ತು ಹೋಲಿಕೆ

ಮಾದರಿ ಮೌಲ್ಯಮಾಪನ ಸ್ಕ್ರಿಪ್ಟ್ ಅನ್ನು ನಿಮ್ಮದೆ ಮಾಡಲು ಮಾದರಿ 03 ಆಧರಿಸಿ:

```cmd
REM create_model_test.cmd
@echo off
echo Model Discovery and Testing Script
echo =====================================

echo.
echo Step 1: List available models
foundry model list

echo.
echo Step 2: Check what's cached
foundry cache list

echo.
echo Step 3: Start phi-4-mini for testing
foundry model run phi-4-mini --verbose

echo.
echo Step 4: Test with a simple prompt
curl -X POST http://localhost:8000/v1/chat/completions ^
  -H "Content-Type: application/json" ^
  -d "{\"model\":\"phi-4-mini\",\"messages\":[{\"role\":\"user\",\"content\":\"Hello, please introduce yourself.\"}],\"max_tokens\":100}"

echo.
echo Model test complete!
```

### ನಿಮ್ಮ ಕಾರ್ಯ

1. **ಮಾದರಿ 03 ಸ್ಕ್ರಿಪ್ಟ್ ಚಾಲನೆ ಮಾಡಿ**: `samples\03\list_and_bench.cmd`
2. **ವಿವಿಧ ಮಾದರಿಗಳನ್ನು ಪ್ರಯತ್ನಿಸಿ**: ಕನಿಷ್ಠ 3 ವಿಭಿನ್ನ ಮಾದರಿಗಳನ್ನು ಪರೀಕ್ಷಿಸಿ
3. **ಕಾರ್ಯಕ್ಷಮತೆಯನ್ನು ಹೋಲಿಸಿ**: ವೇಗ ಮತ್ತು ಪ್ರತಿಕ್ರಿಯೆ ಗುಣಮಟ್ಟದ ವ್ಯತ್ಯಾಸಗಳನ್ನು ನೋಟ್ ಮಾಡಿ
4. **ಹುಡುಕಾಟ ಪ್ರമാണೀಕರಿಸಿ**: ಸರಳ ಹೋಲಿಕೆ ಚಾರ್ಟ್ ರಚಿಸಿ

## ಭಾಗ 7: ಸಮಸ್ಯೆ ಪರಿಹಾರ ಮತ್ತು ಉತ್ತಮ ಅಭ್ಯಾಸಗಳು

### ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಪರಿಹಾರಗಳು

**ಮಾದರಿ ಪ್ರಾರಂಭವಾಗುತ್ತಿಲ್ಲ:**
```cmd
REM Check service status
foundry service status

REM Restart service if needed
foundry service stop
foundry service start

REM Try with verbose output
foundry model run phi-4-mini --verbose
```

**ಮೆಮೊರಿ ನೀಡಿಕೆಯಲ್ಲಿ ಕೊರತೆ:**
- ಸಣ್ಣ ಮಾದರಿಗಳಿಂದ ಪ್ರಾರಂಭಿಸಿ (`phi-4-mini`)
- ಇತರ ಅಪ್ಲಿಕೇಶನ್ಗಳನ್ನು ಮುಚ್ಚಿರಿ
- ನಿಯಮಿತವಾಗಿ ಸೀಮೆಯನ್ನು ತಲುಪಿದರೆ RAM ಅನ್ನು ಅಪ್ಗ್ರೇಡ್ ಮಾಡಿ

**ಮಂದವಿರುವ ಕಾರ್ಯಕ್ಷಮತೆ:**
- ಮಾದರಿ ಸಂಪೂರ್ಣವಾಗಿ ಲೋಡ್ ಆಗಿದೆಯೆಂದು ಖಚಿತಪಡಳಿ (ವಿವರಿತ ಔಟ್ಪುಟ್ ಪರಿಶೀಲಿಸಿ)
- ಅನಗತ್ಯ ಬ್ಯಾಕ್ಗ್ರೌಂಡ್ ಅಪ್ಲಿಕೇಶನ್ಗಳನ್ನು ಮುಚ್ಚಿರಿ
- ವೇಗವಾದ ಸಂಗ್ರಹಣೆ (SSD) ಪರಿಗಣಿಸಿ

### ಉತ್ತಮ ಅಭ್ಯಾಸಗಳು

1. **ಸಣ್ಣದರಿಂದ ಪ್ರಾರಂಭಿಸಿ**: ಸ್ಥಾಪನೆ ಪರಿಶೀಲಿಸಲು `phi-4-mini` ಬಳಸಿ
2. **ಒಂದು ಮಾದರಿಯನ್ನು ಒಂದೇ ಸಮಯದಲ್ಲಿ**: ಹೊಸದೊಂದು ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು ಹಳೆಯ ಮಾದರಿಗಳನ್ನು ನಿಲ್ಲಿಸಿ
3. **ಸಂಪನ್ಮೂಲಗಳನ್ನು ಆಲೋಚಿಸಿ**: ಮೆಮೊರಿ ಬಳಕೆಯನ್ನು ಗಮನಿಸಿ
4. **ನಿರಂತರವಾಗಿ ಪರೀಕ್ಷಿಸು**: ನ್ಯಾಯಾಲು ಪ್ರಾಂಪ್ಟ್ಗಳನ್ನು ಉಪಯೋಗಿಸಿ ಸಮನ್ವಯ ಹೋಲಿಕೆಗಾಗಿ
5. **ಫಲಿತಾಂಶ ಕಾಗದ ಲಕ್ಷ್ಯ ಮಾಡಿ**: ನಿಮ್ಮ ಬಳಕೆ ಪ್ರಕರಣಗಳಿಗಾಗಿ ಮಾದರಿ ಕಾರ್ಯಕ್ಷಮತೆಯ ಟಿಪ್ಪಣಿಗಳನ್ನು ಇಟ್ಟುಕೊಳ್ಳಿ

## ಭಾಗ 1: Foundry CLI ಮೂಲಕ ಮಾದರಿ ಪತ್ತೆಮಾಡಿಕೆ

### ಮೂಲ ಮಾದರಿ ನಿರ್ವಹಣಾ ಆಜ್ಞೆಗಳು

Foundry CLI ಮಾದರಿ ಪತ್ತೆಮಾಡಿಕೆ ಮತ್ತು ನಿರ್ವಹಣೆಗಾಗಿ ಸರಳ ಆಜ್ಞೆಗಳನ್ನೂ ಒದಗಿಸುತ್ತದೆ:

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### ನಿಮ್ಮ ಪ್ರಥಮ ಮಾದರಿಗಳನ್ನು ಚಾಲನೆಯಲ್ಲಿಡುವುದು

ಕಾರ್ಯಕ್ಷಮತಾ ಲಕ್ಷಣಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಜನಪ್ರಿಯ, ಚೆನ್ನಾಗಿ ಪರೀಕ್ಷಿಸಲ್ಪಟ್ಟ ಮಾದರಿಗಳಿಂದ ಪ್ರಾರಂಭಿಸಿ:

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**ಗಮನಿಸಿ:** `--verbose` ಧ್ವಜವು ವಿವರವಾದ ಆರಂಭಿಕ ಮಾಹಿತಿಯನ್ನು ನೀಡುತ್ತದೆ, ಇದರಲ್ಲಿ:
- ಮಾದರಿ ಡೌನ್ಲೋಡ್ ಪ್ರಗತಿ (ಮೊದಲ ಚಾಲನೆಯಾಗುವಾಗ)
- ಮೆಮೊರಿ ಅನ್ವಯಿಕೆ ವಿವರಗಳು
- ಸೇವಾ ಬಂಧನ ಮಾಹಿತಿ
- ಕಾರ್ಯಕ್ಷಮತಾ ಪ್ರಾರಂಭಿಕ ಮಾನದಂಡಗಳು

### ಮಾದರಿ ವರ್ಗಗಳ ಅರ್ಥ

**ಸಣ್ಣ ಭಾಷಾ ಮಾದರಿಗಳು (SLMs):**

- `phi-4`: ಉತ್ತಮ ತರ್ಕಬದ್ಧತೆ ಹೊಂದಿದ ಹೆಚ್ಚು ಸಾಮರ್ಥ್ಯ ಇರುವ ಆವೃತ್ತಿ

## ಭಾಗ 5: ಸರಳ ಮಾದರಿ ಬೆಂಚ್ ಮಾರ್ಕಿಂಗ್

### ಮೂಲ ಕಾರ್ಯಕ್ಷಮತೆ ಪರೀಕ್ಷೆ

ಇಲ್ಲಿದೆ ಮಾದರಿ ಕಾರ್ಯಕ್ಷಮತೆಯನ್ನು ಹೋಲಿಕೆ ಮಾಡಲು ಸರಳ ವಿಧಾನ:

```python
# simple_bench.py - ಮಾದರಿ 03 ಮಾದರಿಗಳ ಆಧಾರದ ಮೇಲೆ
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# ಪ್ರಸ್ತುತ ನಡೆಯುತ್ತಿರುವ ಮಾದರಿಯನ್ನು ಪರೀಕ್ಷಿಸಿ
if __name__ == "__main__":
    # ವಿಭಿನ್ನ ಮಾದರಿಗಳೊಂದಿಗೆ ಪರೀಕ್ಷಿಸಿ (ಪ್ರತಿ ಮಾದರಿಯನ್ನು ಮೊದಲು ಪ್ರಾರಂಭಿಸಿ)
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```

**ಪರೀಕ್ಷೆ ಪ್ರಾಂಪ್ಟ್ ಗಳು:**
