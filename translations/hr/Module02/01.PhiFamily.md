Iako ovaj pristup omogućuje pristup najsuvremenijim mogućnostima, stvara ovisnost o skupom hardveru, uvodi visoke operativne troškove i ograničava fleksibilnost implementacije.

## Ključne tehnologije koje omogućavaju Phi obitelj

### "Tekstbočna" metoda treniranja

Jedan od najspektakularnijih aspekata obitelji Phi je metodologija treniranja "kvalitete kao u udžbeniku". Umjesto treniranja na ogromnim količinama nefiltriranih podataka s interneta, Phi modeli koriste pažljivo kurirane, visokokvalitetne obrazovne sadržaje dizajnirane da učinkovito pouče rezoniranje, matematiku, kodiranje i opće znanje.

Ovaj pristup funkcionira stvaranjem sintetičkoga obrazovnog sadržaja koji oponaša visokokvalitetne udžbenike i akademske materijale. Podaci za treniranje posebno su dizajnirani da budu pedagoški ispravni, fokusirajući se na jasna objašnjenja, korak-po-korak rezoniranje i strukturiranu prezentaciju znanja.

### Napredno treniranje rezoniranja

Najnoviji Phi modeli uključuju sofisticirane metode treniranja rezoniranja koje omogućuju složeno rješavanje problema u više koraka. Te tehnike uključuju:

**Chain-of-Thought Training**: Modeli uče razlagati složene probleme u međukorake rezoniranja, čineći proces rješavanja problema transparentnijim i pouzdanijim.

**Inference-Time Scaling**: Modeli generiraju detaljne lance rezoniranja koji koriste dodatne računalne resurse tijekom generiranja odgovora radi poboljšane preciznosti.

**Edge-of-Capability Training**: Podaci za treniranje odabrani su tako da izazovu model na rubu njegovih trenutnih sposobnosti, potičući učenje složenih obrazaca rezoniranja.

### Arhitektonske inovacije

Obitelj Phi uključuje nekoliko arhitektonskih optimizacija dizajniranih posebno za učinkovitost:

**Učinkovitost parametara**: Pažljivi arhitektonski odabiri koji maksimiziraju utjecaj svakog parametra u modelu.

**Višemedijalna integracija**: Učinkovita integracija mogućnosti obrade teksta, vida i govora unutar kompaktnih arhitektura.

**Optimizacija za hardver**: Specijalizirane varijante optimizirane za specifične hardverske platforme i scenarije implementacije.

### Primjer matematičkog rezoniranja

Phi-4-mini-reasoning izvrsno rješava matematičke probleme korak po korak. Na primjer, kad se pita "Kako riješiti 3*x^2+4*x+5=1?", model daje detaljne korake rezoniranja:

```
<|system|>Your name is Phi, an AI math expert developed by Microsoft.<|end|>
<|user|>How to solve 3*x^2+4*x+5=1?<|end|>
<|assistant|>
I need to solve the quadratic equation 3x² + 4x + 5 = 1.

First, let me rearrange this to standard form:
3x² + 4x + 5 = 1
3x² + 4x + 5 - 1 = 0  
3x² + 4x + 4 = 0

Now I can use the quadratic formula: x = (-b ± √(b² - 4ac)) / (2a)
Where a = 3, b = 4, c = 4

Let me calculate the discriminant:
b² - 4ac = 4² - 4(3)(4) = 16 - 48 = -32

Since the discriminant is negative (-32), this equation has no real solutions.
The solutions are complex: x = (-4 ± √(-32)) / 6 = (-4 ± 4i√2) / 6 = (-2 ± 2i√2) / 3
```

Rani Phi modeli uspostavili su temeljna načela visokokvalitetnih trening podataka i učinkovitih arhitektura:

- **Phi-3-small (7B parametara)**: Napredne performanse koje nadmašuju GPT-3.5 Turbo na različitim testovima.
- **Phi-3-medium (14B parametara)**: Performanse na enterprise razini koje nadmašuju Gemini 1.0 Pro.

## Primjeri razvoja i integracije

### Brzi početak s Transformersima

Evo kako započeti s Phi modelima koristeći Hugging Face Transformers biblioteku:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# Učitaj Phi-4-mini-instruct
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True,
    attn_implementation="flash_attention_2"  # Za optimizirane performanse
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")

# Formatirajte svoj upit koristeći predložak za razgovor
messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain quantum computing in simple terms."}
]

# Primijeni predložak za razgovor
input_text = tokenizer.apply_chat_template(messages, tokenize=False)
inputs = tokenizer(input_text, return_tensors="pt")

# Generiraj odgovor
with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=200, temperature=0.7)
    
response = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(response)
```

### Primjer fino podešavanja

Sljedeći primjer prikazuje kako fino podesiti Phi-4-mini-instruct za specifične zadatke:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig
from trl import SFTTrainer
from datasets import load_dataset

# Konfiguracija za LoRA fino podešavanje
peft_config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
    target_modules="all-linear"
)

# Konfiguracija treniranja optimizirana za učinkovitost
training_config = TrainingArguments(
    output_dir="./phi-4-mini-finetuned",
    learning_rate=5.0e-06,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=1,
    num_train_epochs=1,
    bf16=True,
    gradient_checkpointing=True,
    warmup_ratio=0.2,
    save_steps=100
)

# Učitaj model i tokenizator
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-4-mini-instruct",
    torch_dtype=torch.bfloat16,
    trust_remote_code=True
)

tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-4-mini-instruct")
tokenizer.pad_token = tokenizer.unk_token
tokenizer.padding_side = 'right'

# Učitaj i obradi skup podataka
train_dataset = load_dataset("HuggingFaceH4/ultrachat_200k", split="train_sft")

# Inicijaliziraj trenera
trainer = SFTTrainer(
    model=model,
    args=training_config,
    peft_config=peft_config,
    train_dataset=train_dataset,
    max_seq_length=2048,
    tokenizer=tokenizer,
    packing=True
)

# Počni fino podešavanje
trainer.train()
```
