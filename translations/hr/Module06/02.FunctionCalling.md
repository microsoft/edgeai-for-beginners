## Što je pozivanje funkcija?

Pozivanje funkcija je moćna sposobnost koja omogućuje malim jezičnim modelima (SLM-ovima) da komuniciraju s vanjskim alatima, API-jima i uslugama. Umjesto da budu ograničeni na svoje podatke za treniranje, SLM-ovi sada mogu:

- **Povezati se s vanjskim API-jima** (usluge vremenske prognoze, baze podataka, tražilice)
- **Izvršavati specifične funkcije** na temelju korisničkih zahtjeva
- **Dohvatiti informacije u stvarnom vremenu** iz raznih izvora
- **Izvoditi računske zadatke** pomoću specijaliziranih alata
- **Povezati više operacija** za složenije tijekove rada

Ova sposobnost pretvara SLM-ove iz statičnih generatora teksta u dinamične AI agente koji mogu obavljati zadatke u stvarnom svijetu.

## Kako pozivanje funkcija funkcionira

Proces pozivanja funkcije slijedi sustavni tijek rada:

### 1. Integracija alata
- **Vanjski alati**: SLM-ovi se mogu povezati s API-jima za vremensku prognozu, bazama podataka, web uslugama i drugim vanjskim sustavima
- **Definicije funkcija**: Svaki alat definiran je sa specifiranim parametrima, formatima ulaza/izlaza i opisima
- **Kompatibilnost API-ja**: Alati su integrirani putem standardiziranih sučelja (REST API, SDK-ovi itd.)

### 2. Definicija funkcije
Funkcije se definiraju s tri ključne komponente:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Detekcija namjere
- **Obrada prirodnog jezika**: SLM analizira korisnički unos kako bi razumio namjeru
- **Usporedba funkcije**: Određuje koja(i) funkcija(e) su potrebne za ostvarenje zahtjeva
- **Izdvajanje parametara**: Identificira i izdvaja potrebne parametre iz korisnikove poruke

### 4. Generiranje JSON izlaza
SLM generira strukturirani JSON koji sadrži:
- Ime funkcije za pozvati
- Potrebne parametre s odgovarajućim vrijednostima
- Kontekst izvršenja i metapodatke

### 5. Vanjsko izvršenje
- **Validacija parametara**: Osigurava da su svi potrebni parametri prisutni i ispravno formatirani
- **Izvršenje funkcije**: Aplikacija izvršava navedenu funkciju s dostavljenim parametrima
- **Rukovanje pogreškama**: Upravljanje kvarovima, vremenskim prekoračenjima i nevažećim odgovorima

### 6. Integracija odgovora
- **Obrada rezultata**: Izlaz funkcije se vraća SLM-u
- **Integracija konteksta**: SLM uklapa rezultate u svoj odgovor
- **Komunikacija s korisnikom**: Predstavlja informacije u prirodnom, razgovornom obliku

## Scenariji primjene

### Dohvat podataka
Pretvaranje upita prirodnog jezika u strukturirane API pozive:
- **"Prikaži moje nedavne narudžbe"** → Upit bazi podataka s korisničkim ID-om i filtrima po datumu
- **"Kakvo je vrijeme u Tokiju?"** → Poziv vremenskom API-ju s parametrima lokacije
- **"Pronađi e-mailove od Johna prošli tjedan"** → Upit za email uslugu s pošiljateljem i filtrima po datumu

### Izvršenje operacija
Pretvaranje korisničkih zahtjeva u specifične pozive funkcija:
- **"Zakaži sastanak za sutra u 14 sati"** → Integracija kalendarskog API-ja
- **"Pošalji poruku timu"** → API platforme za komunikaciju
- **"Napraviti sigurnosnu kopiju mojih datoteka"** → Operacija datotečnog sustava

### Računski zadaci
Upravljanje složenim matematičkim ili logičkim operacijama:
- **"Izračunaj složenu kamatu na 10.000$ po 5% za 10 godina"** → Financijska funkcija za izračun
- **"Analiziraj ovaj skup podataka za trendove"** → Alati za statističku analizu
- **"Optimiziraj ovu rutu za dostavu"** → Algoritmi za optimizaciju ruta

### Tijekovi obrade podataka
Povezivanje više poziva funkcija za složene operacije:
1. **Dohvati podatke** iz više izvora
2. **Parsiranje i validacija** informacija
3. **Transformacija** podataka u potreban format
4. **Pohranjivanje rezultata** u odgovarajuće sustave
5. **Generiranje izvještaja** ili vizualizacija

### Integracija UI/UX-a
Omogućavanje dinamičkih ažuriranja korisničkog sučelja:
- **"Prikaži prodajne podatke na nadzornoj ploči"** → Generiranje i prikaz grafikona
- **"Ažuriraj kartu s novim lokacijama"** → Integracija geolokacijskih podataka
- **"Osvježi prikaz zaliha"** → Sinkronizacija podataka u stvarnom vremenu

### Implementacija prilagođene funkcije

Također možete definirati prilagođene funkcije za Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Simuliraj poziv vremenske API
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Koristi prilagođeni alat
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

```python
import openai
from foundry_local import FoundryLocalManager

# Inicijaliziraj s aliasom modela
alias = "phi-3.5-mini"  # Ili bilo koji podržani model
manager = FoundryLocalManager(alias)

# Kreiraj OpenAI klijenta koji pokazuje na lokalnu točku
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Definiraj funkcije za model
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Napravi zahtjev za pozivanje funkcije
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

### Uobičajeni problemi i rješenja

#### Problem 1: Funkcija se ne poziva
**Simptomi**: Model odgovara tekstom umjesto da poziva funkciju

**Rješenja**:
1. **Provjerite opis funkcije**: Osigurajte da jasno odgovara korisnikovoj namjeri
2. **Potvrdite definicije parametara**: Provjerite jesu li svi potrebni parametri korektno definirani
3. **Pregledajte sistemsku poruku**: Uključite jasne upute o tome kada se koriste funkcije
4. **Testirajte s eksplicitnim zahtjevima**: Pokušajte s "Molim koristite vremensku funkciju za dohvat podataka za London"

#### Problem 2: Neispravni parametri
**Simptomi**: Funkcija se poziva s pogrešnim ili nedostajućim parametrima

**Rješenja**:
1. **Dodajte primjere parametara**: Uključite primjere vrijednosti u opisima parametara
2. **Koristite enum ograničenja**: Ograničite vrijednosti parametara na određene opcije kad je moguće
3. **Implementirajte zadane vrijednosti**: Pružite smislene zadane vrijednosti za opcionalne parametre

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }
}
```

#### Problem 3: Neuspjesi paralelnog pozivanja funkcija
**Simptomi**: Izvršava se samo jedna funkcija iako bi trebale više

**Rješenja**:
1. **Provjerite podršku modela**: Osigurajte da vaš model podržava paralelno pozivanje funkcija
2. **Ažurirajte sistemsku poruku**: Uključite "neke alate" ili "više alata" u sistemsku poruku
3. **Koristite odgovarajuće verzije modela**: Phi-4-mini:3.8b-fp16 preporučen za Ollama

#### Problem 4: Problemi s predlošcima u Ollama
**Simptomi**: Pozivanje funkcija ne radi s zadanim Ollama postavkama

**Rješenja**:
1. **Koristite prilagođeni ModelFile**: Primijenite ispravljeni predložak iz ovog vodiča
2. **Ažurirajte Ollama**: Osigurajte da koristite verziju 0.5.13 ili noviju

        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Potvrdi da funkcija postoji
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Provjeri ograničenja brzine
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Provjeri parametre
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Izvrši funkciju
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Zabilježi uspješno izvršenje
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Zabilježi neuspjelo izvršenje
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Resetiraj brojač ako je prošla minuta
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Provjeri je li ispod limita
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Provjeri potrebne parametre
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Validiraj tipove i ograničenja parametara
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Validacija tipa
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # Validacija enumeracije

                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )

2. **Fleksibilnost implementacije**: Postoje različiti pristupi, od niskorazinskih implementacija s prilagođenim predlošcima do visokorazinskih okvira poput Qwen-Agent i Foundry Local.

3. **Razmatranja za produkciju**: Implementacije u tvrtkama zahtijevaju pažnju na rukovanje pogreškama, ograničenje brzine, sigurnost i zapisivanje audita.

4. **Optimizacija performansi**: Ispravan dizajn funkcija, učinkovito izvršenje i pametno predmemoriranje mogu značajno poboljšati vrijeme odgovora.

### Buduće smjerove

Kako tehnologija SLM-a nastavlja evoluirati, možemo očekivati:

- **Poboljšanu točnost pozivanja funkcija**: Bolju detekciju namjere i izdvajanje parametara
- **Unaprijeđenu paralelnu obradu**: Sofisticiraniju orkestraciju više funkcija
- **Bolje standarde integracije**: Standardizirane protokole za integraciju alata
- **Napredne sigurnosne značajke**: Poboljšanu autentifikaciju i autorizaciju
- **Prošireni ekosustav**: Rastuću biblioteku preddefiniranih funkcija i integracija

### Početak

Za početak implementacije pozivanja funkcija u vašim projektima:

1. **Započnite jednostavno**: Počnite s osnovnim scenarijima s jednom funkcijom
2. **Odaberite svoj okvir**: Izaberite između direktne implementacije (Ollama/Phi-4) ili okvira (Qwen-Agent)
3. **Pažljivo dizajnirajte funkcije**: Fokusirajte se na jasne, dobro dokumentirane definicije funkcija
4. **Implementirajte rukovanje pogreškama**: Izgradite robustan sustav za rukovanje pogreškama od početka
5. **Postupno skalirajte**: Prijelazite sa jednostavnih na složenije scenarije kako stječete iskustvo

Pozivanje funkcija pretvara SLM-ove iz impresivnih generatora teksta u praktične AI agente sposobne rješavati stvarne probleme. Prateći obrasce i prakse iz ovog vodiča, možete izgraditi moćne, pouzdane AI sustave koji nadilaze tradicionalne chat sučelja.
