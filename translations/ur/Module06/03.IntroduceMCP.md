# سیکشن 03 - ماڈل کانٹیکسٹ پروٹوکول (MCP) انٹیگریشن

## MCP (ماڈل کانٹیکسٹ پروٹوکول) کا تعارف

ماڈل کانٹیکسٹ پروٹوکول (MCP) ایک اوپن سورس معیار ہے جو AI ایپلیکیشنز کو بیرونی نظاموں سے جوڑنے کے لیے استعمال ہوتا ہے۔ MCP کے ذریعے، Claude یا ChatGPT جیسے AI ایپلیکیشنز ڈیٹا ذرائع (جیسے، لوکل فائلز، ڈیٹا بیسز)، ٹولز (مثلاً، سرچ انجنز، کیلکولیٹرز)، اور ورک فلو (مثلاً، مخصوص پرامپٹس) سے جڑ سکتے ہیں—جس سے انہیں اہم معلومات تک رسائی اور کام انجام دینے کی سہولت ملتی ہے۔

MCP کو AI ایپلیکیشنز کے لیے **USB-C پورٹ** سمجھیں۔ جیسے USB-C الیکٹرانک ڈیوائسز کو جوڑنے کا معیاری طریقہ فراہم کرتا ہے، اسی طرح MCP AI ایپلیکیشنز کو بیرونی نظاموں سے منسلک کرنے کا معیاری طریقہ فراہم کرتا ہے۔

### MCP کیا کر سکتا ہے؟

MCP AI ایپلیکیشنز کے لیے طاقتور صلاحیتیں کھولتا ہے:

- **ذاتی نوعیت کے AI اسسٹنٹس**: ایجنٹس آپ کے Google Calendar اور Notion تک رسائی حاصل کر سکتے ہیں، جو ایک زیادہ ذاتی نوعیت کا AI اسسٹنٹ بن جاتے ہیں  
- **جدید کوڈ جنریشن**: Claude Code ایک پورا ویب ایپ Figma ڈیزائن کی بنیاد پر بنا سکتا ہے  
- **انٹرپرائز ڈیٹا انٹیگریشن**: انٹرپرائز چیٹ بوٹس متعدد ڈیٹا بیسز سے جڑ سکتے ہیں، جس سے صارفین کو چیٹ کے ذریعے ڈیٹا تجزیہ کرنے کی صلاحیت ملتی ہے  
- **خلاقی ورک فلو**: AI ماڈلز Blender پر تھری ڈی ڈیزائن بنا سکتے ہیں اور انہیں تھری ڈی پرنٹر کے ذریعے پرنٹ کر سکتے ہیں  
- **ریئل ٹائم معلومات تک رسائی**: اپ ٹو ڈیٹ معلومات کے لیے بیرونی ڈیٹا ذرائع سے جڑنا  
- **پیچیدہ کثیر مرحلہ جاتی آپریشن**: متعدد ٹولز اور نظاموں کو ملا کر نفیس ورک فلو انجام دینا  

### MCP کیوں اہم ہے؟

MCP پوری ماحولیاتی نظام میں فوائد فراہم کرتا ہے:

**ڈیولپرز کے لیے**: MCP AI ایپلیکیشن یا ایجنٹ بنانے یا انٹیگریٹ کرنے کے وقت ترقی کا دورانیہ اور پیچیدگی کم کرتا ہے۔

**AI ایپلیکیشنز کے لیے**: MCP ایک ماحولیاتی نظام کے ڈیٹا ذرائع، ٹولز اور ایپس تک رسائی دیتا ہے جو صلاحیتوں کو بہتر بناتے ہیں اور آخری صارف کے تجربے کو بہتر کرتے ہیں۔

**آخری صارفین کے لیے**: MCP زیادہ قابل AI ایپلیکیشنز یا ایجنٹس فراہم کرتا ہے جو آپ کے ڈیٹا تک رسائی حاصل کر سکتے ہیں اور ضرورت پڑنے پر آپ کی جانب سے کارروائیاں کر سکتے ہیں۔

## چھوٹے زبان کے ماڈلز (SLMs) MCP میں

چھوٹے زبان کے ماڈلز AI نفاذ کا ایک مؤثر طریقہ ہیں، جو متعدد فوائد فراہم کرتے ہیں:

### SLMs کے فوائد
- **وسائل کی کفایت**: کم کمپیوٹیشنل ضروریات  
- **تیز تر ردعمل کے اوقات**: ریئل ٹائم ایپلیکیشنز کے لیے کم تاخیر  
- **لاگت کی مؤثریت**: کم بنیادی ڈھانچے کی ضرورت  
- **رازداری**: مقامی طور پر چل سکتے ہیں بغیر ڈیٹا کی ترسیل کے  
- **حسب ضرورت**: مخصوص شعبوں کے لیے آسان فائن ٹیوننگ  

### SLMs MCP کے ساتھ کیوں اچھے کام کرتے ہیں

MCP کے ساتھ جوڑے گئے SLMs ایک طاقتور امتزاج بناتے ہیں جہاں ماڈل کی استدلال کی صلاحیتوں کو بیرونی ٹولز کے ذریعے بڑھایا جاتا ہے، جو ان کے کم پیرامیٹرز کی گنتی کو مکمل فعالیت سے پورا کرتا ہے۔

## Python MCP SDK کا جائزہ

Python MCP SDK MCP فعال ایپلیکیشنز بنانے کے لیے بنیاد فراہم کرتا ہے۔ SDK میں شامل ہیں:

- **کلائنٹ لائبریریز**: MCP سرورز سے جڑنے کے لیے  
- **سرور فریم ورک**: کسٹم MCP سرور بنانے کے لیے  
- **پروٹوکول ہینڈلرز**: مواصلات کے انتظام کے لیے  
- **ٹول انٹیگریشن**: بیرونی فنکشنز کو چلانے کے لیے  

## عملی نفاذ: Phi-4 MCP کلائنٹ

آئیے ایک حقیقی دنیا کا نفاذ دیکھتے ہیں جو Microsoft کے Phi-4 منی ماڈل کو MCP صلاحیتوں کے ساتھ مربوط کرتا ہے۔

### MCP فن تعمیر کا جائزہ

MCP ایک **کلائنٹ-سرور آرکیٹیکچر** پر مبنی ہے جہاں ایک MCP ہوسٹ (Claude Code یا Claude Desktop جیسی AI ایپلیکیشن) ایک یا زائد MCP سرورز سے کنکشن قائم کرتا ہے۔ MCP ہوسٹ ہر MCP سرور کے لیے ایک MCP کلائنٹ تیار کرتا ہے۔

#### اہم شرکاء

- **MCP ہوسٹ**: AI ایپلیکیشن جو ایک یا ایک سے زائد MCP کلائنٹس کو منظم اور مربوط کرتا ہے  
- **MCP کلائنٹ**: ایک جزو جو MCP سرور کے ساتھ کنکشن برقرار رکھتا ہے اور MCP ہوسٹ کے استعمال کے لیے MCP سرور سے کانٹیکسٹ حاصل کرتا ہے  
- **MCP سرور**: ایک پروگرام جو MCP کلائنٹس کو کانٹیکسٹ فراہم کرتا ہے  

#### دو سطحی فن تعمیر

MCP دو مختلف اقسام کی سطحوں پر مشتمل ہے:

**ڈیٹا لیئر**: کلائنٹ-سرور مواصلات کے لیے JSON-RPC کی بنیاد پر پروٹوکول کی تعریف کرتا ہے، بشمول:  
- زندگی کے مرحلہ کا نظم (کنکشن کی ابتدا، صلاحیت کی گفت و شنید)  
- بنیادی پرمیٹیوز (ٹولز، وسائل، پرامپٹس)  
- کلائنٹ خصوصیات (نمونہ سازی، معلومات حاصل کرنا، لاگنگ)  
- مددگار خصوصیات (نوٹیفیکیشنز، پیش رفت کی نگرانی)  

**ٹرانسپورٹ لیئر**: مواصلاتی طریقے اور چینلز کی وضاحت کرتا ہے:  
- **STDIO ٹرانسپورٹ**: لوکل پروسیسز کے لیے اسٹینڈرڈ ان پٹ/آؤٹ پٹ اسٹریمز استعمال کرتا ہے (بہترین کارکردگی، کوئی نیٹ ورک اوور ہیڈ نہیں)  
- **ایچ ٹی ٹی پی اسٹریم ایبل ٹرانسپورٹ**: ریموٹ سرورز کے لیے HTTP POST استعمال کرتا ہے جس میں اختیاری Server-Sent Events شامل ہیں (معیاری HTTP تصدیق کی حمایت کرتا ہے)  

```
┌─────────────────────────────────────┐
│           MCP Host                  │
│     (AI Application)                │
└─────────────────┬───────────────────┘
                  │
┌─────────────────┴───────────────────┐
│         MCP Client 1                │
│  ┌─────────────────────────────────┐ │
│  │        Data Layer               │ │
│  │  ├── Lifecycle Management       │ │
│  │  ├── Primitives (Tools/Resources)│ │
│  │  └── Notifications              │ │
│  └─────────────────────────────────┘ │
│  ┌─────────────────────────────────┐ │
│  │      Transport Layer           │ │
│  │  ├── STDIO Transport           │ │
│  │  └── HTTP Transport            │ │
│  └─────────────────────────────────┘ │
└─────────────────┬───────────────────┘
                  │
┌─────────────────┴───────────────────┐
│         MCP Server 1                │
│    (Local/Remote Context Provider)  │
└─────────────────────────────────────┘
```

### MCP بنیادی پرمیٹیوز

MCP پرمیٹیوز کی وضاحت کرتا ہے جو AI ایپلیکیشنز کے ساتھ شیئر کی جانے والی سیاق و سباق کی معلومات کی اقسام اور کی جانے والی کارروائیوں کی حد بتاتے ہیں۔

#### سرور پرمیٹیوز

MCP تین بنیادی پرمیٹیوز کی وضاحت کرتا ہے جو سرورز ظہور کر سکتے ہیں:

**ٹولز**: قابل عمل افعال جو AI ایپلیکیشنز کارروائیاں انجام دینے کے لیے بلا سکتے ہیں  
- مثالیں: فائل آپریشنز، API کالز، ڈیٹا بیس سوالات  
- طریقے: `tools/list`, `tools/call`  
- متحرک دریافت اور عمل کاری کی حمایت کرتے ہیں  

**وسائل**: ڈیٹا ذرائع جو AI ایپلیکیشنز کو سیاق و سباق کی معلومات فراہم کرتے ہیں  
- مثالیں: فائل کے مواد، ڈیٹا بیس ریکارڈز، API جوابات  
- طریقے: `resources/list`, `resources/read`  
- منظم ڈیٹا تک رسائی کو قابل بناتے ہیں  

**پرامپٹس**: قابل استعمال ٹیمپلیٹس جو زبان کے ماڈلز کے ساتھ تعامل کو منظم کرتے ہیں  
- مثالیں: سسٹم پرامپٹس، چند مثالیں  
- طریقے: `prompts/list`, `prompts/get`  
- AI تعامل کے نمونوں کو معیاری بناتے ہیں  

#### کلائنٹ پرمیٹیوز

MCP ایسے بھی پرمیٹیوز ڈیفائن کرتا ہے جو کلائنٹس ظاہر کر سکتے ہیں تاکہ مزید بھرپور تعاملات ممکن ہوں:

**نمونہ سازی**: سرورز کو کلائنٹ کے AI ایپلیکیشن سے زبان کے ماڈل کے مکمل ہونے کی درخواست کرنے کی اجازت دیتا ہے  
- طریقہ: `sampling/complete`  
- ماڈل غیر منسلک سرور کی ترقی کو قابل بناتا ہے  
- ہوسٹ کے زبان کے ماڈل تک رسائی فراہم کرتا ہے  

**معلومات حاصل کرنا**: سرورز کو صارفین سے اضافی معلومات طلب کرنے کی اجازت دیتا ہے  
- طریقہ: `elicitation/request`  
- صارف کے تعامل اور تصدیق کو قابل بناتا ہے  
- متحرک معلومات جمع کرنے کی حمایت کرتا ہے  

**لاگنگ**: سرورز کو کلائنٹس کو لاگ پیغامات بھیجنے کی اجازت دیتا ہے  
- ڈی بگنگ اور نگرانی کے مقصد کے لیے استعمال ہوتا ہے  
- سرور کے آپریشنز کی نظرثانی فراہم کرتا ہے  

### MCP پروٹوکول کا لائف سائیکل

#### ابتدا اور صلاحیت کی گفت و شنید

MCP ایک اسٹیٹ فول پروٹوکول ہے جس کے لیے لائف سائیکل مینجمنٹ ضروری ہے۔ ابتدا کا عمل کئی اہم مقاصد پورے کرتا ہے:

1. **پروٹوکول ورژن کی گفت و شنید**: یقینی بناتا ہے کہ کلائنٹ اور سرور دونوں مطابقت پذیر ورژنز استعمال کر رہے ہیں (مثلاً، "2025-06-18")  
2. **صلاحیت کی دریافت**: ہر فریق اپنی حمایت شدہ خصوصیات اور پرمیٹیوز کا اعلان کرتا ہے  
3. **شناخت کا تبادلہ**: شناخت اور ورژن کی معلومات فراہم کرتا ہے  

```python
# مثال کے طور پر ابتدائی درخواست
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {
      "elicitation": {},  # کلائنٹ صارف کی بات چیت کی حمایت کرتا ہے
      "sampling": {}      # کلائنٹ LLM تکمیل فراہم کر سکتا ہے
    },
    "clientInfo": {
      "name": "edge-ai-client",
      "version": "1.0.0"
    }
  }
}
```

#### ٹول کی دریافت اور عملدرآمد

ابتدا کے بعد، کلائنٹس ٹولز دریافت کر کے انہیں چلا سکتے ہیں:

```python
# دستیاب آلات دریافت کریں
tools_response = await session.list_tools()

# ایک آلہ چلائیں
result = await session.call_tool(
    "weather_current",
    {
        "location": "San Francisco",
        "units": "imperial"
    }
)
```

#### حقیقی وقت کی نوٹیفیکیشنز

MCP حرکی اپڈیٹس کے لیے حقیقی وقت کی نوٹیفیکیشنز کی حمایت کرتا ہے:

```python
# جب آلات تبدیل ہوتے ہیں تو سرور اطلاع بھیجتا ہے
{
  "jsonrpc": "2.0",
  "method": "notifications/tools/list_changed"
}

# کلائنٹ ٹولز کی فہرست کو تازہ کرتا ہے
await session.list_tools()  # تازہ شدہ آلات حاصل کریں
```

```python
import asyncio
from ghmodel_mcp_demo import OllamaClient, Phi4MiniMCPClient

async def automated_interaction():
    # ایم سی پی سرور کے پیرامیٹرز کو ترتیب دیں
    server_params = StdioServerParameters(
        command="npx",
        args=["@playwright/mcp@latest"],
        env=None,
    )
    
    # ایم سی پی کلائنٹ بنائیں اور ٹولز کو پروسیس کریں
    async with Phi4MiniMCPClient(server_params) as mcp_client:
        tools = await process_mcp_tools(mcp_client)
        llm_client = OllamaClient()
        
        # ٹول کی صلاحیتوں کے ساتھ جواب تیار کریں
        response, messages = await llm_client.generate_response(
            "Help me automate a web task",
            tools
        )
        return response

# خودکاری کو انجام دیں
result = asyncio.run(automated_interaction())
print(result)
```

## جدید خصوصیات

### کثیر بیک اینڈ سپورٹ

نفاذ Ollama اور vLLM بیک اینڈ دونوں کی حمایت کرتا ہے، جس سے آپ اپنی ضروریات کے مطابق انتخاب کر سکتے ہیں:

- **Ollama**: مقامی ترقی اور ٹیسٹنگ کے لیے بہتر  
- **vLLM**: پیداوار اور زیادہ تھروپٹ کے منظرناموں کے لیے موزوں  

### لچکدار کنکشن پروٹوکولز

دو کنکشن موڈز کی حمایت ہے:

**STDIO موڈ**: براہ راست عمل کی مواصلات  
- کم تاخیر  
- مقامی ٹولز کے لیے موزوں  
- آسان ترتیب  

**SSE موڈ**: HTTP کی بنیاد پر سٹریمنگ  
- نیٹ ورک کی صلاحیت  
- تقسیم شدہ نظاموں کے لیے بہتر  
- حقیقی وقت کی اپڈیٹس  

### ٹول انٹیگریشن کی صلاحیتیں

نظام مختلف ٹولز سے منسلک ہو سکتا ہے:  
- ویب آٹومیشن (Playwright)  
- فائل آپریشنز  
- API تعاملات  
- سسٹم کمانڈز  
- کسٹم فنکشنز  

## ایرر ہینڈلنگ اور بہترین طریقے

### جامع ایرر مینجمنٹ

نفاذ میں مضبوط ایرر ہینڈلنگ شامل ہے:

**کنکشن ایررز:**  
- MCP سرور کی ناکامیاں  
- نیٹ ورک ٹائم آؤٹ  
- کنیکٹیویٹی مسائل  

**ٹولز کے عملدرآمد کے ایررز:**  
- غائب ٹولز  
- پیرامیٹر چیکنگ  
- عملدرآمد کی ناکامیاں  

**جواب کی پروسیسنگ کی ایررز:**  
- JSON کی پارسنگ کے مسائل  
- فارمیٹ کی خلاف ورزیاں  
- LLM کے جواب کی بے قاعدگیاں  

### بہترین طریقے

1. **وسائل کا انتظام**: async context managers کا استعمال کریں  
2. **ایرر ہینڈلنگ**: جامع try-catch بلاکس نافذ کریں  
3. **لاگنگ**: مناسب لاگنگ لیولز فعال کریں  
4. **سیکیورٹی**: ان پٹ کی تصدیق اور آؤٹ پٹ کی صفائی کریں  
5. **کارکردگی**: کنکشن پولنگ اور کیشنگ استعمال کریں  

## حقیقی دنیا کی ایپلیکیشنز

### ویب آٹومیشن
```python
# مثال: خودکار ویب ٹیسٹنگ
async def web_automation_example():
    tools = await setup_playwright_tools()
    response = await llm_client.generate_response(
        "Navigate to example.com and take a screenshot",
        tools
    )
```

### ڈیٹا پروسیسنگ
```python
# مثال: فائل کا تجزیہ
async def data_processing_example():
    tools = await setup_file_tools()
    response = await llm_client.generate_response(
        "Analyze the CSV file and generate a summary report",
        tools
    )
```

### API انٹیگریشن
```python
# مثال: API کے تعاملات
async def api_integration_example():
    tools = await setup_api_tools()
    response = await llm_client.generate_response(
        "Fetch weather data and create a forecast summary",
        tools
    )
```

## MCP کا ماحولیاتی نظام اور ترقی

### MCP پروجیکٹ کا دائرہ کار

ماڈل کانٹیکسٹ پروٹوکول کا ماحولیاتی نظام کئی اہم اجزاء پر مشتمل ہے:

- **[MCP وضاحت](https://modelcontextprotocol.io/specification/latest)**: کلائنٹس اور سرورز کے نفاذ کے لیے سرکاری وضاحت  
- **[MCP SDKs](https://modelcontextprotocol.io/docs/sdk)**: مختلف پروگرامنگ زبانوں کے لیے SDKs جو MCP کو نافذ کرتے ہیں  
- MCP ترقیاتی ٹولز: MCP سرورز اور کلائنٹس کی ترقی کے ٹولز، بشمول [MCP انسپکٹر](https://github.com/modelcontextprotocol/inspector)  
- **[MCP ریفرنس سرور نفاذات](https://github.com/modelcontextprotocol/servers)**: MCP سرورز کے ریفرنس نفاذات  

### MCP کی ترقی کے ساتھ شروعات

تعمیر شروع کرنے کے لیے:

**سرور بنائیں**: [اپنے ڈیٹا اور ٹولز کو ظاہر کرنے کے لیے MCP سرور بنائیں](https://modelcontextprotocol.io/docs/develop/build-server)  

**کلائنٹس بنائیں**: [ایسی ایپلیکیشنز بنائیں جو MCP سرورز سے جڑ سکیں](https://modelcontextprotocol.io/docs/develop/build-client)  

**تصورات سیکھیں**: [MCP کے بنیادی تصورات اور فن تعمیر کو سمجھیں](https://modelcontextprotocol.io/docs/learn/architecture)  

## نتیجہ

MCP کے ساتھ مربوط SLMs AI ایپلیکیشن کی ترقی میں ایک جدید تبدیلی کی نمائندگی کرتے ہیں۔ چھوٹے ماڈلز کی مؤثریت کو بیرونی ٹولز کی طاقت کے ساتھ ملا کر، ڈیولپرز ایسے ذہین نظام بنا سکتے ہیں جو وسائل میں کفایت شعار اور انتہائی قابل ہوں۔

ماڈل کانٹیکسٹ پروٹوکول AI ایپلیکیشنز کو بیرونی نظاموں سے منسلک کرنے کا ایک معیاری طریقہ فراہم کرتا ہے، جیسے USB-C الیکٹرانک ڈیوائسز کے لیے ایک یونیورسل کنکشن معیار فراہم کرتا ہے۔ یہ معیار مندرجہ ذیل چیزیں ممکن بناتا ہے:

- **بہتر انٹیگریشن**: AI ماڈلز کو مختلف ڈیٹا ذرائع اور ٹولز سے جوڑنا  
- **ماحولیاتی نظام کی ترقی**: ایک بار بنائیں، متعدد AI ایپلیکیشنز میں استعمال کریں  
- **بہتر صلاحیتیں**: SLMs کو بیرونی فعالیت کے ساتھ بڑھانا  
- **حقیقی وقت کی اپڈیٹس**: حرکی، جوابی AI ایپلیکیشنز کی حمایت  

کلیدی نکات:  
- MCP ایک اوپن اسٹینڈرڈ ہے جو AI ایپلیکیشنز اور بیرونی نظاموں کے درمیان پل کا کام کرتا ہے  
- پروٹوکول کلیدی پرمیٹیوز کے طور پر ٹولز، وسائل، اور پرامپٹس کی حمایت کرتا ہے  
- حقیقی وقت کی نوٹیفیکیشنز حرکی اور جوابی ایپلیکیشنز کو ممکن بناتی ہیں  
- پیداواری استعمال کے لیے مناسب لائف سائیکل مینجمنٹ اور ایرر ہینڈلنگ ضروری ہے  
- ماحولیاتی نظام جامع SDKs اور ترقیاتی ٹولز فراہم کرتا ہے
