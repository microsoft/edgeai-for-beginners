## فنکشن کالنگ کیا ہے؟

فنکشن کالنگ ایک طاقتور صلاحیت ہے جو چھوٹے زبان ماڈلز (SLMs) کو بیرونی آلات، APIs، اور خدمات کے ساتھ بات چیت کرنے کی اجازت دیتی ہے۔ اپنی تربیتی ڈیٹا تک محدود رہنے کی بجائے، SLMs اب کر سکتے ہیں:

- **بیرونی APIs سے جڑنا** (موسمی خدمات، ڈیٹا بیس، سرچ انجنز)
- **صارف کی درخواستوں کی بنیاد پر مخصوص فنکشنز چلانا**
- **مختلف ذرائع سے حقیقی وقت کی معلومات حاصل کرنا**
- **خاص آلات کے ذریعے حسابی کام انجام دینا**
- **پیچیدہ ورک فلو کے لیے متعدد آپریشنز کو جوڑنا**

یہ صلاحیت SLMs کو جامد متن بنانے والوں سے متحرک AI ایجنٹ میں تبدیل کرتی ہے جو حقیقی دنیا کے کام انجام دے سکتے ہیں۔

## فنکشن کالنگ کیسے کام کرتا ہے

فنکشن کالنگ کا عمل منظم ورک فلو کی پیروی کرتا ہے:

### 1. آلے کا انضمام
- **بیرونی آلات**: SLMs موسمی APIs، ڈیٹا بیس، ویب سروسز اور دیگر بیرونی نظاموں سے جڑ سکتے ہیں
- **فنکشن کی تعریف**: ہر آلہ مخصوص پیرا میٹرز، ان پٹ/آؤٹ پٹ فارمیٹس، اور تفصیلات کے ساتھ بیان کیا جاتا ہے
- **API مطابقت**: آلات معیاری انٹرفیسز (REST APIs، SDKs وغیرہ) کے ذریعے انٹیگریٹ کیے جاتے ہیں

### 2. فنکشن کی تعریف
فنکشنز تین اہم اجزاء کے ساتھ بیان ہوتے ہیں:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. ارادے کا پتہ لگانا
- **قدرتی زبان کی پراسیسنگ**: SLM صارف کے ان پٹ کا تجزیہ کر کے ارادے کو سمجھتا ہے
- **فنکشن میچنگ**: تعین کرتا ہے کہ درخواست پوری کرنے کے لیے کون سا فنکشن(ز) درکار ہے
- **پیرا میٹر کا استخراج**: صارف کے پیغام سے مطلوبہ پیرا میٹرز کی شناخت اور استخراج کرتا ہے

### 4. JSON آؤٹ پٹ کی تخلیق
SLM ساختہ JSON تیار کرتا ہے جس میں شامل ہیں:
- کال کرنے کے لیے فنکشن کا نام
- مناسب قیمتوں کے ساتھ مطلوبہ پیرا میٹرز
- عملدرآمد کا سیاق و سباق اور میٹا ڈیٹا

### 5. بیرونی عملدرآمد
- **پیرا میٹر کی تصدیق**: یقینی بناتا ہے کہ تمام مطلوبہ پیرا میٹر موجود ہیں اور درست طور پر فارمیٹ کیے گئے ہیں
- **فنکشن کا عملدرآمد**: ایپلیکیشن فراہم کردہ پیرا میٹرز کے ساتھ مخصوص فنکشن کو چلاتی ہے
- **خرابی کا نظم و نسق**: ناکامیوں، وقت ختم ہونے، اور غلط ردعمل کو منظم کرتی ہے

### 6. جواب کا انضمام
- **نتائج کی پراسیسنگ**: فنکشن کا آؤٹ پٹ SLM کو واپس کیا جاتا ہے
- **سیاق و سباق کا انضمام**: SLM نتائج کو اپنے جواب میں شامل کرتا ہے
- **صارف سے بات چیت**: معلومات کو فطری، گفتگو کی شکل میں پیش کرتا ہے

## درخواست کے منظرنامے

### ڈیٹا بازیافت
قدرتی زبان کی سوالات کو ساختہ API کالز میں تبدیل کریں:
- **"میرے حالیہ آرڈرز دکھائیں"** → صارف ID اور تاریخ کے فلٹرز کے ساتھ ڈیٹا بیس سوال
- **"ٹوکیو میں موسم کیسا ہے؟"** → مقام کے پیرامیٹر کے ساتھ موسم API کال
- **"جان کے ای میل پچھلے ہفتے کے دوران تلاش کریں"** → بھیجنے والے اور تاریخ کے فلٹرز کے ساتھ ای میل سروس سوال

### آپریشن کا عملدرآمد
صارف کی درخواستوں کو مخصوص فنکشن کالز میں تبدیل کریں:
- **"کل دوپہر 2 بجے میٹنگ شیڈول کریں"** → کیلنڈر API انٹیگریشن
- **"ٹیم کو پیغام بھیجیں"** → مواصلاتی پلیٹ فارم API
- **"میری فائلوں کا بیک اپ بنائیں"** → فائل سسٹم آپریشن

### حسابی کام
پیچیدہ ریاضی یا منطقی عمل انجام دیں:
- **"$10,000 پر 5% پر مرکب سود کا حساب لگائیں 10 سال کے لیے"** → مالیاتی حساب کا فنکشن
- **"اس ڈیٹا سیٹ کا رجحانات کے لیے تجزیہ کریں"** → شماریاتی تجزیہ کے آلات
- **"ترسیل کے لیے اس روٹ کو بہتر بنائیں"** → روٹ آپٹیمائزیشن الگورتھمز

### ڈیٹا پراسیسنگ ورک فلو
پیچیدہ آپریشنز کے لیے متعدد فنکشن کالز کو جوڑیں:
1. **متعدد ذرائع سے ڈیٹا حاصل کریں**
2. **معلومات کو پارس اور تصدیق کریں**
3. **ڈیٹا کو مطلوبہ فارمیٹ میں تبدیل کریں**
4. **نتائج کو مناسب نظاموں میں محفوظ کریں**
5. **رپورٹس یا بصری شکلیں تیار کریں**

### UI/UX انٹیگریشن
متحرک انٹرفیس اپ ڈیٹس کی اجازت دیں:
- **"ڈیش بورڈ پر سیلز ڈیٹا دکھائیں"** → چارٹ بنانا اور دکھانا
- **"نئے مقامات کے ساتھ نقشہ اپ ڈیٹ کریں"** → جیواسپیشل ڈیٹا انٹیگریشن
- **"انونٹری ڈسپلے کو ریفریش کریں"** → حقیقی وقت ڈیٹا ہم آہنگی

### سنگل فنکشن کالنگ کی مثال

```python
import json
import requests

# ٹول/فنگشن کی وضاحت کریں
tools = [
    {
        "name": "get_weather",
        "description": "Get current weather information for a location",
        "parameters": {
            "location": {
                "description": "The city or location name",
                "type": "str",
                "default": "New York"
            },
            "units": {
                "description": "Temperature units (celsius or fahrenheit)",
                "type": "str",
                "default": "celsius"
            }
        }
    }
]

# ٹولز سمیت سسٹم پرامپٹ کے ساتھ پیغام بنائیں
messages = [
    {
        "role": "system",
        "content": "You are a helpful weather assistant",
        "tools": json.dumps(tools)
    },
    {
        "role": "user",
        "content": "What's the weather like in London today?"
    }
]

# اولاما API کو درخواست بھیجیں
response = requests.post(
    "http://localhost:11434/api/chat",
    json={
        "model": "phi4-mini-fc:3.8b-fp16",
        "messages": messages,
        "stream": False
    }
)

print(response.json())
```

## Qwen3 فنکشن کالنگ کے ساتھ کام کرنا

### Qwen-Agent فریم ورک کا استعمال

Qwen-Agent ایک اعلی سطحی فریم ورک فراہم کرتا ہے جو فنکشن کالنگ کے نفاذ کو آسان بناتا ہے:

#### بنیادی سیٹ اپ

```python
import os
from qwen_agent.agents import Assistant

# ایل ایل ایم کو ترتیب دیں
llm_cfg = {
    'model': 'Qwen3-8B',
    # آپشن 1: علی بابا ماڈل اسٹوڈیو استعمال کریں
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # آپشن 2: مقامی تعیناتی استعمال کریں
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'EMPTY',
    
    # سوچنے کے موڈ کے لیے اختیاری ترتیب
    'generate_cfg': {
        'thought_in_content': True,  # جواب میں استدلال شامل کریں
    }
}

# ایم سی پی (ماڈل کانٹیکسٹ پروٹوکول) کا استعمال کرتے ہوئے ٹولز کی تعریف کریں
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # بلٹ ان کوڈ اجرا کرنے والا ٹول
]

# اسسٹنٹ بنائیں
bot = Assistant(llm=llm_cfg, function_list=tools)

# استعمال کی مثال
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# فنکشن کالنگ کے ساتھ جواب پیدا کریں
for response in bot.run(messages=messages):
    print(response)
```

### کسٹم فنکشن کا نفاذ

آپ Qwen3 کے لیے کسٹم فنکشنز بھی تعریف کر سکتے ہیں:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # موسمیاتی API کال کی نقل کریں
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# حسب ضرورت ٹول استعمال کریں
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

import asyncio
import aiohttp

async def batch_function_calls(function_calls):
    """Execute multiple function calls concurrently"""
    async with aiohttp.ClientSession() as session:
        tasks = []
        for call in function_calls:
            if call["name"] == "fetch_url":
                task = fetch_url_async(session, call["parameters"]["url"])
                tasks.append(task)
        
        results = await asyncio.gather(*tasks)
        return results

async def fetch_url_async(session, url):
    async with session.get(url) as response:
        return await response.text()

                "recipients": {"type": "array", "items": {"type": "string"}},
                "message": {"type": "string", "required": True},
                "priority": {"type": "string", "enum": ["low", "medium", "high"], "default": "medium"},
                "channel": {"type": "string", "enum": ["email", "slack", "teams"], "default": "email"}
            },
            handler=self._send_notification,
            rate_limit=200
        )
    
    def register_function(self, name: str, description: str, parameters: Dict, 
                         handler: callable, rate_limit: int = 60):
        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # تصدیق کریں کہ فنکشن موجود ہے
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # ریٹ لمٹس چیک کریں
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # پیرامیٹرز کی تصدیق کریں
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # فنکشن کو چلائیں
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # کامیاب عملدرآمد کو لاگ کریں
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # ناکام عملدرآمد کو لاگ کریں
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # اگر ایک منٹ گزر گیا ہو تو کاؤنٹر ری سیٹ کریں
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # چیک کریں کہ حد کے اندر ہے یا نہیں
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # مطلوبہ پیرامیٹرز چیک کریں
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # پیرامیٹر کی اقسام اور پابندیوں کی تصدیق کریں
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # ٹائپ کی تصدیق
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # انم کی تصدیق
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
        
        return FunctionResult(success=True)
    
    def _log_function_call(self, function_name: str, parameters: Dict, result: FunctionResult):
        """Log function call for audit purposes"""
        log_entry = {
            'timestamp': result.timestamp.isoformat(),
            'function_name': function_name,
            'parameters': parameters,
            'success': result.success,
            'execution_time': result.execution_time,
            'error': result.error if not result.success else None
        }
        
        self.audit_log.append(log_entry)
        
        # اختیاری طور پر بیرونی لاگنگ سسٹم میں لکھیں
        if self.config.get('enable_external_logging', False):
            self._write_to_external_log(log_entry)
    
    def _write_to_external_log(self, log_entry: Dict):
        """Write log entry to external logging system"""
        # عملدرآمد آپ کے لاگنگ انفراسٹرکچر پر منحصر ہوگا
        # مثال کے طور پر، ELK اسٹیک، کلاؤڈ واچ وغیرہ کو بھیجیں
        pass

    def get_function_definitions(self) -> List[Dict]:
        """Get OpenAI-compatible function definitions for all registered functions"""
        definitions = []
        
        for func_name, func_info in self.functions.items():
            definition = {
                'name': func_name,
                'description': func_info['description'],
                'parameters': {
                    'type': 'object',
                    'properties': {},
                    'required': []
                }
            }
            
            for param_name, param_info in func_info['parameters'].items():
                definition['parameters']['properties'][param_name] = {
                    'type': param_info['type'],
                    'description': param_info.get('description', '')
                }
                
                if 'enum' in param_info:
                    definition['parameters']['properties'][param_name]['enum'] = param_info['enum']
                
                if 'default' in param_info:
                    definition['parameters']['properties'][param_name]['default'] = param_info['default']
                
                if param_info.get('required', False):
                    definition['parameters']['required'].append(param_name)
            
            definitions.append(definition)
        
        return definitions

## نتیجہ

چھوٹے زبان ماڈلز میں فنکشن کالنگ ایک نیا رجحان ہے جو جامد AI اسسٹنٹس سے مقامی، قابل ایجنٹس کی جانب منتقلی دکھاتا ہے جو حقیقی دنیا کے ساتھ بات چیت کر سکتے ہیں۔ اس ٹیوٹوریل میں شامل تھے:

### اہم نکات

1. **بنیادی سمجھ**: فنکشن کالنگ SLMs کو ان کی تربیت کے ڈیٹا سے آگے بڑھانے کے لیے بیرونی آلات اور خدمات سے جوڑتا ہے۔

2. **نفاذ کی لچک**: متعدد طریقے موجود ہیں، کم سطحی نفاذ سے لے کر کسٹم ٹیمپلیٹس تک اور اعلی سطحی فریم ورک جیسے Qwen-Agent اور Foundry Local۔

3. **پیداوار کے تقاضے**: انٹرپرائز تعیناتیوں کے لیے خرابی کا انتظام، ریٹ لمیٹنگ، سیکیورٹی، اور آڈٹ لاگنگ پر دھیان دینا ضروری ہے۔

4. **کارکردگی کی بہتری**: مناسب فنکشن ڈیزائن، مؤثر عملدرآمد، اور ہوشیار کیشنگ نمایاں طور پر جواب کے اوقات کو بہتر بناتے ہیں۔

### مستقبل کے راستے

جیسے جیسے SLM ٹیکنالوجی ترقی کرے گی، ہم توقع کر سکتے ہیں:

- **بہتر فنکشن کالنگ درستگی**: بہتر ارادے کی شناخت اور پیرا میٹر استخراج
- **بہتر متوازی پراسیسنگ**: زیادہ پیچیدہ متعدد فنکشن کی ترتیب
- **بہتر انضمامی معیار**: آلات کے انضمام کے لیے معیاری پروٹوکول
- **جدید سیکیورٹی خصوصیات**: بہتر تصدیق اور اجازت کے نظام
- **وسیع تر ماحولیاتی نظام**: پہلے سے بنے ہوئے فنکشنز اور انٹیگریشنز کی بڑھتی ہوئی لائبریری

### آغاز کرنے کا طریقہ

اپنے پروجیکٹس میں فنکشن کالنگ نافذ کرنے کے لیے:

1. **سادہ شروع کریں**: بنیادی سنگل فنکشن منظرناموں سے شروع کریں
2. **اپنا فریم ورک منتخب کریں**: براہ راست نفاذ (Ollama/Phi-4) یا فریم ورک-مدد یافتہ (Qwen-Agent) میں سے انتخاب کریں
3. **فنکشنز کو احتیاط سے ڈیزائن کریں**: واضح، اچھی دستاویزی فنکشن تعریفوں پر توجہ دیں
4. **خرابی کا انتظام نافذ کریں**: ابتدا سے مضبوط خرابی کے انتظام پر کام کریں
5. **تدریجی پیمانہ بڑہائیں**: تجربہ حاصل کرنے کے ساتھ سادہ سے پیچیدہ منظرناموں کی طرف بڑھیں

فنکشن کالنگ SLMs کو متاثر کن متن بنانے والوں سے عملی AI ایجنٹس میں بدل دیتا ہے جو حقیقی دنیا کے مسائل حل کرنے کے قابل ہیں۔ اس ٹیوٹوریل میں بیان کردہ طریقے اور طریقہ کار پر عمل کر کے آپ طاقتور، قابل اعتماد AI نظام بنا سکتے ہیں جو روایتی چیٹ انٹرفیس سے کہیں آگے بڑھ جاتے ہیں۔
