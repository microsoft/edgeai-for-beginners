# ورکشاپ نوٹ بکس

> **ہینڈز آن ایج AI سیکھنے کے لیے انٹرایکٹو جیوپیٹر نوٹ بکس**
>
> مرحلہ وار، خود رفتار ٹیوٹوریلز جو بنیادی چیٹ کمپلیشنز سے Microsoft's Foundry Local اور Small Language Models استعمال کرتے ہوئے جدید ملٹی ایجنٹ سسٹمز تک تعمیری ہوتے ہیں۔

---

## 📖 تعارف

**ایج اے آئی برائے مبتدیان ورکشاپ نوٹ بکس** سے خوش آمدید۔ یہ انٹرایکٹو جیوپیٹر نوٹ بکس آپ کو عملی تجربہ فراہم کرتی ہیں جہاں آپ حقیقی وقت میں ایج اے آئی کوڈ لکھیں گے، چلائیں گے اور تجربہ کریں گے۔

### جیوپیٹر نوٹ بکس کیوں؟

روایتی ٹیوٹوریلز کے برعکس، یہ نوٹ بکس پیش کرتی ہیں:

- **انٹرایکٹو لرننگ**: کوڈ سیلز چلائیں اور فوری نتائج دیکھیں
- **تجربہ کاری**: پیرامیٹرز تبدیل کریں اور حقیقی وقت میں تبدیلیاں مشاہدہ کریں
- **دستاویزات**: ان لائن وضاحتیں اور مارک ڈاؤن سیلز آپ کو تصورات میں رہنمائی کریں
- **دوبارہ پیدا کرنے کی صلاحیت**: مکمل کام کرنے والے نمونے جو آپ حوالہ دے سکتے ہیں اور دوبارہ استعمال کر سکتے ہیں
- **بصری نمائندگی**: کارکردگی کے میٹرکس، ایمبیڈنگز، اور نتائج ان لائن دیکھیں

### یہ نوٹ بکس خاص کیا بناتی ہیں؟

ہر نوٹ بک کی تعمیر **پروڈکشن-ریڈی بہترین طریقہ کار** کے مطابق کی گئی ہے:

✅ **جامع ایرر ہینڈلنگ** - نرمی سے خرابی اور معلوماتی ایرر میسجز  
✅ **ٹائپ ہنٹس اور دستاویزات** - واضح فنکشن سگنیچرز اور ڈاک سٹرنگز  
✅ **کارکردگی کی نگرانی** - ٹوکن کے استعمال کا ٹریک اور تاخیر کی پیمائش  
✅ **ماڈیولر ڈیزائن** - دوبارہ استعمال کے قابل پیٹرنز جو آپ پروجیکٹس کے لیے ڈھال سکتے ہیں  
✅ **مرحلہ وار پیچیدگی** - پچھلے سیشنز پر منظم طریقے سے تعمیر کرتا ہے

## 🎯 تعلیمی مقاصد

### ایسی بنیادی مہارتیں جو آپ ترقی دیں گے

ان نوٹ بکس کے ذریعے کام کرکے، آپ مہارت حاصل کریں گے:

1. **لوکل AI سروس مینجمنٹ**
   - Microsoft Foundry Local سروسز کو ترتیب اور منظم کرنا
   - اپنے ہارڈویئر کیلئے مناسب ماڈلز کا انتخاب اور لوڈ کرنا
   - وسائل کے استعمال کی نگرانی اور کارکردگی کو بہتر بنانا
   - سروس دریافتگی اور صحت کی جانچ کو سنبھالنا

2. **AI ایپلیکیشن کی ترقی**
   - OpenAI-مطابق چیٹ کمپلیشنز کو لوکل طور پر نافذ کرنا
   - بہتر صارف تجربے کے لیے سٹریمنگ انٹرفیس بنانا
   - Small Language Models کے لیے مؤثر پرامپٹس ڈیزائن کرنا
   - لوکل ماڈلز کو ایپلیکیشنز میں ضم کرنا

3. **ریٹریول آگمینٹڈ جنریشن (RAG)**
   - ویکٹر ایمبیڈنگز کے ساتھ معنوی تلاش بنانا
   - LLM جوابات کو مخصوص ڈاکومنٹس پر مبنی کرنا
   - RAG کے معیار کا RAGAS میٹرکس کے ساتھ جائزہ لینا
   - پروٹوٹائپ سے پروڈکشن تک پیمانہ بڑھانا

4. **کارکردگی کی بہتری**
   - کئی ماڈلز کا منظم انداز میں بنچ مارکنگ کرنا
   - تاخیر، تھروپٹ، اور پہلے ٹوکن کے وقت کی پیمائش
   - Small Language Models بمقابلہ Large Language Models کا موازنہ
   - کارکردگی/معیار کے موازنہ کی بنیاد پر بہترین ماڈلز کا انتخاب

5. **ملٹی ایجنٹ آرتھیٹریکشن**
   - مختلف کاموں کے لیے مخصوص ایجنٹس ڈیزائن کرنا
   - ایجنٹ کی میموری اور کانٹیکسٹ مینجمنٹ نافذ کرنا
   - پیچیدہ ورک فلو میں متعدد ایجنٹس کو ہم آہنگ کرنا
   - ایجنٹ تعاون کے لیے کوآرڈی نیٹر پیٹرنز بنانا

6. **ذہین ماڈل راؤٹنگ**
   - نیت کا پتہ لگانا اور پیٹرن میچنگ نافذ کرنا
   - کوئریز کو مناسب ماڈلز کو خودکار طریقے سے روانہ کرنا
   - ملٹی اسٹیپ پائپ لائنز بنانا (منصوبہ → نفاذ → بہتر بنانا)
   - ماڈل-ایز-ٹولز کے اسکیل ایبل آرکیٹیکچرز ڈیزائن کرنا

### فوری تصدیق

سیٹ اپ کی تصدیق کے لیے Python سیل میں یہ چلائیں:

```python
from foundry_local import FoundryLocalManager
import openai

# منیجر کو شروع کریں (خود بخود سروس کی دریافت)
manager = FoundryLocalManager("phi-4-mini")

# OpenAI کلائنٹ کو ترتیب دیں
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# چیٹ مکمل کرنے کا تجربہ کریں
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**متوقع نتیجہ**: مقامی ماڈل کی طرف سے ایک استقبال جواب۔
