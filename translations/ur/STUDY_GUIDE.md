## ماڈیول 6: SLM ایجنٹک سسٹمز - AI ایجنٹس اور فنکشن کالنگ

### اہم تعلیمی مقاصد

- چھوٹے لینگویج ماڈلز کا استعمال کرتے ہوئے ایج ماحول کے لیے ذہین AI ایجنٹس تعمیر کریں
- نظامی ورک فلو کے ساتھ فنکشن کال کرنے کی صلاحیتیں نافذ کریں
- معیاری ٹول انٹریکشن کے لیے ماڈل کانٹیکسٹ پروٹوکول (MCP) انٹیگریشن میں مہارت حاصل کریں
- کم انسانی مداخلت کے ساتھ پیچیدہ ایجنٹک سسٹمز تخلیق کریں

### مطالعہ کے اہم موضوعات

#### سیکشن 1: AI ایجنٹس اور SLM کی بنیادیں
- **ترجیحات**:
  - ایجنٹ کی درجہ بندی کا فریم ورک (ردعملی، ماڈل پر مبنی، مقصد پر مبنی، سیکھنے والے ایجنٹس)
  - SLM بمقابلہ LLM کے تجارتی جائزے
  - ایج کے لیے مخصوص ایجنٹ ڈیزائن کے نمونے
  - ایجنٹس کے لیے وسائل کی بہتری

#### سیکشن 2: چھوٹے لینگویج ماڈلز میں فنکشن کالنگ
- **ترجیحات**:
  - نظامی ورک فلو نفاذ (ارادے کی نشاندہی، JSON آؤٹ پٹ، خارجی نفاذ)
  - پلیٹ فارم مخصوص نفاذ (Phi-4-mini، منتخب کردہ Qwen ماڈلز، Microsoft Foundry Local)
  - جدید مثالیں (کثیر ایجنٹ تعاون، متحرک ٹول منتخب کرنا)
  - پروڈکشن کے پہلو (شرح محدودیت، آڈٹ لاگنگ، سیکیورٹی اقدامات)

#### سیکشن 3: ماڈل کانٹیکسٹ پروٹوکول (MCP) انٹیگریشن
- **ترجیحات**:
  - پروٹوکول آرکیٹیکچر اور تہہ دار نظام ڈیزائن
  - ملٹی-بیک اینڈ سپورٹ (ترقی کے لیے Ollama، پروڈکشن کے لیے vLLM)
  - کنکشن پروٹوکولز (STDIO اور SSE موڈز)
  - حقیقی دنیا کی ایپلیکیشنز (ویب آٹومیشن، ڈیٹا پروسیسنگ، API انٹیگریشن)

### خود تشخیصی سوالات

1. ایج AI ایجنٹس کے لیے کلیدی آرکیٹیکچرل پہلو کیا ہیں؟
2. فنکشن کالنگ ایجنٹ کی صلاحیتوں کو کیسے بڑھاتی ہے؟
3. ایجنٹ کمیونیکیشن میں ماڈل کانٹیکسٹ پروٹوکول کا کردار بیان کریں۔

### عملی مشقیں

- ریکال ایپروچ گائیڈڈ (RAG) پائپ لائنز بنائیں مع معیار کے جائزے اور کارکردگی کی نگرانی کے ساتھ
- کثیر ایجنٹ سسٹمز کو کوآرڈینیٹر پیٹرن کے ساتھ تیار کریں
- ٹاسک کی بنیاد پر ماڈل انتخاب کے لیے ذہین ماڈل روٹنگ میں مہارت حاصل کریں
- پرائیویسی محفوظ آرکیٹیکچرز کے ساتھ لوکل-فرسٹ AI حل تعینات کریں

### مطالعہ کے اہم موضوعات

#### سیشن 01: Foundry Local کے ساتھ آغاز
- **ترجیحات**:
  - FoundryLocalManager SDK انٹیگریشن اور خودکار سروس دریافت
  - بنیادی اور اسٹریمنگ چیٹ نفاذ
  - ایرر ہینڈلنگ نمونے اور صارف کی رائے
  - ماحول کی بنیاد پر کنفیگریشن

#### سیشن 02: RAG کے ساتھ AI حل کی تعمیر

  - RAG پائپ لائن نفاذ (حاصل کریں → پیدا کریں)
  - RAGAS میٹرکس کے ساتھ معیار کی جانچ
  - اختیاری انحصار کے لیے امپورٹ سیفٹی

#### سیشن 03: اوپن سورس ماڈلز
- **ترجیحات**:
  - کثیر ماڈل بینچ مارکنگ حکمت عملیاں
  - لیٹینسی اور تھروپٹ پیمائشیں
  - نرم کمی اور ایرر بازیابی
  - ماڈل فیملیز کے درمیان کارکردگی کا موازنہ

#### سیشن 04: جدید ماڈلز

  - ماڈل مخصوص ایرر ہینڈلنگ

#### سیشن 05: AI سے چلنے والے ایجنٹس

  - کوآرڈینیٹر پیٹرن کے ساتھ کثیر ایجنٹ آرکسٹریشن
  - ایجنٹ میموری مینجمنٹ اور اسٹیٹ ٹریکنگ
  - پائپ لائن ایرر ہینڈلنگ اور اسٹیج لاگنگ

#### سیشن 06: ماڈلز بطور ٹولز

  - کثیر مرحلہ پائپ لائنز (منصوبہ بندی → نفاذ → بہتری)
  - جامع فنکشن دستاویزات

### خود تشخیصی سوالات

3. کثیر ماڈل بینچ مارکنگ میں نرم کمی کو یقینی بنانے کی حکمت عملی کیا ہیں؟
4. کوآرڈینیٹر پیٹرن کس طرح مختلف اسپیشلسٹ ایجنٹس کا انصرام کرتا ہے؟
5. ذہین ماڈل روٹر کے اجزاء کی تفصیل بیان کریں۔

## ماڈیول 7: EdgeAI تعیناتی کے نمونے

### اہم تعلیمی مقاصد

- جامع EdgeAI ترقیاتی ورک فلو کے لیے Visual Studio Code کے AI ٹول کٹ میں مہارت حاصل کریں
- Windows AI Foundry پلیٹ فارم اور NPU آپٹیمائزیشن حکمت عملیوں میں مہارت حاصل کریں
- مختلف ہارڈویئر پلیٹ فارمز اور تعیناتی کے منظرناموں میں EdgeAI نافذ کریں
- پلیٹ فارم مخصوص آپٹیمائزیشن کے ساتھ پروڈکشن-ریڈی EdgeAI ایپلیکیشنز بنائیں

### مطالعہ کے اہم موضوعات

#### سیکشن 1: Visual Studio Code کے لیے AI ٹول کٹ
- **ترجیحات**:
  - VS Code میں جامع Edge AI ترقیاتی ماحول
  - Edge تعیناتی کے لیے ماڈل کیٹلاگ اور دریافت
  - مقامی جانچ، آپٹیمائزیشن، اور ایجنٹ ترقیاتی ورک فلو
  - ایج منظرناموں کے لیے کارکردگی کی نگرانی اور جائزہ

#### سیکشن 2: Windows EdgeAI ترقیاتی گائیڈ
- **ترجیحات**:
  - Windows AI Foundry پلیٹ فارم کا جامع جائزہ
  - Phi Silica API برائے مؤثر NPU انفیرینس
  - تصویری پراسیسنگ اور OCR کے لیے کمپیوٹر وژن APIs
  - مقامی ترقی اور جانچ کے لیے Foundry Local CLI

#### سیکشن 3: پلیٹ فارم مخصوص نفاذ
- **ترجیحات**:
  - NVIDIA Jetson Orin Nano کی تعیناتی (67 TOPS AI کارکردگی)
  - .NET MAUI اور ONNX رن ٹائم GenAI کے ساتھ موبائل ایپلیکیشنز
  - Azure EdgeAI حل کلاؤڈ-ایج ہائبرڈ آرکیٹیکچر کے ساتھ
  - یونیورسل ہارڈویئر سپورٹ کے ساتھ Windows ML آپٹیمائزیشن
  - پرائیویسی مرکوز RAG نفاذ کے ساتھ Foundry Local ایپلیکیشنز

### خود تشخیصی سوالات

1. AI ٹول کٹ EdgeAI ترقیاتی ورک فلو کو کیسے ہموار بناتا ہے؟
2. مختلف ہارڈویئر پلیٹ فارمز میں تعیناتی کی حکمت عملیاں موازنہ کریں۔
3. Edge ترقی کے لیے Windows AI Foundry کے کیا فوائد ہیں؟
4. جدید Edge AI ایپلیکیشنز میں NPU آپٹیمائزیشن کا کیا کردار ہے؟
5. Phi Silica API کس طرح NPU ہارڈویئر کو کارکردگی کی آپٹیمائزیشن کے لیے استعمال کرتا ہے؟
6. پرائیویسی سے حساس ایپلیکیشنز کے لیے مقامی بمقابلہ کلاؤڈ تعیناتی کے فوائد کا موازنہ کریں۔

### عملی مشقیں

1. **AI ٹول کٹ سیٹ اپ**: AI ٹول کٹ کو کنفیگر کریں اور ایک ماڈل کو بہتر بنائیں (1 گھنٹہ)

2. **Windows AI Foundry**: Phi Silica API کا استعمال کرتے ہوئے ایک سادہ Windows AI ایپلیکیشن بنائیں (1 گھنٹہ)
3. **کراس-پلیٹ فارم ڈیپلائمنٹ**: ایک ہی ماڈل کو دو مختلف پلیٹ فارمز پر تعینات کریں (1 گھنٹہ)
4. **NPU آپٹیمائزیشن**: Windows AI Foundry کے ٹولز کے ساتھ NPU کی کارکردگی کا ٹیسٹ کریں (30 منٹ)

## ماڈیول 8: Microsoft Foundry Local – مکمل ڈویلپر ٹول کٹ (جدید شدہ)

### کلیدی تعلیمی مقاصد

- Foundry Local کو جدید SDK انٹیگریشن کے ساتھ انسٹال اور کنفیگر کریں
- کوآرڈینیٹر پیٹرنز کے ساتھ جدید ملٹی ایجنٹ سسٹمز کو نافذ کریں
- خودکار ٹاسک کی بنیاد پر ذہین ماڈل روٹرز بنائیں
- مکمل نگرانی کے ساتھ پروڈکشن کے لیے تیار AI حل تعینات کریں
- ہائبرڈ ڈیپلائمنٹ کے منظرناموں کے لیے Azure AI Foundry کے ساتھ انٹیگریٹ کریں
- FoundryLocalManager اور OpenAI کلائنٹ کے ساتھ جدید SDK پیٹرنز میں مہارت حاصل کریں

### مطالعہ کے مرکز کے علاقے

#### سیکشن 1: جدید انسٹالیشن اور کنفیگریشن
- **ترجیحی تصورات**: 
  - FoundryLocalManager SDK انٹیگریشن
  - خودکار سروس دریافت اور صحت کی نگرانی
  - ماحول کی بنیاد پر کنفیگریشن پیٹرنز
  - پروڈکشن ڈیپلائمنٹ کے لیے غور و فکر

#### سیکشن 2: جدید ملٹی ایجنٹ سسٹمز
- **ترجیحی تصورات**: 
  - ماہر ایجنٹس کے ساتھ کوآرڈینیٹر پیٹرن
  - بازیابی، استدلال، اور عملدرآمد ایجنٹ کی تخصص
  - بہتری کے لیے فیڈبیک لوپ میکانزم
  - کارکردگی کی نگرانی اور اعدادوشمار کا تعاقب

#### سیکشن 3: ذہین ماڈل روٹنگ
- **ترجیحی تصورات**: 
  - کی ورڈ کی بنیاد پر ماڈل کے انتخاب کے الگورتھم
  - متعدد ماڈلز کی حمایت (عام، استدلال، کوڈ، تخلیقی)
  - لچک کے لیے ماحول کی ویریبل کنفیگریشن
  - سروس کی صحت کی جانچ اور غلطی کا انتظام

#### سیکشن 4: پروڈکشن تیار نفاذ
- **ترجیحی تصورات**: 
  - جامع غلطی کا انتظام اور بیک اپ میکانزم
  - درخواست کی نگرانی اور کارکردگی کا تعاقب
  - بینچ مارکس کے ساتھ انٹرایکٹو جیوپیٹر نوٹ بکس کی مثالیں
  - موجودہ ایپلیکیشنز کے ساتھ انٹیگریشن پیٹرنز

### خود تشخیصی سوالات

1. جدید FoundryLocalManager کا طریقہ دستی REST کالز سے کیسے مختلف ہے؟
2. کوآرڈینیٹر پیٹرن کی وضاحت کریں اور یہ ماہر ایجنٹس کو کس طرح ترتیب دیتا ہے۔
3. ذہین روٹر کس طرح سوال کے مواد کی بنیاد پر مناسب ماڈلز کا انتخاب کرتا ہے؟
4. پروڈکشن تیار AI ایجنٹ سسٹم کے کلیدی اجزاء کیا ہیں؟
5. Foundry Local سروسز کے لیے جامع صحت کی نگرانی آپ کیسے نافذ کرتے ہیں؟
6. جدید طریقہ اور روایتی نفاذ پیٹرنز کے فوائد کا موازنہ کریں۔

### عملی مشقیں

1. **جدید SDK سیٹ اپ**: خودکار سروس دریافت کے ساتھ FoundryLocalManager کو کنفیگر کریں (30 منٹ)
2. **ملٹی ایجنٹ سسٹم**: ماہر ایجنٹس کے ساتھ جدید کوآرڈینیٹر چلائیں (30 منٹ)
3. **ذہین روٹنگ**: مختلف سوالات کے اقسام کے ساتھ ماڈل روٹر کا ٹیسٹ کریں (30 منٹ)
4. **انٹرایکٹو ایکسپلوریشن**: جدید خصوصیات کو دریافت کرنے کے لیے جیوپیٹر نوٹ بکس کا استعمال کریں (45 منٹ)
5. **پروڈکشن ڈیپلائمنٹ**: نگرانی اور غلطی کے انتظام کے پیٹرنز نافذ کریں (30 منٹ)
6. **ہائبرڈ انٹیگریشن**: Azure AI Foundry کے بیک اپ منظرناموں کو کنفیگر کریں (30 منٹ)

## چھوٹے منصوبوں کے خیالات

EdgeAI کے تصورات کی مشق کے لیے ان منصوبوں میں سے ایک مکمل کرنے پر غور کریں (ہر ایک کو 2-4 گھنٹے لگیں گے):

### ابتدائی پروجیکٹس (2-3 گھنٹے ہر ایک)
1. **Edge Text Assistant**: ایک چھوٹے زبان کے ماڈل کے ذریعے ایک سادہ آف لائن متن مکمل کرنے کا آلہ بنائیں
2. **ماڈل موازنہ ڈیش بورڈ**: مختلف SLMs کے کارکردگی کے میٹرکس کا ایک بنیادی ویژولائزیشن بنائیں
3. **آپٹیمائزیشن تجربہ**: ایک ہی بنیادی ماڈل پر مختلف کوانٹائزیشن کی سطحوں کا اثر ماپیں

### درمیانے درجے کے پروجیکٹس (3-4 گھنٹے ہر ایک)
4. **AI Toolkit ورک فلو**: VS Code AI Toolkit کا استعمال کرتے ہوئے ماڈل کو شروع سے ختم تک آپٹیمائز اور تعینات کریں
5. **Windows AI Foundry ایپلیکیشن**: Phi Silica API اور NPU آپٹیمائزیشن کا استعمال کرتے ہوئے ونڈوز ایپ بنائیں
6. **کراس-پلیٹ فارم ڈیپلائمنٹ**: ایک ہی آپٹیمائز شدہ ماڈل کو Windows (OpenVINO) اور موبائل (.NET MAUI) پر تعینات کریں
7. **فنکشن کالنگ ایجنٹ**: ایج سیناریوز کے لیے فنکشن کالنگ صلاحیتوں کے ساتھ ایک AI ایجنٹ بنائیں

### اعلیٰ سطح کا انٹیگریشن پروجیکٹس (4-5 گھنٹے ہر ایک)
8. **OpenVINO آپٹیمائزیشن پائپ لائن**: NNCF اور GenAI ٹول کٹ کا استعمال کرتے ہوئے مکمل ماڈل آپٹیمائزیشن نافذ کریں
9. **SLMOps پائپ لائن**: تربیت سے لے کر ایج پر تعیناتی تک ایک مکمل ماڈل لائف سائیکل نافذ کریں
10. **ملٹی ماڈل ایج سسٹم**: مل کر کام کرنے والے متعدد تخصص یافتہ ماڈلز کو ایج ہارڈویئر پر تعینات کریں
11. **MCP انٹیگریشن سسٹم**: ٹول انٹریکشن کے لیے ماڈل کانٹیکسٹ پروٹوکول کے ساتھ ایک ایجنٹک سسٹم بنائیں
