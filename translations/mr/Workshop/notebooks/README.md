# कार्यशाळा नोटबुक्स

> **हाताळणीसाठी इंटरअॅक्टिव्ह Jupyter नोटबुक्स एज AI शिकण्यासाठी**
>
> प्रगतिशील, स्व-अनुक्रमित ट्युटोरियल्स जे बेसिक चॅट पूर्णता पासून प्रगत मल्टी-एजंट सिस्टिम्सपर्यंत बिल्ड करतात Microsoft Foundry Local आणि Small Language Models वापरून.

## 📖 परिचय

**EdgeAI for Beginners Workshop Notebooks** संग्रहात आपले स्वागत आहे. हे इंटरअॅक्टिव्ह Jupyter नोटबुक्स एक हाताळणी शिकण्याचा अनुभव देतात जिथे आपण Edge AI कोड प्रत्यक्ष वेळेत लिहाल, चालवाल, व प्रयोग कराल.

### Jupyter नोटबुक्स का?

पारंपरिक ट्युटोरियल्सपेक्षा, हे नोटबुक्स देतात:

- **इंटरअॅक्टिव्ह शिक्षण**: कोड सेल्स चालवा आणि तत्काळ परिणाम पहा
- **प्रयोग**: पॅरामीटर्स बदला आणि प्रत्यक्ष वेळेत बदल पहा
- **डॉक्युमेंटेशन**: इनलाइन स्पष्टीकरणे आणि मार्कडाउन सेल्स संकल्पना समजून घेण्यासाठी मार्गदर्शन करतात
- **पुनरुत्पादनयोग्यता**: पूर्ण कार्यरत उदाहरणे जी आपण संदर्भित आणि पुनर्वापर करू शकता
- **दृश्यांकन**: कामगिरी मेट्रिक्स, एम्बेडिंग्ज, आणि परिणाम इनलाइन पहा

### या नोटबुक्समध्ये काय खास आहे?

प्रत्येक नोटबुकची रचना केली आहे **उत्पादन-तयार सर्वोत्तम पद्धतींनुसार**:

✅ **संपूर्ण त्रुटी हाताळणी** - सौम्य घटवा आणि माहितीपूर्ण त्रुटी संदेश  
✅ **टाइप हिन्ट्स & डॉक्युमेंटेशन** - स्पष्ट फंक्शन सिग्नेचर्स आणि डॉक्स्ट्रिंग्ज  
✅ **कामगिरी निरीक्षण** - टोकन वापर ट्रॅकिंग आणि विलंब मोजमाप  
✅ **मॉड्युलर डिझाईन** - पुनर्वापरयोग्य पॅटर्न्स ज्यांना आपण आपल्या प्रोजेक्टमध्ये जुळवून घेऊ शकता  
✅ **प्रगत जटिलता** - मागील सत्रांवर प्रणालीबद्धरित्या बांधते

## 🎯 शिकण्याची उद्दिष्टे

### मुख्य कौशल्ये जी आपण विकसित कराल

या नोटबुक्समधून काम करून, आपण पारंगत व्हाल:

1. **स्थानिक AI सेवा व्यवस्थापन**
   - Microsoft Foundry Local सेवा कॉन्फिगर करा आणि व्यवस्थापित करा
   - आपल्या हार्डवेअर साठी योग्य मॉडेल निवडा आणि लोड करा
   - संसाधन वापर निरीक्षण करा आणि कार्यक्षमता ऑप्टिमाइझ करा
   - सेवा शोध आणि हेल्थ तपासणी सांभाळा

2. **AI अनुप्रयोग विकास**
   - स्थानिक पातळीवर OpenAI-समर्थित चॅट पूर्णता अंमलबजावणी करा
   - चांगल्या वापरकर्तानुभवासाठी स्ट्रीमिंग इंटरफेस तयार करा
   - लहान भाषा मॉडेलसाठी प्रभावी प्रॉम्प्ट डिझाइन करा
   - स्थानिक मॉडेल्स अनुप्रयोगांमध्ये एकत्रित करा

3. **रिट्रीव्हल ऑगमेंटेड जनरेशन (RAG)**
   - व्हेक्टर एम्बेडिंग्जसह सेमॅंटिक शोध तयार करा
   - LLM प्रतिसादांना डोमेन-विशिष्ट दस्तऐवजांमध्ये दर्जा द्या
   - RAGAS मेट्रिक्ससह RAG गुणवत्ता मूल्यांकन करा
   - प्रोटोटाइपपासून उत्पादनापर्यंत प्रमाण वाढवा

4. **कार्यक्षमता ऑप्टिमायझेशन**
   - अनेक मॉडेल्सचे प्रणालीबद्ध मापन करा
   - विलंब, थ्रूपुट, आणि पहिले-टोकन वेळ मोजा
   - लहान भाषा मॉडेल्स विरुद्ध मोठे भाषा मॉडेल्स यांची तुलना करा
   - कामगिरी/गुणवत्तेच्या तुटी-फुटीवर आधारित सर्वोत्तम मॉडेल निवडा

5. **मल्टी-एजंट संयोजन**
   - वेगवेगळ्या कामांसाठी विशेष एजंट डिझाइन करा
   - एजंट स्मृती आणि संदर्भ व्यवस्थापन अंमलात आणा
   - जटिल वर्कफ्लोमधील अनेक एजंट्स समन्वयित करा
   - एजंट सहकार्याकरिता संयोजक पॅटर्न तयार करा

6. **बुद्धिमान मॉडेल राउटिंग**
   - हेतू शोध आणि नमुना जुळणी अंमलात आणा
   - योग्य मॉडेल्सकडे क्वेरी स्वयंचलितपणे पाठवा
   - बहुसंख्य मॉडेल्ससाठी पाइपलाईन्स तयार करा (योजना → अंमलबजावणी → सुधारणा)
   - स्केलेबल मॉडेल-एज-टूल्स आर्किटेक्चर डिझाइन करा

### जलद पडताळणी

सेटअपची पुष्टी करण्यासाठी Python सेलमध्ये हे चालवा:

```python
from foundry_local import FoundryLocalManager
import openai

# व्यवस्थापक प्रारंभ करा (सेवा आपोआप शोधून काढते)
manager = FoundryLocalManager("phi-4-mini")

# OpenAI क्लायंट कॉन्फिगर करा
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# चॅट पूर्णता चाचणी करा
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**अपेक्षित आउटपुट**: स्थानिक मॉडेलकडून अभिवादन प्रतिसाद.
