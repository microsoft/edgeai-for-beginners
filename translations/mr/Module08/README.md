# मोड्यूल 08: Microsoft Foundry Local सह प्रत्यक्ष काम - पूर्ण डेव्हलपर टूलकिट

## आढावा

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) हा एज AI विकासाच्या पुढील पिढीचे प्रतिनिधित्व करतो, जो विकसकांना स्थानिकरीत्या AI अनुप्रयोग तयार करण्यासाठी, डिप्लॉय करण्यासाठी आणि स्केल करण्यासाठी सामर्थ्यशाली साधने प्रदान करतो, तसेच Azure AI Foundry सह अखंड समाकलन ठेवतो. हा मोड्यूल Foundry Local ची स्थापना ते प्रगत एजंट विकासापर्यंत सखोल माहिती पुरवतो.

**महत्वाच्या तंत्रज्ञानांचे संच:**
- Microsoft Foundry Local CLI आणि SDK
- Azure AI Foundry समाकलन
- ऑन-डिव्हाइस मॉडेल इन्फरन्स
- स्थानिक मॉडेल कॅशिंग आणि ऑप्टिमायझेशन
- एजंट-आधारित वास्तुकले

## शिक्षण उद्दिष्टे

हा मोड्यूल पूर्ण केल्यावर, आपण:

- **Foundry Local मध्ये प्रभुत्व मिळवा**: Windows 11 विकासासाठी स्थापना, कॉन्फिगरेशन आणि ऑप्टिमायझेशन करा
- **विविध मॉडेल्स डिप्लॉय करा**: स्थानिकरीत्या phi, qwen, deepseek, आणि GPT मॉडेल CLI आदेशांसह चालवा
- **उत्पादन उपाय तयार करा**: प्रगत प्रॉम्प्ट अभियांत्रिकी आणि डेटा समाकलनासह AI अनुप्रयोग तयार करा
- **ओपन-सोर्स पर्यावरणाचा वापर करा**: Hugging Face मॉडेल्स आणि समुदाय योगदान एकत्रित करा
- **AI एजंट विकसित करा**: ग्राउंडिंग आणि ऑर्केस्ट्रेशन क्षमतांसह बुद्धिमान एजंट तयार करा
- **एंटरप्राइज पॅटर्न्स लागू करा**: उत्पादन डिप्लॉयमेंटसाठी मॉड्यूलर, स्केलेबल AI समाधान तयार करा

## पूर्वअटी

### सिस्टम आवश्यकता
- **ऑपरेटिंग सिस्टम**: Windows 11 (22H2 किंवा नंतर)
- **मेमरी**: 16GB RAM (मोठ्या मॉडेल्ससाठी 32GB शिफारसीय)
- **स्टोरेज**: मॉडेल कॅशिंगसाठी 50GB मोकळी जागा
- **हार्डवेअर**: NPU सक्षम उपकरण शिफारसीय (Copilot+ PC), GPU पर्यायी
- **नेटवर्क**: प्रारंभिक मॉडेल डाउनलोडसाठी उच्च गती इंटरनेट

### विकास वातावरण
- AI Toolkit विस्तारासहित Visual Studio Code
- Python 3.10+ आणि pip
- आवृत्ती नियंत्रणासाठी Git
- PowerShell किंवा कमांड प्रॉम्प्ट
- Azure CLI (क्लाउड समाकलनासाठी ऐच्छिक)

### ज्ञान पूर्वअटी
- AI/ML संकल्पनांची मूलभूत समज
- कमांड लाईनशी परिचय
- Python प्रोग्रामिंग मूलतत्त्वे
- REST API संकल्पना
- प्रॉम्प्टिंग आणि मॉडेल इन्फरन्सचे मूलभूत ज्ञान

## शिक्षण परिणाम

हा मोड्यूल पूर्ण केल्यानंतर, आपण सक्षम असाल:

### तांत्रिक प्रभुत्व
- **Foundry Local चे व्यवस्थापन आणि डिप्लॉयमेंट**: विकास आणि उत्पादन वातावरणामध्ये
- **मॉडेल्स समाकलित करा**: Microsoft, Hugging Face, आणि समुदाय स्रोतांमधून विविध मॉडेल कुटुंबे सहज वापरा
- **अनुप्रयोग तयार करा**: प्रगत वैशिष्ट्ये आणि ऑप्टिमायझेशनसह उत्पादन-तयार AI अनुप्रयोग तयार करा
- **एजंट विकसित करा**: ग्राउंडिंग, तर्क, आणि टूल समाकलनासह प्रगत AI एजंट्स अंमलात आणा

### धोरणात्मक समज
- **वास्तुकला निर्णय**: स्थानिक विरुद्ध क्लाउड डिप्लॉयमेंट याबाबत सुज्ञ निवड करा
- **कार्यप्रदर्शन ऑप्टिमायझेशन**: वेगवेगळ्या हार्डवेअर विन्यासांवर इन्फरन्स कार्यक्षमता सुधारित करा
- **एंटरप्राइज स्केलिंग**: स्थानिक प्रोटोटाइपपासून एंटरप्राइज डिप्लॉयमेंटपर्यंत अनुप्रयोग डिझाईन करा
- **गोपनीयता आणि सुरक्षा**: स्थानिक इन्फरन्ससह गोपनीयता रक्षण करणारे AI उपाय लागू करा

### नवोन्मेष क्षमता
- **जलद प्रोटोटायपिंग**: सर्व 10 नमुना पॅटर्न्समध्ये AI अनुप्रयोग संकल्पना जलद तयार करा आणि चाचणी करा
- **समुदाय समाकलन**: ओपन-सोर्स मॉडेल्सचा वापर करा आणि पर्यावरणासाठी योगदान द्या
- **प्रगत पॅटर्न्स**: RAG, एजंट्स, आणि टूल समाकलनासह अत्याधुनिक AI पॅटर्न्स लागू करा
- **फ्रेमवर्क प्रभुत्व**: LangChain, Semantic Kernel, Chainlit, आणि Electron सह तज्ज्ञ स्तरावर समाकलन करा
- **उत्पादन डिप्लॉयमेंट**: स्थानिक प्रोटोटाइपपासून एंटरप्राइज सिस्टमपर्यंत स्केलेबल AI उपाय डिप्लॉय करा
- **भविष्यास तयार विकास**: उदयोन्मुख AI तंत्रज्ञान आणि पॅटर्नसाठी तयार अनुप्रयोग तयार करा

### सामान्य समस्या निवारण

**Foundry Local कनेक्शन त्रुटी**
```powershell
# सेवा स्थिती तपासा
foundry status

# गरज असल्यास पुन्हा सुरू करा
foundry restart

# एंडपॉइंट प्रवेशयोग्यता तपासा
curl http://localhost:5273/v1/models
```

**मॉडेल लोड होत नाही समस्या**
```powershell
# उपलब्ध मॉडेल्स तपासा

# गहाळ मॉडेल्स डाउनलोड करा
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# आवश्यक असल्यास जबरदस्तीने पुन्हा लोड करा

```
