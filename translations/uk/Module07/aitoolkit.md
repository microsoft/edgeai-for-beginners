# AI Toolkit для Visual Studio Code - Посібник із розробки Edge AI

## Вступ

Ласкаво просимо до вичерпного посібника з використання AI Toolkit для Visual Studio Code у розробці Edge AI. Оскільки штучний інтелект переходить від централізованих хмарних обчислень до розподілених пристроїв на периферії, розробникам потрібні потужні, інтегровані інструменти, які можуть впоратися з унікальними викликами периферійного впровадження — від обмежень ресурсів до вимог до роботи в автономному режимі.

AI Toolkit для Visual Studio Code з’єднує цей розрив, надаючи повне середовище розробки, спеціально розроблене для створення, тестування та оптимізації AI-додатків, які ефективно працюють на пристроях на периферії. Незалежно від того, чи розробляєте ви для IoT сенсорів, мобільних пристроїв, вбудованих систем або периферійних серверів, цей комплект інструментів оптимізує весь ваш робочий процес розробки у знайомому середовищі VS Code.

Цей посібник проведе вас через основні концепції, інструменти та найкращі практики використання AI Toolkit у ваших проектах Edge AI — від початкового вибору моделі до впровадження в продуктивне середовище.

## Огляд

AI Toolkit для Visual Studio Code — це потужне розширення, яке оптимізує розробку агентів і створення AI-додатків. Комплект інструментів надає всебічні можливості для дослідження, оцінювання та розгортання AI-моделей від широкого кола провайдерів — зокрема Anthropic, OpenAI, GitHub, Google — при цьому підтримуючи локальне виконання моделей за допомогою ONNX і Ollama.

Що вирізняє AI Toolkit — це комплексний підхід до всього циклу розробки AI. На відміну від традиційних інструментів, які зосереджуються на окремих аспектах, AI Toolkit надає інтегроване середовище, що охоплює пошук моделей, експерименти, розробку агентів, оцінювання та розгортання — усе це в інтерфейсі VS Code, який вам вже знайомий.

Платформа спеціально розроблена для швидкого прототипування та продуктивного розгортання з функціями, як генерація запитів, швидкі стартові шаблони, безшовна інтеграція інструментів MCP (Model Context Protocol) та розширені можливості оцінювання. Для розробки Edge AI це означає, що ви можете ефективно розробляти, тестувати та оптимізувати AI-додатки для сценаріїв периферійного розгортання, зберігаючи повний робочий процес розробки в межах VS Code.

## Навчальні цілі

Наприкінці цього посібника ви зможете:

### Основні компетенції
- **Встановлювати та налаштовувати** AI Toolkit для Visual Studio Code для робочих процесів розробки Edge AI
- **Орієнтуватися та використовувати** інтерфейс AI Toolkit, включаючи Каталог моделей, Playground та Agent Builder
- **Вибирати та оцінювати** AI-моделі, придатні для периферійного розгортання, на основі продуктивності та обмежень ресурсів
- **Конвертувати та оптимізувати** моделі за допомогою формату ONNX і методів квантування для пристроїв на периферії

### Навички розробки Edge AI
- **Проєктувати та реалізовувати** додатки Edge AI за допомогою інтегрованого середовища розробки
- **Виконувати тестування моделей** в умовах, близьких до периферійних, використовуючи локальний висновок і моніторинг ресурсів
- **Створювати та налаштовувати** AI-агентів, оптимізованих для сценаріїв периферійного розгортання
- **Оцінювати продуктивність моделей** за метриками, релевантними для периферійних обчислень (затримка, використання пам’яті, точність)

### Оптимізація та розгортання
- **Застосовувати методи квантування та обрізки**, щоб зменшити розмір моделі, зберігаючи прийнятний рівень продуктивності
- **Оптимізувати моделі** для конкретних апаратних платформ периферії, включно з прискоренням на CPU, GPU і NPU
- **Впроваджувати найкращі практики** у розробці Edge AI, включаючи управління ресурсами та стратегії відновлення
- **Підготувати моделі та додатки** до продуктивного розгортання на периферійних пристроях

### Розвинені концепції Edge AI
- **Інтегруватися з фреймворками Edge AI**, включно з ONNX Runtime, Windows ML та TensorFlow Lite
- **Реалізовувати багатомодельні архітектури** та сценарії федеративного навчання для периферійних середовищ
- **Вирішувати типові проблеми Edge AI**, включно з обмеженнями пам’яті, швидкістю висновку та сумісністю апаратного забезпечення
- **Проєктувати стратегії моніторингу та логування** для додатків Edge AI у продуктивному середовищі

### Практичне застосування
- **Створювати комплексні рішення Edge AI** від вибору моделі до розгортання
- **Демонструвати володіння** специфічними для периферії робочими процесами розробки та методами оптимізації
- **Застосовувати набуті знання** до реальних випадків використання Edge AI, включаючи IoT, мобільні та вбудовані додатки
- **Оцінювати та порівнювати** різні стратегії розгортання Edge AI і їх компроміси

## Ключові можливості для розробки Edge AI

### 1. Каталог моделей і пошук
- **Підтримка багатьох провайдерів**: Перегляд і доступ до AI-моделей від Anthropic, OpenAI, GitHub, Google та інших провайдерів
- **Інтеграція локальних моделей**: Спрощений пошук моделей ONNX і Ollama для периферійного розгортання
- **Моделі GitHub**: Пряма інтеграція з хостингом моделей GitHub для спрощеного доступу
- **Порівняння моделей**: Порівнюйте моделі поруч, щоб знайти оптимальний баланс для обмежень пристроїв на периферії

### 2. Інтерактивний Playground
- **Інтерактивне тестове середовище**: Швидке експериментування з можливостями моделей у контрольованому середовищі
- **Підтримка мультимодальності**: Тестування зображень, тексту та інших ввідних даних, типових для периферійних сценаріїв
- **Експериментування в реальному часі**: Миттєвий зворотний зв’язок про відповіді й продуктивність моделей
- **Оптимізація параметрів**: Тонке налаштування параметрів моделей для вимог периферійного розгортання

### 3. Конструктор запитів (агент)
- **Генерація природною мовою**: Генеруйте початкові запити за допомогою описів природною мовою
- **Ітеративне вдосконалення**: Покращуйте запити на основі відповідей і продуктивності моделей
- **Декомпозиція завдань**: Розбивайте складні завдання за допомогою ланцюжків запитів і структурованих результатів
- **Підтримка змінних**: Використовуйте змінні в запитах для динамічної поведінки агентів
- **Генерація робочого коду**: Створюйте код, готовий для продуктивної розробки додатків

### 4. Масове виконання і оцінювання
- **Тестування кількох моделей**: Виконуйте одночасно кілька запитів на обраних моделях
- **Ефективне тестування в масштабі**: Швидко тестуйте різні введення та налаштування
- **Індивідуальні тестові кейси**: Запускайте агентів із тестовими випадками для перевірки функціональності
- **Порівняння продуктивності**: Порівнюйте результати різних моделей і конфігурацій

### 5. Оцінювання моделей за допомогою наборів даних
- **Стандартні метрики**: Тестуйте AI-моделі за допомогою вбудованих оцінювачів (F1 score, релевантність, схожість, когерентність)
- **Індивідуальні оцінювачі**: Створюйте власні метрики оцінювання для специфічних випадків
- **Інтеграція наборів даних**: Тестуйте моделі на комплексних наборах даних
- **Вимірювання продуктивності**: Кількісно оцінюйте продуктивність моделей для рішень з периферійного розгортання

### 6. Можливості тонкого налаштування
- **Налаштування моделей**: Налаштовуйте моделі для специфічних випадків і доменів
- **Спеціалізована адаптація**: Підлаштовуйте моделі під спеціалізовані домени та вимоги
- **Оптимізація для периферії**: Тонко налагоджуйте моделі саме для обмежень периферійного розгортання
- **Навчання, орієнтоване на домен**: Створюйте моделі, орієнтовані на конкретні випадки використання на периферії

### 7. Інтеграція інструментів MCP
- **Підключення зовнішніх інструментів**: Підключайте агентів до зовнішніх інструментів через сервери Model Context Protocol
- **Реальні дії**: Дозволяйте агентам запитувати бази даних, отримувати доступ до API чи виконувати власну логіку
- **Існуючі сервери MCP**: Використовуйте інструменти за протоколами command (stdio) або HTTP (server-sent event)
- **Розробка власних MCP**: Створюйте та генеруйте каркаси нових серверів MCP з тестуванням у Agent Builder

### 8. Розробка і тестування агентів
- **Підтримка виклику функцій**: Дозволяйте агентам динамічно викликати зовнішні функції
- **Тестування інтеграції в реальному часі**: Перевіряйте інтеграції за допомогою запусків і використання інструментів у реальному часі
- **Версіонування агентів**: Керуйте версіями агентів з можливістю порівняння результатів оцінювання
- **Відладка і трасування**: Локальні можливості трасування і відладки під час розробки агентів

## Робочий процес розробки Edge AI

### Фаза 1: Пошук і вибір моделі
1. **Огляньте каталог моделей**: Використовуйте каталог для пошуку моделей, придатних для периферійного розгортання
2. **Порівняйте продуктивність**: Оцініть моделі за розміром, точністю і швидкістю висновку
3. **Тестування локально**: Використовуйте моделі Ollama або ONNX для локального тестування перед розгортанням на периферії
4. **Оцініть вимоги до ресурсів**: Визначте потреби в пам’яті та обчислювальні ресурси для цільових пристроїв на периферії

### Фаза 2: Оптимізація моделі
1. **Конвертуйте у ONNX**: Конвертуйте обрані моделі у формат ONNX для сумісності з периферійними пристроями
2. **Застосуйте квантування**: Зменшіть розмір моделі за допомогою квантування INT8 або INT4
3. **Оптимізація апаратного забезпечення**: Оптимізуйте для цільового периферійного апаратного забезпечення (ARM, x86, спеціалізовані акселератори)
4. **Перевірка продуктивності**: Переконайтеся, що оптимізовані моделі зберігають прийнятний рівень точності

### Фаза 3: Розробка додатків
1. **Проєктування агентів**: Використовуйте Agent Builder для створення AI-агентів, оптимізованих для периферії
2. **Інженерія запитів**: Розробляйте запити, які ефективно працюють із меншими моделями для периферії
3. **Тестування інтеграції**: Тестуйте агентів у змодельованих периферійних умовах
4. **Генерація коду**: Генеруйте продуктивний код, оптимізований для периферійного розгортання

### Фаза 4: Оцінювання і тестування
1. **Пакетне оцінювання**: Тестуйте кілька конфігурацій, щоб знайти оптимальні параметри для периферії
2. **Профілювання продуктивності**: Аналізуйте швидкість висновку, використання пам’яті та точність
3. **Симуляція периферії**: Тестуйте в умовах, схожих до цільового периферійного середовища розгортання
4. **Стрес-тестування**: Оцінюйте продуктивність за різних умов навантаження

### Фаза 5: Підготовка до розгортання
1. **Фінальна оптимізація**: Застосуйте фінальні оптимізації на основі результатів тестування
2. **Пакування для розгортання**: Упакуйте моделі та код для периферійного розгортання
3. **Документування**: Документуйте вимоги до розгортання та конфігурацію
4. **Налаштування моніторингу**: Підготуйте моніторинг і логування для периферійного розгортання

## Випадки використання Edge AI

### Розумні IoT-пристрої
- **Розпізнавання зображень у реальному часі**: Розгортання моделей комп’ютерного зору на IoT-камерах і сенсорах
- **Обробка голосу**: Реалізація розпізнавання мовлення та обробки природної мови на розумних динаміках
- **Прогнозне обслуговування**: Запуск моделей виявлення аномалій на промислових периферійних пристроях
- **Моніторинг навколишнього середовища**: Розгортання моделей аналізу даних сенсорів для екологічних застосувань

### Мобільні та вбудовані додатки
- **Переклад на пристрої**: Реалізація моделей перекладу мов, що працюють в офлайн-режимі
- **Доповнена реальність**: Розгортання моделей розпізнавання та відстеження об’єктів у реальному часі для AR-застосунків
- **Моніторинг здоров’я**: Запуск моделей аналізу стану здоров’я на носимих пристроях та медичному обладнанні
- **Автономні системи**: Реалізація моделей прийняття рішень для дронів, роботів та транспортних засобів

### Периферійна обчислювальна інфраструктура
- **Периферійні дата-центри**: Розгортання AI-моделей у периферійних дата-центрах для застосунків із низькою затримкою
- **Інтеграція CDN**: Інтеграція AI-процесингу у мережі доставки контенту
- **5G на периферії**: Використання 5G периферійних обчислень для AI-застосунків
- **Туманні обчислення**: Реалізація AI-обробки в середовищах туманних обчислень

## Встановлення та налаштування

### Встановлення розширення
Встановіть розширення AI Toolkit безпосередньо з Visual Studio Code Marketplace:

**Ідентифікатор розширення**: `ms-windows-ai-studio.windows-ai-studio`

**Методи встановлення**:
1. **VS Code Marketplace**: Знайдіть "AI Toolkit" у розділі Extensions
2. **Командний рядок**: `code --install-extension ms-windows-ai-studio.windows-ai-studio`
3. **Пряме встановлення**: Завантажте з [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=ms-windows-ai-studio.windows-ai-studio)

### Передумови для розробки Edge AI
- **Visual Studio Code**: Рекомендується остання версія
- **Середовище Python**: Python 3.8+ з необхідними AI-бібліотеками
- **ONNX Runtime** (опційно): Для інференсу ONNX-моделей
- **Ollama** (опційно): Для локального обслуговування моделей
- **Інструменти апаратного прискорення**: CUDA, OpenVINO або специфічні акселератори платформи

### Початкове налаштування
1. **Активація розширення**: Відкрийте VS Code і підтвердьте, що AI Toolkit з’явився на панелі активності
2. **Налаштування провайдерів моделей**: Налаштуйте доступ до GitHub, OpenAI, Anthropic або інших провайдерів моделей
3. **Локальне середовище**: Налаштуйте Python-середовище і встановіть необхідні пакети
4. **Акселерація апаратного забезпечення**: Налаштуйте прискорення GPU/NPU, якщо доступне
5. **Інтеграція MCP**: Налаштуйте сервери Model Context Protocol, якщо потрібно

## Початок роботи з AI Toolkit

### Короткий посібник із запуску

Рекомендуємо почати з моделей, розміщених на GitHub, для максимально плавного досвіду:

1. **Встановлення**: Дотримуйтесь [інструкції з встановлення](https://code.visualstudio.com/docs/intelligentapps/overview#_install-and-setup), щоб налаштувати AI Toolkit для вашого пристрою
2. **Пошук моделей**: У дереві розширення виберіть **CATALOG > Models** для огляду доступних моделей
3. **Моделі GitHub**: Починайте з моделей, розміщених на GitHub, для оптимальної інтеграції
4. **Тестування у Playground**: З будь-якої картки моделі виберіть **Try in Playground** для початку експериментів із можливостями моделей

### Крок за кроком розробка Edge AI

#### Крок 1: Дослідження та вибір моделі
1. Відкрийте вигляд AI Toolkit на панелі активності VS Code
2. Перегляньте каталог моделей, щоб знайти моделі, придатні для периферійного розгортання
3. Фільтруйте за провайдером (GitHub, ONNX, Ollama) відповідно до ваших вимог до периферії
4. Використовуйте **Try in Playground** для негайного тестування можливостей моделей

#### Крок 2: Розробка агента
1. Використовуйте **Prompt (Agent) Builder** для створення AI-агентів, оптимізованих для периферії
2. Генеруйте початкові запити за допомогою описів природною мовою
3. Ітеруйте та вдосконалюйте запити на основі відповідей моделей
4. Інтегруйте інструменти MCP для розширених можливостей агентів


#### Крок 3: Тестування та оцінка
1. Використовуйте **Bulk Run** для тестування кількох запитів на вибраних моделях
2. Запускайте агентів з тестовими випадками для перевірки функціональності
3. Оцінюйте точність і продуктивність за допомогою вбудованих або користувацьких метрик
4. Порівнюйте різні моделі та конфігурації

#### Крок 4: Тонке налаштування та оптимізація
1. Налаштовуйте моделі для специфічних випадків використання на периферії
2. Застосовуйте домен-специфічне тонке налаштування
3. Оптимізуйте з урахуванням обмежень розгортання на периферії
4. Версіонуйте та порівнюйте різні конфігурації агентів

#### Крок 5: Підготовка до розгортання
1. Генеруйте код, готовий до виробництва, за допомогою Agent Builder
2. Налагоджуйте підключення до серверів MCP для виробничого використання
3. Готуйте пакети для розгортання на периферійних пристроях
4. Конфігуруйте моніторинг та метрики оцінювання

## Найкращі практики розробки Edge AI

### Вибір моделі
- **Обмеження за розміром**: Вибирайте моделі, що поміщаються у межі пам’яті цільових пристроїв
- **Швидкість висновку**: Віддавайте перевагу моделям з швидким часом висновку для додатків у реальному часі
- **Компроміс точності**: Балансуйте точність моделі з ресурсними обмеженнями
- **Сумісність форматів**: Віддавайте перевагу ONNX або форматам, оптимізованим для обладнання, для розгортання на периферії

### Техніки оптимізації
- **Квантування**: Використовуйте квантування INT8 або INT4 для зменшення розміру моделі та покращення швидкості
- **Прутинг**: Видаляйте непотрібні параметри моделі для зниження обчислювальних вимог
- **Дистиляція знань**: Створюйте менші моделі з підтриманням продуктивності великих
- **Аппаратне прискорення**: Використовуйте NPU, GPU або спеціалізовані прискорювачі, якщо вони доступні

### Робочий процес розробки
- **Ітеративне тестування**: Часто тестуйте в умовах, наближених до периферії, під час розробки
- **Моніторинг продуктивності**: Постійно контролюйте використання ресурсів і швидкість висновку
- **Контроль версій**: Відстежуйте версії моделей та налаштування оптимізації
- **Документування**: Документуйте всі рішення щодо оптимізації та компроміси продуктивності

### Особливості розгортання
- **Моніторинг ресурсів**: Контролюйте пам’ять, CPU та витрати енергії у виробництві
- **Стратегії резервного копіювання**: Реалізуйте механізми відкату у разі збоїв моделі
- **Механізми оновлення**: Плануйте оновлення моделей та управління версіями
- **Безпека**: Забезпечуйте відповідні заходи безпеки для застосунків Edge AI

## Інтеграція з фреймворками Edge AI

### ONNX Runtime
- **Кросплатформене розгортання**: Розгортайте ONNX-моделі на різних платформах периферії
- **Оптимізація під обладнання**: Використовуйте оптимізації, специфічні для апаратного забезпечення ONNX Runtime
- **Підтримка мобільних пристроїв**: Використовуйте ONNX Runtime Mobile для застосунків на смартфонах і планшетах
- **Інтеграція з IoT**: Розгортайте на IoT-пристроях за допомогою легких дистрибутивів ONNX Runtime

### Windows ML
- **Пристрої Windows**: Оптимізуйте для пристроїв Edge на базі Windows та ПК
- **Прискорення NPU**: Використовуйте Neural Processing Units на пристроях Windows
- **DirectML**: Використовуйте DirectML для прискорення на GPU у Windows
- **Інтеграція UWP**: Інтегруйте з Universal Windows Platform-застосунками

### TensorFlow Lite
- **Оптимізація для мобільних**: Розгортайте моделі TensorFlow Lite на мобільних та вбудованих пристроях
- **Апаратні делегати**: Використовуйте спеціалізовані апаратні делегати для прискорення
- **Мікроконтролери**: Розгортайте на мікроконтролерах за допомогою TensorFlow Lite Micro
- **Кросплатформена підтримка**: Розгортайте на Android, iOS та вбудованих Linux-системах

### Azure IoT Edge
- **Гібрид хмари та периферії**: Поєднуйте хмарне навчання з висновком на периферії
- **Розгортання модулів**: Розгортайте AI-моделі як модулі IoT Edge
- **Управління пристроями**: Управляйте периферійними пристроями й оновленнями моделей дистанційно
- **Телеметрія**: Збирайте дані про продуктивність та метрики моделей з периферійних розгортань

## Розширені сценарії Edge AI

### Розгортання множинних моделей
- **Ансамблі моделей**: Розгортайте кілька моделей для підвищення точності або резервування
- **A/B тестування**: Одночасно тестуйте різні моделі на периферійних пристроях
- **Динамічний вибір**: Обирайте моделі залежно від поточних умов пристрою
- **Спільне використання ресурсів**: Оптимізуйте використання ресурсів між кількома розгорнутими моделями

### Федеративне навчання
- **Розподілене навчання**: Навчайте моделі на кількох периферійних пристроях
- **Захист приватності**: Залишайте дані для навчання локально, обмінюючись лише покращеннями моделей
- **Спільне навчання**: Дозвольте пристроям навчатися на основі колективного досвіду
- **Координація Edge-Cloud**: Координуйте навчання між периферійними пристроями та хмарною інфраструктурою

### Обробка в реальному часі
- **Обробка потоків**: Обробляйте безперервні потоки даних на периферійних пристроях
- **Низька затримка висновку**: Оптимізуйте для мінімальної затримки висновку
- **Пакетна обробка**: Ефективно обробляйте пакети даних на периферії
- **Адаптивна обробка**: Налаштовуйте обробку залежно від поточних можливостей пристрою

## Усунення неполадок розробки Edge AI

### Поширені проблеми
- **Обмеження пам’яті**: Модель надто велика для пам’яті цільового пристрою
- **Швидкість висновку**: Висновок моделі занадто повільний для вимог реального часу
- **Зниження точності**: Оптимізація неприйнятно знижує точність моделі
- **Несумісність апаратури**: Модель не сумісна з цільовим апаратним забезпеченням

### Стратегії налагодження
- **Профілювання продуктивності**: Використовуйте функції трасування AI Toolkit для виявлення вузьких місць
- **Моніторинг ресурсів**: Контролюйте використання пам’яті та CPU під час розробки
- **Поступове тестування**: Тестуйте оптимізації поступово для ізоляції проблем
- **Симуляція апаратури**: Використовуйте інструменти розробки для імітації цільового обладнання

### Рішення з оптимізації
- **Додаткове квантування**: Застосовуйте більш агресивні методи квантування
- **Архітектура моделі**: Розглядайте різні архітектури моделей, оптимізовані для периферії
- **Оптимізація передобробки**: Оптимізуйте обробку даних з урахуванням обмежень периферії
- **Оптимізація висновку**: Використовуйте апаратно-специфічні оптимізації висновку

## Висновок

AI Toolkit для Visual Studio Code є комплексною платформою для сучасної розробки AI, надаючи ефективні можливості розробки агентів, які особливо корисні для застосувань Edge AI. Завдяки широкому каталогу моделей, що підтримують провайдерів Anthropic, OpenAI, GitHub і Google, а також локальному виконанню через ONNX та Ollama, цей інструментарій пропонує гнучкість, потрібну для різноманітних сценаріїв розгортання на периферії.

Сила інструменту полягає в інтегрованому підході — від відкриття моделей та експериментів у Playground до складної розробки агентів з Prompt Builder, комплексної оцінки та безперебійної інтеграції інструментів MCP. Для розробників Edge AI це означає швидке прототипування й тестування AI агентів перед розгортанням на периферії з можливістю швидко ітеративно оптимізувати під обмежені ресурси.

Головні переваги для розробки Edge AI включають:
- **Швидке експериментування**: Швидке тестування моделей і агентів перед розгортанням на периферії
- **Гнучкість мульти-провайдерів**: Доступ до моделей різних джерел для пошуку оптимальних рішень периферії
- **Локальна розробка**: Тестування з ONNX та Ollama для офлайн і конфіденційної розробки
- **Готовність до виробництва**: Генерація коду, готового до виробництва, та інтеграція з зовнішніми інструментами через MCP
- **Комплексна оцінка**: Використання вбудованих і користувацьких метрик для верифікації продуктивності Edge AI

Оскільки AI продовжує рухатися до сценаріїв розгортання на периферії, AI Toolkit для VS Code забезпечує середовище розробки та робочий процес, необхідні для створення, тестування та оптимізації інтелектуальних додатків для умов з обмеженими ресурсами. Незалежно від того, чи ви розробляєте IoT-рішення, мобільні AI-додатки чи вбудовані інтелектуальні системи, широкий набір функцій та інтегрований робочий процес інструментарію підтримують увесь життєвий цикл розробки Edge AI.

Завдяки постійному розвитку та активній спільноті (понад 1,8 тис. зірок на GitHub) AI Toolkit залишається на передовій інструментів розробки AI, постійно еволюціонуючи, щоб відповідати потребам сучасних розробників AI у сценаріях розгортання на периферії.
