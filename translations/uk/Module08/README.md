# Модуль 08: Практична робота з Microsoft Foundry Local - Повний набір інструментів для розробника

## Огляд

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) представляє наступне покоління розробки edge AI, надаючи розробникам потужні інструменти для створення, розгортання та масштабування AI-застосунків локально з безшовною інтеграцією з Azure AI Foundry. Цей модуль забезпечує комплексне охоплення Foundry Local від інсталяції до розробки просунутих агентів.

**Ключові технології:**
- CLI та SDK Microsoft Foundry Local
- Інтеграція з Azure AI Foundry
- Інференс моделей на пристрої
- Локальне кешування та оптимізація моделей
- Архітектури на основі агентів

## Навчальні цілі

Пройшовши цей модуль, ви:

- **Опануєте Foundry Local**: інсталяція, налаштування та оптимізація для розробки на Windows 11
- **Розгортатимете різноманітні моделі**: запуск phi, qwen, deepseek та GPT моделей локально за допомогою команд CLI
- **Створюватимете рішення для продукції**: створення AI-застосунків з просунутим інжінірингом підказок та інтеграцією даних
- **Використовуватимете екосистему відкритого коду**: інтеграція моделей Hugging Face та внески спільноти
- **Розроблятимете AI-агентів**: створення інтелектуальних агентів з можливостями ґрунтування і оркестрації
- **Впроваджуватимете корпоративні патерни**: створення модульних, масштабованих AI-рішень для розгортання у продукції

## Вимоги

### Системні вимоги
- **Операційна система**: Windows 11 (22H2 або пізніша)
- **Оперативна пам'ять**: 16 ГБ RAM (32 ГБ рекомендовано для більших моделей)
- **Місце на диску**: 50 ГБ вільного простору для кешування моделей
- **Апаратне забезпечення**: рекомендовано пристрій з підтримкою NPU (Copilot+ PC), відеокарта необов’язкова
- **Мережа**: швидкий інтернет для початкового завантаження моделей

### Середовище розробки

- Visual Studio Code з розширенням AI Toolkit
- Python 3.10+ та pip
- Git для контролю версій
- PowerShell або Командний рядок
- Azure CLI (необов’язково для хмарної інтеграції)

### Передумови знань
- Базове розуміння концепцій ШІ/МН
- Знайомство з командним рядком
- Основи програмування на Python
- Концепції REST API
- Базові знання про запити та виведення моделей


**Проблеми з завантаженням моделей**
```powershell
# Перевірте доступні моделі
foundry model list --cached

# Завантажте відсутні моделі
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# Примусово перезавантажте, якщо потрібно
foundry model unload --all
foundry model run phi-4-mini
```

**Проблеми з залежностями**
```powershell
# Оновіть pip та перевстановіть
python -m pip install --upgrade pip
pip install -r requirements.txt --force-reinstall

# Для прикладів Node.js
npm cache clean --force
npm install
```
