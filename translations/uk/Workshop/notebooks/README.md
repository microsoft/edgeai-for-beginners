## 📖 Вступ

Ласкаво просимо до колекції **Робочих зошитів майстер-класу «EdgeAI для початківців»**. Ці інтерактивні ноутбуки Jupyter забезпечують практичний досвід навчання, де ви будете писати, виконувати та експериментувати з кодом Edge AI в режимі реального часу.

### Чому Jupyter ноутбуки?

На відміну від традиційних навчальних посібників, ці ноутбуки пропонують:

- **Інтерактивне навчання**: Запускайте код та миттєво бачте результати
- **Експерименти**: Модифікуйте параметри та спостерігайте зміни в режимі реального часу
- **Документування**: Вбудовані пояснення та markdown-клітинки допомагають розуміти концепції
- **Відтворюваність**: Повні робочі приклади для посилань та повторного використання
- **Візуалізація**: Переглядайте показники продуктивності, ембедінги і результати inline

### Що робить ці ноутбуки особливими?

Кожен ноутбук розроблений згідно з **кращими практиками, готовими для продакшну**:

✅ **Повне оброблення помилок** - Граційне зниження та інформативні повідомлення про помилки  
✅ **Підказки типів і документація** - Чіткі сигнатури функцій та докстрінги  
✅ **Моніторинг продуктивності** - Відстеження використання токенів і вимірювання затримок  
✅ **Модульний дизайн** - Повторно використовувані шаблони для адаптації у ваших проєктах  
✅ **Прогресивна складність** - Систематичне нарощування від попередніх сесій

## 🎯 Цілі навчання

### Основні навички, які ви здобудете

Працюючи з цими ноутбуками, ви опануєте:

1. **Управління локальними сервісами штучного інтелекту**
   - Налаштовувати й керувати Microsoft Foundry Local сервісами
   - Вибирати та завантажувати відповідні моделі для вашого обладнання
   - Моніторити використання ресурсів та оптимізувати продуктивність
   - Обробляти виявлення сервісів та перевірку стану

2. **Розробка AI-застосунків**
   - Впроваджувати локальні chat completions сумісні з OpenAI API
   - Створювати стрімінгові інтерфейси для кращого UX
   - Проєктувати ефективні prompt’и для малих мовних моделей
   - Інтегрувати локальні моделі у застосунки

3. **Retrieval Augmented Generation (RAG)**
   - Створювати семантичний пошук на основі векторних ембедінгів
   - Закріплювати відповіді LLM на спеціалізованих документах
   - Оцінювати якість RAG за метриками RAGAS
   - Масштабувати від прототипу до продакшну

4. **Оптимізація продуктивності**
   - Систематично проводити бенчмарки різних моделей
   - Вимірювати затримки, пропускну здатність та час першого токена
   - Порівнювати малі мовні моделі (SLM) та великі (LLM)
   - Вибирати оптимальні моделі, базуючись на співвідношенні продуктивність/якість

5. **Оркестрація мультиагентних систем**
   - Проєктувати спеціалізованих агентів для різних завдань
   - Впроваджувати управління пам’яттю агента та контекстом
   - Координувати роботу кількох агентів у складних робочих процесах
   - Створювати патерни координатора для співпраці агентів

6. **Інтелектуальний маршрутизатор моделей**
   - Впроваджувати виявлення намірів і пошук за шаблонами
   - Автоматично маршрутизувати запити до відповідних моделей
   - Будувати багатокрокові пайплайни (планування → виконання → уточнення)
   - Проєктувати масштабовані архітектури «модель як інструмент»

- **Місце на диску**: 10 ГБ і більше вільного простору для моделей
- **Обладнання**: CPU з AVX2; GPU (CUDA, Qualcomm NPU) опційно

**Вимоги до програмного забезпечення**:
- **Python 3.8+** з pip
- **Jupyter Notebook** або **VS Code** з розширенням Jupyter
- Встановлений і налаштований **Microsoft Foundry Local**
- **Git** (для клонування репозиторію)

### Кроки встановлення

#### 1. Встановлення Foundry Local

**Windows**:
```cmd
winget install Microsoft.FoundryLocal
```

**macOS**:
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

**Перевірка встановлення**:
```bash
foundry --version
```

#### 2. Налаштування середовища Python

```bash
# Перейдіть до каталогу Workshop
cd Workshop

# Створіть віртуальне середовище
python -m venv .venv

# Активуйте віртуальне середовище
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

# Встановіть залежності
pip install -r requirements.txt
```

#### 3. Запуск Foundry Local

```bash
# Завантажити модель (автоматично завантажується при необхідності)
foundry model run phi-4-mini

# Перевірити, чи працює служба
foundry service status
```

#### 4. Запуск Jupyter

```bash
# Запустіть Jupyter Notebook
jupyter notebook notebooks/

# Або використовуйте VS Code з розширенням Jupyter
code notebooks/
```

### Швидка перевірка

Виконайте це у Python клітинці для перевірки налаштувань:

```python
from foundry_local import FoundryLocalManager
import openai

# Ініціалізувати менеджер (автоматично знаходить сервіс)
manager = FoundryLocalManager("phi-4-mini")

# Налаштувати клієнта OpenAI
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Тестувати завершення чату
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**Очікуваний результат**: привітання від локальної моделі.
