## Вступ

Ласкаво просимо до посібника з вивчення EdgeAI для початківців! Цей документ призначений допомогти вам ефективно орієнтуватися у навчальних матеріалах курсу та максимально покращити ваш досвід навчання. Він містить структуровані навчальні шляхи, рекомендовані графіки занять, ключові підсумки концепцій і додаткові ресурси для поглиблення розуміння технологій Edge AI.

Це компактний курс тривалістю 20 годин, який надає основні знання про EdgeAI у зручному для часу форматі, що робить його ідеальним для зайнятих професіоналів та студентів, які хочуть швидко отримати практичні навички у цій новій сфері.

## Огляд курсу

Цей курс складається з восьми комплексних модулів:

0. **Вступ до EdgeAI** — основи та контекст із прикладами застосувань у галузі та навчальними цілями
1. **Основи EdgeAI та трансформація** — розуміння базових концепцій і технологічних змін
2. **Основи малих мовних моделей (SLM)** — ознайомлення з різними сімействами SLM та їх архітектурою
3. **Розгортання малих мовних моделей** — впровадження практичних стратегій розгортання
4. **Конвертація формату моделі та квантизація** — просунута оптимізація з використанням 6 фреймворків, включно з OpenVINO
5. **SLMOps — операції з малими мовними моделями** — управління життєвим циклом виробництва та розгортання
6. **Агентні системи SLM** — AI агенти, функціональні виклики та протокол контексту моделі
7. **Приклади реалізації EdgeAI** — AI Toolkit, розробка для Windows і платформозалежні реалізації
8. **Microsoft Foundry Local — повний набір інструментів для розробників** — локальна розробка першочергово з гібридною інтеграцією Azure (Модуль 08)

### Області вивчення

#### Розділ 1: Парадигма та визначення Edge AI
- **Пріоритетні концепти**: 
  - Edge AI проти традиційної обробки в хмарі
  - Конвергенція апаратного забезпечення, оптимізації моделей та бізнес-вимог
  - Розгортання AI в реальному часі, із забезпеченням конфіденційності та ефективністю витрат

#### Розділ 2: Галузеві застосування
- **Пріоритетні концепти**: 
  - Виробництво та Індустрія 4.0: передбачуване обслуговування та контроль якості
  - Охорона здоров’я: діагностична візуалізація та моніторинг пацієнтів
  - Автономні системи: безпілотні транспортні засоби та перевезення
  - Розумні міста: управління трафіком та громадська безпека
  - Споживчі технології: смартфони, носимі пристрої та розумні будинки

#### Розділ 3: Основи малих мовних моделей
- **Пріоритетні концепти**: 
  - Характеристики SLM та порівняння продуктивності
  - Ефективність параметрів проти можливостей моделей
  - Обмеження розгортання на периферії та стратегії оптимізації

#### Розділ 4: Освітня структура та кар’єрний шлях
- **Пріоритетні концепти**: 
  - Архітектура курсу та поступовий підхід до освоєння
  - Технічні навички та практичні цілі впровадження

## Ідеї для міні-проєктів

Розгляньте можливість виконання одного з цих проєктів для практики концепцій EdgeAI (кожен розрахований на 2-4 години):

### Проєкти для початківців (2-3 години кожен)
1. **Edge Text Assistant**: Створіть простий офлайн інструмент для доповнення тексту, використовуючи невелику мовну модель
2. **Панель порівняння моделей**: Побудуйте базову візуалізацію показників продуктивності різних SLM
3. **Експеримент з оптимізації**: Виміряйте вплив різних рівнів квантизації на ту саму базову модель

### Проєкти середнього рівня (3-4 години кожен)
4. **Робочий процес AI Toolkit**: Використайте VS Code AI Toolkit для оптимізації та розгортання моделі від початку до кінця
5. **Додаток Windows AI Foundry**: Створіть Windows-додаток з використанням Phi Silica API та оптимізації NPU
6. **Кросплатформене розгортання**: Розгорніть одну й ту ж оптимізовану модель на Windows (OpenVINO) та мобільних пристроях (.NET MAUI)
7. **Агент із можливістю виклику функцій**: Створіть AI агента з функціями виклику для edge сценаріїв

### Проєкти просунутого рівня інтеграції (4-5 годин кожен)
8. **Конвеєр оптимізації OpenVINO**: Реалізуйте повну оптимізацію моделі з використанням інструментів NNCF та GenAI
9. **Конвеєр SLMOps**: Реалізуйте повний життєвий цикл моделі від тренування до розгортання на edge
10. **Система з багатьма моделями для edge**: Розгорніть кілька спеціалізованих моделей, що працюють разом на edge апаратурі
11. **Система інтеграції MCP**: Створіть агентську систему з використанням Model Context Protocol для взаємодії з інструментами
