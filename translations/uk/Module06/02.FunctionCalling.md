## Що таке виклик функцій?

Виклик функцій — це потужна можливість, яка дозволяє малим мовним моделям (SLMs) взаємодіяти з зовнішніми інструментами, API та сервісами. Замість того, щоб обмежуватись навчальними даними, SLM можуть:

- **Підключатися до зовнішніх API** (сервіси погоди, бази даних, пошукові системи)
- **Виконувати конкретні функції** на підставі запитів користувача
- **Отримувати актуальну інформацію в реальному часі** з різних джерел
- **Виконувати обчислювальні завдання** за допомогою спеціалізованих інструментів
- **Ланцюжити кілька операцій** для складних робочих процесів

Ця можливість перетворює SLM зі статичних генераторів тексту на динамічних AI-агентів, здатних виконувати реальні завдання.

## Як працює виклик функцій

Процес виклику функцій слідує систематичному робочому процесу:

### 1. Інтеграція інструментів
- **Зовнішні інструменти**: SLM можуть підключатися до API погоди, баз даних, веб-сервісів та інших зовнішніх систем
- **Визначення функцій**: Кожен інструмент визначено зі специфічними параметрами, форматами вводу/виводу та описами
- **Сумісність API**: Інструменти інтегруються через стандартизовані інтерфейси (REST API, SDK тощо)

### 2. Визначення функції
Функції визначаються з трьома ключовими компонентами:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Виявлення наміру
- **Обробка природної мови**: SLM аналізує ввід користувача, щоб зрозуміти намір
- **Підбір функції**: Визначає, яка (які) функція(ї) потрібна(і) для виконання запиту
- **Витяг параметрів**: Ідентифікує та витягує необхідні параметри з повідомлення користувача

### 4. Генерація JSON-виводу
SLM генерує структурований JSON, що містить:
- Назву функції для виклику
- Необхідні параметри з відповідними значеннями
- Контекст виконання та метадані

### 5. Зовнішнє виконання
- **Перевірка параметрів**: Переконується, що всі необхідні параметри присутні та правильно відформатовані
- **Виконання функції**: Додаток виконує вказану функцію з наданими параметрами
- **Обробка помилок**: Керує відмовами, тайм-аутами та некоректними відповідями

### 6. Інтеграція відповіді
- **Обробка результату**: Вивід функції повертається до SLM
- **Інтеграція контексту**: SLM включає результати у свою відповідь
- **Комунікація з користувачем**: Подає інформацію в природній, розмовній формі

## Сценарії застосування

### Отримання даних
Перетворення запитів природною мовою у структуровані API виклики:
- **"Покажи мої останні замовлення"** → Запит до бази даних з ID користувача та фільтрами за датою
- **"Яка погода в Токіо?"** → Виклик API погоди з параметром локації
- **"Знайди листи від Джона з минулого тижня"** → Запит сервісу електронної пошти з фільтрами відправника та дати

### Виконання операцій
Перетворення запитів користувача у конкретні виклики функцій:
- **"Заплануй зустріч на завтра о 14:00"** → Інтеграція з календарним API
- **"Надішліть повідомлення команді"** → API платформи для спілкування
- **"Створити резервну копію моїх файлів"** → Операції з файловою системою

### Обчислювальні завдання
Обробка складних математичних або логічних операцій:
- **"Обчислити складні відсотки на $10,000 під 5% на 10 років"** → Фінансова обчислювальна функція
- **"Проаналізувати цей набір даних на тренди"** → Інструменти статистичного аналізу
- **"Оптимізувати маршрут доставки"** → Алгоритми оптимізації маршрутів

### Робочі процеси обробки даних
Ланцюжок кількох викликів функцій для складних операцій:
1. **Отримати дані** з кількох джерел
2. **Парсинг і валідація** інформації
3. **Трансформація** даних у потрібний формат
4. **Збереження результатів** у відповідних системах
5. **Генерація звітів** або візуалізацій

### Інтеграція UI/UX
Забезпечує динамічне оновлення інтерфейсів:
- **"Покажи дані продажів на панелі"** → Генерація та відображення графіків
- **"Оновити карту новими локаціями"** → Інтеграція геопросторових даних
- **"Оновити відображення інвентарю"** → Синхронізація даних у реальному часі

## Робота з викликом функцій Qwen3

Qwen3 пропонує розширені можливості виклику функцій з відмінною продуктивністю та гнучкістю. Ось як його впровадити:

### Використання фреймворку Qwen-Agent

Qwen-Agent надає високорівневий фреймворк, що спрощує імплементацію виклику функцій:

#### Встановлення
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### Базове налаштування

```python
import os
from qwen_agent.agents import Assistant

# Налаштувати LLM
llm_cfg = {
    'model': 'Qwen3-8B',
    # Варіант 1: Використовувати Alibaba Model Studio
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # Варіант 2: Використовувати локальне розгортання
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'EMPTY',
    
    # Необов’язкова конфігурація для режиму мислення
    'generate_cfg': {
        'thought_in_content': True,  # Включити логіку у відповідь
    }
}

# Визначити інструменти за допомогою MCP (Протокол контексту моделі)
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # Вбудований інструмент виконання коду
]

# Створити асистента
bot = Assistant(llm=llm_cfg, function_list=tools)

# Приклад використання
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# Згенерувати відповідь з викликом функції
for response in bot.run(messages=messages):
    print(response)
```

### Реалізація власних функцій

Ви також можете визначати власні функції для Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Імітувати виклик API погоди
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Використати спеціальний інструмент
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

## Локальна інтеграція Foundry Local

Foundry Local від Microsoft забезпечує OpenAI-сумісний API для запуску моделей локально з покращеною приватністю та продуктивністю.

### Налаштування та встановлення

#### Windows
Завантажте інсталятор з [сторінки релізів Foundry Local](https://github.com/microsoft/Foundry-Local/releases) та дотримуйтесь інструкцій зі встановлення.

#### macOS
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

#### Базове використання

```python
import openai
from foundry_local import FoundryLocalManager

# Ініціалізувати з псевдонімом моделі
alias = "phi-3.5-mini"  # Або будь-яка інша підтримувана модель
manager = FoundryLocalManager(alias)

# Створити клієнта OpenAI, який вказує на локальний кінцевий пункт
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Визначити функції для моделі
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Виконати запит з викликом функції
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

### Розширені функції Foundry Local

#### Управління моделями
```bash
# Перелік доступних моделей
foundry model list

# Завантажити конкретну модель
foundry model download phi-3.5-mini

# Запустити модель інтерактивно
foundry model run phi-3.5-mini

# Видалити модель з кешу
foundry model remove phi-3.5-mini

# Видалити всі кешовані моделі
foundry model remove "*"
```

#### Оптимізація продуктивності
Foundry Local автоматично обирає найкращий варіант моделі для вашого апаратного забезпечення:
- **CUDA GPU**: Завантажує моделі, оптимізовані для GPU
- **Qualcomm NPU**: Використовує варіанти з апаратним прискоренням NPU
- **Тільки CPU**: Вибирає моделі, оптимізовані для процесора

## Кращі практики та усунення несправностей

### Кращі практики при визначенні функцій

#### 1. Чітке і описове іменування
```python
# Добре
{
    "name": "get_stock_price",
    "description": "Retrieve current stock price for a given symbol"
}

# Уникати
{
    "name": "get_data", 
    "description": "Gets data"
}
```

#### 2. Комплексне визначення параметрів
```python
{
    "name": "send_email",
    "description": "Send an email message to specified recipients",
    "parameters": {
        "to": {
            "type": "array",
            "items": {"type": "string"},
            "description": "List of recipient email addresses",
            "required": True
        },
        "subject": {
```

```python
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Перевірте існування функції
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Перевірте ліміти швидкості
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Перевірте параметри
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Виконайте функцію
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Запишіть успішне виконання
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Запишіть невдале виконання
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Скиньте лічильник, якщо минула хвилина
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Перевірте, чи не перевищено ліміт
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Перевірте обов’язкові параметри
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Перевірте типи параметрів і обмеження
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]

                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )

                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )

                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"

                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
        
        return FunctionResult(success=True)

    def get_function_definitions(self) -> List[Dict]:
        """Get OpenAI-compatible function definitions for all registered functions"""
        definitions = []
        
        for func_name, func_info in self.functions.items():
            definition = {
                'name': func_name,
                'description': func_info['description'],
                'parameters': {
                    'type': 'object',
                    'properties': {},
                    'required': []
                }
            }
            
            for param_name, param_info in func_info['parameters'].items():
                definition['parameters']['properties'][param_name] = {
                    'type': param_info['type'],
                    'description': param_info.get('description', '')
                }
                
                if 'enum' in param_info:

                if param_info.get('required', False):
                    definition['parameters']['required'].append(param_name)
            
            definitions.append(definition)
```

## Висновок

Виклик функцій у малих мовних моделях — це кардинальна зміна парадигми від статичних AI-асистентів до динамічних, здатних агентів, які можуть взаємодіяти з реальним світом. Цей посібник охопив:

### Основні висновки

1. **Базове розуміння**: Виклик функцій дозволяє розширювати SLM за межі навчальних даних шляхом підключення до зовнішніх інструментів і сервісів.

2. **Гнучкість імплементації**: Існують різні підходи — від низькорівневих реалізацій з кастомними шаблонами до високорівневих фреймворків, таких як Qwen-Agent і Foundry Local.

3. **Виробничі аспекти**: Під час впровадження в підприємствах слід враховувати обробку помилок, обмеження частоти, безпеку та аудит логів.

4. **Оптимізація продуктивності**: Правильне проектування функцій, ефективне виконання та розумне кешування значно покращують час відгуку.

### Майбутні напрямки

У міру розвитку технології SLM можна очікувати:

- **Покращення точності виклику функцій**: Кращий розпізнавання наміру та витяг параметрів
- **Посилення паралельної обробки**: Більш складна оркестрація множинних функцій
- **Вдосконалення стандартів інтеграції**: Стандартизовані протоколи для інтеграції інструментів
- **Розширені функції безпеки**: Покращена аутентифікація та авторизація
- **Розширення екосистеми**: Зростаюча бібліотека готових функцій та інтеграцій
