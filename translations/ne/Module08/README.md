# मोड्युल ०८: माइक्रोसफ्ट फाउन्ड्री लोकलसँग हातैले काम गर्ने - पूर्ण विकासकर्ता उपकरण किट

## अवलोकन

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) एज एआई विकासको अर्को पुस्तालाई प्रतिनिधित्व गर्दछ, विकासकर्ताहरूलाई शक्तिशाली उपकरणहरू प्रदान गर्दै जसले उनीहरूलाई स्थानीय रूपमा एआई अनुप्रयोगहरू निर्माण, परिनियोजन, र स्केल गर्न सक्षम गर्दछ, साथै Azure AI Foundry सँग निरन्तर समेकन कायम राख्न। यो मोड्युल स्थापना देखि उन्नत एजेन्ट विकाससम्म फाउन्ड्री लोकलको व्यापक कभर प्रदान गर्दछ।

**मुख्य प्रविधिहरू:**
- माइक्रोसफ्ट फाउन्ड्री लोकल CLI र SDK
- Azure AI Foundry समाकलन
- उपकरणमा मोडेल अनुमान
- स्थानीय मोडेल क्याचिङ र अनुकूलन
- एजेन्ट-आधारित वास्तुकला

## सिकाइ उद्देश्यहरू

यस मोड्युल पूरा गरेर, तपाईं:

- **फाउन्ड्री लोकलमा दक्षता हासिल गर्नुहोस्**: Windows 11 विकासका लागि स्थापना, कन्फिगरेसन, र अनुकूलन गर्नुहोस्
- **विविध मोडेलहरू परिनियोजन गर्नुहोस्**: CLI कमाण्डहरूको माध्यमबाट phi, qwen, deepseek, र GPT मोडेलहरू स्थानीय रूपमा चलाउनुहोस्
- **उत्पादन समाधानहरू निर्माण गर्नुहोस्**: उन्नत प्रॉम्प्ट इन्जिनियरिङ र डेटा समाकलन सहित एआई अनुप्रयोगहरू सिर्जना गर्नुहोस्
- **ओपन-सोर्स इकोसिस्टमको उपयोग गर्नुहोस्**: Hugging Face मोडेलहरू र समुदायका योगदानहरू समाकलन गर्नुहोस्
- **एआई एजेन्टहरू विकास गर्नुहोस्**: ग्राउन्डिङ र अर्खेस्ट्रेसन क्षमताहरू भएको बौद्धिक एजेन्टहरू बनाउनुहोस्
- **उद्यम ढाँचाहरू लागू गर्नुहोस्**: उत्पादन परिनियोजनका लागि मोडुलर, स्केलेबल एआई समाधानहरू सिर्जना गर्नुहोस्

## पूर्वआवश्यकताहरू

### प्रणाली आवश्यकताहरू
- **अपरेटिङ सिस्टम**: Windows 11 (२२H2 वा पछि)
- **मेमोरी**: १६GB RAM (ठूला मोडेलहरूको लागि ३२GB सिफारिस गरिएको)
- **स्टोरेज**: मोडेल क्याचिङका लागि ५०GB खाली ठाउँ
- **हार्डवेयर**: NPU-सक्षम उपकरण सिफारिस गरिएको (Copilot+ PC), GPU वैकल्पिक
- **नेटवर्क**: प्रारम्भिक मोडेल डाउनलोडका लागि उच्च गति इन्टरनेट

### विकास वातावरण

- Visual Studio Code AI Toolkit विस्तारसँग
- Python 3.10+ र pip
- संस्करण नियन्त्रणका लागि Git
- PowerShell वा Command Prompt
- Azure CLI (क्लाउड एकीकरणका लागि वैकल्पिक)

### ज्ञान पूर्वआवश्यकताहरू
- AI/ML अवधारणाहरूको आधारभूत बुझाइ
- कमान्ड लाइन परिचय
- Python प्रोग्रामिङको आधारभूत ज्ञान
- REST API अवधारणाहरू
- प्रॉम्प्टिङ र मोडल अनुमानको आधारभूत ज्ञान

## सिकाइ नतिजाहरू

यस मोड्युल पूरा गरेपछि, तपाईं सक्षम हुनुहुनेछ:

### प्राविधिक दक्षता
- **डिप्लोय र व्यवस्थापन गर्नुहोस्**: विकास र उत्पादन वातावरणमा Foundry Local स्थापना
- **मोडलहरू एकीकृत गर्नुहोस्**: Microsoft, Hugging Face, र समुदाय स्रोतहरूका विभिन्न मोडल परिवारहरूसँग सहज रूपमा काम गर्नुहोस्
- **एप्लिकेसनहरू निर्माण गर्नुहोस्**: उन्नत सुविधाहरू र अनुकूलनसहित उत्पादन-तयार AI एप्लिकेसनहरू सिर्जना गर्नुहोस्
- **एजेन्टहरू विकास गर्नुहोस्**: आधारभूत, तर्कसंगत र उपकरण एकीकरण सहित जटिल AI एजेन्टहरू कार्यान्वयन गर्नुहोस्

### रणनीतिक समझ
- **आर्किटेक्चर निर्णयहरू**: स्थानीय बनाम क्लाउड डिप्लोयमेन्ट बीच सूचित छनोट गर्नुहोस्
- **प्रदर्शन अनुकूलन**: विभिन्न हार्डवेयर कन्फिगरेसनमा अनुमान प्रदर्शन अनुकूलन गर्नुहोस्
- **उद्यम स्केलिङ**: स्थानीय प्रोटोटाइपहरूबाट उद्यम डिप्लोयमेन्टसम्म एप्लिकेसनहरू डिजाइन गर्नुहोस्
- **गोपनीयता र सुरक्षा**: स्थानीय अनुमानसहित गोपनीयता-संरक्षित AI समाधानहरू कार्यान्वयन गर्नुहोस्

### नवप्रवर्तन क्षमता
- **छिटो प्रोटोटाइपिङ**: सम्पूर्ण १० नमुना ढाँचाहरूमा छिटो AI एप्लिकेसन अवधारणाहरू निर्माण र परीक्षण गर्नुहोस्
- **समुदाय एकीकरण**: खुला स्रोत मोडलहरू उपयोग गर्नुहोस् र पारिस्थितिकी तन्त्रमा योगदान गर्नुहोस्
- **उन्नत ढाँचाहरू**: RAG, एजेन्टहरू, र उपकरण एकीकरण सहित नयाँतम AI ढाँचाहरू कार्यान्वयन गर्नुहोस्
- **फ्रेमवर्क दक्षता**: LangChain, Semantic Kernel, Chainlit, र Electron सँग विशेषज्ञ स्तरको एकीकरण
- **उत्पादन डिप्लोयमेन्ट**: स्थानीय प्रोटोटाइपहरूबाट उद्ध्यम प्रणालीसम्म मापनयोग्य AI समाधानहरू डिप्लोय गर्नुहोस्
- **भविष्य-तयार विकास**: उदाउँदो AI प्रविधिहरू र ढाँचाहरूका लागि तयार एप्लिकेसनहरू बनाउनुहोस्
