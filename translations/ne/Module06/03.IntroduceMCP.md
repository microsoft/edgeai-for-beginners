# खण्ड 03 - मोडल सन्दर्भ प्रोटोकल (MCP) एकीकरण

## MCP (मोडल सन्दर्भ प्रोटोकल) परिचय

मोडल सन्दर्भ प्रोटोकल (MCP) बाह्य प्रणालीहरूसँग एआई अनुप्रयोगहरू जडान गर्ने खुला-स्रोत मानक हो। MCP प्रयोग गरेर, Claude वा ChatGPT जस्ता एआई अनुप्रयोगहरूले डेटा स्रोतहरू (जस्तै, स्थानीय फाइलहरू, डाटाबेसहरू), उपकरणहरू (जस्तै, खोज इन्जिनहरू, क्यालकुलेटरहरू), र कार्यप्रवाहहरू (जस्तै, विशेष प्रॉम्प्टहरू) सँग जडान गर्न सक्छन्— जसले तिनीहरूलाई मुख्य जानकारी पहुँच गर्न र कार्यहरू प्रदर्शन गर्न सक्षम बनाउँछ।

MCP लाई एआई अनुप्रयोगहरूको लागि **USB-C पोर्ट जस्तो सोच्नुहोस्**। जसरी USB-C ले इलेक्ट्रोनिक उपकरणहरू जडान गर्ने मानकीकृत तरिका प्रदान गर्छ, त्यसैगरी MCP ले एआई अनुप्रयोगहरूलाई बाह्य प्रणालीहरूसँग जडान गर्ने मानकीकृत तरिका प्रदान गर्दछ।

### MCP के के सक्षम पार्न सक्छ?

MCP ले एआई अनुप्रयोगहरूका लागि शक्तिशाली क्षमता अनलक गर्दछ:

- **व्यक्तिगत एआई सहायकहरू**: एजेन्टहरूले तपाईंको Google क्यालेन्डर र Notion पहुँच गर्न सक्छन्, जसले अधिक व्यक्तिगत एआई सहायकको रूपमा कार्य गर्दछ
- **उन्नत कोड निर्माण**: Claude Code ले Figma डिजाइनको प्रयोग गरी पूर्ण वेब एप्लिकेशन निर्माण गर्न सक्छ
- **उद्यम डाटा एकीकरण**: उद्यम च्याटबोटहरूले संस्थाभरिका बहुविध डाटाबेसहरू सँग जडान गर्न सक्छन्, जसले प्रयोगकर्ताहरूलाई च्याटमार्फत डेटा विश्लेषण गर्न सक्षम बनाउँछ
- **सृजनात्मक कार्यप्रवाहहरू**: एआई मोडेलहरूले Blender मा 3D डिजाइनहरू सिर्जना गर्न सक्छन् र 3D प्रिन्टरको प्रयोग गरी तिनलाई प्रिन्ट गर्न सक्छन्
- **रियल-टाइम सूचना पहुँच**: बाह्य डेटा स्रोतहरूमा जडान गरी अद्यावधिक जानकारी प्राप्त गर्न
- **जटिल बहु-चरण कार्यहरू**: विभिन्न उपकरण र प्रणालीहरूलाई संयोजन गरी जटिल कार्यप्रवाहहरू सञ्चालन गर्न

### MCP किन महत्त्वपूर्ण छ?

MCP ले सम्पूर्ण परिसंघमा फाइदाहरू प्रदान गर्दछ:

**डेभलपर्सका लागि**: MCP ले एआई अनुप्रयोग वा एजेन्ट निर्माण गर्दा वा एकीकरण गर्दा विकास समय र जटिलता घटाउँछ।

**एआई अनुप्रयोगहरूको लागि**: MCP ले डेटा स्रोतहरू, उपकरणहरू र एपहरूसँगको पहुँच प्रदान गर्दछ जसले क्षमता वृद्धि गर्दछ र अन्त-प्रयोगकर्ता अनुभव सुधार गर्दछ।

**अन्त-प्रयोगकर्ताहरूका लागि**: MCP ले अधिक सक्षम एआई अनुप्रयोग वा एजेन्टहरू जन्माउँछ जसले तपाईंको डेटा पहुँच गर्न र आवश्यक परे तपाईंको तर्फबाट कार्यहरू गर्न सक्छन्।

## MCP मा सानो भाषा मोडेलहरू (SLMs)

सानो भाषा मोडेलहरू (SLMs) एआई वितरणको लागि एक प्रभावकारी उपाय प्रस्तुत गर्दछन्, जसले विभिन्न फाइदाहरू दिन्छ:

### SLMs का फाइदाहरू
- **स्रोत दक्षता**: कम कम्प्युटेशनल आवश्यकताहरू
- **चाँडो प्रतिक्रिया समय**: वास्तविक-समय अनुप्रयोगहरूको लागि कम ढिलाइ  
- **लागत प्रभावकारीता**: न्यूनतम पूर्वाधार आवश्यकताहरू
- **गोपनीयता**: डेटा प्रसारण बिना स्थानीय रूपमा चलाउन सकिन्छ
- **अनुकूलन**: विशिष्ट डोमेनहरूका लागि सजिलो फाइन-ट्यूनिङ

### किन SLMs MCP सँग राम्रो काम गर्छन्

SLMs लाई MCP सँग जोड्दा एउटा शक्तिशाली संयोजन सिर्जना हुन्छ जहाँ मोडेलका तर्क क्षमताहरू बाह्य उपकरणहरूले बढाइन्छ, र उनीहरूको सानो प्यारामिटर सङ्ख्या कार्यक्षमताबाट सम्हालिन्छ।

## Python MCP SDK अवलोकन

Python MCP SDK ले MCP-सक्षम अनुप्रयोगहरू निर्माण गर्न आधार प्रदान गर्दछ। SDK मा समावेश छन्:

- **क्लाइन्ट लाइब्रेरीहरू**: MCP सर्भरसँग जडान गर्न
- **सर्भर फ्रेमवर्क**: अनुकूल MCP सर्भरहरू सिर्जना गर्न
- **प्रोटोकल ह्याण्डलरहरू**: सञ्चार व्यवस्थापन गर्न
- **उपकरण एकीकरण**: बाह्य कार्यहरू सञ्चालन गर्न

## व्यवहारिक कार्यान्वयन: Phi-4 MCP क्लाइन्ट

Microsoft को Phi-4 मिनी मोडललाई MCP क्षमतासँग एकीकृत गरेर वास्तविक-विश्व कार्यान्वयन अन्वेषण गरौं।

### MCP वास्तुकला अवलोकन

MCP ले **क्लाइन्ट-सर्भर वास्तुकला** पछ्याउँछ जहाँ MCP होस्ट (जस्तै Claude Code वा Claude Desktop जस्ता एआई अनुप्रयोग) एउटाभन्दा बढी MCP सर्भरसँग जडान बनाउँछ। MCP होस्ट यो प्रत्येक MCP सर्भरको लागि एक MCP क्लाइन्ट सिर्जना गरेर पूरा गर्दछ।

#### प्रमुख सहभागीहरू

- **MCP होस्ट**: एआई अनुप्रयोग जुन एक वा बहुविध MCP क्लाइन्टहरूको समन्वय र व्यवस्थापन गर्छ
- **MCP क्लाइन्ट**: एउटा घटक जसले MCP सर्भरसँग जडान कायम राख्छ र MCP होस्टलाई प्रयोगको लागि सन्दर्भ प्राप्त गर्छ
- **MCP सर्भर**: एउटा कार्यक्रम जुन MCP क्लाइन्टहरूलाई सन्दर्भ प्रदान गर्छ

#### दुई-तह वास्तुकला

MCP दुई भिन्न तहहरूमा बनेको छ:

**डेटा तह**: JSON-RPC आधारित प्रोटोकल परिभाषित गर्दछ क्लाइन्ट-सर्भर सञ्चारको लागि, जसमा छन्:
- जीवनचक्र व्यवस्थापन (जडान सुरुवात, क्षमता वार्ता)
- मुख्य प्रिमिटिवहरू (उपकरणहरू, स्रोतहरू, प्रॉम्प्टहरू)
- क्लाइन्ट सुविधाहरू (साम्पलिङ, उत्सर्जन, लगिङ)
- उपयोगिता सुविधाहरू (सूचना, प्रगति ट्र्याकिङ)

**ट्रान्सपोर्ट तह**: सञ्चार संयन्त्र र च्यानल परिभाषित गर्दछ:
- **STDIO ट्रान्सपोर्ट**: स्थानीय प्रक्रियाहरूका लागि मानक इनपुट/आउटपुट स्ट्रिमहरू प्रयोग गर्दछ (उत्तम प्रदर्शन, कुनै नेटवर्क ओभरहेड छैन)
- **स्ट्रीमयोग्य HTTP ट्रान्सपोर्ट**: HTTP POST र वैकल्पिक Server-Sent Events प्रयोग गरेर दूरस्थ सर्भरहरूलाई समर्थन गर्दछ (मानक HTTP प्रमाणीकरण सक्षम)

```
┌─────────────────────────────────────┐
│           MCP Host                  │
│     (AI Application)                │
└─────────────────┬───────────────────┘
                  │
┌─────────────────┴───────────────────┐
│         MCP Client 1                │
│  ┌─────────────────────────────────┐ │
│  │        Data Layer               │ │
│  │  ├── Lifecycle Management       │ │
│  │  ├── Primitives (Tools/Resources)│ │
│  │  └── Notifications              │ │
│  └─────────────────────────────────┘ │
│  ┌─────────────────────────────────┐ │
│  │      Transport Layer           │ │
│  │  ├── STDIO Transport           │ │
│  │  └── HTTP Transport            │ │
│  └─────────────────────────────────┘ │
└─────────────────┬───────────────────┘
                  │
┌─────────────────┴───────────────────┐
│         MCP Server 1                │
│    (Local/Remote Context Provider)  │
└─────────────────────────────────────┘
```

### MCP मुख्य प्रिमिटिवहरू

MCP ले प्रिमिटिवहरू परिभाषित गर्दछ जसले निर्दिष्ट गर्छन् कि के प्रकारका सन्दर्भ जानकारी एआई अनुप्रयोगहरूसँग साझा गर्न सकिन्छ र कुन प्रकारका कार्यहरू प्रदर्शन गर्न सकिन्छ।

#### सर्भर प्रिमिटिवहरू

MCP ले तीन मुख्य प्रिमिटिवहरू परिभाषित गर्दछ जुन सर्भरहरूले उपलब्ध गराउन सक्छन्:

**उपकरणहरू**: कार्यान्वयन योग्य कार्यहरू जुन एआई अनुप्रयोगहरूले क्रियान्वयन गर्न सक्छन्
- उदाहरणहरू: फाइल अपरेशनहरू, API कलहरू, डाटाबेस सोधपुछ
- विधिहरू: `tools/list`, `tools/call`
- गतिशील खोज र कार्यान्वयनलाई समर्थन गर्छ

**स्रोतहरू**: डेटा स्रोतहरू जुन एआई अनुप्रयोगहरूलाई सन्दर्भ जानकारी प्रदान गर्छन्
- उदाहरणहरू: फाइल सामग्री, डाटाबेस रेकर्डहरू, API प्रतिक्रियाहरू
- विधिहरू: `resources/list`, `resources/read`
- संरचित डाटामा पहुँच सक्षम पार्छ

**प्रॉम्प्टहरू**: पुन: प्रयोग गर्न मिल्ने टेम्प्लेटहरू जसले भाषागत मोडेलहरूसँग अन्तरक्रिया संरचना गर्न मद्दत गर्छन्
- उदाहरणहरू: सिस्टम प्रॉम्प्टहरू, थोरै-शट उदाहरणहरू
- विधिहरू: `prompts/list`, `prompts/get`
- एआई अन्तरक्रिया ढाँचाहरूलाई मानकीकृत गर्छ

#### क्लाइन्ट प्रिमिटिवहरू

MCP ले क्लाइन्टहरूले प्रदान गर्न सक्ने प्रिमिटिवहरू पनि परिभाषित गर्छ ताकि धनी अन्तरक्रियाहरू सक्षम होउन्:

**साम्पलिङ**: सर्भरहरूले क्लाइन्टको एआई अनुप्रयोगबाट भाषागत मोडेल पूरकहरू अनुरोध गर्न पाउँछन्
- विधि: `sampling/complete`
- मोडल-स्वतन्त्र सर्भर विकास सक्षम गर्दछ
- होस्टको भाषागत मोडलमा पहुँच प्रदान गर्छ

**उत्प्रेरणा (Elicitation)**: सर्भरहरूले प्रयोगकर्ताबाट थप जानकारी अनुरोध गर्न सक्छन्
- विधि: `elicitation/request`
- प्रयोगकर्ता अन्तरक्रिया र पुष्टिकरण सक्षम गर्दछ
- गतिशील जानकारी सङ्कलन समर्थन गर्छ

**लगिङ**: सर्भरहरूले क्लाइन्टहरूलाई लग सन्देशहरू पठाउन सक्छन्
- डिबगिङ र अनुगमनका लागि प्रयोग हुन्छ
- सर्भर अपरेसनहरूमा दृश्यता प्रदान गर्छ

### MCP प्रोटोकल जीवनचक्र

#### सुरुवात र क्षमता वार्ता

MCP एउटा अवस्थासँग सम्बन्धित प्रोटोकल हो जसले जीवनचक्र व्यवस्थापन आवश्यक पर्दछ। सुरुवात प्रक्रियाले विभिन्न महत्वपूर्ण उद्देश्य पुरा गर्छ:

1. **प्रोटोकल संस्करण वार्ता**: दुबै क्लाइन्ट र सर्भरले उपयुक्त संस्करणहरू प्रयोग गर्छन् भनी सुनिश्चित गर्ने (जस्तै, "2025-06-18")
2. **क्षमता पत्ता लगाउने**: प्रत्येक पक्षले समर्थित सुविधाहरू र प्रिमिटिवहरू घोषणा गर्ने
3. **पहिचान विनिमय**: परिचय र संस्करण जानकारी प्रदान गर्ने

```python
# उदाहरण सुरुवात अनुरोध
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {
      "elicitation": {},  # क्लाइंटले प्रयोगकर्ता अन्तरक्रिया समर्थन गर्दछ
      "sampling": {}      # क्लाइंटले LLM पूरा गर्न सक्छ
    },
    "clientInfo": {
      "name": "edge-ai-client",
      "version": "1.0.0"
    }
  }
}
```

#### उपकरण पत्ता लगाउने र कार्यान्वयन

सुरुवात पछि, क्लाइन्टहरूले उपकरणहरू पत्ता लगाउन र कार्यान्वयन गर्न सक्छन्:

```python
# उपलब्ध उपकरणहरू पत्ता लगाउनुहोस्
tools_response = await session.list_tools()

# उपकरण सञ्चालन गर्नुहोस्
result = await session.call_tool(
    "weather_current",
    {
        "location": "San Francisco",
        "units": "imperial"
    }
)
```

#### वास्तविक-समय सूचनाहरू

MCP ले गतिशील अपडेटहरूका लागि वास्तविक-समय सूचनाहरू समर्थन गर्दछ:

```python
# उपकरणहरू परिवर्तन हुँदा सर्भरले सूचना पठाउँछ
{
  "jsonrpc": "2.0",
  "method": "notifications/tools/list_changed"
}

# क्लाइन्टले उपकरण सूची ताजा गरेर जवाफ दिन्छ
await session.list_tools()  # अद्यावधिक उपकरणहरू प्राप्त गर्नुहोस्
```

### चरण 4: प्रोग्रामिक प्रयोग

```python
import asyncio
from ghmodel_mcp_demo import OllamaClient, Phi4MiniMCPClient

async def automated_interaction():
    # MCP सर्भर प्यारामिटरहरू कन्फिगर गर्नुहोस्
    server_params = StdioServerParameters(
        command="npx",
        args=["@playwright/mcp@latest"],
        env=None,
    )
    
    # MCP क्लाइन्ट र प्रोसेस उपकरणहरू सिर्जना गर्नुहोस्
    async with Phi4MiniMCPClient(server_params) as mcp_client:
        tools = await process_mcp_tools(mcp_client)
        llm_client = OllamaClient()
        
        # उपकरण क्षमताहरू सहित प्रतिक्रिया उत्पन्न गर्नुहोस्
        response, messages = await llm_client.generate_response(
            "Help me automate a web task",
            tools
        )
        return response

# स्वचालन कार्यान्वयन गर्नुहोस्
result = asyncio.run(automated_interaction())
print(result)
```

- **[MCP रेफरेन्स सर्भर कार्यान्वयनहरू](https://github.com/modelcontextprotocol/servers)**: MCP सर्भरहरूको रेफरेन्स कार्यान्वयनहरू

**क्लाइन्टहरू बनाउनुहोस्**: [अनुप्रयोगहरू विकास गर्नुहोस्](https://modelcontextprotocol.io/docs/develop/build-client) जो MCP सर्भरसँग जडान हुन्छन्

**धारणाहरू सिक्नुहोस्**: [MCP का मुख्य अवधारणाहरू बुझ्नुहोस्](https://modelcontextprotocol.io/docs/learn/architecture) र वास्तुकला

## निष्कर्ष

MCP सँग एकीकृत SLMs ले एआई अनुप्रयोग विकासमा एक नयाँ परिदृश्य प्रस्तुत गर्छ। साना मोडेलहरूको दक्षता र बाह्य उपकरणहरूको शक्तिलाई संयोजन गरेर, विकासकर्ताहरूले स्रोत-प्रभावकारी र उच्च क्षमताका बुद्धिमान प्रणालीहरू निर्माण गर्न सक्छन्।

मोडल सन्दर्भ प्रोटोकलले एआई अनुप्रयोगलाई बाह्य प्रणालीहरूसँग जडान गर्ने मानकीकृत तरिका प्रदान गर्दछ, जसरी USB-C ले इलेक्ट्रोनिक उपकरणहरूको लागि सार्वभौम जडान मानक प्रदान गर्दछ। यस मानकीकरणले सक्षम पार्दछ:

- **निरन्तर एकीकरण**: एआई मोडेलहरूलाई विविध डेटा स्रोत र उपकरणहरू सँग जडान गर्ने
- **परिसंघ विकास**: एकपटक निर्माण गरी विभिन्न एआई अनुप्रयोगहरूमा प्रयोग गर्ने
- **सुधारिएको क्षमता**: SLMs लाई बाह्य कार्यक्षमताले वृद्धि गर्ने
- **रियल-टाइम अपडेटहरू**: गतिशील, प्रतिक्रिया दिने एआई अनुप्रयोगहरू समर्थन गर्न

मुख्य निष्कर्षहरू:
- MCP एउटा खुला मानक हो जुन एआई अनुप्रयोगहरू र बाह्य प्रणालीहरूबीच पुलको रूपमा काम गर्छ
- प्रोटोकलले उपकरणहरू, स्रोतहरू, र प्रॉम्प्टहरूलाई मुख्य प्रिमिटिवहरूको रूपमा समर्थन गर्छ
- वास्तविक-समय सूचनाले गतिशील, प्रतिक्रिया दिने अनुप्रयोगहरू सक्षम गर्छ
- उचित जीवनचक्र व्यवस्थापन र त्रुटि ह्यान्डलिङ उत्पादन प्रयोगका लागि अनिवार्य छ
- परिसंघले व्यापक SDK र विकास उपकरणहरू प्रदान गर्छ
