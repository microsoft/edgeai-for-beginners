## कार्य कलिंग भनेको के हो?

कार्य कलिंग एउटा शक्तिशाली क्षमता हो जसले सानो भाषा मोडेलहरू (SLMs) लाई बाह्य उपकरण, API हरू, र सेवाहरू सँग अन्तरक्रिया गर्न अनुमति दिन्छ। आफ्नो तालिम डेटा भित्र सीमित नरही, SLM हरू अब:

- **बाह्य API हरू सँग जडान गर्न सक्छन्** (मौसम सेवा, डाटाबेस, खोज इन्जिनहरू)
- **प्रयोगकर्ताको अनुरोध अनुसार निश्चित कार्यहरू कार्यान्वयन गर्न सक्छ**
- **विभिन्न स्रोतहरूबाट वास्तविक-समय जानकारी प्राप्त गर्न सक्छ**
- **विशेष उपकरणहरूको माध्यमबाट गणनात्मक कामहरू गर्न सक्छ**
- **जटिल कार्यप्रवाहहरूको लागि धेरै अपरेसनहरूलाई श्रृंखलाबद्ध गर्न सक्छ**

यस क्षमताले SLM हरूलाई स्थिर टेक्स्ट उत्पादकहरूबाट गतिशील AI एजेन्टहरूमा परिवर्तन गर्छ जुन वास्तविक संसारका कार्यहरू गर्न सक्छन्।

## कार्य कलिंग कसरी काम गर्छ

कार्य कलिंग प्रक्रिया एउटा व्यवस्थित कार्यप्रवाह अनुसरण गर्छ:

### 1. उपकरण एकीकरण
- **बाह्य उपकरणहरू**: SLM हरू मौसम API, डाटाबेस, वेब सेवा, र अन्य बाह्य प्रणालीहरूसँग जडान हुन सक्छन्
- **कार्य परिभाषाहरू**: प्रत्येक उपकरण निश्चित प्यारामिटरहरू, इनपुट/आउटपुट ढाँचा, र विवरणहरूसहित परिभाषित हुन्छ
- **API अनुकूलता**: उपकरणहरू मानकीकृत इन्टरफेस (REST APIs, SDKs, आदि) मार्फत एकीकृत गरिन्छ

### 2. कार्य परिभाषा
कार्यहरू तीन मुख्य कम्पोनेन्टहरूसहित परिभाषित गरिन्छ:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. उद्देश्य पहिचान
- **प्राकृतिक भाषा प्रशोधन**: SLM ले प्रयोगकर्ता इनपुटको विश्लेषण गरी उद्देश्य बुझ्छ
- **कार्य मिलान**: अनुरोध पूरा गर्न आवश्यक कार्य(हरू) निर्धारण गर्छ
- **प्यारामिटर निकालन**: प्रयोगकर्ताको सन्देशबाट आवश्यक प्यारामिटरहरू पहिचान र निकाल्छ

### 4. JSON आउटपुट उत्पादन
SLM ले संरचित JSON उत्पादन गर्छ जसमा:
- कल गर्नुपर्ने कार्यको नाम
- उपयुक्त मानहरूसहित आवश्यक प्यारामिटरहरू
- कार्य सन्दर्भ र मेटाडाटा

### 5. बाह्य कार्यान्वयन
- **प्यारामिटर जाँच**: सबै आवश्यक प्यारामिटरहरू उपस्थिति र सही ढाँचामा रहेको सुनिश्चित गर्छ
- **कार्य कार्यान्वयन**: आवेदनले निर्दिष्ट कार्यलाई उपलब्ध गराइएको प्यारामिटरहरूसँग चलाउँछ
- **त्रुटि व्यवस्थापन**: असफलता, टाइमआउट, र अवैध प्रतिक्रियाहरूको व्यवस्थापन गर्छ

### 6. प्रतिक्रिया एकीकरण
- **नतिजा प्रशोधन**: कार्यका परिणामहरू SLM लाई फर्काइन्छ
- **सन्दर्भ एकीकरण**: SLM ले परिणामहरू आफ्नो प्रतिक्रियामा समावेश गर्छ
- **प्रयोगकर्ता संचार**: जानकारीलाई प्राकृतिक, संवादात्मक ढाँचामा प्रस्तुत गर्छ

## आवेदनका परिदृश्यहरू

### डेटा पुन:प्राप्ति
प्राकृतिक भाषा सोधपुछलाई संरचित API कलहरूमा रूपान्तरण गर्नुहोस्:
- **"मेरो पछिल्ला अर्डरहरू देखाउनुहोस्"** → प्रयोगकर्ता ID र मिति फिल्टरहरू सहित डाटाबेस सोधपुछ
- **"टोकियोको मौसम कस्तो छ?"** → स्थान प्यारामिटर सहित मौसम API कल
- **"जोन बाट आएका इमेलहरू सामाप्त हप्ता खोज्नुहोस्"** → प्रेषक र मिति फिल्टरहरूसहित इमेल सेवा सोधपुछ

### अपरेशन कार्यान्वयन
प्रयोगकर्ताका अनुरोधहरूलाई विशेष कार्य कलहरूमा रूपान्तरण गर्नुहोस्:
- **"भोली दिउँसो २ बजे बैठक तालिका गर्नुहोस्"** → क्यालेन्डर API एकीकरण
- **"समूहलाई सन्देश पठाउनुहोस्"** → सञ्चार प्लेटफर्म API
- **"मेरो फाइलहरूको ब्याकअप बनाउनुहोस्"** → फाइल प्रणाली अपरेशन

### गणनात्मक कार्यहरू
जटिल गणितीय वा तार्किक अपरेसनहरू सम्हाल्नुहोस्:
- **"१०,००० डलरमा ५% मा १० वर्षको चक्रवृद्धि ब्याज गणना गर्नुहोस्"** → वित्तीय गणना कार्य
- **"यो डेटासेटलाई प्रवृत्तिहरूको लागि विश्लेषण गर्नुहोस्"** → सांख्यिक विश्लेषण उपकरणहरू
- **"वितरणका लागि यो मार्ग अनुकूलन गर्नुहोस्"** → मार्ग अनुकूलन एल्गोरिदम

### डेटा प्रशोधन कार्यप्रवाहहरू
जटिल अपरेसनहरूसँग विभिन्न कार्य कलहरूलाई श्रृंखलाबद्ध गर्नुहोस्:
1. **धेरै स्रोतहरूबाट डेटा पुन:प्राप्ति गर्नुहोस्**
2. **जानकारीलाई पार्स र प्रमाणित गर्नुहोस्**
3. **डेटालाई आवश्यक ढाँचामा रूपान्तरण गर्नुहोस्**
4. **परिणामहरू उपयुक्त प्रणालीहरूमा भण्डारण गर्नुहोस्**
5. **प्रतिवेदनहरू वा भिजुअलाइजेसनहरू उत्पादन गर्नुहोस्**

### UI/UX एकीकरण
गतिशील इन्टरफेस अपडेटहरू सक्षम गर्नुहोस्:
- **"ड्यासबोर्डमा बिक्री डेटा देखाउनुहोस्"** → चार्ट उत्पादन र प्रदर्शन
- **"नयाँ स्थानहरूसँग नक्शा अपडेट गर्नुहोस्"** → भौगोलिक डेटा एकीकरण
- **"सूची प्रदर्शन ताजा गर्नुहोस्"** → वास्तविक-समय डेटा सिंक्रोनाइजेसन

## Phi-4-mini र Ollama सँग कार्य कलिंग सेटअप गर्ने तरिका

- Ollama संस्करण 0.5.13 वा उच्च
- Phi-4-mini मोडेल (सिफारिस गरिन्छ: `phi4-mini:3.8b-fp16`)

### एकल कार्य कलिंग उदाहरण

```python
import json
import requests

# उपकरण/फंक्शन परिभाषित गर्नुहोस्
tools = [
    {
        "name": "get_weather",
        "description": "Get current weather information for a location",
        "parameters": {
            "location": {
                "description": "The city or location name",
                "type": "str",
                "default": "New York"
            },
            "units": {
                "description": "Temperature units (celsius or fahrenheit)",
                "type": "str",
                "default": "celsius"
            }
        }
    }
]

# उपकरणहरू सहित सिस्टम प्रम्प्टको साथ सन्देश सिर्जना गर्नुहोस्
messages = [
    {
        "role": "system",
        "content": "You are a helpful weather assistant",
        "tools": json.dumps(tools)
    },
    {
        "role": "user",
        "content": "What's the weather like in London today?"
    }
]

# Ollama API मा अनुरोध गर्नुहोस्
response = requests.post(
    "http://localhost:11434/api/chat",
    json={
        "model": "phi4-mini-fc:3.8b-fp16",
        "messages": messages,
        "stream": False
    }
)

print(response.json())
```

## Qwen3 कार्य कलिंगसँग काम गर्ने तरिका

Qwen3 ले उत्कृष्ट प्रदर्शन र लचकता सहित उन्नत कार्य कलिंग क्षमता प्रदान गर्दछ। यसलाई लागू गर्ने तरिका:

### Qwen-Agent फ्रेमवर्कको प्रयोग

Qwen-Agent ले कार्य कलिंग कार्यान्वयनलाई सजिलो बनाउने उच्च-स्तरीय फ्रेमवर्क प्रदान गर्दछ:

#### स्थापना
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### आधारभूत सेटअप

```python
import os
from qwen_agent.agents import Assistant

# LLM कन्फिगर गर्नुहोस्
llm_cfg = {
    'model': 'Qwen3-8B',
    # विकल्प १: Alibaba मोडेल स्टुडियो प्रयोग गर्नुहोस्
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # विकल्प २: स्थानीय परिनियोजन प्रयोग गर्नुहोस्
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'EMPTY',
    
    # सोच्ने मोडको वैकल्पिक कन्फिगरेसन
    'generate_cfg': {
        'thought_in_content': True,  # प्रतिक्रियामा तर्क समावेश गर्नुहोस्
    }
}

# MCP (मोडेल सन्दर्भ प्रोटोकल) प्रयोग गरेर उपकरणहरू परिभाषित गर्नुहोस्
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # बिल्ट-इन कोड निष्पादन उपकरण
]

# सहायक सिर्जना गर्नुहोस्
bot = Assistant(llm=llm_cfg, function_list=tools)

# प्रयोग उदाहरण
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# फङ्क्शन कलिङ्गसँग प्रतिक्रिया उत्पादन गर्नुहोस्
for response in bot.run(messages=messages):
    print(response)
```

```python
import asyncio
import aiohttp

async def batch_function_calls(function_calls):
    """Execute multiple function calls concurrently"""
    async with aiohttp.ClientSession() as session:
        tasks = []
        for call in function_calls:
            if call["name"] == "fetch_url":
                task = fetch_url_async(session, call["parameters"]["url"])
                tasks.append(task)
        
        results = await asyncio.gather(*tasks)
        return results

async def fetch_url_async(session, url):
    async with session.get(url) as response:
        return await response.text()
```

```python
        """Execute a function with comprehensive error handling and logging"""

        try:
            # फंक्शन अवस्थित छ कि छैन भनेर मान्यता गर्नुहोस्
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )

                    timestamp=start_time
                )

            if not validation_result.success:
                return validation_result

            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # सफल कार्यान्वयन लग गर्नुहोस्
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:

            result = FunctionResult(
                success=False,

                timestamp=start_time
            )

            return result
```

2. **कार्यान्वयन लचकता**: कम-स्तरीय कार्यान्वयनदेखि उच्च-स्तरीय फ्रेमवर्कहरू जस्तै Qwen-Agent र Foundry Local सम्म विभिन्न पद्धतिहरू उपलब्ध छन्।

4. **प्रदर्शन अनुकूलन**: उचित कार्य डिजाइन, प्रभावकारी कार्यान्वयन, र स्मार्ट क्यासिङले प्रतिक्रिया समयमा ठूलो सुधार गर्न सक्छ।

### भविष्यका दिशाहरू

SLM प्रविधि विकास भइरहँदा हामी आशा गर्न सक्छौं:

- **कार्य कलिंग सटिकता सुधार**: राम्रो उद्देश्य पहिचान र प्यारामिटर निकालन
- **उन्नत समानान्तर प्रशोधन**: धेरै-कार्य सञ्चालनमा बढी परिष्कृत व्यवस्थापन
- **राम्रो एकीकरण मापदण्डहरू**: उपकरण एकीकरणका लागि मानकीकृत प्रोटोकलहरू
- **उन्नत सुरक्षा सुविधाहरू**: राम्रो प्रमाणीकरण र अधिकार व्यवस्थापन उपायहरू
- **विस्तारित पारिस्थितिकी तन्त्र**: पूर्व-निर्मित कार्यहरू र एकीकरणहरूको बढ्दो पुस्तकालय

### सुरु गर्ने तरिका

तपाईंका परियोजनाहरूमा कार्य कलिंग लागू गर्न शुरु गर्नुहोस्:

1. **सरलबाट शुरु गर्नुहोस्**: आधारभूत एकल कार्य परिदृश्यमार्फत सुरु गर्नुहोस्
2. **आफ्नो फ्रेमवर्क छनौट गर्नुहोस्**: प्रत्यक्ष कार्यान्वयन (Ollama/Phi-4) वा फ्रेमवर्क समर्थन (Qwen-Agent) बीच चयन गर्नुहोस्
3. **कार्यहरू सावधानीपूर्वक डिजाइन गर्नुहोस्**: स्पष्ट, राम्रो कागजात गरिएको कार्य परिभाषामा ध्यान दिनुहोस्
4. **त्रुटि व्यवस्थापन कार्यान्वयन गर्नुहोस्**: सुरुदेखि नै दिगो त्रुटि व्यवस्थापन बनाउनुहोस्
5. **धैर्यपूर्वक विस्तार गर्नुहोस्**: अनुभव प्राप्तसँगै सरलदेखि जटिल परिदृश्यहरूमा जानुहोस्

कार्य कलिंगले SLM हरूलाई प्रभावशाली टेक्स्ट उत्पादकहरूबाट व्यावहारिक AI एजेन्टहरूमा रूपान्तरण गर्छ जो वास्तविक संसारका समस्याहरू समाधान गर्न सक्षम छन्। यस तालिममा उल्लिखित ढाँचा र अभ्यासहरू पालना गरेर तपाईं शक्तिशाली, भरपर्दो AI प्रणालीहरू निर्माण गर्न सक्नुहुन्छ जुन पारंपरिक कुराकानी इन्टरफेसहरू भन्दा धेरै अगाडि जान्छ।
