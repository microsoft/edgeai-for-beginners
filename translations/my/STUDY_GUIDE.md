## မိတ်ဆက်ခြင်း

EdgeAI စတင်သူများအတွက် သင်ဒိုင်ယာရီမှ ကြိုဆိုပါတယ်! ဤစာတမ်းသည် သင်သည် သင်ပညာပိုင်း အကြောင်းအရာများကို ထိရောက်စွာ လမ်းညွှန်ခံနိုင်ရန်နှင့် သင်ယူမှုအတွေ့အကြုံအများဆုံး ရရှိနိုင်ရန် ရည်ရွယ်ပါသည်။ ၎င်းသည် တိကျသေချာသော သင်ယူမှုလမ်းကြောင်းများ၊ အကြံပြုသင်ကြားမှု အချိန်ဇယားများ၊ အဓိက သဘောတရားအကျဉ်းချုပ်များနှင့် Edge AI နည်းပညာများကို နက်ရှိုင်းစွာ နားလည်နိုင်ရန် အကူအညီဖြစ်စေလိမ့်မည့် အပိုဆောင်း tàiရင်းများ ပေးပို့ပါသည်။

ဤသည်မှာ အချိန်ကာလတိုအတွင်း EdgeAI အကြောင်း အရေးပါသော သတင်းအချက်အလက်များကို ပေးအပ်သည့် ၂၀ နာရီ သင်တန်းလေးဖြစ်ပြီး အလုပ်များသော ဝန်ထမ်းများနှင့် တက္ကသိုလ်ကျောင်းသားများအတွက် လျင်မြန်စွာ လက်တွေ့ကျကျနှင့် နည်းပညာများ ရရှိစေသည်။

## သင်တန်းအနှိုင်းအယှက်

သင်တန်းသည် လုံးဝပြည့်စုံသော ၈ Module များအဖြစ် အဖွဲ့ပေါင်းစည်းထားပါသည်-

0. **EdgeAI မိတ်ဆက်ခြင်း** - အခြေခံနှင့် လောကီဆိုင်ရာ အသုံးချမှုများ၊ သင်ယူရမည့် ရည်မှန်းချက်များ
1. **EdgeAI အခြေခံများနှင့် ပြောင်းလဲမှု** - အခြေခံသဘောတရား နှင့် နည်းပညာပြောင်းလဲမှုကို နားလည်ခြင်း
2. **Small Language Model အခြေခံကျမှုများ** - SLM မျိုးစုံ၏ မူပိုင်ဆိုင်မှုကို ရှာဖွေခြင်း
3. **Small Language Model တပ်ဆင်ခြင်း** - လက်တွေ့တပ်ဆင်မှု မဟာဗျူဟာများ ကျင့်သုံးခြင်း
4. **မော်ဒယ် ဖော်မတ် ပြောင်းလဲခြင်းနှင့် Quantization** - OpenVINO အပါအဝင် ဖရိမ်ဝတ် ၆ ခုဖြင့် မြင့်မားသော ထိန်းချုပ်မှု
5. **SLMOps - Small Language Model လည်ပတ်မှုများ** - ထုတ်လုပ်မှုလုပ်ငန်းလည်ပတ်မှုနှင့် တပ်ဆင်မှု
6. **SLM Agentic Systems** - AI အေးဂျင့်များ၊ မှေ့ခွင့်ခေါ်ဆိုမှုနှင့် မော်ဒယ် Context Protocol
7. **EdgeAI အကောင်အထည်ဖော် နမူနာများ** - AI Toolkit, Windows ဖွံ့ဖြိုးရေးနှင့် ပလပ်ဖောင်းအထူးအစီအစဉ်များ
8. **Microsoft Foundry Local – Developer Toolkit အပြည့်စုံ** - Hybrid Azure ပေါင်းစပ်မှုဖြင့် ဒေသခံ-ဦးစားပေး ဖွံ့ဖြိုးရေး (Module 08)

## Module 0: EdgeAI မိတ်ဆက်

### အဓိက သင်ယူရမည့် ရည်မှန်းချက်များ

- Edge AI ဆိုတာဘာလဲ၊ ယနေ့ နည်းပညာလောကတွင် အရေးကြီးချက်ကို နားလည်ပါ
- Edge AI ကြောင့် ပြောင်းလဲသွားသော ရုပ်ပုံ များနှင့် သူတို့၏ အသုံးချမှုကဏ္ဍများ ရှာဖွေပါ
- Edge တွင် တပ်ဆင်ရန် Small Language Models (SLMs) ၏ အားသာချက်များ သိရှိပါ
- သင်တန်းအပြည့်အစုံအတွက် သင်ယူမည့် ရည်မှန်းချက်များနှင့် ရလဒ်များ သတ်မှတ်ပါ
- Edge AI လုပ်ငန်းတွင် အသက်မွေးဝမ်းကြောင်း ရွေးချယ်မှုများနှင့် ကျွမ်းကျင်မှုလိုအပ်ချက်များ သိရှိပါ

### သင်ယူမှု အာရုံစိုက်ရာများ

#### အပိုင်း ၁: Edge AI သဘောတရားနှင့် သတ်မှတ်ချက်
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - Edge AI နှင့် ရိုးရာ cloud AI လုပ်ငန်းဆောင်တာ များကို နှိုင်းယှဥ်ခြင်း
  - ဟာ့ဒ်ဝဲ၊ မော်ဒယ်ထိန်းသိမ်းမှုနှင့် စီးပွားရေးလိုအပ်ချက်များ ပေါင်းစပ်ခြင်း
  - အချိန်နှင့်တပြေးညီ၊ သီးသန့် ကာကွယ်မှု၊ ဈေးနှုန်းသက်သာသော AI တပ်ဆင်မှု

#### အပိုင်း ၂: စက်မှု လုပ်ငန်းများမှ အသုံးချမှုများ
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - စက်မှုလုပ်ငန်း & Industry 4.0: ကြိုတင် ထိန်းသိမ်းရေးနှင့် အရည်အသွေးထိန်းချုပ်မှု
  - ကျန်းမာရေး: ရောဂါ ဓာတ်ပုံကြည့်ခြင်းနှင့် လူနာကြည့်ရှုခြင်း
  - လွတ်လပ်သော စနစ်များ: ကိုယ်ပိုင် မောင်းနှင်ခြင်း စက်ဘီးများနှင့် သယ်ယူ ပို့ဆောင်ရေး
  - မြို့ကြီးများ: လမ်းပိတ်တားနည်းနှင့် လူထုလုံခြုံရေး
  - သုံးစွဲသူနည်းပညာ: စမတ်ဖုန်းများ၊ ဝတ်ဆင်နိုင်သော စက်ပစ္စည်းများ နှင့် စမတ်အိမ်များ

#### အပိုင်း ၃: Small Language Models အခြေခံကျမှု
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - SLM ၏ အင်္ဂါရပ်များနှင့် ဖော်ပြချက်များ
  - ပါရာမီတာ ထိရောက်မှု နှင့် တာဝန်ထမ်းဆောင်မှု နှိုင်းယှဉ်ချက်များ
  - Edge တွင် တပ်ဆင်ခြင်း အကန့်အသတ်များနှင့် ထိန်းချုပ်နည်း မဟာဗျူဟာများ

#### အပိုင်း ၄: သင်ယူမှု ကိုယ်ပိုင် အခြေစိုက်ခြင်း နှင့် အသက်မွေးဝမ်းကြောင်း လမ်းကြောင်း
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - သင်တန်း အဆောက်အအုံနှင့် တိုးတက်သော ကျွမ်းကျင်မှုများ ရယူနည်း
  - နည်းပညာ ကျွမ်းကျင်မှုများနှင့် လက်တွေ့ကျကျ အကောင်အထည်ဖော်မြင်ရန် ရည်မှန်းချက်များ
  - အသက်မွေးဝမ်းကြောင်းမြှင့်တင်ရေး အခွင့်အလမ်းများနှင့် စက်မှုလုပ်ငန်း အသုံးချမှုများ

### ကိုယ်တိုင် စစ်ဆေးမေးခွန်းများ

1. Edge AI ကို အကောင်းတကာ မည်သည့် နည်းပညာသုံးခုက ဆောင်ကြဉ်းပေးခဲ့ပါသလဲ?
2. Edge AI နှင့် cloud-based AI ၏ အားသာချက်များနှင့် စိန်ခေါ်ချက်များကို နှိုင်းယှဥ် ပြောပြပါ။
3. Edge AI သည် အရေးပါသော စီးပွားရေး တန်ဖိုးဖြတ်တောက်ပေးသော စက်မှုလုပ်ငန်း သုံးခု ကို မည်သို့ ဖော်ပြနိုင်ပါသလဲ။
4. Small Language Models တွင် Edge AI ကို လက်တွေ့ကျကျ တပ်ဆင်ပေးနိုင်စေရန် မည်သို့ ကူညီပါသလဲ။
5. သင်တန်းတစ်လျှောက် လေ့လာသင်ယူမည့် အဓိက နည်းပညာ ကျွမ်းကျင်မှုများမှာ အဘယ်နည်း။
6. သင်တန်းတွင် အသုံးပြုသည့် အဆင့် ၄ ဆင့် သင်ယူမှု နည်းစနစ်ကို ဖေါ်ပြပါ။

### လက်တွေ့ လေ့ကျင့်ခန်းများ

1. **စက်မှု လေ့လာမှု**: စက်မှုလုပ်ငန်း တစ်ခုကို ရွေးချယ်ပြီး Edge AI ၏ လက်တွေ့ အကောင်အထည်ဖော်မှုကို သုတေသနလုပ်ပါ (၃၀ မိနစ်)
2. **မော်ဒယ် ရှာဖွေရေး**: Hugging Face တွင် ရနိုင်သည့် Small Language Models များစွာ ကြည့်ရှု၍ ပါရာမီတာ အရေအတွက် နှင့် တာဝန်သိမ်းဆောင်မှုများ နှိုင်းယှဥ်ပါ (၃၀ မိနစ်)
3. **သင်ယူမှု စီမံကိန်း**: သင်တန်းအား အပြည့်အစုံ ကြည့်ရှု၍ ကိုယ်ပိုင် သင်ကြားမှု အချိန်ဇယား တစ်ခု ပြုလုပ်ပါ (၁၅ မိနစ်)

## Module 1: EdgeAI အခြေခံများနှင့် ပြောင်းလဲမှု

### အဓိက သင်ယူရမည့် ရည်မှန်းချက်များ

- Cloud-based နှင့် Edge-based AI ၏ ကွာခြားချက်များ နားလည်ပါ
- အရင်းအမြစ် ကန့်သတ်ထားသည့် ပတ်ဝန်းကျင်များအတွက် အဓိက ထိန်းချုပ်နည်းများ ကျွမ်းကျင်ပါ
- EdgeAI နည်းပညာများ၏ လက်တွေ့အသုံးချမှုများ ခွဲခြမ်းစိတ်ဖြာပါ
- EdgeAI ပရောဂျက်များအတွက် ဖွံ့ဖြိုးရေး ပတ်ဝန်းကျင် တည်ဆောက်ပါ

### သင်ယူမှု အာရုံစိုက်ရာများ

#### အပိုင်း ၁: EdgeAI အခြေခံများ
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - Edge နှင့် Cloud ကွန်ပျူတာပညာ မူဝါဒများ
  - မော်ဒယ် Quantization နည်းပညာများ
  - ဟာ့ဒ်ဝဲ မြန်ဆန်စေမှု ရွေးချယ်စရာများ (NPU, GPU, CPU)
  - ကိုယ်ရေးကာကွယ်မှု နှင့် လုံခြုံရေး အားသာချက်များ

- **အပိုဆောင်း tàiရင်းများ**:
  - [TensorFlow Lite စာတမ်းများ](https://www.tensorflow.org/lite)
  - [ONNX Runtime GitHub](https://github.com/microsoft/onnxruntime)
  - [Edge Impulse စာတမ်းများ](https://docs.edgeimpulse.com)

#### အပိုင်း ၂: လက်တွေ့ အသုံးချမှု နမူနာများ
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - Microsoft Phi & Mu model ecosystem
  - စက်မှုလုပ်ငန်းများအတွင်း လက်တွေ့အသုံးပြုမှုများ
  - တပ်ဆင်မှု သတိပြုချက်များ

#### အပိုင်း ၃: လက်တွေ့ ပြုလုပ်သည့် လမ်းညွှန်
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - ဖွံ့ဖြိုးရေး ပတ်ဝန်းကျင် စနစ်တကျ ပြင်ဆင်ခြင်း
  - Quantization နှင့် optimization ကိရိယာများ
  - EdgeAI လက်တွေ့ အသုံးပြုမှု အကဲဖြတ်နည်းများ

#### အပိုင်း ၄: Edge တွင် တပ်ဆင်ရန် ဟာ့ဒ်ဝဲ
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - ဟာ့ဒ်ဝဲ ပလက်ဖောင်းများ နှိုင်းယှဥ်ခြင်း
  - ဟာ့ဒ်ဝဲအမျိုးအစားများအတွက် ထိန်းချုပ်နည်းများ
  - တပ်ဆင်မှု သတိပြုချက်များ

### ကိုယ်တိုင် စစ်ဆေးမေးခွန်းများ

1. Cloud-based AI နှင့် Edge-based AI တပ်ဆင်ခြင်းများကို နှိုင်းယှဥ် ပြောပြပါ။
2. Edge တပ်ဆင်မှုအတွက် မော်ဒယ်များကို အထူးပြု ထိန်းချုပ်ရန် နည်းလမ်း သုံးခုကို ဖေါ်ပြပါ။
3. Edge တွင် AI မော်ဒယ်များကို လည်ပတ်မှု၏ အဓိကအားသာချက်များ ဘာတွေရှိပါသလဲ။
4. မော်ဒယ် Quantization လုပ်ငန်းစဉ်ကို ဖော်ပြပြီး ၎င်းသည် စွမ်းဆောင်ရည်ကို မည်သို့ သက်ရောက်စေပါသလဲ။
5. ဟာ့ဒ်ဝဲမြန်ဆန်စေမှု ကိရိယာများ (NPU, GPU, CPU) သည် EdgeAI တပ်ဆင်မှုကို မည်သို့ သက်ရောက်စေပါသလဲ။

### လက်တွေ့ လေ့ကျင့်ခန်းများ

1. **လျင်မြန်စွာ ပတ်ဝန်းကျင် ပြင်ဆင်ခြင်း**: အခြေခံအဖွဲ့စည်းများဖြင့် အနည်းဆုံး ဖွံ့ဖြိုးရေးပတ်ဝန်းကျင် တည်ဆောက်ပါ (၃၀ မိနစ်)
2. **မော်ဒယ် ရှာဖွေရေး**: ကြိုတင်လေ့လာထားသော Small Language Model တစ်ခု ဒေါင်းလုပ်လုပ်၍ စစ်ဆေးပါ (၁ နာရီ)
3. **အခြေခံ Quantization**: မော်ဒယ် သေးငယ်လေးတစ်ခုတွင် ရိုးရှင်း Quantization ကို စမ်းသပ်ပါ (၁ နာရီ)

## Module 2: Small Language Model အခြေခံကျမှုများ

### အဓိက သင်ယူရမည့် ရည်မှန်းချက်များ

- SLM မျိုးစုံ၏ အင်ဂျင်နီးယားလုပ်ငန်းဆိုင်ရာ မူဝါဒများ နားလည်ပါ
- ပါရာမီတာ အတိုင်းအတာအလိုက် မော်ဒယ် တာဝန်သိမ်းဆောင်မှုများ နှိုင်းယှဉ်ပါ
- ထိရောက်မှု၊ တာဝန်သိမ်းဆောင်မှုနှင့် တပ်ဆင်မှု လိုအပ်ချက်များအရ မော်ဒယ်များ ထောက်လှမ်းပါ
- မော်ဒယ် မျိုးစုံအတွက် သင့်တော်သော အသုံးချမှုများ ရွေးချယ်မှုကို သဘောပေါက်ပါ

### သင်ယူမှု အာရုံစိုက်ရာများ

#### အပိုင်း ၁: Microsoft Phi မော်ဒယ် မျိုးဆက်
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - ဒီဇိုင်း နောက်ပြန်ပြောင်းလဲမှု
  - ထိရောက်မှု ဦးစားပေး ဖွဲ့စည်းမှု
  - အထူးပြု လုပ်ဆောင်ချက်များ

#### အပိုင်း ၂: Qwen မျိုးဆက်
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - Open source အဖွဲ့ဝင်များ
  - တပ်ဆင်စရာများ အလျားလိုက် ရွေးချယ်မှုများ
  - အဆင့်မြင့် အကြောင်း ရှာဖွေမှု စနစ်

#### အပိုင်း ၃: Gemma မျိုးဆက်
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - သုတေသန မူတည်သော ဘောင်မြူ
  - မသည်မာစိုက် ဖွဲ့စည်းမှုများ
  - မိုဘိုင်း ထိန်းသိမ်းမှု

#### အပိုင်း ၄: BitNET မျိုးဆက်
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - ၁ bit Quantization နည်းပညာ
  - မြှင့်တင်ခြင်း စနစ်
  - တာရှည်ခံ စဉ်းစားမှုများ

#### အပိုင်း ၅: Microsoft Mu မော်ဒယ်
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - စက်ပစ္စည်း ဦးစားပေး ဖွဲ့စည်းမှု
  - Windows နှင့် စနစ် ပေါင်းစပ်မှု
  - ကိုယ်ရေးကာကွယ်မှု ကာကွယ်ခြင်း လုပ်ငန်းစဉ်

#### အပိုင်း ၆: Phi-Silica
- **အရေးကြီး ဆင်ခြင်ချက်များ**: 
  - NPU အထူးပြု ဖွဲ့စည်းမှု
  - စွမ်းဆောင်ရည် တိုင်းတာချက်များ
  - ဖွံ့ဖြိုးသူ ပေါင်းစည်းခြင်း

### ကိုယ်တိုင် စစ်ဆေးမေးခွန်းများ

1. Phi နှင့် Qwen မော်ဒယ် မျိုးစုများ၏ ဖွဲ့စည်းမှု အကြောင်း ပြောပြပါ။
2. BitNET ၏ Quantization နည်းပညာသည် ရိုးရာ Quantization နည်းပညာနှင့် မည်သို့ ကွာခြားသည်ကို ရှင်းပြပါ။
3. Mu မော်ဒယ်သည် Windows ပေါ်တွင် ပေါင်းစပ်အသုံးချရာတွင် ထူးခြားသော အားသာချက်များ ရှိပါသလား။
4. Phi-Silica သည် NPU ဟာ့ဒ်ဝဲကို စွမ်းဆောင်ရည် မြှင့်တင်ရန် မည်သို့ အသုံးချသနည်း။

5. ဆက်သွယ်မှုအကန့်အသတ်ရှိသည့် မိုဘိုင်းအက်ပလီကေးရှင်းအတွက် မည်သည့် မော်ဒယ်မိသားစုကို သင့်တော်ဆုံးသည်နှင့် အကြောင်းရင်းက ဘာလဲ?

### လက်တွေ့လေ့ကျင့်မှုများ

1. **မော်ဒယ်နှိုင်းယှဉ်ခြင်း**: SLM မော်ဒယ်နှစ်ခုအား အမြန်တင်စားခြင်း (1 နာရီ)
2. **ရိုးရှင်းသော စာသားထုတ်လုပ်မှု**: သေးငယ်သောမော်ဒယ်နဲ့ စာသားထုတ်လုပ်မှုအခြေခံအသုံးပြုမှု (1 နာရီ)
3. **မြန်ဆန်သော အကောင်းပြုပြင်ခြင်း**: inference အမြန်နှုန်းတိုးတက်ရေးအတွက် အကောင်းပြုပြင်နည်းတစ်ခု လုပ်ဆောင်ခြင်း (1 နာရီ)

## မော်ဒူလ် ၃: သေးငယ်သော ဘာသာစကား မော်ဒယ် တပ်ဆင်ခြင်း

### အဓိက သင်ယူရမည့် ရည်မှန်းချက်များ

- တပ်ဆင်ရန် ကန့်သတ်ချက်အရ သင့်တော်သော မော်ဒယ်များ ရွေးချယ်ခြင်း
- တပ်ဆင်မှု အခြေအနေမျိုးစုံအတွက် အကောင်းပြုနည်းများ ကျွမ်းကျင်မှု ရရှိခြင်း
- SLM မော်ဒယ်များကို ဒေသတွင်းနှင့် မိုးကောင်းကင် ပတ်ဝန်းကျင်များတွင် တပ်ဆင်ခြင်း
- EdgeAI အသုံးပြုမှုများအတွက် ထုတ်လုပ်နိုင်သည့် ဖွဲ့စည်းမှု ဒီဇိုင်းရေးဆွဲခြင်း

### လေ့လာသင့်သော အချက်များ

#### အပိုင်း ၁: SLM အဆင့်မြှင့် သင်ယူမှု
- **ဦးစားပေး အယူအဆများ**:
  - ပါရာမီတာ အမျိုးအစားသတ်မှတ်ခြင်း စနစ်
  - အဆင့်မြှင့် အကောင်းပြုပြင်နည်းများ
  - မော်ဒယ် ရရှိရေးရဲ့ မဟာဗျူဟာများ

#### အပိုင်း ၂: ဒေသတွင်း ပတ်ဝန်းကျင် တပ်ဆင်ခြင်း
- **ဦးစားပေး အယူအဆများ**:
  - Ollama ပလက်ဖောင်း တပ်ဆင်ခြင်း
  - Microsoft Foundry ဒေသတွင်း ဖြေရှင်းချက်များ
  - ဖြamework တွေ နှိုင်းယှဉ် ခွဲခြမ်းစိတ်ဖြာခြင်း

#### အပိုင်း ၃: ကွန်တိန်နာမက်ဒိုးဖြင့် မိုးကောင်းကင် တပ်ဆင်ခြင်း
- **ဦးစားပေး အယူအဆများ**:
  - vLLM အမြင့်ထိန်း ဖော်ထုတ်မှု
  - ကွန်တိန်နာ စီမံခန့်ခွဲခြင်း
  - ONNX Runtime ကို အသုံးပြုခြင်း

### ကိုယ့်ကိုယ်ကို သုံးသပ်မေးခွန်းများ

1. ဒေသတွင်း တပ်ဆင်ခြင်းနှင့် မိုးကောင်းကင် တပ်ဆင်ခြင်းကို ရွေးချယ်ရာတွင် ဘာတွေလေ့လာစဉ်းစားသင့်သလဲ?
2. Ollama နှင့် Microsoft Foundry Local တို့၏ တပ်ဆင်မှုရွေးချယ်စရာများကို နှိုင်းယှဉ်ပါ။
3. SLM တပ်ဆင်မှုအတွက် ကွန်တိန်နာမေးခွန်းဖြေဆိုခြင်း၏ အကျိုးကျေးဇူးများကို ရှင်းပြပါ။
4. အနားစွန် ထည့်သွင်းထားသော SLM အတွက် မအောင်မြင်မှုကို စောင့်ကြည့်ရန် အဓိက သတ်မှတ်ချက်များ ဘာတွေရှိသလဲ?
5. မော်ဒယ်ရွေးချယ်မှုမှ ထုတ်လုပ်မှု အကောင်အထည်ဖော်မှုထံ သွားသော ပြည့်စုံသော တပ်ဆင်မှု လုပ်ငန်းစဉ်ကို ဖေါ်ပြပါ။

### လက်တွေ့လေ့ကျင့်မှုများ

1. **အခြေခံ ဒေသတွင်း တပ်ဆင်ခြင်း**: Ollama ကို အသုံးပြု၍ ရိုးရှင်းသော SLM တပ်ဆင်ပါ (1 နာရီ)
2. **စွမ်းဆောင်ရည် စစ်ဆေးမှု**: တပ်ဆင်ထားသော မော်ဒယ်ကို အမြန် Benchmarks ပြုလုပ်ပါ (၃၀ မိနစ်)
3. **ရိုးရှင်းသော ပေါင်းစပ်မှု**: တပ်ဆင်ထားသော မော်ဒယ်ကို အသုံးပြုသည့် အနည်းဆုံးအက်ပလီကေးရှင်းတစ်ခု ဖန်တီးပါ (1 နာရီ)

## မော်ဒူလ် ၄: မော်ဒယ် ဖော်မတ် ပြောင်းလဲခြင်းနှင့် ပမာဏ ခွဲခြားခြင်း

### အဓိက သင်ယူရမည့် ရည်မှန်းချက်များ

- 1-bit မှ 8-bit များအထိ အဆင့်မြှင့် ပမာဏ ခွဲခြားနည်းများ ကျွမ်းကျင်မှု ရရှိခြင်း
- ဖော်မတ် ပြောင်းလဲနည်း မဟာဗျူဟာများ (GGUF, ONNX) ကို နားလည်ခြင်း
- ခြောက်မျိုးအမျိုးအစား Framework များတွင် အကောင်းပြုလုပ္ငန္းမ်ား အကောင်အထည်ဖော်ခြင်း (Llama.cpp, Olive, OpenVINO, MLX, workflow synthesis)
- Intel, Apple နှင့် cross-platform hardware များအတွက် ထုတ်လုပ်နိုင်သော edge ပတ်ဝန်းကျင်များတွင် အကောင်းပြု မော်ဒယ်များ တပ်ဆင်ခြင်း

### လေ့လာသင့်သော အချက်များ

#### အပိုင်း ၁: ပမာဏ ခွဲခြားခြင်း အခြေခံ အခြေအနေများ
- **ဦးစားပေး အယူအဆများ**:
  - တိကျမှန်ကန်မှု အမျိုးအစား သတ်မှတ်ခြင်း စနစ်
  - စွမ်းဆောင်ရည် နှင့် တိကျမှန်ကန်မှု အပြောင်းအလဲများ
  - မှတ်ဉာဏ် အသုံးပြုမှုပိုမိုကောင်းမွန်စေရေး

#### အပိုင်း ၂: Llama.cpp ဖြင့် အသုံးပြုခြင်း
- **ဦးစားပေး အယူအဆများ**:
  - Cross-platform တပ်ဆင်မှု
  - GGUF ဖော်မတ် အကောင်းပြုပြင်ခြင်း
  - हार्डဝဲ Acceleration နည်းပညာများ

#### အပိုင်း ၃: Microsoft Olive Suite
- **ဦးစားပေး အယူအဆများ**:
  - Hardware သတိပြုမှု အကောင်းပြုပြင်ခြင်း
  - စီးပွားရေးအဆင့် တပ်ဆင်မှု
  - အလိုအလြို့ အကောင်းပြုပြင်မှု လုပ်ငန်းစဉ်များ

#### အပိုင်း ၄: OpenVINO ကိရိယာစု
- **ဦးစားပေး အယူအဆများ**:
  - Intel hardware အကောင်းပြုပြင်မှု
  - Neural Network Compression Framework (NNCF)
  - Cross-platform inference တပ်ဆင်မှု
  - OpenVINO GenAI ဖြင့် LLM တပ်ဆင်မှု

#### အပိုင်း ၅: Apple MLX ဖရိမ်ဝတ်
- **ဦးစားပေး အယူအဆများ**:
  - Apple Silicon အကောင်းပြုပြင်မှု
  - ညီမျှ unified memory architecture
  - LoRA အဆင့်မြှင့်ပြင်ဆင်နိုင်စွမ်းများ

#### အပိုင်း ၆: Edge AI ဖွံ့ဖြိုးတိုးတက်မှု workflow စုပေါင်းခြင်း
- **ဦးစားပေး အယူအဆများ**:
  - Unified workflow architecture
  - Framework ရွေးချယ်မှု ဆုံးဖြတ်ပုံမွန်များ
  - ထုတ်လုပ်မှုအဆင့် အသင့်ရှိမှု စစ်ဆေးခြင်း
  - အနာဂတ်ကို အာမခံနိုင်ရေး မဟာဗျူဟာများ

### ကိုယ့်ကိုယ်ကို သုံးသပ်မေးခွန်းများ

1. 1-bit မှ 8-bit အတိအကျမျှ မတူညီသော ပမာဏခွဲခြားနည်း များကို နှိုင်းယှဉ်ပါ။
2. Edge တပ်ဆင်မှုအတွက် GGUF ဖော်မတ်၏ အားသာချက်များကို ရှင်းပြပါ။
3. Microsoft Olive မှ hardware-aware optimization က တပ်ဆင်မှု ထိရောက်မှုကို မည်သို့ တိုးတက်စေသနည်း?
4. OpenVINO ၏ NNCF သည် မော်ဒယ် စုပေါင်းမှုအတွက် အဓိက အားသာချက်များဘာတွေလဲ?
5. Apple MLX သည် ယူနစ်ဖိုင်း memory architecture ကို optimization အတွက် မည်သို့ အသုံးပြုသနည်း?
6. Workflow synthesis က optimization framework အသေးစိတ် ရွေးချယ်ရာတွင် မည်သို့ အကူအညီပေးသနည်း?

### လက်တွေ့လေ့ကျင့်မှုများ

1. **မော်ဒယ် ပမာဏ ခွဲခြားခြင်း**: မော်ဒယ်တစ်ခုအား မတူညီသော ပမာဏခွဲခြားမှု အဆင့်များ လုပ်ဆောင်ပြီး နောက်ဆက်တွဲရလဒ်တွေနှိုင်းယှဉ်ပါ (1 နာရီ)
2. **OpenVINO အကောင်းပြုပြင်ခြင်း**: Intel hardware အတွက် NNCF ဖြင့် မော်ဒယ် စုပေါင်းပါ (1 နာရီ)
3. **ဖရိမ်ဝတ် နှိုင်းယှဉ်မှု**: တူညီသော မော်ဒယ်အား optimization ဖရိမ်ဝတ် ၃ ခုတွင် စမ်းသပ်ပါ (1 နာရီ)
4. **စွမ်းဆောင်ရည် တင်ဂဏန်း ဆန်းစစ်ခြင်း**: inference အမြန်နှုန်းနှင့် မှတ်ဉာဏ် အသုံးပြုမှု၌ optimization ၏ သက်ရောက်မှု ကိုတိုင်းတာပါ (1 နာရီ)

## မော်ဒူလ် ၅: SLMOps - သေးငယ်သော ဘာသာစကားမော်ဒယ် ဗဟိုစီမံခန့်ခွဲမှု

  - ကုန်ကျစရိတ် ထိန်းသိမ်းမှုနှင့် privacy-first architecture
  - စီးပွားရေး မဟာဗျူဟာ ထိရောက်မှုများနှင့် ရွှေ့ပြောင်းနိုင်မှု အားသာချက်များ

#### အပိုင်း ၂: မော်ဒယ် Distillation
- **ဦးစားပေး အယူအဆများ**:
  - အသိပညာ ပေးပို့မှု နည်းစနစ်များ
  - နှစ်ဆင့် distillation လုပ်ငန်းစဉ် အကောင်အထည်ဖော်ခြင်း
  - Azure ML distillation workflow များ

#### အပိုင်း ၃: Fine-tuning မဟာဗျူဟာများ
- **ဦးစားပေး အယူအဆများ**:
  - ပါရာမီတာ ထိရောက်စွာ fine-tuning (PEFT)
  - LoRA နှင့် QLoRA အဆင့်မြှင့် နည်းစနစ်များ
  - Multi-adapter သင်တန်းနှင့် hyperparameter optimization

#### အပိုင်း ၄: ထုတ်လုပ်မှု တပ်ဆင်မှု
- **ဦးစားပေး အယူအဆများ**:
  - ထုတ်လုပ်မှုအတွက် မော်ဒယ် ပြောင်းလဲခြင်းနှင့် ပမာဏခွဲခြားမှု
  - Foundry Local တပ်ဆင်မှု ဖွဲ့စည်းတည်ဆောက်ခြင်း
  - စွမ်းဆောင်ရည် စမ်းသပ်မှုနှင့် အရည်အသွေး စစ်ဆေးမှုကဏ္ဍများ

### ကိုယ့်ကိုယ်ကို သုံးသပ်မေးခွန်းများ

1. SLMOps မှ ယခင် MLOps တွေနဲ့ ဘယ်လို ကွဲပြားနေသလဲ?
2. နယ်နိမိတ် တပ်ဆင်မှုအတွက် မော်ဒယ် distillation ၏ အကျိုးကျေးဇူးများ ကို ရှင်းပြပါ။
3. ရင်းနှီးမြုပ်နှံမှု ကန့်သတ်ထားသော ပတ်ဝန်းကျင်များအတွက် SLM များကို fine-tune ပြုလုပ်ရာတွင် အဓိက စဉ်းစားရမည့်အချက်များ ဘာတွေလဲ?
4. နယ်စပ် AI အပလီကေးရှင်းများအတွက် ထွက်ရှိသည့် ထုတ်လုပ်မှု တပ်ဆင်မှု လုပ်ငန်းစဉ် တစ်ခုကို ဖော်ပြပါ။

### လက်တွေ့လေ့ကျင့်မှုများ

1. **အခြေခံ Distillation**: အကြီးမော်ဒယ်မှ သေးငယ်တဲ့ မော်ဒယ်ကို ဖန်တီးပါ (1 နာရီ)
2. **Fine-tuning စမ်းသပ်မှု**: သတ်မှတ်ထားသော ဒေတာများအတွက် မော်ဒယ်ကို fine-tune လုပ်ပါ (1 နာရီ)
3. **တပ်ဆင်မှု လုပ်ငန်းစဉ်**: မော်ဒယ်တပ်ဆင်ရန် CI/CD လုပ်ငန်းစဉ် အခြေခံဖော်ဆောင်ပါ (1 နာရီ)

## မော်ဒူလ် ၆: SLM Agentic Systems - AI Agents နှင့် Function Calling

### အဓိက သင်ယူရမည့် ရည်မှန်းချက်များ

- သေးငယ်သော ဘာသာစကား မော်ဒယ်များကို အသုံးပြု၍ နယ်စပ် ပတ်ဝန်းကျင်အတွက် ကျွမ်းကျင်သော AI agent များ တည်ဆောက်ခြင်း
- function calling  စနစ်တကျ ဝိဇ္ဇာနည်း လုပ်ငန်းစဉ်များ ဖြင့် ထိရောက်စွာ ဆောင်ရွက်ခြင်း
- Model Context Protocol (MCP) အထောက်အပံ့ဖြင့် စံပြ တူးဆွဲယူရာ tools များနှင့် ချိတ်ဆက်ပေးခြင်း
- လူ့တတ်မြောက်မှု အနည်းဆုံးဖြင့် ကျွမ်းကျင် agentic systems ကို ဖန်တီးခြင်း

### လေ့လာသင့်သော အချက်များ

#### အပိုင်း ၁: AI Agents နှင့် SLM အခြေခံ
- **ဦးစားပေး အယူအဆများ**:
  - Agent အမျိုးအစား စနစ် (ပြန်ကြားမှု, မော်ဒယ်အခြေခံ, ရည်ရွယ်ချက်အခြေခံ, သင်ယူသော agent များ)
  - SLM နှင့် LLM အကြား စီးပြားရေး စိတျမှု့များ
  - နယ်စပ်အထူး agent ဒီဇိုင်းပုံစံများ
  - Agent များအတွက် အရင်းအမြစ် optimization

#### အပိုင်း ၂: သေးငယ်သော ဘာသာစကား မော်ဒယ်များတွင် Function Calling
- **ဦးစားပေး အယူအဆများ**:
  - စနစ်တကျ လုပ်ငန်းစဉ် ဆောင်ရွက်မှု (ရည်ရွယ်ချက် ဖော်ထုတ်ခြင်း၊ JSON output၊ ပြင်ပ အမိန့်ထုတ်ခြင်း)
  - ပလက်ဖောင်းအလိုက် နမူနာများ (Phi-4-mini, ရွေးချယ်ထားသော Qwen မော်ဒယ်များ, Microsoft Foundry Local)
  - အဆင့်မြင့် နမူနာများ (မူလတည်းက agent များ ပူးပေါင်းဆောင်ရွက်ခြင်း, dynamic tool ရွေးချယ်မှု)
  - ထုတ်လုပ်မှုစဉ်းစားရန်များ (အမြန်နှုန်း ထိန်းချုပ်မှု, မှတ်တမ်းတင်ခြင်း, လုံခြုံရေး)

#### အပိုင်း ၃: Model Context Protocol (MCP) ပေါင်းစည်းမှု
- **ဦးစားပေး အယူအဆများ**:
  - Protocol ကျောရိုးဖွဲ့စည်းမှုနှင့် အဆင့်မြှင့်စနစ်ဒီဇိုင်း
  - များပြားသော backend ပံ့ပိုးမှု (Ollama ဖြင့် ဖွံ့ဖြိုးရေး, vLLM ဖြင့် ထောက်ပံ့မှု)
  - ချိတ်ဆက်မှု Protocols (STDIO နှင့် SSE ပုံစံများ)
  - အမွန်တကယ် အသုံးချမှုများ (ဝက်ဘ် အလိုအလြှို့လုပ်ခြင်း, ဒေတာကိုင်တွယ်မှု, API ပူးပေါင်းဆောင်ရွက်မှု)

### ကိုယ့်ကိုယ်ကို သုံးသပ်မေးခွန်းများ

1. နယ်စပ် AI agent များအတွက် အဓိက စက်ပိုင်းဆိုင်ရာ စဉ်းစားရန် အချက်များ ဘာတွေလဲ?
2. Function calling က agent ၏ စွမ်းဆောင်မှု ကောင်းမှုကို မည်သို့ တိုးတက်စေသလဲ?
3. Model Context Protocol သည် agent များဆက်သွယ်ရာတွင် မည်သို့ အရေးကြီးသလဲ?

### လက်တွေ့လေ့ကျင့်မှုများ

1. **ရိုးရှင်းသော agent**: Function calling ပါသော အခြေခံ AI agent တစ်ခု ဖန်တီးပါ (1 နာရီ)
2. **MCP ပေါင်းစည်းမှု**: Agent အက်ပလီကေးရှင်းတွင် MCP ကို အကောင်အထည်ဖော်ပါ (၃၀ မိနစ်)

## အလုပ်ရုံဆွေးနွေးပွဲ: လက်တွေ့ သင်ယူရေးလမ်းကြောင်း

### အဓိက သင်ယူရမည့် ရည်မှန်းချက်များ

- Foundry Local SDK နှင့် အကောင်းဆုံး လုပ်ထုံးလုပ်နည်းများကို အသုံးပြု၍ ထုတ်လုပ်ရန် အသင့် AI အက်ပလီကေးရှင်းများ ဖန်တီးခြင်း
- ပြီးပြည့်စုံသော အမှား ကာကွယ်ရန်နှင့် အသုံးပြုသူ တုံ့ပြန်မှု ပုံစံများကို အသုံးပြုခြင်း
- RAG pipeline များ ဖန်တီးခြင်း၊ အရည်အသွေး သုံးသပ်မှုနှင့် စွမ်းဆောင်ရည် စောင့်ကြည့်မှု
- Multi-agent စနစ်များကို Coordinator ပုံစံဖြင့် ဖွံ့ဖြိုးတိုးတက်စေရန်
- အလုပ်တာဝန် အလိုက် မော်ဒယ်ရွေးချယ်ရေး အတွက် ကျွမ်းကျင်သော မော်ဒယ် လမ်းညွှန်မှု ထိန်းချုပ်ခြင်း
- Privacy ကာကွယ်မှု ပါဝင်သော ဒေသတွင်း AI ဖြေရှင်းချက်များ တပ်ဆင်ခြင်း

### လေ့လာသင့်သော အချက်များ

#### အစည်းအဝေး ၀၁: Foundry Local နှင့် စတင်ပါ
- **ဦးစားပေး အယူအဆများ**:
  - FoundryLocalManager SDK ပေါင်းစည်းခြင်းနှင့် အလိုအလြို့ ဝန်ဆောင်မှု ရှာဖွေမှု
  - အခြေခံနှင့် စီးဆင်းမှု chat လုပ်ငန်းစဉ်များ
  - အမှား ထိန်းညှိမှု ပုံစံများ နှင့် အသုံးပြုသူ တုံ့ပြန်မှု
  - ပတ်ဝန်းကျင် အခြေခံ ဖွဲ့စည်းမှု

#### အစည်းအဝေး ၀၂: RAG ဖြင့် AI ဖြေရှင်းချက် ဖန်တီးခြင်း
- **ဦးစားပေး အယူအဆများ**:
  - Memory များအတွင်း vector embedding များနှင့် sentence-transformers
  - RAG pipeline အကောင်အထည်ဖော်မှု (ထုတ်ယူ → ဖန်တီး)
  - RAGAS မီထရစ်များဖြင့် အရည်အသွေး သုံးသပ်မှုပြုလုပ်ခြင်း
  - ရွေးချယ်လိုက်သော dependency များအတွက် import လုံခြုံရေး

#### အစည်းအဝေး ၀၃: Open Source မော်ဒယ်များ
- **ဦးစားပေး အယူအဆများ**:
  - မော်ဒယ်များ များစွာကို benchmark ပြုလုပ်ရန် မဟာဗျူဟာများ
  - အချိန်နှောင့်နှေးမှုနှင့် throughput တိုင်းတာမှုများ
  - ကြပ်မတ် စနစ် ပျက်စီးမှု နှင့် တိုးတက်ဖြေရှင်းမှု
  - မော်ဒယ် မိသားစုများအလိုက် စွမ်းဆောင်ရည် နှိုင်းယှဉ်မှု

#### အစည်းအဝေး ၀၄: နောက်ဆုံးပေါ် မော်ဒယ်များ
- **ဦးစားပေး အယူအဆများ**:
  - SLM နှင့် LLM တို့၏ နှိုင်းယှဉ်မှု နည်းလမ်း
  - Type hints နှင့် ပြည့်စုံသော output ဖော်စပ်မှု
  - မော်ဒယ်အလိုက် အမှား ထိန်းညှိမှု
  - သုံးသပ်မှုအတွက် ဖွဲ့စည်းထားသော ရလဒ်

#### အစည်းအဝေး ၀၅: AI- ကိုယ်စားလှယ်များ
- **ဦးစားပေး အယူအဆများ**:
  - Coordinator ပုံစံဖြင့် multi-agent လည်ပတ်မှု
  - Agent မှတ်ဉာဏ်စီမံခန့်ခွဲမှုနှင့် အခြေအနေ ထိန်းသိမ်းမှု
  - Pipeline မှ အမှား ထိန်းညှိမှုနှင့် အဆင့် မှတ်တမ်းတင်ခြင်း
  - စွမ်းဆောင်ရည် စောင့်ကြည့်မှုနှင့် အချက်အလက်များ

#### အစည်းအဝေး ၀၆: ကိရိယာများအဖြစ် မော်ဒယ်များ
- **ဦးစားပေး အယူအဆများ**:
  - ရည်ရွယ်ချက် ဖော်ထုတ်ခြင်းနှင့် ပုံစံ တွက်ချက်ခြင်း
  - စကားလုံးအခြေပြု မော်ဒယ်လမ်းညွှန်မှု အလက်ဂေါရီသမ်များ
  - အဆင့်မြှင့် pipeline များ (စီမံ→ ဆောင်ရွက်→ တိုးတက်ဖြစ်မြှင့်)
  - ပြည့်စုံသော function စာရွက်စာတမ်း

### ကိုယ့်ကိုယ်ကို သုံးသပ်မေးခွန်းများ

1. FoundryLocalManager သည် လက်မြောက် REST ခေါ်ဆိုမှု နှိုင်းယှဉ်သည့် ဝန်ဆောင်မှု စီမံခန့်ခွဲမှုကို မည်သို့ ပေါများစေသလဲ?
2. Sentence-transformers ကဲ့သို့ ရွေးချယ်လိုက်သော dependency များအတွက် import မကောင်းမှု ကာကွယ်မှု အရေးပါမှုကို ရှင်းပြပါ။
3. မော်ဒယ်များ များစွာအား တွဲဖက် benchmark လုပ်ရာတွင် ကြပ်မတ်မှု သက်တမ်း ပြတ်ကြားမှု ရှောင်ရှားရေး မဟာဗျူဟာများ ဘာတွေရှိသလဲ?
4. Coordinator ပုံစံဖြင့် ရွေးချယ်ထားသော အထူးပြု agent များကို မည်သို့ စီမံပေးသနည်း?
5. ကျွမ်းကျင်သော မော်ဒယ် လမ်းညွှန်ပစ္စည်းများ၏ အစိတ်အပိုင်းများကို ဖော်ပြပါ။
6. ထုတ်လုပ်မှု အသင့် အမှား ထိန်းသိမ်းမှု၏ အဓိက အချက်များ ဘာတွေလဲ?

### လက်တွေ့လေ့ကျင့်မှုများ

1. **စကားပြော အက်ပလီကေးရှင်း**: အမှား ထိန်းညှိမှုပါသော စီးဆင်း chat ကို တည်ဆောက်ပါ (၄၅ မိနစ်)
2. **RAG Pipeline**: အရည်အသွေး သုံးသပ်မှုပါ ရိုးရှင်းသော RAG တစ်ခု တည်ဆောက်ပါ (1 နာရီ)
3. **မော်ဒယ် စမ်းသပ်မှု**: မော်ဒယ် ၃ ခုအထက်ကို စွမ်းဆောင်ရည်ဒါဏ်ခြင်းဖြင့် နှိုင်းယှဉ်ပါ (1 နာရီ)
4. **Multi-Agent စနစ်**: ကိုဩဒင်းနေတာဖြင့် အထူးပြု agent ၂ ယောက်တည်ဆောက်ပါ (1.5 နာရီ)
5. **ကျွမ်းကျင်သော လမ်းညွှန်မှု**: အလုပ်တာဝန်အလိုက် မော်ဒယ်ရွေးချယ်မှု တည်ဆောက်ပါ (1 နာရီ)
6. **ထုတ်လုပ်မှု တပ်ဆင်မှု**: စောင့်ကြည့်မှုနှင့် ပြည့်စုံသော အမှား ထိန်းညှိမှု ထည့်သွင်းပါ (၄၅ မိနစ်)

### အချိန် သတ်မှတ်ခြင်း

**တိုက်ရိုက် သင်ယူမှု (၁ ပတ်)**:
- နေ့ ၁: အစည်းအဝေး ၀၁-၀၂ (Chat + RAG) - ၃ နာရီ
- နေ့ ၂: အစည်းအဝေး ၀၃-၀၄ (Benchmarking + နှိုင်းယှဉ်ခြင်း) - ၃ နာရီ
- နေ့ ၃: အစည်းအဝေး ၀၅-၀၆ (Agents + Routing) - ၃ နာရီ
- နေ့ ၄: လက်တွေ့ လေ့ကျင့်မှုများနှင့် အတည်ပြုခြင်း - ၂ နာရီ

**အပိုင်းအစိတ်အပိုင်း သင်ယူမှု (၂ ပတ်)**:
- ပတ် ၁: အစည်းအဝေး ၀၁-၀၃ (စုစုပေါင်း ၆ နာရီ)
- ပတ် ၂: အစည်းအဝေး ၀၄-၀၆ နှင့် လေ့ကျင့်မှုများ (စုစုပေါင်း ၅ နာရီ)

- Windows AI Foundry ပလက်ဖောင်းနှင့် NPU အကောင်းပြုပြင်နည်းများအတွက် ကျွမ်းကျင်မှု ရရှိခြင်း
- ပလက်ဖောင်း နှင့် တပ်ဆင်မှု အခြေအနေများ များစွာတွင် EdgeAI အသုံးပြုခြင်း
- ပလက်ဖောင်းအလိုက် အကောင်းပြုပြင်မှုများနှင့် ထုတ်လုပ်နိုင်သော EdgeAI အက်ပလီကေးရှင်းများ တည်ဆောက်ခြင်း

### လေ့လာသင့်သော အချက်များ

#### အပိုင်း ၁: Visual Studio Code အတွက် AI Toolkit
- **ဦးစားပေး အယူအဆများ**:
  - VS Code ၏ အပြည့်အစုံ Edge AI ဖွံ့ဖြိုးတိုးတက်ရေး ပတ်ဝန်းကျင်
  - Edge တပ်ဆင်မှုအတွက် မော်ဒယ် စာရင်းဇယားနှင့် ရှာဖွေရေး
  - ဒေသတွင်း စမ်းသပ်ခြင်း၊ အကောင်းပြုပြင်ခြင်းနှင့် agent ဖွံ့ဖြိုးတိုးတက်ရေး workflow များ
  - Edge ပတ်ဝန်းကျင်များအတွက် စွမ်းဆောင်ရည် စောင့်ကြည့်မှုနှင့် သုံးသပ်မှု

#### အပိုင်း ၂: Windows EdgeAI ဖွံ့ဖြိုးတိုးတက်ရေး လမ်းညွှန်
- **ဦးစားပေး အယူအဆများ**:

  - ဒေသတွင်း ဖွံ့ဖြိုးရေးနှင့် စမ်းသပ်မှုအတွက် Foundry Local CLI

#### အပိုင်း ၃: ပလက်ဖောင်းအလိုက် အကောင်အထည်ဖော်မှုများ
- **ဦးစားပေး အယူအဆများ**:
  - NVIDIA Jetson Orin Nano တပ်ဆင်မှု (67 TOPS AI စွမ်းဆောင်ရည်)
  - .NET MAUI နှင့် ONNX Runtime GenAI နည်းပညာဖြင့် မိုဘိုင်း အက်ပလီကေးရှင်းများ
  - Azure EdgeAI ဖြင့် မိုးကောင်းကင်-ဒေသတွင်း ပေါင်းစပ် ဂျီယိုဖေရာ့မာ
  - Windows ML အကောင်းပြုပြင်မှုနှင့် ပြည်ပ hardware ပံ့ပိုးမှု
  - Privacy အာမခံချက်ပါဝင်သော RAG သုံးသော Foundry Local အက်ပလီကေးရှင်းများ

### ကိုယ့်ကိုယ်ကို သုံးသပ်မေးခွန်းများ

2. မတူညီသော hardware ပလက်ဖောင်းများအလိုက် တပ်ဆင်မှု ထိန်းချုပ်မှုများကို နှိုင်းယှဉ်ပါ။
3. Windows AI Foundry သည် နယ်စပ် ဖွံ့ဖြိုးတိုးတက်မှု အတွက် ဘယ်လို အားသာချက်များ ရှိသနည်း?
4. ကျောင်းများ Edge AI အက်ပလီကေးရှင်းများတွင် NPU အကောင်းပြုပြင်မှု၏ အရေးပါတ်တာ ဘာလဲ?
5. Phi Silica API သည် NPU hardware အသုံးပြု၍ စွမ်းဆောင်ရည် အကောင်းပြုပြင်မှုကို မည်သို့ ရယူသနည်း?
6. Privacy-sensitive အက်ပလီကေးရှင်းများအတွက် ဒေသတွင်းနှင့် မိုးကောင်းကင် တပ်ဆင်မှုများ၏ အကျိုးကျေးဇူးများကို နှိုင်းယှဉ်ပါ။

3. **Cross-Platform Deployment**: အလားတူ မော်ဒယ်တစ်ခုကို ပလက်ဖောင်း နှစ်ခုတွင် တပ်ဆင်ခြင်း (၁ နာရီ)
4. **NPU Optimization**: Windows AI Foundry tools ဖြင့် NPU အဆင့်မြှင့်တင်မှု စမ်းသပ်ခြင်း (၃၀ မိနစ်)

## Module 8: Microsoft Foundry Local – အပြည့်အစုံ Developer Toolkit (ခေတ်မီပြန်လည်တည်ဆောက်ထားသော)

### အဓိကသင်ယူရမည့် ရည်မှန်းချက်များ

- Foundry Local ကို ခေတ်မီ SDK ဖြင့် ထည့်သွင်း၍ တပ်ဆင်ခြင်း
- များပြားသော agent များအတွက် ကော်အော်ဒင်းနိတ် ပုံစံများ အသုံးပြုခြင်း
- အလိုအလျောက် တာဝန်အခြေခံ စနစ်ဖြင့် ထူးချွန်သော မော်ဒယ် ရွေးချယ်ရေး လုပ်ငန်းစဉ်များ တည်ဆောက်ခြင်း
- အပြည့်အစုံ စောင့်ကြည့်ရေးနှင့် အတူ ထုတ်လုပ်ရောင်းချရန် အဆင်သင့် AI ဖြေရှင်းနည်းများ တပ်ဆင်ခြင်း
- Azure AI Foundry နှင့် ပေါင်းစပ်မည့် ရိုးရာ မဟုတ်သော တပ်ဆင်မှု နည်းလမ်းများ
- FoundryLocalManager နှင့် OpenAI client သုံးပြီး ခေတ်မီ SDK ပုံစံများ ကျွမ်းကျင်ခြင်း

### လေ့လာသင့်သော အပိုင်းများ

#### အပိုင်း ၁: ခေတ်မီ တပ်ဆင်ခြင်းနှင့် ပြင်ဆင်ခြင်း
- **အဓိက အယူအဆများ**: 
  - FoundryLocalManager SDK ပေါင်းစပ်မှု
  - အလိုအလျောက် ဝန်ဆောင်မှု ရှာဖွေရေးနှင့် ကျန်းမာရေး စောင့်ကြည့်မှု
  - ပတ်ဝန်းကျင် အခြေခံ ပြင်ဆင်မှု ပုံစံများ
  - ထုတ်လုပ်မှုဆိုင်ရာ တပ်ဆင်မှု အကြံပြုချက်များ

#### အပိုင်း ၂: အဆင့်မြင့် များပြားသော agent စနစ်များ
- **အဓိက အယူအဆများ**: 
  - ကော်အော်ဒင်းနိတ် ပုံစံနှင့် အထူးပြု agent များ
  - ပြန်လည်ရယူခြင်း၊ ရှင်းလင်းခြင်းနှင့် ဖော်ဆောင်ခြင်း agent အထူးပြုခြင်း
  - တုံ့ပြန်မှု ​အကြောင်းအရာများ မှ ပြုပြင်တိုးတက်မှုလုပ်ငန်းစဉ်များ
  - စွမ်းဆောင်ရည် စောင့်ကြည့်မှုနှင့် စာရင်းသွင်းမှုများ

#### အပိုင်း ၃: ထူးချွန်သော မော်ဒယ် ရွေးချယ်မှု
- **အဓိက အယူအဆများ**: 
  - စကားလုံးအခြေခံ မော်ဒယ် ရွေးချယ်မှု အယ်လဂေါရီသမ်များ
  - မော်ဒယ်များ အမျိုးမျိုး (အထွေထွေ၊ ရှင်းလင်းမှု၊ ကုဒ်၊ ဖန်တီးမှု)
  - ပတ်ဝန်းကျင် မတည်ငြိမ်မှု များအတွက် ပြင်ဆင်မှု ကိရိယာများ
  - ဝန်ဆောင်မှု ကျန်းမာရေး စစ်ဆေးမှုနှင့် အမှား ကိုင်တွယ်မှု

#### အပိုင်း ၄: ထုတ်လုပ်ရန် အဆင့်မှီ အကောင်အထည်ဖော်ခြင်း
- **အဓိက အယူအဆများ**: 
  - အပြည့်အစုံ ပြဿနာ ကိုင်တွယ်မှုနှင့် ထွက်မကျသည့် မဟာဗျူဟာများ
  - တောင်းဆိုမှု စောင့်ကြည့်မှုနှင့် စွမ်းဆောင်ရည် မှတ်တမ်းများ
  - ဂုဏ်သတ္တိရှိသော Jupyter notebook ဥပမာများနှင့် သတ်မှတ်ချက်များ
  - ရှိပြီးသား အပလီကေးရှင်းများနှင့် ပေါင်းစပ်မှု ပုံစံများ

### ကိုယ်ကိုယ်စစ်ဆေးမေးခွန်းများ

1. ခေတ်မီ FoundryLocalManager အရမ်းနှင့် လက်လုပ် REST အခေါ်များမှာ ဘယ်လိုကွာခြားသနည်း?
2. ကော်အော်ဒင်းနိတ် ပုံစံကို ရှင်းပြပြီး ဒါဟာ အထူးပြု agent များကို မည်သို့ ညှိနှိုင်းထားသနည်း?
3. ထူးချွန်သော router သည် မေးခွန်းအခြေအနေအရ မော်ဒယ်များကို မည်သို့ ရွေးချယ်သနည်း?
4. ထုတ်လုပ်ရန် အဆင့်မှီ AI agent စနစ်၏ အဓိက အစိတ်အပိုင်းများက ဘာများနည်း?
5. Foundry Local ဝန်ဆောင်မှုများ အတွက် ကျန်းမာရေး စောင့်ကြည့်မှု အပြည့်အစုံကို မည်သို့ အသုံးပြုသနည်း?
6. များပြားသော နည်းလမ်းများနှင့် ခေတ်မီ ပုံစံများ၏ အားသာချက်များကို နှိုင်းယှဉ်ရှင်းပြပါ။

### လက်တွေ့ လေ့ကျင့်ခန်းများ

1. **ခေတ်မီ SDK တပ်ဆင်ခြင်း**: FoundryLocalManager ကို အလိုအလျောက် ဝန်ဆောင်မှု ရှာဖွေရေးနှင့်တစ်ဆက်တည်း ပြင်ဆင်ခြင်း (၃၀ မိနစ်)
2. **များပြားသော agent စနစ်**: အထူးပြု agent များနှင့် အဆင့်မြင့် ကော်အော်ဒင်းနိတ် လည်ပတ်ခြင်း (၃၀ မိနစ်)
3. **ထူးချွန်သော routing**: မတူညီသော မေးခွန်း အမျိုးအစားများ ဖြင့် မော်ဒယ် router ကို စမ်းသပ်ခြင်း (၃၀ မိနစ်)
4. **အပြန်အလှန် စူးစမ်း လေ့လာခြင်း**: Jupyter notebooks များ သုံးပြီး အဆင့်မြင့် လုပ်ဆောင်ချက်များ လေ့လာခြင်း (၄၅ မိနစ်)
5. **ထုတ်လုပ်မှု တပ်ဆင်ခြင်း**: စောင့်ကြည့်မှုနှင့် အမှား ကိုင်တွယ် ဝန်းကျင်များ တပ်ဆင်မှု (၃၀ မိနစ်)
6. **ဖျော်ဖြေ ပေါင်းစပ်မှု**: Azure AI Foundry fallback ကိစ္စရပ်များ ပြင်ဆင်ခြင်း (၃၀ မိနစ်)

## မီနီ ပရောဂျက် အကြံပြုချက်များ

EdgeAI အယူအဆ များကို လေ့ကျင့်ရန် အောက်ပါ ပရောဂျက်များကို ပြီးမြောက်စေပါ (တစ်ခုလျှင် ၂-၄ နာရီ ခန့်)

### အခြေခံ ပရောဂျက်များ (တစ်ခုလျှင် ၂-၃ နာရီ)
၁။ **Edge စာသား ကူညီသူ**: အသေးစား ဘာသာစကား မော်ဒယ် အသုံးပြု၍ အော့ဖ်လိုင်း စာသား ပြည့်စုံရေးကိရိယာ တည်ဆောက်ခြင်း
၂။ **မော်ဒယ် နှိုင်းယှဉ်မှု ဒိုင်ယာလော့ ဘုတ်ပြား**: မတူညီသော SLM များ၏ စွမ်းဆောင်ရည် အချက်အလက် များကို ပုံဖော်ခြင်း
၃။ **အဆင်မြှင့်တင်မှု စမ်းသပ်မှု**: အခြေခံ မော်ဒယ်တစ်ခုအပေါ် မတူညီသော Quantization အဆင့်များ၏ ပါဝင်မှုကို တိုင်းတာခြင်း

### အလယ်အလတ် ပရောဂျက်များ (တစ်ခုလျှင် ၃-၄ နာရီ)
၄။ **AI Toolkit လုပ်ငန်းစဉ်**: VS Code AI Toolkit အသုံးပြုပြီး မော်ဒယ်တစ်ခုကို အစမှအဆုံး အဆင်မြှင့်တင်ပြီး တပ်ဆင်ခြင်း
၅။ **Windows AI Foundry လျှောက်လွှာ**: Phi Silica API နှင့် NPU စွမ်းဆောင်ရည်မြှင့်တင်မှု အသုံးပြု၍ Windows အက်ပ်တစ်ခု ဖန်တီးခြင်း
၆။ **Cross-Platform Deployment**: OpenVINO ဖြင့် Windows နှင့် .NET MAUI ဖြင့် မိုဘိုင်းတွင် တူညီသော အဆင်မြှင့်တင်ထားသော မော်ဒယ် တပ်ဆင်ခြင်း
၇။ **Function Calling Agent**: edge ရာဇဝင်များအတွက် function calling အင်အားများပါရှိသော AI agent တည်ဆောက်ခြင်း

### အဆင့်မြင့် ပေါင်းစပ်မှု ပရောဂျက်များ (တစ်ခုလျှင် ၄-၅ နာရီ)
၈။ **OpenVINO အဆင်မြှင့်တင်ခြင်း လုပ်ငန်းစဉ်**: NNCF နှင့် GenAI ကိရိယာများ အသုံးပြုပြီး အပြည့်အစုံ မော်ဒယ် အဆင်မြှင့်တင်ခြင်း
၉။ **SLMOps လုပ်ငန်းစဉ်**: သင်တန်းမှ edge deployment အထိ မော်ဒယ် အသက်မွေးဝမ်းကျောင်း လုပ်ငန်းစဥ် တစ်ခု ပြုလုပ်ခြင်း
၁၀။ **များပြားသော မော်ဒယ် Edge စနစ်**: edge hardware တွင် အတူတကွ လုပ်ဆောင်သော အထူးပြု မော်ဒယ်များ စုစည်းပြီး တပ်ဆင်ခြင်း
၁၁။ **MCP ပေါင်းစပ်မှု စနစ်**: ကိရိယာကို တိုတောင်းဆက်သွယ်နိုင်ရန် Model Context Protocol အား အသုံးပြု agent စနစ်တစ်ခု ဖန်တီးခြင်း

## နိဂုံးချုပ်

EdgeAI သည် လူမှုစိတ်တဇအာရုံပြု AI ကို တိုက်ရိုက် ကိရိယာများသို့ ချိတ်ဆက်အသုံးပြုနိုင်စေပြီး ကိုယ်ရေးအချက်အလက် များ စောင့်ရှောက်မှု၊ နောက်ကျမှုနည်းခြင်းနှင့် ချိတ်ဆက်မှု ဆက်စပ်သော စိုးရိမ်ချက်များကို ဖြေရှင်းကာ စွမ်းဆောင်ရည်မြင့် စနစ်များ တည်ဆောက်ရန် နယ်ပယ်အသစ် ဖြစ်သည်။ ဒီ ၂၀ နာရီ သင်တန်းက သင်တို့ကို အခြေခံ သိရှိမှုနှင့် လက်တွေ့ကျွမ်းကျင်မှုများဖြင့် ပုံစံပြပြီး ချက်ချင်း EdgeAI နည်းပညာများ အသုံးပြုနိုင်ရန် ကူညီပါသည်။

သင်တန်းသည် ရိုးရှင်းကျဉ်းမြောင်းပြီး အရေးကြီးဆုံး အယူအဆများကို သက်သာစွာ သင်ကြားပေးသောကြောင့် အချိန်ပို မကုန်ဆုံးဘဲ စွမ်းဆောင်ရည်ကြီးမြတ်သော ကျွမ်းကျင်သူ ျဖစ္လာနိုင်ပါသည်။ ရိုးရှင်းသော်လည်း လက်တွေ့ လေ့ကျင့်မှုများ ပြုလုပ်ခြင်းက သင်သင်ကြားသည့် အချက်အလက်များကို တိကျစွာ သတိထားစေရန် အဓိက ဖြစ်ပါသည်။

ပျော်ရွှင်စရာ သင်ယူမှု ဖြစ်ပါစေ!
