# 第三單元：開源模型發現與管理

## 概覽

本單元聚焦於使用 Foundry Local 進行實務模型發現與管理。您將學習如何列出可用模型、測試不同選項，並了解基礎效能特性。此方法強調使用 foundry CLI 的實際操作，幫助您為您的使用案例選擇合適的模型。

## 學習目標

- 掌握 foundry CLI 命令以進行模型發現與管理
- 理解模型快取與本地儲存模式
- 學會快速測試與比較不同模型
- 建立模型選擇與基準測試的實務工作流程
- 探索通過 Foundry Local 可用的日益增長的模型生態系統

- 完成第一單元：Foundry Local 入門

## 第七部分：故障排除與最佳實踐

### 常見問題與解決方案

**模型無法啟動：**
```cmd
REM Check service status
foundry service status

REM Restart service if needed
foundry service stop
foundry service start

REM Try with verbose output
foundry model run phi-4-mini --verbose
```

**記憶體不足：**
- 從較小的模型開始（`phi-4-mini`）
- 關閉其他應用程式
- 若經常觸及限制，考慮升級 RAM

**效能緩慢：**
- 確認模型已完全載入（檢查詳細輸出）
- 關閉不必要的背景應用程式
- 考慮使用更快的儲存裝置（SSD）

### 最佳實踐

1. <strong>從小開始</strong>：先用 `phi-4-mini` 以驗證設定
2. <strong>一次一個模型</strong>：啟動新模型前停止舊模型
3. <strong>監控資源</strong>：關注記憶體使用狀況
4. <strong>持續測試</strong>：使用相同提示詞作公正比較
5. <strong>紀錄結果</strong>：保留模型效能的筆記以供使用案例參考

## 第一部分：使用 Foundry CLI 進行模型發現

### 基本模型管理命令

foundry CLI 提供簡單的模型發現與管理命令：

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### 執行您的第一個模型

從受歡迎且已測試的模型開始，以了解效能特性：

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**注意：** `--verbose` 標誌提供詳細啟動資訊，包括：
- 模型下載進度（首次運行時）
- 記憶體分配細節
- 服務綁定資訊
- 效能初始化指標

### 瞭解模型類別

**小型語言模型 (SLMs)：**
- `phi-4-mini`：快速高效，適合一般聊天

**中型模型：**
- `qwen2.5-7b`：出色的推理與更長的上下文
- `deepseek-r1-7b`：優化用於程式碼生成

**大型模型：**
- `llama-3.2`：Meta 最新開源模型
- `qwen2.5-14b`：企業級推理能力

- `qwen2.5-7b`：約 4.1 GB  
- `deepseek-r1-7b`：約 4.3 GB
- `llama-3.2`：約 4.9 GB

**儲存最佳實踐：**

- 移除未使用模型以釋放空間：`foundry cache clean`
- 監控磁碟使用，尤其是在較小的 SSD 上
- 考慮模型大小與能力之間的權衡

### 硬體需求指南

**最低系統需求：**
```
phi-4-mini:     8GB RAM,  entry-level CPU
phi-4:         12GB RAM,  mid-range CPU
qwen2.5-7b:    16GB RAM,  mid-range CPU
deepseek-r1:   16GB RAM,  mid-range CPU
```

**推薦以達最佳效能：**
- 32GB 以上 RAM，方便多模型切換
- 使用 SSD 儲存以加速模型載入
- 採用具有良好單線程效能的現代 CPU
- 支援 NPU（Windows 11 Copilot+ 電腦）以加速運算

## 第五部分：簡單模型基準測試

### 基礎效能測試

透過以下簡單方法比較模型效能：

```python
# simple_bench.py - 基於範例03模式
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# 測試目前正在執行的模型
if __name__ == "__main__":
    # 使用不同的模型進行測試（先啟動每個模型）
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```

### 手動品質評估

對每個模型使用一致的提示詞並手動評估：

**測試提示詞：**
1. 「用簡單的話解釋量子計算。」
2. 「撰寫一個 Python 函數來排序清單。」
3. 「遠端工作的優缺點是什麼？」
4. 「總結邊緣 AI 的好處。」

**評估標準：**
- <strong>準確度</strong>：資訊是否正確？
- <strong>清晰度</strong>：解釋是否易於理解？
- <strong>完整性</strong>：是否完整回應問題？
- <strong>速度</strong>：回應速度快慢？
