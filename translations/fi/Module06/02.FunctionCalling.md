## Mikä on funktiokutsu?

Funktiokutsu on tehokas ominaisuus, joka mahdollistaa pienten kielimallien (SLM) vuorovaikutuksen ulkoisten työkalujen, API:en ja palveluiden kanssa. Sen sijaan, että ne olisivat rajoittuneita vain koulutusdataansa, SLM:t voivat nyt:

- **Yhdistää ulkoisiin API:hin** (sääpalvelut, tietokannat, hakukoneet)
- **Suorittaa tiettyjä funktioita** käyttäjän pyyntöjen perusteella
- **Hakea reaaliaikaista tietoa** eri lähteistä
- **Suorittaa laskennallisia tehtäviä** erikoistyökalujen avulla
- **Ketjuttaa useita toimintoja** monimutkaisten työnkulkujen toteuttamiseksi

Tämä ominaisuus muuttaa SLM:t staattisista tekstin tuottajista dynaamisiksi tekoälyagentteiksi, jotka voivat suorittaa todellisen maailman tehtäviä.

## Miten funktiokutsu toimii

Funktiokutsuprosessi noudattaa systemaattista työnkulkua:

### 1. Työkalujen integrointi
- **Ulkoiset työkalut**: SLM:t voivat yhdistyä sää-API:hin, tietokantoihin, web-palveluihin ja muihin ulkoisiin järjestelmiin
- **Funktioiden määrittely**: Kukin työkalu määritellään tietyillä parametreilla, syöte-/tulostemuodoilla ja kuvauksilla
- **API-yhteensopivuus**: Työkalut integroidaan standardoitujen rajapintojen (REST API:t, SDK:t jne.) kautta

### 2. Funktion määrittely
Funktiot määritellään kolmella keskeisellä komponentilla:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Tavoitteen tunnistus
- **Luonnollisen kielen käsittely**: SLM analysoi käyttäjän syötteen ymmärtääkseen tavoitteen
- **Funktion määräminen**: Päätetään, mitä funktio(ita) tarvitaan pyynnön toteuttamiseen
- **Parametrien poiminta**: Tunnistaa ja poimii vaadittavat parametrit käyttäjän viestistä

### 4. JSON-vastauksen generointi
SLM luo rakenteellista JSONia, joka sisältää:
- Kutsuttavan funktion nimen
- Vaaditut parametrit oikeilla arvoilla
- Suoritusympäristön ja metatiedot

### 5. Ulkoinen suoritus
- **Parametrien validointi**: Varmistaa, että kaikki vaaditut parametrit ovat olemassa ja oikein muotoiltuja
- **Funktion suoritus**: Sovellus suorittaa määritellyn funktion annetuilla parametreilla
- **Virheenkäsittely**: Hallinnoi virheitä, aikakatkaisuja ja virheellisiä vastauksia

### 6. Vastauksen integraatio
- **Tuloksen käsittely**: Funktion tulos palautetaan SLM:lle
- **Kontekstin yhdistäminen**: SLM ottaa tulokset osaksi vastaustaan
- **Käyttäjäviestintä**: Esittää tiedot luonnollisessa, keskustelumuotoisessa esitystavassa

## Sovelluskohtaiset tilanteet

### Datan hakeminen
Muunna luonnollisen kielen kyselyt rakenteellisiksi API-kutsuiksi:
- **"Näytä viimeisimmät tilaukseni"** → Tietokantakysely käyttäjätunnuksella ja päivämääräsuodattimilla
- **"Mikä on sää Tokiossa?"** → Sää-API-kutsu sijaintiparametrilla
- **"Etsi Johnin viime viikolla lähettämät sähköpostit"** → Sähköpostipalvelun haku lähettäjän ja ajankohdan perusteella

### Toimintojen suoritus
Muunna käyttäjän pyynnöt tietyiksi funktiokutsuiksi:
- **"Ajoita kokous huomiseksi klo 14"** → Kalenterin API-integraatio
- **"Lähetä viesti tiimille"** → Viestintäalustan API
- **"Luo varmuuskopio tiedostoistani"** → Tiedostojärjestelmän toiminto

### Laskennalliset tehtävät
Käsittele monimutkaisia matemaattisia tai loogisia operaatioita:
- **"Laske korkoa korolle $10,000 summalle 5 %:lla 10 vuotta"** → Talouslaskentafunktio
- **"Analysoi tämä aineisto trendejä varten"** → Tilastollisen analyysin työkalut
- **"Optimoi tämä reitti toimitusta varten"** → Reittioptimointialgoritmit

### Datan käsittelyn työnkulut
Ketjuta useita funktiokutsuja monimutkaisiin operaatioihin:
1. **Hae data** useista lähteistä
2. **Jäsennä ja validoi** tieto
3. **Muuta** data vaadittuun muotoon
4. **Tallenna tulokset** sopiviin järjestelmiin
5. **Luo raportit** tai visualisoinnit

### UI/UX-integraatio
Mahdollista dynaamiset käyttöliittymän päivitykset:
- **"Näytä myyntidata kojelaudalla"** → Kaavioiden generointi ja näyttö
- **"Päivitä kartta uusilla sijainneilla"** → Paikkatietojen integraatio
- **"Päivitä varaston näyttö"** → Reaaliaikainen datan synkronointi

### Mukautettujen funktioiden toteutus

Voit myös määritellä omia funktioita Qwen3:lle:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Simuloi sää-API-kutsua
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Käytä mukautettua työkalua
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

        }
    }

        }

### Yleiset ongelmat ja ratkaisut

#### Ongelma 1: Funktiota ei kutsuta
**Oireet**: Malli vastaa tekstinä eikä kutsu funktiota

**Ratkaisut**:
1. **Tarkista funktion kuvaus**: Varmista, että se vastaa selkeästi käyttäjän tarkoitusta
2. **Varmista parametrien määrittelyt**: Kaikki vaaditut parametrit on oikein määritelty
3. **Tarkista järjestelmäkehote**: Sisällytä selkeät ohjeet siitä, milloin funktioita käytetään
4. **Testaa eksplisiittisillä pyynnöillä**: Kokeile esimerkiksi "Käytä sääfunktiota saadaksesi tiedot Lontoosta"

#### Ongelma 2: Virheelliset parametrit
**Oireet**: Funktiota kutsutaan väärillä tai puuttuvilla parametreilla

**Ratkaisut**:
1. **Lisää parametriesimerkkejä**: Sisällytä esimerkkivarat parametrien kuvauksiin
2. **Käytä enum-rajoituksia**: Rajoita parametriarvot tiettyihin vaihtoehtoihin kun mahdollista
3. **Toteuta oletusarvot**: Tarjoa järkevät oletusarvot vapaaehtoisille parametreille

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }
}
```

#### Ongelma 3: Rinnakkaisten funktioiden kutsun epäonnistuminen
**Oireet**: Vain yksi funktio suoritetaan, vaikka useita pitäisi ajaa

**Ratkaisut**:
1. **Tarkista mallin tuki**: Varmista, että mallisi tukee rinnakkaisia funktiokutsuja
2. **Päivitä järjestelmäkehote**: Lisää viestiin "joitain työkaluja" tai "useita työkaluja"
3. **Käytä sopivia malliversioita**: Suositus Phi-4-mini:3.8b-fp16 Ollama-käyttöön

#### Ongelma 4: Mallipohjaongelmat Ollamassa
**Oireet**: Funktiokutsut eivät toimi oletus-Ollama-asetuksilla

**Ratkaisut**:
1. **Käytä mukautettua ModelFilea**: Käytä tässä ohjeessa annettua korjattua mallia
2. **Päivitä Ollama**: Käytä versiota 0.5.13 tai uudempaa
3. **Tarkista mallin kvantisointi**: Korkeammat kvantisointitasot (Q8_0, fp16) toimivat paremmin kuin voimakkaasti kvantisoidut versiot

### Suorituskyvyn optimointi

#### 1. Tehokas funktiosuunnittelu
- **Pidä funktiot ytimekkäinä**: Jokaisella funktiolla tulisi olla yksi selkeä tarkoitus

import asyncio
import aiohttp

async def batch_function_calls(function_calls):
    """Execute multiple function calls concurrently"""
    async with aiohttp.ClientSession() as session:
        tasks = []
        for call in function_calls:
            if call["name"] == "fetch_url":
                task = fetch_url_async(session, call["parameters"]["url"])
                tasks.append(task)
        
        results = await asyncio.gather(*tasks)
        return results

async def fetch_url_async(session, url):
    async with session.get(url) as response:
        return await response.text()

from datetime import datetime

@dataclass
class FunctionResult:
    """Standard result format for all function calls"""
    success: bool
    data: Any = None
    error: str = None
    execution_time: float = 0.0
    timestamp: datetime = None

class EnterpriseAIAgent:
    """Production-ready AI agent with comprehensive function calling capabilities"""
    
    def __init__(self, config: Dict):
        self.config = config
        self.functions = {}
        self.audit_log = []
        self.rate_limiters = {}
        
        # Alusta ydintoiminnot

    def _register_core_functions(self):
        """Register all available business functions"""

        self.register_function(

    def register_function(self, name: str, description: str, parameters: Dict, 
                         handler: callable, rate_limit: int = 60):
        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Vahvista, että funktio on olemassa
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Tarkista rajoitukset
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Vahvista parametrit
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Suorita funktio
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Kirjaa onnistunut suoritus
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Kirjaa epäonnistunut suoritus
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Nollaa laskuri, jos minuutti on kulunut
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Tarkista, että ollaan rajan alapuolella
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Tarkista vaaditut parametrit
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Vahvista parametrien tyypit ja rajoitteet
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Tyyppivahvistus
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # Luettelon vahvistus
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
        
        return FunctionResult(success=True)

## Yhteenveto

Funktiokutsut pienissä kielimalleissa edustavat paradigman muutosta staattisista tekoälyavustajista dynaamisiksi, kykeneviksi agenteiksi, jotka voivat olla vuorovaikutuksessa todellisen maailman kanssa. Tämä opas kattoi:

### Keskeiset opit

1. **Perusymmärrys**: Funktiokutsut mahdollistavat SLM:ien laajentamisen koulutusdatansa ulkopuolelle yhdistämällä ulkoisiin työkaluihin ja palveluihin.

2. **Toteutusvaihtoehdot**: Useita tapoja on, alhaisesta tasosta mukautettuihin malleihin ja korkean tason kehyksiin kuten Qwen-Agent ja Foundry Local.

3. **Tuotantokysymykset**: Yrityskäyttö vaatii huomion virheenkäsittelyyn, kutsujen rajoituksiin, tietoturvaan ja lokitukseen.

4. **Suorituskyvyn optimointi**: Hyvä funktiomuotoilu, tehokas suoritus ja älykäs välimuisti parantavat huomattavasti vasteaikoja.

### Tulevaisuuden näkymät

SLM-teknologian kehittyessä voimme odottaa:

- **Parannettua funktiokutsojen tarkkuutta**: Parempi tavoitteen tunnistus ja parametrien poiminta
- **Parannettua rinnakkaiskäsittelyä**: Kehittyneempää monifunktioiden orkestrointia
- **Parempia integraatiostandardeja**: Standardoituja protokollia työkalujen yhdistämiseksi
- **Edistyneitä turvallisuusominaisuuksia**: Kehittyneitä tunnistus- ja valtuutusmekanismeja
- **Laajentuvaa ekosysteemiä**: Kasvava valikoima valmiita funktioita ja integraatioita

### Aloittaminen

Funktiokutsujen käyttöönoton projektissasi aloitusvinkit:

1. **Aloita yksinkertaisesti**: Aloita perus yksittäisfunktiotapauksista
2. **Valitse kehys**: Valitse suora toteutus (Ollama/Phi-4) tai kehysavusteinen (Qwen-Agent)
3. **Suunnittele funktiot huolella**: Panosta selkeisiin ja hyvin dokumentoituihin funktiomäärittelyihin
4. **Toteuta virheenkäsittely**: Rakenna vankka virheenkäsittely alusta alkaen
5. **Kasvata asteittain**: Edisty yksinkertaisista monimutkaisempiin tilanteisiin kokemuksen kasvaessa

Funktiokutsut muuttavat SLM:t vaikuttavista tekstin tuottajista käytännöllisiksi tekoälyagenteiksi, jotka ratkovat todellisen maailman ongelmia. Seuraamalla tämän oppaan kaavoja ja käytäntöjä voit rakentaa tehokkaita, luotettavia tekoälyjärjestelmiä, jotka ylittävät perinteiset keskustelukäyttöliittymät.
