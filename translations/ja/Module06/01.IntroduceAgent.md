## AIエージェントの理解：基礎と分類

### 定義と核心概念

人工知能（AI）エージェントとは、ユーザーや他のシステムの代わりに自律的にタスクを実行し、ワークフローを設計し、利用可能なツールを活用できるシステムやプログラムを指します。従来の質問への応答を行うAIとは異なり、エージェントは目標達成のために独立して行動できます。

### エージェント分類フレームワーク

エージェントの境界を理解することで、異なる計算シナリオに適したエージェントタイプの選択が可能になります：

- **🔬 単純反射エージェント**：即時の知覚に応答するルールベースシステム（サーモスタット、基本的な自動化）
- **📱 モデルベースエージェント**：内部状態と記憶を保持するシステム（ロボット掃除機、ナビゲーションシステム）
- **⚖️ 目標指向エージェント**：目標達成のための計画と実行を行うシステム（ルートプランナー、タスクスケジューラ）
- **🧠 学習エージェント**：時間と共にパフォーマンスを改善する適応システム（推薦システム、パーソナライズアシスタント）

### AIエージェントの主な利点

AIエージェントは以下の基本的な利点を提供し、エッジコンピューティングに最適です：

<strong>運用自律性</strong>：エージェントは常時の人間の監督なしに独立してタスクを実行でき、リアルタイムアプリケーションに理想的です。最小限の監督で適応的な動作を維持し、リソースが限定されたデバイスでの展開を可能にし、運用負荷を軽減します。

<strong>展開の柔軟性</strong>：これらのシステムはインターネット接続が不要なオンデバイスAI機能を実現し、ローカル処理によるプライバシーとセキュリティを強化し、ドメイン固有のアプリケーションにカスタマイズでき、さまざまなエッジコンピューティング環境に適用可能です。

<strong>コスト効率</strong>：エージェントシステムはクラウドベースのソリューションに比べコスト効率の良い展開を可能にし、運用コストを削減し、エッジアプリケーションの帯域幅要件を低減します。

## 高度な小型言語モデル戦略

### SLM（小型言語モデル）の基本

小型言語モデル（SLM）は、一般的な消費者向け電子機器に収まり、1人のユーザーのエージェント要求を処理する際に実用的な低遅延推論を行える言語モデルです。実際には、SLMは通常、100億パラメーター未満のモデルを指します。

<strong>フォーマット発見機能</strong>：SLMはさまざまな量子化レベル、クロスプラットフォームの互換性、リアルタイムパフォーマンス最適化、エッジ展開機能を高度にサポートします。ユーザーはローカル処理とブラウザベースの展開向けのWebGPUサポートによる強化されたプライバシーにアクセスできます。

<strong>量子化レベルのコレクション</strong>：人気のあるSLMフォーマットには、モバイルアプリ向けのバランスの取れた圧縮を提供するQ4_K_M、品質重視のエッジ展開用Q5_K_Sシリーズ、強力なエッジデバイス向けのほぼオリジナル精度のQ8_0、超低リソースシナリオ向けの実験的フォーマットQ2_Kなどがあります。

### GGUF（General GGML Universal Format）によるSLM展開

GGUFは、CPUおよびエッジデバイス上で量子化されたSLMを展開するための主要フォーマットであり、特にエージェント型アプリケーション向けに最適化されています：

<strong>エージェント最適化機能</strong>：ツール呼び出し、構造化出力生成、多ターン会話へのサポートを強化し、SLMの変換および展開に包括的なリソースを提供します。クロスプラットフォームの互換性により異なるエッジデバイスで一貫したエージェント動作が保証されます。

<strong>パフォーマンス最適化</strong>：GGUFはエージェントワークフローの効率的なメモリ使用を可能にし、多エージェントシステムの動的モデル読み込みをサポートし、リアルタイムエージェント対話のための最適化推論を提供します。

### エッジ最適化SLMフレームワーク

#### エージェント向けのLlama.cpp最適化

Llama.cppは、エージェント型SLM展開に特化した最先端の量子化技術を提供します：

<strong>エージェント専用量子化</strong>：このフレームワークは、モバイルエージェント展開に最適な75％のサイズ削減を実現するQ4_0、エッジ推論エージェント向けの品質と圧縮のバランスを取ったQ5_1、本格的なエージェントシステム向けのほぼオリジナル品質のQ8_0をサポートします。高度なフォーマットは極限エッジシナリオ向けの超圧縮エージェントを可能にします。

<strong>実装の利点</strong>：SIMDアクセラレーションによるCPU最適化推論でメモリ効率の良いエージェント実行を提供します。x86、ARM、Apple Siliconのアーキテクチャ全体でのクロスプラットフォーム互換性により、普遍的なエージェント展開能力を実現します。

#### Apple MLXフレームワークによるSLMエージェント

Apple MLXは、Apple Siliconデバイス上のSLM搭載エージェント向けにネイティブ最適化を提供します：

**Apple Siliconエージェント最適化**：Metal Performance Shaders統合のユニファイドメモリアーキテクチャ、自動混合精度のエージェント推論、多エージェントシステム向けメモリ帯域幅の最適化を活用します。SLMエージェントはMシリーズチップで卓越したパフォーマンスを発揮します。

<strong>開発機能</strong>：PythonおよびSwift APIのサポート、エージェント特有の最適化、エージェント学習のための自動微分、Apple開発ツールとのシームレスな統合により、包括的なエージェント開発環境を提供します。

#### クロスプラットフォームSLMエージェント向けONNX Runtime

ONNX Runtimeは、異なるハードウェアプラットフォームとオペレーティングシステムで一貫してSLMエージェントを実行できるユニバーサル推論エンジンを提供します：

<strong>ユニバーサル展開</strong>：ONNX RuntimeはWindows、Linux、macOS、iOS、Androidプラットフォーム間で一貫したSLMエージェントの動作を保証します。このクロスプラットフォーム対応により、開発者は一度書くだけで全てに展開でき、多プラットフォームアプリの開発と保守の負荷を大幅に軽減します。

<strong>ハードウェアアクセラレーションオプション</strong>：このフレームワークはCPU（Intel、AMD、ARM）、GPU（NVIDIA CUDA、AMD ROCm）、および特殊アクセラレータ（Intel VPU、Qualcomm NPU）向けの最適化された実行プロバイダーを提供します。SLMエージェントはコード変更なしに利用可能な最適なハードウェアを自動的に活用できます。

<strong>生産準備機能</strong>：ONNX Runtimeは、高速推論のためのグラフ最適化、リソース制約環境向けメモリ管理、性能分析用の包括的なプロファイリングツールなど、生産エージェント展開に不可欠なエンタープライズグレードの機能を提供します。PythonおよびC++ APIをサポートし柔軟な統合が可能です。


## エージェント型システムにおけるSLMとLLMの高度な比較

### エージェント向けのSLMの利点

<strong>運用効率</strong>：SLMはLLMに比べてエージェントタスクのコストを10〜30倍削減し、大規模なリアルタイムエージェント応答を可能にします。計算の複雑さが低いため推論時間が短く、インタラクティブなエージェントアプリケーションに理想的です。

<strong>エッジ展開能力</strong>：SLMはインターネット依存なしにオンデバイスでエージェント実行を可能にし、ローカル処理によるプライバシー強化、ドメイン固有エージェントアプリケーションのカスタマイズを実現し、さまざまなエッジ環境に適合します。

<strong>エージェント特化最適化</strong>：SLMはツール呼び出し、構造化出力生成、典型的なエージェントタスクの70〜80％を占めるルーチン意思決定ワークフローに優れています。

### エージェントシステムにおけるSLMとLLMの使い分け

**SLMに最適**：
- <strong>繰り返しのエージェントタスク</strong>：データ入力、フォーム記入、定型API呼び出し
- <strong>ツール統合</strong>：データベースクエリ、ファイル操作、システム操作
- <strong>構造化ワークフロー</strong>：既定のエージェントプロセスの追従
- <strong>ドメイン固有エージェント</strong>：顧客サービス、スケジューリング、基本的分析
- <strong>ローカル処理</strong>：プライバシーに敏感なエージェント操作

**LLMが適している場合**：
- <strong>複雑な推論</strong>：新規問題解決、戦略的計画
- <strong>自由形式の会話</strong>：一般的なチャット、創造的な議論
- <strong>広範な知識を要するタスク</strong>：広範な一般知識を必要とする研究
- <strong>新規状況</strong>：全く新しいエージェントシナリオの対応

### ハイブリッドエージェントアーキテクチャ

最適なアプローチは、異種エージェント型システムにおいてSLMとLLMを組み合わせることです：

<strong>スマートなエージェントオーケストレーション</strong>：
1. **SLMを主軸に**：定型的エージェントタスクの70〜80％をローカルで処理
2. **必要に応じてLLM**：複雑なクエリはクラウドベースの大規模モデルへルーティング
3. **専門的なSLM**：異なるエージェントドメインごとに異なる小型モデルを使用
4. <strong>コスト最適化</strong>：高価なLLM呼び出しをインテリジェントなルーティングで最小限に

```python
import asyncio
from foundry_local import FoundryLocalManager
from microsoft_agent_framework import Agent, Config, Tool

class ProductionAgentService:
    def __init__(self, model_alias="phi-4-mini"):
        self.foundry = FoundryLocalManager(model_alias)
        self.agent = self._create_agent()
        
    def _create_agent(self):
        config = Config(
            name="production-customer-service",
            model_provider="foundry-local",
            model_id=self.foundry.get_model_info().id,
            endpoint=self.foundry.endpoint,
            api_key=self.foundry.api_key,
            max_tokens=512,
            temperature=0.1,
            timeout=30.0
        )
        
        agent = Agent(config=config)
        
        # 本番用ツールを追加
        @agent.tool
        def lookup_customer(customer_id: str) -> dict:
            """Look up customer information from local database."""
            return self.local_db.get_customer(customer_id)
            
        @agent.tool
        def create_ticket(issue: str, priority: str = "medium") -> str:
            """Create a support ticket."""
            ticket_id = self.ticketing_system.create(issue, priority)
            return f"Created ticket {ticket_id}"
            
        return agent
    
    async def process_request(self, user_input: str) -> str:
        """Process user request with error handling and monitoring."""
        try:
            response = await self.agent.chat_async(user_input)
            self.log_interaction(user_input, response, "success")
            return response
        except Exception as e:
            self.log_interaction(user_input, str(e), "error")
            return "I'm experiencing technical difficulties. Please try again."
    
    def health_check(self) -> dict:
        """Check service health for monitoring."""
        return {
            "foundry_status": self.foundry.health_check(),
            "model_loaded": self.foundry.is_model_loaded(),
            "endpoint": self.foundry.endpoint,
            "memory_usage": self.foundry.get_memory_usage()
        }

response = await service.process_request("I need help with my order #12345")
```

```python
from foundry_local import FoundryLocalManager
from microsoft_agent_framework import AgentOrchestrator, Agent, Config

class MultiAgentProductionSystem:
    def __init__(self):
        self.agents = self._initialize_agents()
        self.orchestrator = AgentOrchestrator(list(self.agents.values()))
        
    def _initialize_agents(self):
        agents = {}
        
        # 軽量ルーティングエージェント
        routing_foundry = FoundryLocalManager("qwen2.5-0.5b")
        agents["router"] = Agent(Config(
            name="request-router",
            model_provider="foundry-local",
            endpoint=routing_foundry.endpoint,
            api_key=routing_foundry.api_key,
            role="Route user requests to appropriate specialized agents"
        ))
        
        # カスタマーサービスエージェント
        service_foundry = FoundryLocalManager("phi-4-mini")
        agents["customer_service"] = Agent(Config(
            name="customer-service",
            model_provider="foundry-local",
            endpoint=service_foundry.endpoint,
            api_key=service_foundry.api_key,
            role="Handle customer service inquiries and support requests"
        ))
        
        # テクニカルサポートエージェント
        tech_foundry = FoundryLocalManager("qwen2.5-coder-0.5b")
        agents["technical"] = Agent(Config(
            name="technical-support",
            model_provider="foundry-local",
            endpoint=tech_foundry.endpoint,
            api_key=tech_foundry.api_key,
            role="Provide technical assistance and troubleshooting"
        ))
        
        return agents
    
    async def process_request(self, user_input: str) -> str:
        """Route and process user requests through appropriate agents."""
        # 適切なエージェントへリクエストをルーティング
        routing_result = await self.agents["router"].chat_async(
            f"Classify this request and route to customer_service or technical: {user_input}"
        )
        
        # ルーティングに基づいてターゲットエージェントを決定
        target_agent = "customer_service" if "customer" in routing_result.lower() else "technical"
        
        # 専門エージェントで処理
        response = await self.agents[target_agent].chat_async(user_input)
        
        return response

# 本番環境へのデプロイ
system = MultiAgentProductionSystem()
response = await system.process_request("My application keeps crashing")
```

#### エンタープライズ機能とモニタリング

<strong>ヘルスモニタリングと可観測性</strong>：
```python
from foundry_local import FoundryLocalManager
import asyncio
import logging

class FoundryMonitoringService:
    def __init__(self):
        self.managers = {}
        self.metrics = []
        
    def add_model(self, alias: str) -> FoundryLocalManager:
        """Add a model to monitoring."""
        manager = FoundryLocalManager(alias)
        self.managers[alias] = manager
        return manager
    
    async def collect_metrics(self):
        """Collect performance metrics from all Foundry Local instances."""
        metrics = {
            "timestamp": time.time(),
            "models": {}
        }
        
        for alias, manager in self.managers.items():
            try:
                model_metrics = {
                    "status": "healthy" if manager.health_check() else "unhealthy",
                    "memory_usage": manager.get_memory_usage(),
                    "inference_count": manager.get_inference_count(),
                    "average_latency": manager.get_average_latency(),
                    "error_rate": manager.get_error_rate()
                }
                metrics["models"][alias] = model_metrics
            except Exception as e:
                logging.error(f"Failed to collect metrics for {alias}: {e}")
                metrics["models"][alias] = {"status": "error", "error": str(e)}
        
        self.metrics.append(metrics)
        return metrics
    
    def get_health_status(self) -> dict:
        """Get overall system health status."""
        healthy_models = 0
        total_models = len(self.managers)
        
        for alias, manager in self.managers.items():
            if manager.health_check():
                healthy_models += 1
        
        return {
            "overall_status": "healthy" if healthy_models == total_models else "degraded",
            "healthy_models": healthy_models,
            "total_models": total_models,
            "health_percentage": (healthy_models / total_models) * 100 if total_models > 0 else 0
```

```python
class FoundryResourceManager:
    def __init__(self):
        self.model_instances = {}
        self.resource_limits = {
            "max_memory_gb": 8,
            "max_concurrent_models": 3,
            "cpu_threshold": 80
        }
    
    def auto_scale_models(self, demand_metrics: dict):
        """Automatically scale models based on demand."""
        current_memory = self.get_total_memory_usage()
        
        # メモリ使用量が多い場合は縮小します
        if current_memory > self.resource_limits["max_memory_gb"] * 0.8:
            self.scale_down_idle_models()
        
        # 需要が高く、リソースが許す場合は拡張します
        for model_alias, demand in demand_metrics.items():
            if demand > 0.8 and len(self.model_instances) < self.resource_limits["max_concurrent_models"]:
                self.load_model_instance(model_alias)
    
    def load_model_instance(self, alias: str) -> FoundryLocalManager:
        """Load a new model instance if resources allow."""
        if alias not in self.model_instances:
            try:
                manager = FoundryLocalManager(alias)
                self.model_instances[alias] = manager
                logging.info(f"Loaded model instance: {alias}")
                return manager
            except Exception as e:
                logging.error(f"Failed to load model {alias}: {e}")
                return None
        return self.model_instances[alias]
    
    def scale_down_idle_models(self):
        """Remove idle model instances to free resources."""
        idle_models = []
        
        for alias, manager in self.model_instances.items():
            if manager.get_idle_time() > 300:  # 5分間アイドル状態
                idle_models.append(alias)
        
        for alias in idle_models:
            self.model_instances[alias].shutdown()
            del self.model_instances[alias]
            logging.info(f"Scaled down idle model: {alias}")
```

```python
            model_provider="ollama",
```

```python
import time
import asyncio
import requests
from typing import Dict, List

class OllamaMonitoringService:
    def __init__(self, base_url: str = "http://localhost:11434"):
        self.base_url = base_url
        self.metrics_history = []
        self.alert_thresholds = {
            "response_time_ms": 2000,
            "error_rate_percent": 5,
            "memory_usage_percent": 85
        }
    
    async def collect_metrics(self) -> dict:
        """Collect comprehensive metrics from Ollama service."""
        metrics = {
            "timestamp": time.time(),
            "service_status": "unknown",
            "models": {},
            "performance": {},
            "resources": {}
        }
        
        try:
            # サービスの健康状態を確認する
            health_response = requests.get(f"{self.base_url}/api/tags", timeout=5)
            metrics["service_status"] = "healthy" if health_response.status_code == 200 else "unhealthy"
            
            if metrics["service_status"] == "healthy":
                # モデル情報を取得する
                models_data = health_response.json().get('models', [])
                for model in models_data:
                    model_name = model['name']
                    metrics["models"][model_name] = {
                        "size_gb": model.get('size', 0) / (1024**3),
                        "modified": model.get('modified_at', ''),
                        "digest": model.get('digest', '')[:12]  # 短い要約
                    }
                
                # 推論性能をテストする
                start_time = time.time()
                test_response = requests.post(f"{self.base_url}/api/generate", 
                    json={
                        "model": list(metrics["models"].keys())[0] if metrics["models"] else "",
                        "prompt": "Hello",
                        "stream": False
                    }, timeout=10)
                
                if test_response.status_code == 200:
                    inference_time = (time.time() - start_time) * 1000
                    metrics["performance"] = {
                        "inference_time_ms": inference_time,
                        "tokens_per_second": self._calculate_tokens_per_second(test_response.json()),
                        "last_successful_inference": time.time()
                    }
            
        except Exception as e:
            metrics["service_status"] = "error"
            metrics["error"] = str(e)
        
        self.metrics_history.append(metrics)
        
        # 最新の100件のメトリクスのみ保持する
        if len(self.metrics_history) > 100:
            self.metrics_history = self.metrics_history[-100:]
        
        return metrics
    
    def _calculate_tokens_per_second(self, response_data: dict) -> float:
        """Calculate approximate tokens per second from response."""
        try:
            # トークン数を推定する（概算）
            response_text = response_data.get('response', '')
            estimated_tokens = len(response_text.split())
            
            # 利用可能であればタイミング情報を取得する
            eval_duration = response_data.get('eval_duration', 0)
            if eval_duration > 0:
                # ナノ秒を秒に変換する
                duration_seconds = eval_duration / 1e9
                return estimated_tokens / duration_seconds if duration_seconds > 0 else 0
        except:
            pass
        return 0
    
    def check_alerts(self, current_metrics: dict) -> List[dict]:
        """Check current metrics against alert thresholds."""
        alerts = []
        
        # 応答時間を確認する
        if current_metrics.get('performance', {}).get('inference_time_ms', 0) > self.alert_thresholds['response_time_ms']:
            alerts.append({
                "type": "performance",
                "message": f"High response time: {current_metrics['performance']['inference_time_ms']:.0f}ms",
                "severity": "warning"
            })
        
        # サービスの状態を確認する
        if current_metrics.get('service_status') != 'healthy':
            alerts.append({
                "type": "availability",
                "message": f"Service unhealthy: {current_metrics.get('error', 'Unknown error')}",
                "severity": "critical"
            })
        
        return alerts
    
    def get_performance_summary(self, minutes: int = 60) -> dict:
        """Get performance summary for the last N minutes."""
        cutoff_time = time.time() - (minutes * 60)
        recent_metrics = [m for m in self.metrics_history if m['timestamp'] > cutoff_time]
        
        if not recent_metrics:
            return {"error": "No recent metrics available"}
        
        # 平均値を計算する
        response_times = [m.get('performance', {}).get('inference_time_ms', 0) 
                         for m in recent_metrics if m.get('performance')]
        
        healthy_checks = sum(1 for m in recent_metrics if m.get('service_status') == 'healthy')
        uptime_percent = (healthy_checks / len(recent_metrics)) * 100 if recent_metrics else 0
        
        return {
            "period_minutes": minutes,
            "total_checks": len(recent_metrics),
            "uptime_percent": uptime_percent,
            "avg_response_time_ms": sum(response_times) / len(response_times) if response_times else 0,
            "max_response_time_ms": max(response_times) if response_times else 0,
            "min_response_time_ms": min(response_times) if response_times else 0
        }
```

### VLLM：高性能SLMエージェント推論

VLLM（Very Large Language Model推論）は、製品環境の大規模なSLM展開に特化した高スループットかつメモリ効率の高い推論エンジンを提供します。Foundry Localは使いやすさに重点を置き、Ollamaはコミュニティモデルを強調する一方で、VLLMは最大スループットと効率的なリソース利用を必要とする高性能シナリオで優れています。

<strong>コアアーキテクチャと機能</strong>：
- **PagedAttention**：効率的なアテンション計算のための革新的なメモリ管理
- **Dynamic Batching**：最適なスループットのためのインテリジェントなリクエストバッチ処理
- **GPU最適化**：高度なCUDAカーネルおよびテンソル並列処理対応
- **OpenAI互換性**：シームレスな統合のための完全なAPI互換性
- **Speculative Decoding**：高度な推論高速化技術
- **Quantization対応**：INT4、INT8、FP16によるメモリ効率化

```python
import asyncio
from concurrent.futures import ThreadPoolExecutor
from microsoft_agent_framework import Agent, Config
import openai

class VLLMHighThroughputManager:
    def __init__(self):
        self.model_configs = {
            "lightweight": {
                "model": "Qwen/Qwen2.5-0.5B-Instruct",
                "port": 8000,
                "max_model_len": 2048,
                "gpu_memory_utilization": 0.3
            },
            "balanced": {
                "model": "microsoft/Phi-3.5-mini-instruct",
                "port": 8001,
                "max_model_len": 4096,
                "gpu_memory_utilization": 0.5
            },
            "capable": {
                "model": "meta-llama/Llama-3.2-3B-Instruct",
                "port": 8002,
                "max_model_len": 8192,
                "gpu_memory_utilization": 0.7
            }
        }
        self.managers = {}
        self.agents = {}
        self.client_pool = {}
        
    async def initialize_all_models(self):
        """Initialize all VLLM models in parallel."""
        initialization_tasks = []
        
        for category, config in self.model_configs.items():
            task = self._initialize_model(category, config)
            initialization_tasks.append(task)
        
        results = await asyncio.gather(*initialization_tasks, return_exceptions=True)
        
        successful_inits = 0
        for i, result in enumerate(results):
            category = list(self.model_configs.keys())[i]
            if isinstance(result, Exception):
                print(f"Failed to initialize {category}: {result}")
            else:
                successful_inits += 1
                print(f"Successfully initialized {category} model")
        
        return successful_inits
    
    async def _initialize_model(self, category: str, config: Dict[str, Any]):
        """Initialize a single VLLM model instance."""
        manager = VLLMManager(
            model_name=config["model"],
            port=config["port"],
            max_model_len=config["max_model_len"],
            gpu_memory_utilization=config["gpu_memory_utilization"]
        )
        
        # ブロッキングを避けるためにスレッドでサーバーを起動
        loop = asyncio.get_event_loop()
        with ThreadPoolExecutor() as executor:
            success = await loop.run_in_executor(executor, manager.start_server)
        
        if success:
            self.managers[category] = manager
            
            # エージェントを作成
            agent_config = Config(
                name=f"vllm-{category}-agent",
                model_provider="vllm",
                model_id=manager.get_served_model_name(),
                endpoint=f"{manager.base_url}/v1",
                api_key="none"
            )
            
            self.agents[category] = Agent(config=agent_config)
            
            # 高スループットのためのクライアントプールを作成
            self.client_pool[category] = [
                openai.OpenAI(base_url=f"{manager.base_url}/v1")
                for _ in range(5)  # 並列処理のためにモデルごとに5つのクライアント
            ]
            
            return True
        else:
            raise Exception(f"Failed to start VLLM server for {category}")
    
    def get_optimal_agent(self, request_complexity: str, current_load: Dict[str, int]) -> str:
        """Select optimal agent based on request complexity and current load."""
        complexity_mapping = {
            "simple": "lightweight",
            "moderate": "balanced", 
            "complex": "capable"
        }
        
        preferred_category = complexity_mapping.get(request_complexity, "balanced")
        
        # 優先エージェントが利用可能で過負荷でないか確認
        if (preferred_category in self.agents and 
            current_load.get(preferred_category, 0) < 10):  # エージェントごとに最大10の同時処理
            return preferred_category
        
        # 最も負荷の少ない利用可能なエージェントにフォールバック
        available_agents = [(cat, load) for cat, load in current_load.items() 
                          if cat in self.agents and load < 10]
        
        if available_agents:
            return min(available_agents, key=lambda x: x[1])[0]
        
        return "balanced"  # デフォルトのフォールバック
    
    async def process_batch_requests(self, requests: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
        """Process multiple requests in parallel for maximum throughput."""
        current_load = {cat: 0 for cat in self.agents.keys()}
        tasks = []
        
        for request in requests:
            # 最適なエージェントを決定
            complexity = request.get("complexity", "moderate")
            agent_category = self.get_optimal_agent(complexity, current_load)
            current_load[agent_category] += 1
            
            # 処理タスクを作成
            task = self._process_single_request(request, agent_category)
            tasks.append(task)
        
        # すべてのリクエストを並列処理
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        # 結果をフォーマット
        formatted_results = []
        for i, result in enumerate(results):
            if isinstance(result, Exception):
                formatted_results.append({
                    "request_id": requests[i].get("id", i),
                    "status": "error",
                    "error": str(result)
                })
            else:
                formatted_results.append(result)
        
        return formatted_results
    
    async def _process_single_request(self, request: Dict[str, Any], agent_category: str) -> Dict[str, Any]:
        """Process a single request with the specified agent."""
        start_time = time.time()
        
        try:
            agent = self.agents[agent_category]
            response = await agent.chat_async(request["message"])
            
            processing_time = time.time() - start_time
            
            return {
                "request_id": request.get("id"),
                "status": "success",
                "response": response,
                "agent_used": agent_category,
                "processing_time": processing_time
            }
            
        except Exception as e:
            return {
                "request_id": request.get("id"),
                "status": "error",
                "error": str(e),
                "agent_used": agent_category,
                "processing_time": time.time() - start_time
            }

# 高スループット使用例
throughput_manager = VLLMHighThroughputManager()

# すべてのモデルを初期化

print(f"Initialized {initialized_count} models")

# バッチリクエストを処理

    {"id": 1, "message": "Simple question", "complexity": "simple"},
    {"id": 2, "message": "Complex analysis needed", "complexity": "complex"},
    {"id": 3, "message": "Moderate difficulty task", "complexity": "moderate"}
]

    print(f"Request {result['request_id']}: {result['status']} in {result.get('processing_time', 0):.2f}s")
```

```python
            @agent.tool
            def run_system_diagnostics(system_id: str) -> dict:
                """Run comprehensive system diagnostics."""
                return {"system_id": system_id, "status": "healthy", "issues": []}
            
            @agent.tool
            def create_incident_report(description: str, severity: str) -> str:
                """Create incident report in production system."""
                incident_id = f"INC-{hash(description) % 100000:05d}"
                return f"Created incident {incident_id} with severity {severity}"
    
    def _setup_routes(self):
        """Set up FastAPI routes for production service."""
        @self.app.post("/chat")
        async def chat_endpoint(request: AgentRequest, background_tasks: BackgroundTasks):
            try:
                # リクエストをキューに追加する
                await self.request_queue.put({
                    "request": request,
                    "timestamp": time.time(),
                    "future": asyncio.Future()
                })
                
                # 処理を待つ（タイムアウト付き）
                result = await asyncio.wait_for(
                    self._wait_for_result(request),
                    timeout=request.timeout
                )
                
                return result
                
            except asyncio.TimeoutError:
                raise HTTPException(status_code=408, detail="Request timeout")
            except Exception as e:
                raise HTTPException(status_code=500, detail=str(e))
        
        @self.app.get("/health")
        async def health_endpoint():
            return await self.get_health_status()
        
        @self.app.get("/metrics")
        async def metrics_endpoint():
            return self.get_production_metrics()
    
    async def _processing_worker(self, worker_id: int):
        """Background worker for processing agent requests."""
        logging.info(f"Starting processing worker {worker_id}")
        
        while True:
            try:
                # キューからリクエストを取得する
                queue_item = await self.request_queue.get()
                request_data = queue_item["request"]
                request_future = queue_item["future"]
                
                # 適切なエージェントを選択する
                agent_name = self._select_agent(request_data.agent_type)
                
                if agent_name not in self.agents:
                    request_future.set_exception(Exception(f"Agent {agent_name} not available"))
                    continue
                
                # リクエストを処理する
                start_time = time.time()
                try:
                    agent = self.agents[agent_name]
                    response = await agent.chat_async(request_data.message)
                    
                    processing_time = time.time() - start_time
                    
                    # メトリクスを更新する
                    self.metrics["requests_processed"] += 1
                    self.metrics["total_processing_time"] += processing_time
                    self.metrics["agent_usage"][agent_name] += 1
                    
                    result = {
                        "response": response,
                        "agent_used": agent_name,
                        "processing_time": processing_time,
                        "worker_id": worker_id
                    }
                    
                    request_future.set_result(result)
                    
                except Exception as e:
                    self.metrics["requests_failed"] += 1
                    request_future.set_exception(e)
                
                finally:
                    self.request_queue.task_done()
                    
            except Exception as e:
                logging.error(f"Worker {worker_id} error: {e}")
                await asyncio.sleep(1)
    
    def _select_agent(self, agent_type: str) -> str:
        """Select appropriate agent based on request type."""
        agent_mapping = {
            "customer_service": "customer_service",
            "technical": "technical_support",
            "general": "general_purpose"
        }
        
        return agent_mapping.get(agent_type, "general_purpose")
    
    async def _wait_for_result(self, request: AgentRequest):
        """Wait for request processing to complete."""
        # これは簡略化されている - 本番では正しくfutureを追跡する
        await asyncio.sleep(0.1)  # プレースホルダー
        return {"response": "Processed", "status": "success"}
    
    async def get_health_status(self) -> dict:
        """Get comprehensive health status of all services."""
        health_status = {
            "overall_status": "healthy",
            "servers": {},
            "queue_size": self.request_queue.qsize(),
            "active_workers": len([w for w in self.processing_workers if not w.done()]),
            "timestamp": time.time()
        }
        
        unhealthy_servers = 0
        for name, manager in self.managers.items():
            try:
                is_healthy = manager.health_check()
                health_status["servers"][name] = {
                    "status": "healthy" if is_healthy else "unhealthy",
                    "endpoint": manager.base_url,
                    "model": manager.model_name
                }
                if not is_healthy:
                    unhealthy_servers += 1
            except Exception as e:
                health_status["servers"][name] = {
                    "status": "error",
                    "error": str(e)
                }
                unhealthy_servers += 1
        
        if unhealthy_servers > 0:
            health_status["overall_status"] = "degraded" if unhealthy_servers < len(self.managers) else "unhealthy"
        
        return health_status
    
    def get_production_metrics(self) -> dict:
        """Get production performance metrics."""
        total_requests = self.metrics["requests_processed"] + self.metrics["requests_failed"]
        avg_processing_time = (
            self.metrics["total_processing_time"] / self.metrics["requests_processed"]
            if self.metrics["requests_processed"] > 0 else 0
        )
        
        success_rate = (
            self.metrics["requests_processed"] / total_requests * 100
            if total_requests > 0 else 0
        )
        
        return {
            "total_requests": total_requests,
            "successful_requests": self.metrics["requests_processed"],
            "failed_requests": self.metrics["requests_failed"],
            "success_rate_percent": success_rate,
            "average_processing_time_seconds": avg_processing_time,
            "agent_usage_distribution": self.metrics["agent_usage"],
            "queue_size": self.request_queue.qsize()
        }
    
    async def start_production_server(self, host: str = "0.0.0.0", port: int = 8080):
        """Start the production FastAPI server."""
        config = uvicorn.Config(
            self.app,
            host=host,
            port=port,
            log_level="info",
            workers=1  # シンプルさのための単一ワーカー
        )
        server = uvicorn.Server(config)
        await server.serve()
```

## Microsoft Agent Framework：プロダクション対応エージェント開発

### 概要とアーキテクチャ

Microsoft Agent Frameworkは、クラウドおよびオフラインのエッジ環境の両方で動作可能なAIエージェントを構築、展開、管理するための包括的かつエンタープライズグレードのプラットフォームを提供します。特にSmall Language Modelsとエッジコンピューティングシナリオに最適化されており、プライバシーに配慮したリソース制限環境での展開に理想的です。

<strong>コアフレームワークコンポーネント</strong>：
- <strong>エージェントランタイム</strong>：エッジデバイス向けに最適化された軽量実行環境
- <strong>ツール統合システム</strong>：外部サービス・API接続用の拡張可能なプラグインアーキテクチャ
- <strong>状態管理</strong>：セッション間での永続的なエージェントメモリとコンテキスト処理
- <strong>セキュリティレイヤー</strong>：エンタープライズ展開向けの組み込みセキュリティ制御
- <strong>オーケストレーションエンジン</strong>：マルチエージェント調整とワークフロー管理

### エッジ展開向けの主な特徴

<strong>オフラインファーストアーキテクチャ</strong>：Microsoft Agent Frameworkはオフラインファースト設計で、インターネット接続なしでもエージェントが効果的に動作します。これにはローカルモデル推論、キャッシュ済みナレッジベース、オフラインツール実行、クラウドサービスが利用不可時のグレースフルディグレードが含まれます。

<strong>リソース最適化</strong>：SLMの自動メモリ最適化、エッジデバイスのCPU/GPU負荷分散、利用可能なリソースに基づく適応的モデル選択、モバイル展開のための省電力推論パターンを提供します。

<strong>セキュリティとプライバシー</strong>：エンタープライズグレードのセキュリティ機能には、プライバシー保持のためのローカルデータ処理、暗号化されたエージェント通信チャネル、エージェント機能に対するロールベースアクセス制御、コンプライアンス要件のための監査ログがあります。

### Foundry Localとの統合

Microsoft Agent FrameworkはFoundry Localとシームレスに統合し、完全なエッジAIソリューションを提供します：

<strong>自動モデル検出</strong>：フレームワークはFoundry Localインスタンスを自動的に検出・接続し、利用可能なSLMモデルを発見、エージェント要件とハードウェア能力に基づき最適なモデルを選択します。

<strong>動的モデル読み込み</strong>：エージェントは特定タスク用に異なるSLMモデルを動的に読み込みできます。これにより複数モデルを用いるエージェントシステムが可能となり、モデルごとに異なる種類のリクエストを処理し、利用状況や性能に応じて自動フェイルオーバーも実現します。

<strong>パフォーマンス最適化</strong>：統合キャッシュ機構がモデル読み込み時間を短縮し、接続プーリングによりFoundry LocalへのAPI呼び出しを最適化、多数のエージェントリクエストのスループット向上にインテリジェントなバッチ処理を行います。

## SLMエージェント実装のベストプラクティス

### エージェント向けSLM選択ガイドライン

エージェント展開のためのSLM選択時に考慮すべき要素：

<strong>モデルサイズの考慮</strong>：超圧縮モデルのQ2_Kは極限的なモバイルエージェント用途に、バランス型Q4_K_Mは一般的エージェントシナリオに、高精度型Q8_0は品質重視のエージェント用途に推奨。

<strong>エージェントユースケースの整合</strong>：SLMの能力を特定のエージェント要件に合わせる。エージェントの意思決定に必要な精度維持、リアルタイム対話向けの推論速度、エッジデプロイのメモリ制約、プライバシー重視のオフライン動作要件などを考慮。

### SLMエージェント向け最適化戦略の選択

<strong>エージェント向け量子化アプローチ</strong>：エージェントの品質要件とハードウェア制約に基づき適切な量子化レベルを選択する。モバイルエージェントの最大圧縮にはQ4_0を、一般エージェントの品質と圧縮のバランスにはQ5_1を、重要な品質要求のあるエージェントにはQ8_0を考慮。


<strong>エージェント展開のためのフレームワーク選択</strong>: 対象ハードウェアおよびエージェント要件に基づいて最適化フレームワークを選択します。CPU最適化エージェント展開にはLlama.cpp、Apple SiliconエージェントアプリケーションにはApple MLX、クロスプラットフォームのエージェント互換性にはONNXを使用します。

## 実用的なSLMエージェントの変換とユースケース

### 実際のエージェント展開シナリオ

<strong>モバイルエージェントアプリケーション</strong>: Q4_Kフォーマットはスマートフォン向けエージェントアプリケーションにおいて最小のメモリフットプリントで優れており、Q8_0はタブレットベースのエージェントシステムにバランスの取れたパフォーマンスを提供します。Q5_Kフォーマットはモバイル生産性エージェントに対して優れた品質を提供します。

<strong>デスクトップおよびエッジエージェントコンピューティング</strong>: Q5_Kはデスクトップエージェントアプリケーションに最適なパフォーマンスを発揮し、Q8_0はワークステーションエージェント環境で高品質な推論を提供し、Q4_Kはエッジエージェントデバイスで効率的な処理を可能にします。

<strong>研究および実験的エージェント</strong>: 先進的な量子化フォーマットにより、学術研究や極度にリソース制約のあるエージェントアプリケーションに求められる超低精度エージェント推論の探求が可能になります。

### SLMエージェントの性能ベンチマーク

<strong>エージェント推論速度</strong>: Q4_KはモバイルCPUで最速のエージェント応答時間を実現し、Q5_Kは一般的なエージェントアプリケーションにバランスの取れた速度・品質比を提供し、Q8_0は複雑なエージェントタスクに対して優れた品質を提供し、実験的フォーマットは特殊なエージェントハードウェア向けの最大スループットを実現します。

<strong>エージェントのメモリ要件</strong>: エージェントの量子化レベルはQ2_K（小型エージェントモデルで500MB未満）からQ8_0（元のサイズの約50%）まであり、実験的な構成ではリソース制約のあるエージェント環境向けに最大の圧縮を達成します。

## SLMエージェントの課題と考慮事項

### エージェントシステムにおける性能のトレードオフ

SLMエージェント展開では、モデルサイズ、エージェント応答速度、出力品質の間のトレードオフを慎重に考慮する必要があります。Q4_Kはモバイルエージェントに対して卓越した速度と効率を提供し、Q8_0は複雑なエージェントタスクに対して優れた品質を提供します。Q5_Kはほとんどの一般的なエージェントアプリケーションに適した中間的な選択肢です。

### SLMエージェントのハードウェア互換性

異なるエッジデバイスはSLMエージェント展開において異なる能力を持ちます。Q4_Kは単純なエージェント用の基本的なプロセッサで効率的に動作し、Q5_Kはバランスの取れたエージェント性能に中程度の計算資源を要求し、Q8_0は高度なエージェント機能のために高性能ハードウェアを活用します。

### SLMエージェントシステムにおけるセキュリティとプライバシー

SLMエージェントはプライバシー強化のためのローカル処理を可能にしますが、エッジ環境におけるエージェントモデルとデータを保護するために適切なセキュリティ対策を実施する必要があります。これは特に企業環境で高精度エージェントフォーマットを展開する場合や、機密データを扱うアプリケーションで圧縮エージェントフォーマットを使用する場合に重要です。

SLMエージェントの領域は、圧縮技術、最適化手法、エッジ展開戦略の進歩とともに変化し続けています。将来的には、エージェントモデルのためのより効率的な量子化アルゴリズム、エージェントワークフローのための改良された圧縮手法、エージェント処理のためのエッジハードウェアアクセラレータとのより良い統合が期待されます。

**SLMエージェントの市場予測**: 最近の研究によると、エージェントによる自動化は2027年までに企業の反復的な認知作業の40～60%を削減でき、コスト効率と展開の柔軟性に優れるSLMがこの変革を主導します。

**SLMエージェントの技術動向**:
- **特化型SLMエージェント**: 特定のエージェントタスクや業界向けにトレーニングされたドメイン固有モデル

### ステップ 3: Microsoft Agent Frameworkで最初のエージェントを作成

<strong>基本的なエージェント設定</strong>:
```python
from microsoft_agent_framework import Agent, Config
from foundry_local import FoundryLocalManager

# Foundryローカル接続を初期化します
foundry = FoundryLocalManager("phi-4-mini")

# エージェント設定を作成します
config = Config(
    name="my-first-agent",
    model_provider="foundry-local",
    model_alias="phi-4-mini",
    offline_mode=True
)

# エージェントを作成および設定します
agent = Agent(
    config=config,
    model_endpoint=foundry.endpoint,
    api_key=foundry.api_key
)

# シンプルなツールを定義します
@agent.tool
def get_current_time() -> str:
    """Get the current time."""
    from datetime import datetime
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

# エージェントをテストします
response = agent.chat("What time is it?")
print(response)
```
