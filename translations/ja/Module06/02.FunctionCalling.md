## 関数呼び出しとは何か？

関数呼び出しは、スモール言語モデル（SLM）が外部ツール、API、サービスと連携できる強力な機能です。トレーニングデータに限定される代わりに、SLMは以下を実現できます：

- **外部APIとの接続**（天気サービス、データベース、検索エンジン）
- <strong>ユーザーのリクエストに基づく特定機能の実行</strong>
- **様々なソースからのリアルタイム情報の取得**
- <strong>専門ツールを使った計算タスクの実行</strong>
- <strong>複数の操作を連鎖させることで複雑なワークフローを実現</strong>

この機能により、SLMは静的なテキスト生成器から、現実のタスクを実行できる動的なAIエージェントへと変貌します。

## 関数呼び出しの仕組み

関数呼び出しプロセスは体系的なワークフローに従います：

### 1. ツール統合
- <strong>外部ツール</strong>: SLMは天気API、データベース、ウェブサービス、その他の外部システムと接続可能
- <strong>関数定義</strong>: 各ツールは特定のパラメータ、入出力フォーマット、説明とともに定義される
- **API互換性**: ツールは標準化されたインターフェース（REST API、SDK等）を通じて統合される

### 2. 関数定義
関数は三つの主要コンポーネントで定義されます：
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. 意図検出
- <strong>自然言語処理</strong>: SLMはユーザー入力を分析し意図を理解
- <strong>関数マッチング</strong>: 要求を満たすために必要な関数を決定
- <strong>パラメータ抽出</strong>: ユーザーのメッセージから必要なパラメータを特定し抽出

### 4. JSON出力生成
SLMは以下を含む構造化されたJSONを生成：
- 呼び出す関数名
- 適切な値を持つ必要なパラメータ
- 実行コンテキストとメタデータ

### 5. 外部実行
- <strong>パラメータ検証</strong>: すべての必要なパラメータが存在し正しくフォーマットされているか確認
- <strong>関数実行</strong>: 指定されたパラメータで関数をアプリケーションが実行
- <strong>エラー処理</strong>: 失敗、タイムアウト、無効な応答を管理

### 6. 応答統合
- <strong>結果処理</strong>: 関数の出力がSLMに返される
- <strong>コンテキスト統合</strong>: SLMは結果を応答に取り込む
- <strong>ユーザーへの伝達</strong>: 情報を自然な会話形式で提示

## 応用シナリオ

### データ取得
自然言語のクエリを構造化API呼び出しに変換：
- **「最近の注文を見せて」** → ユーザーIDと日付フィルター付きのデータベースクエリ
- **「東京の天気は？」** → 位置パラメータを使った天気API呼び出し
- **「先週のJohnからのメールを探して」** → 送信者と日付フィルター付きのメールサービスクエリ

### 操作実行
ユーザーのリクエストを特定の関数呼び出しに変換：
- **「明日午後2時に会議を設定」** → カレンダーAPI連携
- **「チームにメッセージを送って」** → コミュニケーションプラットフォームAPI
- **「ファイルのバックアップを作成」** → ファイルシステム操作

### 計算タスク
複雑な数学的または論理的操作を処理：
- **「1万ドルを5%の複利で10年間計算」** → 金融計算関数
- **「このデータセットの傾向を分析」** → 統計解析ツール
- **「配達ルートを最適化」** → ルート最適化アルゴリズム

### データ処理ワークフロー
複雑な操作のために複数の関数呼び出しを連鎖：
1. <strong>複数のソースからデータ取得</strong>
2. <strong>情報の解析と検証</strong>
3. <strong>必要なフォーマットへの変換</strong>
4. <strong>適切なシステムへの結果保存</strong>
5. <strong>レポートや可視化の生成</strong>

### UI/UX統合
動的なインターフェイス更新を可能に：
- **「ダッシュボードに売上データを表示」** → チャート生成と表示
- **「新しい場所で地図を更新」** → 地理空間データの統合
- **「在庫表示をリフレッシュ」** → リアルタイムデータ同期

### 単一関数呼び出しの例

```python
import json
import requests

# ツール/関数を定義する
tools = [
    {
        "name": "get_weather",
        "description": "Get current weather information for a location",
        "parameters": {
            "location": {
                "description": "The city or location name",
                "type": "str",
                "default": "New York"
            },
            "units": {
                "description": "Temperature units (celsius or fahrenheit)",
                "type": "str",
                "default": "celsius"
            }
        }
    }
]

# ツールを含むシステムプロンプトでメッセージを作成する
messages = [
    {
        "role": "system",
        "content": "You are a helpful weather assistant",
        "tools": json.dumps(tools)
    },
    {
        "role": "user",
        "content": "What's the weather like in London today?"
    }
]

# Ollama APIにリクエストを送る
response = requests.post(
    "http://localhost:11434/api/chat",
    json={
        "model": "phi4-mini-fc:3.8b-fp16",
        "messages": messages,
        "stream": False
    }
)

print(response.json())
```

## Qwen3関数呼び出しの活用

Qwen3は優れた性能と柔軟性を持つ高度な関数呼び出し機能を提供します。実装手順は以下の通りです：

### Qwen-Agent フレームワークの利用

Qwen-Agentは関数呼び出しの実装を簡素化する高レベルフレームワークです：

#### インストール
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### 基本設定

```python
import os
from qwen_agent.agents import Assistant

# LLMを設定する
llm_cfg = {
    'model': 'Qwen3-8B',
    # オプション1: Alibaba Model Studioを使用する
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # オプション2: ローカル展開を使用する
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'EMPTY',
    
    # 思考モードのオプション設定
    'generate_cfg': {
        'thought_in_content': True,  # 応答に推論を含める
    }
}

# MCP（モデルコンテキストプロトコル）を使用してツールを定義する
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # 組み込みコード実行ツール
]

# アシスタントを作成する
bot = Assistant(llm=llm_cfg, function_list=tools)

# 使用例
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# 関数呼び出しで応答を生成する
for response in bot.run(messages=messages):
    print(response)
```

### カスタム関数の実装

Qwen3用のカスタム関数も定義できます：

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # 天気API呼び出しをシミュレートする
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# カスタムツールを使用する
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

```python
import openai
from foundry_local import FoundryLocalManager

# モデルエイリアスで初期化

client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key

functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# 関数呼び出しリクエストを行う
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

### よくある問題と対処法

#### 問題1: 関数が呼び出されない
<strong>症状</strong>: モデルがテキストで応答し、関数を呼び出さない

<strong>対処法</strong>:
1. <strong>関数説明を確認</strong>: ユーザーの意図に明確に合致しているか確認
2. <strong>パラメータ定義を検証</strong>: 必要な全パラメータが正しく定義されているか確認
3. <strong>システムプロンプトを見直す</strong>: 関数を使用すべき際の明確な指示を含める
4. <strong>明示的なリクエストでテスト</strong>: 「ロンドンのデータを得るために天気関数を使ってください」と試す

#### 問題2: パラメータの誤り
<strong>症状</strong>: 関数が誤った、または不足したパラメータで呼び出される

<strong>対処法</strong>:
1. <strong>パラメータ例を追加</strong>: パラメータ説明にサンプル値を含める
2. **enum制約を利用**: 可能な場合パラメータ値を特定の選択肢に限定
3. <strong>フォールバック値を実装</strong>: 任意パラメータに妥当なデフォルトを設定

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }
}
```

#### 問題3: 並列関数呼び出しの失敗
<strong>症状</strong>: 複数の関数が実行されるべきところで一つしか実行されない

<strong>対処法</strong>:
1. <strong>モデルのサポートを確認</strong>: 並列関数呼び出しをサポートしているか確認

        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # 関数が存在するか検証する
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # レート制限をチェックする
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # パラメータを検証する
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # 関数を実行する
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # 成功した実行をログに記録する
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # 失敗した実行をログに記録する
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # 1分経過したらカウンターをリセットする
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # 制限内か確認する
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # 必要なパラメータをチェックする
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # パラメータの型と制約を検証する
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # 型検証
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )

                        success=False,

                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )

                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
