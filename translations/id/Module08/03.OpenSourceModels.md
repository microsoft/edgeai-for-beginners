## Bagian 1: Penemuan Model dengan Foundry CLI

### Perintah Dasar Manajemen Model

foundry CLI menyediakan perintah sederhana untuk penemuan dan manajemen model:

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### Menjalankan Model Pertama Anda

Mulailah dengan model populer dan teruji untuk memahami karakteristik kinerja:

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**Catatan:** Flag `--verbose` memberikan informasi startup terperinci, termasuk:
- Progres unduhan model (pada run pertama)
- Detail alokasi memori
- Informasi binding layanan
- Metrik inisialisasi kinerja

### Memahami Kategori Model

**Model Bahasa Kecil (SLMs):**
- `phi-4-mini`: Cepat, efisien, bagus untuk chat umum
- `phi-4`: Versi lebih mampu dengan penalaran lebih baik

**Model Menengah:**
- `qwen2.5-7b`: Penalaran luar biasa dan konteks lebih panjang
- `deepseek-r1-7b`: Dioptimalkan untuk generasi kode

**Model Lebih Besar:**
- `llama-3.2`: Model open-source terbaru dari Meta
- `qwen2.5-14b`: Penalaran kelas enterprise

## Bagian 3: Manajemen Cache Model dan Penyimpanan

### Memahami Cache Model

Foundry Local secara otomatis mengelola unduhan model dan cache:

```cmd
REM Check cache directory and contents
foundry cache ls

REM View cache location
foundry cache cd

REM Clean up unused models (if needed)
foundry cache clean
```

### Pertimbangan Penyimpanan Model

**Ukuran Model Umum:**
- `phi-4-mini`: ~2.5 GB
- `qwen2.5-7b`: ~4.1 GB  
- `deepseek-r1-7b`: ~4.3 GB
- `llama-3.2`: ~4.9 GB
- `qwen2.5-14b`: ~8.2 GB

**Praktik Terbaik Penyimpanan:**
- Simpan 2-3 model dalam cache untuk pergantian cepat
- Hapus model yang tidak digunakan untuk mengosongkan ruang: `foundry cache clean`
- Pantau penggunaan disk, terutama pada SSD kecil
- Pertimbangkan kompromi ukuran model vs kemampuan

### Pemantauan Kinerja Model

Saat model berjalan, pantau sumber daya sistem:

**Windows Task Manager:**
- Amati penggunaan memori (model tetap dimuat dalam RAM)
- Pantau pemakaian CPU selama inferensi
- Cek I/O disk saat pemuatan awal model

**Pemantauan Baris Perintah:**
```cmd
REM Check memory usage (PowerShell)
Get-Process | Where-Object {$_.ProcessName -like "*foundry*"} | Select-Object ProcessName, WorkingSet64

REM Monitor running models
foundry service ps
```

## Bagian 4: Pedoman Praktis Seleksi Model

### Memilih Model berdasarkan Kasus Penggunaan

**Untuk Chat Umum dan Tanya Jawab:**
- Mulai dengan: `phi-4-mini` (cepat, efisien)
- Upgrade ke: `phi-4` (penalaran lebih baik)
- Tingkat lanjut: `qwen2.5-7b` (konteks lebih panjang)

**Untuk Generasi Kode:**
- Direkomendasikan: `deepseek-r1-7b`
- Alternatif: `qwen2.5-7b` (juga baik untuk kode)

**Untuk Penalaran Kompleks:**
- Terbaik: `qwen2.5-7b` atau `qwen2.5-14b`
- Opsi anggaran: `phi-4`

### Panduan Persyaratan Perangkat Keras

**Persyaratan Sistem Minimum:**
```
phi-4-mini:     8GB RAM,  entry-level CPU
phi-4:         12GB RAM,  mid-range CPU
qwen2.5-7b:    16GB RAM,  mid-range CPU
deepseek-r1:   16GB RAM,  mid-range CPU
qwen2.5-14b:   24GB RAM,  high-end CPU
```

**Direkomendasikan untuk Kinerja Terbaik:**
- RAM 32GB+ untuk pergantian multi-model yang nyaman
- Penyimpanan SSD untuk pemuatan model lebih cepat
- CPU modern dengan kinerja single-thread yang baik
- Dukungan NPU (PC Windows 11 Copilot+) untuk percepatan

### Alur Kerja Pergantian Model

```cmd
REM Stop current model (if needed)
foundry service stop

REM Start different model
foundry model run qwen2.5-7b

REM Verify model is running
foundry service status
```

## Bagian 5: Benchmarking Model Sederhana

### Pengujian Kinerja Dasar

Berikut pendekatan sederhana untuk membandingkan kinerja model:

```python
# simple_bench.py - Berdasarkan pola Contoh 03
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# Uji model yang sedang berjalan saat ini
if __name__ == "__main__":
    # Uji dengan model yang berbeda (mulai setiap model terlebih dahulu)
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```

### Penilaian Kualitas Manual

Untuk setiap model, uji dengan prompt konsisten dan evaluasi secara manual:

**Prompt Tes:**
1. "Jelaskan komputasi kuantum dengan bahasa sederhana."
2. "Tulis fungsi Python untuk mengurutkan daftar."
3. "Apa kelebihan dan kekurangan kerja jarak jauh?"
4. "Ringkas manfaat edge AI."

**Kriteria Evaluasi:**
- **Akurasi**: Apakah informasinya benar?
- **Kejelasan**: Apakah penjelasannya mudah dimengerti?
- **Kelengkapan**: Apakah pertanyaan terjawab sepenuhnya?
- **Kecepatan**: Seberapa cepat responnya?
