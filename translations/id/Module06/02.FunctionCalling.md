## Apa itu Panggilan Fungsi?

Panggilan fungsi adalah kemampuan kuat yang memungkinkan Small Language Models (SLMs) berinteraksi dengan alat eksternal, API, dan layanan. Alih-alih terbatas pada data pelatihan mereka, SLM sekarang dapat:

- **Terhubung ke API eksternal** (layanan cuaca, basis data, mesin pencari)
- **Menjalankan fungsi tertentu** berdasarkan permintaan pengguna
- **Mengambil informasi real-time** dari berbagai sumber
- **Melakukan tugas komputasi** melalui alat khusus
- **Menggabungkan operasi beberapa fungsi** untuk alur kerja kompleks

Kemampuan ini mengubah SLM dari pembuat teks statis menjadi agen AI dinamis yang dapat menjalankan tugas dunia nyata.

## Cara Kerja Panggilan Fungsi

Proses panggilan fungsi mengikuti alur kerja sistematis:

### 1. Integrasi Alat
- **Alat Eksternal**: SLM dapat terhubung ke API cuaca, basis data, layanan web, dan sistem eksternal lainnya
- **Definisi Fungsi**: Setiap alat didefinisikan dengan parameter spesifik, format input/output, dan deskripsi
- **Kompatibilitas API**: Alat diintegrasikan melalui antarmuka standar (REST API, SDK, dll.)

### 2. Definisi Fungsi
Fungsi didefinisikan dengan tiga komponen utama:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Deteksi Niat
- **Pemrosesan Bahasa Alami**: SLM menganalisis masukan pengguna untuk memahami niat
- **Pencocokan Fungsi**: Menentukan fungsi mana yang dibutuhkan untuk memenuhi permintaan
- **Ekstraksi Parameter**: Mengidentifikasi dan mengambil parameter yang diperlukan dari pesan pengguna

### 4. Penghasilan Output JSON
SLM menghasilkan JSON terstruktur yang berisi:
- Nama fungsi untuk dipanggil
- Parameter yang diperlukan dengan nilai sesuai
- Konteks eksekusi dan metadata

### 5. Eksekusi Eksternal
- **Validasi Parameter**: Memastikan semua parameter yang diperlukan ada dan diformat dengan benar
- **Eksekusi Fungsi**: Aplikasi menjalankan fungsi yang ditentukan dengan parameter yang diberikan
- **Penanganan Kesalahan**: Mengelola kegagalan, timeout, dan respons tidak valid

### 6. Integrasi Respons
- **Pemrosesan Hasil**: Output fungsi dikembalikan ke SLM
- **Integrasi Konteks**: SLM memasukkan hasil ke dalam responsnya
- **Komunikasi dengan Pengguna**: Menampilkan informasi dalam format alami dan percakapan

## Skenario Aplikasi

### Pengambilan Data
Mengubah kueri bahasa alami menjadi panggilan API terstruktur:
- **"Tampilkan pesanan terakhir saya"** → Kueri basis data dengan ID pengguna dan filter tanggal
- **"Bagaimana cuaca di Tokyo?"** → Panggilan API cuaca dengan parameter lokasi
- **"Cari email dari John minggu lalu"** → Kueri layanan email dengan filter pengirim dan tanggal

### Eksekusi Operasi
Mengubah permintaan pengguna menjadi panggilan fungsi spesifik:
- **"Jadwalkan rapat besok pukul 2 siang"** → Integrasi API kalender
- **"Kirim pesan ke tim"** → API platform komunikasi
- **"Buat cadangan file saya"** → Operasi sistem berkas

### Tugas Komputasi
Menangani operasi matematis atau logis kompleks:
- **"Hitung bunga majemuk dari $10,000 dengan tingkat 5% selama 10 tahun"** → Fungsi perhitungan keuangan
- **"Analisis dataset ini untuk tren"** → Alat analisis statistik
- **"Optimalkan rute ini untuk pengiriman"** → Algoritma optimasi rute

### Alur Kerja Pemrosesan Data
Menggabungkan panggilan fungsi multipel untuk operasi kompleks:
1. **Ambil data** dari berbagai sumber
2. **Parse dan validasi** informasi
3. **Transformasi** data ke format yang dibutuhkan
4. **Simpan hasil** di sistem yang sesuai
5. **Buat laporan** atau visualisasi

### Integrasi UI/UX
Memungkinkan pembaruan antarmuka dinamis:
- **"Tampilkan data penjualan di dashboard"** → Pembuatan dan tampilan grafik
- **"Perbarui peta dengan lokasi baru"** → Integrasi data geospasial
- **"Segarkan tampilan inventaris"** → Sinkronisasi data real-time

Anda juga dapat mendefinisikan fungsi kustom untuk Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Simulasikan panggilan API cuaca
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Gunakan alat khusus
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

### Masalah Umum dan Solusinya

#### Masalah 1: Fungsi Tidak Dipanggil
**Gejala**: Model merespons dengan teks alih-alih memanggil fungsi

**Solusi**:
1. **Periksa deskripsi fungsi**: Pastikan sesuai dengan niat pengguna secara jelas
2. **Verifikasi definisi parameter**: Pastikan semua parameter diperlukan sudah terdefinisi dengan benar
3. **Tinjau prompt sistem**: Sertakan instruksi jelas kapan harus menggunakan fungsi
4. **Uji dengan permintaan eksplisit**: Coba "Harap gunakan fungsi cuaca untuk mendapatkan data London"

#### Masalah 2: Parameter Salah
**Gejala**: Fungsi dipanggil dengan parameter salah atau hilang

**Solusi**:
1. **Tambahkan contoh parameter**: Sertakan nilai sampel dalam deskripsi parameter
2. **Gunakan batasan enum**: Batasi nilai parameter ke opsi tertentu jika memungkinkan
3. **Terapkan nilai cadangan**: Berikan default yang wajar untuk parameter opsional

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }
}
```

#### Masalah 3: Kegagalan Panggilan Fungsi Paralel
**Gejala**: Hanya satu fungsi yang berjalan saat seharusnya banyak dijalankan

**Solusi**:
1. **Periksa dukungan model**: Pastikan model Anda mendukung panggilan fungsi paralel
2. **Perbarui prompt sistem**: Sertakan "beberapa alat" atau "berbagai alat" dalam pesan sistem
3. **Gunakan versi model yang tepat**: Phi-4-mini:3.8b-fp16 direkomendasikan untuk Ollama

#### Masalah 4: Masalah Template dengan Ollama
**Gejala**: Panggilan fungsi tidak bekerja dengan pengaturan default Ollama

**Solusi**:
1. **Gunakan ModelFile kustom**: Terapkan template yang dikoreksi seperti yang disediakan tutorial ini
2. **Perbarui Ollama**: Pastikan menggunakan versi 0.5.13 atau lebih tinggi
3. **Periksa kuantisasi model**: Tingkat kuantisasi yang lebih tinggi (Q8_0, fp16) bekerja lebih baik daripada versi yang sangat dikurangi

### Optimasi Performa

#### 1. Desain Fungsi Efisien
- **Fokus pada fungsi**: Setiap fungsi harus memiliki tujuan tunggal yang jelas
- **Minimalkan ketergantungan eksternal**: Kurangi panggilan API dan permintaan jaringan jika memungkinkan
- **Cache hasil**: Simpan data yang sering diminta untuk mempercepat respons

#### 2. Pengelompokkan dan Operasi Asinkron
```python
import asyncio
import aiohttp

async def batch_function_calls(function_calls):
    """Execute multiple function calls concurrently"""
    async with aiohttp.ClientSession() as session:
        tasks = []
        for call in function_calls:
            if call["name"] == "fetch_url":
                task = fetch_url_async(session, call["parameters"]["url"])
                tasks.append(task)
        
        results = await asyncio.gather(*tasks)
        return results

async def fetch_url_async(session, url):
    async with session.get(url) as response:
        return await response.text()
```

#### 3. Manajemen Sumber Daya
- **Pooling koneksi**: Gunakan kembali koneksi basis data dan API
- **Pembatasan laju**: Terapkan pembatasan yang tepat untuk API eksternal
- **Penanganan timeout**: Tetapkan batas waktu yang wajar untuk semua panggilan eksternal

class EnterpriseAIAgent:

    def register_function(self, name: str, description: str, parameters: Dict, 
                         handler: callable, rate_limit: int = 60):
        """Register a new function with the agent"""
        self.functions[name] = {
            'description': description,
            'parameters': parameters,
            'handler': handler,
            'rate_limit': rate_limit,
            'call_count': 0,
            'last_reset': datetime.now()
        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Validasi fungsi ada
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Periksa batas laju
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Validasi parameter
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Jalankan fungsi
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Catat eksekusi berhasil
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Catat eksekusi gagal
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Reset penghitung jika satu menit telah berlalu
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Periksa apakah di bawah batas
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Periksa parameter yang diperlukan
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Validasi tipe dan batasan parameter
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Validasi tipe
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # Validasi enum
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
        
        return FunctionResult(success=True)

## Kesimpulan

Panggilan fungsi dalam Small Language Models mewakili pergeseran paradigma dari asisten AI statis menjadi agen dinamis yang mampu berinteraksi dengan dunia nyata. Tutorial ini telah membahas:

### Poin Penting

1. **Pemahaman Dasar**: Panggilan fungsi memungkinkan SLM melampaui data pelatihan mereka dengan menghubungkan ke alat dan layanan eksternal.

2. **Fleksibilitas Implementasi**: Ada berbagai pendekatan, dari implementasi tingkat rendah dengan template kustom hingga kerangka kerja tingkat tinggi seperti Qwen-Agent dan Foundry Local.

3. **Pertimbangan Produksi**: Penyebaran enterprise memerlukan perhatian pada penanganan kesalahan, pembatasan laju, keamanan, dan pencatatan audit.

4. **Optimasi Performa**: Desain fungsi yang tepat, eksekusi efisien, dan caching cerdas dapat sangat meningkatkan waktu respons.

### Arah Masa Depan

Seiring teknologi SLM terus berkembang, kita dapat mengharapkan:

- **Akurasi Panggilan Fungsi yang Lebih Baik**: Deteksi niat dan ekstraksi parameter yang lebih baik
- **Peningkatan Pemrosesan Paralel**: Orkestrasi multi-fungsi yang lebih canggih
- **Standar Integrasi yang Lebih Baik**: Protokol standar untuk integrasi alat
- **Fitur Keamanan Lanjutan**: Mekanisme autentikasi dan otorisasi yang diperkuat
- **Ekosistem yang Berkembang**: Perpustakaan fungsi dan integrasi pre-built yang terus bertambah

### Memulai

Untuk mulai mengimplementasikan panggilan fungsi di proyek Anda:

1. **Mulai Sederhana**: Mulailah dengan skenario fungsi tunggal dasar
2. **Pilih Kerangka Kerja Anda**: Pilih antara implementasi langsung (Ollama/Phi-4) atau berbantuan kerangka kerja (Qwen-Agent)
3. **Rancang Fungsi dengan Baik**: Fokus pada definisi fungsi yang jelas dan terdokumentasi baik
4. **Implementasikan Penanganan Kesalahan**: Bangun penanganan kesalahan yang kuat sejak awal
5. **Skalakan Secara Bertahap**: Beralih dari skenario sederhana ke kompleks saat Anda memperoleh pengalaman

Panggilan fungsi mengubah SLM dari pembuat teks yang mengesankan menjadi agen AI praktis yang mampu memecahkan masalah dunia nyata. Dengan mengikuti pola dan praktik yang dijelaskan dalam tutorial ini, Anda dapat membangun sistem AI yang kuat dan andal yang melampaui antarmuka chat tradisional.
