## Что такое вызов функций?

Вызов функций — это мощная возможность, которая позволяет малым языковым моделям (SLMs) взаимодействовать с внешними инструментами, API и сервисами. Вместо того чтобы ограничиваться своими обучающими данными, SLM теперь могут:

- **Подключаться к внешним API** (сервисы погоды, базы данных, поисковые системы)
- **Выполнять конкретные функции** на основе пользовательских запросов
- **Получать информацию в реальном времени** из различных источников
- **Выполнять вычислительные задачи** с помощью специализированных инструментов
- **Последовательно выполнять несколько операций** для сложных рабочих процессов

Эта возможность преобразует SLM из статичных генераторов текста в динамичных AI-агентов, которые могут выполнять реальные задачи.

## Как работает вызов функций

Процесс вызова функций следует систематическому рабочему процессу:

### 1. Интеграция инструментов
- **Внешние инструменты**: SLM может подключаться к API погоды, базам данных, веб-сервисам и другим внешним системам
- **Определения функций**: Каждый инструмент определяется с конкретными параметрами, форматами ввода/вывода и описаниями
- **Совместимость с API**: Инструменты интегрируются через стандартизированные интерфейсы (REST API, SDK и т.д.)

### 2. Определение функций
Функции определяются с тремя ключевыми компонентами:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Определение намерения
- **Обработка естественного языка**: SLM анализирует ввод пользователя, чтобы понять намерение
- **Соответствие функции**: Определяет, какие функции необходимы для выполнения запроса
- **Извлечение параметров**: Идентифицирует и извлекает необходимые параметры из сообщения пользователя

### 4. Генерация JSON-вывода
SLM создает структурированный JSON, содержащий:
- Имя вызываемой функции
- Необходимые параметры с соответствующими значениями
- Контекст выполнения и метаданные

### 5. Внешнее выполнение
- **Проверка параметров**: Обеспечивает наличие всех требуемых параметров и их корректный формат
- **Выполнение функции**: Приложение выполняет указанную функцию с переданными параметрами
- **Обработка ошибок**: Управляет сбоями, таймаутами и некорректными ответами

### 6. Интеграция ответов
- **Обработка результатов**: Результат функции возвращается в SLM
- **Интеграция контекста**: SLM включает результаты в свой ответ
- **Общение с пользователем**: Представляет информацию в естественной, разговорной форме

## Сценарии применения

### Получение данных
Преобразование запросов на естественном языке в структурированные вызовы API:
- **"Покажи мои последние заказы"** → Запрос к базе данных с учитыванием ID пользователя и фильтров по датам
- **"Какая погода в Токио?"** → Вызов API погоды с параметром местоположения
- **"Найди письма от Джона за прошлую неделю"** → Запрос к почтовому сервису с фильтрами по отправителю и дате

### Выполнение операций
Преобразование запросов пользователя в конкретные вызовы функций:
- **"Назначить встречу завтра в 14:00"** → Интеграция с календарным API
- **"Отправить сообщение команде"** → API платформы коммуникаций
- **"Создать резервную копию моих файлов"** → Операция с файловой системой

### Вычислительные задачи
Обработка сложных математических или логических задач:
- **"Вычислить сложные проценты по $10,000 под 5% на 10 лет"** → Функция финансовых расчетов
- **"Проанализировать этот набор данных на наличие трендов"** → Инструменты статистического анализа
- **"Оптимизировать этот маршрут для доставки"** → Алгоритмы оптимизации маршрутов

### Рабочие процессы обработки данных
Последовательное выполнение нескольких вызовов функций для сложных операций:
1. **Получение данных** из нескольких источников
2. **Парсинг и проверка валидности** информации
3. **Преобразование** данных в нужный формат
4. **Сохранение результатов** в соответствующих системах
5. **Генерация отчетов** или визуализаций

### Интеграция UI/UX
Обеспечение динамического обновления интерфейса:
- **"Показать данные продаж на панели"** → Создание и отображение графиков
- **"Обновить карту новыми локациями"** → Интеграция геопространственных данных
- **"Обновить отображение запасов"** → Синхронизация данных в реальном времени

## Настройка вызова функций с Phi-4-mini и Ollama

- Модель Phi-4-mini (рекомендуется: `phi4-mini:3.8b-fp16`)

### Шаги установки

## Работа с вызовом функций Qwen3

Qwen3 предлагает продвинутые возможности вызова функций с отличной производительностью и гибкостью. Вот как это реализовать:

### Использование фреймворка Qwen-Agent

Qwen-Agent предоставляет высокоуровневый фреймворк, который упрощает реализацию вызова функций:

#### Установка
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### Основная настройка

```python
import os
from qwen_agent.agents import Assistant

# Настройте LLM
llm_cfg = {
    'model': 'Qwen3-8B',
    # Вариант 1: Использовать Alibaba Model Studio
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # Вариант 2: Использовать локальное развертывание
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'EMPTY',
    
    # Дополнительная настройка режима мышления
    'generate_cfg': {
        'thought_in_content': True,  # Включить рассуждения в ответе
    }
}

# Определите инструменты с помощью MCP (Протокол контекста модели)
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # Встроенный инструмент выполнения кода
]

# Создать ассистента
bot = Assistant(llm=llm_cfg, function_list=tools)

# Пример использования
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# Сгенерировать ответ с вызовом функции
for response in bot.run(messages=messages):
    print(response)
```

### Реализация пользовательских функций

Вы также можете определить пользовательские функции для Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Смоделировать вызов API погоды
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Использовать настраиваемый инструмент
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

## Интеграция Foundry Local

Foundry Local от Microsoft предоставляет API, совместимый с OpenAI, для локального запуска моделей с повышенной конфиденциальностью и производительностью.

### Настройка и установка

#### Windows
Скачайте установщик с [страницы релизов Foundry Local](https://github.com/microsoft/Foundry-Local/releases) и следуйте инструкциям по установке.

#### macOS
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

#### Базовое использование

```python
import openai
from foundry_local import FoundryLocalManager

# Инициализация с псевдонимом модели
alias = "phi-3.5-mini"  # Или любой поддерживаемой моделью
manager = FoundryLocalManager(alias)

# Создать OpenAI клиента, указывающего на локальную конечную точку
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Определить функции для модели
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Сделать вызов функции запроса
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

### Распространённые проблемы и их решения

#### Проблема 1: Функция не вызывается

        }

        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Проверить, что функция существует
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Проверить лимиты по частоте вызовов
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Проверить параметры
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Выполнить функцию
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Записать успешное выполнение
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Записать неудачное выполнение
            self._log_function_call(function_name, parameters, result)
            
            return result

        func_info = self.functions[function_name]

        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Проверить, не превышен ли лимит
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Проверить обязательные параметры
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )

                        error=f"Parameter '{param_name}' must be a string"
                    )

                        error=f"Parameter '{param_name}' must be a number"

                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"

                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"

                'parameters': {
                    'type': 'object',
                    'properties': {},
                    'required': []
                }
            }
            
            for param_name, param_info in func_info['parameters'].items():
                definition['parameters']['properties'][param_name] = {
                    'type': param_info['type'],
                    'description': param_info.get('description', '')
                }
                
                if 'enum' in param_info:
                    definition['parameters']['properties'][param_name]['enum'] = param_info['enum']
                
                if 'default' in param_info:
                    definition['parameters']['properties'][param_name]['default'] = param_info['default']
                
                if param_info.get('required', False):
                    definition['parameters']['required'].append(param_name)
            
            definitions.append(definition)
        
        return definitions

## Заключение

Вызов функций в малых языковых моделях представляет собой сдвиг парадигмы от статичных AI-помощников к динамичным, способным агентам, которые могут взаимодействовать с реальным миром. В этом руководстве были рассмотрены:

### Основные выводы

1. **Базовое понимание**: Вызов функций позволяет SLM выходить за пределы своих обучающих данных, подключаясь к внешним инструментам и сервисам.

2. **Гибкость реализации**: Существует множество подходов — от низкоуровневой реализации с пользовательскими шаблонами до высокоуровневых фреймворков, таких как Qwen-Agent и Foundry Local.

3. **Требования к эксплуатации**: Внедрение в корпоративной среде требует внимания к обработке ошибок, ограничению скорости, безопасности и журналированию аудита.

4. **Оптимизация производительности**: Правильное проектирование функций, эффективное выполнение и умное кэширование значительно улучшают время отклика.

### Перспективы развития

По мере развития технологий SLM можно ожидать:

- **Улучшенную точность вызова функций**: Лучшая детекция намерений и извлечение параметров
- **Расширенную параллельную обработку**: Более сложное управление множественными вызовами функций
- **Лучшие стандарты интеграции**: Стандартизированные протоколы для подключения инструментов
- **Продвинутые функции безопасности**: Улучшенная аутентификация и авторизация
- **Расширенную экосистему**: Растущая библиотека готовых функций и интеграций

### С чего начать

Чтобы начать внедрение вызова функций в ваших проектах:

1. **Начинайте просто**: С базовых сценариев одиночных вызовов функций
2. **Выберите фреймворк**: Между прямой реализацией (Ollama/Phi-4) и фреймворк-асистентом (Qwen-Agent)
3. **Тщательно проектируйте функции**: Фокусируйтесь на понятных, хорошо документированных определениях функций
4. **Реализуйте обработку ошибок**: Создавайте надежную обработку ошибок с самого начала
5. **Масштабируйтесь постепенно**: Переходите от простых к сложным сценариям по мере накопления опыта

Вызов функций превращает SLM из впечатляющих генераторов текста в практичных AI-агентов, способных решать реальные задачи.
