# വര്‍ഷോപ് നോട്ട്‌ബുക്കുകള്‍

> **ഹാന്റ്‌സോണ്‍ എഡ്ജ് എ.ഐ. പഠനത്തിന് ഇന്ററാക്ടീവ് ജുപിറ്റര്‍ നോട്ട്‌ബുക്കുകള്‍**
>
> Microsoft Foundry Local ഉം Small Language Models ഉം ഉപയോഗിച്ച് അടിസ്ഥാന ചാറ്റ് പൂര്‍ത്തീകരണങ്ങളില്‍ നിന്ന് മുന്നേറ്റം കുറിച്ചെടുത്ത് പരിപൂര്‍ണ്ണമായ, സ്വയം പ്രഗത്ഭമായ ട്യൂട്ടോറിയലുകള്‍.

---

## 📖 പരിചയം

**EdgeAI for Beginners Workshop Notebooks** എന്ന സമാഹവത്തിലേക്ക് സ്വാഗതം. ഈ ഇന്ററാക്ടീവ് ജുപിറ്റര്‍ നോട്ട്‌ബുക്കുകള്‍ നിങ്ങളെ Edge AI കോഡ് യാഥാര്‍ത്ഥ്യത്തിൽ എഴുതാനും പ്രവർത്തിപ്പിക്കാനും പരീക്ഷണമെടുക്കാനും സഹായിക്കുന്നു.

### ജുപിറ്റര്‍ നോട്ട്‌ബുക്കുകള്‍ എന്തുകൊണ്ടാണ്?

പരമ്പരാഗത ട്യൂട്ടോറിയലുകളെ അപേക്ഷിച്ച്, ഈ നോട്ട്‌ബുക്കുകള്‍:

- **ഇന്ററാക്ടീവ് പഠനം**: കോഡ് സെല്ലുകള്‍ റണ്‍ ചെയ്ത് ഉടനടി ഫലങ്ങള്‍ കാണുക
- **പരിശോധന**: പാരാമീറ്ററുകള്‍ മാറ്റി യഥാര്‍ത്ഥ സമയത്ത് മാറ്റങ്ങൾ നിരീക്ഷിക്കുക
- **ഡോക്യുമെന്റേഷൻ**: ലൈനിലുള്ള വിശദീകരണങ്ങളും മാര്‍ക്ക്‌ഡൗണ്‍ സെല്ലുകളും ആശയങ്ങള്‍ വെളിപ്പെടുത്തുന്നു
- **പുനരാവർത്തനക്ഷമത**: നിങ്ങൾ കാണാനും പുനഃപ്രయోగിക്കാനും കഴിയുന്ന പൂര്‍ണ്ണമായ പ്രവർത്തിക്കുന്ന ഉദാഹരണങ്ങള്‍
- **ദൃശ്യീകരണം**: പ്രകടനമിത്രങ്ങള്‍, എംബഡ്ഡിംഗുകള്‍, ഫലങ്ങള്‍ ആ കളിൽ കാണുക

### ഈ നോട്ട്‌ബുക്കുകള്‍ വിശേഷമായി എന്താണ്?

ഓരോ നോട്ട്‌ബുക്കും **ഉത്പാദന-സജ്ജമായ മികച്ച കാഴ്ചപ്പാടുകൾ** പിന്തുടരുന്നുള്ളിൽ രൂപകല്‍പന ചെയ്തതാണ്:

✅ **സമഗ്രമായ പിശക് കൈകാര്യം ചെയ്യല്‍** - സൗമ്യേമായ മന്ദഗതിയും വിവരപരമായ പിശക് സന്ദേശങ്ങളും  
✅ **ടൈപ്പ് ഹിൻറ്റ്സ് & ഡോക്യുമെന്റേഷൻ** - വ്യക്തമായ ഫംഗ്ഷന്‍ സിഗ്‌നേച്ചറുകളും ഡോക്സ്ട്രിംഗുകളും  
✅ **പ്രകടനം നിരീക്ഷണം** - ടോക്കണ്‍ ഉപയോഗ നിരീക്ഷണവും വൈകല്യങ്ങൾ അളക്കലും  
✅ **മോഡുലാർ രൂപകല്‍പന** - നിങ്ങളുടെ പദ്ധതികള്‍ക്കനുസരിച്ച് പുനഃപ്രയോഗിക്കാവുന്ന മാതൃകകള്‍  
✅ **ക്രമാനുഗതമായ സങ്കീർണം** - മുമ്പത്തെ സെഷനുകളിൽ നിന്നു ക്രമീകരിച്ചു വളരുന്നു

## 🎯 പഠന ലക്ഷ്യങ്ങൾ

### നിങ്ങൾ അഭ്യസിക്കുന്ന പ്രധാന കഴിവുകൾ

ഈ നോട്ട്‌ബുക്കുകള്‍ മുഖാന്തിരം നിങ്ങൾ അറിയും:

1. **ലോകൽ എ.ഐ. സേവന മാനേജ്മെന്റ്**
   - Microsoft Foundry Local സേവനങ്ങൾ ക്രമീകരിക്കുകയും നടത്തുകയും ചെയ്യുക
   - നിങ്ങളുടെ ഹാർഡ്‌വെയർ അനുയോജ്യമായ മോഡലുകൾ തിരഞ്ഞെടുക്കുക ലോഡ് ചെയ്യുക
   - സ്രോതസ്സ് ഉപയോഗം നിരീക്ഷിക്കുകയും പ്രകടന ഓപ്റ്റിമൈസുചെയ്യുകയും ചെയ്യുക
   - സേവന കണ്ടെത്തലും ആരോഗ്യം പരിശോധിക്കുകയും ചെയ്യുക

2. **എ.ഐ. ആപ്ലിക്കേഷൻ വികസനം**
   - OpenAI-സമാനമായ ചാറ്റ് പൂര്‍ത്തീകരണങ്ങള്‍ പ്രാദേശികമായി നടപ്പിലാക്കുക
   - മെച്ചപ്പെട്ട ഉപഭോക്തൃ അനുഭവത്തിനായി സ്ട്രീമിംഗ് ഇന്റർഫേസുകള്‍ പണിയുക
   - ചെറു ഭാഷാ മോഡലുകള്‍ക്ക് ഫലപ്രദമായ പ്രോംപ്റ്റ് ഡിസൈന്‍ ചെയ്യുക
   - പ്രാദേശിക മോഡലുകള്‍ ആപ്ലിക്കേഷനുകളില്‍ ഇന്റഗ്രേറ്റ് ചെയ്യുക

3. **റിട്രീവല്‍ ഓഗ്മെന്‍റഡ് ജനറേഷൻ (RAG)**
   - വെക്ടര്‍ എംബഡ്ഡിംഗുകളോടെ സാങ്കേതിക തിരയല്‍ സൃഷ്ടിക്കുക
   - LLM മറുപടികൾ ഡൊമെയ്ൻ-വിശദമായ ഡോക്യുമെന്റുകളില്‍ നിലനിര്‍ത്തുക
   - RAGAS ഘടകങ്ങള്‍ ഉപയോഗിച്ച് RAG ഗുണമേന്മ വിലയിരുത്തുക
   - പ്രോട്ടോടെപ്പ് മുതൽ ഉത്പാദനത്തിലേക്ക് സ്‌കെയിൽ ചെയ്യുക

4. **പ്രകടന ഓപ്റ്റിമൈസേഷൻ**
   - വിവിധ മോഡലുകള്‍ ക്രമപാതിയിലും തുലനാപരിശോധന നടത്തുക
   - വൈകല്യം, തുകലാറ്റന്‍, ആദ്യ ടോക്കണ്‍ സമയം അളക്കുക
   - ചെറு ഭാഷാ മോഡലുകളും വലിയ ഭാഷാ മോഡലുകളും തമ്മിൽ താരതമ്യം നടത്തുക
   - പ്രകടനം/ഗുണമേന്മ പരിഗണനയില്‍ അടിസ്ഥാനപ്പെടുത്തി മികച്ച മോഡലുകള്‍ തിരഞ്ഞെടുക്കുക

5. **ബഹു-എജന്റ് ഒർക്കസ്‌ട്രേഷൻ**
   - വിവിധ ജോലികള്‍ക്കായി പ്രത്യേക എജന്റുകള്‍ രൂപകല്‍പന ചെയ്യുക
   - എജന്റ് മെമ്മറി, കോൺടെക്സ്റ്റ് മാനേജ്മെന്റ് നടപ്പിലാക്കുക
   - സങ്കീർണ്ണ പ്രവാഹങ്ങളിൽ ബഹു-എജന്റുകൾ സഹകരിപ്പിക്കുക
   - എജന്റ് സഹകരണത്തിനായി കോർഡിനേറ്റർ മാതൃകകൾ പണിയുക

6. **ബുദ്ധിമുട്ടുള്ള മോഡൽ റൂട്ടിംഗ്**
   - ഉദ്ദേശ്യം കണ്ടെത്തലും മാതൃകയെ അനുപാതിപ്പിക്കലും നടപ്പിലാക്കുക
   - ചോദ്യങ്ങൾ അനുയോജ്യമായ മോഡലുകൾക്ക് സ്വയം റൂട്ടുചെയ്യുക
   - ബഹു-പടി പൈപ്പ്ലൈനുകൾ പണിയുക (പ്ലാൻ → നടപ്പിലാക്കുക → മെച്ചപ്പെടുത്തുക)
   - സ്കെയിലബിൾ മോഡൽ-ആസ്-ടൂൾസ് ആർക്കിടെക്ചറുകൾ ഡിസൈന്‍ ചെയ്യുക

### ദ്രുത പരിശോധന

സജ്ജീകരണം പരിശോധനയ്ക്ക് Python സെല്ലിൽ ഇത് ഓടിക്കുക:

```python
from foundry_local import FoundryLocalManager
import openai

# മാനേജർ ഇൻഷിയലൈസ് ചെയ്യുക (സ്‌വയം-വിസ്താര സേവനം കണ്ടെത്തുന്നു)
manager = FoundryLocalManager("phi-4-mini")

# OpenAI ക്ലയന്റ് കോൺഫിഗർ ചെയ്യുക
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# ചാറ്റ് പൂർത്തീകരണം പരിശോദിക്കുക
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**പ്രതീക്ഷിക്കുന്ന ഔട്ട്‌പുട്ട്**: ലോക്കൽ മോഡലിൽ നിന്നുള്ള സ്വാഗതമലയാളം.

- ❌ സെൽ കൃത്യമായ ക്രമത്തിൽ ഓടിക്കാത്തതിൽ നിന്ന് ഒഴിവാക്കുക
- ❌ പിശക് സന്ദേശങ്ങൾ ശ്രദ്ധാപൂർവ്വം വായിക്കാത്തത്
- ❌ അർത്ഥമാക്കാതെ വേഗത്തിൽ പോകുന്നത്
- ❌ മാർക്ക്ഡൗൺ വിശദീകരണങ്ങൾ അവഗണിക്കൽ
- ❌ നിങ്ങളുടെ മാറ്റം നടത്തിയ നോട്ട്‌ബുക്കുകൾ സംരക്ഷിക്കാതെ വെയ്ക്കുക

**ഡീബഗ്ഗിംഗ് സഹായങ്ങൾ**:
1. **സേവനം പ്രവർത്തിക്കുന്നില്ല**: `foundry service status` പരിശോധിക്കുക
2. **ഇംപോർട്ട് പിശകുകൾ**: വെർച്വൽ എൻവയോൺമെന്റ് ആക്ടിവേറ്റുചെയ്തിട്ടുണ്ടോ കാണുക
3. **മോഡൽ കണ്ടെത്തിയില്ല**: ലോഡ് ചെയ്ത മോഡലുകൾ കാണാൻ `foundry model ls` ഓടിക്കുക
4. **മന്ദഗതിയുള്ള പ്രകടനം**: റാം ഉപയോഗം പരിശോധിക്കുക, മറ്റു ആപ്പുകൾ അടയ്ക്കുക
5. **അപ്രതീക്ഷിത ഫലങ്ങൾ**: കർണൽ പുനരാരംഭിച്ച് മേൽനോട്ടത്തിന്ന് മുഴുവൻ സെലുകളും ഓടിക്കുക
