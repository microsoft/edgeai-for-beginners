## Шта је позивање функција?

Позивање функција је моћна могућност која омогућава Малим језичким моделима (SLMs) да интерагују са спољним алатима, API-јима и услугама. Уместо да буду ограничени искључиво на своје податке за обуку, SLM-ови сада могу:

- **Повезати се на спољне API-је** (услуге времена, базе података, претраживачи)
- **Извршити специфичне функције** на основу корисничких захтева
- **Прикупити информације у реалном времену** из различитих извора
- **Обављати рачунске задатке** преко специјализованих алата
- **Повезати више операција** за комплексне радне токове

Ова способност претвара SLM-ове из статичних генератора текста у динамичне AI агенте који могу обављати задатке из стварног света.

## Како функционише позивање функција

Процес позивања функција следи систематски радни ток:

### 1. Интеграција алата
- **Спољни алати**: SLM-ови могу да се повежу на weather API-је, базе података, веб услуге и друге спољне системе
- **Дефиниције функција**: Сваком алату се дефинишу специфични параметри, формати улаза/излаза и описе
- **Компатибилност са API-јима**: Алат је интегрисан кроз стандардизоване интерфејсе (REST API-ји, SDK-ови итд.)

### 2. Дефиниција функције
Функције се дефинишу са три кључне компоненте:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Детекција намере
- **Обрада природног језика**: SLM анализира улаз корисника да би разумео намеру
- **Усклађивање функција**: Одлучује која(е) функција(е) је потребна да испуни захтев
- **Извлачење параметара**: Идентификује и извлачи потребне параметре из поруке корисника

### 4. Генерација JSON излаза
SLM генерише структуриран JSON који садржи:
- Име функције која се позива
- Потребне параметре са одговарајућим вредностима
- Контекст извршења и метаподатке

### 5. Спољно извршење
- **Валидација параметара**: Обезбеђује да су сви потребни параметри присутни и исправно форматирани
- **Извршење функције**: Апликација извршава назначену функцију са датим параметрима
- **Руковање грешкама**: Управља неуспесима, истеком времена и неважећим одговорима

### 6. Интеграција одговора
- **Обрада резултата**: Излаз функције се враћа SLM-у
- **Интеграција контекста**: SLM укључује резултате у свој одговор
- **Комуникација са корисником**: Представља информације у природном, конверзацијском формату

## Сценарији примене

### Преузимање података
Претварајте упите на природном језику у структуриран позив API-ју:
- **"Прикажи моје недавне поруџбине"** → Упит базе података са корисничким ID и датумским филтерима
- **"Какво је време у Токију?"** → Позив weather API-ја са параметром локације
- **"Пронађи мејлове од Џона прошле недеље"** → Упит сервису е-поште са филтерима пошиљаоца и датума

### Извршење операција
Претворите корисничке захтеве у специфичне позиве функција:
- **"Закажи састанак за сутра у 14 сати"** → Интеграција са календарским API-јем
- **"Пошаљи поруку тиму"** → API комуникационе платформе
- **"Направи резервну копију мојих фајлова"** → Операција над фајл системом

### Рачунски задаци
Обрадите комплексне математичке или логичке операције:
- **"Израчунај сложене камате на 10.000$ по 5% за 10 година"** → Финансијска функција израчунавања
- **"Анализирај овај скуп података за трендове"** → Алати за статистичку анализу
- **"Оптимизуј ову руту за доставу"** → Алгоритми за оптимизацију руте

### Радни токови обраде података
Повежите више позива функција за сложене операције:
1. **Прикупите податке** из више извора
2. **Парсирајте и верификујте** информације
3. **Трансформишите** податке у потребан формат
4. **Сачувајте резултате** у одговарајуће системе
5. **Генеришите извештаје** или визуализације

### UI/UX интеграција
Омогућите динамичка ажурирања интерфејса:
- **"Прикажи податке о продаји на контролној табли"** → Генерисање и приказ графикона
- **"Ажурирај мапу са новим локацијама"** → Интеграција геопросторних података
- **"Освежи приказ залиха"** → Синхронизација података у реалном времену

## Рад са Qwen3 позивањем функција

Qwen3 нуди напредне могућности позивања функција са одличним перформансама и флексибилношću. Ево како га имплементирати:

### Коришћење Qwen-Agent оквира

Qwen-Agent пружа оквир високог нивоа који поједностављује имплементацију позивања функција:

#### Инсталација
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### Основно подешавање

```python
import os
from qwen_agent.agents import Assistant

# Конфигуришите LLM
llm_cfg = {
    'model': 'Qwen3-8B',
    # Опција 1: Користите Alibaba Model Studio
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # Опција 2: Користите локално постављање
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'ПРАЗАН',
    
    # Опциона конфигурација за режим размишљања
    'generate_cfg': {
        'thought_in_content': True,  # Укључи разлогање у одговор
    }
}

# Дефинишите алате користећи MCP (Протокол Контекста Модела)
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # Уграђени алат за извршавање кода
]

# Креирајте асистента
bot = Assistant(llm=llm_cfg, function_list=tools)

# Пример коришћења
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# Генериши одговор са позивом функције
for response in bot.run(messages=messages):
    print(response)
```

### Имплементација прилагођених функција

Такође можете дефинисати прилагођене функције за Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Симулирати позив временске API
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Користите прилагођени алат
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

## Foundry локална интеграција

Microsoft's Foundry Local пружа OpenAI-компатибилан API за покретање модела локално са побољшаном приватношћу и перформансама.

### Подешавање и инсталација

#### Windows
Преузмите инсталациони програм са [Foundry Local releases page](https://github.com/microsoft/Foundry-Local/releases) и пратите упутства за инсталацију.

#### macOS
```bash
brew tap microsoft/foundrylocal
brew install foundrylocal
```

#### Основна употреба

```python
import openai
from foundry_local import FoundryLocalManager

# Иницијализуј са алјасом модела
alias = "phi-3.5-mini"  # Или било којим подржаним моделом
manager = FoundryLocalManager(alias)

# Креирај OpenAI клијента који показује на локални ендпоинт
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# Дефиниши функције за модел
functions = [
    {
        "name": "calculate_tax",
        "description": "Calculate tax amount based on income and rate",
        "parameters": {
            "type": "object",
            "properties": {
                "income": {
                    "type": "number",
                    "description": "Annual income amount"
                },
                "tax_rate": {
                    "type": "number", 
                    "description": "Tax rate as decimal (e.g., 0.25 for 25%)"
                }
            },
            "required": ["income", "tax_rate"]
        }
    }
]

# Направи захтев за позивање функције
response = client.chat.completions.create(
    model=manager.model_info.id,
    messages=[
        {
            "role": "user",
            "content": "Calculate the tax for someone earning $75,000 with a 22% tax rate"
        }
    ],
    functions=functions,
    function_call="auto"
)

print(response.choices[0].message.content)
```

- **Само CPU**: Бира CPU-оптимизоване моделе

        """Execute a function with comprehensive error handling and logging"""

        try:
            # Потврдите да функција постоји
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Провера ограничења броја позива
            if not self._check_rate_limit(function_name):
                return FunctionResult(

                    timestamp=start_time

            # Потврдите параметре
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Извршите функцију

            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Запишите успешну извршеност
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Запишите неуспешну извршеност
            self._log_function_call(function_name, parameters, result)
            
            return result

        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Проверите да ли је испод лимита
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Проверите потребне параметре
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:

                    success=False,
                    error=f"Missing required parameter: {param_name}"

    def get_function_definitions(self) -> List[Dict]:
        """Get OpenAI-compatible function definitions for all registered functions"""
        definitions = []
        
        for func_name, func_info in self.functions.items():
            definition = {
                'name': func_name,
                'description': func_info['description'],
                'parameters': {
                    'type': 'object',
                    'properties': {},
                    'required': []
                }
            }
            
            for param_name, param_info in func_info['parameters'].items():
                definition['parameters']['properties'][param_name] = {
                    'type': param_info['type'],
                    'description': param_info.get('description', '')
                }
                
                if 'enum' in param_info:
                    definition['parameters']['properties'][param_name]['enum'] = param_info['enum']
                
                if 'default' in param_info:
                    definition['parameters']['properties'][param_name]['default'] = param_info['default']
                
                if param_info.get('required', False):
                    definition['parameters']['required'].append(param_name)
            
            definitions.append(definition)
        
        return definitions

## Закључак

Позивање функција у Малим језичким моделима представља парадигме померања од статичних AI помоћника ка динамичним, способним агентима који могу интераговати са стварним светом. Овај туторијал је покрио:

### Кључне појединости

1. **Основно разумевање**: Позивање функција омогућује SLM-овима да се прошире изван својих података за обуку повезивањем са спољним алатима и услугама.

2. **Флексибилност имплементације**: Постоји више приступа, од нискон-ивелских имплементација са прилагођеним шаблонима до оквира високог нивоа као што су Qwen-Agent и Foundry Local.

3. **Разматрања за продукцију**: Примена у предузећима захтева пажњу на руковање грешкама, ограничења брзине, безбедност и евиденцију ревизија.

4. **Оптимизација перформанси**: Правилан дизајн функција, ефикасно извршење и паметно кеширање могу значајно побољшати време одговора.

### Будући правци

Како технологија SLM наставља да се развија, можемо очекивати:

- **Побољшану тачност позивања функција**: Боље детектовање намере и извлачење параметара
- **Напредну паралелну обраду**: Сложенија оркестрација више функција
- **Боље стандарде интеграције**: Стандартизоване протоколе за интеграцију алата
- **Напредне безбедносне функције**: Побољшане механизме аутентификације и ауторизације
- **Проширени екосистем**: Растућу библиотеку претходно направљених функција и интеграција

### Почетак рада

За почетак имплементације позивања функција у вашим пројектима:

1. **Почни једноставно**: Започни са основним сценаријима једноструких функција
2. **Изабери оквир**: Одабери између директне имплементације (Ollama/Phi-4) или помоћу оквира (Qwen-Agent)
3. **Дизајнирај функције пажљиво**: Фокусирај се на јасне, добро документоване дефиниције функција
4. **Имплементирај руковање грешкама**: Изгради робусно руковање грешкама од почетка
5. **Постепено скалирање**: Прелази са једноставних на сложене сценарије како стичеш искуство

Позивање функција претвара SLM-ове из импресивних генератора текста у практичне AI агенте који могу решавати проблеме стварног света. Пратећи обрасце и праксе наведене у овом туторијалу, можете изградити моћне, поуздане AI системе који превазилазе традиционалне интерфејсе за чет.
