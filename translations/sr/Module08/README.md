# Модул 08: Практична примена Microsoft Foundry Local - Комплетан сет алата за програмере

## Преглед

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) представља нову генерацију развоја еџ AI-а, пружајући програмерима моћне алате за изградњу, увођење и скалирање AI апликација локално уз одржавање беспрекорне интеграције са Azure AI Foundry. Овај модул покрива свеобухватно Foundry Local, од инсталације до напредног развоја агената.

**Кључне технологије:**
- Microsoft Foundry Local CLI и SDK
- Интеграција са Azure AI Foundry
- Извођење модела на уређају
- Локално кеширање и оптимизација модела
- Архитектуре засноване на агентима

## Циљеви учења

Завршетком овог модула постаћете у стању да:

- **Мастер Foundry Local**: Инсталирате, конфигуришете и оптимизујете за развој на Windows 11
- **Управљате разноликим моделима**: Покрећете модели phi, qwen, deepseek и GPT локално помоћу CLI команди
- **Правите производна решења**: Креирате AI апликације са напредном инжењерингом упита и интеграцијом података
- **Искористите отворени изворни екосистем**: Интегришете Hugging Face моделе и доприносе заједнице
- **Развијате AI агенте**: Градите интелигентне агенте са могућностима ослањања на чињенице и оркестрације
- **Имплементирате предузетничке обрасце**: Креирате модуларна, скалабилна AI решења за производно увођење

## Предуслови

### Системски захтеви
- **Оперативни систем**: Windows 11 (22H2 или новији)
- **Рам меморија**: 16GB RAM (32GB препоручено за веће моделе)
- **Складиште**: 50GB слободног простора за кеширање модела
- **Хардвер**: Препоручен уређај са омогућеним NPU-ом (Copilot+ PC), GPU опционално
- **Мрежа**: Брзи интернет за почетно преузимање модела

### Развојно окружење

- Visual Studio Code са AI Toolkit додатком
- Python 3.10+ и pip
- Git за контролу верзија
- PowerShell или Command Prompt
- Azure CLI (опционо за интеграцију у облаку)

- Основно разумевање AI/ML концепата
- Познавање командне линије
- Основе програмирања у Питону

### Решавање честих проблема

**Грешке везе са Foundry Local**
```powershell
# Проверите статус сервиса
foundry status

# Поново покрените ако је потребно
foundry restart

# Проверите приступачност крајње тачке
curl http://localhost:5273/v1/models
```

**Проблеми са учитавањем модела**
```powershell
# Провери доступне моделе
foundry model list --cached

# Преузми недостајуће моделе
foundry model download phi-4-mini
foundry model download qwen2.5-0.5b

# Принуди поновно учитавање ако је потребно
foundry model unload --all
foundry model run phi-4-mini
```

**Проблеми са зависностима**
```powershell
# Ажурирај pip и поново инсталирај
python -m pip install --upgrade pip
pip install -r requirements.txt --force-reinstall
```

## Резиме


Овај модул представља врхунски развој у области edge AI, комбинујући Microsoft-ове алате за предузећа са флексибилношћу и иновацијама open-source екосистема. Савладавањем Foundry Local кроз свих 10 свеобухватних примера бићете позиционирани у самом врху развоја AI апликација.
