## Део 1: Откривање модела помоћу Foundry CLI-а

### Основне команде за управљање моделима

Foundry CLI пружа директне команде за откривање и управљање моделима:

```cmd
REM List all available models in the catalog
foundry model list

REM List cached (downloaded) models
foundry cache list

REM Check cache directory location
foundry cache ls
```

### Покретање првих модела

Почните са популарним, добро тестираним моделима да бисте разумели карактеристике перформанси:

```cmd
REM Run Phi-4-Mini (lightweight, fast)
foundry model run phi-4-mini --verbose

REM Run Qwen 2.5 7B (larger, more capable)
foundry model run qwen2.5-7b --verbose

REM Run DeepSeek (specialized for coding)
foundry model run deepseek-r1-7b --verbose
```

**Напомена:** Заставица `--verbose` пружа детаљне информације о покретању, укључујући:
- Напредак преузимања модела (при првом покретању)
- Детаље о алокацији меморије
- Информације о повезивању сервиса
- Метрике иницијализације перформанси

### Разумевање категорија модела

**Мали језички модели (SLMs):**
- `phi-4-mini`: Брз, ефикасан, одличан за општи разговор
- `phi-4`: Снажнија верзија са бољим размишљањем

**Средњи модели:**
- `qwen2.5-7b`: Одлично размишљање и дужи контекст
- `deepseek-r1-7b`: Оптимизован за генерисање кода

**Већи модели:**
- `llama-3.2`: Најновији модел отвореног кода из Meta
- `qwen2.5-14b`: Пословни ниво размишљања

**Типичне величине модела:**
- `phi-4-mini`: ~2.5 GB
- `qwen2.5-7b`: ~4.1 GB  
- `deepseek-r1-7b`: ~4.3 GB
- `llama-3.2`: ~4.9 GB
- `qwen2.5-14b`: ~8.2 GB

**Најбоље праксе за складиштење:**
- Чувајте 2-3 модела кеширана за брзо пребацивање
- Уклоните неискоришћене моделе ради ослобађања простора: `foundry cache clean`
- Пратите коришћење диска, посебно на мањим SSD-овима
- Размислите о узајамном односу величине и способности модела

- Праћење коришћења CPU-а током инференције


```
phi-4:         12GB RAM,  mid-range CPU
qwen2.5-7b:    16GB RAM,  mid-range CPU
deepseek-r1:   16GB RAM,  mid-range CPU
qwen2.5-14b:   24GB RAM,  high-end CPU
```

**Препоручено за најбоље перформансе:**
- 32GB+ RAM за удобно пребацивање између више модела

## Део 5: Једноставно мерење перформанси модела

### Основно тестирање перформанси

Ево директног приступа за упоређивање перформанси модела:

```python
# simple_bench.py - Засновано на узорцима из Примера 03
import time
import requests
import json

def test_model_response(model_name, prompt="Explain edge AI in one sentence."):
    """Test a single model with a prompt and measure response time."""
    start_time = time.time()
    
    try:
        response = requests.post(
            "http://localhost:8000/v1/chat/completions",
            headers={"Content-Type": "application/json"},
            json={
                "model": model_name,
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 64
            },
            timeout=30
        )
        
        elapsed = time.time() - start_time
        
        if response.status_code == 200:
            result = response.json()
            return {
                "model": model_name,
                "latency_sec": round(elapsed, 3),
                "response": result["choices"][0]["message"]["content"],
                "status": "success"
            }
        else:
            return {
                "model": model_name,
                "status": "error",
                "error": f"HTTP {response.status_code}"
            }
            
    except Exception as e:
        return {
            "model": model_name,
            "status": "error", 
            "error": str(e)
        }

# Тестирај тренутно покренути модел
if __name__ == "__main__":
    # Тестирај са различитим моделима (прво покрени сваки модел)
    test_models = ["phi-4-mini", "qwen2.5-7b", "deepseek-r1-7b"]
    
    print("Model Performance Test")
    print("=" * 50)
    
    for model in test_models:
        print(f"\nTesting {model}...")
        print("Note: Make sure this model is running first with 'foundry model run {model}'")
        
        result = test_model_response(model)
        
        if result["status"] == "success":
            print(f"✅ {model}: {result['latency_sec']}s")
            print(f"   Response: {result['response'][:100]}...")
        else:
            print(f"❌ {model}: {result['error']}")
```

### Ручна процена квалитета

За сваки модел, тестирајте исти упите и ручно процените:

**Тест упити:**
1. "Објасните квантно рачунање једноставним речима."
2. "Напиши Python функцију за сортирање листе."
3. "Које су предности и мане рада на даљину?"
4. "Резимирајте предности edge AI."

**Критеријуми процене:**

- **Потпуност**: Да ли одговара на цело питање?
- **Брзина**: Колико брзо одговара?
