## Co je volání funkcí?

Volání funkcí je výkonná schopnost, která umožňuje malým jazykovým modelům (SLM) interagovat s externími nástroji, API a službami. Místo toho, aby byly omezeny pouze na svá tréninková data, mohou SLM nyní:

- **Připojit se k externím API** (služby počasí, databáze, vyhledávače)
- **Vykonávat specifické funkce** na základě požadavků uživatele
- **Získávat informace v reálném čase** z různých zdrojů
- **Provádět výpočetní úkoly** prostřednictvím specializovaných nástrojů
- **Řetězit více operací** pro komplexní pracovní postupy

Tato schopnost přeměňuje SLM z statických generátorů textu na dynamické AI agenty, kteří mohou vykonávat úkoly v reálném světě.

## Jak volání funkcí funguje

Proces volání funkcí následuje systematický pracovní postup:

### 1. Integrace nástrojů
- **Externí nástroje**: SLM se mohou připojit k API pro počasí, databázím, webovým službám a dalším externím systémům
- **Definice funkcí**: Každý nástroj je definován se specifickými parametry, formáty vstupu/výstupu a popisy
- **Kompatibilita API**: Nástroje jsou integrovány přes standardizovaná rozhraní (REST API, SDK apod.)

### 2. Definice funkcí
Funkce jsou definovány třemi klíčovými komponentami:
```json
{
  "name": "function_name",
  "description": "Clear description of what the function does",
  "parameters": {
    "parameter_name": {
      "description": "What this parameter represents",
      "type": "data_type",
      "default": "default_value"
    }
  }
}
```

### 3. Detekce záměru
- **Zpracování přirozeného jazyka**: SLM analyzuje uživatelský vstup, aby porozuměla záměru
- **Přiřazení funkcí**: Určuje, která funkce(y) jsou potřeba k vyřízení požadavku
- **Extrahování parametrů**: Identifikuje a vytahuje požadované parametry ze zprávy uživatele

### 4. Generování JSON výstupu
SLM generuje strukturovaný JSON obsahující:
- Název funkce k volání
- Požadované parametry s odpovídajícími hodnotami
- Kontext provedení a metadata

### 5. Externí provedení
- **Ověření parametrů**: Zajišťuje, že všechny požadované parametry jsou přítomné a správně formátované
- **Vykonání funkce**: Aplikace vykoná specifikovanou funkci s poskytnutými parametry
- **Řešení chyb**: Řídí chyby, překročení časů a neplatné odpovědi

### 6. Integrace odpovědi
- **Zpracování výsledků**: Výstup funkce je vrácen zpět do SLM
- **Integrace kontextu**: SLM začleňuje výsledky do své odpovědi
- **Komunikace s uživatelem**: Prezentuje informace v přirozeném, konverzačním formátu

## Scénáře použití

### Získávání dat
Převádění dotazů v přirozeném jazyce na strukturované API volání:
- **"Zobraz mé nedávné objednávky"** → Databázový dotaz s ID uživatele a časovými filtry
- **"Jaké je počasí v Tokiu?"** → API volání počasí s parametrem lokace
- **"Najdi e-maily od Johna z minulého týdne"** → Dotaz na e-mailovou službu s filtrem odesílatele a datem

### Vykonávání operací
Převádění uživatelských požadavků na specifická volání funkcí:
- **"Naplánuj schůzku na zítra ve 14:00"** → Integrace kalendářového API
- **"Pošli zprávu týmu"** → API komunikační platformy
- **"Vytvoř zálohu mých souborů"** → Operace souborového systému

### Výpočetní úkoly
Zpracování složitých matematických nebo logických operací:
- **"Spočítej složený úrok z 10 000 $ při 5 % na 10 let"** → Finanční výpočtová funkce
- **"Analyzuj dataset pro trendy"** → Statistické analytické nástroje
- **"Optimalizuj trasu pro doručení"** → Algoritmy pro optimalizaci trasy

### Pracovní postupy zpracování dat
Řetězení více volání funkcí pro komplexní operace:
1. **Získání dat** z více zdrojů
2. **Parsování a validace** informací
3. **Transformace** dat do požadovaného formátu
4. **Uložení výsledků** do vhodných systémů
5. **Generování reportů** nebo vizualizací

### Integrace UI/UX
Umožnění dynamických aktualizací rozhraní:
- **"Zobraz data o prodejích na dashboardu"** → Generování a zobrazení grafů
- **"Aktualizuj mapu s novými lokalitami"** → Integrace geodatových informací
- **"Obnov zobrazení inventáře"** → Synchronizace dat v reálném čase

## Nastavení volání funkcí s Phi-4-mini a Ollama

Phi-4-mini od Microsoftu podporuje jak jedno, tak paralelní volání funkcí přes Ollama. Zde je návod, jak to nastavit:

### Požadavky
- Ollama verze 0.5.13 nebo vyšší
- Phi-4-mini model (doporučeno: `phi4-mini:3.8b-fp16`)

### Kroky instalace

#### 1. Instalace a spuštění Phi-4-mini
```bash
# Stáhnout model (pokud již není přítomen)
ollama run phi4-mini:3.8b-fp16

# Ověřit, že je model dostupný
ollama list
```

#### 2. Vytvoření vlastního ModelFile šablony
Kvůli současným omezením výchozích šablon Ollama je potřeba vytvořit vlastní ModelFile s následující šablonou:

```modelfile

Use the following rule to decide when to call a function:
* if the response can be generated from your internal knowledge (e.g., as in the case of queries like "What is the capital of Poland?"), do so
* if you need external information that can be obtained by calling one or more of the provided functions, generate a function calls
If you decide to call functions:

* all function calls should be generated in a single JSON list formatted as functools[{"name": [function name], "arguments": [function arguments as JSON]}, ...]
* follow the provided JSON schema. Do not hallucinate arguments or values. Do to blindly copy values from the provided samples
* respect the argument type formatting. E.g., if the type if number and format is float, write value 7 as 7.0

{{- if .Tools }}
{{ .Tools }}
{{- end }}<|end|>
{{- end }}
{{- range .Messages }}
{{- if ne .Role "system" }}<|{{ .Role }}|>

{{- else if .ToolCalls }}

{{- range .ToolCalls }}{{ "{" }}"name": "{{ .Function.Name }}", "arguments": {{ .Function.Arguments }}{{ "}" }}
{{- end }}]

{{- end }}
{{- end }}<|assistant|>
```

## Práce s voláním funkcí Qwen3

Qwen3 nabízí pokročilé schopnosti volání funkcí s vynikajícím výkonem a flexibilitou. Zde je návod, jak to implementovat:

### Použití rámce Qwen-Agent

Qwen-Agent poskytuje vysoce úrovňový rámec, který zjednodušuje implementaci volání funkcí:

#### Instalace
```bash
pip install -U "qwen-agent[gui,rag,code_interpreter,mcp]"
```

#### Základní nastavení

```python
import os
from qwen_agent.agents import Assistant

# Nakonfigurujte LLM
llm_cfg = {
    'model': 'Qwen3-8B',
    # Možnost 1: Použijte Alibaba Model Studio
    'model_type': 'qwen_dashscope',
    'api_key': os.getenv('DASHSCOPE_API_KEY'),
    
    # Možnost 2: Použijte lokální nasazení
    # 'model_server': 'http://localhost:8000/v1',
    # 'api_key': 'PRÁZDNÉ',
    
    # Volitelné nastavení pro režim přemýšlení
    'generate_cfg': {
        'thought_in_content': True,  # Zahrnout zdůvodnění do odpovědi
    }
}

# Definujte nástroje pomocí MCP (Model Context Protocol)
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx', 
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter',  # Vestavěný nástroj pro spouštění kódu
]

# Vytvořte asistenta
bot = Assistant(llm=llm_cfg, function_list=tools)

# Příklad použití
messages = [
    {
        'role': 'user', 
        'content': 'What time is it now? Also, fetch the latest news from https://example.com/news'
    }
]

# Generujte odpověď s voláním funkce
for response in bot.run(messages=messages):
    print(response)
```

### Definice vlastních funkcí

Můžete také definovat vlastní funkce pro Qwen3:

```python
import json
from qwen_agent.tools.base import BaseTool

class WeatherTool(BaseTool):
    description = 'Get weather information for a specific location'
    parameters = [
        {
            'name': 'location',
            'type': 'string', 
            'description': 'City or location name',
            'required': True
        },
        {
            'name': 'units',
            'type': 'string',
            'description': 'Temperature units (celsius or fahrenheit)',
            'required': False,
            'default': 'celsius'
        }
    ]
    
    def call(self, params: str, **kwargs) -> str:
        """Execute the weather lookup"""
        params_dict = json.loads(params)
        location = params_dict.get('location')
        units = params_dict.get('units', 'celsius')
        
        # Simulovat volání API počasí
        weather_data = {
            'location': location,
            'temperature': '22°C' if units == 'celsius' else '72°F',
            'condition': 'Partly cloudy',
            'humidity': '65%'
        }
        
        return json.dumps(weather_data)

# Použijte vlastní nástroj
tools = [WeatherTool()]
bot = Assistant(llm=llm_cfg, function_list=tools)

messages = [{'role': 'user', 'content': 'What\'s the weather in Tokyo?'}]
response = bot.run(messages=messages)
print(list(response)[-1])
```

```python
import openai
```

### Běžné problémy a řešení

#### Problém 1: Funkce není volána
**Příznaky**: Model odpovídá textem místo volání funkce

**Řešení**:
1. **Zkontrolujte popis funkce**: Ujistěte se, že jasně odpovídá záměru uživatele
2. **Ověřte definice parametrů**: Zajistěte správné definování všech požadovaných parametrů
3. **Projděte systémový prompt**: Zahrňte jasné pokyny, kdy funkce používat
4. **Testujte s explicitními požadavky**: Například „Použij prosím funkci počasí pro data z Londýna“

#### Problém 2: Nesprávné parametry
**Příznaky**: Funkce je volána s nesprávnými nebo chybějícími parametry

**Řešení**:
1. **Přidejte příklady parametrů**: Uveďte ukázkové hodnoty v popisech parametrů
2. **Používejte omezení výčtem**: Omezte hodnoty parametrů na specifické možnosti, kde je to možné
3. **Implementujte výchozí hodnoty**: Poskytněte rozumné výchozí hodnoty pro volitelné parametry

```python
{
    "name": "book_restaurant",
    "parameters": {
        "cuisine": {
            "type": "string",
            "enum": ["italian", "chinese", "mexican", "american", "french"],
            "description": "Type of cuisine (example: 'italian' for Italian food)"
        },
        "party_size": {
            "type": "integer",
            "minimum": 1,
            "maximum": 20,
            "description": "Number of people (example: 4 for a family of four)"
        }
    }
}
```

#### Problém 3: Selhání paralelního volání funkcí
**Příznaky**: Provádí se pouze jedna funkce, přitom by mělo běžet více funkcí

**Řešení**:
1. **Zkontrolujte podporu modelu**: Ujistěte se, že váš model podporuje paralelní volání funkcí
2. **Aktualizujte systémový prompt**: Zahrňte fráze „některé nástroje“ nebo „více nástrojů“ do systémové zprávy
3. **Použijte vhodné verze modelů**: Doporučeno Phi-4-mini:3.8b-fp16 pro Ollama

#### Problém 4: Problémy se šablonami u Ollama
**Příznaky**: Volání funkcí nefunguje s výchozím nastavením Ollama

```python
class EnterpriseAIAgent:

            'call_count': 0,

        }
    
    async def execute_function(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Execute a function with comprehensive error handling and logging"""
        start_time = datetime.now()
        
        try:
            # Ověřte, zda funkce existuje
            if function_name not in self.functions:
                return FunctionResult(
                    success=False,
                    error=f"Function '{function_name}' not found",
                    timestamp=start_time
                )
            
            # Zkontrolujte limity rychlosti
            if not self._check_rate_limit(function_name):
                return FunctionResult(
                    success=False,
                    error=f"Rate limit exceeded for function '{function_name}'",
                    timestamp=start_time
                )
            
            # Ověřte parametry
            validation_result = self._validate_parameters(function_name, parameters)
            if not validation_result.success:
                return validation_result
            
            # Proveďte funkci
            func_info = self.functions[function_name]
            handler = func_info['handler']
            
            if asyncio.iscoroutinefunction(handler):
                result_data = await handler(**parameters)
            else:
                result_data = handler(**parameters)
            
            execution_time = (datetime.now() - start_time).total_seconds()
            
            result = FunctionResult(
                success=True,
                data=result_data,
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Zaznamenejte úspěšné spuštění
            self._log_function_call(function_name, parameters, result)
            
            return result
            
        except Exception as e:
            execution_time = (datetime.now() - start_time).total_seconds()
            result = FunctionResult(
                success=False,
                error=str(e),
                execution_time=execution_time,
                timestamp=start_time
            )
            
            # Zaznamenejte neúspěšné spuštění
            self._log_function_call(function_name, parameters, result)
            
            return result
    
    def _check_rate_limit(self, function_name: str) -> bool:
        """Check if function call is within rate limits"""
        func_info = self.functions[function_name]
        now = datetime.now()
        
        # Resetujte počítadlo, pokud uplynula minuta
        if (now - func_info['last_reset']).seconds >= 60:
            func_info['call_count'] = 0
            func_info['last_reset'] = now
        
        # Zkontrolujte, zda je pod limitem
        if func_info['call_count'] >= func_info['rate_limit']:
            return False
        
        func_info['call_count'] += 1
        return True
    
    def _validate_parameters(self, function_name: str, parameters: Dict) -> FunctionResult:
        """Validate function parameters"""
        func_params = self.functions[function_name]['parameters']
        
        # Zkontrolujte požadované parametry
        for param_name, param_info in func_params.items():
            if param_info.get('required', False) and param_name not in parameters:
                return FunctionResult(
                    success=False,
                    error=f"Missing required parameter: {param_name}"
                )
        
        # Ověřte typy a omezení parametrů
        for param_name, value in parameters.items():
            if param_name in func_params:
                param_info = func_params[param_name]
                
                # Ověření typu
                expected_type = param_info.get('type')
                if expected_type == 'string' and not isinstance(value, str):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a string"
                    )
                elif expected_type == 'number' and not isinstance(value, (int, float)):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a number"
                    )
                elif expected_type == 'boolean' and not isinstance(value, bool):
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be a boolean"
                    )
                
                # Ověření výčtu (enum)
                if 'enum' in param_info and value not in param_info['enum']:
                    return FunctionResult(
                        success=False,
                        error=f"Parameter '{param_name}' must be one of: {param_info['enum']}"
                    )
```

2. **Flexibilita implementace**: Existuje několik přístupů, od nízkoúrovňových implementací s vlastními šablonami po vysoce úrovňové rámce jako Qwen-Agent a Foundry Local.

3. **Úvahy pro produkci**: Podnikové nasazení vyžaduje pozornost k řešení chyb, omezení rychlosti, bezpečnosti a auditování.

4. **Optimalizace výkonu**: Správný návrh funkcí, efektivní provedení a inteligentní ukládání do mezipaměti mohou výrazně zlepšit rychlost odezvy.

### Budoucí směřování

Jak technologie SLM bude nadále vyvíjet, můžeme očekávat:

- **Lepší přesnost volání funkcí**: Vylepšená detekce záměru a extrakce parametrů
- **Vylepšené paralelní zpracování**: Sofistikovanější orchestrace vícero funkcí
- **Lepší standardy integrace**: Standardizované protokoly pro integraci nástrojů
- **Pokročilé bezpečnostní prvky**: Zlepšené mechanismy autentizace a autorizace
- **Rozšířený ekosystém**: Rostoucí knihovna předpřipravených funkcí a integrací

### Začínáme

Pro zahájení implementace volání funkcí ve vašich projektech:
