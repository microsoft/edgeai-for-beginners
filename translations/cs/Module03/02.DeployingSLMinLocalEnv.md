# Sekce 2: Nasazení místního prostředí – řešení šetrná k soukromí

Místní nasazení malých jazykových modelů (SLM) představuje změnu paradigmatu směrem k řešením AI, která chrání soukromí a jsou nákladově efektivní. Tento komplexní průvodce zkoumá dva výkonné frameworky — Ollama a Microsoft Foundry Local — které vývojářům umožňují využít plný potenciál SLM při zachování úplné kontroly nad nasazovacím prostředím.

## Úvod

V této lekci prozkoumáme pokročilé strategie nasazení malých jazykových modelů v místních prostředích. Probereme základní koncepty místního nasazení AI, představíme dvě vedoucí platformy (Ollama a Microsoft Foundry Local) a poskytneme praktické návody k implementaci řešení připravených pro produkci.

## Výukové cíle

Na konci této lekce budete schopni:

- Pochopit architekturu a výhody rámců pro lokální nasazení SLM.
- Implementovat produkčně připravená nasazení s použitím Ollama a Microsoft Foundry Local.
- Porovnat a vybrat vhodnou platformu na základě konkrétních požadavků a omezení.
- Optimalizovat místní nasazení pro výkon, bezpečnost a škálovatelnost.

## Pochopení architektury místního nasazení SLM

Místní nasazení SLM představuje zásadní posun od cloudově závislých AI služeb k on-premises řešením, která zachovávají soukromí. Tento přístup umožňuje organizacím udržovat úplnou kontrolu nad infrastrukturou AI a zároveň zajišťuje suverenitu dat a provozní nezávislost.

### Klasifikace rámců nasazení

Porozumění různým přístupům k nasazení pomáhá vybrat správnou strategii pro konkrétní případy použití:

- **Zaměřeno na vývoj**: Zjednodušené nastavení pro experimentování a prototypování
- **Podnikového rázu**: Produkčně připravená řešení s možností integrace do podnikové infrastruktury
- **Víceplatfromní**: Univerzální kompatibilita přes různé operační systémy a hardware

### Klíčové výhody místního nasazení SLM

Lokální nasazení SLM nabízí několik zásadních výhod, které je činí ideálními pro podnikové a na ochranu soukromí citlivé aplikace:

**Soukromí a bezpečnost**: Lokální zpracování zajišťuje, že citlivá data nikdy neopustí infrastrukturu organizace, což umožňuje dodržování GDPR, HIPAA a dalších regulačních požadavků. V izolovaném nasazení je možné fungovat i v utajených prostředích, zatímco kompletní auditní záznamy udržují bezpečnostní dohled.

**Nákladová efektivita**: Eliminace modelů cen za token výrazně snižuje provozní náklady. Nižší požadavky na šířku pásma a snížená závislost na cloudu zajišťují předvídatelné nákladové struktury pro podnikové rozpočtování.

**Výkon a spolehlivost**: Rychlejší doby odezvy bez zpoždění sítí umožňují aplikace v reálném čase. Offline funkčnost zajišťuje nepřetržitý provoz bez ohledu na dostupnost internetu, zatímco optimalizace místních zdrojů poskytuje konzistentní výkon.

## Ollama: Univerzální platforma pro místní nasazení

### Jádrová architektura a filozofie

Ollama je navržena jako univerzální, pro vývojáře přívětivá platforma, která demokratizuje lokální nasazení LLM napříč různými hardwarovými konfiguracemi a operačními systémy.

**Technický základ**: Postavená na robustním frameworku llama.cpp, Ollama využívá efektivní formát modelů GGUF pro optimální výkon. Víceplatfromní kompatibilita zajišťuje konzistentní chování na Windows, macOS a Linuxu, zatímco inteligentní správa zdrojů optimalizuje využití CPU, GPU a paměti.

**Filozofie designu**: Ollama upřednostňuje jednoduchost bez obětování funkcionality a nabízí nasazení bez konfigurace pro okamžitou produktivitu. Platforma zachovává širokou kompatibilitu modelů a zajišťuje konzistentní API napříč různými architekturami modelů.

### Pokročilé funkce a schopnosti

**Excelence v řízení modelů**: Ollama poskytuje komplexní správu životního cyklu modelů s automatickým stahováním, cachováním a verzováním. Platforma podporuje rozsáhlý ekosystém modelů včetně Llama 3.2, Google Gemma 2, Microsoft Phi-4, Qwen 2.5, DeepSeek, Mistral a specializovaných embedovacích modelů.

**Přizpůsobení pomocí Modelfiles**: Pokročilí uživatelé mohou vytvářet vlastní konfigurace modelů se specifickými parametry, systémovými promptami a úpravami chování. To umožňuje optimalizace pro konkrétní domény a speciální aplikační požadavky.

**Optimalizace výkonu**: Ollama automaticky detekuje a využívá dostupné hardwarové akcelerace včetně NVIDIA CUDA, Apple Metal a OpenCL. Inteligentní správa paměti zabezpečuje optimální využití zdrojů napříč různými konfiguracemi hardwaru.

    "stream": False,

        "top_p": 0.95,
        "num_predict": 1024
    }
}

# Proveďte požadavek na API
response = requests.post(OLLAMA_ENDPOINT, json=params)
result = response.json()

# Zpracujte a zobrazte odpověď
print(result["response"])

# Příklad streamování (pro odpovědi v reálném čase)
def stream_response():
    params["stream"] = True
    response = requests.post(OLLAMA_ENDPOINT, json=params, stream=True)
    
    for line in response.iter_lines():
        if line:
            chunk = json.loads(line)
            if "response" in chunk:
                print(chunk["response"], end="", flush=True)
            if chunk.get("done", False):
                print()
                break

**Integrace JavaScript/TypeScript (Node.js)**:

```javascript
const axios = require('axios');

// Konfigurace API
const OLLAMA_API = 'http://localhost:11434/api';

// Funkce pro generování textu pomocí Ollama
async function generateText(model, prompt, systemPrompt = '') {
  try {
    const response = await axios.post(`${OLLAMA_API}/generate`, {
      model: model,
      prompt: prompt,
      system: systemPrompt,
      stream: false,
      options: {
        temperature: 0.7,
        top_k: 40,
        top_p: 0.9,
        num_predict: 1024
      }
    });
    
    return response.data.response;
  } catch (error) {
    console.error('Error generating text:', error.message);
    throw error;
  }
}

// Příklad použití v Express API
const express = require('express');
const app = express();
app.use(express.json());

app.post('/api/chat', async (req, res) => {
  const { message } = req.body;
  
  try {
    const response = await generateText(
      'phi4:mini',
      message,
      'You are a helpful AI assistant.'
    );
    
    res.json({ response });
  } catch (error) {
    res.status(500).json({ error: 'Failed to generate response' });
  }
});

app.listen(3000, () => {
  console.log('API server running on port 3000');
});
```

## Microsoft Foundry Local: Podniková edge AI platforma

### Podniková architektura

Microsoft Foundry Local představuje komplexní podnikové řešení navržené speciálně pro produkční edge AI nasazení s hlubokou integrací do ekosystému Microsoftu.

**Základ ONNX**: Postavený na průmyslovém standardu ONNX Runtime, Foundry Local poskytuje optimalizovaný výkon přes různé hardwarové architektury. Platforma využívá integraci Windows ML pro nativní optimalizaci ve Windows a zároveň zachovává víceplatformní kompatibilitu.

**Excelence v hardwarové akceleraci**: Foundry Local disponuje inteligentní detekcí a optimalizací hardwaru napříč CPU, GPU a NPU. Hluboká spolupráce s dodavateli hardwaru (AMD, Intel, NVIDIA, Qualcomm) zajišťuje optimální výkon na podnikových hardwarových konfiguracích.

### Pokročilá zkušenost vývojáře

**Víceuživatelské rozhraní**: Foundry Local nabízí komplexní vývojářské rozhraní včetně výkonného CLI pro správu a nasazení modelů, multi-jazyková SDK (Python, NodeJS) pro nativní integraci a RESTful API kompatibilní s OpenAI pro bezproblémovou migraci.

**Integrace do Visual Studio**: Platforma se hladce integruje s AI Toolkit pro VS Code, poskytující nástroje pro konverzi modelů, kvantizaci a optimalizaci přímo ve vývojovém prostředí. Tato integrace urychluje vývojové procesy a snižuje složitost nasazení.

**Pipeline pro optimalizaci modelů**: Integrace Microsoft Olive umožňuje sofistikované pracovní postupy optimalizace modelů včetně dynamické kvantizace, optimalizace grafů a ladění specifického pro hardware. Cloudové možnosti konverze přes Azure ML poskytují škálovatelnou optimalizaci pro velké modely.

| **Zaměření platformy** | Univerzální víceplatfromní | Optimalizace pro Windows/podnikové prostředí |
| **Integrace hardwaru** | Obecná podpora GPU/CPU | Hluboká podpora Windows ML, NPU |
| **Optimalizace** | Kvantizace llama.cpp | Microsoft Olive + ONNX Runtime |
