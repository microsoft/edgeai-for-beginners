# ਮਾਡਿਊਲ 08: ਮਾਇਕਰੋਸਾਫਟ ਫਾਊਂਡਰੀ ਲੋਕਲ ਨਾਲ ਹੈਂਡਸ-ਆਨ - ਪੂਰਾ ਡਿਵੈਲਪਰ ਟੂਲਕਿਟ

## ਸੰਖੇਪ ਜਾਣਕਾਰੀ

[Microsoft Foundry Local](https://learn.microsoft.com/azure/ai-foundry/foundry-local/) ਐਜ ਏਆਈ ਵਿਕਾਸ ਦੀ ਅਗਲੀ ਪੀੜ੍ਹੀ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ, ਜੋ ਡਿਵੈਲਪਰਾਂ ਨੂੰ ਸ਼ਕਤੀਸ਼ਾਲੀ ਟੂਲਜ਼ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ ਤਾਂ ਜੋ ਉਹ ਲੋਕਲ ਤੌਰ 'ਤੇ ਏਆਈ ਐਪਲੀਕੇਸ਼ਨਾਂ ਦਾ ਨirmaGiven ਨਿਰਮਾਣ, ਤਾਇਨਾਤ ਤੇ ਵਧਾਉ ਕਰ ਸਕਣ, ਅਤੇ ਇਸ ਦੇ ਨਾਲ ਨਾਲ Azure AI Foundry ਨਾਲ ਬਿਨਾਂ ਰੁਕਾਵਟ ਬੰਨ੍ਹਤ ਰਹਿਣ। ਇਹ ਮਾਡਿਊਲ ਫਾਊਂਡਰੀ ਲੋਕਲ ਦੀ ਸਥਾਪਨਾ ਤੋਂ ਲੈ ਕੇ ਅਡਵਾਂਸਡ ਏਜੰਟ ਵਿਕਾਸ ਤੱਕ ਦੀ ਵਿਸਤ੍ਰਿਤ ਕਵਰੇਜ ਦਿੰਦਾ ਹੈ।

**ਮੁੱਖ ਤਕਨੀਕਾਂ:**
- ਮਾਇਕਰੋਸਾਫਟ ਫਾਊਂਡਰੀ ਲੋਕਲ CLI ਅਤੇ SDK
- Azure AI Foundry ਇੰਟੀਗ੍ਰੇਸ਼ਨ
- ਡਿਵਾਈਸ-ਉੱਤੇ ਮਾਡਲ ਇਨਫਰੰਸ
- ਲੋਕਲ ਮਾਡਲ ਕੈਸ਼ਿੰਗ ਅਤੇ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ
- ਏਜੰਟ-ਆਧਾਰਿਤ ਢਾਂਚੇ

## ਸਿੱਖਣ ਦੇ ਲਕੜੇ

ਇਸ ਮਾਡਿਊਲ ਨੂੰ ਪੂਰਾ ਕਰ ਕੇ, ਤੁਸੀਂ:

- **ਫਾਊਂਡਰੀ ਲੋਕਲ ਮਾਹਰ ਬਣੋ**: Windows 11 ਵਿਕਾਸ ਲਈ ਇੰਸਟਾਲ, ਸੰਰਚਿਤ ਅਤੇ ਅਪਟੀਮਾਈਜ਼ ਕਰੋ
- **ਵੱਖ-ਵੱਖ ਮਾਡਲ ਤਾਇਨਾਤ ਕਰੋ**: phi, qwen, deepseek ਅਤੇ GPT ਮਾਡਲ ਲੋਕਲ ਤੌਰ 'ਤੇ CLI ਕਮਾਂਡਾਂ ਨਾਲ ਚਲਾਓ
- **ਉਤਪਾਦਨ ਸਮਾਧਾਨ ਬਣਾਓ**: ਅਡਵਾਂਸਡ ਪ੍ਰਾਂਪਟ ਇੰਜੀਨੀਅਰਿੰਗ ਅਤੇ ਡਾਟਾ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਨਾਲ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਓ
- **ਓਪਨ-ਸੋਰਸ ਇਕੋਸਿਸਟਮ ਨਾਲ ਲਾਭ ਉਠਾਓ**: Hugging Face ਮਾਡਲ ਅਤੇ ਕਮਿュਨਿਟੀ ਯੋਗਦਾਨ ਨੂੰ ਇੰਟੀਗ੍ਰੇਟ ਕਰੋ
- **AI ਏਜੰਟ ਵਿਕਸਿਤ ਕਰੋ**: ਗਰਾਉਂਡਿੰਗ ਅਤੇ ਆਰਕੈਸਟ੍ਰੇਸ਼ਨ ਕਾਬਲੀਅਤਾਂ ਵਾਲੇ ਸਿਆਣੇ ਏਜੰਟ ਬਣਾਓ
- **ਐੰਟਰਪਰਾਈਜ਼ ਪੈਟਰਨ ਲਾਗੂ ਕਰੋ**: ਉਤਪਾਦਨ ਤਾਇਨਾਤ ਲਈ ਮੋਡੀਊਲਰ, ਸਕੇਲ ਕਰਨ ਯੋਗ AI ਸਮਾਧਾਨ ਬਣਾਓ

## ਪੂਰਵ-ਸ਼ਰਤਾਂ

### ਸਿਸਟਮ ਲੋੜੀਂਦਾ
- **ਓਪਰੇਟਿੰਗ ਸਿਸਟਮ**: Windows 11 (22H2 ਜਾਂ ਬਾਅਦ ਵਿੱਚ)
- **ਮੈਮੋਰੀ**: 16GB RAM (ਵੱਡੇ ਮਾਡਲਾਂ ਲਈ 32GB ਸਿਫਾਰਿਸ਼ੀ)

### ਵਿਕਾਸ ਵਾਤਾਵਰਨ

- Python 3.10+ ਅਤੇ pip
- Git ਵਰਜਨ ਕਨਟਰੋਲ ਲਈ
- PowerShell ਜਾਂ Command Prompt
- Azure CLI (ਕਲਾਉਡ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਲਈ ਵਿਕਲਪਿਕ)

### ਗਿਆਨ ਪੂਰਵ-ਸ਼ਰਤਾਂ

- ਪ੍ਰਾਂਪਟਿੰਗ ਅਤੇ ਮਾਡਲ ਇਨਫਰੰਸ ਬਾਰੇ ਮੁੱਢਲਾ ਗਿਆਨ

## ਸਿੱਖਣ ਦੇ ਨਤੀਜੇ

- **ਏਜੰਟ ਵਿਕਸਿਤ ਕਰਨਾ**: ਗਰਾਉਂਡਿੰਗ, ਤਰਕ, ਅਤੇ ਟੂਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਸਮੇਤ ਸੋਫਿਸਟਿਕੇਟੇਡ AI ਏਜੰਟ ਲਾਗੂ ਕਰਨਾ

### ਰਣਨੀਤਿਕ ਸਮਝ
- ** ਢਾਂਚਾਗਤ ਫੈਸਲੇ**: ਲੋਕਲ ਵਿਰੁੱਧ ਕਲਾਉਡ ਤਾਇਨਾਤ ਵਿਚ ਸਮਝਦਾਰ ਚੋਣਾਂ ਕਰਨਾ
- **ਕਾਰਗੁਜ਼ਾਰੀ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ**: ਵੱਖ-ਵੱਖ ਹਾਰਡਵੇਅਰ ਕੰਫਿਗਰੇਸ਼ਨਾਂ ਵਿੱਚ ਇਨਫਰੰਸ ਕਾਰਗੁਜ਼ਾਰੀ ਅਪਟੀਮਾਈਜ਼ ਕਰਨਾ

- **ਗੋਪਨੀਯਤਾ ਅਤੇ ਸੁਰੱਖਿਆ**: ਲੋਕਲ ਇਨਫਰੰਸ ਨਾਲ ਗੋਪਨੀਯਤਾ-ਸੁਰੱਖਿਅਤ AI ਸਮਾਧਾਨ ਲਾਗੂ ਕਰਨਾ

### ਨਵੀਨਤਾ ਸਮਰੱਥਾ
- **ਤੇਜ਼ ਪ੍ਰੋਟੋਟਾਈਪਿੰਗ**: ਸਭ 10 ਨਮੂਨਾ ਪੈਟਰਨਾਂ ਵਿੱਚ ਤੇਜ਼ੀ ਨਾਲ AI ਐਪਲੀਕੇਸ਼ਨ ਸੰਕਲਪ ਬਣਾਉਣ ਅਤੇ ਟੈਸਟ ਕਰਨ

- **ਭਵਿੱਖ-ਤਿਆਰ ਵਿਕਾਸ**: ਉੱਭਰ ਰਹੀਆਂ AI ਤਕਨੀਕਾਂ ਅਤੇ ਪੈਟਰਨਾਂ ਲਈ ਤਿਆਰ ਐਪਲੀਕੇਸ਼ਨ ਬਣਾਉਣਾ
