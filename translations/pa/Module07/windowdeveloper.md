# Windows Edge AI ਵਿਕਾਸ ਗਾਈਡ

## ਪਰੇਚਾ

Windows Edge AI ਵਿਕਾਸ ਵਿੱਚ ਤੁਹਾਡਾ ਸਵਾਗਤ ਹੈ - ਇਹ ਤੁਹਾਡੇ ਲਈ ਇੱਕ ਵਿਸਤ੍ਰਿਤ ਗਾਈਡ ਹੈ ਜੋ ਬੁੱਧੀਮਾਨ ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਬਣਾਉਣ ਲਈ ਹੈ ਜੋ ਮਾਇਕਰੋਸੌਫਟ ਦੇ Windows AI Foundry ਪਲੇਟਫਾਰਮ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਡਿਵਾਈਸ-ਅੰਦਰੂਨੀ AI ਦੀ ਤਾਕਤ ਨੂੰ ਭੁਲੀ ਸੱਕਦਾ ਹੈ। ਇਹ ਗਾਈਡ ਵਿਸ਼ੇਸ਼ ਤੌਰ 'ਤੇ ਉਹਨਾਂ Windows ਵਿਕਾਸਕਾਰਾਂ ਲਈ ਤਿਆਰ ਕੀਤੀ ਗਈ ਹੈ ਜੋ ਆਪਣੇ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ ਨਵੀਂ ਪੀੜੀ ਦੀ Edge AI ਸਮਰਥਾ ਨੂੰ ਸ਼ਾਮਿਲ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹਨ ਅਤੇ Windows ਹਾਰਡਵੇਅਰ ਤੇਜ਼ੀ ਦੀ ਪੂਰੀ ਵਰਤੋਂ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹਨ।

### Windows AI ਦਾ ਫਾਇਦਾ

Windows AI Foundry ਇੱਕ ਇਕੱਤਰ, ਭਰੋਸੇਯੋਗ ਅਤੇ ਸੁਰੱਖਿਅਤ ਪਲੇਟਫਾਰਮ ਹੈ ਜੋ ਪੂਰੇ AI ਵਿਕਾਸਕਾਰ ਲਾਈਫਸਾਈਕਲ ਨੂੰ ਸਹਿਯੋਗ ਦਿੰਦਾ ਹੈ - ਮਾਡਲ ਚੋਣ ਤੋਂ ਲੈ ਕੇ ਬਿਹਤਰੀ ਅਤੇ CPU, GPU, NPU ਅਤੇ ਹਾਈਬ੍ਰਿਡ ਕਲਾਉਡ ਆਰਕੀਟੈਕਚਰਾਂ ਵਿੱਚ ਏਤਬਾਰਿਕ ਕਰਵਾਉਣ ਤੱਕ। ਇਹ ਪਲੇਟਫਾਰਮ AI ਵਿਕਾਸ ਨੂੰ ਲੋਕਸਭਾ ਬਣਾਉਂਦਾ ਹੈ:

- **ਹਾਰਡਵੇਅਰ ਅਬਸਟ੍ਰੈਕਸ਼ਨ**: AMD, Intel, NVIDIA, ਅਤੇ Qualcomm ਸਿਲਿਕਾਨ 'ਤੇ ਬਿਨਾ ਰੁਕਾਵਟ ਡਿਪਲੌਯਮੈਂਟ
- **ਡਿਵਾਈਸ ਵਿੱਚ ਕੰਮ ਕਰਨ ਵਾਲੀ ਬੁੱਧੀ**: ਐਸਾ ਪਰਦੇਦਾਰੀ-ਰੱਖਣ ਵਾਲਾ AI ਜੋ ਪੂਰੀ ਤਰ੍ਹਾਂ ਸਥਾਨਕ ਹਾਰਡਵੇਅਰ 'ਤੇ ਚੱਲਦਾ ਹੈ
- **ਅਧਿਕਤਮ ਕਾਰਗੁਜ਼ਾਰੀ**: Windows ਹਾਰਡਵੇਅਰ ਸੰਰਚਨਾਵਾਂ ਲਈ ਪੂਰਵ-ਅਨੁਕੂਲਿਤ ਮਾਡਲ
- **ਇੰਟਰਪ੍ਰਾਈਜ਼-ਤਿਆਰ**: ਪ੍ਰੋਡਕਸ਼ਨ-ਗਰੇਡ ਸੁਰੱਖਿਆ ਅਤੇ ਅਨੁਕੂਲਤਾ ਫੀਚਰ

### Windows ML
Windows ਮਸ਼ੀਨ ਲਰਨਿੰਗ (ML) C#, C++, ਅਤੇ Python ਵਿਕਾਸਕਾਰਾਂ ਨੂੰ ONNX AI ਮਾਡਲਾਂ ਨੂੰ Windows ਪੀਸੀਆਂ 'ਤੇ ਥਾਂ-ਥਾਂ అమਲ ਕਰਨਾ ਯੋਗ ਬਣਾਉਂਦਾ ਹੈ ONNX Runtime ਰਾਹੀਂ, ਵੱਖ-ਵੱਖ ਹਾਰਡਵੇਅਰ (CPU, GPU, NPU) ਲਈ ਸਵੈਚਾਲਿਤ ਕਾਰਜ੍ਹਕਾਰੀ ਪ੍ਰਦਾਤਾ ਪਰਬੰਧਨ ਦੇ ਨਾਲ। [ONNX Runtime](https://onnxruntime.ai/docs/) ਨੂੰ PyTorch, Tensorflow/Keras, TFLite, scikit-learn, ਅਤੇ ਹੋਰ ਫਰੇਮਵਰਕਾਂ ਤੋਂ ਆਏ ਮਾਡਲਾਂ ਨਾਲ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ।


![WindowsML A diagram illustrating an ONNX model going through Windows ML to then reach NPUs, GPUs, and CPUs.l](https://learn.microsoft.com/en-us/windows/ai/images/winml-diagram.png)

Windows ML ONNX Runtime ਦੀ Windows-ਵਿਆਪੀ ਸਾਂਝੀ ਕਾਪੀ ਦਿੰਦਾ ਹੈ, ਤੋੜ ਤੇ ਕਾਰਜਕਾਰੀ ਪ੍ਰਦਾਤਾ (EPs) ਨੂੰ ਗਤੀ ਨਾਲ ਡਾਊਨਲੋਡ ਕਰਨ ਦੀ ਸਮਰਥਾ ਦੇ ਨਾਲ।

### Edge AI ਲਈ Windows ਕਿਉਂ?

**ਸਾਰਥਕ ਹਾਰਡਵੇਅਰ ਸਹਿਯੋਗ**
Windows ML ਸਾਰੇ Windows ਪਰਿਸ਼ਰ 'ਤੇ ਸਵੈਚਾਲਿਤ ਹਾਰਡਵੇਅਰ ਅਨੁਕੂਲਤਾ ਦਿੰਦਾ ਹੈ, ਇਹ ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ ਕਿ ਤੁਹਾਡੇ AI ਐਪਸ ਸਲੋਚੀਲ ਸਿਲਿਕਾਨ ਆਰਕੀਟੈਕਚਰ ਦੇ ਬਾਵਜੂਦ ਬਹੁਤ ਹੀ ਵਧੀਆ ਤਰ੍ਹਾਂ ਚੱਲਣ।

**ਇੰਟੀਗ੍ਰੇਟਿਡ AI ਰੰਟਾਈਮ**
Windows ML ਇੰਫਰੈਂਸ ਇੰਜਣ ਜੋ ਅੰਦਰੂਨੀ ਹੈ, ਇਸ ਨਾਲ ਬਿਅਰਕ ਹੋਏ ਸੈੱਟਅੱਪ ਦੀ ਜਟਿਲਤਾ ਨੂੰ ਹਟਾ ਦਿੰਦਾ ਹੈ ਅਤੇ ਵਿਕਾਸਕਾਰਾਂ ਨੂੰ ਐਪ ਲੋਕਿਕ 'ਤੇ ਧਿਆਨ ਦੇਣ ਦਿੰਦਾ ਹੈ ਨਾ ਕਿ ਇੰਫ੍ਰਾਸਟਰੱਕਚਰ ਦੇ ਮੁੱਦਿਆਂ 'ਤੇ।

**ਕੋਪਾਇਲਟ+ PC ਅਨੁਕੂਲਤਾ**
ਬਿਸ਼ੇਸ਼ ਤੌਰ 'ਤੇ ਅਗਲੀ ਪੀੜ੍ਹੀ ਦੇ Windows ਡਿਵਾਈਸਾਂ ਲਈ ਤਿਆਰ ਕੀਤੇ API, ਜੋ ਨਿਊਰਲ ਪ੍ਰੋਸੈਸਿੰਗ ਯੂਨਿਟਸ (NPUs) ਨਾਲ ਅਦ਼ਭੁਤ ਵਾਟ ਪ੍ਰਤੀ ਪ੍ਰਦਰਸ਼ਨ ਦਿੰਦੇ ਹਨ।

**ਡਿਵੈਲਪਰ ਪਰਿਵਾਰ**
ਅਮੀਰ ਟੂਲਿੰਗ ਜਿਸ ਵਿੱਚ ਵਿਜ਼ੂਅਲ ਸਟੂਡਿਓ ਇੰਟੀਗ੍ਰੇਸ਼ਨ, ਵਿਆਪਕ ਦਸਤਾਵੇਜ਼ੀਕਰਨ ਅਤੇ ਸਮਰਥਨ ਐਪਲੀਕੇਸ਼ਨਾਂ ਸ਼ਾਮਿਲ ਹਨ ਜੋ ਵਿਕਾਸ ਲਈ ਵੇਗ ਨੂੰ ਬਢ਼ਾਉਂਦੇ ਹਨ।

## ਸਿੱਖਣ ਦੇ ਲੱਕੜੇ

ਇਸ Windows Edge AI ਵਿਕਾਸ ਗਾਈਡ ਨੂੰ ਪੂਰਾ ਕਰਕੇ, ਤੁਸੀਂ Windows ਪਲੇਟਫਾਰਮ 'ਤੇ ਪ੍ਰੋਡਕਸ਼ਨ ਤਿਆਰ ਐਪਸ ਬਣਾਉਣ ਲਈ ਬੁਨਿਆਦੀ ਕੌਸ਼ਲਾਂ ਵਿੱਚ ਮਾਹਿਰ ਹੋਵੋਗੇ।

### ਮੁੱਖ ਤਕਨੀਕੀ ਯੋਗਤਾਂ

**Windows AI Foundry ਵਿੱਚ ਨਿਪੁੰਨਤਾ**
- Windows AI Foundry ਪਲੇਟਫਾਰਮ ਦੀ ਸੰਰਚਨਾ ਅਤੇ ਭਾਗਾਂ ਦੀ ਸਮਝ
- Windows ਪਰਿਬੈਸ਼ ਵਿੱਚ ਪੂਰੇ AI ਵਿਕਾਸਕਾਰ ਲਾਈਫਸਾਈਕਲ ਨੂੰ ਸਮਝਨਾ
- ਡਿਵਾਈਸ-ਅੰਦਰੂਨੀ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਸੁਰੱਖਿਆ ਦੇ ਸਿਰੇ ਭਰ ਕਰਨ ਲਈ ਪ੍ਰਵ੍ਰਿੱਤੀਆਂ ਨੂੰ ਲਾਗੂ ਕਰਨਾ
- ਵੱਖ-ਵੱਖ Windows ਹਾਰਡਵੇਅਰ ਸੰਰਚਨਾਵਾਂ ਲਈ ਐਪਲੀਕੇਸ਼ਨਾਂ ਦਾ ਅਨੁਕੂਲਨ ਕਰਨਾ

**API ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਵਿਸ਼ੇਸ਼ਜ্ঞান**
- ਟੈਕਸ, ਵਿਜ਼ਨ, ਅਤੇ ਮਲਟੀਮੋਡਲ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ Windows AI APIs ਵਿੱਚ ਮਾਹਿਰ ਹੋਣਾ
- Phi Silica ਭਾਸ਼ਾ ਮਾਡਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਨੂੰ ਟੈਕਸਟ ਜਨਰੇਸ਼ਨ ਅਤੇ ਰੀਜ਼ਨਿੰਗ ਲਈ ਲਾਗੂ ਕਰਨਾ
- ਨਿਰਮਿਤ ਚਿੱਤਰ ਪ੍ਰੋਸੈਸਿੰਗ APIs ਨਾਲ ਕਮਪਿਊਟਰ ਵਿਜ਼ਨ ਸਮਰਥਾ ਨੂੰ ਡਿਪਲੌਯ ਕਰਨਾ
- LoRA (ਲੋ-ਰੈਂਕ ਅਡੈਪਟੇਸ਼ਨ) ਤਕਨੀਕਾਂ ਨਾਲ ਪੂਰਵ-ਤਿਆਰ ਮਾਡਲਾਂ ਨੂੰ ਅਨੁਕੂਲਿਤ ਕਰਨਾ

**Foundry Local ਕਾਰਗੁਜ਼ਾਰੀ ਪੁਸ਼ਟੀਕਰਨ**
- Foundry Local CLI ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਖੁੱਲ੍ਹਾ ਸਰੋਤ ਭਾਸ਼ਾ ਮਾਡਲਾਂ ਨੂੰ ਬ੍ਰਾਊਜ਼, ਮੂਲਿਆਂਕਨ, ਅਤੇ ਡਿਪਲੌਯ ਕਰਨਾ
- ਸਥਾਨਕ ਡਿਪਲੌਯਮੈਂਟ ਲਈ ਮਾਡਲ ਅਨੁਕੂਲਨ ਅਤੇ ਕਾਂਟੀਜ਼ੇਸ਼ਨ ਨੂੰ ਸਮਝਣਾ
- ਇੰਟਰਨੈੱਟ ਬਿਨਾਂ ਕੰਮ ਕਰਨ ਵਾਲੀਆਂ ਆਫਲਾਈਨ AI ਸਮਰਥਾਵਾਂ ਲਾਗੂ ਕਰਨਾ
- ਉਤਪਾਦਨ ਮਾਹੌਲਾਂ ਵਿੱਚ ਮਾਡਲ ਲਾਈਫਸਾਈਕਲ ਅਤੇ ਅੱਪਡੇਟਾਂ ਨੂੰ ਪ੍ਰਬੰਧਿਤ ਕਰਨਾ

**Windows ML ਡਿਪਲੌਯਮੈਂਟ**
- Windows ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ ਕਸਟਮ ONNX ਮਾਡਲਾਂ ਲਿਆਉਣਾ Windows ML ਵਰਤ ਕੇ
- CPU, GPU, ਅਤੇ NPU ਆਰਕੀਟੈਕਚਰਾਂ 'ਤੇ ਸਵੈਚਾਲਿਤ ਹਾਰਡਵੇਅਰ ਤੇਜ਼ੀ ਵਰਤਣਾ
- ਵਾਧੂ ਸਰੋਤ ਉਪਯੋਗਤਾ ਨਾਲ ਰੀਅਲ-ਟਾਈਮ ਇੰਫਰੈਂਸ ਕਰਨਾ
- ਵਿਭਿੰਨ Windows ਡਿਵਾਈਸ ਵਰਗਾਂ ਲਈ ਸਕੇਲੇਬਲ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਦੀ ਡਿਜ਼ਾਇਨਿੰਗ

### ਐਪਲੀਕੇਸ਼ਨ ਵਿਕਾਸ ਕੌਸ਼ਲ

**ਕ੍ਰਾਸ-ਪਲੇਟਫਾਰਮ Windows ਵਿਕਾਸ**
- ਵਿਸ਼ਵ ਵਿਆਪੀ Windows ਡਿਪਲੌਯਮੈਂਟ ਲਈ .NET MAUI ਦੀ ਵਰਤੋਂ ਕਰਕੇ AI-ਚਲਤ ਐਪਸ ਬਣਾਵੋ
- Win32, UWP, ਅਤੇ ਪ੍ਰੋਗਰੈਸੀਵ ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ AI ਸਮਰਥਾਵਾਂ ਸ਼ਾਮਿਲ ਕਰੋ
- AI ਪ੍ਰਕਿਰਿਆ ਸਥਿਤੀਆਂ ਲਈ ਅਨੁਕੂਲਤ UI ਡਿਜ਼ਾਇਨਾਂ ਲਾਗੂ ਕਰੋ
- ਬਿਲਕੁਲ ਸਹੀ ਉਪਭੋਗਤਾ ਅਨੁਭਵ ਪੈਟਰਨ ਨਾਲ ਐਸਿੰਕ੍ਰੋਨਸ AI ਕਾਰਜਸੂਚੀ ਸੰਭਾਲੋ

**ਕਾਰਗੁਜ਼ਾਰੀ ਅਨੁਕੂਲਨ**
- ਵੱਖ-ਵੱਖ ਹਾਰਡਵੇਅਰ ਸੰਰਚਨਾਵਾਂ 'ਤੇ AI ਇੰਫਰੈਂਸ ਕਾਰਗੁਜ਼ਾਰੀ ਦਾ ਪ੍ਰੋਫਾਈਲ ਅਤੇ ਅਨੁਕੂਲਨ ਕਰੋ
- ਵੱਡੇ ਭਾਸ਼ਾ ਮਾਡਲ ਲਈ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਮੈਮੋਰੀ ਪ੍ਰਬੰਧਨ ਲਾਗੂ ਕਰੋ
- ਐਸੇ ਐਪਲੀਕੇਸ਼ਨਾਂ ਦੀ ਰਚਨਾ ਕਰੋ ਜੋ ਉਪਲਬਧ ਹਾਰਡਵੇਅਰ ਸਮਰਥਾਵਾਂ ਦੇ ਅਧਾਰ 'ਤੇ ਚੰਗੇ ਤਰ੍ਹਾਂ ਘਟਦੇ ਜਾਣ
- ਅਕਸਰ ਵਰਤੇ ਜਾਂਦੇ AI ਕਾਰਜਾਂ ਲਈ ਕੈਸ਼ਿੰਗ ਰਣਨੀਤੀਆਂ ਲਾਗੂ ਕਰੋ

**ਉਤਪਾਦਨ ਤਿਆਰੀ**
- ਵਿਸਤ੍ਰਿਤ ਤਰ੍ਹਾਂ ਤ੍ਰੁੱਟੀ ਸੰਭਾਲ ਅਤੇ ਫਾਲਬੈਕ ਮਕੈਨੀਜ਼ਮ ਲਾਗੂ ਕਰੋ
- AI ਐਪਲੀਕੇਸ਼ਨ ਦੀ ਕਾਰਗੁਜ਼ਾਰੀ ਲਈ ਟੈਲੀਮੇਟਰੀ ਅਤੇ ਮਾਨੀਟਰਿੰਗ ਡਿਜ਼ਾਇਨ ਕਰੋ
- ਸਥਾਨਕ AI ਮਾਡਲ ਸਟੋਰੇਜ਼ ਅਤੇ ਕਾਰਜਸੂਚੀ ਲਈ ਸੁਰੱਖਿਆ ਦੀਆਂ ਬਿਹਤਰ ਰੀਤੀਆਂ ਲਾਗੂ ਕਰੋ
- ਇੰਟਰਪ੍ਰਾਈਜ਼ ਅਤੇ ਉਪਭੋਗਤਾ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਡਿਪਲੌਯਮੈਂਟ ਰਣਨੀਤੀਆਂ ਬਣਾਓ

### ਵਪਾਰ ਅਤੇ ਰਣਨੀਤਕ ਸਮਝ

**AI ਐਪਲੀਕੇਸ਼ਨ ਆਰਕੀਟੈਕਚਰ**
- ਸਥਾਨਕ ਅਤੇ ਕਲਾਉਡ AI ਪ੍ਰਕਿਰਿਆ ਵਿੱਚ ਕਥਿਤ ਰਣਨੀਤਕ ਆਰਕੀਟੈਕਚਰਾਂ ਨੂੰ ਡਿਜ਼ਾਇਨ ਕਰੋ
- ਮਾਡਲ ਆਕਾਰ, ਸਹੀਤਾ, ਅਤੇ ਇੰਫਰੈਂਸ ਦੀ ਗਤੀ ਦੇ ਵਿਚਕਾਰ ਟਰੇਡ-ਆਫ਼ ਦਾ ਮੁਲਾਂਕਣ ਕਰੋ
- ਡਾਟਾ ਫਲੋ ਆਰਕੀਟੈਕਚਰਾਂ ਦੀ ਯੋਜਨਾ ਬਣਾਓ ਜੋ ਗੋਪਨੀਯਤਾ ਰੱਖਦੇ ਹਨ ਜਦਕਿ ਬੁੱਧੀਰਤਾ ਯੋਗ ਬਣਾਉਂਦੇ ਹਨ
- ਉਪਭੋਗਤਾ ਦੀ ਮੰਗ ਨਾਲ ਅਨੁਕੂਲ ਤੌਰ 'ਤੇ ਵਧਨ ਵਾਲੇ ਖਰਚ ਪ੍ਰਭਾਵਸ਼ਾਲੀ AI ਹੱਲ ਲਾਗੂ ਕਰੋ

**ਬਾਜ਼ਾਰ ਸਥਿਤੀ**
- Windows-ਸਥਾਨਕ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਦੇ ਮੁਕਾਬਲਤਾਤਮਕ ਫਾਏਦੇ ਸਮਝੋ

### ਆਮ ਨਮੂਨਾ ਵਰਕਫਲੋ

ਜ਼ਿਆਦਾਤਰ Windows ML ਨਮੂਨੇ ਇਸ ਮਿਆਰੀ ਪੈਟਰਨ ਦੀ ਪਾਲਣਾ ਕਰਦੇ ਹਨ:

1. **ਵਾਤਾਵਰਣ ਸ਼ੁਰੂਆਤ ਕਰੋ** - ONNX Runtime ਵਾਤਾਵਰਣ ਬਣਾਓ
2. **ਕਾਰਜਕਾਰੀ ਪ੍ਰਦਾਤਾ ਰਜਿਸਟਰ ਕਰੋ** - ਉਪਲਬਧ ਹਾਰਡਵੇਅਰ ਤੇਜ਼ੀ ਵਧਾਉਣ ਵਾਲੇ (CPU, GPU, NPU) ਖੋਜੋ ਅਤੇ ਰਜਿਸਟਰ ਕਰੋ
3. **ਮਾਡਲ ਲੋਡ ਕਰੋ** - ONNX ਮਾਡਲ ਲੋਡ ਕਰੋ, ਜ਼ਰੂਰਤ ਪੈਣ 'ਤੇ ਨਿਸ਼ਾਨਾ ਹਾਰਡਵੇਅਰ ਲਈ ਕੰਪਾਈਲ ਕਰੋ
4. **ਇਨਪੁੱਟ ਦਾ ਪ੍ਰੀ-ਪ੍ਰੋਸੈਸਿੰਗ ਕਰੋ** - ਚਿੱਤਰਾਂ/ਡਾਟਾ ਨੂੰ ਮਾਡਲ ਇਨਪੁੱਟ ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲੋ
5. **ਇੰਫਰੈਂਸ ਚਲਾਓ** - ਮਾਡਲ ਚਲਾਓ ਅਤੇ ਅੰਦਰਾਸ਼ੇ ਪ੍ਰਾਪਤ ਕਰੋ
6. **ਪਰਿਨਾਮ ਪ੍ਰੋਸੈਸ ਕਰੋ** - ਸੋਫਟਮੈਕਸ ਲਗਾਓ ਅਤੇ ਉੱਚ ਦਰਜਾ ਅੰਦਰਾਸ਼ੇ ਦਿਖਾਓ

## Windows AI Foundry ਪਲੇਟਫਾਰਮ ਦੇ ਭਾਗ

### 1. Windows AI APIs

Windows AI APIs ਸਥਾਨਕ ਮਾਡਲਾਂ ਨਾਲ ਤਿਆਰ-ਵਰਤੋਂ ਯੋਗ AI ਸਮਰਥਾਵਾਂ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ, ਜੋ ਕਿ ਕੋਪਾਇਲਟ+ PC ਡਿਵਾਈਸਾਂ 'ਤੇ ਘੱਟ ਤੋਂ ਘੱਟ ਸੈੱਟਅੱਪ ਨਾਲ ਕਰਗੁਜ਼ਾਰੀ ਅਤੇ ਪ੍ਰਭਾਵਸ਼ਾਲੀਤਾ ਲਈ ਅਨੁਕੂਲਿਤ ਹਨ।

#### ਮੁੱਖ API ਵਰਗ

**Phi Silica ਭਾਸ਼ਾ ਮਾਡਲ**
- ਛੋਟਾ ਪਰ ਤਾਕਤਵਰ ਭਾਸ਼ਾ ਮਾਡਲ ਟੈਕਸਟ ਜਨਰੇਸ਼ਨ ਅਤੇ ਤਰਕ ਲਈ
- ਘੱਟ ਤੋਂ ਘੱਟ ਬਿਜਲੀ ਖਪਤ ਨਾਲ ਰੀਅਲ-ਟਾਈਮ ਇੰਫਰੈਂਸ ਲਈ ਅਨੁਕੂਲਿਤ
- LoRA ਤਕਨੀਕਾਂ ਨਾਲ ਕਸਟਮ ਪਰੀ-ਟਿਆਰ ਕਰਨ ਦੀ ਸਮਰਥਾ
- Windows ਸਮਾਂਰਥਕੀ ਖੋਜ ਅਤੇ ਗਿਆਨ ਪ੍ਰਾਪਤੀ ਨਾਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ

**ਕੰਪਿਊਟਰ ਵਿਜ਼ਨ APIs**
- **ਟੈਕਸਟ ਰਿਕਗਨੀਸ਼ਨ (OCR)**: ਚਿੱਤਰਾਂ ਵਿਚੋਂ ਉੱਚ ਸਹੀਤਾ ਨਾਲ ਲਿਖਤ ਖਿੱਚੋ
- **ਚਿੱਤਰ ਸੁਪਰ ਰੇਜ਼ੋਲੂਸ਼ਨ**: ਸਥਾਨਕ AI ਮਾਡਲਾਂ ਨਾਲ ਚਿੱਤਰ ਉੱਪਸਕੇਲ ਕਰੋ
- **ਚਿੱਤਰ ਵਿਭਾਜਨ**: ਚਿੱਤਰਾਂ ਵਿੱਚ ਖਾਸ ਆਬਜੈਕਟਾਂ ਦੀ ਪਛਾਣ ਅਤੇ ਵੱਖ-ਵੱਖ ਕਰਨਾ
- **ਚਿੱਤਰ ਵੇਰਵਾ**: ਦ੍ਰਿਸ਼ਟੀ ਸੰਦਰਭ ਲਈ ਵਿਸਥਾਰ ਨਾਲ ਲਿਖਤ ਵੇਰਵਾ ਬਣਾਓ
- **ਆਬਜੈਕਟ ਮਿਟਾਓ**: ਚਿੱਤਰਾਂ ਵਿੱਚ ਅਣਚਾਹੇ ਆਬਜੈਕਟ ਹਟਾਉਣ ਲਈ AI ਨਾਲ ਪੇਟਿੰਗ

**ਮਲਟੀਮੋਡਲ ਸਮਰਥਾ**
- **ਵਿਜ਼ਨ-ਭਾਸ਼ਾ ਏਕਤਾ**: ਟੈਕਸਟ ਅਤੇ ਚਿੱਤਰ ਸਮਝਦਾਰੀ ਨੂੰ ਜੋੜੋ
- **ਸਮਾਂਰਥਕੀ ਖੋਜ**: ਮਲਟੀਮੀਡੀਆ ਸਮੱਗਰੀ ਵਿੱਚ ਕੁਦਰਤੀ ਭਾਸ਼ਾ ਪੁੱਛ-ਪੜਤਾਲ ਯੋਗ
- **ਗਿਆਨ ਪ੍ਰਾਪਤੀ**: ਸਥਾਨਕ ਡਾਟਾ ਨਾਲ ਬੁੱਧੀਮਾਨ ਖੋਜ ਅਨੁਭਵ ਬਣਾਓ

#### ਵਰਤੋਂ ਕੇਸ ਅਨੁਸਾਰ ਸੈਂਪਲ ਕੈਟੇਗਰੀਜ਼

**RAG (ਰੀਟ੍ਰੀਵਲ-ਆਗਮੈਂਟਡ ਜੈਨਰੇਸ਼ਨ)**
- **dotNET/rag**: Semantic Kernel, Qdrant ਵੈਕਟਰ ਡੇਟਾਬੇਸ, ਅਤੇ JINA ਐਮਬੈਡਿੰਗਜ਼ ਵਰਤ ਕੇ ਪੂਰਾ RAG ਇੰਪਲੀਮੇਨਟੇਸ਼ਨ
- **ਆਰਕੀਟੈਕਚਰ**: ਦਸਤਾਵੇਜ਼ ਇੰਜੈਸ਼ਨ → ਟੈਕਸਟ ਚੰਕਿੰਗ → ਵੈਕਟਰ ਐਮਬੈਡਿੰਗਜ਼ → ਸਮਾਨਤਾ ਖੋਜ → ਪ੍ਰਸੰਗ-ਜਾਣੂ ਜਵਾਬ
- **ਟੈਕਨੋਲੋਜੀਜ਼**: Microsoft.SemanticKernel, Qdrant.Client, BERT ONNX ਐਮਬੈਡਿੰਗਜ਼, ਸਟ੍ਰੀਮੀੰਗ ਚੈਟ ਕੰਪਲੀਸ਼ਨ

**ਡੈਸਕਟਾਪ ਐਪਲੀਕੇਸ਼ਨਜ਼**
- **electron/foundry-chat**: ਪ੍ਰੋਡਕਸ਼ਨ-ਤਿਆਰ ਚੈਟ ਐਪਲੀਕੇਸ਼ਨ ਨਾਲ ਲੋਕਲ/ਕਲਾਉਡ ਮਾਡਲ ਸਵਿੱਚਿੰਗ
- **ਫੀਚਰ**: ਮਾਡਲ ਚੁਣਨ ਵਾਲਾ, ਸਟ੍ਰੀਮੀੰਗ ਜਵਾਬ, ਐਰਰ ਹੈਂਡਲਿੰਗ, ਕ੍ਰਾਸ-ਪਲੇਟਫਾਰਮ ਡਿਪਲਾਇਮੈਂਟ
- **ਆਰਕੀਟੈਕਚਰ**: ਇਲੈਕਟ੍ਰਾਨ ਮੇਨ ਪ੍ਰੋਸੈਸ, IPC ਕਮਿਊਨਿਕੇਸ਼ਨ, ਸੁਰੱਖਿਅਤ ਪ੍ਰੀਲੋਡ ਸਕ੍ਰਿਪਟ

**SDK ਇੱਕੀਕਰਨ ਉਦਾਹਰਣ**
- **ਜਾਵਾਸਕ੍ਰਿਪਟ (Node.js)**: ਬੁਨਿਆਦੀ ਮਾਡਲ ਇੰਟਰਐਕਸ਼ਨ ਅਤੇ ਸਟ੍ਰੀਮੀੰਗ ਜਵਾਬ
- **ਪਾਇਥਨ**: OpenAI-ਅਨુਕੂਲ API ਵਰਤੋਂ ਨਾਲ async ਸਟ੍ਰੀਮੀੰਗ
- **ਰੱਸਟ**: reqwest ਅਤੇ tokio ਨਾਲ ਘੱਟ-ਪੱਧਰੀ ਇੱਕੀਕਰਨ async ਆਪਰੇਸ਼ਨ ਲਈ

#### ਫਾਊਂਡਰੀ ਲੋਕਲ ਸੈਂਪਲ ਲਈ ਜ਼ਰੂਰੀਆਂ

**ਸਿਸਟਮ ਲੋੜਾਂ:**
- Windows 11 ਨਾਲ ਫਾਊਂਡਰੀ ਲੋਕਲ ਇੰਸਟਾਲ ਕੀਤਾ ਹੋਇਆ
- ਜਾਵਾਸਕ੍ਰਿਪਟ/ਇਲੈਕਟ੍ਰਾਨ ਸੈਂਪਲ ਲਈ Node.js v16+ 
- C# ਸੈਂਪਲ ਲਈ .NET 8.0+ 
- ਪਾਇਥਨ ਸੈਂਪਲ ਲਈ Python 3.10+ 
- ਰੱਸਟ ਸੈਂਪਲ ਲਈ Rust 1.70+

```powershell

foundry --version
foundry model list
```

#### ਮੁੱਖ ਫੀਚਰ

**ਮਾਡਲ ਕੈਟਾਲਾਗ**
- ਪਹਿਲਾਂ ਤੋਂੈ ਅਨੁਕੂਲ ਕੀਤੀਆਂ ਗਈਆਂ ਖੁੱਲ੍ਹੀਆਂ ਸਰੋਤ ਮਾਡਲਾਂ ਦਾ ਵਿਸਤ੍ਰਿਤ ਸੰਗ੍ਰਹਿ
- CPUs, GPUs, ਅਤੇ NPUs 'ਤੇ ਤੁਰੰਤ ਡਿਪਲਾਇਮੈਂਟ ਲਈ ਮਾਡਲਾਂ ਦੀ ਬਿਹਤਰ ਬਣਤਰ

**CLI ਇੱਕੀਕਰਨ**
- ਮਾਡਲ ਪ੍ਰਬੰਧਨ ਅਤੇ ਡਿਪਲਾਇਮੈਂਟ ਲਈ ਕਮਾਂਡ-ਲਾਈਨ ਇੰਟਰਫੇਸ
- ਸੁਚਾਲਿਤ ਅਨੁਕੂਲਣ ਅਤੇ ਕੁਆਨਟਾਈਜ਼ੇਸ਼ਨ ਵਰਕਫਲੋਜ਼
- ਪ੍ਰਸਿੱਧ ਵਿਕਾਸ ਵਾਤਾਵਰਨਾਂ ਅਤੇ CI/CD ਪਾਈਪਲਾਈਨਾਂ ਨਾਲ ਇੱਕੀਕਰਨ

**ਸਥਾਨਕ ਡਿਪਲਾਇਮੈਂਟ**
- ਬਿਨਾਂ ਕਲਾਉਡ ਨਿਰਭਰਤਾ ਦੇ ਪੂਰੀ ਤਰ੍ਹਾਂ ਆਫਲਾਈਨ ਕਾਰਗੁਜ਼ਾਰੀ
- ਕਸਟਮ ਮਾਡਲ ਫਾਰਮੈਟ ਅਤੇ ਕੰਫਿਗਰੇਸ਼ਨ ਲਈ ਸਮਰਥਨ
- ਆਟੋਮੈਟਿਕ ਹਾਰਡਵੇਅਰ ਅਨੁਕੂਲਣ ਨਾਲ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਮਾਡਲ ਸੇਵਾ

### ਅਨੁਕੂਲਤਾ ਵਿਚਾਰ

**ਨਿਯਮਾਂ ਦੀ ਪਾਲਣਾ**
- GDPR, HIPAA, ਅਤੇ ਹੋਰ ਨਿਯਮਾਂ ਦੀ ਪਾਲਣਾ ਕਰਦੇ ਹੋਏ ਐਪ्लीਕੇਸ਼ਨਾਂ ਨੂੰ ਡਿਜ਼ਾਈਨ ਕਰੋ
- AI ਫੈਸਲਿਆਂ ਦੇ ਕਾਰਜਾਂ ਲਈ ਆਡਿਟ ਲੌਗਿੰਗ ਲਾਗੂ ਕਰੋ
- AI-ਜਨਰੇਟ ਕੀਤੇ ਨਤੀਜਿਆਂ ਲਈ ਪਾਰਦਰਸ਼ਤਾ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਮੁਹੱਈਆ ਕਰੋ
- AI ਡੇਟਾ ਪ੍ਰਕਿਰਿਆ ਉੱਤੇ ਉਪਭੋਗਤਾ ਕੰਟਰੋਲ ਯੋਗ ਬਣਾਓ

**ਐਂਟਰਪ੍ਰਾਈਜ਼ ਸੁਰੱਖਿਆ**
- Windows ਐਂਟਰਪ੍ਰਾਈਜ਼ ਸੁਰੱਖਿਆ ਨੀਤੀਆਂ ਨਾਲ ਇੱਕੀਕਰਨ ਕਰੋ
- ਐਂਟਰਪ੍ਰਾਈਜ਼ ਪ੍ਰਬੰਧਨ ਸੰਦਾਂ ਰਾਹੀਂ ਪ੍ਰਬੰਧਿਤ ਡਿਪਲਾਇਮੈਂਟ ਲਈ ਸਮਰਥਨ
- AI ਫੀਚਰਾਂ ਲਈ ਭੂਮਿਕਾ-ਆਧਾਰਿਤ ਪਹੁੰਚ ਨਿਯੰਤਰਣ ਲਾਗੂ ਕਰੋ
- AI ਕਾਰਗੁਜ਼ਾਰੀ ਲਈ ਪ੍ਰਸ਼ਾਸਕੀ ਕੰਟਰੋਲ ਪ੍ਰਦਾਨ ਕਰੋ

## ਸਮੱਸਿਆ ਨਿਵਾਰਨ ਅਤੇ ਡਿਬੱਗਿੰਗ

### ਆਮ ਵਿਕਾਸ ਚੁਣੌਤੀਆਂ

**ਬਿਲਡ ਕਨਫਿਗਰੇਸ਼ਨ ਮੁੱਦੇ**
- Windows AI API ਸੈਂਪਲ ਲਈ ARM64 ਪਲੇਟਫਾਰਮ ਕਨਫਿਗਰੇਸ਼ਨ ਯਕੀਨੀ ਬਣਾਓ
- Windows App SDK ਵਰਜਨ ਸੰਗਤਤਾ (1.8.1+ ਲੋੜੀਂਦਾ) ਦੀ ਜਾਂਚ ਕਰੋ
- ਪੈਕੇਜ ਪਛਾਣ ਕੀ ശരੀ ਕਨਫਿਗਰ ਕੀਤੀ ਗਈ ਹੈ (Windows AI APIs ਲਈ ਲਾਜ਼ਮੀ)
- ਬੀਲਡ ਟੂਲਜ਼ ਨੂੰ ਟਾਰਗਟ ਫਰੇਮਵਰਕ ਵਰਜਨ ਦਾ ਸਮਰਥਨ ਹੈ ਇਸ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ

**ਮਾਡਲ ਲੋਡਿੰਗ ਸਮੱਸਿਆਵਾਂ**
- Windows ML ਨਾਲ ONNX ਮਾਡਲ ਅਨੁਕੂਲਤਾ ਦੀ ਜਾਂਚ ਕਰੋ
- ਮਾਡਲ ਫਾਇਲ ਦੀ ਅਖੰਡਤਾ ਅਤੇ ਫਾਰਮੈਟ ਲੋੜਾਂ ਦੀ ਜਾਂਚ ਕਰੋ
- ਖਾਸ ਮਾਡਲਾਂ ਲਈ ਹਾਰਡਵੇਅਰ ਸਮਰੱਥਾ ਲੋੜਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ
- ਮਾਡਲ ਲੋਡ ਕਰਨ ਦੌਰਾਨ ਮੇਮੋਰੀ ਆਲੋਕੇਸ਼ਨ ਸਮੱਸਿਆਵਾਂ ਲਈ ਡਿਬੱਗ ਕਰੋ
- ਹਾਰਡਵੇਅਰ ਤੇਜ਼ੀ ਲਈ ਏਗਜ਼ੈਕਿਊਸ਼ਨ ਪ੍ਰੋਵਾਈਡਰ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਯਕੀਨੀ ਬਣਾਓ

**ਡਿਪਲਾਇਮੈਂਟ ਮੋਡ ਵਿਚਾਰ**
- **ਸਵੈ-ਸਮਰਪਿਤ ਮੋਡ**: ਵੱਡੇ ਡਿਪਲਾਇਮੈਂਟ ਆਕਾਰ ਨਾਲ ਪੂਰੀ ਤਰ੍ਹਾਂ ਸਹਾਇਤਾਸ਼ੀਲ
- **ਫਰੇਮਵਰਕ ਨਿਰਭਰ ਮੋਡ**: ਛੋਟਾ ਫੁੱਟਪ੍ਰਿੰਟ ਪਰ ਸਾਂਝਾ ਰਹਣ ਵਾਲੇ ਰਨਟਾਈਮ ਦੀ ਲੋੜ
- **ਅਨਪੈਕੇਜਡ ਐਪਲੀਕੇਸ਼ਨਜ਼**: Windows AI APIs ਲਈ ਹੁਣ ਸਹਾਇਤ ਨਹੀਂ
- ARM64 ਡਿਪਲਾਇਮੈਂਟ ਲਈ `dotnet run -p:Platform=ARM64 -p:SelfContained=true` ਵਰਤੋਂ

**ਕਾਰਗੁਜ਼ਾਰੀ ਸਮੱਸਿਆਵਾਂ**
- ਵੱਖ-ਵੱਖ ਹਾਰਡਵੇਅਰ ਸੰਰਚਨਾਵਾਂ ਵਿੱਚ ਐਪਲੀਕੇਸ਼ਨ ਕਾਰਗੁਜ਼ਾਰੀ ਦਾ ਪ੍ਰੋਫਾਈਲ ਬਣਾਓ
- AI ਪ੍ਰੋਸੈਸਿੰਗ ਪਾਈਪਲਾਈਨਾਂ ਵਿੱਚ ਬੋਟਲਨੇਕ ਦੀ ਪਛਾਣ ਕਰੋ
- ਡੇਟਾ ਪ੍ਰੀ-ਪ੍ਰੋਸੈਸਿੰਗ ਅਤੇ ਪੋਸਟ-ਪ੍ਰੋਸੈਸਿੰਗ ਕਾਰਜਾਂ ਨੂੰ ਅਨੁਕੂਲਿਤ ਕਰੋ
- ਕਾਰਗੁਜ਼ਾਰੀ ਮਾਨੀਟਰਨਿੰਗ ਅਤੇ ਚੇਤਾਵਨੀ ਪ੍ਰਣਾਲੀਆਂ ਲਾਗੂ ਕਰੋ

**ਇੱਕੀਕਰਨ ਮੁਸ਼ਕਲਾਂ**
- ਸਹੀ ਐਰਰ ਹੈਂਡਲਿੰਗ ਨਾਲ API ਇੱਕੀਕਰਨ ਸਮੱਸਿਆਵਾਂ ਲਈ ਡਿਬੱਗ ਕਰੋ
- ਇਨਪੁੱਟ ਡੇਟਾ ਫਾਰਮੈਟ ਅਤੇ ਪ੍ਰੀ-ਪ੍ਰੋਸੈਸਿੰਗ ਲੋੜਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ
- ਅੰਤਿਮ ਹਾਲਤਾਂ ਅਤੇ ਐਰਰ ਸਥਿਤੀਆਂ ਨੂੰ ਵਿਆਪਕ ਟੈਸਟ ਕਰੋ
- ਉਤਪਾਦਨ ਸਮੱਸਿਆਵਾਂ ਲਈ ਵਿਆਪਕ ਲੌਗਿੰਗ ਲਾਗੂ ਕਰੋ

### ਡਿਬੱਗਿੰਗ ਟੂਲ ਅਤੇ ਤਕਨੀਕਾਂ

**Visual Studio ਇੱਕੀਕਰਨ**
- ਮਾਡਲ ਕਾਰਜਨਵਾਈ ਵਿਸ਼ਲੇਸ਼ਣ ਲਈ AI Toolkit ਡਿਬੱਗਰ ਵਰਤੋਂ
- AI ਕਾਰਜਾਂ ਲਈ ਕਾਰਗੁਜ਼ਾਰੀ ਪ੍ਰੋਫਾਈਲਿੰਗ ਲਾਗੂ ਕਰੋ
- ਢੁਕਵੀਂ ਐਕਸਪਸ਼ਨ ਹੈਂਡਲਿੰਗ ਨਾਲ async AI ਕਾਰਜਾਂ ਨੂੰ ਡਿਬੱਗ ਕਰੋ
- ਅਨੁਕੂਲਣ ਲਈ ਮੇਮੋਰੀ ਪ੍ਰੋਫਾਈਲਿੰਗ ਟੂਲ ਵਰਤੋਂ

**Windows AI Foundry ਟੂਲ**
- ਮਾਡਲ ਟੈਸਟਿੰਗ ਅਤੇ ਤਸਦੀਕ ਲਈ Foundry Local CLI ਲਾਭ ਉਠਾਓ
- ਇੱਕੀਕਰਨ ਜਾਂਚ ਲਈ Windows AI API ਟੈਸਟਿੰਗ ਟੂਲ ਵਰਤੋਂ
- AI ਓਪਰੇਸ਼ਨ ਮਾਨੀਟਰਨਿੰਗ ਲਈ ਕਸਟਮ ਲੌਗਿੰਗ ਲਾਗੂ ਕਰੋ
- AI ਫੰਕਸ਼ਨਲਿਟੀ ਭਰੋਸਾਗੇਯੋਗਤਾ ਲਈ ਆਟੋਮੇਟਿਕ ਟੈਸਟਿੰਗ ਬਣਾਓ

## ਆਪਣੇ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਭਵਿੱਖ-ਪ੍ਰਮਾਣੀਕਰਨ

### ਨਵੀਆਂ ਉਭਰ ਰਹੀਆਂ ਤਕਨੀਕਾਂ

**ਅਗਲੀ ਪੀੜ੍ਹੀ ਹਾਰਡਵੇਅਰ**
- ਭਵਿੱਖ ਦੀਆਂ NPU ਸਮਰੱਥਾਵਾਂ ਲਈ ਐਪਲੀਕੇਸ਼ਨਾਂ ਦਾ ਡਿਜ਼ਾਈਨ ਕਰੋ
- ਵੱਧ ਮਾਡਲ ਆਕਾਰ ਅਤੇ ਜਟਿਲਤਾ ਦੀ ਯੋਜਨਾ ਬਣਾਓ
- ਵਿਕਾਸਸ਼ੀਲ ਹਾਰਡਵੇਅਰ ਲਈ ਅਨੁਕੂਲ ਆਰਕੀਟੈਕਚਰ ਲਾਗੂ ਕਰੋ
- ਭਵਿੱਖ ਦੀ ਸੰਗਤਤਾ ਲਈ ਕਵਾਂਟਮ-ਤਿਆਰ ਅਲਗੋਰਿਦਮਾਂ ਬਾਰੇ ਸੋਚੋ

**ਉੱਚ ਤਕਨੀਕ ਵਾਲੀਆਂ AI ਸਮਰੱਥਾਵਾਂ**
- ਹੋਰ ਡੇਟਾ ਪ੍ਰਕਾਰਾਂ 'ਤੇ ਬਹੁ-ਮੋਡਲ AI ਇੱਕੀਕਰਨ ਲਈ ਤਿਆਰੀ ਕਰੋ
- ਕਈ ਯੰਤਰਾਂ ਵਿਚਕਾਰ ਰੀਅਲ-ਟਾਈਮ ਸਹਿਯੋਗੀ AI ਦੇ ਯੋਜਨਾ ਬਣਾਓ
- ਫੈਡਰੇਟਿਡ ਲਰਨਿੰਗ ਸਮਰੱਥਾਵਾਂ ਲਈ ਡਿਜ਼ਾਈਨ
- ਐਜ-ਕਲਾਉਡ ਹਾਈਬ੍ਰਿਡ ਬੁੱਧਿਮਾਨੀ ਆਰਕੀਟੈਕਚਰਾਂ ਬਾਰੇ ਵਿਚਾਰ ਕਰੋ

### ਲਗਾਤਾਰ ਸਿੱਖਣਾ ਅਤੇ ਅਨੁਕੂਲਣ

**ਮਾਡਲ ਅੱਪਡੇਟਾਂ**
- ਬਿਨਾ ਰੁਕਾਵਟ ਦੇ ਮਾਡਲ ਅੱਪਡੇਟ ਮਕੈਨਿਜ਼ਮ ਲਾਗੂ ਕਰੋ
- ਸੁਧਰੇ ਹੋਏ ਮਾਡਲ ਸਮਰੱਥਾਵਾਂ ਲਈ ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਅਨੁਕੂਲ ਕਰਨ ਲਈ ਡਿਜ਼ਾਈਨ ਕਰੋ
- ਮੌਜੂਦਾ ਮਾਡਲਾਂ ਨਾਲ ਪਿਛੜਤਾਪੂਰਕ ਸੰਗਤਤਾ ਲਈ ਯੋਜਨਾ ਬਣਾਓ
- ਮਾਡਲ ਕਾਰਗੁਜ਼ਾਰੀ ਮੁਲਾਂਕਣ ਲਈ A/B ਟੈਸਟਿੰਗ ਲਾਗੂ ਕਰੋ

**ਫੀਚਰ ਵਿਕਾਸ**
- ਉਹ ਮਾਡਲਰ ਆਰਕੀਟੈਕਚਰ ਡਿਜ਼ਾਈਨ ਕਰੋ ਜੋ ਨਵੀਆਂ AI ਸਮਰੱਥਾਵਾਂ ਨੂੰ ਸਥਾਨ ਦੇ ਸਕਣ
- ਨਵੀਆਂ ਵਿਂਡੋਜ਼ AI APIs ਦੇ ਇੱਕੀਕਰਨ ਲਈ ਯੋਜਨਾ ਬਣਾਓ
- ਤਰੱਕੀਵਾਰ ਸਮਰੱਥਾ ਰੋਲਆਊਟ ਲਈ ਫੀਚਰ ਫਲੈਗਜ਼ ਲਾਗੂ ਕਰੋ
- ਸੁਧਰੇ ਹੋਏ AI ਫੀਚਰਾਂ ਲਈ ਉਪਭੋਗਤਾ ਇੰਟਰਫੇਸ ਡਿਜ਼ਾਈਨ ਕਰੋ

## ਨਤੀਜਾ

Windows Edge AI ਵਿਕਾਸ ਸਮਰੱਥ AI ਖੂਬੀਆਂ ਨੂੰ ਭਰੋਸੇਮੰਦ, ਸੁਰੱਖਿਅਤ, ਅਤੇ ਸਕੇਲਯੋਗ Windows ਪਲੇਟਫਾਰਮ ਨਾਲ ਜੋੜਦਾ ਹੈ। Windows AI Foundry ਪਰਿਵਾਰ ਨੂੰ ਸਰਗਰਮੀ ਨਾਲ ਵਰਤ ਕੇ, ਵਿਕਾਸਕਾਰ ਬੁੱਧਿਮਾਨ ਐਪਲੀਕੇਸ਼ਨ ਬਣਾ ਸਕਦੇ ਹਨ ਜੋ ਉਤਕ੍ਰਿਸ਼ਟ ਉਪਭੋਗਤਾ ਅਨੁਭਵ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ ਅਤੇ ਗੋਪਨੀਯਤਾ, ਸੁਰੱਖਿਆ ਅਤੇ ਕਾਰਗੁਜ਼ਾਰੀ ਦੇ ਸਭ ਤੋਂ ਉੱਚੇ ਮਿਆਰਾਂ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਦੇ ਹਨ।

Windows AI APIs, Foundry Local, ਅਤੇ Windows ML ਦਾ ਸੰਗਮ ਬੁੱਧਿਮਾਨ Windows ਐਪਲੀਕੇਸ਼ਨਾਂ ਦੀ ਅਗਲੀ ਪੀੜ੍ਹੀ ਰਚਨ ਲਈ ਬੇਮਿਸਾਲ ਬੁਨਿਆਦ ਮੁਹੱਈਆ ਕਰਦਾ ਹੈ। ਜਿਵੇਂ-ਜਿਵੇਂ AI ਵਿਕਸਿਤ ਹੁੰਦਾ ਰਹੇਗਾ, Windows ਪਲੇਟਫਾਰਮ ਇਹ ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ ਕਿ ਤੁਹਾਡੇ ਐਪਲੀਕੇਸ਼ਨ ਉਭਰਦੀਆਂ ਤਕਨੀਕਾਂ ਨਾਲ ਵਰਧਿਤ ਅਤੇ ਵਿਭਿੰਨ Windows ਹਾਰਡਵੇਅਰ ਪਰਿਸ਼ਰਾਂ ਨਾਲ ਪੂਰੀ ਤਰ੍ਹਾਂ ਸੰਗਤ ਰਹਿਣਗੇ।

ਚਾਹੇ ਤੁਸੀਂ ਉਪਭੋਗਤਾ ਐਪਲੀਕੇਸ਼ਨਾਂ, ਐਂਟਰਪ੍ਰਾਈਜ਼ ਹੱਲਾਂ ਜਾਂ ਵਿਸ਼ੇਸ਼ ਉਦਯੋਗ ਟੂਲਾਂ ਦਾ ਵਿਕਾਸ ਕਰ ਰਹੇ ਹੋ, Windows Edge AI ਵਿਕਾਸ ਤੁਹਾਨੂੰ ਅਜਿਹਾ ਬੁੱਧਿਮਾਨ, ਪ੍ਰਤੀਕਿਰਿਆਸ਼ੀਲ ਅਤੇ ਗਹਿਰੀ ਤਰ੍ਹਾਂ ਇੱਕੀਕ੍ਰਿਤ ਅਨੁਭਵ ਬਣਾਉਣ ਦੀ ਸਮਰਥਾ ਦਿੰਦਾ ਹੈ ਜੋ ਆਧੁਨਿਕ Windows ਯੰਤਰਾਂ ਦੀ ਪੂਰੀ ਸਮਰੱਥਾ ਦਾ ਫਾਇਦਾ ਉਠਾਉਂਦਾ ਹੈ।
