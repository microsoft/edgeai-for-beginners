# ਭਾਗ 03 - ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ (MCP) ਇੰਟਿਗ੍ਰੇਸ਼ਨ

## MCP (ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ) ਦਾ ਪਰਚਯ

ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ (MCP) ਇੱਕ ਖੁਲਾ ਸਰੋਤ ਮਿਆਰ ਹੈ ਜੋ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਬਾਹਰੀ ਪ੍ਰਣਾਲੀਆਂ ਨਾਲ ਜੁੜਨ ਲਈ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ। MCP ਦੀ ਵਰਤੋਂ ਨਾਲ, Claude ਜਾਂ ChatGPT ਵਰਗੀਆਂ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਡੇਟਾ ਸਰੋਤਾਂ (ਜਿਵੇਂ ਕਿ ਸਥਾਨਕ ਫਾਇਲਾਂ, ਡੇਟਾਬੇਸ), ਸੰਦਾਂ (ਜਿਵੇਂ ਕਿ ਖੋਜ ਇੰਜਣ, ਕੈਲਕੂਲੇਟਰ), ਅਤੇ ਵਰਕਫਲੋਜ਼ (ਜਿਵੇਂ ਵਿਸ਼ੇਸ਼ ਪ੍ਰਾਂਪਟਾਂ) ਨਾਲ ਜੁੜ ਸਕਦੀਆਂ ਹਨ — ਜਿਹੜੀਆਂ ਅਹੰਕਾਰਪੂਰਕ ਜਾਣਕਾਰੀ ਪ੍ਰਦਾਨ ਕਰਦੀਆਂ ਹਨ ਅਤੇ ਟਾਸਕ ਕਰ ਸਕਦੀਆਂ ਹਨ।

ਟਿਸਤ MCP ਨੂੰ ਇੱਕ **AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ USB-C ਪੋਰਟ** ਵਜੋਂ ਸੋਚੋ। ਜਿਵੇਂ USB-C ਇਲੈਕਟ੍ਰਾਨਿਕ ਉਪਕਰਣਾਂ ਨੂੰ ਜੁੜਨ ਲਈ ਇੱਕ ਮਿਆਰੀ ਰਾਹ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ, ਓਸੇ ਤਰ੍ਹਾਂ MCP AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਬਾਹਰੀ ਪ੍ਰਣਾਲੀਆਂ ਨਾਲ ਜੁੜਨ ਲਈ ਇੱਕ ਮਿਆਰੀ ਰਾਹ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।

### MCP ਕੀ ਕੁਝ ਸਮਰੱਥਾ ਪ੍ਰਦਾਨ ਕਰ ਸਕਦਾ ਹੈ?

MCP AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਸ਼ਕਤੀਸ਼ਾਲੀ ਸਮਰੱਥਾਵਾਂ ਖੋਲ੍ਹਦਾ ਹੈ:

- **ਨਿੱਜੀਕ੍ਰਿਤ AI ਮਦਦਗਾਰ**: ਏਜੰਟ ਤੁਹਾਡੇ Google ਕੈਲੇਂਡਰ ਅਤੇ Notion ਤੱਕ ਪਹੁੰਚ ਸਕਦੇ ਹਨ, ਜਿਸ ਨਾਲ ਇਹ ਇੱਕ ਵੱਧ ਨਿੱਜੀਕ੍ਰਿਤ AI ਮਦਦਗਾਰ ਵਜੋਂ ਕੰਮ ਕਰ ਸਕਦਾ ਹੈ
- **ਉੱਚਤਮ ਕੋਡ ਜਨਰੇਸ਼ਨ**: Claude Code ਇੱਕ ਪੂਰੀ ਵੈੱਬ ਐਪ Figma ਡਿਜ਼ਾਇਨ ਦੀ ਵਰਤੋਂ ਨਾਲ ਬਣਾ ਸਕਦਾ ਹੈ
- **ਐਂਟਰਪ੍ਰਾਈਜ਼ ਡੇਟਾ ਇੰਟਿਗ੍ਰੇਸ਼ਨ**: ਐਂਟਰਪ੍ਰਾਈਜ਼ ਚੈਟਬੋਟਾਂ ਸੰਗਠਨ ਭਰ ਵਿੱਚ ਕਈ ਡੇਟਾਬੇਸਾਂ ਨਾਲ ਜੁੜ ਸਕਦੀਆਂ ਹਨ, ਉਪਭੋਗਤਾਵਾਂ ਨੂੰ ਚੈਟ ਰਾਹੀਂ ਡੇਟਾ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਨ ਲਈ ਸਮਰੱਥ
- **ਕ੍ਰੀਏਟਿਵ ਵਰਕਫਲੋਜ਼**: AI ਮਾਡਲ Blender ਤੇ 3D ਡਿਜ਼ਾਈਨ ਤਿਆਰ ਕਰ ਸਕਦੇ ਹਨ ਅਤੇ ਉਹਨਾਂ ਨੂੰ 3D ਪ੍ਰਿੰਟਰ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਪ੍ਰਿੰਟ ਕਰ ਸਕਦੇ ਹਨ
- **ਰੀਅਲ-ਟਾਈਮ ਜਾਣਕਾਰੀ ਪਹੁੰਚ**: ਤਾਜ਼ਾ ਜਾਣਕਾਰੀ ਲਈ ਬਾਹਰੀ ਡੇਟਾ ਸਰੋਤਾਂ ਨਾਲ ਜੁੜੋ
- **ਜਟਿਲ ਕਈ ਕਦਮ ਵਾਲੇ ਓਪਰੇਸ਼ਨ**: ਕਈ ਸੰਦਾਂ ਅਤੇ ਪ੍ਰਣਾਲੀਆਂ ਨੂੰ ਮਿਲਾ ਕੇ ਸੁਝਬੂਝ ਵਾਲੇ ਵਰਕਫਲੋਜ਼ ਕਿਰਿਆਨਵਿਤ ਕਰੋ

### MCP ਕਿਉਂ ਮਹੱਤਵਪੂਰਨ ਹੈ?

MCP ਪੂਰੇ ਪਰਿਸਰ ਵਿੱਚ ਲਾਭ ਦੇਂਦਾ ਹੈ:

**ਡਿਵੈਲਪਰਾਂ ਲਈ**: MCP ਵਿਕਾਸ ਸਮਾਂ ਅਤੇ ਜਟਿਲਤਾ ਨੂੰ ਘਟਾਉਂਦਾ ਹੈ, ਜਦੋਂ ਕਿਸੇ AI ਐਪਲੀਕੇਸ਼ਨ ਜਾਂ ਏਜੰਟ ਦੇ ਨਾਲ ਬਣਾਉਣ ਜਾਂ ਇੰਟਿਗ੍ਰੇਟ ਕਰਨ ਦੀ ਗੱਲ ਆਉਂਦੀ ਹੈ।

**AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ**: MCP ਡੇਟਾ ਸਰੋਤਾਂ, ਸੰਦਾਂ ਅਤੇ ਐਪਲੀਕੇਸ਼ਨਾਂ ਦਾ ਇਕ ਇਕੋਸਿਸਟਮ ਮੁਹੱਈਆ ਕਰਵਾਉਂਦਾ ਹੈ, ਜੋ ਸਮਰੱਥਾਵਾਂ ਨੂੰ ਵਧਾਉਂਦਾ ਅਤੇ ਫਾਈਨਲ ਉਪਭੋਗਤਾ ਅਨੁਭਵ ਨੂੰ ਸੁਧਾਰਦਾ ਹੈ।

**ਅੰਤ-ਉਪਭੋਗਤਾਵਾਂ ਲਈ**: MCP ਵਧੇਰੇ ਸਮਰੱਥ AI ਐਪਲੀਕੇਸ਼ਨ ਜਾਂ ਏਜੰਟ ਨਤੀਜੇ生 ਹੁੰਦੇ ਹਨ ਜੋ ਤੁਹਾਡੇ ਡੇਟਾ ਤੱਕ ਪਹੁੰਚ ਕਰ ਸਕਦੇ ਹਨ ਅਤੇ ਜ਼ਰੂਰਤ ਪੈਣ ‘ਤੇ ਤੁਹਾਡੇ ਵੱਲੋਂ ਕਾਰਵਾਈ ਕਰ ਸਕਦੇ ਹਨ।

## ਛੋਟੇ ਭਾਸ਼ਾ ਮਾਡਲ (SLMs) MCP ਵਿੱਚ

ਛੋਟੇ ਭਾਸ਼ਾ ਮਾਡਲ AI ਵਿਤਰਨ ਲਈ ਇੱਕ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਤਰੀਕਾ ਪ੍ਰਸਤੁਤ ਕਰਦੇ ਹਨ, ਜੋ ਕਈ ਫਾਇਦੇ ਦਿੰਦੇ ਹਨ:

### SLMs ਦੇ ਫਾਇਦੇ
- **ਸੰਸਾਧਨ ਕੁਸ਼ਲਤਾ**: ਘੱਟ ਗਣਨਾਤਮਕ ਲੋੜਾਂ
- **ਜ਼ਿਆਦਾ ਤੇਜ਼ ਜਵਾਬ ਸਮਾਂ**: ਰੀਅਲ-ਟਾਈਮ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਘਟਿਆ ਲਾਗ
- **ਲਾਗਤ ਕੁਸ਼ਲਤਾ**: ਘੱਟ ਇੰਫਰਾਸਟਰੱਕਚਰ ਦੀ ਲੋੜ
- **ਪਰਦੇਦਾਰੀ**: ਡੇਟਾ ਸੰਗ੍ਰਹਿ ਕੀਤੇ ਬਿਨਾਂ ਸਥਾਨਕ ਤੌਰ ‘ਤੇ ਚੱਲ ਸਕਦੇ ਹਨ
- **ਕਸਟਮਾਈਜ਼ੇਸ਼ਨ**: ਖ਼ਾਸ ਡੋਮੇਨਾਂ ਲਈ ਸੌਖਾ ਫਾਈਨ-ਟਿਊਨ ਕਰਨਾ

### SLMs MCP ਨਾਲ ਕਿਉਂ ਚੰਗੇ ਹਨ

SLMs MCP ਨਾਲ ਮਿਲ ਕੇ ਇੱਕ ਸ਼ਕਤੀਸ਼ਾਲੀ ਸੰਯੋਜਨ ਬਣਾਉਂਦੇ ਹਨ ਜਿਥੇ ਮਾਡਲ ਦੀ ਸੋਚਣ ਦੀ ਸਮਰੱਥਾ ਬਾਹਰੀ ਸੰਦਾਂ ਨਾਲ ਵਧਾਈ ਜਾਂਦੀ ਹੈ, ਆਪਣਾ ਛੋਟਾ ਪੈਰਾਮੀਟਰ ਗਿਣਤੀ ਵਧੀਆ ਕਾਰਗੁਜ਼ਾਰੀ ਨਾਲ ਪੂਰੀ ਕਰਦੀ ਹੈ।

## Python MCP SDK ਜਾਇਜ਼ਾ

Python MCP SDK MCP-ਸਮਰਥਿਤ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਉਣ ਲਈ ਬੁਨਿਆਦ ਮੁਹੱਈਆ ਕਰਵਾਉਂਦਾ ਹੈ। SDK ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:

- **ਕਲਾਇੰਟ ਲਾਇਬ੍ਰੇਰੀਜ਼**: MCP ਸਰਵਰਾਂ ਨਾਲ ਜੁੜਨ ਲਈ
- **ਸਰਵਰ ਫਰੇਮਵਰਕ**: ਮਿਆਰੀ MCP ਸਰਵਰ ਬਣਾਉਣ ਲਈ
- **ਪ੍ਰੋਟੋਕੋਲ ਹੈਂਡਲਰ**: ਸੰਚਾਰ ਦਾ ਪ੍ਰਬੰਧਨ ਕਰਨ ਲਈ
- **ਟੂਲ ਇੰਟਿਗ੍ਰੇਸ਼ਨ**: ਬਾਹਰੀ ਫੰਕਸ਼ਨਾਂ ਨੂੰ ਚਲਾਉਣ ਲਈ

## ਪ੍ਰਯੋਗਿਕ ਨਿਰਵੇਸ਼: Phi-4 MCP ਕਲਾਇੰਟ

ਚਲੋ Microsoft ਦੇ Phi-4 ਮਿੰਨੀ ਮਾਡਲ ਦੀ MCP ਸਮਰੱਥਾਵਾਂ ਨਾਲ ਇਕ ਨਿੱਜੀ ਨਿਰਵੇਸ਼ ਨੂੰ ਵੇਖਦੇ ਹਾਂ।

### MCP ਆਰਕੀਟੈਕਚਰ ਜਾਇਜ਼ਾ

MCP ਇੱਕ **ਕਲਾਇੰਟ-ਸਰਵਰ ਆਰਕੀਟੈਕਚਰ** ਨੂੰ ਫਾਲੋ ਕਰਦਾ ਹੈ ਜਿੱਥੇ MCP ਹੋਸਟ (ਜਿਵੇਂ Claude Code ਜਾਂ Claude ਡੈਸਕਟਾਪ ਵਰਗਾ AI ਐਪਲੀਕੇਸ਼ਨ) ਇੱਕ ਜਾਂ ਵਧੇਰੇ MCP ਸਰਵਰਾਂ ਨਾਲ ਕਨੈਕਸ਼ਨ ਸਥਾਪਤ ਕਰਦਾ ਹੈ। MCP ਹੋਸਟ ਹਰੇਕ MCP ਸਰਵਰ ਲਈ ਇੱਕ MCP ਕਲਾਇੰਟ ਬਣਾਉਂਦਾ ਹੈ।

#### ਮੁੱਖ ਭਾਗੀਦਾਰ

- **MCP ਹੋਸਟ**: AI ਐਪਲੀਕੇਸ਼ਨ ਜੋ ਇੱਕ ਜਾਂ ਕਈ MCP ਕਲਾਇੰਟਾਂ ਦਾ ਏਕਤ੍ਰਿਤ ਕਮਾਂਡ ਅਤੇ ਪਰਬੰਧ ਕਰਦਾ ਹੈ
- **MCP ਕਲਾਇੰਟ**: ਇੱਕ ਹਿੱਸਾ ਜੋ MCP ਸਰਵਰ ਨਾਲ ਸਬੰਧ ਬਣਾਕੇ ਰੱਖਦਾ ਹੈ ਅਤੇ MCP ਹੋਸਟ ਲਈ ਸੰਦਰਭ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ
- **MCP ਸਰਵਰ**: ਇੱਕ ਪ੍ਰੋਗਰਾਮ ਜੋ MCP ਕਲਾਇੰਟਾਂ ਨੂੰ ਸੰਦਰਭ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ

#### ਦੋ-ਸਤਰੀ ਆਰਕੀਟੈਕਚਰ

MCP ਵਿੱਚ ਦੋ ਵੱਖਰੇ ਸਤਰ ਹਨ:

**ਡੇਟਾ ਸਤਰ**: JSON-RPC ਅਧਾਰਿਤ ਪ੍ਰੋਟੋਕੋਲ ਨੂੰ ਪਰਿਭਾਸ਼ਿਤ ਕਰਦਾ ਹੈ ਜੋ ਕਲਾਇੰਟ-ਸਰਵਰ ਸੰਚਾਰ ਲਈ ਹੈ, ਜਿਸ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:
- ਲਾਇਫਸਾਈਕਲ ਪ੍ਰਬੰਧਨ (ਕਨੈਕਸ਼ਨ ਸ਼ੁਰੂਆਤ, ਸਮਰੱਥਾ ਮੱਦੇਨਜ਼ਰ)
- ਮੁੱਖ ਪ੍ਰਚੀਨ (ਸੰਦ, ਸਰੋਤ, ਪ੍ਰਾਂਪਟ)
- ਕਲਾਇੰਟ ਫੀਚਰ (ਨਮੂਨਾ ਲੈਣਾ, ਪ੍ਰੇਰਣਾ, ਲੌਗਿੰਗ)
- ਯੂਟਿਲਿਟੀ ਫੀਚਰ (ਸੂਚਨਾਵਾਂ, ਪ੍ਰਗਤੀ ਟ੍ਰੈਕਿੰਗ)

**ਟ੍ਰਾਂਸਪੋਰਟ ਸਤਰ**: ਸੰਚਾਰ ਮਕੈਨੀਜ਼ਮ ਅਤੇ ਚੈਨਲ ਪਰਿਭਾਸ਼ਿਤ ਕਰਦਾ ਹੈ:
- **STDIO ਟ੍ਰਾਂਸਪੋਰਟ**: ਸਥਾਨਕ ਪ੍ਰਕਿਰਿਆ ਲਈ ਇਨਪੁੱਟ/ਆਊਟਪੁੱਟ ਸਟ੍ਰੀਮਾਂ ਦੀ ਵਰਤੋਂ (ਉਤਕ੍ਰਿਸ਼ਟ ਕਾਰਗੁਜ਼ਾਰੀ, ਕੋਈ ਨੈੱਟਵਰਕ ਓਹਦਾ ਨਹੀਂ)
- **ਸਟ੍ਰੀਮਬਲ HTTP ਟ੍ਰਾਂਸਪੋਰਟ**: ਦੂਰੀ ਸਰਵਰਾਂ ਲਈ HTTP POST ਨਾਲ ਅਤੇ ਵਿਕਲਪਿਕ ਸਰਵਰ-ਸੈਂਟ ਇਵੈਂਟਸ (SSE) ਦੇ ਨਾਲ (ਸਰਵ ਮਿਆਰੀ HTTP ਪ੍ਰਮਾਣਿਕਤਾ ਸਹਾਇਤ)

### MCP ਕੋਰ ਪ੍ਰimitives

MCP ਉਹ ਪ੍ਰimitives ਪਰਿਭਾਸ਼ਿਤ ਕਰਦਾ ਹੈ ਜੋ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਨਾਲ ਸਾਂਝਾ ਕੀਤੀ ਜਾ ਸਕਣ ਵਾਲੀ ਪ੍ਰਸੰਗਕ ਜਾਣਕਾਰੀ ਨੂੰ ਦਰਸਾਉਂਦੇ ਹਨ ਅਤੇ ਕੀ ਕੀ ਕਾਰਵਾਈਆਂ ਕੀਤੀਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ।

#### ਸਰਵਰ ਪ੍ਰimitives

MCP ਤਿੰਨ ਮੁੱਖ ਪ੍ਰimitives ਪਰਿਭਾਸ਼ਿਤ ਕਰਦਾ ਹੈ ਜੋ ਸਰਵਰਾਂ ਦੁਆਰਾ ਪ੍ਰਦਾਨ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ:

**ਸੰਦ**: ਕਮਾਂਡਾਂ ਜੋ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਕਰਵਾਉਂਦੀਆਂ ਹਨ ਤਾ ਕਿ ਕਾਰਵਾਈ ਕੀਤੀ ਜਾ ਸਕੇ
- ਉਦਾਹਰਣ: ਫਾਇਲ ਆਪਰੇਸ਼ਨ, API ਕਾਲਾਂ, ਡੇਟਾਬੇਸ ਪੁੱਛ
- ਮੈਥਡਜ਼: `tools/list`, `tools/call`
- ਗਤੀਸ਼ੀਲ ਖੋਜ ਅਤੇ ਅਮਲ ਦਾ ਸਮਰਥਨ

**ਸਰੋਤ**: ਡੇਟਾ ਸਰੋਤ ਜੋ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਸੰਦਰਭ ਜਾਣਕਾਰੀ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ
- ਉਦਾਹਰਣ: ਫਾਇਲ ਸਮਗਰੀ, ਡੇਟਾਬੇਸ ਰਿਕਾਰਡ, API ਜਵਾਬ
- ਮੈਥਡਜ਼: `resources/list`, `resources/read`
- ਸੰਰਚਿਤ ਡੇਟਾ ਤੱਕ ਪਹੁੰਚ ਨੂੰ ਯੋਗ ਬਣਾਉਂਦੇ ਹਨ

**ਪ੍ਰਾਂਪਟ**: ਮੁੜ ਵਰਤੋਂਯੋਗ ਟੈਂਪਲੇਟ ਜੋ ਭਾਸ਼ਾ ਮਾਡਲਾਂ ਨਾਲ ਇੰਟਰੈਕਸ਼ਨ ਦੀ ਰਚਨਾ ਵਿੱਚ ਮਦਦਗਾਰ ਹੁੰਦੇ ਹਨ
- ਉਦਾਹਰਣ: ਸਿਸਟਮ ਪ੍ਰਾਂਪਟ, ਕੁਝ-ਸ਼ਾਟ ਉਦਾਹਰਣ
- ਮੈਥਡਜ਼: `prompts/list`, `prompts/get`
- AI ਇੰਟਰੈਕਸ਼ਨ ਪੈਟਰਨ ਨੂੰ ਮਿਆਰੀਕ੍ਰਿਤ ਕਰਦੇ ਹਨ

#### ਕਲਾਇੰਟ ਪ੍ਰimitives

MCP ਉਹ ਪ੍ਰimitives ਵੀ ਪਰਿਭਾਸ਼ਿਤ ਕਰਦਾ ਹੈ ਜੋ ਕਲਾਇੰਟ ਵੱਲੋਂ ਪ੍ਰਦਾਨ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ ਤਾ ਜੋ ਸਮਰਥ ਇੰਟਰੈਕਸ਼ਨ ਹੋ ਸਕੇ:

**ਸੈਂਪਲਿੰਗ**: ਸਰਵਰਾਂ ਨੂੰ ਪਰਮਿੱਟ ਕਰਦਾ ਹੈ ਕਿ ਕਲਾਇੰਟ ਦੇ AI ਐਪਲੀਕੇਸ਼ਨ ਤੋਂ ਭਾਸ਼ਾ ਮਾਡਲ ਦੀਆਂ ਪੂਰੀਆਂ ਮੰਗ ਸਕਣ
- ਮੈਥਡ: `sampling/complete`
- ਮਾਡਲ-ਸਵਤੰਤਰ ਸਰਵਰ ਵਿਕਾਸ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ
- ਹੋਸਟ ਦੇ ਭਾਸ਼ਾ ਮਾਡਲ ਤੱਕ ਪਹੁੰਚ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ

**ਇਲਿਸੀਟੇਸ਼ਨ**: ਸਰਵਰਾਂ ਨੂੰ ਉਪਭੋਗਤਾਵਾਂ ਤੋਂ ਵਾਧੂ ਜਾਣਕਾਰੀ ਮੰਗਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ
- ਮੈਥਡ: `elicitation/request`
- ਉਪਭੋਗਤਾ ਇੰਟਰੈਕਸ਼ਨ ਅਤੇ ਪੁਸ਼ਟੀਕਾਰਣ ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ
- ਗਤੀਸ਼ੀਲ ਜਾਣਕਾਰੀ ਇਕੱਠਾ ਕਰਨ ਦਾ ਸਹਾਰਾ ਦਿੰਦਾ ਹੈ

**ਲੌਗਿੰਗ**: ਸਰਵਰਾਂ ਨੂੰ ਕਲਾਇੰਟਾਂ ਨੂੰ ਲੌਗ ਸੁਨੇਹੇ ਭੇਜਣ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ
- ਡਿਬੱਗਿੰਗ ਅਤੇ ਨਿਗਰਾਨੀ ਲਈ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ
- ਸਰਵਰ ਪਰਿਚਾਲਨਾਂ ਦੀ ਦ੍ਰਿਸ਼ਟੀ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ

### MCP ਪ੍ਰੋਟੋਕੋਲ ਲਾਇਫਸਾਈਕਲ

#### ਸ਼ੁਰੂਆਤ ਅਤੇ ਸਮਰੱਥਾ ਮੱਦੇਨਜ਼ਰ

MCP ਇੱਕ ਸਥਿਤੀ-ਰੱਖਣ ਵਾਲਾ ਪ੍ਰੋਟੋਕੋਲ ਹੈ ਜਿਸਦੇ ਲਈ ਲਾਇਫਸਾਈਕਲ ਪ੍ਰਬੰਧਨ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ। ਸ਼ੁਰੂਆਤੀ ਪ੍ਰਕਿਰਿਆ ਕਈ ਜ਼ਰੂਰੀ ਸਮਰਥਾ ਪੂਰੀ ਕਰਦੀ ਹੈ:

1. **ਪ੍ਰੋਟੋਕੋਲ ਵਰਜਨ ਮੱਦੇਨਜ਼ਰ**: ਇਹ ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ ਕਿ ਦੋਹਾਂ ਕਲਾਇੰਟ ਅਤੇ ਸਰਵਰ ਸਮਰਥ ਯੋਗ ਪ੍ਰੋਟੋਕੋਲ ਵਰਜਨਾਂ ਦੀ ਵਰਤੋਂ ਕਰ ਰਹੇ ਹਨ (ਜਿਵੇਂ, "2025-06-18")
2. **ਸਮਰੱਥਾ ਖੋਜ**: ਹਰ ਪੱਖ ਆਪਣੀਆਂ ਸਮਰੱਥਾ ਅਤੇ ਪ੍ਰimitives ਦਾ ਐਲਾਨ ਕਰਦਾ ਹੈ
3. **ਪਹਚਾਣ ਬਦਲਾਅ**: ਪਹਚਾਣ ਅਤੇ ਵਰਜਨ ਜਾਣਕਾਰੀ ਮੁਹੱਈਆ ਕਰਵਾਉਂਦਾ ਹੈ

```python

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {
      "elicitation": {},  # ਕਲਾਈਂਟ ਉਪਭੋਗਤਾ ਇੰਟਰਐਕਸ਼ਨ ਨੂੰ ਸਮਰਥਿਤ ਕਰਦਾ ਹੈ
      "sampling": {}      # ਕਲਾਈਂਟ LLM مکملات ਪ੍ਰਦਾਨ ਕਰ ਸਕਦਾ ਹੈ
    },
    "clientInfo": {
      "name": "edge-ai-client",
      "version": "1.0.0"
    }
  }
}
```

#### ਟੂਲ ਖੋਜ ਅਤੇ ਚਲਾਉਣਾ

ਸ਼ੁਰੂਆਤ ਤੋਂ ਬਾਅਦ, ਕਲਾਇੰਟ ਟੂਲ ਖੋਜ ਅਤੇ ਚਲਾਉਣ ਦੇ ਯੋਗ ਹੋ ਜਾਂਦੇ ਹਨ:

```python
# ਉਪਲਬਧ ਟੂਲਾਂ ਦੀ ਖੋਜ ਕਰੋ

import asyncio
from ghmodel_mcp_demo import OllamaClient, Phi4MiniMCPClient

async def automated_interaction():
    # ਐਮਸੀਪੀ ਸਰਵਰ ਪੈਰਾਮੀਟਰਾਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰੋ
    server_params = StdioServerParameters(
        command="npx",
        args=["@playwright/mcp@latest"],
        env=None,
    )
    
    # ਐਮਸੀਪੀ ਕਲਾਇੰਟ ਬਣਾਓ ਅਤੇ ਟੂਲ ਪ੍ਰਕਿਰਿਆ ਕਰੋ
    async with Phi4MiniMCPClient(server_params) as mcp_client:
        tools = await process_mcp_tools(mcp_client)
        llm_client = OllamaClient()
        
        # ਟੂਲ ਸਮਰਥਾਵਾਂ ਨਾਲ ਜਵਾਬ ਪੈਦਾ ਕਰੋ
        response, messages = await llm_client.generate_response(
            "Help me automate a web task",
            tools
        )
        return response

# ਆਟੋਮੇਸ਼ਨ ਨੂੰ ਚਲਾਓ
result = asyncio.run(automated_interaction())
print(result)
```

## ਉੱਚ ਵੇਖਣ ਵਾਲੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

### ਬਹੁ-ਬੈਕਐਂਡ ਸਮਰਥਨ

ਇਹ ਨਿਰਵੇਸ਼ ਓਲਾਮਾ ਅਤੇ vLLM ਦੋਹਾਂ ਬੈਕਐਂਡ ਲਈ ਸਮਰਥਨ ਕਰਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਤੁਸੀਂ ਆਪਣੀਆਂ ਲੋੜਾਂ ਦੇ ਅਨੁਸਾਰ ਚੋਣ ਕਰ ਸਕਦੇ ਹੋ:

- **ਓਲਾਮਾ**: ਸਥਾਨਕ ਵਿਕਾਸ ਅਤੇ ਟੈਸਟਿੰਗ ਲਈ ਵਧੀਆ
- **vLLM**: ਉਤਪਾਦਨ ਅਤੇ ਉੱਚ-ਪ੍ਰਵਾਹ ਦ੍ਰਿਸ਼ਾਂਕ ਲਈ ਅਨੁਕੂਲਿਤ

### ਲਚਕੀਲੇ ਕਨੈਕਸ਼ਨ ਪ੍ਰੋਟੋਕੋਲ

ਦੋ ਕਨੈਕਸ਼ਨ ਮੋਡ ਸਮਰਥਿਤ ਹਨ:

**STDIO ਮੋਡ**: ਸਿੱਧਾ ਪ੍ਰਕਿਰਿਆ ਸੰਚਾਰ
- ਘੱਟ ਲਾਗ
- ਸਥਾਨਕ ਸੰਦਾਂ ਲਈ ਉਚਿਤ
- ਸੌਖਾ ਸੈੱਟਅੱਪ

**SSE ਮੋਡ**: HTTP-ਅਧਾਰਿਤ ਸਟ੍ਰੀਮਿੰਗ
- ਨੈੱਟਵਰਕ-ਯੋਗ
- ਵੰਡੇ ਗਏ ਪ੍ਰਣਾਲੀਆਂ ਲਈ ਵਧੀਆ
- ਰੀਅਲ-ਟਾਈਮ ਅਪਡੇਟ

### ਟੂਲ ਇੰਟਿਗ੍ਰੇਸ਼ਨ ਸਮਰੱਥਾਵਾਂ

ਪ੍ਰਣਾਲੀ ਵੱਖ-ਵੱਖ ਟੂਲਾਂ ਨਾਲ ਇੰਟਿਗ੍ਰੇਟ ਕਰ ਸਕਦੀ ਹੈ:
- ਵੈੱਬ ਆਟੋਮੇਸ਼ਨ (Playwright)
- ਫਾਇਲ ਆਪਰੇਸ਼ਨ
- API ਇੰਟਰੈਕਸ਼ਨ
- ਸਿਸਟਮ ਕਮਾਂਡ
- ਕਸਟਮ ਫੰਕਸ਼ਨਾਂ

## ਗਲਤੀ ਸੰਭਾਲਣ ਅਤੇ ਸਰਵੋਤਮ ਅਮਲ

### ਵਿਆਪਕ ਗਲਤੀ ਪ੍ਰਬੰਧਨ

ਨਿਰਵੇਸ਼ ਵਿੱਚ ਮਜ਼ਬੂਤ ਗਲਤੀ ਸੰਭਾਲਣ ਸ਼ਾਮਲ ਹੈ:

**ਕਨੈਕਸ਼ਨ ਗਲਤੀਆਂ:**
- MCP ਸਰਵਰ ਫੇਲੀਆਂ
- ਨੈੱਟਵਰਕ ਟਾਈਮਆਊਟ
- ਕਨੈਕਟਿਵਿਟੀ ਸਮੱਸਿਆਵਾਂ

**ਟੂਲ ਚਲਾਉਣ ਵਾਲੀਆਂ ਗਲਤੀਆਂ:**
- ਗੁੰਮ ਟੂਲ
- ਪੈਰਾਮੀਟਰ ਪ੍ਰਮਾਣਿਕਤਾ
- ਚਲਾਉਣ ਵਿੱਚ ਅਸਫਲਤਾ

**ਜਵਾਬ ਪ੍ਰਕਿਰਿਆ ਗਲਤੀਆਂ:**
- JSON ਪਾਰਸਿੰਗ ਸਮੱਸਿਆਵਾਂ
- ਫਾਰਮੈਟ ਅਸੰਗਤਤਾ
- LLM ਜਵਾਬ ਵਿਅਕਤਗਤਤਾ

### ਸਰਵੋਤਮ ਅਮਲ

1. **ਸੰਸਾਧਨ ਪ੍ਰਬੰਧਨ**: async ਸੰਦੇਸ਼ੀਕ੍ਰਿਤ ਪ੍ਰਬੰਧਕਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ
2. **ਗਲਤੀ ਸੰਭਾਲ**: ਵਿਆਪਕ try-catch ਬਲਾਕਾਂ ਲਾਗੂ ਕਰੋ
3. **ਲੌਗਿੰਗ**: ਉਚਿਤ ਲੌਗਿੰਗ ਪੱਧਰ ਚਾਲੂ ਕਰੋ
4. **ਸੁਰੱਖਿਆ**: ਇਨਪੁੱਟ ਮਨਜੂਰ ਕਰੋ ਅਤੇ ਆਊਟਪੁੱਟ ਸਾਫ਼ ਕਰੋ
5. **ਕਾਰਗੁਜ਼ਾਰੀ**: ਕਨੈਕਸ਼ਨ ਪੁਲਿੰਗ ਅਤੇ ਕੈਸ਼ਿੰਗ ਦੀ ਵਰਤੋਂ ਕਰੋ

## MCP ਪਰਿਸਰ ਅਤੇ ਵਿਕਾਸ

### MCP ਪ੍ਰੋਜੈਕਟ ਦਾ ਖੇਤਰਫਲ

ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ ਪਰਿਸਰ ਕਈ ਮੁੱਖ ਭਾਗ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ:

- **[MCP ਵਿਸ਼ੇਸ਼ਤਾ](https://modelcontextprotocol.io/specification/latest)**: ਕਲਾਇੰਟ ਅਤੇ ਸਰਵਰਾਂ ਲਈ ਨਿਰਮਾਣ ਦੀਆਂ ਲੋੜਾਂ ਦਾ ਅਧਿਕਾਰਕ ਵਿਸ਼ੇਸ਼ਣ
- **[MCP SDKs](https://modelcontextprotocol.io/docs/sdk)**: ਵੱਖ-ਵੱਖ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਂ ਲਈ SDK ਜੋ MCP ਨੂੰ ਅਮਲ ਕਰਦੇ ਹਨ
- **MCP ਵਿਕਾਸ ਸੰਦ**: MCP ਸਰਵਰਾਂ ਅਤੇ ਕਲਾਇੰਟਾਂ ਦਾ ਵਿਕਾਸ ਕਰਨ ਲਈ ਸੰਦ, ਜਿਸ ਵਿੱਚ [MCP ਇੰਸਪੈਕਟਰ](https://github.com/modelcontextprotocol/inspector) ਸ਼ਾਮਲ ਹੈ
- **[MCP ਰੈਫਰੈਂਸ ਸਰਵਰ ਨਿਰਵੇਸ਼](https://github.com/modelcontextprotocol/servers)**: MCP ਸਰਵਰਾਂ ਦੇ ਰੈਫਰੈਂਸ ਨਿਰਵੇਸ਼

### MCP ਵਿਕਾਸ ਨਾਲ ਸ਼ੁਰੂਆਤ

ਬਿਲਡਿੰਗ ਸ਼ੁਰੂ ਕਰਨ ਲਈ:

**ਸਰਵਰ ਬਣਾਓ**: [ਆਪਣੇ ਡੇਟਾ ਅਤੇ ਸੰਦਾਂ ਨੂੰ ਖੋਲ੍ਹਣ ਲਈ MCP ਸਰਵਰ ਬਣਾਓ](https://modelcontextprotocol.io/docs/develop/build-server)

**ਕਲਾਇੰਟ ਬਣਾਓ**: [MCP ਸਰਵਰਾਂ ਨਾਲ ਜੁੜਨ ਵਾਲੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿਕਸਿਤ ਕਰੋ](https://modelcontextprotocol.io/docs/develop/build-client)

**ਧਾਰਨਾਵਾਂ ਸਿੱਖੋ**: [MCP ਦੇ ਮੁੱਖ ਸਿਧਾਂਤਾਂ ਅਤੇ ਆਰਕੀਟੈਕਚਰ ਨੂੰ ਸਮਝੋ](https://modelcontextprotocol.io/docs/learn/architecture)

## ਨਤੀਜਾ

MCP ਨਾਲ ਇੰਟਿਗ੍ਰੇਟ ਕੀਤੇ ਛੋਟੇ ਭਾਸ਼ਾ ਮਾਡਲ AI ਐਪਲੀਕੇਸ਼ਨ ਵਿਕਾਸ ਵਿੱਚ ਇੱਕ ਵਿਸ਼ਾਲ ਬਦਲਾਵ ਦਾ ਪ੍ਰਤੀਨਿਧਿਤਵ ਕਰਦੇ ਹਨ। ਛੋਟੇ ਮਾਡਲਾਂ ਦੀ ਕੁਸ਼ਲਤਾ ਨੂੰ ਬਾਹਰੀ ਸੰਦਾਂ ਦੀ ਸ਼ਕਤੀ ਨਾਲ ਮਿਲਾ ਕੇ, ਡਿਵੈਲਪਰਸ ਬੁੱਧੀਮਾਨ ਪ੍ਰਣਾਲੀਆਂ ਤਿਆਰ ਕਰ ਸਕਦੇ ਹਨ ਜੋ ਸੰਸਾਧਨਾਂ ਵਿੱਚ ਕੁਸ਼ਲ ਅਤੇ ਬਹੁਤ ਹੀ ਸਮਰੱਥ ਹੁੰਦੇ ਹਨ।

ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਬਾਹਰੀ ਪ੍ਰਣਾਲੀਆਂ ਨਾਲ ਜੁੜਨ ਲਈ ਇੱਕ ਮਿਆਰੀ ਰਾਹ ਮੁਹੱਈਆ ਕਰਵਾਉਂਦਾ ਹੈ, ਜਿਵੇਂ USB-C ਇਲੈਕਟ੍ਰਾਨਿਕ ਉਪਕਰਣਾਂ ਲਈ ਯੂਨੀਵਰਸਲ ਕਨੈਕਸ਼ਨ ਮਿਆਰ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ। ਇਹ ਮਿਆਰੀਕਰਨ ਇਹ ਯਕੀਨੀ ਬਨਾਉਂਦਾ ਹੈ:

- **ਬਿਨਾਂ ਰੁਕਾਵਟ ਇੰਟਿਗ੍ਰੇਸ਼ਨ**: AI ਮਾਡਲਾਂ ਨੂੰ ਵੱਖ-ਵੱਖ ਡੇਟਾ ਸਰੋਤਾਂ ਅਤੇ ਸੰਦਾਂ ਨਾਲ ਜੁੜਨ ਦਿਓ
- **ਇਕੋਸਿਸਟਮ ਵਿਕਾਸ**: ਇੱਕ ਵਾਰੀ ਬਣਾਓ, ਕਈ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ ਵਰਤੋਂ
- **ਵਧੀਕ ਸਮਰੱਥਾ**: SLMs ਨੂੰ ਬਾਹਰੀ ਕਾਰਗੁਜ਼ਾਰੀ ਨਾਲ ਵਧਾਓ
- **ਰੀਅਲ-ਟਾਈਮ ਅਪਡੇਟ**: ਗਤੀਸ਼ੀਲ, ਜਵਾਬਦਾਰ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਦਾ ਸਮਰਥਨ ਕਰੋ

ਪ੍ਰਮੁੱਖ ਸਿੱਖਿਆ:
- MCP ਇੱਕ ਖੁਲਾ ਮਿਆਰ ਹੈ ਜੋ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਅਤੇ ਬਾਹਰੀ ਪ੍ਰਣਾਲੀਆਂ ਨੂੰ ਜੋੜਦਾ ਹੈ
- ਪ੍ਰੋਟੋਕੋਲ ਸੰਦ, ਸਰੋਤ ਅਤੇ ਪ੍ਰਾਂਪਟ ਨੁਮਾਇੰਦਾ ਕਰਦਾ ਹੈ
- ਰੀਅਲ-ਟਾਈਮ ਸੂਚਨਾਵਾਂ ਗਤੀਸ਼ੀਲ, ਜਵਾਬਦਾਰ ਐਪਲੀਕੇਸ਼ਨ ਯਕੀਨੀ ਬਣਾਉਂਦੀਆਂ ਹਨ
- ਉਤਪਾਦਨ ਨੂੰ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ ਠੀਕ ਲਾਇਫਸਾਈਕਲ ਪ੍ਰਬੰਧਨ ਅਤੇ ਗਲਤੀ ਸੰਭਾਲ ਜ਼ਰੂਰੀ ਹੈ
- ਪਰਿਸਰ ਪੂਰੇ SDKs ਅਤੇ ਵਿਕਾਸ ਸੰਦ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ
