## ਤਾਰੂਫ

Microsoft Olive ਇੱਕ ਸ਼ਕਤੀਸ਼ਾਲੀ, ਆਸਾਨ-ਉਪਯੋਗ ਹਾਰਡਵੇਅਰ-ਸੂਚਿਤ ਮਾਡਲ ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਟੂਲਕਿੱਟ ਹੈ ਜੋ ਵੱਖ-ਵੱਖ ਹਾਰਡਵੇਅਰ ਪਲੇਟਫਾਰਮਾਂ 'ਤੇ ਡਿਪਲੋਇਮੈਂਟ ਲਈ ਮਸ਼ੀਨ ਲਰਨਿੰਗ ਮਾਡਲਾਂ ਨੂੰ ਸੁਧਾਰਨ ਦੇ ਪ੍ਰਕਿਰਿਆ ਨੂੰ ਸਧਾਰਨ ਬਣਾਉਂਦਾ ਹੈ। ਤੁਸੀਂ ਚਾਹੇ CPU, GPU, ਜਾਂ ਵਿਸ਼ੇਸ਼ AI ਐਕਸੈਲਰੇਟਰਾਂ ਨਿਸ਼ਾਨਾ ਬਣਾਉਂਦੇ ਹੋ, Olive ਤੁਹਾਨੂੰ ਮਾਡਲ ਦੀ ਸਹੀਅਤ ਬਣਾਈ ਰੱਖਦਿਆਂ ਬਿਹਤਰ ਪ੍ਰਦਰਸ਼ਨ ਪ੍ਰਾਪਤ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ।

## Microsoft Olive ਕੀ ਹੈ?

Olive ਇੱਕ ਆਸਾਨ-ਉਪਯੋਗ ਹਾਰਡਵੇਅਰ-ਸੂਚਿਤ ਮਾਡਲ ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਟੂਲ ਹੈ ਜੋ ਮਾਡਲ ਸੰਕੁਚਨ, ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਅਤੇ ਸੰकलਨ ਵਿੱਚ ਇੰਡਸਟਰੀ ਲੀਡਿੰਗ ਤਕਨੀਕਾਂ ਨੂੰ ਜੋੜਦਾ ਹੈ। ਇਹ ONNX ਰਨਟਾਈਮ ਨਾਲ ਇੱਕ ਪੂਰਨ ਅਨੁਮਾਨ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਹੱਲ ਵਜੋਂ ਕੰਮ ਕਰਦਾ ਹੈ।

### ਮੁੱਖ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

- **ਹਾਰਡਵੇਅਰ-ਸੂਚਿਤ ਅਪਟੀਮਾਈਜੇਸ਼ਨ**: ਤੁਹਾਡੇ ਨਿਸ਼ਾਨਾ ਹਾਰਡਵੇਅਰ ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਤਕਨੀਕਾਂ ਨੂੰ ਸਵੈਚਾਲਿਤ ਚੁਣਦਾ ਹੈ
- **40+ ਅੰਦਰੂਨੀ ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਕੰਪੋਨੈਂਟਸ**: ਮਾਡਲ ਸੰਕੁਚਨ, ਕੁਆਂਟਾਈਜ਼ੇਸ਼ਨ, ਗ੍ਰਾਫ ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਅਤੇ ਹੋਰ ਕਥਮ ਹੈ
- **ਆਸਾਨ CLI ਇੰਟਰਫੇਸ**: ਆਮ ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਕੰਮਾਂ ਲਈ ਸੌਖੇ ਕਮਾਂਡਾਂ
- **ਮਲਟੀ-ਫ੍ਰੇਮਵਰਕ ਸਹਿਯੋਗ**: PyTorch, Hugging Face ਮਾਡਲਾਂ ਅਤੇ ONNX ਨਾਲ ਕੰਮ ਕਰਦਾ ਹੈ
- **ਲੋਕਪ੍ਰਿਯ ਮਾਡਲ ਸਹਿਯੋਗ**: Olive ਆਟੋਮੈਟਿਕ ਤੌਰ 'ਤੇ ਲੋਕਪ੍ਰਿਯ ਮਾਡਲ ਆਰਕੀਟੈਕਚਰਾਂ ਜਿਵੇਂ ਕਿ Llama, Phi, Qwen, Gemma ਆਦਿ ਨੂੰ ਬਿਆਰ ਕਰਦਾ ਹੈ

### ਲਾਭ

- **ਵਿਕਾਸ ਸਮਾਂ ਘਟਾਉਣਾ**: ਵੱਖ-ਵੱਖ ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਤਕਨੀਕਾਂ ਨਾਲ ਹੱਥੋਂ ਪ੍ਰਯੋਗ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਰਹਿੰਦੀ
- **ਪ੍ਰਦਰਸ਼ਨ ਫਾਇਦੇ**: ਕਈ ਕੇਸਾਂ ਵਿੱਚ 6 ਗੁਣਾ ਤਕ ਤੇਜ਼ੀ
- **ਕ੍ਰਾਸ-ਪਲੇਟਫਾਰਮ ਡਿਪਲੋਇਮੈਂਟ**: ਅਪਟੀਮਾਈਜ਼ ਕੀਤੇ ਮਾਡਲ ਵੱਖਰੇ ਹਾਰਡਵੇਅਰ ਅਤੇ ਓਪਰੇਟਿੰਗ ਸਿਸਟਮਾਂ 'ਤੇ ਕੰਮ ਕਰਦੇ ਹਨ
- **ਸਹੀਅਤ ਕਾਇਮ ਰੱਖਣਾ**: ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨਾਂ ਨਾਲ ਮਾਡਲ ਦੀ ਗੁਣਵੱਤਾ ਬਰਕਰਾਰ ਰਹਿੰਦੀ ਹੈ

## ਇੰਸਟਾਲੇਸ਼ਨ

### ਜਰੂਰੀਆਂ ਸ਼ਰਤਾਂ

- Python 3.8 ਜਾਂ ਉਸ ਤੋਂ ਉਚੀ
- pip ਪੈਕੇਜ ਮੈਨੇਜਰ
- ਵਰਚੁਅਲ ਵਾਤਾਵਰਣ (ਸੁਝਾਏ ਗਏ)

### ਬੁਨਿਆਦੀ ਇੰਸਟਾਲੇਸ਼ਨ

ਇੱਕ ਵਰਚੁਅਲ ਵਾਤਾਵਰਣ ਬਣਾਓ ਅਤੇ ਚਾਲੂ ਕਰੋ:

```bash
# ਵਰਚੁਅਲ ਵਾਤਾਵਰਨ ਬਣਾਓ
python -m venv olive-env

# ਵਰਚੁਅਲ ਵਾਤਾਵਰਨ ਸਰਗਰਮ ਕਰੋ
# ਵਿੰਡੋਜ਼ 'ਤੇ:
olive-env\Scripts\activate
# ਮੈਕਓਐਸ/ਲਿਨਕਸ 'ਤੇ:
source olive-env/bin/activate
```

Olive ਨੂੰ ਆਟੋ-ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਫੀਚਰਾਂ ਨਾਲ ਇੰਸਟਾਲ ਕਰੋ:

```bash
pip install olive-ai[auto-opt]
pip install transformers onnxruntime-genai
```

### ਵਿਕਲਪੀ ਨਿਰਭਰਤਾਵਾਂ

Olive ਵੱਖ-ਵੱਖ ਵਿਕਲਪੀ ਨਿਰਭਰਤਾਵਾਂ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ ਵਾਧੂ ਫੀਚਰਾਂ ਲਈ:

```bash
# ਏਜ਼ੂਰ ML ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਲਈ

# ਡਾਇਰੈਕਟਐਮਐਲ (ਵਿੰਡੋਜ਼ ਜੀਪੀਯੂ ਐਕਸੀਲੇਰੇਸ਼ਨ) ਲਈ

# ਸੀਪੀਯੂ ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਲਈ
```

## ਤਾੱਤਕਾਲ ਸ਼ੁਰੂਆਤੀ ਮਾਰਗਦਰਸ਼ਕ

### ਤੁਹਾਡਾ ਪਹਿਲਾ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ

ਆਓ Olive ਦੇ ਆਟੋ-ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਫੀਚਰ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਇੱਕ ਛੋਟੇ ਭਾਸ਼ਾ ਮਾਡਲ ਨੂੰ ਅਪਟੀਮਾਈਜ਼ ਕਰੀਏ:

```bash
olive auto-opt \
  --model_name_or_path HuggingFaceTB/SmolLM2-135M-Instruct \
  --output_path models/smolm2-optimized \
  --device cpu \
  --provider CPUExecutionProvider \
  --use_ort_genai \
  --precision int4 \
  --log_level 1
```

### ਇਹ ਕਮਾਂਡ ਕੀ ਕਰਦੀ ਹੈ

ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਪ੍ਰਕਿਰਿਆ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ: ਮਾਡਲ ਨੂੰ ਸਥਾਨਕ ਕੈਸ਼ ਤੋਂ ਪ੍ਰਾਪਤ ਕਰਨਾ, ONNX ਗ੍ਰਾਫ ਕੈਪਚਰ ਕਰਕੇ ONNX ਡਾਟਾ ਫਾਇਲ ਵਿੱਚ ਵਜ਼ਨ ਸਟੋਰ ਕਰਨ, ONNX ਗ੍ਰਾਫ ਨੂੰ ਅਪਟੀਮਾਈਜ਼ ਕਰਨਾ, ਅਤੇ RTN ਵਿਧੀ ਨਾਲ ਮਾਡਲ ਨੂੰ int4 'ਚ ਕੁਆਂਟਾਈਜ਼ ਕਰਨਾ।

### ਕਮਾਂਡ ਪੈਰਾਮੀਟਰਾਂ ਦੀ ਵਿਆਖਿਆ

- `--model_name_or_path`: Hugging Face ਮਾਡਲ ਦੀ ਪਛਾਣ ਜਾਂ ਸਥਾਨਕ ਰਸਤਾ
- `--output_path`: ਡਾਇਰੈਕਟਰੀ ਜਿੱਥੇ ਅਪਟੀਮਾਈਜ਼ਡ ਮਾਡਲ ਸੇਵ ਕੀਤਾ ਜਾਵੇਗਾ
- `--device`: ਨਿਸ਼ਾਨਾ ਜੰਤਰ (cpu, gpu)
- `--provider`: ਕਾਰਜ ਪ੍ਰਦਾਤਾ (CPUExecutionProvider, CUDAExecutionProvider, DmlExecutionProvider)
- `--use_ort_genai`: ਅਨੁਮਾਨ ਲਈ ONNX ਰਨਟਾਈਮ ਜਨਰੇਟ AI ਵਰਤਣਾ
- `--precision`: ਕੁਆਂਟਾਈਜ਼ੇਸ਼ਨ ਪ੍ਰਿਸੀਸ਼ਨ (int4, int8, fp16)
- `--log_level`: ਲੌਗਿੰਗ ਦਿੱਖ (0=ਘੱਟੋ-ਘੱਟ, 1=ਵਿਸਤ੍ਰਿਤ)

## ਉਦਾਹਰਨ: Qwen3 ਨੂੰ ONNX INT4 ਵਿੱਚ ਬਦਲਣਾ

ਦਿੱਤੇ ਗਏ Hugging Face ਉਦਾਹਰਨ ਤੇ ਆਧਾਰਿਤ [lokinfey/Qwen3-8B-ONNX-INT4-CPU](https://huggingface.co/lokinfey/Qwen3-8B-ONNX-INT4-CPU), ਇੱਥੇ Qwen3 ਮਾਡਲ ਨੂੰ ਅਪਟੀਮਾਈਜ਼ ਕਰਨਾ ਹੈ:

### ਕਦਮ 1: ਮਾਡਲ ਡਾਊਨਲੋਡ ਕਰੋ (ਵਿਕਲਪੀ)

ਡਾਊਨਲੋਡ ਸਮਾਂ ਘਟਾਉਣ ਲਈ, ਸਿਰਫ਼ ਜ਼ਰੂਰੀ ਫਾਇਲਾਂ ਕੈਸ਼ ਕਰੋ:

```bash
huggingface-cli download Qwen/Qwen2.5-0.5B-Instruct *.json *.safetensors *.txt
```

### ਕਦਮ 2: Qwen3 ਮਾਡਲ ਨੂੰ ਅਪਟੀਮਾਈਜ਼ ਕਰੋ

```bash
olive auto-opt \
  --model_name_or_path Qwen/Qwen2.5-0.5B-Instruct \
  --output_path models/qwen3-onnx-int4 \
  --device cpu \
  --provider CPUExecutionProvider \
  --use_ort_genai \
  --precision int4 \
  --log_level 1
```

### ਕਦਮ 3: ਅਪਟੀਮਾਈਜ਼ਡ ਮਾਡਲ ਦਾ ਟੈਸਟ ਕਰੋ

ਆਪਣੀ ਅਪਟੀਮਾਈਜ਼ ਕੀਤੀ ਮਾਡਲ ਕੋ ਟੈਸਟ ਕਰਨ ਲਈ ਇੱਕ ਸਧਾਰਣ Python ਸਕ੍ਰਿਪਟ ਬਣਾਓ:

```python
import onnxruntime_genai as og

# ਢੰਗ ਨਾਲ ਬਣਾਇਆ ਮਾਡਲ ਲੋਡ ਕਰੋ
model = og.Model('models/qwen3-onnx-int4')
tokenizer = og.Tokenizer(model)

# ਚੈਟ ਟੈਮਪਲੇਟ ਬਣਾਓ
chat_template = '<|im_start|>user\n{input}<|im_end|>\n<|im_start|>assistant\n'

# ਲਿਖਤ ਤਿਆਰ ਕਰੋ
prompt = "What is machine learning?"
input_tokens = tokenizer.encode(chat_template.format(input=prompt))

params = og.GeneratorParams(model)
params.set_search_options(max_length=200)
params.input_ids = input_tokens

generator = og.Generator(model, params)

print("Generated response:")
while not generator.is_done():
    generator.compute_logits()
    generator.generate_next_token()
    
    new_token = generator.get_next_tokens()[0]
    print(tokenizer.decode([new_token]), end='', flush=True)

print()
```

## ਸਰੋਤੀਆਂ ਜ਼ਰੂਰੀ ਗੱਲਾਂ

### 1. ਮਾਡਲ ਚੋਣ
- ਟੈਸਟ ਕਰਨ ਲਈ ਛੋਟੇ ਮਾਡਲਾਂ ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ (ਜਿਵੇਂ 0.5B-7B ਪੈਰामीਟਰ)
- ਆਪਣੇ ਨਿਸ਼ਾਨਾ ਮਾਡਲ ਆਰਕੀਟੈਕਚਰ ਨੂੰ Olive ਦੇ ਸਮਰਥਿਤ ਹੋਣ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ

### 2. ਹਾਰਡਵੇਅਰ ਵਿਚਾਰ
- ਆਪਣੀ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਨਿਸ਼ਾਨਾ ਨੂੰ ਆਪਣੀ ਡਿਪਲੋਾਇਮੈਂਟ ਹਾਰਡਵੇਅਰ ਨਾਲ ਮਿਲਾਓ
- ਜੇ CUDA-ਅਨੁਕੂਲ ਹਾਰਡਵੇਅਰ ਹੈ, ਤਾਂ GPU ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਵਰਤੋਂ
- Windows ਮਸ਼ੀਨਾਂ ਲਈ ਇੰਟਰਗ੍ਰੇਟਿਡ ਗ੍ਰਾਫਿਕਸ ਨਾਲ DirectML ਬਾਰੇ ਸੋਚੋ

### 3. ਪ੍ਰਿਸੀਸ਼ਨ ਚੋਣ
- **INT4**: ਵੱਧ ਤੋਂ ਵੱਧ ਸੰਕੁਚਿਤ, ਹਲਕੀ ਸਹੀਅਤ ਗਿਰਾਵਟ
- **INT8**: ਆਕਾਰ ਅਤੇ ਸਹੀਅਤ ਦਾ ਵਧੀਆ ਸੰਤੁਲਨ
- **FP16**: ਘੱਟੋ-ਘੱਟ ਸਹੀਅਤ ਨੁਕਸਾਨ, ਮੱਧਮ ਆਕਾਰ ਘਟਾਉਣਾ

### 4. ਟੈਸਟਿੰਗ ਅਤੇ ਪੁਸ਼ਟੀ
- ਸਦਾ ਵਿਸ਼ੇਸ਼ ਵਰਤੋਂ ਕੇਸਾਂ ਨਾਲ ਅਪਟੀਮਾਈਜ਼ ਕੀਤੇ ਮਾਡਲਾਂ ਦੀ ਚਕਾਸ਼ ਕਰੋ
- ਪ੍ਰਦਰਸ਼ਨ ਮੈਟਰਿਕਸ (ਲੇਟੈੰਸੀ, ਥਰੂਪੁੱਟ, ਸਹੀਅਤ) ਦੀ ਤੁਲਨਾ ਕਰੋ
- ਮੁਲਾਂਕਣ ਲਈ ਪ੍ਰਤੀਨਿਧੀ ਇਨਪੁੱਟ ਡਾਟਾ ਦੀ ਵਰਤੋਂ ਕਰੋ

### 5. ਧੀਰੇ-ਧੀਰੇ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ
- ਤੇਜ਼ ਨਤੀਜਿਆਂ ਲਈ ਆਟੋ-ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ
- ਜ਼ਿਆਦਾ-ਮਹਿਰਤ ਲਈ ਸੰਰਚਨਾ ਫਾਇਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ
- ਵੱਖ-ਵੱਖ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਪਾਸਾਂ ਨਾਲ ਪ੍ਰਯੋਗ ਕਰੋ

```json
    }
  },
  "systems": {
    "local_system": {
      "type": "LocalSystem",
      "config": {
        "accelerators": [
          {
            "device": "cpu",
            "execution_providers": ["CPUExecutionProvider"]
          }
        ]
      }
    }
  },
  "passes": {
    "convert": {
      "type": "ModelBuilder",
      "config": {
        "precision": "int4"
      }
    }
  }
}
```

### ਰੇਸੀਪੀਜ਼ ਨੂੰ ਆਪਣੇ ਅਨੁਸਾਰ ਬਣਾਉਣਾ

#### ਨਿਸ਼ਾਨਾ ਹਾਰਡਵੇਅਰ ਨੂੰ ਬਦਲਣਾ

ਨਿਸ਼ਾਨਾ ਹਾਰਡਵੇਅਰ ਬਦਲਣ ਲਈ, `systems` ਸੈਕਸ਼ਨ ਅਪਡੇਟ ਕਰੋ:

```json
{
  "systems": {
    "gpu_system": {
      "type": "LocalSystem",
      "config": {
        "accelerators": [
          {
            "device": "gpu",
            "execution_providers": ["CUDAExecutionProvider"]
          }
        ]
      }
    }
  }
}
```

#### ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਪੈਰਾਮੀਟਰਾਂ ਨੂੰ ਢਾਲਣਾ

ਵੱਖ-ਵੱਖ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਪੱਧਰਾਂ ਲਈ `passes` ਸੈਕਸ਼ਨ ਸੋਧੋ:

```json
{
  "passes": {
    "convert": {
      "type": "ModelBuilder",
      "config": {
        "precision": "int8",           // Change from int4 to int8
        "use_ort_genai": true,
        "use_dynamo_exporter": true
      }
    },
    "optimize": {
      "type": "OrtTransformersOptimization",
      "config": {
        "optimization_level": "all"
      }
    }
  }
}
```

#### 4. **ਕਮਿਊਨਿਟੀ ਯੋਗਦਾਨ**
- ਏਆਈ ਕਮਿਊਨਿਟੀ ਨਾਲ ਸਹਿਯੋਗੀ ਵਿਕਾਸ
- ਸਾਂਝੀ ਜਾਣਕਾਰੀ ਅਤੇ ਸਰੋਤੀਆਂ ਵਧੀਆ ਅਭਿਆਸਾਂ

### Olive ਰੇਸੀਪੀਜ਼ ਵਿੱਚ ਯੋਗਦਾਨ ਦੇਣਾ

ਜੇ ਤੁਸੀਂ ਕਿਸੇ ਐਸੇ ਮਾਡਲ ਨੂੰ ਅਪਟੀਮਾਈਜ਼ ਕੀਤਾ ਹੈ ਜੋ ਰਿਪੋਜ਼ਟਰੀ ਵਿੱਚ ਨਹੀਂ ਹੈ:

1. **ਰਿਪੋਜ਼ਟਰੀ ਫੋਰਕ ਕਰੋ**: olive-recipes ਦੀ ਆਪਣੀ ਫੋਰਕ ਬਣਾਓ
2. **ਰੇਸੀਪੀ ਡਾਇਰੈਕਟਰੀ ਬਣਾਓ**: ਆਪਣੇ ਮਾਡਲ ਲਈ ਨਵੀਂ ਡਾਇਰੈਕਟਰੀ ਸ਼ਾਮਲ ਕਰੋ
3. **ਸੰਰਚਨਾ ਸ਼ਾਮਲ ਕਰੋ**: olive_config.json ਅਤੇ ਸਹਾਇਕ ਫਾਇਲਾ ਸ਼ਾਮਲ ਕਰੋ
4. **ਵਰਤੋਂ ਵਾਲਾ ਦਸਤਾਵੇਜ਼ ਬਣਾਓ**: ਰੇਡੀਮੀ ਵਿੱਚ ਸਪਸ਼ਟ ਹੁਕਮਾਂ ਨਾਲ ਪ੍ਰਦਾਨ ਕਰੋ
5. **ਪੁਲ ਰਿਕਵੇਸਟ ਸਬਮਿਟ ਕਰੋ**: ਕਮਿਊਨਿਟੀ ਨੂੰ ਵਾਪਸ ਯੋਗਦਾਨ ਦਿਓ

### ਪ੍ਰਦਰਸ਼ਨ ਨਾਪ

ਕਈ ਰੇਸੀਪੀਜ਼ ਪ੍ਰਦਰਸ਼ਨ ਨਾਪ ਸ਼ਾਮਲ ਕਰਦੀਆਂ ਹਨ ਜਿਹੜੇ ਦਰਸਾਉਂਦੀਆਂ ਹਨ:
- **ਲੇਟੈਂਸੀ ਵਿੱਚ ਸੁਧਾਰ**: ਆਮ 2-6 ਗੁਣਾ ਤੇਜ਼ੀ ਬੇਸਲਾਈਨ ਨਾਲੋਂ
- **ਮੈਮਰੀ ਘਟਾਓ**: ਕੁਆਂਟਾਈਜ਼ੇਸ਼ਨ ਨਾਲ 50-75% ਮੈਮਰੀ ਖਪਤ ਘਟਾਓ
- **ਸਹੀਅਤ ਕਾਇਮ**: 95-99% ਸਹੀਅਤ ਬਰਕਰਾਰ

### AI ਟੂਲਕਿੱਟ ਨਾਲ ਇੰਟਿਗ੍ਰੇਸ਼ਨ

ਰੇਸੀਪੀਜ਼ ਸਹਿਯੋਗ ਨਾਲ ਕੰਮ ਕਰਦੀਆਂ ਹਨ:
- **VS Code AI Toolkit**: ਮਾਡਲ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਲਈ ਸਿੱਧਾ ਇੰਟਿਗ੍ਰੇਸ਼ਨ
- **Azure Machine Learning**: ਬਾਦਲ-ਆਧਾਰਿਤ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਵਰਕਫਲੋਜ਼
- **ONNX Runtime**: ਅਪਟੀਮਾਈਜ਼ਡ ਅਨੁਮਾਨ ਡਿਪਲੋਇਮੈਂਟ
