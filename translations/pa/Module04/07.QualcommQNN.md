## ਪ੍ਰਸਤਾਵਨਾ

Qualcomm QNN (Qualcomm ਨਿਊਰਲ ਨੈੱਟਵਰਕ) ਇੱਕ ਵਿਸਤ੍ਰਿਤ AI ਇੰਫਰੈਂਸ ਫਰੇਮਵਰਕ ਹੈ ਜੋ Qualcomm ਦੇ AI ਹਾਰਡਵੇਅਰ ਐਕਸੇਲਰੇਟਰਾਂ ਦੀ ਪੂਰੀ ਸਮਰੱਥਾ ਨੂੰ ਖੋਲ੍ਹਣ ਲਈ ਡਿਜ਼ਾਈਨ ਕੀਤਾ ਗਿਆ ਹੈ, ਜਿਵੇਂ ਕਿ Hexagon NPU, Adreno GPU ਅਤੇ Kryo CPU। ਚਾਹੇ ਤੁਸੀਂ ਮੋਬਾਈਲ ਡਿਵਾਈਸ, ਐਜ ਕੰਪਿਊਟਿੰਗ ਪਲੇਟਫਾਰਮ ਜਾਂ ਆਟੋਮੋਟਿਵ ਸਿਸਟਮਾਂ ਨੂੰ ਨਿਸ਼ਾਨਾ ਬਣਾ ਰਹੇ ਹੋ, QNN ਵਿਸ਼ੇਸ਼ AI ਪ੍ਰੋਸੈਸਿੰਗ ਯੂਨਿਟਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਮਹੱਤਵਪੂਰਨ ਪ੍ਰਦਰਸ਼ਨ ਅਤੇ ਊਰਜਾ ਕੁਸ਼ਲਤਾ ਵਾਲੀਆਂ ਅਪਟੀਮਾਈਜ਼ਡ ਇੰਫਰੈਂਸ ਖੁਬੀਆਂ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।

## Qualcomm QNN ਕੀ ਹੈ?

Qualcomm QNN ਇੱਕ ਇਕੀਕृत AI ਇੰਫਰੈਂਸ ਫਰੇਮਵਰਕ ਹੈ ਜੋ ਵਿਕਾਸਕਾਰਾਂ ਨੂੰ Qualcomm ਦੀ ਵਿਭਿੰਨ ਲੇਆਉਟ ਕੀਤੀ ਗਈ ਕੰਪਿਊਟਿੰਗ ਬਣਤਰ ਵਿੱਚ AI ਮਾਡਲਾਂ ਨੂੰ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਤਰੀਕੇ ਨਾਲ ਤैनਾਤ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਇਹ Hexagon NPU (ਨਿਊਰਲ ਪ੍ਰੋਸੈਸਿੰਗ ਯੂਨਿਟ), Adreno GPU ਅਤੇ Kryo CPU ਤੱਕ ਪਹੁੰਚ ਲਈ ਇਕਤਰਿਤ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਇੰਟਰਫੇਸ ਮੁਹੱਈਆ ਕਰਵਾਉਂਦਾ ਹੈ ਜੋ ਵੱਖ-ਵੱਖ ਮਾਡਲ ਪਰਤਾਂ ਅਤੇ ਕਾਰਵਾਈਆਂ ਲਈ ਸਭ ਤੋਂ ਉਚਿਤ ਪ੍ਰੋਸੈਸਿੰਗ ਯੂਨਿਟ ਨੂੰ ਖੁਦ ਬ-ਖੁਦ ਚੁਣਦਾ ਹੈ।

- **ਹੇਟੇਰੋਜੀਨੀਅਸ ਕੰਪਿਊਟਿੰਗ**: NPU, GPU ਅਤੇ CPU ਲਈ ਇਕਜੁੱਟ ਪਹੁੰਚ ਅਤੇ ਆਟੋਮੈਟਿਕ ਵਾਰਕਲੋਡ ਵੰਡੀਕਰਨ

- **ਕੁਆਐਂਟੀਜ਼ੇਸ਼ਨ ਸਹਾਇਤਾ**: ਅੱਗੇ ਵਧੀ ہوئی INT8, INT16 ਅਤੇ ਮਿਕਸਡ-ਪ੍ਰਿਸੀਜ਼ਨ ਕੁਆਐਂਟੀਜ਼ੇਸ਼ਨ ਤਕਨੀਕਾਂ
- **ਮਾਡਲ ਬਦਲਣ ਦੇ ਸੰਦ**: TensorFlow, PyTorch, ONNX ਅਤੇ Caffe ਮਾਡਲਾਂ ਲਈ ਸਿੱਧੀ ਸਹਾਇਤਾ
- **ਐਜ AI ਲਈ ਅਪਟੀਮਾਈਜ਼ਡ**: ਮੋਬਾਈਲ ਅਤੇ ਐਜ ਤੈਨਾਤੀ ਲਈ ਖਾਸ ਤੌਰ 'ਤੇ ਤਿਆਰ ਕੀਤਾ ਗਿਆ, ਵਪਾਰਕ ਊਰਜਾ ਕੁਸ਼ਲਤਾ ਨੂੰ ਧਿਆਨ ਵਿੱਚ ਰੱਖਦੇ ਹੋਏ

## ਤੁਰੰਤ ਸ਼ੁਰੂਆਤ ਗਾਈਡ

### ਤੁਹਾਡੀ ਪਹਿਲੀ ਮਾਡਲ ਬਦਲੀ

ਆਓ ਇੱਕ ਸਧਾਰਣ PyTorch ਮਾਡਲ ਨੂੰ Qualcomm ਹਾਰਡਵੇਅਰ 'ਤੇ ਚਲਾਉਣ ਲਈ ਬਦਲੀਏ:

```python
import torch
import torch.nn as nn
import numpy as np

# ਇੱਕ ਸਾਦਾ ਮਾਡਲ ਪਰिभਾਸ਼ਿਤ ਕਰੋ
class SimpleModel(nn.Module):
    def __init__(self):
        super(SimpleModel, self).__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.pool = nn.AdaptiveAvgPool2d((1, 1))
        self.fc = nn.Linear(64, 10)
    
    def forward(self, x):
        x = self.relu(self.conv1(x))
        x = self.relu(self.conv2(x))
        x = self.pool(x)
        x = x.view(x.size(0), -1)
        x = self.fc(x)
        return x

# ਮਾਡਲ ਬਣਾਓ ਅਤੇ ਨਿਰਯਾਤ ਕਰੋ
model = SimpleModel()
model.eval()

# ਟਰੇਸਿੰਗ ਲਈ ਡਮੀ ਇਨਪੁਟ ਬਣਾਓ
dummy_input = torch.randn(1, 3, 224, 224)

# ONNX ਨੂੰ ਨਿਰਯਾਤ ਕਰੋ
torch.onnx.export(
    model,
    dummy_input,
    "simple_model.onnx",
    export_params=True,
    opset_version=11,
    do_constant_folding=True,
    input_names=['input'],
    output_names=['output'],
    dynamic_axes={'input': {0: 'batch_size'},
                  'output': {0: 'batch_size'}}
)
```

### ONNX ਨੂੰ QNN ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲੋ

```bash
# ONNX ਮਾਡਲ ਨੂੰ QNN ਮਾਡਲ ਲਾਇਬ੍ਰੇਰੀ ਵਿੱਚ ਬਦਲੋ
qnn-onnx-converter \
    --input_network simple_model.onnx \
    --output_path simple_model.cpp \
    --input_dim input 1,3,224,224 \
    --quantization_overrides quantization_config.json
```

### QNN ਮਾਡਲ ਲਾਇਬ੍ਰੇਰੀ ਬਣਾਓ

```bash
# ਮਾਡਲ ਲਾਇਬਰੇਰੀ ਕੰਪਾਇਲ ਕਰੋ
qnn-model-lib-generator \
    -c simple_model.cpp \
    -b simple_model.bin \
    -t x86_64-linux-clang \
    -l simple_model \
    -o simple_model_qnn.so
```

### ਇਹ ਪ੍ਰਕਿਰਿਆ ਕੀ ਕਰਦੀ ਹੈ

ਅਪਟੀਮਾਈਜੇਸ਼ਨ ਵਰਕਫਲੋ ਵਿੱਚ ਸ਼ਾਮਲ ਹੈ: ਮੂਲ ਮਾਡਲ ਨੂੰ ONNX ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲਣਾ, ONNX ਨੂੰ QNN ਮਧਿਆਮਿਕ ਪ੍ਰਤੀਨਿਧਿਤ ਵਿੱਚ ਤਬਦੀਲ ਕਰਨਾ, ਹਾਰਡਵੇਅਰ-ਵਿਸ਼ੇਸ਼ ਅਪਟੀਮਾਈਜੇਸ਼ਨਾਂ ਨੂੰ ਲਾਗੂ ਕਰਨਾ ਅਤੇ ਤੈਨਾਤੀ ਲਈ ਕੰਪਾਈਲ ਕੀਤੀ ਹੋਈ ਮਾਡਲ ਲਾਇਬ੍ਰੇਰੀ ਤੈਆਰ ਕਰਨਾ।

### ਮੁੱਖ ਪੈਰਾਮੀਟਰ ਵੇਰਵੇ

- `--input_network`: ਸਰੋਤ ONNX ਮਾਡਲ ਫਾਈਲ
- `--output_path`: ਬਣਾਇਆ ਗਿਆ C++ ਸੋर्स ਫਾਈਲ
- `--input_dim`: ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ ਲਈ ਇਨਪੁੱਟ ਟੈਨਸਰ ਮਾਪ
- `--quantization_overrides`: ਕਸਟਮ ਕੁਆਐਂਟੀਜ਼ੇਸ਼ਨ ਵਿਵਸਥਾ
- `-t x86_64-linux-clang`: ਨਿਸ਼ਾਨਾ ਆਰਕੀਟੈਕਚਰ ਅਤੇ ਕੰਪਾਇਲਰ

## ਉਦਾਹਰਨ: QNN ਨਾਲ ਮਾਡਲਾਂ ਦੀ ਬਦਲੀ ਅਤੇ ਅਪਟੀਮਾਈਜੇਸ਼ਨ

### ਪਹਿਲਾ ਕਦਮ: ਕੁਆਐਂਟੀਸ਼ਨ ਨਾਲ ਅਡਵਾਂਸਡ ਮਾਡਲ ਬਦਲੀ

ਕਸਟਮ ਕੁਆਐਂਟੀਜ਼ੇਸ਼ਨ ਲਾਗੂ ਕਰਨ ਦਾ ਤਰੀਕਾਃ

```json
// quantization_config.json
{
  "activation_encodings": {

      "bitwidth": 8,
      "max": 6.0,
      "min": 0.0,
      "scale": 0.023529,
      "offset": 0
    }
  },
  "param_encodings": {
    "conv1.weight": {
      "bitwidth": 8,
      "max": 2.5,
      "min": -2.5,

      "offset": 127
    }
  },
  "activation_bitwidth": 8,
  "param_bitwidth": 8,
  "bias_bitwidth": 32
}
```

ਕਸਟਮ ਕੁਆਐਂਟੀਜ਼ੇਸ਼ਨ ਨਾਲ ਬਦਲੀ ਕਰੋ:

```bash
qnn-onnx-converter \
    --input_network model.onnx \
    --output_path model_quantized.cpp \
    --input_dim input 1,3,224,224 \
    --quantization_overrides quantization_config.json \
    --target_device hexagon \
    --optimization_level high
```

### ਦੂਜਾ ਕਦਮ: ਮਲਟੀ-ਬੈਕਐਂਡ ਅਪਟੀਮਾਈਜੇਸ਼ਨ

NPU, GPU ਅਤੇ CPU 'ਤੇ ਹੇਟੇਰੋਜੀਨੀਅਸ ਐਗਜ਼ੀਕਿਊਸ਼ਨ ਲਈ ਵਿਆਸਥਾ ਕਰੋ:

```bash
# ਕਈ ਬੈਕਐਂਡ ਸਹਾਇਤਾ ਨਾਲ ਮਾਡਲ ਲਾਇਬ੍ਰੇਰੀ ਤਿਆਰ ਕਰੋ
qnn-model-lib-generator \
    -c model_quantized.cpp \
    -b model_quantized.bin \
    -t aarch64-android \
    -l model_optimized \
    -o model_optimized.so \
    --target_backends htp,gpu,cpu
```

### ਤੀਜਾ ਕਦਮ: ਤੈਨਾਤ ਲਈ ਕਾਂਟੈਕਸਟ ਬਾਇਨਰੀ ਬਣਾਓ

```bash
# ਵਧੇਰੇ ਪ੍ਰਭਾਵਸ਼ালী ਸੰਦਰਭ ਬਾਈਨਰੀ ਤਿਆਰ ਕਰੋ

    --model model_optimized.so \
    --backend libQnnHtp.so \

```

### ਚੌਥਾ ਕਦਮ: QNN ਰਨਟਾਈਮ ਨਾਲ ਇੰਫਰੈਂਸ

```python
import ctypes
import numpy as np

# ਕਿਊਐੱਨਐਨ ਲਾਇਬ੍ਰੇਰੀ ਲੋਡ ਕਰੋ
qnn_lib = ctypes.CDLL('./libQnn.so')

class QNNInference:
    def __init__(self, model_path, backend='htp'):
        self.model_path = model_path
        self.backend = backend
        self.context = None
        self._initialize()
    
    def _initialize(self):
        # ਕਿਊਐੱਨਐਨ ਰਨਟਾਈਮ ਸ਼ੁਰੂ ਕਰੋ
        # ਮਾਡਲ ਲੋਡ ਕਰੋ ਅਤੇ ਇਨਫਰੇਂਸ ਸੰਦਰਭ ਬਣਾਓ
        pass
    
    def preprocess_input(self, data):
        # ਜ਼ਰੂਰਤ ਹੋਣ 'ਤੇ ਇਨਪੁੱਟ ਡਾਟਾ ਨੂੰ ਕਵਾਂਟਾਈਜ਼ ਕਰੋ
        if self.is_quantized:
            # ਕਵਾਂਟਾਈਜ਼ੇਸ਼ਨ ਪੈਰਾਮੀਟਰ ਲਾਗੂ ਕਰੋ
            scale = self.input_scale
            offset = self.input_offset
            quantized = np.clip(
                np.round(data / scale + offset), 
                0, 255
            ).astype(np.uint8)
            return quantized
        return data.astype(np.float32)
    
    def inference(self, input_data):
        # ਇਨਪੁੱਟ ਨੂੰ ਪ੍ਰੀਪ੍ਰੋਸੈਸ ਕਰੋ
        processed_input = self.preprocess_input(input_data)
        
        # ਕਵਾਲਕੌਮ ਹਾਰਡਵੇਅਰ 'ਤੇ ਇਨਫਰੇਂਸ ਚਲਾਓ
        # ਇਹ ਕਿਊਐਨਐਨ C++ API ਨੂੰ ਕਾਲ ਕਰੇਗਾ
        output = self._run_inference(processed_input)
        
        # ਆਉਟਪੁੱਟ ਨੂੰ ਪੋਸਟਪ੍ਰੋਸੈਸ ਕਰੋ
        return self.postprocess_output(output)
    
    def postprocess_output(self, output):
        # ਜ਼ਰੂਰਤ ਹੋਣ 'ਤੇ ਆਉਟਪੁੱਟ ਦੀ ਡੀਕਵਾਂਟਾਈਜ਼ ਕਰੋ
        if self.is_quantized:
            scale = self.output_scale
            offset = self.output_offset
            dequantized = (output.astype(np.float32) - offset) * scale
            return dequantized
        return output
```

ਚੰਗੀ ਸਹੀਤਾ ਲਈ ਰਨਟਾਈਮ ਤੇ ਕੁਆਐਂਟੀਜ਼ੇਸ਼ਨ ਲਾਗੂ ਕਰੋ:

```python
class DynamicQuantization:
    def __init__(self, model_path):
        self.model_path = model_path
        self.calibration_data = []
    
    def collect_statistics(self, calibration_dataset):
        """Collect activation statistics for quantization"""
        for data in calibration_dataset:
            # ਇਨਫਰੰਸ ਚਲਾਓ ਅਤੇ ਐਕਟੀਵੇਸ਼ਨ ਰੇਂਜ ਇੱਕੱਠਾ ਕਰੋ
            activations = self.forward_hooks(data)
            self.calibration_data.append(activations)
    
    def compute_quantization_params(self):
        """Compute optimal quantization parameters"""
        params = {}
        for layer_name, activations in self.calibration_data:
            min_val = np.min(activations)
            max_val = np.max(activations)
            
            # INT8 ਮਾਤਰਾ ਲਈ ਸਕੇਲ ਅਤੇ ਔਫਸੈੱਟ ਕੈਲਕੁਲੇਟ ਕਰੋ
            scale = (max_val - min_val) / 255.0
            offset = -min_val / scale
            
            params[layer_name] = {
                "scale": scale,
                "offset": int(offset),
                "min": min_val,
                "max": max_val
            }
        
        return params
    
    def apply_quantization(self, quantization_params):
        """Apply computed quantization parameters"""
        config = {
            "activation_encodings": {},
            "param_encodings": {}
        }
        
        for layer, params in quantization_params.items():
            config["activation_encodings"][layer] = {
                "bitwidth": 8,
                "scale": params["scale"],
                "offset": params["offset"],
                "min": params["min"],
                "max": params["max"]
            }
        
        return config
```

```python
            result = inference_func(input_data)
```

```python
class BackendSelector:
    def __init__(self):
        self.backend_capabilities = {
            "htp": {
                "supported_ops": ["Conv2d", "Dense", "BatchNorm", "ReLU"],
                "max_tensor_size": 8 * 1024 * 1024,  # 8MB
                "preferred_precision": "int8",
                "power_efficiency": 0.9
            },
            "gpu": {
                "supported_ops": ["Conv2d", "Dense", "ReLU", "Softmax"],
                "max_tensor_size": 64 * 1024 * 1024,  # 64MB
                "preferred_precision": "fp16",
                "power_efficiency": 0.6
            },
            "cpu": {
                "supported_ops": ["*"],  # ਸਾਰੇ ਓਪਰੇਸ਼ਨ
                "max_tensor_size": 512 * 1024 * 1024,  # 512MB
                "preferred_precision": "fp32",
                "power_efficiency": 0.4
            }
        }
    
    def select_optimal_backend(self, model_info, constraints):
        """Select optimal backend based on model and constraints"""
        scores = {}
        
        for backend, caps in self.backend_capabilities.items():
            score = 0
            
            # ਓਪਰੇਸ਼ਨ ਸਹਿਯੋਗ ਦੀ ਜਾਂਚ ਕਰੋ
            if all(op in caps["supported_ops"] or "*" in caps["supported_ops"] 
                   for op in model_info["operations"]):
                score += 30
            
            # ਟੈਂਸਰ ਸਾਈਜ਼ ਅਨੁਕੂਲਤਾ ਦੀ ਜਾਂਚ ਕਰੋ
            if model_info["max_tensor_size"] <= caps["max_tensor_size"]:
                score += 25
            
            # ਪਾਵਰ ਕਾਰਗੁਜ਼ਾਰੀ ਦਾ ਵਿਚਾਰ
            if constraints.get("power_critical", False):
                score += caps["power_efficiency"] * 25
            
            # ਪ੍ਰਦਰਸ਼ਨ ਪਸੰਦ
            if constraints.get("performance_critical", False):
                if backend == "htp":
                    score += 20
            
            scores[backend] = score
        
        return max(scores, key=scores.get)

# ਵਰਤੋਂ
selector = BackendSelector()
model_info = {
    "operations": ["Conv2d", "ReLU", "Dense"],
    "max_tensor_size": 4 * 1024 * 1024,
    "precision": "int8"
}
constraints = {
    "power_critical": True,
    "performance_critical": True
}

optimal_backend = selector.select_optimal_backend(model_info, constraints)
print(f"Recommended backend: {optimal_backend}")
```

### 1. ਮਾਡਲ ਢਾਂਚਾ ਅਪਟੀਮਾਈਜ਼ੇਸ਼ਨ
- **ਲੇਅਰ ਫਿਊਜ਼ਨ**: Conv+BatchNorm+ReLU ਵਰਗੇ ਓਪਰੇਸ਼ਨਾਂ ਨੂੰ ਮਿਲਾ ਕੇ NPU ਦੀ ਵਧੀਆ ਵਰਤੋਂ
- **ਡੈਪਥ-ਵਾਇਜ਼ ਸੇਪਰੇਬਲ ਕੰਵੋਲੁਸ਼ਨਜ਼**: ਮੋਬਾਈਲ ਤੈਨਾਤ ਲਈ ਇਹਨਾਂ ਨੂੰ ਪਸੰਦ ਕਰੋ
- **ਕੁਆਐਂਟੀਜ਼ੇਸ਼ਨ-ਫ੍ਰੈਂਡਲੀ ਡਿਜ਼ਾਈਨ**: ReLU ਐਕਟੀਵੇਸ਼ਨ ਦੀ ਵਰਤੋਂ ਕਰੋ ਅਤੇ ਉਹਨਾਂ ਓਪਰੇਸ਼ਨਾਂ ਤੋਂ ਬਚੋ ਜੋ ਚੰਗੀ ਤਰ੍ਹਾਂ ਕੁਆਐਂਟੀਜ਼ ਨਹੀਂ ਹੁੰਦੇ

### 2. ਕੁਆਐਂਟੀਸ਼ਨ ਰਣਨੀਤੀ
- **ਪੋਸਟ-ਟ੍ਰੇਨਿੰਗ ਕੁਆਐਂਟੀਜ਼ੇਸ਼ਨ**: ਤੇਜ਼ ਤੈਨਾਤ ਲਈ ਇਸ ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ
- **ਕੈਲੀਬਰੇਸ਼ਨ ਡੇਟਾਸੈਟ**: ਸਾਰੇ ਇਨਪੁੱਟ ਵੈਰੀਏਸ਼ਨ ਕਵਰ ਕਰਨ ਵਾਲਾ ਪ੍ਰਤੀਨਿਧੀ ਡੇਟਾ ਵਰਤੋਂ

- **NPU (HTP)**: CNN ਵਰਕਲੋਡ, ਕੁਆਐਂਟੀਜ਼ ਮਾਡਲ ਅਤੇ ਪਾਵਰ ਸੰਵੇਦਨਸ਼ੀਲ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ
- **GPU**: ਗਣਨਾ-ਗੀਤ ਕਾਰਵਾਈਆਂ, ਵੱਡੇ ਮਾਡਲ ਅਤੇ FP16 ਪ੍ਰਿਸੀਜ਼ਨ ਲਈ ਉਪਯੋਗੀ
- **CPU**: ਅਣਸਮਰਥਿਤ ਕਾਰਵਾਈਆਂ ਅਤੇ ਡਿਬੱਗਿੰਗ ਲਈ ਫਾਲਬੈਕ

```python
# ਕਾਰਕਿਰਦਗੀ ਵਿਸ਼ਲੇਸ਼ਣ ਟੂਲ ਤਿਆਰ ਕਰੋ
class QNNDebugger:
    def __init__(self, model_path):
        self.model_path = model_path
        self.layer_timings = {}
    
    def profile_layers(self, input_data):
        """Profile individual layer performance"""
        # ਇਸ ਲਈ QNN ਪ੍ਰੋਫਾਇਲਿੰਗ APIs ਨਾਲ ਏਕੀਕਰਨ ਦੀ ਲੋੜ ਹੋਵੇਗੀ
        for layer_name in self.get_layer_names():
            start = time.perf_counter()
            # ਲੇਅਰ ਚਲਾਓ
            end = time.perf_counter()
            self.layer_timings[layer_name] = (end - start) * 1000
    
    def analyze_bottlenecks(self):
        """Identify performance bottlenecks"""
        sorted_layers = sorted(
            self.layer_timings.items(), 
            key=lambda x: x[1], 
            reverse=True
        )
        
        print("Top 5 slowest layers:")
        for layer, time_ms in sorted_layers[:5]:
            print(f"  {layer}: {time_ms:.2f} ms")
    
    def suggest_optimizations(self):
        """Suggest optimization strategies"""
        suggestions = []
        
        for layer, time_ms in self.layer_timings.items():
            if time_ms > 10:  # ਲੇਅਰ ਨੂੰ 10ms ਤੋਂ ਵੱਧ ਸਮਾਂ ਲੱਗਦਾ ਹੈ
                if "conv" in layer.lower():
                    suggestions.append(f"Consider depthwise separable conv for {layer}")
                elif "dense" in layer.lower():
                    suggestions.append(f"Consider quantization for {layer}")
        
        return suggestions
```
