## ਐਪਲ MLX ਦਾ ਪਰਿਚਯ

ਐਪਲ MLX ਇੱਕ ਐਾਰੇ ਫਰੇਮਵਰਕ ਹੈ ਜੋ ਖਾਸ ਤੌਰ 'ਤੇ ਐਪਲ ਸਿਲਿਕਾਨ 'ਤੇ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਅਤੇ ਲਚਕੀਲੇ ਮਸ਼ੀਨ ਲਰਨਿੰਗ ਲਈ ਵਿਕਸਤ ਕੀਤਾ ਗਿਆ ਹੈ, ਜੋ ਕਿ ਐਪਲ ਮਸ਼ੀਨ ਲਰਨਿੰਗ ਰਿਸਰਚ ਦੁਆਰਾ ਤਿਆਰ ਕੀਤਾ ਗਿਆ ਹੈ। ਦਸੰਬਰ 2023 ਵਿੱਚ ਰਿਲੀਜ਼, MLX ਐਪਲ ਦਾ ਜਵਾਬ ਹੈ ਜਿਵੇਂ ਪਾਇਟਾਰਚ ਅਤੇ ਟੈਂਸਰਫਲੋ ਵਰਗੇ ਫਰੇਮਵਰਕਾਂ ਨੂੰ, ਖਾਸ ਤੌਰ 'ਤੇ ਮੈਕ ਕੰਪਿਊਟਰਾਂ ਉੱਤੇ ਬਲਦ ਮਸ਼ਹੂਰ ਵੱਡੇ ਭਾਸ਼ਾ ਮਾਡਲ ਸਮਰੱਥਾਵਾਂ ਨੂੰ ਸਮਰਪਿਤ।

### LLM ਲਈ MLX ਨੂੰ ਵਿਸ਼ੇਸ਼ ਕੀ ਬਣਾਉਂਦਾ ਹੈ?

MLX ਨੂੰ ਐਪਲ ਸਿਲਿਕਾਨ ਦੀ ਯੂਨੀਫਾਈਡ ਮੈਮੋਰੀ ਆਰਕੀਟੈਕਚਰ ਦਾ ਪੂਰੀ ਤਰ੍ਹਾਂ ਲਾਭ ਉਠਾਉਣ ਲਈ ਡਿਜ਼ਾਈਨ ਕੀਤਾ ਗਿਆ ਹੈ, ਜੋ ਇਸ ਨੂੰ ਮੈਕ ਕਮਪਿਊਟਰਾਂ ਉੱਤੇ ਵੱਡੇ ਭਾਸ਼ਾ ਮਾਡਲਾਂ ਨੂੰ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਚਲਾਉਣ ਅਤੇ ਫਾਈਨ-ਟਿਊਨ ਕਰਨ ਲਈ ਖਾਸ ਤੌਰ 'ਤੇ ਉਚਿਤ ਬਣਾਉਂਦਾ ਹੈ। ਇਹ ਫਰੇਮਵਰਕ ਉਹ ਬਹੁਤ ਸਾਰੀਆਂ ਸਮੱਸਿਆਵਾਂ ਹਟਾਂਦਾ ਹੈ ਜੋ ਮੈਕ ਉਪਭੋਗਤਾ ਆਮ ਤੌਰ 'ਤੇ LLMs ਨਾਲ ਕੰਮ ਕਰਨ ਵੇਲੇ ਦਰਪੇਸ਼ ਹੁੰਦੀਆਂ ਹਨ।

### LLM ਲਈ MLX ਕੌਣ ਵਰਤਣਾ ਚਾਹੀਦਾ ਹੈ?

- **ਮੈਕ ਉਪਭੋਗਤਾ** ਜੋ ਬਦਲਾਵਰ ਕਲਾਉਡ ਦੀਆਂ ਲੋੜਾਂ ਤੋਂ ਬਿਨਾਂ LLMs ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਚਲਾਉਣਾ ਚਾਹੁੰਦੇ ਹਨ
- **ਰਿਸਰਚਰ** ਜੋ ਭਾਸ਼ਾ ਮਾਡਲ ਦੀ ਫਾਈਨ-ਟਿਊਨਿੰਗ ਅਤੇ ਕਸਟਮਾਈਜ਼ੇਸ਼ਨ ਵਿੱਚ ਪ੍ਰਯੋਗ ਕਰ ਰਹੇ ਹਨ
- **ਡਿਵੈਲਪਰ** ਜੋ ਭਾਸ਼ਾ ਮਾਡਲ ਸਮਰੱਥਾ ਵਾਲੀਆਂ AI ਐਪਲੀਕੇਸ਼ਨ ਬਣਾਉਂਦੇ ਹਨ
- **ਕੋਈ ਵੀ** ਜੋ ਐਪਲ ਸਿਲਿਕਾਨ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਟੈਕਸਟ ਜਨੇਰੇਸ਼ਨ, ਚੈਟ, ਅਤੇ ਭਾਸ਼ਾ ਕੰਮ ਕਰਨਾ ਚਾਹੁੰਦਾ ਹੈ

## LLM ਵਿਕਾਸ ਲਈ ਮੁੱਖ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

### 1. ਯੂਨੀਫਾਈਡ ਮੈਮੋਰੀ ਆਰਕੀਟੈਕਚਰ
ਐਪਲ ਸਿਲਿਕਾਨ ਦੀ ਯੂਨੀਫਾਈਡ ਮੈਮੋਰੀ MLX ਨੂੰ ਵੱਡੇ ਭਾਸ਼ਾ ਮਾਡਲਾਂ ਨੂੰ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਤਰੀਕੇ ਨਾਲ ਸੰਭਾਲਣ ਦੀ ਆਗਿਆ ਦਿੰਦੀ ਹੈ ਬਿਨਾਂ ਕਿਸੇ ਮੈਮੋਰੀ ਕਾਪੀ ਕਰਨ ਦੀ ਲੋੜ ਦੇ, ਜੋ ਹੋਰ ਫਰੇਮਵਰਕਾਂ ਵਿੱਚ ਹੁੰਦਾ ਹੈ। ਇਸਦਾ ਮਤਲਬ ਹੈ ਕਿ ਤੁਸੀਂ ਇੱਕੋ ਹੀ ਹਾਰਡਵੇਅਰ 'ਤੇ ਵੱਡੇ ਮਾਡਲਾਂ ਨਾਲ ਕੰਮ ਕਰ ਸਕਦੇ ਹੋ।

### 2. ਨੈਟਿਵ ਐਪਲ ਸਿਲਿਕਾਨ ਓਪਟੀਮਾਈਜ਼ੇਸ਼ਨ
MLX ਨੂੰ ਐਪਲ ਦੇ M-ਸਿਰੀਜ਼ ਚਿਪਸ ਲਈ ਜਮੀਨ ਤੋਂ ਬਣਾਇਆ ਗਿਆ ਹੈ, ਜੋ ਭਾਸ਼ਾ ਮਾਡਲਾਂ ਵਿੱਚ ਆਮ ਤੌਰ 'ਤੇ ਵਰਤੇ ਜਾਣ ਵਾਲੇ ਟਰਾਂਸਫਾਰਮਰ ਆਰਕੀਟੈਕਚਰ ਲਈ ਸਰਵੋਤਮ ਪ੍ਰਦਰਸ਼ਨ ਮੁਹੱਈਆ ਕਰਦਾ ਹੈ।

### 3. ਕਵਾਂਟੀਜੇਸ਼ਨ ਸਹਾਇਤਾ
4-ਬਿੱਟ ਅਤੇ 8-ਬਿੱਟ ਕਵਾਂਟੀਜੇਸ਼ਨ ਲਈ ਬਣੀਵਟੀ ਸਹਾਇਤਾ ਮੈਮੋਰੀ ਦੀ ਲੋੜ ਘਟਾਉਂਦੀ ਹੈ ਜਦ ਕਿ ਮਾਡਲ ਦੀ ਗੁਣਵੱਤਾ ਬਰਕਰਾਰ ਰਹਿੰਦੀ ਹੈ, ਇਸ ਨਾਲ ਵੱਡੇ ਮਾਡਲ ਉਪਭੋਗਤਾ ਹਾਰਡਵੇਅਰ 'ਤੇ ਚਲਾਏ ਜਾ ਸਕਦੇ ਹਨ।

### 4. ਹੱਗਿੰਗ ਫੇਸ ਇੰਟੀਗ੍ਰੇਸ਼ਨ
ਹੱਗਿੰਗ ਫੇਸ ਪਰਿਵੇਸ਼ ਦੇ ਨਾਲ ਬਿਨਾ ਰੁਕਾਵਟ ਦੇ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਹਜ਼ਾਰਾਂ ਪ੍ਰੀ-ਟ੍ਰੇਨ ਕੀਤੇ ਭਾਸ਼ਾ ਮਾਡਲਾਂ ਤੱਕ ਸੌਖਾ ਪਹੁੰਚ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।

### 5. LoRA ਫਾਈਨ-ਟਿਊਨਿੰਗ
Low-Rank Adaptation (LoRA) ਲਈ ਸਹਾਇਤਾ ਵੱਡੇ ਮਾਡਲਾਂ ਦੀ ਕਮਪਿਊਟیشنل ਸਰੋਤ ਘੱਟ ਹੋਣ ਦੇ ਨਾਲ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਫਾਈਨ-ਟਿਊਨਿੰਗ ਕਰਾਉਂਦੀ ਹੈ।

## MLX ਨਾਲ ਸ਼ੁਰੂਆਤ

```bash
# ਕਮਾਂਡ ਲਾਈਨ ਤੋਂ ਤੇਜ਼ ਲਿਖਤ ਤਿਆਰ ਕਰਨਾ
python -m mlx_lm.generate --model mlx-community/Mistral-7B-Instruct-v0.3-4bit --prompt "Explain artificial intelligence in simple terms:"
```

### ਪਾਇਥਨ API ਉਦਾਹਰਨ

```python
from mlx_lm import load, generate

# ਇਕ ਕੁਆਂਟਾਈਜ਼ਡ ਮਾਡਲ ਲੋਡ ਕਰੋ (ਘੱਟ ਮੇਮੋਰੀ ਵਰਤਦਾ ਹੈ)
model, tokenizer = load("mlx-community/Mistral-7B-Instruct-v0.3-4bit")

# ਟੈਕਸਟ ਜਨਰੇਟ ਕਰੋ
prompt = "Write a short story about a robot learning to understand emotions:"
response = generate(
    model, 
    tokenizer, 
    prompt=prompt, 
    verbose=True,
    max_tokens=300,
    temp=0.7
)
print(response)
```

### ਮਾਡਲ ਲੋਡਿੰਗ ਨੂੰ ਸਮਝਣਾ

```python
from mlx_lm import load

# ਮਾਡਲ ਲੋਡ ਕਰਨ ਦੇ ਵੱਖ-ਵੱਖ ਤਰੀਕੇ
model, tokenizer = load("mistralai/Mistral-7B-Instruct-v0.2")  # ਪੂਰੀ ਸਹੀਤਾ

# ਕਸਟਮ ਸੈਟਿੰਗਾਂ ਨਾਲ ਲੋਡ ਕਰੋ
model, tokenizer = load(
    "qwen/Qwen-7B-Chat",
    tokenizer_config={
        "eos_token": "<|endoftext|>",
        "trust_remote_code": True
    }
)
```

## MLX-LM: ਭਾਸ਼ਾ ਮਾਡਲ

### ਸਹਾਇਤਾ ਪ੍ਰਾਪਤ ਮਾਡਲ ਆਰਕੀਟੈਕਚਰ

MLX-LM ਵਿਆਪਕ ਵਰਗ ਦੇ ਲੋਕਪ੍ਰਿਯ ਭਾਸ਼ਾ ਮਾਡਲ ਆਰਕੀਟੈਕਚਰਾਂ ਨੂੰ ਸਹਾਰਾ ਦਿੰਦਾ ਹੈ:

- **LLaMA ਅਤੇ LLaMA 2** - ਮੀਟਾ ਦੇ ਮੂਲ ਮਾਡਲ
- **Mistral ਅਤੇ Mixtral** - ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਅਤੇ ਤਾਕਤਵਰ ਮਾਡਲ
- **Phi-3** - ਮਾਇਕਰੋਸਾਫਟ ਦੇ ਸੰਕੁਚਿਤ ਭਾਸ਼ਾ ਮਾਡਲ
- **Qwen** - ਅਲੀਬਾਬਾ ਦੇ ਬਹੁਭਾਸ਼ੀ ਮਾਡਲ
- **Code Llama** - ਕੋਡ ਜਨਰੇਸ਼ਨ ਲਈ ਵਿਸ਼ੇਸ਼
- **Gemma** - ਗੂਗਲ ਦੇ ਖੁੱਲ੍ਹੇ ਭਾਸ਼ਾ ਮਾਡਲ

### ਕਮਾਂਡ ਲਾਈਨ ਇੰਟਰਫੇਸ

MLX-LM ਕਮਾਂਡ ਲਾਈਨ ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ ਮਾਡਲਾਂ ਨਾਲ ਕੰਮ ਕਰਨ ਲਈ ਤਾਕਤਵਰ ਸੰਦ ਮੁਹੱਈਆ ਕਰਦਾ ਹੈ:

```bash
# ਬੇਸਿਕ ਟੈਕਸਟ ਜਨਰੇਸ਼ਨ
python -m mlx_lm.generate --model mistralai/Mistral-7B-Instruct-v0.2 --prompt "Hello, how are you?"

# ਖਾਸ ਪੈਰਾਮੀਟਰਾਂ ਨਾਲ ਜਨਰੇਟ ਕਰੋ
python -m mlx_lm.generate \
    --model mlx-community/CodeLlama-7b-Instruct-hf-4bit \
    --prompt "Write a Python function to calculate fibonacci numbers:" \
    --max-tokens 500 \
    --temp 0.3

# ਇੰਟਰਐਕਟਿਵ ਚੈਟ ਮੋਡ
python -m mlx_lm.generate --model mistralai/Mistral-7B-Instruct-v0.2 --prompt "You are a helpful assistant." --max-tokens 100

# ਸਾਰੇ ਵਿਕਲਪਾਂ ਲਈ ਮਦਦ ਪ੍ਰਾਪਤ ਕਰੋ
python -m mlx_lm.generate --help
```

### ਉਨੱਤ ਉਪਯੋਗ ਮਾਮਲਿਆਂ ਲਈ ਪਾਇਥਨ API

```python
from mlx_lm import load, generate

# ਕਈ ਪੀੜੀਆਂ ਲਈ ਇਕ ਵਾਰੀ ਮਾਡਲ ਲੋਡ ਕਰੋ
model, tokenizer = load("mlx-community/Mistral-7B-Instruct-v0.3-4bit")

# ਏਕਲ ਪ੍ਰਾਂਪਟ ਪੀੜੀ ਸਿਰਜਣਾ
def generate_response(prompt, max_tokens=200, temperature=0.7):
    return generate(
        model, 
        tokenizer, 
        prompt=prompt,
        max_tokens=max_tokens,
        temp=temperature,
        verbose=True
    )

# ਬੈਚ ਪੀੜੀ ਸਿਰਜਣਾ
```

### ਬਹੁ ਪਾਸਾ ਸੰਵਾਦ

```python
from mlx_lm import load, generate

model, tokenizer = load("mlx-community/Mistral-7B-Instruct-v0.3-4bit")

# ਗੱਲਬਾਤ ਇਤਿਹਾਸ ਪ੍ਰਬੰਧਨ
class Conversation:
    def __init__(self, model, tokenizer):
        self.model = model
        self.tokenizer = tokenizer
        self.history = []
    
    def add_message(self, role, content):
        self.history.append({"role": role, "content": content})
    
    def generate_response(self, user_input):
        self.add_message("user", user_input)
        
        # ਮਾਡਲ ਲਈ ਗੱਲਬਾਤ ਦਾ ਫਾਰਮੈਟ ਬਣਾਓ
        conversation_text = self.format_conversation()
        
        response = generate(
            self.model,
            self.tokenizer,
            prompt=conversation_text,
            max_tokens=300,
            temp=0.7
        )
        
        self.add_message("assistant", response)
        return response
    
    def format_conversation(self):
        formatted = ""
        for message in self.history:
            if message["role"] == "user":
                formatted += f"[INST] {message['content']} [/INST]"
            else:
                formatted += f" {message['content']} "
        return formatted

# ਵਰਤੋਂ
chat = Conversation(model, tokenizer)
response1 = chat.generate_response("What is machine learning?")
response2 = chat.generate_response("Can you give me a practical example?")
```

### ਪ੍ਰੋਮਪਟ ਇੰਜੀਨੀਅਰਿੰਗ ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ ਅਭਿਆਸ

```python
# ਹਦਾਇਤਾਂ ਦੀ ਪਾਲਣਾ ਕਰਨ ਵਾਲੇ ਮਾਡਲਾਂ ਲਈ ਚੰਗੀ ਪ੍ਰੰਪਟ ਢਾਂਚਾ
def create_instruction_prompt(instruction, context="", examples=""):
    prompt = f"[INST] "
    
    if context:
        prompt += f"Context: {context}\n\n"
    
    if examples:
        prompt += f"Examples:\n{examples}\n\n"
    
    prompt += f"Instruction: {instruction} [/INST]"
    
    return prompt

# ਉਦਾਹਰਨ ਦੇ ਤੌਰ 'ਤੇ ਵਰਤੋਂ
prompt = create_instruction_prompt(
    instruction="Summarize the following text in 2-3 sentences:",
    context="You are a helpful assistant that provides concise summaries.",
    examples="Text: 'Long article...' Summary: 'Brief summary...'"
)
```

### ਪ੍ਰਦਰਸ਼ਨ ਓਪਟੀਮੇਜ਼ੇਸ਼ਨ

```python
# ਵਰਤੋਂ ਕੇਸ ਦੇ ਆਧਾਰ 'ਤੇ ਪੈਰامیਟਰ ਜਨਰੇਸ਼ਨ ਨੂੰ ਠੀਕ ਕਰੋ
def optimize_for_use_case(use_case):
    params = {
        "max_tokens": 200,
        "temp": 0.7,
        "top_p": 0.9
    }
    
    if use_case == "code_generation":
        params.update({"temp": 0.3, "max_tokens": 500})
    elif use_case == "creative_writing":
        params.update({"temp": 0.9, "max_tokens": 800})
    elif use_case == "factual_qa":
        params.update({"temp": 0.3, "max_tokens": 150})
    elif use_case == "summarization":
        params.update({"temp": 0.5, "max_tokens": 300})
    
    return params

# ਵਰਤੋਂ
code_params = optimize_for_use_case("code_generation")
response = generate(model, tokenizer, prompt=prompt, **code_params)
```
