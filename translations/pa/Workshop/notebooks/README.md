# ਵਰਕਸ਼ਾਪ ਨੋਟਬੁੱਕ

> **ਹੱਥ-ਅਨ-ਐਜ ਏਆਈ ਸਿੱਖਣ ਲਈ ਇੰਟਰਐਕਟਿਵ ਜੁਪਾਈਟਰ ਨੋਟਬੁੱਕਸ**
>
> ਪ੍ਰਗਟਿਸੀਲ, ਸਵੈ-ਗਤੀ ਵਾਲੇ ਟਿਊਟੋਰਿਯਲ ਜੋ ਬੁਨਿਆਦੀ ਚੈਟ ਪੂਰੇ ਕਰਨ ਤੋਂ ਲੈ ਕੇ ਐਡਵਾਂਸਡ ਮਲਟੀ-ਏਜੰਟ ਸਿਸਟਮਜ਼ ਤੱਕ ਬਿਲਡ ਹੁੰਦੇ ਹਨ, ਮਾਇਕਰੋਸਾਫਟ ਫਾਉਂਡਰੀ ਲੋਕਲ ਅਤੇ ਸਮਾਲ ਲੈਂਗਵੀਜ਼ ਮਾਡਲਜ਼ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋਏ।

---

## 📖 ਪਰੇਚੈ

ਤੁਹਾਡਾ ਸਵਾਗਤ ਹੈ **ਐਜਈਆਈ ਫਾਰ ਬਿਗਿਨਰਜ਼ ਵਰਕਸ਼ਾਪ ਨੋਟਬੁੱਕਸ** ਸੰਗ੍ਰਹਿ ਵਿੱਚ। ਇਹ ਇੰਟਰਐਕਟਿਵ ਜੁਪਾਈਟਰ ਨੋਟਬੁੱਕਸ ਤੁਹਾਨੂੰ ਹੱਥ-ਲਾਈਵ ਸਿੱਖਣ ਦਾ ਅਨੁਭਵ ਦਿੰਦੀਆਂ ਹਨ ਜਿੱਥੇ ਤੁਸੀਂ ਐਜ ਏਆਈ ਕੋਡ ਨੂੰ ਅਸਲ ਸਮੇਂ ਵਿੱਚ ਲਿਖੋਗੇ, ਚਲਾਵੋਗੇ ਅਤੇ ਅਨੁਭਵ ਕਰੋਗੇ।

### ਜੁਪਾਈਟਰ ਨੋਟਬੁੱਕਸ ਕਿਉਂ?

ਪਰੰਪਰਾਗਤ ਟਿਊਟੋਰਿਯਲ ਦੇ ਮੂਕਾਬਲੇ, ਇਹ ਨੋਟਬੁੱਕਸ ਪ੍ਰਦਾਨ ਕਰਦੀਆਂ ਹਨ:

- **ਇੰਟਰਐਕਟਿਵ ਸਿੱਖਣਾ**: ਕੋਡ ਸੈੱਲ ਚਲਾਓ ਅਤੇ ਤਤਕਾਲ ਨਤੀਜੇ ਦੇਖੋ
- **ਅਨੁਭਵ**: ਪੈਰਾਮੀਟਰ ਬਦਲੋ ਅਤੇ ਅਸਲ ਸਮੇਂ ਵਿੱਚ ਬਦਲਾਵ ਵੇਖੋ
- **ਡਾਕੂਮੈਂਟੇਸ਼ਨ**: ਲਾਈਨ ਦੇ ਅੰਦਰ ਵਿਆਖਿਆਵਾਂ ਅਤੇ ਮਾਰਕਡਾਊਨ ਸੈਲ ਤੁਹਾਨੂੰ ਧਾਰਨਾਵਾਂ ਰਾਹੀਂ ਮਾਰਗਦਰਸ਼ਨ ਕਰਦੇ ਹਨ
- **ਪੁਨਰੁਤਪਾਦਨਯੋਗਤਾ**: ਪੂਰੇ ਕੰਮ ਕਰਨ ਵਾਲੇ ਉਦਾਹਰਨ ਜਿਨ੍ਹਾਂ ਨੂੰ ਤੁਸੀਂ ਸੰਦਰਭਿਤ ਅਤੇ ਦੁਬਾਰਾ ਵਰਤ ਸਕਦੇ ਹੋ
- **ਦਿੱਖ**: ਪ੍ਰਦਰਸ਼ਨ ਮੈਟ੍ਰਿਕਸ, ਐਂਬੈਡਿੰਗ ਅਤੇ ਨਤੀਜੇ ਲਾਈਨ ਵਿੱਚ ਦੇਖੋ

### ਇਹ ਨੋਟਬੁੱਕਸ ਖਾਸ ਕੀ ਬਣਾਉਂਦੀਆਂ ਹਨ?

ਹਰ ਨੋਟਬੁੱਕ ਦਾ ਡਿਜ਼ਾਇਨ ਕੀਤਾ ਗਿਆ ਹੈ **ਉਤਪਾਦਨ-ਤਿਆਰ ਸਰਵੋਤਮ ਅਭਿਆਸਾਂ** ਦੇ ਅਨੁਸਾਰ:

✅ **ਵਿਆਪਕ ਗਲਤੀ ਹੈਂਡਲਿੰਗ** - ਸੁਗਮ ਢੰਗ ਨਾਲ ਡੀਗ੍ਰੇਡੇਸ਼ਨ ਅਤੇ ਜਾਣਕਾਰੀ ਭਰਪੂਰ ਗਲਤੀ ਸੁਨੇਹੇ  
✅ **ਟਾਈਪ ਹਿੰਟਸ ਅਤੇ ਡਾਕੂਮੈਂਟੇਸ਼ਨ** - ਸਾਫ਼ ਫੰਕਸ਼ਨ ਸਿਗਨੇਚਰ ਅਤੇ ਡੋਕਸਟ੍ਰਿੰਗ  
✅ **ਪ੍ਰਦਰਸ਼ਨ ਨਿਗਰਾਨੀ** - ਟੋਕਨ ਵਰਤੋਂ ਟ੍ਰੈਕਿੰਗ ਅਤੇ ਵਿਲੰਬ ਮਾਪ  
✅ **ਮਾਡਿਊਲਰ ਡਿਜ਼ਾਇਨ** - ਦੁਬਾਰਾ ਵਰਤੇ ਜਾਣ ਵਾਲੇ ਸੈਂਪਲ ਜਿਹੜੇ ਤੁਸੀਂ ਆਪਣੇ ਪ੍ਰੋਜੈਕਟਾਂ ਲਈ ਅਨੁਕੂਲ ਕਰ ਸਕਦੇ ਹੋ  
✅ **ਪ੍ਰਗਟਿਸ਼ੀਲ ਜਟਿਲਤਾ** - ਪਿਛਲੇ ਸੈਸ਼ਨਾਂ 'ਤੇ ਤੇਜ਼ੀ ਨਾਲ ਤਿਆਰ ਕੀਤੀ ਗਈ

## 🎯 ਸਿੱਖਣ ਦੇ ਲਕਸ਼

### ਮੁੱਖ ਮੁਹਾਰਤਾਂ ਜੋ ਤੁਸੀਂ ਵਿਕਸਤ ਕਰੋਗੇ

ਇਹ ਨੋਟਬੁੱਕਸ ਚੱਲਾਉਂਦੇ ਹੋਏ, ਤੁਸੀਂ ਮਾਹਿਰ ਹੋਵੋਗੇ:

1. **ਲੋਕਲ ਏਆਈ ਸੇਵਾ ਪ੍ਰਬੰਧਨ**
   - ਮਾਇਕਰੋਸਾਫਟ ਫਾਉਂਡਰੀ ਲੋਕਲ ਸੇਵਾਵਾਂ ਕੰਫਿਗਰ ਅਤੇ ਪ੍ਰਬੰਧਤ ਕਰੋ
   - ਆਪਣੇ ਹਾਰਡਵੇਅਰ ਲਈ ਢੁਕਵੇਂ ਮਾਡਲ ਚੁਣੋ ਅਤੇ ਲੋਡ ਕਰੋ
   - ਸਰੋਤ ਵਰਤੋਂ ਦੀ ਨਿਗਰਾਨੀ ਕਰੋ ਅਤੇ ਪ੍ਰਦਰਸ਼ਨ 'ਚ ਸੁਧਾਰ ਕਰੋ
   - ਸੇਵਾ ਖੋਜ ਅਤੇ ਹੈਲਥ ਚੈੱਕਿੰਗ ਸੰਭਾਲੋ

2. **ਏਆਈ ਐਪਲੀਕੇਸ਼ਨ ਵਿਕਾਸ**
   - ਓਪਨ ਏਆਈ-ਕੰਪੈਟਿਬਲ ਚੈਟ ਪੂਰੇ ਕਰਨ ਨੂੰ ਲੋਕਲ ਤੌਰ 'ਤੇ ਲਾਗੂ ਕਰੋ
   - ਬਿਹਤਰ ਉਪਭੋਗਤਾ ਅਨੁਭਵ ਲਈ ਸਟ੍ਰੀਮਿੰਗ ਇੰਟਰਫੇਸ ਬਣਾਓ
   - ਸਮਾਲ ਲੈਂਗਵੀਜ਼ ਮਾਡਲ ਲਈ ਪ੍ਰਭਾਵਸ਼ালী ਪ੍ਰਾਂਪਟ ਡਿਜ਼ਾਇਨ ਕਰੋ
   - ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ ਲੋਕਲ ਮਾਡਲਜ਼ ਇੰਟੀਗ੍ਰੇਟ ਕਰੋ

3. **ਰੀਟਰੀਵਲ ਆਗਮੈਂਟਡ ਜਨਰੇਸ਼ਨ (RAG)**
   - ਵੇਕਟਰ ਐਂਬੈਡਿੰਗਜ਼ ਨਾਲ ਸੇਮੈਂਟਿਕ ਖੋਜ ਬਣਾਓ
   - LLM ਦੇ ਜਵਾਬਾਂ ਨੂੰ ਖੇਤਰ-ਵਿਸ਼ੇਸ਼ ਦਸਤਾਵੇਜ਼ਾਂ 'ਤੇ ਅਧਾਰਿਤ ਕਰੋ
   - RAGAS ਮੈਟ੍ਰਿਕਸ ਨਾਲ RAG ਦੀ ਗੁਣਵੱਤਾ ਦਾ ਮੁਲਾਂਕਣ ਕਰੋ
   - ਪ੍ਰੋਟੋਟਾਈਪ ਤੋਂ ਉਤਪਾਦਨ ਤੱਕ ਸਕੇਲ ਕਰੋ

4. **ਪ੍ਰਦਰਸ਼ਨ ਅਪਟਾਈਮਾਈਜ਼ੇਸ਼ਨ**
   - ਕਈ ਮਾਡਲਾਂ ਦੀ ਪ੍ਰਣਾਲੀਬੱਧ ਤਰੀਕੇ ਨਾਲ ਬੈਂਚਮਾਰਕਿੰਗ ਕਰੋ
   - ਵਿਲੰਬ, ਥਰੂਪੁੱਟ ਅਤੇ ਪਹਿਲਾ ਟੋਕਨ ਸਮਾਂ ਮਾਪੋ
   - ਸਮਾਲ ਲੈਂਗਵੀਜ਼ ਮਾਡਲਜ਼ ਬਨਾਮ ਵੱਡੇ ਲੈਂਗਵੀਜ਼ ਮਾਡਲਜ਼ ਦੀ ਤੁਲਨਾ ਕਰੋ
   - ਪ੍ਰਦਰਸ਼ਨ/ਗੁਣਵੱਤਾ ਦੇ ਤੌਲਣ ਤੇ ਅਧਾਰਿਤ ਮਾਡਲ ਚੁਣੋ

5. **ਮਲਟੀ-ਏਜੰਟ ਆਰਕੀਸਟਰੇਸ਼ਨ**
   - ਵੱਖ-ਵੱਖ ਕੰਮਾਂ ਲਈ ਵਿਸ਼ੇਸ਼ ਏਜੰਟ ਡਿਜ਼ਾਇਨ ਕਰੋ
   - ਏਜੰਟ ਮੈਮੋਰੀ ਅਤੇ ਸੰਦਰਭ ਪ੍ਰਬੰਧਨ ਲਾਗੂ ਕਰੋ
   - ਜਟਿਲ ਵਰਕਫ਼ਲੋਜ਼ ਵਿੱਚ ਕਈ ਏਜੰਟਾਂ ਦਾ ਸੰਯੋਜਨ ਕਰੋ
   - ਏਜੰਟ ਸਹਿਯੋਗ ਲਈ ਕੋਆਰਡੀਨੇਟਰ ਪੈਟਰਨ ਬਣਾਓ

6. **ਸਿਆਨੇ ਮਾਡਲ ਰਾਊਟਿੰਗ**
   - ਇਰਾਦਾ ਪਛਾਣ ਅਤੇ ਪੈਟਰਨ ਮੇਲ ਵਰਤੋ
   - ਕੁਇਰੀਆਂ ਨੂੰ ਢੁਕਵੇਂ ਮਾਡਲਾਂ ਵੱਲ ਆਪੇ ਹੀ ਰਾਹ ਦਿਓ
   - ਬਹੁ-ਕਦਮ ਪਾਈਪਲਾਈਨ ਬਣਾਓ (ਯੋਜਨਾ → ਚਲਾਉਣਾ → ਸੁਧਾਰ)
   - ਸਕੇਲ ਕਰਨ ਯੋਗ ਮਾਡਲ-ਜਿਵੇਂ-ਟੂਲਜ਼ ਦਾ ਡਿਜ਼ਾਇਨ ਕਰੋ

### ਤੇਜ਼ ਜਾਂਚ

ਸੈਟਅਪ ਜਾਂਚਣ ਲਈ ਪਾਇਥਨ ਸੈੱਲ ਵਿੱਚ ਇਹ ਚਲਾਓ:

```python
from foundry_local import FoundryLocalManager
import openai

# ਮੈਨੇਜਰ ਨੂੰ ਸ਼ੁਰੂ ਕਰੋ (ਆਟੋ-ਡਿਸਕਵਰ ਸੇਵਾ)
manager = FoundryLocalManager("phi-4-mini")

# OpenAI ਕਲਾਇੰਟ ਨੂੰ ਸੰਰਚਿਤ ਕਰੋ
client = openai.OpenAI(
    base_url=manager.endpoint,
    api_key=manager.api_key
)

# ਚੈਟ ਕੰਪਲੀਸ਼ਨ ਦੀ ਜਾਂਚ ਕਰੋ
response = client.chat.completions.create(
    model=manager.get_model_info("phi-4-mini").id,
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

**ਉਮੀਦਗ੍ਰਹਿਤ ਨਤੀਜਾ**: ਸਥਾਨਕ ਮਾਡਲ ਤੋਂ ਸਲਾਮੀ ਦਾ ਜਵਾਬ।
