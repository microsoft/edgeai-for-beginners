# ਬਿਗਿਨਰਜ਼ ਲਈ ਏਜਏਈ - ਵਰਕਸ਼ਾਪ

> **ਪੈਦਾਵਾਰੀ-ਤਿਆਰ ਏਜ ਏਆਈ ਐਪਲੀਕੇਸ਼ਨ ਬਣਾਉਣ ਲਈ ਹਥਿਆਰਬੰਦ ਸਿਖਲਾਈ ਰਾਹ**
>
> ਮਾਇਕਰੋਸਾਫਟ ਫਾਊਂਡਰੀ ਲੋਕਲ ਨਾਲ ਸਥਾਨਕ ਏਆਈ ਤੈਅਆਰ ਕਰਨ ਦੀ ਕਲਾਕਾਰੀ ਸਿੱਖੋ, ਪਹਿਲੀ ਗੱਲਬਾਤ ਮੁਕੰਮਲ ਕਰਨ ਤੋਂ ਮਲਟੀ-ਏਜੰਟ ਆਰਕੀਸਟਰੇਸ਼ਨ ਤੱਕ 6 ਪ੍ਰੋਗਰੈਸੀਵ ਸੈਸ਼ਨਾਂ ਵਿੱਚ।

---

## 🎯 ਜਾਣ-ਪਹਿਚਾਣ

ਤੁਹਾਡਾ ਸਵਾਗਤ ਹੈ **ਬਿਗਿਨਰਜ਼ ਲਈ ਏਜਏਈ ਵਰਕਸ਼ਾਪ** ਵਿੱਚ - ਤੁਹਾਡੇ ਲਈ ਇੱਕ ਪ੍ਰਯੋਗਾਤਮਕ, ਹਥ-ਵਰਤੋਂ ਗਾਈਡ ਜੋ ਬਿਲਕੁਲ ਸਥਾਨਕ ਹਾਰਡਵੇਅਰ 'ਤੇ ਚਲਦੇ ਹੋਏ ਤੇਜ਼ਬੁੱਧੀ ਵਾਲੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਉਣਾ ਸਿਖਾਉਂਦੀ ਹੈ। ਇਹ ਵਰਕਸ਼ਾਪ ਨਿਊਨਤਮ ਕਿਸ਼ਤਾਂ ਵਿੱਚ ਪ੍ਰਗਟਵੀਤ ਸਮੱਸਿਆ-ਹੁਨਰਾਂ ਰਾਹੀਂ ਸਿਧਾਂਤਕ ਏਜ ਏਆਈ ਧਾਰਣਾਵਾਂ ਨੂੰ ਹਕੀਕਤ ਵਿੱਚ ਬਦਲਦੀ ਹੈ, ਜੋ ਮਾਇਕਰੋਸਾਫਟ ਫਾਊਂਡਰੀ ਲੋਕਲ ਅਤੇ ਸਮਾਲ ਲੈਂਗਵੇਜ਼ ਮਾਡਲਜ਼ (SLMs) ਦੀ ਵਰਤੋਂ ਕਰਦੀ ਹੈ।

### ਇਹ ਵਰਕਸ਼ਾਪ ਕਿਉਂ?

**ਏਜ ਏਆਈ ਇਨਕਲਾਬ ਆ ਗਿਆ ਹੈ**

ਸੰਸਾਰ ਭਰ ਦੀਆਂ ਸੰਸਥਾਵਾਂ ਤਿੰਨ ਅਹੰਕਾਰਿਕ ਕਾਰਨਾਂ ਕਰਕੇ ਕਲਾਉਡ-ਨਿਰਭਰ ਏਆਈ ਤੋਂ ਏਜ ਕੰਪਿਊਟਿੰਗ ਵੱਲ ਬਦਲ ਰਹੀਆਂ ਹਨ:

1. **ਗੋਪਨੀਯਤਾ ਅਤੇ ਅਨੁਕੂਲਤਾ** - ਸੰਵੇਦਨਸ਼ੀਲ ਡੇਟਾ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਪ੍ਰੋਸੈਸ ਕਰੋ ਬਿਨਾਂ ਕਲਾਉਡ ਤਰਸ਼ਣ (HIPAA, GDPR, ਵਿੱਤੀ ਨਿਯਮ)
2. **ਕਾਰਗੁਜ਼ਾਰੀ** - ਨੈੱਟਵਰਕ ਦੀ ਦੇਰੀ ਖ਼ਤਮ ਕਰੋ (ਸਥਾਨਕ 50-500ਮਿ.ਸੇ 0.5-2 ਸਕਿੰਟ ਕਲਾਉਡ ਰਾਊਂਡ-ਟ੍ਰਿਪ ਤੋਂ ਕਮ)
3. **ਖਰਚਾ ਨਿਯੰਤਰਣ** - ਪ੍ਰਤੀ-ਟੋਕਨ API ਲਾਗਤ ਦੂਰ ਕਰੋ ਤੇ ਬਿਨਾਂ ਕਲਾਉਡ ਦੇ ਖਰਚਿਆਂ ਦੇ ਸਕੇਲ ਕਰੋ

**ਪਰ ਏਜ ਏਆਈ ਵੱਖਰਾ ਹੈ**

ਥਾਂ ਮੌਕੇ 'ਤੇ ਏਆਈ ਚਲਾਉਣਾ ਨਵੇਂ ਹੁਨਰਾਂ ਦੀ ਮੰਗ ਕਰਦਾ ਹੈ:
- ਸਰੋਤ ਸੀਮਾਵਾਂ ਲਈ ਮਾਡਲ ਚੋਣ ਅਤੇ ਸੁਧਾਰ
- ਸਥਾਨਕ ਸੇਵਾ ਪ੍ਰਬੰਧਨ ਅਤੇ ਹਾਰਡਵੇਅਰ ਐਕਸੈਲੇਰੇਸ਼ਨ
- ਛੋਟੇ ਮਾਡਲਾਂ ਲਈ ਪ੍ਰੋੰਪਟ ਇੰਜੀਨੀਅਰਿੰਗ
- ਏਜ ਡਿਵਾਈਸਾਂ ਵਾਸਤੇ ਪੈਦਾਵਾਰੀ ਤੈਅਆਰੀ ਪੈਟਰਨਜ਼

**ਇਹ ਵਰਕਸ਼ਾਪ ਇਹਹੁਣ ਹੁਨਰ ਪ੍ਰਦਾਨ ਕਰਦੀ ਹੈ**

6 ਧਿਆਨ ਕੇਂਦਰਿਤ ਸੈਸ਼ਨਾਂ (~ਕੁਲ 3 ਘੰਟੇ) ਵਿੱਚ, ਤੁਸੀਂ "ਹੈਲੋ ਵਰਲਡ" ਤੋਂ ਪੈਦਾਵਾਰੀ ਤੈਅਆਰ ਮਲਟੀ-ਏਜੰਟ ਸਿਸਟਮ ਤੱਕ ਅੱਗੇ ਵਧੋਗੇ - ਸਾਰੇ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ 'ਤੇ ਚੱਲ ਰਹੇ ਹੋਣਗੇ।

## 📚 ਸਿੱਖਣ ਦੇ ਲਕੜ

ਇਸ ਵਰਕਸ਼ਾਪ ਨੂੰ ਪੂਰਾ ਕਰਨ ਨਾਲ, ਤੁਸੀਂ ਸਮਰੱਥ ਹੋ ਜਾਓਗੇ:

### ਮੁੱਖ ਯੋਗਤਾਵਾਂ
1. **ਸਥਾਨਕ ਏਆਈ ਸੇਵਾਵਾਂ ਤੈਅਆਰ ਅਤੇ ਪ੍ਰਬੰਧਨ ਕਰੋ**
   - ਮਾਇਕਰੋਸਾਫਟ ਫਾਊਂਡਰੀ ਲੋਕਲ ਇੰਸਟਾਲ ਅਤੇ ਕਨਫਿਗਰ ਕਰੋ
   - ਏਜ ਡਿਪਲੌਇਮੈਂਟ ਲਈ ਉਚਿਤ ਮਾਡਲ ਚੁਣੋ
   - ਮਾਡਲ ਲੀਫਸਾਈਕਲ ਪ੍ਰਬੰਧਨ (ਡਾਊਨਲੋਡ, ਲੋਡ, ਕੈਸ਼)
   - ਸਰੋਤ ਉਪਯੋਗ ਨਿਗਰਾਨੀ ਅਤੇ ਕਾਰਗੁਜ਼ਾਰੀ ਸੁਧਾਰ

2. **ਏਆਈ-ਸ਼ਕਤਿਸ਼ਾਲੀ ਐਪਲੀਕੇਸ਼ਨ ਬਣਾਓ**
   - ਸਥਾਨਕ ਤੌਰ 'ਤੇ OpenAI-ਅਨੁਕੂਲ ਗੱਲਬਾਤ ਮੁਕੰਮਲ ਕਰੋ
   - ਸਮਾਲ ਲੈਂਗਵੇਜ਼ ਮਾਡਲ ਲਈ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਪ੍ਰੋੰਪਟ ਡਿਜ਼ਾਈਨ ਕਰੋ
   - ਬਿਹਤਰ ਯੂਐਕਸ ਲਈ ਸਟ੍ਰੀਮਿੰਗ ਜਵਾਬਾਂ ਸੰਭਾਲੋ
   - ਮੌਜੂਦਾ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ ਸਥਾਨਕ ਮਾਡਲ ਸ਼ਾਮਲ ਕਰੋ

3. **RAG (ਰਿਟਰੀਵਲ ਆਗਮੈਂਟਡ ਜਨਰੇਸ਼ਨ) ਸਿਸਟਮ ਬਣਾਓ**
   - ਐਮਬੈੱਡਿੰਗ ਨਾਲ ਸੈਮਾਂਟਿਕ ਖੋਜ ਬਣਾਓ
   - ਡੋਮੇਨ-ਵਿਸ਼ੇਸ਼ ਗਿਆਨ ਵਿੱਚ LLM ਜਵਾਬ ਪੱਕਾ ਕਰੋ
   - RAG ਗੁਣਵੱਤਾ ਉਦਯੋਗ-ਮਿਆਰੀ ਮੈਟਰਿਕਸ ਨਾਲ ਮੁਲਾਂਕਣ ਕਰੋ
   - ਨਮੂਨਾ ਤੋਂ ਪੈਦਾਵਾਰੀ ਤਕ ਸਕੇਲਿੰਗ ਕਰੋ

4. **ਮਾਡਲ ਕਾਰਗੁਜ਼ਾਰੀ ਸੁਧਾਰੋ**
   - ਆਪਣੇ ਉਪਯੋਗ ਮਾਮਲੇ ਲਈ ਕਈ ਮਾਡਲBenchmarks ਕਰੋ
   - ਦੇਰੀ, ਥਰੂਪੁੱਟ, ਅਤੇ ਪਹਿਲਾ-ਟੋਕਨ ਸਮਾਂ ਮਾਪੋ
   - ਗਤੀ/ਗੁਣਵੱਤਾ ਵਪਾਰ ਵਿੱਥ ਸਹੀ ਮਾਡਲ ਚੁਣੋ
   - ਅਸਲੀ ਸਥਿਤੀਆਂ ਵਿੱਚ SLM ਅਤੇ LLM ਵਪਾਰ ਵਿੱਥੋਂ ਦੀ ਤੁਲਨਾ ਕਰੋ

5. **ਮਲਟੀ-ਏਜੰਟ ਸਿਸਟਮ ਆਰਕੀਸਟਰੇਸ਼ਨ ਕਰੋ**
   - ਵੱਖ-ਵੱਖ ਕੰਮਾਂ ਵਾਸਤੇ ਵਿਸ਼ੇਸ਼ ਏਜੰਟ ਡਿਜ਼ਾਈਨ ਕਰੋ
   - ਏਜੰਟ ਮੈਮੋਰੀ ਅਤੇ ਸੰਦਰਭ ਪ੍ਰਬੰਧਨ ਲਾਗੂ ਕਰੋ
   - ਜਟਿਲ ਵਰਕਫਲੋ ਵਿੱਚ ਏਜੰਟਾਂ ਦਾ ਕੋਆਰਡੀਨੇਸ਼ਨ ਕਰੋ
   - ਕਈ ਮਾਡਲਜ਼ ਵਿੱਚ ਬੁੱਧੀਮਾਨ ਤਰੀਕੇ ਨਾਲ ਬੇਨਤੀ ਰੂਟਿੰਗ ਕਰੋ

6. **ਪੈਦਾਵਾਰੀ ਤਿਆਰ ਹੱਲ ਤੈਅਆਰ ਕਰੋ**
   - ਗਲਤੀ ਸੰਭਾਲਣ ਅਤੇ ਦੁਬਾਰਾ ਕੋਸ਼ਿਸ਼ ਲਾਜ਼ਮੀ ਕਰੋ
   - ਟੋਕਨ ਖਪਤ ਅਤੇ ਸਿਸਟਮ ਸਰੋਤਾਂ ਦੀ ਨਿਗਰਾਨੀ ਕਰੋ
   - ਟੂਲ ਪੈਟਰਨ ਦੇ ਨਾਲ ਸਕੇਲ ਕਰਨਯੋਗ ਆਰਕੀਟੈਕਚਰ ਬਣਾਓ
   - ਏਜ ਤੋਂ ਹਾਈਬ੍ਰਿਡ (ਏਜ + ਕਲਾਉਡ) ਤੱਕ ਮਾਈਗ੍ਰੇਸ਼ਨ ਪੱਥ ਯੋਜਨਾ ਬਣਾਓ

## CLI ਕਮਾਂਡ ਸਹੀਤਾ ਐਪੈਂਡਿਕਸ

ਵਰਕਸ਼ਾਪ ਸਾਜ਼-ਬੱਧ Foundry Local CLI ਕਮਾਂਡਾਂ ਹੀ ਵਰਤਦਾ ਹੈ ਜੋ ਮਨਨਯੋਗ ਅਤੇ ਸਥਿਰ ਹਨ।

### ਸਥਿਰ ਕਮਾਂਡਾਂ ਜਿਨ੍ਹਾਂ ਦਾ ਹਵਾਲਾ ਦਿੱਤਾ ਗਿਆ

| ਸ਼੍ਰੇਣੀ | ਕਮਾਂਡ | ਉਦੇਸ਼ |
|----------|---------|---------|
| ਕੋਰ | `foundry --version` | ਇੰਸਟਾਲ ਕੀਤੀ ਵਰਜਨ ਦਿਖਾਓ |
| ਸਰਵਿਸ | `foundry service start` | ਸਥਾਨਕ ਸਰਵਿਸ ਚਾਲੂ ਕਰੋ (ਜੇ ਆਟੋ ਨ ਜਾਏ ਤਾਂ) |
| ਸਰਵਿਸ | `foundry service status` | ਸਰਵਿਸ ਦੀ ਸਥਿਤੀ ਦਿਖਾਓ |
| ਮਾਡਲ | `foundry model list` | ਕੈਟਾਲੋਗ / ਉਪਲੱਬਧ ਮਾਡਲ ਸੂਚੀਬੱਧ ਕਰੋ |
| ਮਾਡਲ | `foundry model download <alias>` | ਮਾਡਲ ਦੇ ਭਾਰ ਤੁਸੀਂ ਕੈਸ਼ ਵਿੱਚ ਡਾਊਨਲੋਡ ਕਰੋ |
| ਮਾਡਲ | `foundry model run <alias>` | ਸਥਾਨਕ ਤੌਰ ਤੇ ਮਾਡਲ ਲਾਂਚ ਕਰੋ; ਇਕ-ਸ਼ਾਟ ਲਈ `--prompt` ਨਾਲ ਮਿਲਾ ਕੇ |
| ਮਾਡਲ | `foundry model unload <alias>` / `foundry model stop <alias>` | ਯਾਦاشت ਤੋਂ ਮਾਡਲ ਨੂੰ ਅਨਲੋਡ ਕਰੋ (ਜੇ ਸਮਰਥਿਤ ਹੈ) |
| ਕੈਸ਼ | `foundry cache list` | ਕੈਸ਼ ਕੀਤੇ (ਡਾਊਨਲੋਡ ਕੀਤੇ) ਮਾਡਲ ਸੂਚੀਬੱਧ ਕਰੋ |

### ਇੱਕ-ਸ਼ਾਟ ਪ੍ਰੌੰਪਟ ਪੈਟਰਨ

ਪੁਰਾਣੇ `model chat` ਸਬਕਮਾਂਡ ਦੇ ਬਦਲੇ:

```powershell
foundry model run <alias> --prompt "Your question here"
```

ਇਹ ਇੱਕ ਜੁੜੀ ਪ੍ਰੌੰਪਟ/ਜਵਾਬ ਸਾਇਕਲ ਨੂੰ ਅੰਜਾਮ ਦਿੰਦਾ ਹੈ ਅਤੇ ਫਿਰ ਬਾਹਰ ਨਿਕਲਦਾ ਹੈ।

### ਹਟਾਏ ਗਏ / ਬਚਾਏ ਗਏ ਪੈਟਰਨ

| ਪੁਰਾਣੇ / ਗੈਰ-ਦਸਤਾਵੇਜ਼ੀਕ੍ਰਿਤ | ਬਦਲ / ਦਿਸ਼ਾ-ਨਿਰਦੇਸ਼ |

## ਤੇਜ਼ CLI → SDK ਮਾਈਗ੍ਰੇਸ਼ਨ ਟੇਬਲ

| ਕਾਰਜ | CLI ਇਕ-ਸਤਰ | SDK (ਪਾਈਥਨ) ਸਮਕੱਖ | ਨੋਟਸ |
|------|---------------|-------------------------|-------|
| ਇੱਕ ਮਾਡਲ ਇੱਕ ਵਾਰੀ ਚਲਾਓ (ਪ੍ਰੌੰਪਟ) | `foundry model run phi-4-mini --prompt "Hello"` | `manager=FoundryLocalManager("phi-4-mini"); client=OpenAI(base_url=manager.endpoint, api_key=manager.api_key or "not-needed"); client.chat.completions.create(model=manager.get_model_info("phi-4-mini").id, messages=[{"role":"user","content":"Hello"}])` | SDK ਸੇਵਾ ਅਤੇ ਕੈਸ਼ਿੰਗ ਆਟੋਮੈਟਿਕ ਭਰਦੀ ਹੈ |
| ਮਾਡਲ ਡਾਊਨਲੋਡ (ਕੈਸ਼) ਕਰੋ | `foundry model download qwen2.5-0.5b` | `FoundryLocalManager("qwen2.5-0.5b")  # ਡਾਊਨਲੋਡ/ਲੋਡ ਕਰਦਾ ਹੈ` |  ਜੇ ਅਲਾਇਸ ਕਈ ਬਿਲਡਾਂ ਨੂੰ ਨਕਸ਼ਾ ਕਰਦਾ ਹੈ ਤਾਂ ਮੈਨੇਜਰ ਸਭ ਤੋਂ ਵਧੀਆ ਵਰਜਨ ਚੁਣਦਾ ਹੈ |
| ਕੈਟਾਲੋਗ ਸੂਚੀਬੱਧ ਕਰੋ | `foundry model list` | `# ਹਰ ਅਲਾਇਸ ਲਈ ਮੈਨੇਜਰ ਵਰਤੋਂ ਜਾਂ ਜਾਣੂ ਸੂਚੀ ਬਣਾਓ` | CLI ਸੰਘਟਿਤ ਹੈ; SDK ਇਸ ਵੇਲੇ ਪਰ-ਅਲਾਇਸ ਇੰਸਟੈਂਸ਼ੀਏਸ਼ਨ ਹੈ |
| ਕੈਸ਼ ਕੀਤੇ ਮਾਡਲਾਂ ਦੀ ਸੂਚੀ | `foundry cache list` | `manager.list_cached_models()` | ਮੈਨੇਜਰ ਸ਼ੁਰੂਆਤੀ ਮੰਜ਼ਲ (ਕਿਸੇ ਵੀ ਅਲਾਇਸ ਨਾਲ) ਤੋਂ ਬਾਅਦ |
| Endpoint URL ਪ੍ਰਾਪਤ ਕਰੋ | (ਅਸਪਸ਼ਟ) | `manager.endpoint` | OpenAI-ਸੰਮਤ ਕਲਾਇੰਟ ਬਣਾਉਣ ਲਈ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ |
| ਮਾਡਲ ਗਰਮ ਕਰੋ | `foundry model run <alias>` ਫਿਰ ਪਹਿਲਾ ਪ੍ਰੌੰਪਟ | `chat_once(alias, messages=[...])` (ਯੂਟਿਲਿਟੀ) | ਯੂਟਿਲਿਟੀਜ਼ ਪਹਿਲੀ ਠੰਢੀ ਲੇਟੈਂਸੀ ਵਾਰਮਅਪ ਸੰਭਾਲਦੀਆਂ ਹਨ |
| ਲੇਟੈਂਸੀ ਮਾਪੋ | `python -m session03.benchmark_oss_models` | `import benchmark_oss_models` (ਜਾਂ ਨਵਾਂ ਐਕਸਪੋਰਟਰ ਸਕ੍ਰਿਪਟ) | ਇਕਸਾਰ ਮੈਟ੍ਰਿਕਸ ਲਈ ਸਕ੍ਰਿਪਟ ਤਰਜੀਹੀ |
| ਰੋਕੋ / ਮਾਡਲ ਅਨਲੋਡ ਕਰੋ | `foundry model unload <alias>` | (ਸਰਵਿਸ / ਪ੍ਰਕਿਰਿਆ ਨੂੰ ਮੁੜ ਚਾਲੂ ਕਰੋ - ਪਰਦਰਸ਼ਿਤ ਨਹੀਂ) | ਆਮ ਤੌਰ ਤੇ ਵਰਕਸ਼ਾਪ ਪ੍ਰਵਾਹ ਲਈ ਲੋੜੀਂਦਾ ਨਹੀਂ |
| ਟੋਕਨ ਵਰਤੋਂ ਪ੍ਰਾਪਤ ਕਰੋ | (ਆਉਟਪੁੱਟ ਵੇਖੋ) | `resp.usage.total_tokens` | ਜੇ ਬੈਕਐਂਡ ਵਰਤੋਂ ਵਸਤੂ ਵਾਪਸ ਕਰਦਾ ਹੈ ਤਾਂ ਪ੍ਰਦਾਨ ਕੀਤਾ ਜਾਂਦਾ ਹੈ |

## ਬੈਂਚਮਾਰਕ ਮਾਰਕਡਾਊਨ ਐਕਸਪੋਰਟ

ਨਵਾਂ ਬੈਂਚਮਾਰਕ ਚਲਾਉਣ ਲਈ ਸਕ੍ਰਿਪਟ `Workshop/scripts/export_benchmark_markdown.py` ਵਰਤੋਂ ਕਰੋ (ਉਹੀ ਤਰੱਕੀ ਜਿਵੇਂ `samples/session03/benchmark_oss_models.py`) ਅਤੇ GitHub-ਮਿੱਤਰ ਮਾਰਕਡਾਊਨ ਟੇਬਲ ਨਾਲ ਕੱਚਾ JSON ਜਾਰੀ ਕਰੋ।

```powershell
python Workshop\scripts\export_benchmark_markdown.py --models "qwen2.5-0.5b,mistral-7b" --prompt "Explain retrieval augmented generation briefly." --rounds 3 --output benchmark_report.md
```

ਤਿਆਰ ਕੀਤੀਆਂ ਫਾਇਲਾਂ:
| ਫਾਇਲ | ਸਮੱਗਰੀ |
|------|----------|
| `benchmark_report.md` | ਮਾਰਕਡਾਊਨ ਟੇਬਲ + ਵਿਆਖਿਆ ਸੂਚਕ |
| `benchmark_report.json` | ਕੱਚਾ ਮੈਟਰਿਕਸ ਏਰੇ (ਤਰੱਕੀ ਜਾਂ ਢਿੱਲ ਖੋਜ ਲਈ) |
